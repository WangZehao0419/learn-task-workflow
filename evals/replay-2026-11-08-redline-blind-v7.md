## RL-09

```text
不是一回事，但只差一步：**相关系数**是**协方差**标准化之后的样子。

你算相关系数的时候，分子其实一直是协方差：

r = Cov(X, Y) / (σx · σy)

Cov(X, Y) 就是 X 与 Y 的协方差，σx、σy 分别是 X、Y 的标准差。分子带单位，分母带着同样的单位，一除就约掉了，所以 r 是没有单位的纯数。

协方差本身说的是：X 偏离自己均值、Y 也偏离自己均值，这两个偏离同号还是反号，平均下来有多强。拿一组具体数字看，X 取 1、2、3，Y 取 2、4、6：

均值 x̄ = 2、ȳ = 4；三对偏离乘积 (-1)×(-2)、0×0、1×2 加起来是 4，除以 3，协方差 = 4/3。两个标准差的乘积是 √(2/3)·√(8/3) = 4/3，所以 r = 1。

把 Y 的单位从厘米换成毫米，Y 变成 20、40、60：协方差跟着变成 40/3，大了十倍；r 还是 1。

认这两个量，看三条：

- 看单位：协方差带着 X 的单位乘 Y 的单位，换单位数值就变；相关系数无量纲，换单位不动。
- 看范围：协方差可正可负、可大可小，只有符号能直接读方向；相关系数压在 -1 到 1 之间，绝对值就能比强弱。
- 看用途：只想知道两列数一起动的方向对不对，协方差够；想知道关系有多紧，必须换相关系数。

最容易踩的坑是**拿协方差的数值比强弱**。同一个 X 配厘米版 Y 和毫米版 Y，协方差差十倍，关系却一模一样。

边界也记一条：协方差为 0 只说明没有线性关系，不等于两个变量没关系；r = 0 是同一个意思，只是 r 还多告诉你它离一条直线有多近。

上面按除以 n 算；换成除以 n−1，协方差数值会变，r 不变。

协方差的完整算法和性质，正式讲的时候再展开。先问你一个学过的：同一组数据，把 Y 的单位从厘米换成毫米，你算出的 r 会不会变？为什么？
```
