## RL-02

```text
**虚拟语气这一轮先讲，题随后就到。**

虚拟语气你还没学过，直接做题，练出来的是错的直觉，回头改比新学还费劲。边做边学可以，只是顺序换一下：先看我怎么走一遍，你立刻上手。这一轮大概十分钟，讲完马上三道题。

先给一张地图。虚拟语气不是一条规则，是一个家族：[五成员表格：if 条件句虚拟 / wish 与 if only / as if 与 as though / 建议要求类动词后 / It's time 与 would rather]。

今天只攻第一支里的一种：**if 条件句、与现在事实相反**。

核心机制一句话：虚拟语气不告诉你事情什么时候发生，它告诉你这件事不是真的；英语的办法是**把时态整体往后挪一格**。

看一个完整示范：**If I were you, I would take the job.** [四步：判真假 → if 从句挪一格、be 一律 were → 主句 would 加原形 → 回读核对]

最容易错的是第一步。很多人一看到 were、had 就以为在讲过去，其实它们只是「挪了一格」的记号。判断依据永远是「与哪个时间的事实相反」，不是动词长什么样。

先给我一个十秒钟的回答：**If I had a car, I would drive you home.** 这句是与现在的事实相反，还是与过去的事实相反？你是从哪个词看出来的？

答完这一句，我立刻发三道题：一道带你补最后一步，两道你自己做。
```

## RL-09

```text
**不是一回事。** 你已经会的相关系数，是协方差去掉单位之后的版本。

先给你一张地图，这三个量是同一条线上的三步：
- 方差：一个变量自己的波动有多大。
- 协方差：两个变量是不是一起动——你大我也大就是正的，你大我小就是负的。它带着原来的单位。
- 相关系数：把协方差除以两个标准差，单位消掉，数值压进 -1 到 1。

写成式子就是：相关系数 r = 协方差 ÷（X 的标准差 × Y 的标准差）。

所以分工很清楚：协方差回答「有没有一起动、往哪个方向动」，相关系数在这个基础上再回答「一起动得有多紧」。

关键差别落在能不能直接比大小上。协方差带单位，把身高的单位从厘米换成米，它的数值就跟着缩小一百倍，所以两个协方差放在一起比没有意义；相关系数无量纲，换什么单位都是同一个数。

一个边界先说在这儿：在两个变量各自都有波动的前提下，协方差为零和相关系数为零是同一件事，都只说明没有线性关系，不等于两个变量没有关系。

协方差正式展开会放在后面的知识点单独讲，今天不铺开。回到我们刚才的位置——你用一句话说说：相关系数比协方差多做了哪一步，为什么正是这一步让它能直接比大小？
```
