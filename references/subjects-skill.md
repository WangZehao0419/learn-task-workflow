# skill 学科群 正本册

> 本册是「skill」学科族的四类切片（plan / teach / practice / review）合一。

## 艺术与技能群 · 规划切片

### 群边界与能力边界

本群：音乐、美术、体育、手工、驾驶、厨艺等以**程序性技能＋身体协调**为主的内容。

**能力边界必须在 S0 就说明，不等到上课才说**：对话式家教没有身体、没有器材、没有实时动作反馈，下列内容**不能教**——实时动作纠错、示范（无法展示身体动作）、器材与场地的手感反馈、视奏与听音的即时判定、需要物理接触的技法（推拿、器械操作）。能教的是：练习设计、反馈解释、注意焦点改写、心理表象训练、练习排程、乐理与规则、作品分析与评图。

把这条边界说清楚不是免责，而是让学员知道「哪部分需要真人或面授补上」。

默认内容类型分布：程序型约八成，概念型约一成半，记忆型少量。S2 按实际目清单核正。

### 内容结构与前置链

- **共同结构**：基本动作／元素 → 组合 → 完整作品／成套动作 → 表现力与风格。
- **前置断层高发点**：基本动作未自动化的阶段就上完整作品，导致每次都在同一处卡住；缺乏对「正确是什么样」的感知（听不出、看不出），就无从自我纠正。
- **感知先于动作**：能分辨好坏差异（听辨、观察、评图）是自我纠正的前提。对话式家教在这方面反而有优势——可以用文字把差异描述清楚。

### 目标深度锚点

按动作技能三阶段定目标（Fitts & Posner）：**认知阶段**（知道要做什么，动作不连贯）→ **联结阶段**（动作连贯，能自我纠正）→ **自动化阶段**（不需注意即可完成）。

- 认知阶段的目标是「说得对、做得慢」；联结阶段是「稳定重复」；自动化阶段才是「在压力下仍稳」。
- 每个阶段的教学法不同：认知阶段要显式示范与分解，联结阶段要变式与反馈，自动化阶段要压力情境与减少反馈。
- **不按练习时长计进度**，按「带反馈的结构化练习事件数」计——练习量与表现的相关在各领域都远低于直觉，教育领域尤其低。

### 排期侧重

- **短而频**：技能靠高频短练维持，一周一次长练远不如每天二十分钟。
- **练习单元要小**：每次练一个具体难点（一个小节、一个动作、一个笔触），不练「整首曲子」「整张画」。
- **反馈点前置**：练之前先说清「这次只看什么」，练完立即对照。
- **线下任务单列**：需要动手的练习作为线下任务布置，家教负责设计任务与复盘结果，不假装能陪同练习。
- **考前／演出前**：不排新内容，只做压力情境模拟与流程复盘。

## 艺术与技能群 · 出题切片

### 题型阶梯

本群的「题」多数是**判断与设计**，不是计算：

1. **听辨／观察判断题**：给两段材料（录音、图、视频帧）问哪段更符合标准、差在哪。需要学员自己带到线下完成，家教判读其描述。
2. **诊断题**：给一段自己的练习录音／作品，问「最大的一个问题是什么、下一步改哪一个变量」。
3. **练习设计题**：给定难点，要求写出练习方案（练什么／怎么练／多久／怎么自查）。
4. **规则与乐理／技法概念题**：调式、和声进行、构图法则、运动规则——考「何时用」而不是「叫什么」。
5. **复盘题**：给一份练习日志，问「这次调整有效吗、依据是什么」。

### 群级共享误区库

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 一万小时定律 | 「练够一万小时就能成专家」 | 通俗读物简化 | 练习量对表现的解释力在教育领域极低，各领域也远非决定性 |
| 练得久＝练得好 | 从头到尾匀速重复整首 | 用时长代替设计 | 高质量练习的特征是「停下思考 + 错误立即修正 + 变速与分段」 |
| 重复即巩固 | 弹错／画错也继续重复 | 以为次数会覆盖错误 | 重复的是错误模式，固化后更难改 |
| 慢练万能 | 永远慢速完整练习 | 慢练确实有用 | 需要变速 + 分段 + 目标短句的组合，不是一味慢 |
| 内部焦点更精细 | 「注意手腕角度」优于「把球送到目标」 | 觉得越具体越准 | 指向动作效果的指令稳定优于指向身体部位 |
| 只分块不混排 | 一直分块练，从不打乱 | 分块当下见效快 | 分块利于习得、随机利于迁移，两段都要走 |
| 心理练习可替代实练 | 只想不练 | 省力 | 心理练习是补充，替代不了实练 |
| 右脑画画 | 「画画靠开发右脑」 | 神经迷思 | 左右脑分工说法无实证；观察训练本身有用，与其绑定的理论不成立 |

### 判定题构造

问「改哪一个」而不是「哪里不对」：给三条可能的调整方向问先改哪个、给两个版本的练习方案问哪个更可能有效、给一个已经练了很久仍卡住的片段问「问题在练法还是在难度」。干扰项要是「听起来有道理但顺序错了」的方案。

### 答案形态与最小单元

- 练习设计用 `练习方案：` 起笔，分段为「练什么 / 怎么练 / 多久 / 怎么自查 / 带回什么」，每段可独立核对。
- 诊断题用 `诊断：` 起笔，写「主要问题 / 依据 / 下一步调整」三段。
- 概念题用 `答：` 起笔，写「定义 + 一个例子 + 一处易错」。
- **不编造「无法远程评估」的结论**：涉及手感、音色、身体感受的判断，明确写「本条需线下确认」，不假装能判。

### 视觉任务

用学员自己的作品照片、录音波形、原谱原画与范例对照，原始材料由学员提供并记录来源；替代禁令与证据资格见 `references/assessment.md`「视觉任务证据」。需要听辨的任务在纯文字会话中不声明为视觉任务，改为「描述差异」的文字任务。

### 给分点结构

练习方案按「难点界定 / 步骤 / 自查判据」三段给分；诊断题按「问题定位 / 依据 / 调整方案」三段；概念题按「定义 / 例子 / 易错」三段。

## 艺术与技能群 · 复习切片

### 复习形态与间隔侧重

- **复习的是练习日志，不是知识点**：每次开课先看上次的任务单与日志，问「这一条改掉了吗、依据是什么」。
- **技能维持靠高频短练**：中断超过一周，联结阶段的动作会明显退化；复习间隔比认知类内容更短。
- **概念与规则部分按间隔复习**：乐理、构图法则、运动规则属记忆与概念型，走常规间隔；不要因为「整体是技能」就跳过。
- **变式复习优先于原样重复**：在同样的难度上换情境（换一段曲、换一个角度、换一个对手站位），比重复同一条更能巩固。
- **阶段性录像／录音对照**：隔一段时间对比同一片段的早期与现在版本，差异比「感觉进步了」可靠。

### 错因分流与纠错脚本

| 错因 | 判别信号 | 纠错动作 |
|---|---|---|
| 动作未自动化 | 知道怎么做但一快就乱 | 降到慢速分块，先求稳再求快；不加新内容 |
| 感知不足 | 听不出、看不出差别 | 先练分辨（对比范例），再练动作 |
| 注意力方向错 | 越想越僵 | 把指令从身体部位改写成动作效果 |
| 练习设计错 | 练了很久不变 | 检查是否在练「整段」而非「难点」，是否缺少即时反馈 |
| 反馈依赖 | 有人提示才对，自己不行 | 降低反馈频率，改为先自评再对照 |
| 迁移不足 | 固定条件下行，换个情境就崩 | 改随机混排，加压力情境 |

**纠错话术**：技能类错误先问「你练的时候注意到什么」，而不是直接给方法——多数时候问题是没感知到差异，而不是不知道方法。

### 冲刺侧重（方法层）

- **压力情境模拟**：限时、连贯、一次过、有人在看——演出前要练的就是这个，不是再抠细节。
- **不排新内容**：最后阶段只做流程复盘与热身方案，学新动作会打乱已经稳定的动作。
- **热身与流程写成一页纸**：热身步骤、上台前检查项、失误后的恢复动作。
- **睡眠与体力计入计划**：技能类表现对状态敏感，考前熬夜的代价比多练一小时大。
- **边界再说明一次**：最后阶段涉及手感与身体状态的判断，明确告诉学员这部分需要线下确认。

## 艺术与技能群 · 讲授切片

### 讲授侧重（六拍内的群差异）

- **先建「正确是什么样」的感知**：讲任何动作或技法，先用文字把好与差的差别描述清楚（哪里紧、哪里松、快慢如何变）。学员听不出、看不出差异，就永远无法自我纠正。
- **按阶段换教法**：认知阶段给分解动作 + 显式说明 + 慢速示范描述；联结阶段给变式练习 + 即时反馈；自动化阶段给压力情境（限时、连贯、公开）并逐步减少反馈。
- **注意焦点指向效果，不指向身体**：不说「手肘抬高三十度」，说「让球飞向那棵树」；不说「手指这样动」，说「让声音连到下一个音」。指向动作效果的指令，学习效果稳定优于指向身体部位的指令——尤其在动作已经能大致完成之后。
- **分块与随机按阶段用**：习得期用分块（同一个难点反复练）；一旦动作稳定，改为随机混排（打乱顺序、混合情境）以促进迁移。反过来用会两头不讨好。
- **心理练习作补充**：闭眼过一遍动作流程、想象手感与节奏，是实练之外的有效补充，但它替代不了实练，只能按比例加进去。
- **反馈频率要递减**：初学高频反馈有助上手，但长期高频会让人依赖外部提示；随熟练度降低反馈频率，改为自我评估后再对照。

### 技能学习的思维实践

1. **定难点**：这次练的到底是哪一个小节／动作／笔触？不界定难点就没有练习。
2. **定标准**：什么样算对？用可观察的描述，不用「好听」「好看」。
3. **定反馈**：怎么知道自己对了？录音、录像、对照范例、他人评。
4. **定调整**：错了改哪一个变量？一次只改一个。
5. **定复盘**：练完记一条「今天改掉了什么、下次练什么」。

### 表征体系

- **动作分解图**：把连续动作拆成关键帧，标出重心、方向、节奏。
- **乐谱／画面临摹对照**：原谱原画与自己的版本并排。
- **练习日志**：日期、难点、反馈、调整、结果——一行一条。
- **评图四问**：主体是什么？视线往哪走？哪里最亮／最重？去掉什么会更好？

### 类比库

- 慢练＝放大镜：把细节放大到能看清；不像处——放大镜不改对象，慢练会改变动作本身的控制方式。
- 分块练习＝拆零件、合练＝装整机；不像处——技能不是零件拼接，合练时会出现新的协调问题。
- 评图＝批改作文：先看整体结构再抠字句；不像处——画面是同时呈现的，没有阅读顺序，必须先给视线路径。

### 术语纪律

技法术语（触键、运弓、握拍、笔触、刀工）首现给「定义 + 一个可观察的描述 + 一处易错」。不同流派对同一动作的叫法不同时，统一一个，其余括注。

### 线下任务单的写法

每次布置练习给五行：**练什么**（一个难点）／**怎么练**（分解步骤与速度）／**练多久**（短而频，不写「练一小时」）／**怎么自查**（可观察的判据）／**带回什么**（录音、照片、日志一条）。练完只复盘这条任务单，不泛泛问「练得怎么样」。
