# 精读笔记式（论证文材料默认）

<!-- owns: 精读笔记式骨架、五要素映射与写作要点；must-not-define: 材料分流（quality）、单元 schema（unit-schema）、来源真实性（quality） -->

> 相关正本：`references/handout/style-standard.md`「标准讲义（默认）」；`references/handout/quality.md`「材料型按材料结构分流」。

> 何时读：精读/带我读论证文（论文、评论、著作章节），按块复述主张与证据时。

- 适用：材料型任务中**有「主张—证据」结构**的论证文（论文 / 评论 / 著作章节；「带我读 X」「精读 X」「帮我啃 X」多属此类）——有原文、目标是读懂作者在说什么，而不是掌握一个可计算的概念。条文 / 手册 / 代码库 / 数据表不走本式，按 `references/handout/quality.md`「材料型按材料结构分流」改用标准讲义或操作手册式。
- **单元 = 一个论证块**（一章 / 一节 / 一组自然段）：标题写该块的主张一句话，编号沿用 `## 概念 N · …`（脚本与闸口按同一单元处理，不另设第二套 schema）。
- 骨架：**① 题目**（这块要回答的问题 / 读完能复述什么）→ **块定位**（原文位置 + 这块在整篇里干什么：提出 / 支撑 / 反驳 / 收束）→ **② 解析：读法**（先拆结构骨架与证据强度 → 再抠关键术语 → 最后合上原文复述）→ **结构骨架与证据强度**（3–6 条：主张 → 证据（数据 / 案例 / 引文 / 推理，标原文位置）→ 让步或反驳 → 结论；每条注明「已证」还是「只是断言」）→ **关键术语**（术语｜原文用法｜一句白话｜易混点）→ **④ 易错**（断章取义、把作者转述的观点当成作者主张、旧译名混淆）→ **③ 答案**（参考复述的可誊抄版：`参考概括：` 起笔 + 末段 `原文定位：`；学员先写自己的版本再对照）→ **⑤ 小结**（≤2 句：主张 + 最强证据的压缩，供隔周回看定位）→ **检验**（2 道：这块的主张是什么 / 作者用什么支撑、哪里可质疑）。
- **五要素映射**（仍按 schema 写；映射结构不得省略，③ 豁免按 `references/handout/unit-schema.md`「③ 豁免 canonical 标签」的 canonical 四类执行——精读笔记式纯背景章可用参照级豁免）：①题目=这块要回答的问题（读完能复述什么）；②解析=读法步骤（先拆结构骨架与证据强度、再抠术语、后复述）；③答案=**参考概括 + 原文定位**——直接用 `参考概括：` 起笔，末段写 `原文定位：<章节·段句范围>`，不写题面段（原文出处放块定位）；④易错=断章取义、把作者转述的观点当成作者主张；⑤小结=主张 + 最强证据的压缩（≤2 句，不是第二份复述）。
- 写作要点：
  - **转述不抄写**：直接引用不超过本单元篇幅两成，其余用自己的话；引用加引号并标位置。
  - **区分三层**：作者的主张 / 作者的证据 / 我的判断——后两层不得写成第一层（衔接「事实、来源与不确定性」）。
  - **术语首现即解释**（同标准讲义）；原文用旧译名或异体字时并列，避免学员换本书就不认识。
  - **枝节不进正文**：与本节目标无关的背景、考据进「扩展（选读）」区，或只标位置不展开。
  - **争议与过时**：原文观点有争议或已被修正时，写一句「截至<日期>，另有……」并给出处；**不替作者补论证**，也不把作者的话升格成事实。
  - ③ 是**参考概括**不是唯一答案：学员用自己的话覆盖要点即通过（衔接 `references/assessment/scoring.md`「批改与申诉」）。
