## 风格切换映射

<!-- intent:I-STYLE-RETEACH@chat -->

只在「换角度重讲」或讲义改版时使用，不用于首次选型。卡壳信号 → 讲义风格：

| 学员表现 | 换到 | 为什么 |
|---|---|---|
| 概念抽象、复述总卡壳 | 费曼卡 | 白话 + 类比 + 反例，逼出定义 |
| 分不清 X 和 Y | 对比辨析卡 | 对照表把适用条件摆出来 |
| 会做但慢、考场做不完 | 考试冲刺卡 | 步骤模板 + 时间预算 |
| 看得懂、动手就废 | 操作手册式 | 分步 + 成功标志 |
| 论证文读不懂、抓不住作者主张 | 精读笔记式 | 块定位 + 结构骨架与证据强度 + 复述 |
| 标准讲义的信息量扛不住 | 压缩出口 | 结论 + 必要依据 + 边界（见「对话讲授契约」） |

六套风格的骨架见各自正本（见下「六套风格选型」）；本表只决定「卡壳后换哪套」，不重复风格定义。

## 六套风格选型

| 风格 | 适用 | 骨架正本 |
|---|---|---|
| 标准讲义（默认） | 绝大多数知识型小节 | `references/handout/style-standard.md`「标准讲义（默认）」 |
| 费曼卡 | 抽象概念；复述总卡壳；复习重讲 | `references/handout/style-feynman.md`「费曼卡」 |
| 考试冲刺卡 | 备考型考点小节；结课前总复习 | `references/handout/style-exam.md`「考试冲刺卡」 |
| 对比辨析卡 | 一对易混概念（分不清 X 和 Y） | `references/handout/style-compare.md`「对比辨析卡」 |
| 操作手册式 | 技能型任务（编程、工具、软件操作） | `references/handout/style-manual.md`「操作手册式」 |
| 精读笔记式 | 有主张—证据结构的论证文材料 | `references/handout/style-reading.md`「精读笔记式（论证文材料默认）」 |

选型规则见 `references/handout/pipeline.md`「0.1 风格选择」（默认标准讲义、用户点名优先、同一份讲义只用一种）。
