## 讲义概念单元 schema（所有风格共用）

讲义每个概念单元具备**可定位的必需槽位**：定义/规则、按需表示（类比 / 配图 / 对照表等）、完整示例或正反例、易错点、小结、检验问题。其他风格可重排槽位，但**不得漏槽位、不得删除必需信息**（参照级单元按「分层标注」条豁免，只留 ① 题目与正文里的定义、边界）。

**单元≠KP**：`## 概念 N` 是**教学单元**（历史标题，保留给脚本），不是 KP；映射关系、混合类型与规划区标注的唯一事实源见 `references/handout/pipeline.md` §2.5。

**六个槽位的落点必须可指认**：每条风格骨架已用〔〕标出落点——五个编号槽位（① 题目 / ② 解析 / ③ 答案 / ④ 易错 / ⑤ 小结）外加 schema 的**检验**。写完按骨架逐项指认，指认不出的就是漏槽位；**④ 与 ⑤ 最容易被别的段落顺带承担**（反例、对照表、报错清单、检查清单、骨架末尾的收束句都不等于 ④ 或 ⑤），须能指到具体那一行，不认「隐含在……」。④ 与 ⑤ 都按「≤3 句、不引入新信息」写（⑤ 的记忆族「本节地图」变体上限见 `references/teaching/explanation-density.md`「讲解文本密度原则」），不因加了槽位就扩写。**修复表、决策日志、对照表算附件，不占 ④/⑤ 的三句额度；但单元仍要有一句 ≤3 句的摘要**（见 `references/handout/pipeline.md` §2.9）。

- **节首导读（定稿必备，3 行）**：在第一个 `## 概念` 之前写 `- 本节目标：学完能独立……`｜`- 前置：需要……（无则写「无」）`｜`- 预计：约 N 分钟`。与对话轮「课首定位」（`references/teaching/lesson-prep.md`「课首定位」）同源，不复制理由；学员隔周回看先读这三行。脚本 `E-HEADER-BRIEF`：**定稿**缺任一行报 E，草稿不查（讲的过程中可后补）。**读者假设、已会/未会并入「前置」一行；用法放文末；类型/支持级放规划区——不新增第四行必填字段**（见 `references/handout/pipeline.md` §2.6）。
- **默认顺序**（标准讲义）：定义/规则（含一句机制/边界）→ 配图（按需）→ 教学例（① 题目 → ② 解析 → ③ 答案框）→ 配对练习（配对自测）→ 易错点（④）→ 小结（⑤）→ 闭卷自检（阅读动作）→ 评估例/迁移（迁移自测）。类比不单设槽位，归入「按需表示」，有合适类比时才用（见 `references/handout/style-standard.md`「标准讲义（默认）」）。**读者版 P1 可选增量**的版面与格式见 `references/layout/reader-path.md`「8. 读者路径与导航（P1）」；三者只做导航，不改变上述五要素顺序与答案框位置。
- **风格 × ③ ⑤ 落点（六套风格都必须写出 ③ 与 ⑤）**：下表只列最容易写错的 ③ 与 ⑤；① ② ④ 与检验的落点见各风格骨架里的〔〕标注，不在此重复。**③ 只允许纯概念/纯记忆/已会·检索版/参照级豁免；⑤ 除参照级外任何单元都不得省**（canonical 标签与各自豁免范围见本节「③ 豁免 canonical 标签」；下表逐行列出主要豁免，未列到的风格按同一规则处理）。
  | 风格       | ③ 答案（框）                        | ⑤ 小结                       | 允许的豁免                             |
  | -------- | ------------------------------ | -------------------------- | --------------------------------- |
  | 标准讲义（默认） | 可誊抄全文：从交付起笔到结论（不写题面段）        | 三句话小结（≤3 句）                | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」；参照级→「③ 不适用（参照级）」 |
  | 费曼卡      | 「最容易怎么用错」的对照答案，可只给关键句         | 一句话回收（≤2 句）                | 同上（纯概念/纯记忆/已会·检索版/参照级）          |
  | 考试冲刺卡    | 每题答案（选择题含逐项排除），详解附给分点量表       | 秒杀技巧或口诀（≤2 句）              | 无（备考型必有）                          |
  | 对比辨析卡    | 辨析题答案 + 判定依据                   | 判别口诀（≤2 句）                 | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」 |
  | 操作手册式    | `步骤：`/`代码：` + `输出：` 成功标志      | 关键决策三句话（≤3 句）              | 无                                 |
  | 精读笔记式    | `参考概括：` + 末段 `原文定位：`          | 主张 + 最强证据的压缩（≤2 句）         | 纯背景章→「③ 不适用（参照级）」                 |

### ③ 豁免 canonical 标签

允许且只允许四类：

- `③ 不适用（纯概念）`：豁免 ②③，①④⑤仍须；
- `③ 不适用（纯记忆）`：豁免 ②③，①④⑤仍须；记忆有可复现答案时仍可给 ③，但给了 ③ 就要按完整示例补 ②；不补 ② 就用本条豁免，不要只给 ③；
- `③ 不适用（已会·检索版）`：豁免 ②③，①④⑤仍须；用于 L3/已会单元的检索版；若给 ③，同样按完整示例补 ②，不补 ② 就用本条豁免；
- `③ 不适用（参照级）`：豁免 ②③④⑤，①仍须。

禁止把纯记忆写成「纯概念」；脚本 `THIRD_EXEMPT_RE` 接受任意 `③ 不适用`，`E-REQ-MISSING` 提示必须列全上述四类。

### 交付标识分类

| 类别 | 交付标识 |
|---|---|
| 数学/理科 | `解：`/`解答：`/`证明：`/`Solution:`/`Proof:` |
| 文科/理论 | `答：`/`解答：`/`参考答案：`/`方案：`/`设计说明：` |
| 语言 | `参考答案：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`Model answer:`/`Sample answer:`/`Translation:` |
| 精读 | `参考概括：`（收尾 `原文定位：`） |
| 编程 | `代码：`/`脚本：`/`输出：`/`Code:`/`Script:`/`Output:` |
| 技能/实验 | `步骤：`/`操作：`/`Steps:` |
| 记忆/客观 | `答案：`/`Answer:`/`Key:` |

- `方案：`/`设计说明：` 用于设计类，接受多解 + 评价标准；`答案：` 用于记忆/客观；**不得默认 `解：`**。
- 精确 canonical 集合（脚本必须全部接受）见 `references/layout/char-typography.md`「交付起笔与答案标识」；本表只做学科族选择，不重复精确集合。

- **分层标注（每概念单元出厂必须带）**：在概念单元起始处用方括号标签标注 **【本节最小必需】**、**【选学·后期必用（何时用/依赖哪节）】** 或 **【参照】**；也可写在规划区对应概念行（表格列或列表行，纯文本即可），二者其一。选学标注须写明何时用到、依赖哪节；学员据此自行判断是否当前深学，不必等导师逐个说明。**【参照】对应深度契约的参照级（定义见 `references/teaching/explanation-depth.md`「深度分层」）**：只需「知道它是什么、什么时候用不上」，可标 `③ 不适用（参照级）` 豁免 ②③④⑤（① 题目仍须，定义与边界写在正文）；**工作级/最小必需级不得用参照豁免**。正文里只是提到「选学 / 最小必需 / 参照」字样不算标注。**纯记忆用 `③ 不适用（纯记忆）`、已会·检索版用 `③ 不适用（已会·检索版）`；两者只用于对应情形，不得拿来给工作级/最小必需级省讲解**。
- **定稿边界**：定稿 = 判分记账零残留（**台账状态行**、伺服档位、检验作答记录、补讲台账留 progress.md 与题组文件，不进定稿；两态流转见 `references/handout/pipeline.md` §2.1）。**`verify_explanation.py` 通过只表示「结构可定稿」，不等于状态转定稿**：**讲义状态行** `- 状态：` 仍保持「草稿」，待小节闸口通过后再改为「定稿」。两态用词见 `references/handout/pipeline.md` §2.1。
- **讲义头部（讲义状态行 + 可选指针行，不复制规则正文）**：`- 状态：草稿（…）` 或 `- 状态：定稿（…）`；**台账状态行不进讲义**。需要记录体例约定时只写一行指针 `- 体例约定（LaTeX 排版/答案框）：统一见 progress.md「质量保障机制」`；**该区存在时才写指针，否则省略或先建区，不能留死指针**。规则正文归任务侧 progress.md；在头部复制规则块会触发 `W-STYLE-POINTER`。头部之后、第一个概念单元之前接「节首导读」三行（必填行与合并规则见上一条与 `references/handout/pipeline.md` §2.6）。
