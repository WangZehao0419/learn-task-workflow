## 讲义概念单元 schema（所有风格共用）

讲义每个概念单元具备**可定位的必需槽位**：定义/规则、按需表示（类比 / 配图 / 对照表等）、完整示例或正反例、易错点、小结、检验问题。其他风格可重排槽位，但**不得漏槽位、不得删除必需信息**（参照级单元按「分层标注」条豁免，只留 ① 题目与正文里的定义、边界）。

**单元≠KP**：`## 概念 N` 是**教学单元**（历史标题，保留给脚本），不是 KP；映射关系、混合类型与规划区标注的唯一事实源见 `handout/pipeline.md` §2.5。

**六个槽位的落点必须可指认**：每条风格骨架已用〔〕标出落点——五个编号槽位（① 题目 / ② 解析 / ③ 答案 / ④ 易错 / ⑤ 小结）外加 schema 的**检验**。写完按骨架逐项指认，指认不出的就是漏槽位；**④ 与 ⑤ 最容易被别的段落顺带承担**（反例、对照表、报错清单、检查清单、骨架末尾的收束句都不等于 ④ 或 ⑤），须能指到具体那一行，不认「隐含在……」。④ 与 ⑤ 都按「≤3 句、不引入新信息」写（⑤ 的记忆族「本节地图」变体上限见 `teaching/explanation-density.md`「讲解文本密度原则」），不因加了槽位就扩写。**修复表、决策日志、对照表算附件，不占 ④/⑤ 的三句额度；但单元仍要有一句 ≤3 句的摘要**（见 `handout/pipeline.md` §2.9）。

- **节首导读（定稿必备，3 行）**：在第一个 `## 概念` 之前写 `- 本节目标：学完能独立……`｜`- 前置：需要……（无则写「无」）`｜`- 预计：约 N 分钟`。与对话轮「课首定位」（`teaching/lesson-prep.md`「课首定位」）同源，不复制理由；学员隔周回看先读这三行。脚本 `E-HEADER-BRIEF`：**定稿**缺任一行报 E，草稿不查（讲的过程中可后补）。**读者假设、已会/未会并入「前置」一行；用法放文末；类型/支持级放规划区——不新增第四行必填字段**（见 `handout/pipeline.md` §2.6）。
- **默认顺序**（标准讲义）：定义/规则（含一句机制/边界）→ 配图（按需）→ 教学例（① 题目 → ② 解析 → ③ 答案框）→ 配对练习（配对自测）→ 易错点（④）→ 小结（⑤）→ 闭卷自检（阅读动作）→ 评估例/迁移（迁移自测）。类比不单设槽位，归入「按需表示」，有合适类比时才用（见 `handout/styles.md`「标准讲义」）。**读者版 P1 可选增量**的版面与格式见 `handout/reader-path.md`「读者路径与导航」；三者只做导航，不改变上述五要素顺序与答案框位置。
- **风格 × ③ ⑤ 落点（六套风格都必须写出 ③ 与 ⑤）**：下表只列最容易写错的 ③ 与 ⑤；① ② ④ 与检验的落点见各风格骨架里的〔〕标注，不在此重复。**③ 只允许纯概念/纯记忆/已会·检索版/参照级豁免；⑤ 除参照级外任何单元都不得省**（canonical 标签与各自豁免范围见本节「③ 豁免 canonical 标签」；下表逐行列出主要豁免，未列到的风格按同一规则处理）。
  | 风格       | ③ 答案（框）                        | ⑤ 小结                       | 允许的豁免                             |
  | -------- | ------------------------------ | -------------------------- | --------------------------------- |
  | 标准讲义（默认） | 可誊抄全文：从交付起笔到结论（不写题面段）        | 三句话小结（≤3 句）                | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」；参照级→「③ 不适用（参照级）」 |
  | 费曼卡      | 「最容易怎么用错」的对照答案，可只给关键句         | 一句话回收（≤2 句）                | 同上（纯概念/纯记忆/已会·检索版/参照级）          |
  | 考试冲刺卡    | 每题答案（选择题含逐项排除），详解附给分点量表       | 秒杀技巧或口诀（≤2 句）              | 无（备考型必有）                          |
  | 对比辨析卡    | 辨析题答案 + 判定依据                   | 判别口诀（≤2 句）                 | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」 |
  | 操作手册式    | `步骤：`/`代码：` + `输出：` 成功标志      | 关键决策三句话（≤3 句）              | 无                                 |
  | 精读笔记式    | `参考概括：` + 末段 `原文定位：`          | 主张 + 最强证据的压缩（≤2 句）         | 纯背景章→「③ 不适用（参照级）」                 |

### ③ 豁免 canonical 标签

允许且只允许四类：

- `③ 不适用（纯概念）`：豁免 ②③，①④⑤仍须；
- `③ 不适用（纯记忆）`：豁免 ②③，①④⑤仍须；记忆有可复现答案时仍可给 ③，但给了 ③ 就要按完整示例补 ②；不补 ② 就用本条豁免，不要只给 ③；
- `③ 不适用（已会·检索版）`：豁免 ②③，①④⑤仍须；用于 L3/已会单元的检索版；若给 ③，同样按完整示例补 ②，不补 ② 就用本条豁免；
- `③ 不适用（参照级）`：豁免 ②③④⑤，①仍须。

禁止把纯记忆写成「纯概念」；脚本 `THIRD_EXEMPT_RE` 接受任意 `③ 不适用`，`E-REQ-MISSING` 提示必须列全上述四类。

### 交付标识分类

| 类别 | 交付标识 |
|---|---|
| 数学/理科 | `解：`/`解答：`/`证明：`/`Solution:`/`Proof:` |
| 文科/理论 | `答：`/`解答：`/`参考答案：`/`方案：`/`设计说明：` |
| 语言 | `参考答案：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`Model answer:`/`Sample answer:`/`Translation:` |
| 精读 | `参考概括：`（收尾 `原文定位：`） |
| 编程 | `代码：`/`脚本：`/`输出：`/`Code:`/`Script:`/`Output:` |
| 技能/实验 | `步骤：`/`操作：`/`Steps:` |
| 记忆/客观 | `答案：`/`Answer:`/`Key:` |

- `方案：`/`设计说明：` 用于设计类，接受多解 + 评价标准；`答案：` 用于记忆/客观；**不得默认 `解：`**。
- 精确 canonical 集合（脚本必须全部接受）见 `ops/typography.md`「交付起笔与答案标识」；本表只做学科族选择，不重复精确集合。

- **分层标注（每概念单元出厂必须带）**：在概念单元起始处用方括号标签标注 **【本节最小必需】**、**【选学·后期必用（何时用/依赖哪节）】** 或 **【参照】**；也可写在规划区对应概念行（表格列或列表行，纯文本即可），二者其一。选学标注须写明何时用到、依赖哪节；学员据此自行判断是否当前深学，不必等导师逐个说明。**【参照】对应深度契约的参照级（定义见 `teaching/explanation-depth.md`「深度分层」）**：只需「知道它是什么、什么时候用不上」，可标 `③ 不适用（参照级）` 豁免 ②③④⑤（① 题目仍须，定义与边界写在正文）；**工作级/最小必需级不得用参照豁免**。正文里只是提到「选学 / 最小必需 / 参照」字样不算标注。**纯记忆用 `③ 不适用（纯记忆）`、已会·检索版用 `③ 不适用（已会·检索版）`；两者只用于对应情形，不得拿来给工作级/最小必需级省讲解**。
- **定稿边界**：定稿 = 判分记账零残留（**台账状态行**、伺服档位、检验作答记录、补讲台账留 progress.md 与题组文件，不进定稿；两态流转见 `handout/pipeline.md` §2.1 与 `handout/quality.md` §12）。**`verify_explanation.py` 通过只表示「结构可定稿」，不等于状态转定稿**：**讲义状态行** `- 状态：` 仍保持「草稿」，待小节闸口通过后再改为「定稿」。两态用词见 `handout/pipeline.md` §2.1。
- **讲义头部（讲义状态行 + 可选指针行，不复制规则正文）**：`- 状态：草稿（…）` 或 `- 状态：定稿（…）`；**台账状态行不进讲义**。需要记录体例约定时只写一行指针 `- 体例约定（LaTeX 排版/答案框）：统一见 progress.md「质量保障机制」`；**该区存在时才写指针，否则省略或先建区，不能留死指针**。规则正文归任务侧 progress.md；在头部复制规则块会触发 `W-STYLE-POINTER`。头部之后、第一个概念单元之前接「节首导读」三行（必填行与合并规则见上一条与 `handout/pipeline.md` §2.6）。
### 答案框体例（学科无关）

<!-- intent:I-ANSWER-BOX-CONTENT@content -->

- **起笔**：框内只写**解题过程**，从**交付起笔**开始，或框内直接给出代码块。起笔标识的分类见本节「交付标识分类」，精确 canonical 集合见 `ops/typography.md`「交付起笔与答案标识」；本行与脚本 `LEAD_WORDS` 必须一致。**不得默认 `解：`**——按当前内容所属学科族取形态；跨族内容（如物理借数学族）以内容所属族为准。
  - **不写题面段**：题干归 ① 题目，框内不再抄一遍（`题目：`/`任务：`/`Prompt:`/`原文：` 这类题面起笔在框内不再使用）。精读式另在末段写 `原文定位：<章节·段句范围>`（收尾段，不算第二类必需标识）。
  - **标记行留空**：只写 `③ 答案：`，答案写进框内；标记行带内容报 `W-MARKER-CONTENT`。
  - **标记行须在行首**（列表项，可加粗），正文里提一句「见 ③ 答案」不会被当成标记。
  - **多题单元**（如冲刺卡 3 道真题）：每题一个 `③ 答案（第 N 题）：` 框，或在一个框里按题号分段（`（1）解：…`，题号可写在框内段首，仍算交付起笔）。
  - **交付段须有实质内容**：去掉标识与标点后为空、或只剩「略／从略／见教材／同上／自行体会」等占位词的，不算答案（`E-BOX-EMPTY`）。
  - **分点编号**：段首 ①–⑩ 合法——按点给分的给分点就是「每点一段、段首起编号」；句中编号不合规（`答：①……②……` 挤在一行），须拆成每点一段。
  - **代码块**：框内的代码围栏（三反引号起止）整块算一段，块内多行不拆行、不查箭头与验算标记（验算只认 ✓ ✔ ✅，`√` 视为根号不拦），紧接 `输出：` 段给运行结果与成功标志。
  - **同一体例的五种形态**——数学 `解：…∴ …`；文科 `答：①资本：…`（每点一段）；语言 `Model answer: 他跑得很快。`；精读 `参考概括：…` / `原文定位：…`；编程 `代码：` + 围栏块 + `输出：无报错即成功`。
  - **客观题**：选择题给「答案 + 逐项一句排除（错项错在哪）」，填空写清多空顺序与单位，不得只给字母——教辅答案册多把逐项分析并入答案，故留在 ③；② 只讲这类题的判定方法（何时用排除、何时直接算），不复述逐项内容。
  - **带图答案**：作图 / 受力图 / 流程图 / 装置图 / 结构式在框内单独一行 `图：assets/NN-xx.svg（示意/按比例）`，图须先落盘后引用（同「图像可视化双轨」），并按「绘图后核对」检查图文一致；无图可画时写清作法与关键点。各群的默认形态见 `references/subjects/{group}-practice.md`「答案形态与最小单元」。
- **其余族的最小形态（只演示段结构、篇幅从简；完整范例见「标准讲义 · 成品范例」）**：以下只给框内内容，题面一律写在 ① 题目。
  - **语言**：`Model answer:` 起交付；翻译可用 `参考译文：`；改错类末段补一句「为什么这么改」。
    > Model answer: 他跑得很快。
  - **编程**：`代码：` 后接围栏块（整块算一段）；末段 `输出：` 给运行结果与成功标志。
    > 代码：
    >
    > ```python
    > import os
    > for name in os.listdir('.'):
    >     if not name.startswith('p_'):
    >         os.rename(name, 'p_' + name)
    > ```
    >
    > 输出：无报错，文件名已加前缀。
  - **理科计算 / 化学**：物理按「公式、代入（带单位）、结果（有效数字与单位）」各一段；化学把配平系数、条件与物态写在同一段，反应箭头用 `->`，不用 Unicode 箭头。
    > 解：由 $v^2=2gh$ 得 $v=\sqrt{2gh}$。
    >
    > 代入 $h=20$ m、$g=10$ m/s²，得 $v=20$ m/s，方向竖直向下（两位有效数字）。

    > 解：2 H2 + O2 -> 2 H2O (点燃)，两边 H 各 4、O 各 2。
  - **文科 / 记忆（按点给分）**：`答：` 后每点一段、段首 ①–⑩，段间空 `>` 行。
    > 答：①资本：殖民扩张与海外贸易积累了大量资本。
    >
    > ②劳动力：圈地运动为工厂提供自由劳动力。
    >
    > ③市场：海外殖民地扩大了商品需求。
  - **理论（案例 / 论述）**：`答：` 按「结论、依据、适用」各一段，末段落到本题事实（案例事实写在 ① 题目）。
    > 答：结论：可以解除。
    >
    > 依据：一方迟延履行主要债务，经催告后在合理期限内仍未履行的，对方可以解除合同。
    >
    > 适用：本案卖方经催告仍未交货，符合解除条件。
  - **精读**：`参考概括：` 起交付、`原文定位：` 收尾，两段固定顺序。
    > 参考概括：作者主张中国乡土社会是「熟悉社会」，以人情与礼俗维持秩序，而非契约。
    >
    > 原文定位：第一章第 2 段，第 3–7 句。
- **给分点量表（框外，备考/阅卷型适用）**：紧跟 ③ 框之后**单独一行**，不进框内——格式 `- 给分点量表：①<要点>（2分）；②<要点>（3分）；合计 5 分（训练量表，非官方细则）`。各点分值之和须等于合计（`E-RUBRIC-SUM`）；无官方细则写「训练量表，非官方细则」，有官方来源写「官方细则」并附名称/年份（缺声明 `W-RUBRIC-SOURCE`）。非备考任务不写分值，改给关键步骤、验证方式或成功标志，不编造官方分值。
- **教学例版面**：①–⑤ 各占一段或独立列表项，段间空行；标记行加粗；③ 用引用块；一单元只用一个 ③ 框；版面细则见 `handout/typography.md`「教学例版面」。本节只管内容分段与槽位。
- **框内分段（通用判据）**：一段 = 一个**可独立核对的最小单元**——单独拿出来能判对错、能给分、能对照的最小块。段内不再塞第二个这样的单元，也不把一个单元拆到两段。一句话：**看这一段能不能单独判对错**。
  - **段间写一个只含 `>` 的空行**；**段数不设下限**（单步答案一段即可，`> 答：B。` 合法）。
  - `解：`/`答：` 等交付起笔放在**首段起头**（不单独占一段），末段为结论。
  - **公式 / 算式 / 引文不跨段**，长式转行只落在等号 / 关系符 / 运算符之后（细则见 `ops/formulas.md` 第 3 节）。
  - **每段以单行为准**：普通文字多行会被渲染器并成一行、内容不丢——脚本不再提示（避免每个框都冒一条噪声），由「讲解出厂自检」第 8 项人工核对；若段内断行截断了 `$…$` 公式或行内代码，渲染直接损坏（`E-BOX-WRAP`）。分段前先把同一句被拆开的续行合并成一行。
  - **围栏代码块整块算一段**，块内多行照原样保留。
- **各族的「最小单元」（同一判据的不同形状）**：计算 / 证明 = 一个**语句**（对象 = 结果：一次变形、一次代入、一次判定各一单元，`∵…∴…` 依据与结论同段；同一表达式的连续变形可用连等式合并，解方程 / 不等式 / 证明逐步写）；按点给分（文科 / 记忆）= 一个**给分点**（段首 ①–⑩，每点一段）；论述 / 理论 = 一个**论证环节**（结论 / 依据 / 适用）；语言 = 一个**句子或意群**（译文按原句切）；编程 = 代码整块一段 + `输出：` 一段；精读 = 概括一段 + `原文定位：` 一段。
- **答案框紧邻**：③ 标记行之后只允许空行，紧邻的引用块即答案框；教材原题等其他引用内容放在 ③ 之前，不得插在标记与框之间。**卡片类的检验与详解都留在概念单元内**：冲刺卡 / 对比辨析卡的「检验：…」与 ③ 详解写成单元内的列表行与引用框，**不单独设 `## 检验` 标题**——任何 `## ` 标题都会终结单元，③ 落在单元外就会报「缺 ③」；若检验确需独立成区，③ 详解须写在区之前。
- **自测与题组的分工**：题量与配对/迁移分工见 `assessment/generation.md`「题量预算与自测≠题组」；自测是低风险自检，不判分、不进闸门、不写 `exercises/`；闭卷解释是阅读动作，不占题量。`exercises/` 题组 = **唯一判分证据**（出题与题量按 `assessment/generation.md`「出题流水线」「题量预算」）。二者**不得同题**（可同知识点换情境；L3 复习产物例外见下），自测答对也不作为掌握证据；逐目正式确认的未印答案要求见 `assessment/generation.md`「题量预算与自测≠题组」。答案与反馈按 `handout/pipeline.md` §1 第 7 条。**每节题量预算见 `assessment/generation.md`「题量预算与自测≠题组」**（正式确认题另计口径见同节；简单目轻量确认见 `workflow/s3-block.md`「逐目循环」）。**L3 复习产物例外**：题量与同题豁免见 `assessment/generation.md`「题量预算与自测≠题组」；产物形态与 ③ 标注见 `handout/support-levels.md` §6。**类型化自测见 `handout/templates.md` §4.2；L1/L2/L3 支持级见 `handout/support-levels.md`。**
  - **脚本检查（标题约定）**：题面区认 `## 本节自测`（推荐）/ `## 自测` / `## 自测题` / `## 检验` / `## 检验题` / `## 检验问题` / `## 本节检验`；答案区认同词干 + `答案`（`## 本节自测答案` 推荐）、`答案区`、`答案要点`、`答案与解析`，也认通用的 `## 答案` / `## 参考答案`。**标题统一用中文**——英文讲义也写中文标题（正文与答案内容可用英文），`## Self-test` 这类英文标题不识别。一个文件可有多个答案区（如自测、检验各一区），逐区检查。自造标题（如 `## 小测`）既不检查也不豁免。
  - **两条警告（不阻断）**：题面区之后没有同族答案区（自测 / 检验各自成族）、也没有通用答案区 → `W-SELFTEST-MISSING`（文末一个 `## 参考答案` 可统管前面多个题面区，`## 检验问题答案` 不给 `## 自测` 兜底）；答案区只写「略／见教材／同上」或整区为空 → `W-SELFTEST-EMPTY`（只有代码块的答案不算空）。
  - **开放/动手检验豁免**：确无书面答案的（开放题、口头复述、动手练手、本节不设检验）须在该区首行显式写 `- 检验说明：开放题，无标准答案（说出/复述即算）`——含 开放/口头/无标准答案/不设/跳过/练手/动手/压缩 任一字样即认，不报 MISSING；没写说明又没答案区，一律按「学员做完无处对答案」处理。
- **闭卷自检（阅读动作，不计题量）**：唯一事实源见 `handout/pipeline.md` §3.5（⑤ 之后、自测之前一行；模型答案用 ⑤；≤3 个阅读动作/节）。
- **概念地图（可选节首区块，5 个以上概念或 ≥3 条依赖关系的节建议写）**：`## 概念地图` 放在节首导读之后、第一个 `## 概念` 之前，用一张表列「概念 N｜一句话是什么｜依赖哪个概念｜分层」。脚本不把它当概念单元、不查五要素；它只用于隔周回看与复习定位，不替代各单元的完整讲解。长节可再加一张“空概念图”做闭卷检索（旧「8 个以上」阈值废止；本条的 5+/3 依赖是唯一阈值）。

- **扩展（选读）区**：讲义可在节末设 `## 扩展（选读）` 区，只放**不进闸口、不出题、不作定稿判定依据**的内容（背景沿革、更深的证明、工具技巧、跨领域补充）。准入三问——本节解题用得上吗？本节后必须会吗？删掉会不会漏考点？三条全为「否」才可进。区内**不挂**分层标注、**不强制**配 ③ 框，也不得写考点结论。位置排在「自测/检验答案区」之后，且必须是本文件最后一个区（范围到文末）。
