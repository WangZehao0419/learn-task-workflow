# 标准讲义（默认）

> 相关正本：`references/handout/unit-schema.md`「讲义概念单元 schema（所有风格共用）」；`references/handout/pipeline.md`「1. 一页合同（目标态，11 条）」。

<!-- intent:I-STYLE-DEFINITION@handout -->

- 适用：绝大多数知识型小节。
- 骨架（〔〕= 槽位落点；六套风格都按此逐个指认，漏槽位即不算讲完）：概念〔定义/规则 + 一句机制/边界〕→ **类比（有合适类比时才用；无则改准确定义 / 实例 / 图示）〔按需表示，可省〕** → **教学例〔① 题目 ② 解析 ③ 答案〕（worked example；最小典型、透明）** → **配对练习〔配对自测：同构题，可回看教学例，答案放节末〕** → 易错点〔④：症状 + 原因 + 补救〕→ 三句话小结〔⑤ 小结：≤3 句、不引入新信息；优先写判别句〕→ **闭卷自检（阅读动作：3 句解释 → 信心 → 对照 ⑤）** → **评估例/迁移〔迁移自测：真实/新情境，答案放节末〕**。顺序与「讲义概念单元 schema · 默认顺序」一致；四段细节见 `references/handout/pipeline.md` §3.3。
- 题区写 `## 本节自测`，题前固定一行「先独立做完，再看本节自测答案」——提示语里不写「③ 答案」字样，避免被当成③标记行；答案统一放 `## 本节自测答案` 区，短答案合法、可短但不得写「略／见教材／同上」，不属五要素之③。配对题写在教学例后（配对自测）；`## 本节自测` 区放迁移题（迁移自测），也可两题都放；两题答案统一放 `## 本节自测答案`。题量与自测≠题组见 `references/assessment/quiz-budget.md`「题量预算与自测≠题组」。
- **类型矩阵见 `references/handout/templates.md` §4.2**：记忆/概念/设计按矩阵替换 ③/⑤/自测形态；**L2/L3 可不出完整教学例**（`references/handout/support-levels.md`），不违反“教学例只用一个”。
- **教学例判据（完整示例；适用于含解题/操作/作答过程的概念；五要素缺一不算讲完）**：
  - ① 题目（**要解决的问题或要完成的任务**）：题目型写题干要点——要你做什么、产出什么、交付给谁看；纯概念 / 纯记忆 / 参照级没有题干，写「本节要弄清楚什么」即可，不编造题目。题目只在这里写一次，答案框内不再重复。
  - ② 解析：方法与关键判断——每步做什么、为什么这么做、哪一步最容易错，以结论收尾。
  - ③ 答案（**参考解答**）：可整体誊抄的规范卷面，完整可复现即可，不排斥等价解法。
  - ④ 易错：本例最容易错的一步，症状 + 原因；⑤ 小结：≤3 句，只压缩不新增。
  - **③ 空位豁免**（下称「③ 空位豁免」，与深度契约的「机制豁免」不是一回事）：含解题/操作过程时③必选；纯概念/纯记忆没有可复现产物时**③ 框可省，但标记行不可省**——须在概念单元内显式标注 `③ 不适用（…）`，四类 canonical 标签与各自豁免范围见 `references/handout/unit-schema.md`「③ 豁免 canonical 标签」；参照级单元标 `【参照】` + `③ 不适用（参照级）`，豁免范围按该表；标记行放在③位置、正文叙述里不重复该字样，避免误判；单元须有正反例或等价表示。
  - **③ 框的形态**：框内内容、起笔、标识、分点与最小单元见 `references/handout/answer-box.md`「答案框体例（学科无关）」；精确 canonical 集合见 `references/layout/char-typography.md`「交付起笔与答案标识」。
  - 备考/阅卷型任务按已声明的给分点书写并可整体誊抄，非备考任务按可提交/可复现格式书写，不虚构评分细则——②讲「为什么这么做」，③示范「卷面长什么样」，在已声明评分口径下覆盖必要步骤（备考/阅卷型任务学员照抄③应能得分）。涉及新记号/新操作的示例另须满足 `references/teaching/notation.md`「新记号/新操作讲透」三件套。
- **教学例 vs 评估例（四段支架）**：①–③ + 配对用**教学例**（最小典型、透明、可判别；可原创/简化并标「改编自 p.X」）；迁移自测用**评估例**（优先来源原题/真题/学员真实任务，换新情境；**不是第二个完整教学例**）。评估例的答案按 `references/handout/pipeline.md` §1 第 7 条答案三件套，不写成第二个 ③ 示范盒；备考型至少每个高权重小节有 1 个来源/真题风格的评估例。
- 写作要点：**深讲概念先按「深度契约」定层（D/P/M/H/B/C）再动笔**；零基础首次按「现象→符号引入序」。类比**优先取自学习者画像的类比领域**（无画像则贴学员场景），且**仅在类比真能说清时才用**——新内容没有合适类比时改用准确定义 / 实例 / 图示，**不强凑生活故事**（衔接 `references/teaching/lesson-prep.md`「课首与旧知锚定」：「无同构可撬则跳过、不硬凑类比」）；**教学例只用一个、做完整**——宁可少讲半个概念，不可给半截教学例（L2 补全/L3 检索版按 `references/handout/support-levels-core.md` §6，不受本句限制）；**评估例是迁移任务，不是第二个完整示范**（见 `references/handout/pipeline.md` §3.3）；误区写「症状 + 原因」而不只写结论；**术语首次出现给一句白话或定义**，不假设学员已知、不依赖未提供的材料。
- 成品范例：完整范例（供导师对照格式与密度，非讲义内容）见 `references/layout/handout-examples.md`「标准讲义成品范例」。
