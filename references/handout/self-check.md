## 11. 自检与证据

**可读性自检（5 问，定稿前）**：

1. 30 秒内只看标题、导读（如有速览也看），能说出本节解决什么、结论是什么？
2. 段落是否一段一义、句子是否一句一判断？若启用 P1，概念单元第一行是否先给结论？
3. 列表/表格/正文是否选对？表格有表头、列数符合移动端上限吗？
4. 标题是否带信息、层级连续？连续两段是否都在用加粗抢重点？
5. 黑白打印、手机窄屏、去色后是否仍可读？

**读者验证（5 问，人工，定稿前）**：

1. 只看标题/导读（如有速览也看），30 秒内能否说出本节问题、结论、用途？
2. 隔天只看标题 + 回看索引，2 分钟内能否重建核心、易错、下一步？
3. 手机 375px 宽是否无横向滚动、无过小图字？
4. 黑白打印/去色后，主线、支线、重点是否仍可区分？
5. 200% 缩放是否无横向滚动、无重叠？屏幕阅读器能否按标题层级跳读、图片 alt 是否可理解？

**元素预算检查（定稿前）**：每单元 ≤1 主图/≤1 答案框/≤1 `<details>`；全文 1 强调色；标题 ≤3 级；无嵌套框/图标/装饰线。

**失败处理**：四问/五问失败时改结构/图/标题，不加题量、不归因学员、不删必要推导。

**运行时边界**：读者版规则不新增运行时闸口；短节可省略速览/回看索引，旧讲义不回溯；与五要素、答案框、密度原则冲突时，以准确性、适用条件与必要推导优先，不为版面删内容。

**证据边界**：读者版可读性、图解语法、图表一致性是**设计决策/方向支持**；文献依据与边界见 `ops/literature.md`「排版可读性」「中文排版/屏幕阅读/打印」。关键边界：排版不等于学习效果；标题帮助搜索/定位，不保证自由回忆；中文行长证据冲突，取保守区间 25–40 字、上限 48；纸面理解优于屏幕（Delgado et al. 2018），但不推出「必须打印」；不把单篇效应量当固定收益。


## 讲解出厂自检（四维度，所有风格共用）

讲授正文（对话讲授轮与讲义正文）在发出/定稿前按以下四维度自检，**条目全表连续编号 1–15**，每项标 **E（阻断）/ W（警告）**。**按执行时点分级，不全量平铺**：

| 时点      | 必查项                                                        | 可后置项                      |
| ------- | ---------------------------------------------------------- | ------------------------- |
| 发出讲授轮   | 1、2（仅含量词时）、3、4、5、6（仅高风险外部事实）、7（仅含计算/代码/可运行示例时）、11、14（仅含图时） | 8–10、12、13、15，以及 6 的完整四要素 |
| 讲义定稿    | 全部 15 项                                                    | 无                         |
| 相关内容修改后 | 受影响项 + 5（术语一致）、8（结构）、14（图）                                 | 其余                        |

**E 项命中 → 修复并重检该项，通过后才能发出/定稿**；**W 项命中 → 同轮修复或显式后置（注明原因），不阻断——但 `W-UNICODE-CHAR` 是定稿例外，必须清零（见 `handout/pipeline.md` §2.11）**。本自检是模型自检，不替代 `scripts/verify_explanation.py` 的静态校验（定稿前两者都跑）。**深讲概念另跑「深度契约」D1–D6（定义见 `teaching/explanation-depth.md`）**：D1–D5 任一不满足 = E；D6 只用于删冗余。该审计不替代本表，二者都跑；缺 M/C 的深讲概念不得定稿。

### 1. 准确性与可信度

1. （E）结论、条件/定义域、量词、单位、版本与边界逐条核对；**含量词的表述（所有/任意/存在/至少/当且仅当等）逐条标注量词归属**；
2. （E）含量词的定义或规则**出厂配齐正例 + 反例（或边界例）+ 代入/验证演示**；不适合举例时说明原因与替代核验方式；
3. （E）分类不完备时明示「只列代表类型、非完备分类 + 补全位置与时机」，本节检验题**不得考所列类外情形**；
4. （E）定义/定理/推导/经验/类比/课程约定可区分（类比不当定义、约定不当事实，见「事实、来源与不确定性」）；
5. （E）符号、术语与引用全节一致；术语首次出现已给白话或定义，未假设学员已知；
6. （E）外部来源学员侧可得并注明名称/年份/链接/核验日期；不可得则改为课程内约定并说明；无法核实的内容标出不确定性，**不编造来源**；
7. （E）计算、推导、代码或操作至少做一次独立核对（代回、量纲、边界样例、运行成功标志，按领域选用）。

### 2. 结构

8. （E）概念单元必需槽位齐全（见 `handout/unit-schema.md`「讲义概念单元 schema」），节首导读三行齐，五要素、新记号三件套、分层标注按内容适用性齐全，答案框体例合规（`verify_explanation.py` 覆盖静态部分；**框内段内是否有多行、是否按最小单元分段，脚本不查，本项必查**）；**所用风格骨架里的 ④ 与 ⑤ 须指认到具体行**（反例/对照表/报错清单/检查清单不算 ④，骨架末尾的收束句不算 ⑤）；**纯概念豁免②③的单元，须有人工确认的正反例或等价表示（脚本不查，本项必查）**；**参照级豁免②③④⑤的单元，须人工确认定义与「何时用不上」的边界已写在正文（脚本只查①题目标记，不查内容）**；
9. （E）示例、讲义自测、题组三者不同题（可同知识点换情境），非只改数字的重复；
10. （E）所选风格可重排槽位，但未删除必需信息。

### 3. 密度

11. （W）易错点单一出处、小结不引入新信息、无空转句；②与③不原样重复——判据见 `teaching/explanation-density.md`「讲解文本密度原则」。
12. （W）逐段做「删除测试」——判据见 `teaching/explanation-density.md`「讲解文本密度原则」；可选细节后置并显式标注。

### 4. 呈现

13. （W）公式符合 LaTeX 约定（见 `ops/formulas.md`）；
14. （E）配图**逐面板与讲义文字对应，禁止漏面板**（漏面板 = 内容缺失）；按图类核对（坐标 / 流程 / 架构 / 时序 / 装置 / 受力 / 结构式，见 `handout/figures.md`「图像可视化双轨」可判读规范）；图文不一致时**以领域事实为准**先修图；
15. （W）代码/操作示例给出可复制的成功标志。
