## 4. 类型模板（阶段 2）

### 4.1 类型判定

- **记忆**：要背、要列、要认；没有可推导的机制（术语表、年份、常数、清单）。
- **概念**：要解释“为什么/是什么/何时用”；有正例、非例与边界。
- **程序**：要按步骤执行；有条件分支、决策点与完成标志。
- **设计**：要在约束下选择、创造或评价；有多解、备选与权衡。
- S0 任务类型只作先验：知识型→记忆/概念；技能型→程序/设计；备考型→记忆/概念/程序；材料型→概念/设计（论证）。
- 混合类型：定**主导类型**；两种都需要独立证据时拆单元或加类型子段。类型标签写规划区，不塞进每个标题；`## 概念 N` 继续保留给脚本，正文可称“学习单元”。
- 判不清时直接问学员：“你要**记住、解释、执行，还是在约束下设计方案**？”不静默混用。

### 4.2 四类矩阵

| 类型 | ① 题目/任务 | ② 解析/过程 | ③ 答案 | ④ 易错 | ⑤ 小结 | 配对 / 迁移 |
|---|---|---|---|---|---|---|
| 记忆 | 记住什么、与什么区分 | 编码线索/记忆策略 | `答案：`/`答：`，或 `③ 不适用（纯记忆）` | 混淆/干扰 | 线索卡（≤7 条） | 回忆+辨别 / 新语境使用 |
| 概念 | 回答/判断什么 | 机制、正例、非例 | `答：`/`参考答案：`+模型解释+例/非例 | 过度泛化/假类比 | 判别句（是什么/何时用/何时错） | 解释+分类 / 新例或非例 |
| 程序 | 完成什么任务 | 决策点、为什么这一步 | `解：`/`步骤：`/`代码：`+输出（决策点/验证写 ②/④，不写框内批注） | 步骤/顺序/条件/单位 | 决策流程（先…再…；卡住看…） | 同构/补全 / 新条件执行 |
| 设计 | 设计/评估什么，约束是什么 | 权衡、备选、评价标准 | `方案：`/`设计说明：`+权衡+标准 | 忽略约束/单一指标/过早定案 | 权衡句（目标/约束/取舍） | 案例分析（改一个约束）/ 新约束或替代方案 |

- **类型决定证据形态，风格决定呈现，学科提供素材**。六套风格不扩；类型模板不是第七套风格。
- 类型化自测：配对 = 同构；迁移 = 只换一个维度；四证动词按 `handout/pipeline.md` §3.1 调整。
- 类型化误区（预判）：记忆=线索混淆/干扰；概念=过度泛化/假类比/相邻概念混装；程序=步骤遗漏/顺序/条件/单位；设计=忽略约束/单一指标/过早定案。
- 类型化误区是**预判清单**；实际错因仍按 `teaching/lesson-flow.md` 六类（未教/遗忘/误解/方法选择/执行偏差/过度泛化）诊断，不替代错因分类。
- 单元数按 `handout/pipeline.md` §2.8：记忆 5–7 chunk、概念 5–7、程序 3–5 决策点、设计 1–3 案例。
- ③ 形态与标识按 `handout/pipeline.md` §2.3/§2.2：设计用 `方案：`/`设计说明：`，接受多解+标准；概念用 `答：`/`参考答案：`+例/非例；程序用 `解：`/`步骤：`/`代码：`；记忆用 `答案：`/`答：` 或纯记忆豁免。
- 类型标签可选；tier 标签仍必须有；两者不要混成同一个标签。


## 6. L1/L2/L3 支持级（阶段 2）

| 支持级 | 判定证据 | 讲义形态 | 产物 |
|---|---|---|---|
| L1 新手/新技能 | 无独立成功证据；首次；高元素交互；零基础/入门 | 完整教学例 → 配对 → 闭卷 → 评估例 | 完整讲义 |
| L2 部分会 | 有部分独立成功（S1 部分对、伺服 70–90%、旧题对但慢） | 补全式教学例 → 独立 → 闭卷 → 迁移 | 补全式讲义（完整五要素） |
| L3 已会 | 独立成功稳定（S1 全对、伺服 >90%、跨会话持续正确） | 无完整教学例；3–5 题检索（至少 1 道新情境） | 检索版要点卡 |

- **按技能判，不按课程判**：课程整体进阶不等于本子技能已会；进阶者学全新子技能仍走 L1。
- 证据缺失：新/复杂内容默认 L1；复习/熟悉内容默认 L2；在讲义前置行写明假设，不假装知道。
- L2 用**补全式教学例**，不是“半截教学例”；③ 仍须；不追求多级渐撤。
- L3 用**检索版要点卡**：题量、同题豁免、产物形态与嵌完整讲义时的 `③ 不适用（已会·检索版）` 标注，唯一事实源见 `handout/pipeline.md` §2.4「L3 复习产物例外」。
- 题量与同题例外见 `handout/pipeline.md` §2.4；支持级不是闸口，S3 仍由判分+关键能力+复述把关。
- 记录：学习日志/质量保障机制一句 `支持级：L2→L3（依据：…）`；不新增字段。

### 6.1 动态升降

| 当前 | 证据 | 下次 |
|---|---|---|
| L1 | 关键能力独立通过 + 连续 2 次独立成功（可同会话） | L2 |
| L2 | 关键能力独立通过 + 伺服 >90% + 至少一次跨会话独立成功 | L3 |
| L2 | 关键能力失败 / 提示后才过 | L1 |
| L3 | 检索或迁移失败 | L2 |
| L3 | 连续 2 次跨会话独立成功 | L3 保持 |

- L1→L2 是**支架渐退**，同会话独立成功可用；L2→L3、L3 保持要求跨会话独立成功（存储强度），同会话重复答对不单独升级。
- 冲刺模式不因时间压力跳级；新题型/新技能仍按证据定级。
- 同一会话重复答对不单独作为升级到 L3 的证据；S/D 也不因同会话重复增长（同会话抑制）。
- 同一子技能第二次仍不会 → 继续给支架，不按“出现次数”硬撤。

## 7. 学习者状态层（阶段 2）

| 来源 | 怎么用 | 禁止 |
|---|---|---|
| KP 状态（未讲/已讲/暂缓/排除） | 未讲→L1；暂缓→不写或标选学；排除→不写；已讲按已会证据决定 | 把“未讲”当“不会”或“已会” |
| 已会证据（S1 全对/伺服>90%/跨会话连续正确） | 已会→L3/压缩 | 把“没否认”当已会 |
| 薄弱点/错题本/保持复习 | 选误解、对比、配对；优先真实错因 | 把一次粗心写成概念误解 |
| 本次交接/学习记录/画像 | 类比领域、沟通偏好、稳定模式 | 把“没否认”当已会 |
| 本次 S1/S3 证据 | 支持级、起点、伺服 | 用课程整体起点替代本技能证据 |

**已会不是 KP 状态**：KP 状态只有未讲/已讲/暂缓/排除；已会证据来自 S1/伺服/连续正确/学员确认，不写进状态列。

- **确证铁律延伸到讲义**：`【已会·可跳过】` 必须带证据/日期；`【薄弱·重点】` 必须来自判分/错题；没有证据就不打标签。
- 标签可选：写规划区或单元旁，不铺满正文；与内容分层（最小必需/选学/参照）正交。
- **先预判真实错误**：六问里的“高信心误解”优先用这个学员的错因，其次才是通用误区；能在草稿里加反误解/辨析，不等二次定稿。
- 独立写讲义无画像：写明读者假设 + 前置自检，不打个性化标签，不假装知道学员已会什么。
- 一个单元映射多个 KP 时，按 KP 分别取状态；不要把“一个 KP 已会”当成整单元已会。


## 标准讲义（默认）

- 适用：绝大多数知识型小节。
- 骨架（〔〕= 槽位落点；六套风格都按此逐个指认，漏槽位即不算讲完）：概念〔定义/规则 + 一句机制/边界〕→ **类比（有合适类比时才用；无则改准确定义 / 实例 / 图示）〔按需表示，可省〕** → **教学例〔① 题目 ② 解析 ③ 答案〕（worked example；最小典型、透明）** → **配对练习〔配对自测：同构题，可回看教学例，答案放节末〕** → 易错点〔④：症状 + 原因 + 补救〕→ 三句话小结〔⑤ 小结：≤3 句、不引入新信息；优先写判别句〕→ **闭卷自检（阅读动作：3 句解释 → 信心 → 对照 ⑤）** → **评估例/迁移〔迁移自测：真实/新情境，答案放节末〕**。顺序与「讲义概念单元 schema · 默认顺序」一致；四段细节见 `handout/pipeline.md` §3.3。
- 题区写 `## 本节自测`，题前固定一行「先独立做完，再看本节自测答案」——提示语里不写「③ 答案」字样，避免被当成③标记行；答案统一放 `## 本节自测答案` 区，短答案合法、可短但不得写「略／见教材／同上」，不属五要素之③。配对题写在教学例后（配对自测）；`## 本节自测` 区放迁移题（迁移自测），也可两题都放；两题答案统一放 `## 本节自测答案`。
- **类型矩阵见 `handout/pipeline.md` §4**：记忆/概念/设计按矩阵替换 ③/⑤/自测形态；**L2/L3 可不出完整教学例**（§6），不违反“教学例只用一个”。
- **教学例判据（完整示例；适用于含解题/操作/作答过程的概念；五要素缺一不算讲完）**：
  - ① 题目（**要解决的问题或要完成的任务**）：题目型写题干要点——要你做什么、产出什么、交付给谁看；纯概念 / 纯记忆 / 参照级没有题干，写「本节要弄清楚什么」即可，不编造题目。题目只在这里写一次，答案框内不再重复。
  - ② 解析：方法与关键判断——每步做什么、为什么这么做、哪一步最容易错，以结论收尾。
  - ③ 答案（**参考解答**）：可整体誊抄的规范卷面，完整可复现即可，不排斥等价解法。
  - ④ 易错：本例最容易错的一步，症状 + 原因；⑤ 小结：≤3 句，只压缩不新增。
  - **③ 空位豁免**（下称「③ 空位豁免」，与深度契约的「机制豁免」不是一回事）：含解题/操作过程时③必选；纯概念/纯记忆没有可复现产物时**③ 框可省，但标记行不可省**——须在概念单元内显式标注 `③ 不适用（纯概念）` 或 `③ 不适用（纯记忆）`，同时豁免②③，①题目、④易错、⑤小结仍须具备——④ 写进「易错点」槽位即可，不依赖完整示例；标记行放在③位置、正文叙述里不重复该字样，避免误判；单元须有正反例或等价表示。**参照级单元**标 `【参照】` + `③ 不适用（参照级）`，豁免 ②③④⑤、只需 ①题目，定义与边界写在正文（canonical 标签全集见 `handout/pipeline.md` §2.2）。
  - **③ 框的形态**：从交付起笔到结论/产物收笔的完整、可复现答案，**框内不写题面段**（题目已在①），按**最小单元**分段（一段一个可独立核对的最小单元，各族形状见「讲义概念单元 schema · 框内分段」）。交付起笔按学科族取形态，**标识清单、分点与代码块规则见「讲义概念单元 schema · 答案框体例」与 `handout/pipeline.md` §2.3**——不把某一学科的写法当通用标准；代码/操作类须给运行结果与成功标志（见「答案框体例」）。
  - 备考/阅卷型任务按已声明的给分点书写并可整体誊抄，非备考任务按可提交/可复现格式书写，不虚构评分细则——②讲「为什么这么做」，③示范「卷面长什么样」，在已声明评分口径下覆盖必要步骤（备考/阅卷型任务学员照抄③应能得分）。涉及新记号/新操作的示例另须满足「新记号/新操作讲透」三件套（见下）。
- **教学例 vs 评估例（四段支架）**：①–③ + 配对用**教学例**（最小典型、透明、可判别；可原创/简化并标「改编自 p.X」）；迁移自测用**评估例**（优先来源原题/真题/学员真实任务，换新情境；**不是第二个完整教学例**）。评估例的答案按 §1 第 7 条答案三件套，不写成第二个 ③ 示范盒；备考型至少每个高权重小节有 1 个来源/真题风格的评估例。
- 写作要点：**深讲概念先按「深度契约」定层（D/P/M/H/B/C）再动笔**；零基础首次按「现象→符号引入序」。类比**优先取自学习者画像的类比领域**（无画像则贴学员场景），且**仅在类比真能说清时才用**——新内容没有合适类比时改用准确定义 / 实例 / 图示，**不强凑生活故事**（衔接 `teaching/lesson-flow.md` 第 3 节「无同构可撬则跳过、不硬凑类比」）；**教学例只用一个、做完整**——宁可少讲半个概念，不可给半截教学例（L2 补全/L3 检索版按 `handout/pipeline.md` §6，不受本句限制）；**评估例是迁移任务，不是第二个完整示范**（见 `handout/pipeline.md` §3.3）；误区写「症状 + 原因」而不只写结论；**术语首次出现给一句白话或定义**，不假设学员已知、不依赖未提供的材料。
- 成品范例（供导师对照格式与密度，非讲义内容；本例为【本节最小必需】级；其余族的段结构见 schema「其余族的最小形态」）：
  > **概念：解一元二次不等式（图像法）【本节最小必需】**
  >
  > - 概念：解 ax^2+bx+c>0，本质是找「抛物线在 x 轴上方」的那段 x 范围。
  > - 类比：抛物线像一座拱桥，>0 就是桥面以上的部分。
  > - ① 题目：解不等式 x^2−x−6>0。
  > - ② 解析：先解 x^2−x−6=0，十字相乘 (x−3)(x+2)=0，得 x=3 或 x=−2；开口向上（a=1>0），两根之间 y<0、两根之外 y>0，故解集为 x<−2 或 x>3。
  > - ③ 答案（可整体誊抄）：
  >
  > > 解：由 x^2−x−6=0，十字相乘得 (x−3)(x+2)=0，解得 x_1=−2，x_2=3。
  > >
  > > ∵抛物线 y=x^2−x−6 开口向上，与 x 轴交于 x=−2、x=3，∴原不等式的解集为 x<−2 或 x>3。
  >
  > - ④ 易错：忘判开口方向；把 >0 的解集写成两根之间（那是 <0 的），开口向上时 >0 取两根之外；Δ<0 只说明无交点，开口向上时 >0 恒成立（解集为全体实数），不是「无解」。
  > - ⑤ 小结：①先解对应方程；②看开口定内外；③解集用区间写全。
  > - 自测：①解 x^2−4>0；②判断 x^2+2x+3>0 的解集。（答案见本节自测答案）

## 费曼卡

- 适用：抽象概念；用户复述总卡壳的小节；复习时重讲。
- 骨架：①题目〔要讲清什么问题，如「$\pm$ 到底怎么读」〕→ 一句话大白话定义〔定义/规则〕→ 为什么重要（1–2 句）〔按需表示·动机，可并入①〕→ 讲给 12 岁孩子听的版本〔② 解析：是什么 → 怎么用 → 哪里会错，可并成一段但三步不得缺〕→ 一个类比〔按需表示；说清哪里像、哪里不像〕→ 反例〔④ 易错：什么不是它 + 最容易错在哪〕→ ③ 答案〔「最容易怎么用错」的对照答案，可只给关键句；纯概念标「③ 不适用（纯概念）」〕→ 一句话回收〔⑤ 小结：≤2 句、不引入新信息；不复述开头定义，只做压缩〕→ 自测〔检验：请用户不看卡复述〕。
- 槽位下限：①③④⑤ 各一行即可（费曼卡靠短取胜，不为凑槽位扩写）；② 由 12 岁版内部的三步承担。**③ 与 ⑤ 分工**：③ 收住「怎么用才不错」的成品答案，⑤ 收住「怎么记、什么时候用」，两句不得同义重复。
- 写作要点：**短而完整**——句句白话、紧凑，但不以字数截断（密度口径见「讲解文本密度原则」）；禁用行话，术语首次出现随即给白话替换。自测若只做口头复述（无书面答案），且单独写成 `## 自测` 区，须在该区首行写 `- 检验说明：口头复述，无标准答案`，不要留空答案区。

## 考试冲刺卡

- 适用：备考型任务的考点小节；结课前总复习。
- 骨架：①题目〔本卡对应的题型与分值，一句〕→ 本节考点清单（按考频标注★）〔定义/规则 + ② 的取材面〕→ 高频题型与解题步骤模板〔② 解析：第一步 / 第二步，可照抄〕→ 易错点（含扣分点提示）〔④：写「症状 + 扣哪分」〕→ 秒杀技巧或口诀〔⑤ 小结：≤2 句、只压缩不新增〕→ 3 道真题风格题〔检验〕→ 详解〔③ 每题答案，按答案框格式写，备考型附给分点量表〕。
- 槽位下限：考点清单 + 步骤模板 + ④ + ⑤ + ③ 缺一不可；口诀不得引入清单外的新知识点（它只是压缩）。
- 写作要点：解题步骤写成「第一步/第二步」可照抄的形式；题目难度对齐用户的目标考试；不引入超纲内容。

## 对比辨析卡

- 适用：一对易混概念（触发信号：薄弱点出现「分不清 X 和 Y」）。
- 骨架：①题目〔要判定的问题：什么场景下该用 A、什么场景该用 B〕→ A/B 一句话定义并排〔定义/规则〕→ 对照表（适用条件 / 典型场景 / 关键差异，≥3 行）〔按需表示 + ② 的判定依据来源〕→ 易混陷阱〔④：最常把 A 的哪条特征错安到 B 上〕→ 判别口诀〔⑤ 小结：≤2 句、只压缩不新增〕→ 各一道辨析题〔检验；③ 答案 + 判定依据〕。
- 槽位下限：② 由对照表的「关键差异」逐行承担（能照着逐条比对即可，不另写流程段）；④ 必须是**一条具体误判**，不写「注意区分」这类空话。
- 写作要点：对照表先行；口诀 ≤2 句；两道题各埋一个「看起来像另一个」的陷阱。

## 操作手册式

- 适用：技能型任务（编程、工具、软件操作）。
- 骨架：①题目〔要完成的操作与预期成果〕→ 环境与前置〔按需表示〕→ 分步操作〔② 解析〕→ ③ 答案〔`步骤：`/`代码：` + `输出：` 成功标志，代码/命令可复制、逐行注释〕→ 常见报错与修复（≥2 条）〔④：报错原文特征 → 原因 → 修法〕→ 关键决策三句话〔⑤ 小结：先做什么 / 卡住看哪条报错 / 什么算做成，≤3 句〕→ 练手任务（改错 / 仿写 / 微项目三选二）〔检验〕→ 完成检查清单。
- 槽位下限：④ 的每条报错必须是**本操作真会遇到的**（能对上②里某一步），不写「权限不足」这类泛泛报错凑数。
- 写作要点：每步可独立验证并给出「成功标志」；报错条目写「报错原文特征 → 原因 → 修法」。练手任务以成功标志判定，若单独写成 `## 检验` 区，须在该区首行写 `- 检验说明：练手任务，按成功标志自评`。

## 精读笔记式（论证文材料默认）

- 适用：材料型任务中**有「主张—证据」结构**的论证文（论文 / 评论 / 著作章节；「带我读 X」「精读 X」「帮我啃 X」多属此类）——有原文、目标是读懂作者在说什么，而不是掌握一个可计算的概念。条文 / 手册 / 代码库 / 数据表不走本式，按`teaching/lesson-flow.md`「材料型按材料结构分流」改用标准讲义或操作手册式。
- **单元 = 一个论证块**（一章 / 一节 / 一组自然段）：标题写该块的主张一句话，编号沿用 `## 概念 N · …`（脚本与闸口按同一单元处理，不另设第二套 schema）。
- 骨架：**① 题目**（这块要回答的问题 / 读完能复述什么）→ **块定位**（原文位置 + 这块在整篇里干什么：提出 / 支撑 / 反驳 / 收束）→ **② 解析：读法**（先拆结构骨架与证据强度 → 再抠关键术语 → 最后合上原文复述）→ **结构骨架与证据强度**（3–6 条：主张 → 证据（数据 / 案例 / 引文 / 推理，标原文位置）→ 让步或反驳 → 结论；每条注明「已证」还是「只是断言」）→ **关键术语**（术语｜原文用法｜一句白话｜易混点）→ **④ 易错**（断章取义、把作者转述的观点当成作者主张、旧译名混淆）→ **③ 答案**（参考复述的可誊抄版：`参考概括：` 起笔 + 末段 `原文定位：`；学员先写自己的版本再对照）→ **⑤ 小结**（≤2 句：主张 + 最强证据的压缩，供隔周回看定位）→ **检验**（2 道：这块的主张是什么 / 作者用什么支撑、哪里可质疑）。
- **五要素映射**（仍按 schema 写，不得豁免）：①题目=这块要回答的问题（读完能复述什么）；②解析=读法步骤（先拆结构骨架与证据强度、再抠术语、后复述）；③答案=**参考概括 + 原文定位**——直接用 `参考概括：` 起笔，末段写 `原文定位：<章节·段句范围>`，不写题面段（原文出处放块定位）；④易错=断章取义、把作者转述的观点当成作者主张；⑤小结=主张 + 最强证据的压缩（≤2 句，不是第二份复述）。
- 写作要点：
  - **转述不抄写**：直接引用不超过本单元篇幅两成，其余用自己的话；引用加引号并标位置。
  - **区分三层**：作者的主张 / 作者的证据 / 我的判断——后两层不得写成第一层（衔接「事实、来源与不确定性」）。
  - **术语首现即解释**（同标准讲义）；原文用旧译名或异体字时并列，避免学员换本书就不认识。
  - **枝节不进正文**：与本节目标无关的背景、考据进「扩展（选读）」区，或只标位置不展开。
  - **争议与过时**：原文观点有争议或已被修正时，写一句「截至<日期>，另有……」并给出处；**不替作者补论证**，也不把作者的话升格成事实。
  - ③ 是**参考概括**不是唯一答案：学员用自己的话覆盖要点即通过（衔接 `teaching/lesson-flow.md` 第 8 节主观题批改纪律）。

## 讲义概念单元 schema（所有风格共用）

讲义每个概念单元具备**可定位的必需槽位**：定义/规则、按需表示（类比 / 配图 / 对照表等）、完整示例或正反例、易错点、小结、检验问题。其他风格可重排槽位，但**不得漏槽位、不得删除必需信息**（参照级单元按「分层标注」条豁免，只留 ① 题目与正文里的定义、边界）。

**单元≠KP**：`## 概念 N` 是**教学单元**（历史标题，保留给脚本），不是 KP；映射关系、混合类型与规划区标注的唯一事实源见 §2.5。

**六个槽位的落点必须可指认**：每条风格骨架已用〔〕标出落点——五个编号槽位（① 题目 / ② 解析 / ③ 答案 / ④ 易错 / ⑤ 小结）外加 schema 的**检验**。写完按骨架逐项指认，指认不出的就是漏槽位；**④ 与 ⑤ 最容易被别的段落顺带承担**（反例、对照表、报错清单、检查清单、骨架末尾的收束句都不等于 ④ 或 ⑤），须能指到具体那一行，不认「隐含在……」。④ 与 ⑤ 都按「≤3 句、不引入新信息」写（⑤ 的记忆族「本节地图」变体上限见「讲解文本密度原则」），不因加了槽位就扩写。**修复表、决策日志、对照表算附件，不占 ④/⑤ 的三句额度；但单元仍要有一句 ≤3 句的摘要**（见 `handout/pipeline.md` §2.9）。

- **节首导读（定稿必备，3 行）**：在第一个 `## 概念` 之前写 `- 本节目标：学完能独立……`｜`- 前置：需要……（无则写「无」）`｜`- 预计：约 N 分钟`。与对话轮「课首定位」`teaching/lesson-flow.md` 第 1.1 节）同源，不复制理由；学员隔周回看先读这三行。脚本 `E-HEADER-BRIEF`：**定稿**缺任一行报 E，草稿不查（讲的过程中可后补）。**读者假设、已会/未会并入「前置」一行；用法放文末；类型/支持级放规划区——不新增第四行必填字段**（见 `handout/pipeline.md` §2.6）。
- **默认顺序**（标准讲义）：定义/规则（含一句机制/边界）→ 配图（按需）→ 教学例（① 题目 → ② 解析 → ③ 答案框）→ 配对练习（配对自测）→ 易错点（④）→ 小结（⑤）→ 闭卷自检（阅读动作）→ 评估例/迁移（迁移自测）。类比不单设槽位，归入「按需表示」，有合适类比时才用（见「标准讲义」写作要点）。**读者版 P1 可选增量**：节首导读之后可加 `## 本节速览`，概念单元首行可加「一句话结论：」，自测答案区之后可加 `## 回看索引`；三者只做导航，不改变上述五要素顺序与答案框位置。
- **风格 × ③ ⑤ 落点（六套风格都必须写出 ③ 与 ⑤）**：下表只列最容易写错的 ③ 与 ⑤；① ② ④ 与检验的落点见各风格骨架里的〔〕标注，不在此重复。**③ 只允许纯概念/纯记忆/已会·检索版/参照级豁免；⑤ 除参照级外任何单元都不得省**（canonical 标签与各自豁免范围见 `handout/pipeline.md` §2.2；下表逐行列出主要豁免，未列到的风格按同一规则处理）。
  | 风格       | ③ 答案（框）                        | ⑤ 小结                       | 允许的豁免                             |
  | -------- | ------------------------------ | -------------------------- | --------------------------------- |
  | 标准讲义（默认） | 可誊抄全文：从交付起笔到结论（不写题面段）        | 三句话小结（≤3 句）                | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」；参照级→「③ 不适用（参照级）」 |
  | 费曼卡      | 「最容易怎么用错」的对照答案，可只给关键句         | 一句话回收（≤2 句）                | 同上（纯概念/纯记忆/已会·检索版/参照级）          |
  | 考试冲刺卡    | 每题答案（选择题含逐项排除），详解附给分点量表       | 秒杀技巧或口诀（≤2 句）              | 无（备考型必有）                          |
  | 对比辨析卡    | 辨析题答案 + 判定依据                   | 判别口诀（≤2 句）                 | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」 |
  | 操作手册式    | `步骤：`/`代码：` + `输出：` 成功标志      | 关键决策三句话（≤3 句）              | 无                                 |
  | 精读笔记式    | `参考概括：` + 末段 `原文定位：`          | 主张 + 最强证据的压缩（≤2 句）         | 纯背景章→「③ 不适用（参照级）」                 |
- **分层标注（每概念单元出厂必须带）**：在概念单元起始处用方括号标签标注 **【本节最小必需】**、**【选学·后期必用（何时用/依赖哪节）】** 或 **【参照】**；也可写在规划区对应概念行（表格列或列表行，纯文本即可），二者其一。选学标注须写明何时用到、依赖哪节；学员据此自行判断是否当前深学，不必等导师逐个说明。**【参照】对应深度契约的参照级**：只需「知道它是什么、什么时候用不上」，可标 `③ 不适用（参照级）` 豁免 ②③④⑤（① 题目仍须，定义与边界写在正文）；**工作级/最小必需级不得用参照豁免**。正文里只是提到「选学 / 最小必需 / 参照」字样不算标注。**纯记忆用 `③ 不适用（纯记忆）`、已会·检索版用 `③ 不适用（已会·检索版）`；两者只用于对应情形，不得拿来给工作级/最小必需级省讲解**。
- **定稿边界**：定稿 = 判分记账零残留（**台账状态行**、伺服档位、检验作答记录、补讲台账留 progress.md 与题组文件，不进定稿；两态流转见 `handout/pipeline.md` §2.1 与 `handout/quality.md` §12）。**`verify_explanation.py` 通过只表示「结构可定稿」，不等于状态转定稿**：**讲义状态行** `- 状态：` 仍保持「草稿」，待小节闸口通过后再改为「定稿」。两态用词见 `handout/pipeline.md` §2.1。
- **讲义头部（讲义状态行 + 可选指针行，不复制规则正文）**：`- 状态：草稿（…）` 或 `- 状态：定稿（…）`；**台账状态行不进讲义**。需要记录体例约定时只写一行指针 `- 体例约定（LaTeX 排版/答案框）：统一见 progress.md「质量保障机制」`；**该区存在时才写指针，否则省略或先建区，不能留死指针**。规则正文归任务侧 progress.md；在头部复制规则块会触发 `W-STYLE-POINTER`。头部之后、第一个概念单元之前接「节首导读」三行（必填行与合并规则见上一条与 §2.6）。
- **答案框体例（学科无关）**：
  - **起笔**：框内只写**解题过程**，从**交付起笔**开始，或框内直接给出代码块。起笔标识以 §2.3 交付标识表与 canonical 集合为唯一清单，本行与脚本 `LEAD_WORDS` 必须一致。**不得默认 `解：`**——按当前内容所属学科族取形态；跨族内容（如物理借数学族）以内容所属族为准。
  - **不写题面段**：题干归 ① 题目，框内不再抄一遍（`题目：`/`任务：`/`Prompt:`/`原文：` 这类题面起笔在框内不再使用）。精读式另在末段写 `原文定位：<章节·段句范围>`（收尾段，不算第二类必需标识）。
  - **标记行留空**：只写 `③ 答案：`，答案写进框内；标记行带内容报 `W-MARKER-CONTENT`。
  - **标记行须在行首**（列表项，可加粗），正文里提一句「见 ③ 答案」不会被当成标记。
  - **多题单元**（如冲刺卡 3 道真题）：每题一个 `③ 答案（第 N 题）：` 框，或在一个框里按题号分段（`（1）解：…`，题号可写在框内段首，仍算交付起笔）。
  - **交付段须有实质内容**：去掉标识与标点后为空、或只剩「略／从略／见教材／同上／自行体会」等占位词的，不算答案（`E-BOX-EMPTY`）。
  - **分点编号**：段首 ①–⑩ 合法——按点给分的给分点就是「每点一段、段首起编号」；句中编号不合规（`答：①……②……` 挤在一行），须拆成每点一段。
  - **代码块**：框内的代码围栏（三反引号起止）整块算一段，块内多行不拆行、不查箭头与验算标记（验算只认 ✓ ✔ ✅，`√` 视为根号不拦），紧接 `输出：` 段给运行结果与成功标志。
  - **同一体例的五种形态**——数学 `解：…∴ …`；文科 `答：①资本：…`（每点一段）；语言 `Model answer: 他跑得很快。`；精读 `参考概括：…` / `原文定位：…`；编程 `代码：` + 围栏块 + `输出：无报错即成功`。

- **给分点量表（框外，备考/阅卷型适用）**：紧跟 ③ 框之后**单独一行**，不进框内——格式 `- 给分点量表：①<要点>（2分）；②<要点>（3分）；合计 5 分（训练量表，非官方细则）`。各点分值之和须等于合计（`E-RUBRIC-SUM`）；无官方细则写「训练量表，非官方细则」，有官方来源写「官方细则」并附名称/年份（缺声明 `W-RUBRIC-SOURCE`）。非备考任务不写分值，改给关键步骤、验证方式或成功标志，不编造官方分值。
- **框内分段（通用判据）**：一段 = 一个**可独立核对的最小单元**——单独拿出来能判对错、能给分、能对照的最小块。段内不再塞第二个这样的单元，也不把一个单元拆到两段。一句话：**看这一段能不能单独判对错**。
  - **段间写一个只含 `>` 的空行**；**段数不设下限**（单步答案一段即可，`> 答：B。` 合法）。
  - `解：`/`答：` 等交付起笔放在**首段起头**（不单独占一段），末段为结论。

  - **围栏代码块整块算一段**，块内多行照原样保留。
- **各族的「最小单元」（同一判据的不同形状）**：计算 / 证明 = 一个**语句**（对象 = 结果：一次变形、一次代入、一次判定各一单元，`∵…∴…` 依据与结论同段；同一表达式的连续变形可用连等式合并，解方程 / 不等式 / 证明逐步写）；按点给分（文科 / 记忆）= 一个**给分点**（段首 ①–⑩，每点一段）；论述 / 理论 = 一个**论证环节**（结论 / 依据 / 适用）；语言 = 一个**句子或意群**（译文按原句切）；编程 = 代码整块一段 + `输出：` 一段；精读 = 概括一段 + `原文定位：` 一段。
