## 9. 来源、范围与评估真实性（阶段 3）

### 9.1 四向对齐

- **内部矩阵**（家教/规划侧）：来源小节 | KP | 讲义单元 | 深度 | 自测/题组 | 状态。
- 每个讲义单元至少有一个来源锚点（页码/章节/图号/表号/数据位置），或标“原创/改编自 p.X”。
- 每个自测/题组映射到 KP/关键能力；允许一单元→多 KP、一 KP→多单元（`handout/pipeline.md` §2.5）。
- 四向对齐要能回答：来源哪段 → 对应哪个 KP → 写在哪个讲义单元 → 哪个自测/题组考它。
- 题组考了但讲义没讲 → 补讲义或移出题组；来源漏了但没写暂缓 → 补覆盖行（§9.2）。
- 矩阵是内部/家教侧；学员讲义只留一行覆盖声明 + 必要锚点，不塞整张表。
- 数据源：对照结论、材料覆盖、目行（课程体系.md）、题组；本册不改字段格式。

### 9.2 覆盖行与暂缓/范围外

- 讲义头部或末尾（有 `## 扩展（选读）` 时放在其前）写一行：
  `- 覆盖：来源 3.1–3.2（KP-01/02）；暂缓：3.3（原因）；补充：原创例 1 个；范围外：3.4（原因）`
- 这行是 SR-7“静默断章/静默裁剪范围”的合规出口：不写暂缓/范围外，就等于暗示“已经讲全”。
- 暂缓与范围外的唯一事实源仍是 progress.md；讲义行是派生显示，不改数据。独立写讲义（无任务）时，这行就是唯一记录。
- 来源缺失、读不到、与目标无关：写“未覆盖/暂缓/范围外 + 原因”，不静默跳过。
- 覆盖行不写分数、判分记录或内部调度信息。

### 9.3 深度分配

| 任务类型 | 深度依据 | 分配 |
|---|---|---|
| 备考 | 真题分值/频次/考纲 | 高频高分→深讲/工作；低频→参照；范围外→扩展/暂缓 |
| 知识型 | 依赖度/下游节数/迁移价值 | 高依赖/多下游→深讲；孤立→参照 |
| 技能型 | 真实任务频率/失败代价 | 高频/高代价→深讲；低频→参照 |
| 材料型 | 材料结构/作者权重 | 核心论证→深讲；枝节→参照 |

- 深度用现有分层标注：深讲/工作/参照；不平均用力。分层定义见 `teaching/explanation-depth.md`「深度分层」。
- 若所有概念都标“最小必需”，先重查证据；不要把“全讲”当负责。
- 深度分配与题量预算一致：深讲多练、参照少练，不靠加题补密度；**核心新题按 `assessment/scoring.md` 的题量预算**（正式确认题另计口径见同节）。
- 用户 `目标程度` 与证据冲突时，用户目标优先，并写明取舍。
- 深度分配是内部决策，不新增字段；可在规划区/覆盖行标注。

### 9.4 教学例 vs 评估例：来源真实性

- 教学例：最小典型、透明、可判别；可原创/简化，标“改编自 p.X”。
- 评估例：优先来源原题/真题/学员真实任务；换新情境；不是第二个完整教学例；答案三件套。
- 备考型：每个高权重小节至少 1 个来源原题/真题风格的评估例；用考试题型/分值/格式，不用通用例子替代。
- 非备考：用学员真实场景或现实情境；没有真实材料时用最小典型迁移。
- 来源例子太密：教学例可简化，评估例保留来源真实性；不要把来源例子同时当教学例和评估例。
- 来源例子有误/过时：写明并修正，不静默沿用。

### 9.5 来源保真

- 每个单元/示例记来源锚点：页码/章节/图号/表号/数据位置；原创/改编明确标注。
- 简化可以改语法/数字/背景，不得删适用条件、单位、例外；写明简化了什么。
- 引用原文不超过本单元两成；其余转述并标锚点；不伪造引文/链接/权威背书（来源分级与四要素见 `ops/evidence.md`）。
- 来源冲突：并列两说，写选择理由与日期；不静默取一个。
- 来源过时：标版本/年份；考试/考纲变化时说明；无法核实标“未核实”。
- 来源不可得：不得把推测写成事实；先按已知讲并标不确定性。

### 9.6 章规划与考试对齐

- 每个讲义小节映射到 S2 的一个章规划能力句与 1–3 项关键能力；映射写规划区/覆盖行，不新增必填头部字段。独立写讲义无任务时，用讲义目标 + 覆盖行作章目标记录，写读者假设，不伪造任务文件。
- 备考型：在覆盖行或评估例旁标考频/题型/分值；答案格式/单位/有效数字按考试口径；不编造官方分值。
- 非备考：迁移目标对齐学员目标/真实场景；不把“覆盖教材”当目标。
- 章规划/材料覆盖的唯一事实源仍是课程体系.md；讲义只引用，不复制记账。

## 12. 证据与边界

- 类型模板与支持级是**设计决策**：参考 Merrill 的成分显示、Van Merriënboer 的 4C/ID、Anderson & Krathwohl 的知识分类、认知任务分析与专家盲点研究、专长反转/支架渐撤；不是“某篇实验证明这套模板一定有效”。
- 来源四向对齐、覆盖行、深度分配、教学例/评估例真实性是**设计决策**：参考 constructive alignment、机会学习/覆盖度、真实性评估；不是单篇实验证明。
- P1/P2 是**设计决策/方向支持**：文本结构参考 Pyle 等结构教学综述；效用价值参考 Hulleman & Harackiewicz；质量回路参考形成性评价；教材章节层参考课程设计与教材组织研究；不宣称单一实验验证。具体规则见 `handout/enhancements.md` 与 `handout/reader-path.md`。
- 读者版可读性、图解语法与图表一致性的规则见 `handout/self-check.md`「自检与证据」；文献依据与边界见 `ops/literature.md`。本册不再重复，不宣称单一实验验证。
- 类型/支持级/学习者状态/来源对齐/P1/P2 都是**生成指导**，不新增运行时闸口；S3 仍由判分、关键能力、复述把关。支持级见 `handout/support-levels.md`。
- 四证/闭卷/二次定稿仍需真人冷读与延迟迁移验证；E44–E126 等人评未跑前不得宣称“已学会”（E108/E109/E116/E122 只是机器契约）。
- 不新增 progress.md 字段；旧讲义不回溯；`③ 不适用（纯记忆/已会·检索版）` 与设计类标识是增量合法出口。

### 材料型按材料结构分流

**判据 = 材料有没有「主张—证据」结构**：论证文（论文 / 评论 / 著作章节）→「精读笔记式」，单元 = 一个论证块，③ 为「参考概括 + 原文定位」；条文 / 手册 / 规范 / 教材条目（无论证结构）→「标准讲义」，单元 = 一条款，③ 为「条款引用 + 适用条件与例外」；代码库 / 配置文件 →「操作手册式」，单元 = 一个可跑通的改动，③ 为 `代码：` + `输出：`；数据表 / 图表 →「标准讲义」，单元 = 一个读图结论，③ 为结论 + 数据位置。知识型/技能型/备考型按学科族选标准讲义或对应卡片。
