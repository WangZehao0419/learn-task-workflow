# medicine 学科群 正本册

> 本册是「medicine」学科族的四类切片（plan / teach / practice / review）合一。

## 医学与健康群 · 规划切片

### 群边界与借用

本群：临床医学、药理学、解剖学、生理学、病理学、护理、公共卫生。它的特殊之处是**记忆与推理必须同时成立**——记不住药名做不了鉴别，只会背药名也做不了鉴别。

默认内容类型分布：记忆型与概念型并重（各约四成），程序型（操作、查体、病例书写）约两成。S2 按实际目清单核正。

本群不借用其他群的细则；但「记忆型怎么教」遵循内容类型处方（errorless 渐退、检索优先，口径见 `references/teaching.md`），不在这里另立一套。

### 内容结构与前置链

- **解剖与组胚**是形态学地基；**生理**是功能地基；**病理**是「功能怎么坏」；**药理**是「怎么干预」；**临床**是「怎么在病人身上整合」。
- 学习顺序的常见错误是**先临床后基础**：没有生理与病理的底子，病例分析只能靠背。
- **前置断层高发点**：反馈环（负反馈／正反馈）、层级结构（系统—器官—组织—细胞—分子）、体液与电解质的基本概念。
- **知识组织形态**：临床内容按「疾病脚本」组织，不按教科书章节组织——见讲授切片的疾病脚本三元组。

### 目标深度锚点

- **记忆型目**（药名、解剖名词、正常值）：能列举、能区分易混对、能说出「大概归哪一类」。到多点结构即可，不要求长篇复述。
- **概念型目**（生理机制、病理过程）：能画反馈环、能预测「如果这一步坏了会怎样」（SOLO 关联）。
- **程序型目**（查体、操作、病例书写）：能按序完整做完并说出每一步为什么；对应「可托付级别」——看着做／带着做／独立做需复核／完全独立。
- **临床推理目**：能从主诉推到鉴别诊断再收敛到诊断，且能说出排除了什么（拓展抽象）。
- **本群特别提醒**：先背结论不理解机制，在考试里可能过关，在临床上是危险的。机制目不能用背诵验收。

### 排期侧重

- **基础与临床交替**：连续多节纯解剖会掉动机，连续多节纯病例会悬空。按「一个系统的基础 + 一个该系统的病例」配对排。
- **记忆量按间隔铺开**：药名与正常值不能攒到考前背，从第一次接触起就进复习队列，按间隔铺开。
- **病例课单独占课时**：病例讨论不能挤在讲理论的轮次里顺带做。
- **复盘优先于新病例**：错过的病例要重做，新病例的价值低于把旧病例吃透。
- **考前**：以错题与高频鉴别为主，不重背全书。

## 医学与健康群 · 出题切片

### 题型阶梯

- **配对与区分题**：药名↔机制、症状↔系统、正常值↔意义。用「易混对辨析」而不是单项回忆——给一个情形问是 A 还是 B。
- **机制题**：给一个环节出故障，问后果；或给一个表现，问是哪个环节坏了。
- **图表题**：反馈环补全（挖一个节点）、因果链排序、鉴别表填空。
- **病例题**：从主诉到处置的完整链路；中级水平阶段必须包含「列出至少三个鉴别并说明排除依据」。
- **偏误题**：给一个已经下错的判断，问「这里可能犯了哪个偏误、应该补什么」。
- **交错**：机制题、病例题、鉴别题混排，逼学员先判「这题在考记忆还是推理」。

### 群级共享误区库

跨医学学科通用的误区见 `references/disciplines/medicine.md`「实证误区库」。

### 判定题构造

问「先做什么」而不是「这是什么病」：给一个急诊场景问第一步处置（排查致命 vs 完善检查）、给两个相似病例问关键鉴别点在哪、给一个已下的诊断问「最该补的一项检查是什么」。干扰项要是「常规上会做但在该情境下优先级更低」的操作。

### 答案形态与最小单元

- 起笔用 `答：`；病例写在讲义 ① 题目，框内不抄病例。
- 最小单元＝一个**论证环节**：诊断一段、依据一段、鉴别一段、处置一段。
- 病例题按「主诉—现病史—查体—辅助检查—诊断—鉴别—处置」分段；每段可独立核对。
- 机制题用「因为……所以……」写因果，不写「一般来说」。
- 客观题给答案 + 逐项一句排除。

### 视觉任务

用原始图像与原始数据：影像片、心电图、病理切片、检验报告、体格检查示意图，记录来源与图号；替代禁令、证据资格与原图不可得处置见 `references/assessment.md`「视觉任务证据」。

### 给分点结构

病例题按「主诉与病史 / 查体与检查 / 诊断与依据 / 鉴别与排除 / 处置」五段给分；机制题按「环节定位 / 因果链 / 结论」三段；偏误题按「指认偏误 / 说明机制 / 给出补救」三段。

## 医学与健康群 · 复习切片

### 复习形态与间隔侧重

- **记忆条目走间隔重复**：药名、正常值、解剖名词从第一次接触起就进队列；间隔重复在医学教育里有稳定的中等效应，是最高性价比的复习方式。
- **机制条目走「反事实」复习**：不问「这个机制是什么」，问「如果这个环节失效会怎样」。答得出说明机制是活的。
- **病例走复现而非重读**：遮住诊断，只看主诉与检查，重新推一遍；推完再对照。重读病例几乎不产生学习。
- **易混疾病成对复习**：鉴别表行级复现，两个病同框比较，不分开背。
- **跨系统串联**：每隔几次复习插一道跨系统题（如「这个症状可能来自哪三个系统」），防止知识按章节割裂。

### 错因分流与纠错脚本

| 错因 | 判别信号 | 纠错动作 |
|---|---|---|
| 记忆缺口 | 想不起药名或数值 | 单条进间隔队列，一卡一事实；不整段重背 |
| 机制不清 | 能说出表现，说不出为什么 | 重画反馈环或因果链，补「如果坏了会怎样」 |
| 脚本未成型 | 见过但想不起来，或跟别的病混 | 补疾病脚本三元组，与易混病同框对比 |
| 鉴别遗漏 | 只给一个诊断 | 强制三候选练习，含一个危险项 |
| 偏误 | 锚定、过早收敛、标签化 | 偏误专项：给已下错的判断，问该补什么 |
| 时间轴混乱 | 急慢不分、先后颠倒 | 画病程时间线，标可逆点 |

**提醒**：单纯提醒「注意偏误」并不改善判断，必须同时补知识与流程——去偏清单单独使用在对照实验里没有优势。纠错时先补知识缺口，再谈流程。

### 冲刺侧重（方法层）

- **高频鉴别优先**：冲刺期把课时给「最容易混的几组病」，不给「最不熟的罕见病」。
- **病例限时**：按考试节奏限时做病例，练「先列鉴别再收敛」的答题顺序。
- **记忆条目只清错题**：不重背全书，只过错题清单与易混对。
- **机制题按三句话说**：定位环节、说因果、给结论——按这个骨架练，避免答题时铺陈过多。
- **考前确认考点范围**：以官方大纲与真题结构为准，不按教材厚度估重点。

## 医学与健康群 · 讲授切片

### 讲授侧重（六拍内的群差异）

- **知识按「疾病脚本」组织，不按章节组织**：每个疾病记三件事——**启用条件**（流行病学、危险因素、年龄性别）、**故障**（病理生理）、**后果**（症状、体征、检查）。这三元组是专家做快速模式识别的知识形态，也是病例分析的检索索引。
- **反馈环必须画成环**：生理与病理的机制不能画成单向箭头。体温、血糖、血压、电解质——凡出现「升高的东西会反过来抑制升高」，就必须画环。
- **双过程并用**：模式识别（像什么病）与解析推理（列出并排除）都要教。**中级水平最危险**——知道得多但脚本还没成型，容易过早收敛。对这个阶段要强制列鉴别。
- **记忆与推理分开练**：药名、正常值用检索卡；病例用推理题。不要用病例题考药名，也不要用背诵考推理。
- **先讲「如果不这样会怎样」**：机制讲完立刻问一个反事实（「如果这段血管堵了，上游会怎样」），比复述机制有效。

### 临床思维实践

1. **定问题**：主诉是什么？这个主诉可能来自哪些系统？
2. **列鉴别**：至少三个候选，含一个「危险但少见」的——漏掉致命的那个是最贵的错误。
3. **找证据**：每个候选需要什么证据支持／反对？该做什么检查？
4. **收敛并说明**：为什么支持这个诊断？排除了什么？还留什么不确定？
5. **反思偏误**：我这个判断有没有受锚定、可得性、过早收敛影响？

### 表征体系

- **疾病脚本卡**：启用条件／机制／表现／检查／鉴别，一页一张。
- **反馈环图**：传感器—中枢—效应器—反向调节，环形不画箭头。
- **因果链图**：病理过程用「起—承—转」三段，标出可逆点。
- **鉴别表**：易混疾病并排，行是「支持点／反对点／关键检查」。
- **时间线**：急症与慢病的病程节奏差异要标出来。

### 类比库

- 免疫系统＝边防＋公安：识别病原＋清除异常细胞；不像处——免疫会误伤自身，边防不会。
- 负反馈＝空调恒温：偏离就反向调节；不像处——生理调节目标本身会随状态移动（如发热时的调定点上移）。
- 肾脏＝滤网＋回收站：先滤后选择性回收；不像处——回收是主动耗能的，不是被动拦截。
- 药物＝钥匙，受体＝锁；不像处——很多药是部分激动、反向激动，不是非开即关。

### 术语纪律

解剖方位词（上下／前后／内外／近远端）必须统一参照系，全课程同一套。同义异名（如「内环境」与「细胞外液」）统一到一个，另一个括注。术语首现给「定义 + 一个例子 + 一处易错」。

### 病例分析的标准流程

**七段顺序**：主诉 → 现病史 → 查体 → 辅助检查 → 诊断 → 鉴别 → 处置；各段要点（含依据、排除理由、随访与红旗征）见 `references/disciplines/medicine.md`「病例答案结构」。

示范时每一步说清「为什么问这个、为什么查这个」，不只给结论。
