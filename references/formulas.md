# 公式与科学符号排版

<!-- owns: 公式/符号排版、定界符实测、复制与窄屏、formula_checks 口径；must-not-define: 教学决策、图形/讲义结构、判分 -->

本分册是公式、方程式与科学符号「结构化呈现」的**唯一事实源**：只管呈现、定界符、分组、窄屏分行与复制，不承担其他职责。所有定界符在宿主验证（第 8 节）完成前一律只是待实测候选；宿主未验证或目标语法不支持时，停止当前运行并说明恢复条件，不自动改文字或纯文本替代渲染交付。用户一开始就明确要求纯文本时，按纯文本目标生成，不属于替代。

- **触发**：当前输出准备包含学习者可见、需要结构化呈现的公式、方程式、化学式、单位关系、向量/张量记号、统计表达式或其他科学符号语义表达式时，才应用本册。
- **不触发**：普通年份、数量、页码、日期、版本号和不承担公式语义的数字；代码围栏、程序字符串、数据字段中展示的公式源码；引用材料中的公式源码（除非任务明确要求转为学习者可读公式）；没有公式/符号的普通讲解、计划、进度汇报。
- **混合任务**：只对相关公式/符号片段应用本册；文字、代码和图形仍按各自事实源处理。
- **跨学科适用**：数学（分式/根式/幂/上下标/矩阵/定义域/多步推导）、物理（量/单位/向量/误差）、化学（下标/电荷/反应式/条件）、统计/概率（条件概率/求和/分布）及其他领域的科学符号表达式均适用；**格式入口是「是否有学习者可见公式/符号」，不是学科名称**。
- **本册不设默认定界符**：任何定界符只有「未选定」与「已实测选定」两种状态，状态记录见第 8 节 (e)。
- **边界分工**：讲义风格与函数图像/几何图形 SVG 双轨归 `handout.md`；新记号/新公式「语义—代入演示—易错点」三件套与教学决策归 `teaching.md`；本册不重复、不削弱、不接管上述内容。

## 1. 行内与块级的选择

- **行内**用于短小、不打断句意的变量条件、简单关系或代入式：
  - 变量条件：x>0、k 为正整数；
  - 简单关系：y = kx + b；
  - 代入式：代入 n=10 后的取值。
- **块级**用于较长或嵌套的表达式、重要结论、独立待求式、复杂分式/根式、多步推导。
- 判据：行内公式删掉后句子仍通顺才算「不打断句意」；需要独立阅读的表达式一律升为块级。
- 多步推导**每行只呈现一个关键变形**，不把多个变形挤进同一行；变形行之间不插大段文字。
- **公式不能替代必要的自然语言解释**：解释写在公式外，不把整段中文塞进公式环境；公式块前有引出句、后有承接句，不留悬空公式。
- **中文标点通常放公式环境外**：只有属于公式本身的逗号、分号、条件符号才留在公式内。
  - 示例：「解得 x=3，且 x≠1」——逗号在公式外；
  - 分段定义内部的分隔逗号属公式本身，保留在公式内。
- 行内公式不得挤乱句子节奏：一句话内不堆多个行内公式，密集时改写句子或升为块级。
- **数学表达式用公式呈现，程序代码用代码块**，两者不混用；同一份材料内同一符号前后用同一写法。
- 引用材料中的公式源码保持原样；转写为学习者可读公式须任务明确要求，且转写后按本册全流程检查。

## 2. 结构与嵌套

- 使用常见且可移植的结构命令，如 \frac{a}{b}、\sqrt{x+1}、x^2、a_n——**此四例仅作结构命令示例，不构成任何宿主已支持的承诺**，可渲染性以第 8 节实测为准。
- **参数和分组括号必须完整**，不得省略，不依赖读者脑补。
  - 示例：sqrt((a+b)/c) 的括号决定根号覆盖范围，漏括号即变义。
- 明确**分子/分母、根号覆盖范围、嵌套括号**；**上下标归属一眼可判**，多字符上下标要显式分组（如 a_(n+1) 不写 a_n+1）。
- **不用 a+b/c 表达本意为 (a+b)/c 的结构**：纯文本写 (a+b)/c；渲染态写成分式整体。
- 矩阵、多行结构等复杂结构**整块呈现**，不手工拼空格对齐；目标语法未验证或不支持时停止当前运行，不自动改写成文字描述。
- **首次出现**的变量、单位、统计量、化学符号要说明含义与适用范围。
- 定义域、非零条件、正负条件、单位制、量纲、反应条件在**推导前或使用处**说明：
  - 数学：sqrt 内非负、分母非零、对数真数为正；
  - 物理：单位制与量纲；
  - 化学：温度、催化剂等反应条件。
- 条件不进公式时用紧邻文字补出，位置保证读者在使用公式前已读到。
- **只在含义准确时用**等号、等价、推出、近似符号：数值近似用 ≈ 不用 =；推出关系不冒充等式。
- **变形若改变解集或引入候选根必须说明并验回**：候选根逐个代回原式，排除不成立的解再下结论；验根的中间数值可省，排除理由必须写出。

## 3. 多步推导与中文标点

- 每步**保留采用的定律/近似**，不写无来源跳步；定律与近似名称写在公式外或行内文字中。
- **等号或关系符尽量对齐到同一竖列**，让每步依据一眼可对；无法对齐时按行写依据，不硬凑空格对齐。
- 是否可用 aligned/align 等多行结构**取决于目标渲染器实测**；未实测则停止当前运行，不能自动改成纯文本交付。
- **窄屏不得拆开分式、根式、上下标结构**；长式在等号/关系符/运算符处整行换写，是否溢出按第 8 节 (d) 第 4 步判定。
- 变形改变解集时**显式写出变化并验根**，验完才写最终结论。纯文本目标的分行示例（解 sqrt(2x+3)=x）：
  - 前提：2x+3 >= 0（根式内非负）；左端非负，故 x >= 0
  - x^2 = 2x+3（原式两边平方）
  - x^2 - 2x - 3 = 0（移项合并）
  - (x-3)(x+1) = 0（因式分解）
  - x = 3（x = -1 代回得 sqrt(1) = 1 != -1，排除）
- 推导的引出句与结论句写在公式外；推导行内不夹中文标点，标点留给公式外的文字。

## 4. 物理专节

- 适用对象：v=Δs/Δt、F=ma 等量关系，向量与分量，误差与不确定度，单位与量纲；**物理题型与实验教学策略不由本节改变**。
- **先定义量，再写关系式**：v、a、F 等首次出现即说明含义与单位。
- 数值代入时**数值与单位分开，最后统一单位**。示例：s=3000 m、t=60 s，分别带单位写出，得 v=50 m/s；不写 v=3000/60 m/s 这类半换算形态。
- **同一推导内单位制统一**（全 SI 或全题目单位），换算集中在代入前完成。
- **检查单位换算与量纲一致性**（如 km/h 换 m/s，先换单位再代入）；量纲对不上说明公式或条件有错，先修内容再修排版。
- **单位不得因排版黏成变量下标**：速度符号是 v，单位 m/s 独立可辨，不把 m/s 塞进下标。
- **向量、分量、时间序号、误差、不确定度的上下标必须可辨**；必要时补一句「该下标表示分量/时刻/样本」。
  - 示例：v_x、a_1、Δt、m_0——下标是分量、序号还是初始值，一眼可判。
- 向量记号（箭头或加粗）全篇保持同一种形态，不中途混用。
- **每步保留定律或近似**（「由牛顿第二定律」「忽略空气阻力」），让推导可逐步追踪。

## 5. 化学专节

- 适用对象：反应式、离子电荷、同位素、物态符号、反应条件；**化学概念、反应机理和安全规则不由本节改变**。
- **系数与下标语义不同，不能混写**：配平系数改变粒子数，下标属于化学式本身——2 H2O 表示两个水分子，H2 表示氢分子由 2 个氢原子构成。
- **保留**离子电荷、同位素质量数/原子序数、反应箭头、物态符号、温度/催化剂条件；用户明确要求纯文本时，物态与条件括注在箭头后（如 (点燃)）。
- 同位素记号的位置（质量数/原子序数在元素符号的左上/左下）在文字中写明。
- **mhchem 或 \ce{...} 是可选扩展**：必须先在目标宿主实测支持，才可用于复杂化学式；未实测时不得假设宿主支持，测试字段见第 8 节 (a)。
- **mhchem 未实测或实测不支持时停止当前运行**，不自动改成纯文本替代；用户明确修改为纯文本目标后才按该格式继续。
  - 同位素：C-14（质量数 14）
  - 系数与化学式之间留一个空格（2 H2O，不写 2H2O）。
- **配平结果必须能从左右原子数核对**；离子方程式左右电荷也须可核对；**渲染通过不等于化学正确**，对不上先修内容再修排版。

## 6. 统计/概率专节

- 适用对象：条件概率、求和与期望、方差、分布、置信区间；**统计推断方法与数据解释不由本节改变**。
- **明确条件概率的条件线**：P(A|B) 读作「在 B 发生条件下 A 的概率」，条件线不可省略。
- **明确求和上下限**：纯文本写 Σ(i=1 到 n) a_i，缺上下限即含糊；求和对象与求和变量写清（对 i 还是对 j）。
- 求和、积分等大型算子的上下限在块级中写全；行内只写简式并配合文字说明上下限。
- **区分样本统计量与总体参数记号**，不混用，首次出现即说明：
  - 样本：x̄（均值）、s^2（方差）；
  - 总体：μ（均值）、σ^2（方差）。
- **期望、方差、分布记号先定义再用**（如 E(X)、Var(X)；正态分布两个参数各是什么），不甩裸记号。
- 置信区间、假设检验的符号（如 α、z_(α/2)）**首次出现即说明下标与取值含义**。
- 表格或文字中的公式与**列名对应清楚**，每列符号含义可逐列对上；列宽窄时改用第 7 节分行或文字描述，不压缩上下标。
- **复制后不得丢失上下标和求和范围**。

## 7. 代码边界、复制与窄屏

- **代码围栏、程序字符串、引用源码中的公式一律按代码原样展示，不渲染**。示例：程序字符串里的 "\frac{a}{b}" 显示为源码字符本身（此处仅为源码示范代码边界，非输出语法）；伪代码中的数学表达同此处理。
- **数据字段、CSV、表格单元格里的公式源码按数据原样展示**，不渲染。
- 用户明确要求纯文本时，用可辨分组书写：分式/根式写 `sqrt((a+b)/c)`、`(a+b)/c`，幂/下标写 `x^2`、`a_n`，化学式写 `SO4^2-`、`2 H2 + O2 -> 2 H2O (点燃)`；这是目标格式，不是渲染替代。
- 纯文本分组、范围、条件必须与语义一一对应，不得省略条件。
- **长表达式按语义在等号/关系符/运算符处逐行**，不把分式、根号、上下标拆成无法判断归属的片段。
  - 例：等号右端过长时，「= 右端」单独成行，关系符仍对齐。
- **复制后至少保留可辨结构**：
  - 指数与上下标（x^2、a_n）；
  - 分子/分母与根号范围（(a+b)/c、sqrt((a+b)/c)）；
  - 化学下标/电荷（SO4^2-）、单位与箭头（->）。
  - 不要求各宿主复制出字节相同的结果。
- 渲染不可用时停止当前运行，不得把复杂源码或文字描述冒充已渲染交付；用户处理宿主后重跑第 8 节验证。
- 复制验证按第 8 节 (d) 第 3 步执行；宿主或预览器更新后复测。
- 落盘材料与对话内输出保持同一呈现形态。

## 8. 目标宿主验证记录模板

**定界符按宿主实测选定；在实测记录完成前，不得把任何定界符写成事实。**

- **(a) 记录字段清单**（首次接入新宿主时逐项填写，缺项标注「未测」）：
  - 聊天宿主名称/版本；
  - Markdown 预览器名称/版本；
  - 目标屏宽；
  - 是否支持 MathJax/KaTeX；
  - 是否支持 mhchem；
  - 复制结果；
  - 渲染截图或人工检查说明。
- **(b) 候选定界符测试顺序**（均为待实测候选，非默认语法）：
  - 顺序：目标宿主原生方案 → \(...\)/\[...\] → $$...$$ → 宿主明确记录支持的其他方案；
  - 若候选采用单美元符号，须**额外测试**价格文本误识别、转义和 $$ 的解析顺序；
  - 两个环境无共同渲染语法时停止当前运行，说明不兼容环境；用户调整目标环境后重测，不得用某一环境的替代形态冒充两处一致。
- **(c) 固定样例 7 项**（样例中的 frac、sqrt 写法仅为待测结构命令示例，不代表已支持）：
  1. 行内 frac{1}{2} 与 sqrt{x+1}；
  2. 块级 frac{a+b}{sqrt{c}}；
  3. 含等号对齐的两步变形；
  4. v=Δs/Δt 的数值与单位；
  5. 纯文本待测样例：2 H2 + O2 -> 2 H2O、SO4^2- 和同位素；
  6. 中文标点紧邻公式；
  7. 代码中原样展示公式源码。
  - 七项分别对应行内、块级、对齐、单位、化学、标点、代码七类场景，实测时逐项记录；
  - 聊天宿主与预览器使用同一批样例文本，便于对照。
- **(d) 五步验证流程**：
  1. 聊天宿主检查分式上下结构、根号范围、上下标、电荷、箭头；
  2. 预览器重复检查；不支持时记录阻断原因，不伪造通过、不继续交付；
  3. 复制到纯文本编辑器，确认结构仍可辨；
  4. 缩窄窗口，确认长公式不横向溢出；必要时按语义分行；
  5. 检查代码源码没有被误渲染。
- **(e) 选定记录位**：selected_inline 与 selected_block 各一行；
  - 格式如「selected_inline：<定界符>（宿主 X vX / 预览器 Y vY，2026-MM-DD 实测）」；
  - **未实测前保持「未选定」**。
- **判定线**：只有目标聊天界面和主要 Markdown 预览器都能稳定显示分式、根式、上下标、中文标点和多步结构时，才允许写入 selected_inline 与 selected_block。
- **验证产物**：环境记录、选定定界符、渲染截图或人工检查说明、复制结果、窄屏结果；不支持项列为阻断原因与恢复条件。

## formula_checks 附加评分口径

> 本表是 formula_checks 的唯一口径；`evals.json` 的 `formula_checks_rubric` 只作评分模板，引用本表，不另立定义。

- **仅作评测附加字段**，不替代 evals.json 现有五轴主评分（0–5），不改变现有分数与 verdict 语义。
- 字段名 formula_checks，五维各 0–2 分，逐维独立记分、不折算，各维附一句理由写入 review_note。
- 证据字段固定为：prompt、fixture、actual_output、run_id、scores、verdict、reviewer、review_note；run 标识建议 formula-typesetting-<版本>-<YYYYMMDD>-<短commit>。
- 评分者独立核对学科内容：**渲染通过不等于学科正确**（见第 4、5 节），渲染检查者不得兼任学科评分。
- 结构渲染、复制保真两维的评分须引用第 8 节 (d) 的检查结果作为证据。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 学科内容 | 公式/方程或条件错误 | 大体正确但漏条件/核验 | 结论、条件、步骤均正确 |
| 结构渲染 | 定界符破损或范围歧义 | 基本可读但层次欠佳 | 结构清楚、渲染正确、版面适合 |
| 教学解释 | 只给公式/答案 | 有部分说明 | 符号、条件和关键变形均解释 |
| 复制保真 | 复制后含义丢失 | 需猜分组 | 复制/目标格式后仍可辨 |
| 边界 | 普通文字或源码被公式化 | 局部多余 | 公式、文字、代码各自正确 |

- **阻断型评测用例**的学科内容、结构渲染、边界必须为 2，其他适用项不得低于 1。
- 未真实回放的条目保持「未验证」（verdict 枚举以 evals.json 为准：通过/未通过/未验证）；有真实回放但未独立评分的条目，verdict 暂记「未验证」并在 review_note 标注「待独立评分」。
