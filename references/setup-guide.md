# 运行依赖与配置指南（setup-guide）

本指南说明 learn-task-workflow 的运行依赖、环境检查与缺失项处理。本技能**无网络与凭据依赖**：不需要登录、不需要 Token/API Key；联网查证为可选的模型侧动作，失败时按「未验证」话术降级，不阻塞主流程。

## 依赖总览

| 依赖 id | 类型 | 必需 | 支撑功能 | 检查方式 |
|---|---|---|---|---|
| python-runtime | runtime | 是 | 任务索引与进度解析 / 进度校验与证据验证 / 间隔调度与校准计算 / KP 拓扑排序与检环 / 环境就绪检查 / 讲义结构校验 | `scripts/check_environment.py`（python 检查项） |

> 跨平台注：本技能只依赖终端执行、文件读写、目录枚举与文本检索等能力接口；具体能力由宿主以等价工具提供，不绑定某个 agent、终端或命令名。
>
> **两项能力没有可检查依赖**（清单中只声明 capability 与 `functional_degradation`，不设 check）：
> - `学习数据落盘`：宿主文件写入。检测写权限要么真写一次（违背「检查器全程只读」），要么依赖不可靠的 ACL 判断，故不做机器检查；由首次真实写入的结果说话。
> - `备料来源检索`：模型侧可选检索。本技能零网络请求，无可探测实体。
>
> `check_environment.py` 对这两项输出 `unmapped_capabilities`（`status=not_checkable`），状态为 `partial`；**这是「没检查过」，不是「检查失败」，更不是「已验证」**。

## 调度算法口径

`scripts/scheduler.py` 采用**自研简化双参数算法**（稳定度 / 难度双参数，按判分档位递增间隔），以零第三方依赖、简单稳健为先；**非 FSRS 算法，亦非 SM-2 标准实现**，不做参数个性化拟合。字段定义见 `references/data-and-recovery.md`「复习调度字段」，计算命令见 `phases-and-gates.md`「调度调用速查」（S4）。

## Python 版本要求

- 基础要求：Python ≥ 3.10（六个脚本）。
- 版本低于 3.10 时检查器判 `needs_setup`，脚本可能因语法或标准库差异失败；不支持更低版本。
- 托管环境（解释器由平台托管）通常无需手动安装；非托管环境请自行安装。
- 官方主页：https://www.python.org/
- 官方文档：https://docs.python.org/3/
- 官方安装指南：https://docs.python.org/3/using/index.html（Python setup and usage）

## 检查与路由

本脚本为**诊断入口**（日常默认不预检——脚本自身失败时已显式报错；仅当脚本调用出现解释器/版本类失败时，运行 `python "<技能根>/scripts/check_environment.py"`（默认检查全部功能，可按需传 `--capability`）诊断一次）。按输出状态路由：

| 状态 | 含义 | 处理 |
|---|---|---|
| ready | 依赖齐备 | 跳过本指南，直接进入正常流程 |
| partial | 基础可用、部分功能不可用或**不可机器检查**（如解释器版本不足导致相关能力不可用；落盘/检索无检查项） | 进入可用流程，**只说明「请求能力 ∩ 失败检查」交集中的受影响功能**与降级方式——check 可声明其影响的能力（**单检查可省略、默认继承依赖声明的全部能力；多检查必须逐个声明**，漏声明会直接 `manifest_error`），**不得把无关能力一并降级**；单独请求某能力时明确该能力不可用而其余不受影响。输出 `unmapped_capabilities`（`status=not_checkable`）表示该能力没有可检查依赖：**按对应 `functional_degradation` 执行，不等于已失败**，也不得声称已验证 |
| needs_setup | 缺失必需依赖 | 只展示缺失项配置步骤，配置后重新检查 |
| unavailable | 版本不兼容或环境异常 | 展示原因、恢复步骤与安全降级 |

配置齐全时不重复展示本指南；重新检查时只报告状态变化。

**`dependencies` 的显示口径**：`status=ready` 时列出全部依赖项；非 `ready` 时只列**未通过**的项——空数组表示其余依赖的检查都通过了，不是“没检查”。被过滤掉的通过项不重复展示。

## 验证方式

- `python --version`：确认解释器存在与版本。
- 运行 `python -B "<技能根>/scripts/check_environment.py"`：确认 status 为 ready，或**可解释的 partial**（`unmapped_capabilities` 里只有落盘/检索这两项不可机器检查能力）。若 partial 里出现其他能力，才按降级矩阵处理。
- **六脚本自测**（契约回归口径；详细脚本契约与自测清单位于 `evals/scripts-contract.json`，不放进 `skill-dependencies.json`，以保持环境清单 schema 兼容）：`python -B "<技能根>/scripts/{task_index,progress_check,scheduler,kp_sort,check_environment,verify_explanation}.py" --selftest`，逐一退出码 0。
- **打包前清理**：删除 `scripts/__pycache__`（字节码缓存会被静态预检当作不可扫描脚本）；`.trae`/`.workbuddy` 是本地 IDE/记忆目录，**打包时用干净副本排除**（`package` 不会自动忽略它们）。`scripts/task_index.py` 的 `tmp.unlink()` 只清理 `index.json.tmp`；preflight 的 high `file_delete` 属该临时清理，人工复核后可带 `--risk-ack` 打包。
- **人工核验边界（F15）**：无解释器时上述脚本项**不可机器判定**，只能按本指南人工核对并如实标注「部分验证 / 未验证」——**不得谎称已通过脚本验证**；哪些环节可人工核验、何时只给部分验证、何时确需阻断，**一律以 `skill-dependencies.json` 的降级条目为唯一事实源**（下方矩阵为摘要，冲突时以清单为准）。

## 缺失与故障处理

- 解释器缺失：按上方官方入口安装 Python 后重新运行检查。
- 版本低于 3.10：升级解释器；暂时无法升级时按下方降级矩阵执行。
- 权限或环境异常：确认工作区可写、脚本路径未被安全策略拦截，修复后重检。

## 降级矩阵（摘要；唯一事实源为 `skill-dependencies.json`，冲突时以清单为准）

| 功能 | 触发条件 | 降级方式 | 停止条件 |
|---|---|---|---|
| 任务索引与进度解析 | 解释器不可用 | 用目录枚举与文件读取能力手工枚举与解析（降级可用，标注已降级） | 数据根不可读且任务需要精确枚举时停止并说明 |
| 进度校验与证据验证 | 解释器不可用 | 按字段与证据清单人工核对并标注「未完成运行验证」 | 用户要求正式通过结论或涉及闸口放行时停止 |
| 间隔调度与校准计算 | 解释器不可用 | 由模型按同一公式手工计算并标注「推断」 | 用户要求可复核的脚本级结论时停止 |
| KP 拓扑排序与检环 | 解释器不可用或脚本不可执行 | 人工依赖排序并展示理由，标注「未检环」 | 依赖关系复杂且存在环风险时停止并建议恢复解释器 |
| 环境就绪检查 | 解释器不可用 | 按本指南逐项人工核对 | 无法判断必需依赖状态时停止并说明 |
| 讲义结构校验 | 解释器不可用或脚本不可执行 | 按 `lecture-styles.md`「讲解出厂自检」定稿维度全量人工核对并标注「部分验证」 | 讲义定稿或交付且结构核对无法完成时停止并说明 |
| 学习数据落盘 | 工作区只读、写入被拒或数据根不可写 | 改对话内推进：给出 `progress.md` 进度块与判分记录文本，由用户在自选可写位置留档；明确说明本轮未落盘（`evidence_label=未验证`） | 需正式闸口放行、结课结论或可复核证据时停止并说明 |
| 备料来源检索 | 无网络、检索工具不可用或未返回可用来源 | 不建 `materials/00-备课来源.md` 台账；路线按通用脉络自拟，S2 对照结论显式标「无外部基准」（`evidence_label=未验证`） | 用户要求以官方大纲/真题为准且无任何材料时停止并说明 |

## 安全与权限

- 本技能不收集、不存储、不传输任何凭据；检查器只输出「已配置/未配置」与版本号，不回显环境变量值。
- 检查器全程只读：不写盘、不安装、不登录、不授权、不修改配置。**因此它不探测写权限**——`学习数据落盘` 是否可用，以首次真实写入的结果为准，由模型如实说明，不靠检查器断言。
- 检查器不含任何网络探测能力：全程零网络请求、零子进程。
- 无凭据轮换与撤销事项（无凭据、无登录）。
