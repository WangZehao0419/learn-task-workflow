常驻硬规则 11（SKILL.md）是本册的地板，本册给正本形态与反例。讲授/反馈/提示/路线/状态五类轮各有 owner，不适用本册。

## 交付轮版式

<!-- intent:I-ROUND-LAYOUT@global -->

交付轮 = 交给学员做或看的轮：题组、节末小结、重发。三个槽位固定：**轮首句（可选）→ 主体 → 收尾行**。首行是学员要做或要看的内容，不是轮型标签；不写台账动词（清债、顺延、读数）。

「交付轮」指轮的类型，与答案标识「交付起笔」不是一回事。

### 轮首句（可选）

- 一段、不加粗、不分条、至多两句；只交代「现在做什么、为什么现在做」。
- 有到期批次时只装两类信息：清几条；其中有没有「很有把握却答错」的。读数取 `scripts/scheduler.py calibration` 输出，现取现念，禁止心算；边界见 `assessment/scheduling.md`「校准画像」。
  - 有：`今天清 3 条；其中 1 条上次很有把握却答错了，先练它。`
  - 无：`今天清 3 条；其中没有「很有把握却答错」的。`
  - 记录不足 5 条：句末加 `（记录才 3 条，先当参考）`。
  - 读数无效（`rate_valid=false`）：**不写读数半句**，只报「今天清 N 条」。
- 无批次（普通练习）只写一句练什么，或不写；没有前置条数就不得说「其中」。
- **只说有几条，不说哪一条**：点名会把「这条上次错了」带进本次作答，影响信心分（口径见 `assessment/scoring.md`「信心时序」）。
- **禁词**：cw、台账、清债、顺延、问题记录、信心读数、高信心。只列无歧义的台账词；「分母」「占比」「校准」「快照」「元认知」可能是学科内容，不在此列。
- 没有状态要交代就不写，直接进主体；不得用轮首句预告下一目或复述教材结构。

### 题组交付

- **首行**：`**题 N**` 起块；题前至多一句范围说明（不加粗），说清练哪个目或清哪几条。
- **题卡**：一题一块——题干接排；附问与给分点随本题，不入他块；组内按序。
- **收尾固定一行**：每题作答带信心分 1–5，凭第一感觉，报低不扣分，与作答一并发。
- 短题与正式确认不走题卡（口径见 `assessment/scoring.md`「统计口径」）。

### 小结交付（节末）

- **首行**：`**本节小结**` + 节名。
- 五件套结果逐条一行（判分/薄弱点/保持复习/下一步/交接），不整段叙述；进度对账数字照报。
- S5 结课收束不走本节小结形态，按结课分册执行。

### 重发交付（未作答题组）

- **触发**：`exercises/` 已有本节未作答题组（未作答题组优先）。
- **形态**：原题卡原文照搬 + 同一行提交格式；不写轮首句、不重报条数、不换题、不加题。

### 发出前自检（4 项）

1. 首行有轮型名、状态锚点或台账词吗？
2. 轮首句超过两句、或出现禁词吗？
3. 题卡外还有题面吗？提交格式单独一行了吗？
4. 这一轮交了两种东西（题组 + 小结）吗？

### 反例（命中即改）

裸段落出题、无题卡；`题 1　` 全角空格对齐；题干整句加粗；`**续学**｜…` 用竖线接状态；两行读数（占比 + 分母）。完整负样例见 `evals/fixtures/round-layout/`。

### 边界

- 轮型决策与讲授轮版式见 `layout/chat-presentation.md`「对话呈现系统」；本册只管形态，不管题量与题目内容。
- 压缩出口命中时可减结构，题卡与提交格式不省。
