# 可选加练（巩固与举一反三，R55）

<!-- owns: 可选加练定位、两类题组（举一反三/跨节串联）、判分落盘与频控（R55）；must-not-define: 判分口径（scoring）、调度算法、教学动作、数据字段 -->

> 何时读：学员接受节末加练征询。

<!-- intent:I-REINFORCE@global -->

- **定位**：节闸口达标后的**自愿**扩展练习——学生可选做，拒绝零评判（不追问、不记录负面、不施压）；不占节核心题量、不进节闸口分母、不计入伺服样本。两个入口：①**节末征询**（`references/workflow/s3-close.md`「节末收尾五件套」后一句话提议）；②**快捷指令「来点挑战 / 加练」**（`references/routing/shortcuts.md`）。
- **两类题组（学员选其一或都做，合计 ≤ 契约 `budget.reinforce_max`）**：
  - **举一反三题组**：两道**表面不同、结构相同**的题并排（换情境 / 换问向；干扰项与预判误区同源）→ 学员各解 → 请学员**一句话总结两题共用的结构或方法**（说得出才算过——迁移的判据是结构可见，不是做对就算）→ 再给 1 道**远迁移题**（陌生情境或逆问题）。与 R43 的关系：并排对比是**并列对照**，不受「一次一维」约束（对比的目的就是让差异同时可见）；对比组内每道题的生成仍守 R43 与「变式真变」。与 R35 的关系：按**准入②**执行（已讲授 + 至少一次成功作答——节末达标后天然满足）；R46 术语对账照跑。
  - **跨节串联综合题**：把本节内容与 ≥1 个之前节的内容连起来用 1 道综合题（连接证据取向对齐 `references/workflow/s3-block.md`「跨目串联（多目节）」）；选节按课程体系前置依赖图取与本节相邻或被依赖的已讲节；R35 / R46 照跑。
- **判分与落盘**：判分照四态与调度档，attempt 行写 KP 映射；落 `exercises/j-加练-<日期>.md`，文件头加一行「可选加练，不计闸口」（文件结构同 `references/assessment/exercise-files.md`，`j-` 前缀见 `references/data/layout.md`「目录布局」）。做对的内容条目按既有条目命令更新 S/D/due；**加练判错仍入薄弱点 / 错题本**（数据诚实；「判错↔入账」护栏对 `j-` 文件照常校验），反馈话术按「挑战题答错正常」零施压口径；熔断条照适用，熔断即止不转必修（见 `references/ops/composition.md`）。
- **频控与关闭**：节末征询默认每节末一句话；学员说「别再问 / 不用来这套」→ 写 `references/data/profile.md`「学习者画像」①层偏好（学员亲口说的，免确认落盘），此后只留快捷指令入口；快捷指令不受征询关闭影响。
