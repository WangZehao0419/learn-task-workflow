## 判分口径

**判分三维 + 调度档位**（闸口正确性与调度 grade **分离**，避免「慢=半分」把独立性/流畅度混进正确性）：

- **正确性（四态）**：`对 / 部分 / 错 / 未判`。`对` 计入闸口分子与分母；`部分` 计入分母、不计入分子（未达完整正确，按缺失点归因并进薄弱点；如需保留原题再进错题本并标 `结果=部分`，调度档用 Again）；`错` 计入分母；`未判` 不计入分母、不写 S/D、不进错题本——它表示答案键/输入/来源不足以判，不是「错」。**作废**行只保留审计，不计入闸口/S/D，不删除原判分行。
- **独立性**：独立完成 / 经提示②–④（非答案级）后完成 / 经梯⑤获答案后才理解（**给答案不算答对**，计 0）。
- **流畅度**：快速（无停顿、无试错）/ 常规 / 明显卡顿·试错；**时间/过程不可观测时记「未测」**，不猜、不折半。
- **调度档位（仅用于 scheduler 算 S'/D'，不折算闸口正确性）**：Easy=独立且快速答对；Good=独立答对（常规节奏）；Hard=经提示②–④后答对 / 明显卡顿试错后答对；Again=未答对 / 梯⑤给答案后才理解。
- **有效作答全为未判/作废** → `E-NO-GRADED-ATTEMPT`，不得标已掌握。

### 难度伺服

| 参数 | 取值 |
|---|---|
| 滚动窗口 | 最近 **~7 题**正确率（按**正确性**计：独立正确与提示后正确均计 1，Again/给答案计 0） |
| 计分 | 正确性驱动：正确=1，未答对=0；**Hard 不记半分** |
| \>90% | 加难（去提示 / 迁移题 / 双概念综合） |
| 70–90% | 保持 |
| <70% | 降难（缩 chunk / 给示例 / 降为选择题） |
| 落盘 | 伺服判定结论（档位 + 依据 + **样本数**）随判分记录落盘；报「正确 x/样本 n 题」，**n < 5 时标注「样本过小，档位仅供参考」** |

难度伺服 85% 目标为**启发式参数**（Wilson et al. 2019 仿真研究、Rosenshine 课堂 ~82% 呼应；边界见 `ops/evidence.md`）。

**统计口径**：正式推进确认题随 `## 作答与判分` 的 attempt 进入正确性分母；轻量确认不计入分母；难度伺服以题组 attempt 为主，正式确认只作即时教学信号，不单独改变档位。

### 信心时序

信心**可选**，学员可在**反馈前随作答一并提交**「当时几分把握（1–5）」——这是可用于 cw / 校准的**原信心**；若在批改反馈**之后**才补报，一律标注**回顾性**（postdiction），**不得据此推断其原先信心、不计入 cw、不计入信心校准**。（cw = 反馈前信心 ≥4 且判错。）

## 闸口比例与小节目标线

- **默认比例**取契约 `gates.min_ratio`；**非默认值**写入 `progress.md` 元信息 `小节目标线：a/b`（可选，缺省即契约默认）。非法值 → `E-GATE-RATIO-INVALID` 拦停，不得静默回退。
- **闸口两层**：比例线可按 `小节目标线` 收紧/放宽；**关键能力独立通过与复述通过是底线，不随量表放宽**、伺服不可替代。
- 独立正确 + 提示②–④后正确合计进入比例计算；提示后正确不计入「关键能力独立通过」。
- 所有阈值数字只在本册写契约键；不重复打印数值。

## 复述证据

- **通过标准**：学员复述**覆盖 ≥ `restatement.keypoints` 个本节关键点**且**无事实性错误**。判分时逐项勾选检查清单（关键点 1 / 关键点 2 / 有无硬错），把勾选结果写进题组文件。
- **模板与字段**见 `data/layout.md`「复述检查清单」；勾选语法与解析规则以脚本为准。
- **一份证据可复用**：teach-back 的复述已覆盖关键点且无事实性错误 → 即视为复述通过，**不再索要同义重复总结**。
- **深讲概念的深度验收**：节末除复述外，至少问一类「为什么/边界/对比」题（深讲概念建议三选二）；答不出 → 补对应层，不判学员。
- **取消「装不懂」**：追问只在**真有疑点或需检验迁移**时进行，不为拖延而假追问；追问后仍以「覆盖关键点且无硬错」判定。
- 复述未通过时**逐项告知缺哪个关键点、错在哪**，再换角度重讲后请复述，不判通过、也不让学员猜。


## 视觉任务证据

- 视觉任务（识别/关系/图表/比较）只在确有原始图/表/截图/数据的 KP 上声明；图类任务须基于原始图（原始像素或矢量图），表类任务须基于原始数据表；数学、物理、化学、生物等有原始图表的学科优先，其他学科有原始图/表时同样适用；纯文本概念不硬加。
- 证据必须基于原始来源：在题面或题组文件记录页码/图号/数据位置；**不得用生成图、重绘图或讲义示意图替代原图**；图中编号、关系与数据按原图，不重排、不补造；原图缺失、模糊或读不到时：新任务不要声明该视觉任务；已声明的不得删除或改写字段或证据标签来绕过闸口，按 `未判` 处理或补齐来源后再判，不凭记忆补。
- 讲义 SVG 只用于讲解，不能充当视觉任务的原始来源。attempt 仍按 `KP=<id>｜视觉=<任务>` 且 `独立性=独立` 记录；提示后作答不算独立。旧任务未声明视觉任务 = 合法；已声明但无来源锚点的旧证据不追溯作废，下一次使用时补齐；无法补齐时按 `未判` 处理，不当作独立正确证据。
- 字段格式见 `data/lists.md`「知识清单文件」「作答与判分」。

## 批改与申诉

- **输入判读不预设预期**：判读学员输入（手写照片、OCR、复述转录）时**不按题干预期去读**；仅当指数、下标、正负号、分数线等关键字符**存在不确定性且可能影响判分**时，才将读到的题干与关键行向学员复述确认，确认无误再判分；已清晰且不影响结论的输入**不重复确认**（避免审问式负担）。学员更正输入时，**回滚**受影响的已写判分记录并留痕（记录更正日期与更正依据后按新判分重写）。
- **手写照片预处理协议**：照片判读**先预处理再判读**——转向正立、放大、按答题块分段裁剪后逐行识别；判读结果按「清楚/不确定」分级，仅对确实模糊且影响判分的关键字符（不等号方向、界值、指数、正负号、分数线）请学员确认，其余直接判分；**禁止以「不读照片」规避判读责任**，也禁止「先判分、后附注请更正」。预处理后仍无法确证的关键行，才向学员索要文字版。
- **作废与申诉**：学员指出判分有误（答案键错、来源歧义、输入读错）时，先核对题目 ID、保存的作答、参考答案与来源；确认原判不成立 → 在原行标 `作废（原因，日期）`，**保留原行不删除**；需要改判时新增一行（可复用原 `attempt_id`，已作废行不参与冲突判定），并只按新行更新 S/D。若只是补判，原 `未判` 行改为新结果或另起一行，二者择一但不得同时作为有效证据。作废与未判都不算负面证据；申诉本身也不算掌握。全程在学习日志留一句纠错留痕。
- **主观题批改纪律**（问答/论述/作文类题面）：**接受语义等价表达**——学员用自己的话说对了意思即给分，不因措辞与参考答案不同重复扣分；**每个得分点关联学员作答中的对应证据**（引其原句或指出缺失位置）；无官方评分细则时**明示「本次按训练量表判分，非官方标准」**；未知官方扣分规则不得编造。批改对象是作答不是人——只判对错与差距，不作能力评价。
- **答案与解析格式**：批改中凡给出解析的时机，解题/计算/操作/论述/翻译类一律以**答案框格式**呈现（从交付起笔到结论/产物的完整可复现答案，不排斥等价解法；交付标识按学科族取 `解：`/`解答：`/`证明：`/`答：`/`参考答案：`/`答案：`/`参考概括：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`代码：`/`输出：`/`方案：`/`设计说明：`/`Answer:`/`Solution:`/`Proof:`/`Model answer:`/`Sample answer:`/`Translation:`/`Output:`/`Code:`/`Script:`/`Steps:`/`Key:` 等，**框内不写题面段**）；学员原作答与答案逐点对照。答案之后**框外单独一行**附**给分点量表**（备考/阅卷型任务适用，格式见 `handout/pipeline.md`「给分点量表」，各点分值之和须等于合计）；非备考任务给关键步骤、验证方式或成功标志，不编造官方分值。无官方细则时明示「训练量表，非官方细则」，未知官方分值不得编造。**框体体例**（交付起笔、段首分点、代码块、句中编号与批注、标记行留空）**的唯一事实源见 `handout/templates.md`「讲义概念单元 schema · 答案框体例」及五要素之③**；本条只约束解析呈现格式。
