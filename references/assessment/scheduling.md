## 间隔调度

`scripts/scheduler.py` 采用**自研简化双参数算法**（稳定度 / 难度双参数，按判分档位递增间隔），以零第三方依赖、简单稳健为先；**非 FSRS 算法，亦非 SM-2 标准实现**，不做参数个性化拟合。公式结构见 `scheduler.py` docstring，常数唯一来源 = 契约 `scheduler` 块；本册只写策略与调用时机。

### 调用速查

> **有效域与边界（脚本强制、非有限数一律 exit 2 结构化拒绝）**：S ∈ (0,365]、D ∈ [1,5] 且 0.5 粒度、**elapsed 有限且 ≥0**；日期加法越界同样拒绝，不裸崩、不输出非有限数。

- **新条目首次调度**（S3 新产生的薄弱点 / 错题 / 保持复习）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <判分档> --new-card --last <今天> --today <今天> [--init-shift {-1|0|1}]`
  —— grade 取该条判分档（判错=again）；保持复习初始条目固定用 `--grade good`；`--init-shift` 影响初始 D：顺向检索 -1（默认 0），反向问 / 迁移 +1；返回 stability_new / difficulty_new / due。
- **既有条目复习判分**（S4）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <grade> --stability <S> --difficulty <D> --last <last> --today <今天> [--current-due <原due>]`。
  **同会话重复答对**（`--last` 与 `--today` 同日）：必须同时传 `--current-due <原due>`；脚本返回 `same_session=true` 并原样返回该 due，S/D 不变——只刷新召回，不把一天内反复刷题记成长期保持。非同日复习不传 `--current-due`。保持复习按同一命令更新；`partial` 用 `again`，`未判/作废` 不写 S/D。前提：`due` 由脚本生成、不要手改；手改 due 的条目先按当前 S 与手工 due 对齐后再复习。

### due-queue 与复习预算

- `due-queue` 同时读取「薄弱点」「错题本」「保持复习」三区，输出 `kind` 与 `reason`，schema 以契约为准；刚入库/当日的条目不重复入队。
- **未讲授过滤（R35 前置）**：入队条目所属知识点尚未讲授时，不作测验、不催答，转安排对应讲授（先教后练）；口径唯一事实源见 `assessment/generation.md`「出题范围与未讲授过滤」。
- 进入新小节前按本次可用时间设预算（复习不超过约 1/3 课时，其余留给新内容）；队列非空 → 优先清「关键先修 + 高影响错误（cw / 顽固）+ 到期的保持复习」，其余显式顺延（保留原到期日并在进度对账中可见）；队列长（>5 条）→ 明示队列长度与顺延方案，默认按预算顺延并继续新内容、不空等批准。
- 排序契约：cw → 最逾期 → due 早 → 稳定序；`顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- 缺日期/坏条目的口径见 `data/layout.md`：缺日期不入队、`W-UNPARSED-ITEM`；不得以当日或猜值补造。

### 校准画像

校准画像是脚本对既有「信心 / cw」元数据的**实时只读统计**：**不新增任何 progress.md 字段，不落任何新文件**。进入 S4 时由模型运行：

`python "<技能根>/scripts/scheduler.py" calibration --root "<数据根>" [--slug "<slug>"]`

- **指标名称**：**当前问题记录中的高信心错误占比**（cw 条目数 ÷ 分母；脚本键 `overconfidence_rate`）——它只描述「当前未清除问题记录」中高信心错误的投影比例，**不得用来评价学员整体人格或整体校准水平**（分母只含问题记录、不含正确作答，天然不代表整体校准）。若需整体校准判断，**必须另有**包含正确与错误作答、采样时机明确的有效窗口——当前快照口径不提供该窗口。
- **畸形数据判读**：脚本先按 `evt` 归组、合并互补字段，再形成「合法观察」（可推算日期 + 无冲突），最后才统计。**分子 `cw` 只数「反馈前信心 ≥4 且判错」的合法观察**——`cw` 必须是同口径高信心错误观察的**子集**；任何**孤立 cw**（有 cw 无显式信心）、**低信心 cw**（信心 <4）或**同 evt 投影冲突**都会单独告警并令脚本**输出 `overconfidence_rate: null` + `rate_valid:false` + `invalid_reason`**（不展示不可靠读数）；先核对补齐数据，不得采信该画像做元认知教学。
- **窗口口径：快照口径，不做时间窗**。统计对象是「当前未清除的条目」，教学呈现措辞必须用「当前快照」，禁称「全程累计」。
- **投影去重与口径披露**：条目**带 `evt=` 作答事件 ID** 时按事件归组，同一作答的投影（错题/薄弱点）**只计一次**，互补字段合并；**无 ID 的旧条目**沿用「两条投影各计一次」的**声明式双计**。全部带 ID → `dedup_mode:"by_evt"`；全部无 ID → `"legacy_double_count"`；**新旧混排 → `"mixed"`**，并在呈现时显式披露 `evt_tagged_count` / `legacy_count`（不得统一标 `by_evt` 掩盖旧条目计数）。
- **兼容口径**：旧任务读数不静默变样，仅新写数据启用按事件去重；旧条目保持 `legacy_double_count` / `mixed` 披露，不统一改标 `by_evt`。
- **两层语义（防模型混用）**：`cw` 是**逐条重测信号**——单条「自信但错」的调度标记，回答「这条该不该先练」（作用在 due-queue 排序优先）；校准画像是**聚合教学素材**——把当前问题记录里的信心标记汇总成**问题投影比例**，**只回答「当前错题快照里的高信心占比」**，**不得**回答「这位学员整体是否系统性高估自己」。一句话：**cw 是画像的输入行，画像是 cw 的列总和**。脚本只算不判；「本快照读数如何解读与呈现」归模型，但**不得越界作整体人格判断**。

## 数据兼容语义

字段格式、默认值与解析器口径以 `data/layout.md` 为准；本册只保留评估侧语义：

- **旧条目缺字段**：不做批量迁移、不新建文件；首次在 S4/S3 热身/due-queue 遇到时按默认值计算 due，并在下一次正常写入时顺带补写；缺日期不入队、输出 `W-UNPARSED-ITEM`，不得以当日或猜值补造。
- **错因是语义属性**：缺省值只是脚本输出侧的占位回显（`meta_default:true`），模型侧必须按当下归因判断写入真实值；不得盲目补「知识性」把技巧性失误误导到重学。
- **三种数据形态**：完整 / 缺错因级 / 旧格式的行为按 `data/layout.md` 的表执行；旧格式不计入 calibration 分母，脚本标注 `migrated`/`meta_default`，不静默改样。
