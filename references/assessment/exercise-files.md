## 题组与判分文件（exercises/）

<!-- intent:I-EXERCISE-SCHEMA@global -->

文件名 `NN-<节名>-<日期>.md`（编号两位补零；判分记录与「已掌握」勾选的比对口径见 `data/layout.md`「目录布局」编号契约条）。特殊前缀：`z-` 变式自创（见 `workflow/s4-review.md`「S4 复习巩固」）；`j-` 可选加练（`j-加练-<日期>.md`，R55——文件头加一行「可选加练，不计闸口」，attempt 字段与区块结构照常，见 `assessment/generation.md`「可选加练（巩固与举一反三，R55）」）。文件内按以下结构落盘（**v2 卡片版式**；字级见 `layout/char-typography.md`「字体语义」，落盘按 Markdown 基本格式自检）：

```markdown
# 第 2 节 循环与迭代 · 题组与判分（2026-10-15）

## 题组
1. <题面>
2. <题面>
3. <题面（判定题：考「何时用」）>

## 关键能力
- C1：<本节核心方法 / 唯一核心应用题 / 主要易错点>（1–3 项；每项须能独立判分）

## 作答与判分

### 题 1 · <考点名>（C1）

- 题 1：作答「<学员答案，过长截断加 …>」｜信心=4｜正确性=对（<得分点 6/6 过线>）｜独立性=独立｜调度档=Good｜能力=C1
  - 讲评：<一句话依据；作答原文过长时全文放这里>

### 题 2 · <考点名>（C1）

- 题 2：作答「<学员答案>」｜正确性=错（错因=理解性，级=B）｜独立性=独立｜调度档=Again
  - 讲评：<错在哪、下一步> → 入错题本

### 目 8「<KP 名>」· 推进确认

- 目 8「KP 名」（推进）：作答「<学员答案>」｜正确性=对｜独立性=独立｜流畅度=常规｜用途=推进｜KP=KP-03-08

- 伺服：档位=保持 ｜ 依据：近 7 题正确率 79% ｜ 样本 n=7
- 闸口：正确性达契约比例（见 `assessment/scoring.md`）＋**每项关键能力独立通过**＋复述通过 → 达标；独立性：1 独立对 ／ 1 提示后对

## 复述检查清单
- [x] 关键点 1：<名称>｜[x] 关键点 2：<名称>｜[x] 无事实性错误

## 参考答案（判分完成后回填；可选）
- 题 1：<答案或要点>｜依据：<解:… 或 见 materials/NN-<节名>.md 概念 N 的 ③ 框>
- 题 2：<要点行；主观/论述题可只写「见讲义概念 N 的 ③ 框」>
```

- **机器行与讲评行分离（v2 核心纪律）**：每题卡片 = `### 题 N · <考点>（能力）` 标题 + 一条**机器行**（`- 题 N：作答「…」｜字段…`，唯一携带 `正确性=`/`独立性=`/`调度档=`/`KP=`/attempt token 的行，≤120 字，括号注只缀在枚举值后）+ 按需的缩进 `- 讲评：` 行（放依据、错因、作答原文全文；**讲评行不得再写机器 token**，避免被解析成第二条作答）。判分解析按行配对三要素，机器行拆散到多行 = 判分丢失。

### 正式/轻量确认（推进确认）

- **正式确认（可选）**：关键目正式确认写入 `## 作答与判分`（卡片体例见上方「推进确认」示例），标 `用途=推进`；有对应 KP 时写 `KP=<id>`（格式 `KP=KP-<节>-<KP序>`，如 `KP-03-08`；`KP-03-08a` 这类编号不合法，脚本不识别），无对应目行时写 `目=<目名>`——`目=` 是人读字段，不进闸口计算；计入正确性分母与本节新题总量（题量口径见 `assessment/generation.md`「题量预算」）；正式确认可作记忆/程序 KP 的分型证据（带 `KP=<id>` 独立正确），概念/设计仍需复述勾选行含该 KP 编号；早期错误与变式均保留，不删不改。简单目轻量确认不写 `正确性=` 判分行；需要留痕时在记忆.md 学习日志写一句「目名 + 确认方式 + 结果」。
- **分型字段**：若 `课程体系.md` 的目行声明了类型/视觉任务（可选分型字段见 `data/curriculum.md`「课程体系文件」），attempt 行补 `KP=KP-<节>-<KP序>`；视觉任务再加 `｜视觉=<任务>`；概念/设计在复述勾选行写该 KP 编号。分型闸口见 `workflow/s3-block.md`「S3 闸口（可检验）」。
- **反例（应避免的版面形态）**：`1.（节末第 1 题·词性判定）判定…` 无空格列表、单行 430 字「作答＋判分＋备注」流水账——按 Markdown 基本格式（列表空格、行内 `$` 成对、标题不跳级、表头齐全）自检改写，不设机器闸口。
- **向后兼容**：v1 单行台账格式仍可被脚本解析；新写与改写一律按 v2 卡片，不改判分语义（四态、调度档、attempt 语义 owner 仍在 `assessment/scoring.md`）。
- **参考答案区块（可选，判分后回填）**：位置固定在文件**末尾**（「作答与判分」之后）——`progress_check.py` 的 `evidence_section` 截到下一个二级标题为止，区块放在判分段之前会把判分记录截断。**出题时不预写**（防泄题），判分完成后回填；客观题写「答案 + 一句依据」，主观/论述题写要点行或 `见 materials/NN-…md 概念 N 的 ③ 框`，不复制讲义全文。**正文唯一事实源仍是讲义 ③**：本区块只做复习索引，二者不一致时以 ③ 为准并同步更正。**不另建 `-答案.md` 分册**——`exercises/` 内文件按编号前缀被当作判分证据消费，同前缀的答案文件会被误当证据（`E-EMPTY-EVIDENCE` / 证据错配）。
- **组卷（独立触发「组一套卷」）**：卷末同设 `## 参考答案` 区块，题面区顶部写一行「作答后再看文末答案」；不拆答案册，命名与普通题组一致。
- **落盘自检**：写盘前按 Markdown 基本格式（列表空格、行内 `$` 成对、标题不跳级、表头齐全）核对即可，不设机器闸口。
