# 出题范围与未讲授过滤（R35）

> 何时读：讲授检验/确认题需要出题域。

- **唯一允许的出题域 = 已讲授内容**：**从未讲授的知识点永不出题**——覆盖热身、练习、复习、综合测验与快捷指令出题的全部场景。**分层准入门槛**：①**首练 / 讲义自测**：知识点已讲授即可出（首练是「先教后练」的补步/独立练习，不要求此前有作答）；②**变式 / 正式题组 / 迁移 / 复习抽题**：知识点已讲授，且学员已有至少一次**成功作答**（独立或经提示后正确，口径统一）；只有未判/作废作答不算成功记录。
- **未讲授条目处理**：due-queue 输出中，所属知识点尚未讲授的薄弱点/错题条目**不入测验队列、不催答**；到期转为安排对应讲授（先教后练，六拍见 `references/teaching/lesson-flow.md`），讲授完成后再按新条目入调度。
- **摸底薄弱点 ≠ 已授内容**：S1 摸底产生的薄弱点，在其对应内容讲授完成前一律按未讲授处理。
- **「已讲授」判据**：课程体系目行状态 `已讲`、节路线勾选、或该目有讲授/检验记录——三者取其一即可；复述与闸口是否通过是另一层的事，不影响「已讲过」的认定。
- **执行落点**：S3 热身（`references/workflow/s3-cycle.md`「每轮小步（五步）」②）、S4 抽取（`references/workflow/s4-review.md`「复习债治理」）、S5 综合测验（覆盖约束的终极对照见 `references/workflow/s5-close.md`「S5 结课」出题范围约束）。
