## 题量预算与自测≠题组

<!-- intent:I-SELF-TEST-VS-GROUP@handout -->

- **每节核心新题合计 ≤ 契约 `budget.core_total_max`**：讲义自测取 `budget.self_test`；题组合计 `budget.exercise_group_min`–`budget.exercise_group_max`；单元检验 0–`budget.unit_check_max` 用剩余额度；深度验收与 S4 复习复用题组题，不额外加题。
- **关键目正式推进确认题另计**，不设每节道数上限；简单目轻量确认不计题量、不写判分行。
- **题组不与本节讲义自测同题**（L3 复习产物例外见下）；自测只作低风险自检，不作判分证据。**正式确认题必须使用未印答案的新题或变体**；已印答案的讲义自测不因复用而变成判分证据。
- **L3 复习产物例外**：检索版要点卡 3–5 题优先复用旧题/题组（至少 1 道换情境/新问法），不作新判分证据；`budget.l3_review_min/max` 以契约为准。产物形态（检索版要点卡、`③ 不适用（已会·检索版）` 标注）见 `handout/support-levels.md` §6；本条只定义题量与同题例外。
- **超预算时**先减单元检验，再并题组或移入 `exercises/` 次日再做，不靠加题补密度。

### 分块与交错切换

- **习得期**：新程序还在习得期（独立解题常失败）→ 同型分块练，先把单个程序练稳。
- **切换**：当独立解题开始成功 → 切为交错混练，混入已会程序/旧题型，迫使学员区分适用条件。
- 切换时序为推断级（证据见 `ops/evidence.md`）；不改变题量预算、判定题要求与 S3/S4 的其他规则。

## 出题流水线（四步）

出题（S3 练习、S4 复习、独立「考考我」/组卷）按四步执行；题量、题型与难度仍受 S3/S4 预算与目标约束。S5 综合测验不改变既有蓝图与目标线规则：先按「能力—任务—评分点蓝图」定覆盖、题量与分值，再用本流水线生成与自检。

1. **探索**：先读本次节目标与讲义范围；读课程体系中本次相关 KP 目行（S5 按蓝图读全部纳入目行）；S4/已有任务的独立出题先跑 `due-queue`（无任务时跳过；S3 沿用进入节前的结果，跨日续学可重跑）；再读 `exercises/` 最近题组与判分记录，标出「要考的能力 / 主要错因 / 已出过的题」，避免重复旧题（T11 明确选择「原题保持」时除外）。
2. **规划**：按本次题量预算列题（默认取契约题组范围；S5 综合测验按蓝图），逐题定 topic、题型（基础/应用/变式/判定）、难度、对应 KP 或能力；题型含判定题（要求见「零提示与条件化判定题」）；组内 topic 不重复（T11 明确选择「原题保持」时除外；同一薄弱点需多问、或 S5 蓝图要求同一 KP 多题时，用不同题型/情境/变式，不以换数字充数）；新学按基础→应用→变式递进，复习按 T11 选「原题保持 / 近迁移 / 远迁移」。
3. **生成**：逐题写题干、选项（选择题）、答案、解析、难度与 KP 映射（选项与答案纪律见「零提示与条件化判定题」）；用材料出题时记来源锚点（页码/图号/数据位置）。主观题（计算、证明、解答、写作类）随题列**给分点清单**——按解题步骤逐点列，每点可独立判 0/1；判分按清单走「部分」，不整体印象分。
4. **修复**：整套题一次性复核**第 3 步各项**，另查四项——**难度自检两线**（题组预估难度至少跨两档；预期全对或全错的死题不入题组）、与旧题是否重复（T11 明确选择「原题保持」时除外）、是否与本节自测同题（仅 S3 新学题组适用，此项无例外）、**术语对账（R46，见「出题前术语对账」）**；发现问题修一次并重检，不无限重写；答案键不确定标 `未判`，不猜。

四步是同一轮的内部流程，不额外占用学员轮次；题组仍按既有「一组题一条消息交齐」交付。**未作答题组优先**：若 `exercises/` 已有本节未作答题组，直接取用并等用户作答，不重新出题。

### 短题与正式确认

- **短题豁免**：关键目正式推进确认题等短题不走四步流水线；但答案键须先核对、无提示泄漏。
- **答案键不确定**：标 `未判`，不得以未判推进；照片/手写输入按「批改与申诉」的输入判读规则处理。
- 正式确认仍按判分四态/独立性照记，计入正确性分母；不替代题组的关键能力独立通过与节复述。

## 零提示与条件化判定题

出题时遵守「零提示」规则，防止题目本身泄漏答案或降低检索难度。以下规则在第 2 步规划与第 3 步生成时逐条核对：

- **出题形态分界**：能从已有知识逻辑推导的内容，练成解题/应用题；无法推导、纯记忆的任意性内容（单词、常数、术语表）才做填空/背诵卡。判断标准一句话：**这条能否从别的东西推出来**——可推导内容做成死记卡是浪费检索练习，任意性内容硬出证明题是折磨学员。
- **答案与选项纪律**：题目与答案分离，先出题、等作答，正确答案与解析批改前不下发。选择题选项在长度与结构上对称，正确项不得更长、更完整或带「推荐」标记；展示前打乱顺序；题干和解析都不引用「A/B/C/D」，按内容说答案。难度在题面或题组文件头注明「难度：易/中/难」，不写进调度档（调度档记录表现，不记录题目难度）；每题都能在批改反馈或判分后的参考答案区找到解析（不要求在题面预写）。
- **干扰项**：取本节常见误区的具象化，与预判误区清单一一对应（R42），不用显然错的弱干扰。
- **防猜测选项**：选择题可含「我不确定」类选项，学员选它按未答（Again）处理——防 25% 猜对虚增闸口正确率，给低信心一个诚实出口。
- **格式不泄题**：不在题干里暗示答案（如「以下**错误**的**是**」的加粗位置、选项排序规律）。
- **变式真变**：递进题（基础 → 应用 → 变式）须换情境或逆问题，而非只改数字；**一次只变一个维度（R43，结构判据与预测轮见下节）**——一次变两个维度学员无法归因；关键目变式前加预测轮。
- **条件化出题（判定题）**：每个题组至少 1 道考「**何时用**」的判定题——给出场景问该用哪个知识点 / 给出信号问该触发什么方法 / 追问权衡（「方法 A 什么时候反而不如 B」）。只考「是什么」的题组默认不合格：掌握 = 会内容 + 会判定适用条件，二者缺一不可。判定题的干扰项须是「邻近情境下才对」的方法，制造真实的判定张力（R42）。
- **复习变式优先、原题按目标保留（T11）**：S3 热身、S4 复习、综合测验重试的题目**以变式为默认**（换措辞 / 换情境 / 反向问 / 迁移情境），与「变式真变」同一取向；但**不一律禁止原题**——按目标组合「**原题保持** / **近迁移** / **远迁移**」，需检验长期保持时可原样重问（同日两次正确 ≠ 长期保持）。凡暴露过具名误区（概念探测或判错）的条目，重测设问优先对准该误区（迷思只被抑制、需反复压制）。
- **难度对齐**：题组难度对齐用户目标（考试对齐真题，兴趣对齐应用），不超纲、不降维羞辱；加难/降难按 `assessment/scoring.md`「难度伺服」执行，本册不另设目标区间。

## 智能变式一次一维（R43）

- **变式只变一个维度**：数字 / 情境 / 条件 / 问向，四选一；其余表面保持同构。一次变两个维度 = 学员无法归因「哪个变化导致了结果变化」，属违规（结构判据补强本册「变式真变」条）。
- **预测轮**：关键目的例题讲完、出变式前，先请学员预测「这题答案会怎么变、为什么」再动手——预测本身就是检索练习，预测错了印象更深；预测不落盘、不计分母。
- **变化链收口**：连续 2–3 题构成一条「一次一维」的变化链，链末请学员一句话总结「这组题里什么在变、结论跟着怎么变」；说得出的才关目。
- 与难度伺服的关系：伺服加难（`assessment/scoring.md`）改的是题的难度档位，本条改的是题与题之间的结构关系，两者叠加不互斥。

## 出题范围与未讲授过滤（R35）

<!-- intent:I-UNTAUGHT-FILTER@global -->

- **唯一允许的出题域 = 已讲授内容**：**从未讲授的知识点永不出题**——覆盖热身、练习、复习、综合测验与快捷指令出题的全部场景。**分层准入门槛**：①**首练 / 讲义自测**：知识点已讲授即可出（首练是「先教后练」的补步/独立练习，不要求此前有作答）；②**变式 / 正式题组 / 迁移 / 复习抽题**：知识点已讲授，且学员已有至少一次**成功作答**（独立或经提示后正确，口径统一）；只有未判/作废作答不算成功记录。
- **未讲授条目处理**：due-queue 输出中，所属知识点尚未讲授的薄弱点/错题条目**不入测验队列、不催答**；到期转为安排对应讲授（先教后练，六拍见 `teaching/lesson-flow.md`），讲授完成后再按新条目入调度。
- **摸底薄弱点 ≠ 已授内容**：S1 摸底产生的薄弱点，在其对应内容讲授完成前一律按未讲授处理。
- **「已讲授」判据**：课程体系目行状态 `已讲`、节路线勾选、或该目有讲授/检验记录——三者取其一即可；复述与闸口是否通过是另一层的事，不影响「已讲过」的认定。
- **执行落点**：S3 热身（`workflow/s3-cycle.md`「每轮小步（五步）」②）、S4 抽取（`workflow/s4-review.md`「复习债治理」）、S5 综合测验（**必须覆盖对照源全部纳入项**，纳入含未讲项——先补讲再测验；终极对照见 `workflow/s5-close.md`「S5 结课」出题范围约束）。

## 出题前术语对账（R46）

R35 管「出题域」（只对已讲授知识点出题），本节管「题面词汇」——R35 的盲区是：题域对了，题面与被问项里却混入了**尚未引入的术语**（如讲词性判断却让学员「标出定语」），对零基础学员即卡死。对账是**动作**不是原则：每次生成判分题后、交付前执行。

- **已引入集合** = ①课程体系.md 中状态「已讲」目行的 `引入` 列术语（字段见 `data/curriculum.md`「课程体系文件」）；②已讲目名本身；③地基目/术语地图/S1 摸底证据中已给过定义的术语（用 `prereq_check.py --extra-terms` 追加）。
- **对账动作**：逐题扫题干、被问项与选项——每个 ≥2 字的术语必须 ∈ 已引入集合；不 ∈ → 二选一：**换问法**（改用已引入词汇重述）或**先补术语**（给一页术语地图/最小定义，把术语转入已引入集合，再出题）。禁止边出题边补定义、禁止用「语感」「读着顺」当替代判据。
- **术语族一次给地图**：族性术语（句子成分、时态语态、词性体系、记号体系等）首次触碰时，先给**一页地图**（族内全部名字 + 一句话功能），地图级不作判分项；此后该族术语进已引入集合——不按「被问到哪个补哪个」逐词打补丁。
- **机器护栏**：`python -B "<技能根>/scripts/prereq_check.py" --list <课程体系.md> --scan <题组文件>`（对账集合与扫描范围见脚本 docstring；违规输出 `W-TERM-UNTAUGHT`，exit 1）。模型自查不豁免跑脚本；目行缺 `引入` 列时先补齐后再跑。
- **事故升级**：同类「未教术语进判分题」当轮撤题补救后一句简述（🟡 可安全恢复）；同课程第二次发生即教学事故，停轮按 `ops/failure.md` SR-10 处置并修订讲义。

## 可选加练（巩固与举一反三，R55）

<!-- intent:I-REINFORCE@global -->

- **定位**：节闸口达标后的**自愿**扩展练习——学生可选做，拒绝零评判（不追问、不记录负面、不施压）；不占节核心题量、不进节闸口分母、不计入伺服样本。两个入口：①**节末征询**（`workflow/s3-close.md`「节末收尾五件套」后一句话提议）；②**快捷指令「来点挑战 / 加练」**（`routing/shortcuts.md`）。
- **两类题组（学员选其一或都做，合计 ≤ 契约 `budget.reinforce_max`）**：
  - **举一反三题组**：两道**表面不同、结构相同**的题并排（换情境 / 换问向；干扰项与预判误区同源）→ 学员各解 → 请学员**一句话总结两题共用的结构或方法**（说得出才算过——迁移的判据是结构可见，不是做对就算）→ 再给 1 道**远迁移题**（陌生情境或逆问题）。与 R43 的关系：并排对比是**并列对照**，不受「一次一维」约束（对比的目的就是让差异同时可见）；对比组内每道题的生成仍守 R43 与「变式真变」。与 R35 的关系：按**准入②**执行（已讲授 + 至少一次成功作答——节末达标后天然满足）；R46 术语对账照跑。
  - **跨节串联综合题**：把本节内容与 ≥1 个之前节的内容连起来用 1 道综合题（连接证据取向对齐 `workflow/s3-block.md`「跨目串联（多目节）」）；选节按课程体系前置依赖图取与本节相邻或被依赖的已讲节；R35 / R46 照跑。
- **判分与落盘**：判分照四态与调度档，attempt 行写 KP 映射；落 `exercises/j-加练-<日期>.md`，文件头加一行「可选加练，不计闸口」（文件结构同 `assessment/exercise-files.md`，`j-` 前缀见 `data/layout.md`「目录布局」）。做对的内容条目按既有条目命令更新 S/D/due；**加练判错仍入薄弱点 / 错题本**（数据诚实；「判错↔入账」护栏对 `j-` 文件照常校验），反馈话术按「挑战题答错正常」零施压口径；熔断条照适用，熔断即止不转必修（见 `ops/composition.md`）。
- **频控与关闭**：节末征询默认每节末一句话；学员说「别再问 / 不用来这套」→ 写 `data/profile.md`「学习者画像」①层偏好（学员亲口说的，免确认落盘），此后只留快捷指令入口；快捷指令不受征询关闭影响。
