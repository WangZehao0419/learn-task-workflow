## 题量预算与自测≠题组

- **每节核心新题合计 ≤ 契约 `budget.core_total_max`**：讲义自测取 `budget.self_test`；题组合计 `budget.exercise_group_min`–`budget.exercise_group_max`（其中至少 1 道判定题）；单元检验 0–`budget.unit_check_max` 用剩余额度；深度验收与 S4 复习复用题组题，不额外加题。
- **关键块正式推进确认题另计**，不设每节道数上限；简单块轻量确认不计题量、不写判分行。
- **题组不与本节讲义自测同题**（L3 复习产物例外见 `handout/pipeline.md` §2.4）；自测只作低风险自检，不作判分证据。
- **L3 复习产物例外**：检索版要点卡 3–5 题优先复用旧题/题组（至少 1 道换情境/新问法），不作新判分证据；`budget.l3_review_min/max` 以契约为准。
- **超预算时**先减单元检验，再并题组或移入 `exercises/` 次日再做，不靠加题补密度。

### 分块与交错切换

- **习得期**：新程序还在习得期（独立解题常失败）→ 同型分块练，先把单个程序练稳。
- **切换**：当独立解题开始成功 → 切为交错混练，混入已会程序/旧题型，迫使学员区分适用条件。
- 切换时序为推断级（证据见 `ops/evidence.md`）；不改变题量预算、判定题要求与 S3/S4 的其他规则。

## 出题流水线（四步）

出题（S3 练习、S4 复习、独立「考考我」/组卷）按四步执行；题量、题型与难度仍受 S3/S4 预算与目标约束。S5 综合测验不改变既有蓝图与目标线规则：先按「能力—任务—评分点蓝图」定覆盖、题量与分值，再用本流水线生成与自检。

1. **探索**：先读本次小节目标与讲义范围；有清单时读本次相关 KP（S5 按蓝图读全部纳入 KP）；S4/已有任务的独立出题先跑 `due-queue`（无任务时跳过；S3 沿用进入小节前的结果，跨日续学可重跑）；再读 `exercises/` 最近题组与判分记录，标出「要考的能力 / 主要错因 / 已出过的题」，避免重复旧题（T11 明确选择「原题保持」时除外）。
2. **规划**：按本次题量预算列题（默认取契约题组范围；S5 综合测验按蓝图），逐题定 topic、题型（基础/应用/变式/判定）、难度、对应 KP 或能力；至少 1 道判定题；组内 topic 不重复（T11 明确选择「原题保持」时除外；同一薄弱点需多问、或 S5 蓝图要求同一 KP 多题时，用不同题型/情境/变式，不以换数字充数）；新学按基础→应用→变式递进，复习按 T11 选「原题保持 / 近迁移 / 远迁移」。
3. **生成**：逐题写题干、选项（选择题）、答案、解析、难度与 KP 映射；干扰项取本节常见误区；选项等长并打乱，题面与解析不引用字母；答案键批改前私有；用材料出题时记来源锚点（页码/图号/数据位置）。
4. **修复**：整套题一次性自检——答案键、选项字母中立、解析完整、难度标注、KP 映射、与旧题是否重复（T11 明确选择「原题保持」时除外）、是否与本节自测同题（仅 S3 新学题组适用，此项无例外）、**术语对账（R46，见「出题前术语对账」）**；发现问题修一次并重检，不无限重写；答案键不确定标 `未判`，不猜。

四步是同一轮的内部流程，不额外占用学员轮次；题组仍按既有「一组题一条消息交齐」交付。**未作答题组优先**：若 `exercises/` 已有本节未作答题组，直接取用并等用户作答，不重新出题。

### 短题与正式确认

- **短题豁免**：关键块正式推进确认题等短题不走四步流水线；但答案键须先核对、无提示泄漏。
- **答案键不确定**：标 `未判`，不得以未判推进；照片/手写输入按「批改与申诉」的输入判读规则处理。
- 正式确认仍按判分四态/独立性照记，计入正确性分母；不替代题组的关键能力独立通过与小节复述。

## 零提示与条件化判定题

出题时遵守「零提示」规则，防止题目本身泄漏答案或降低检索难度。以下规则在流水线第 3 步生成与第 4 步修复时逐条核对：

- **出题形态分界**：能从已有知识逻辑推导的内容，练成解题/应用题；无法推导、纯记忆的任意性内容（单词、常数、术语表）才做填空/背诵卡。判断标准一句话：**这条能否从别的东西推出来**——可推导内容做成死记卡是浪费检索练习，任意性内容硬出证明题是折磨学员。
- **不主动报答案**：题目与答案分离，先出题、等作答，批改阶段才给解析。
- **选项等长**：选择题选项在长度与结构上对称，避免最长的那个就是正确答案；干扰项 = 本节常见误区的具象化（与判定题「邻近情境干扰」同一取向），不用显然错的弱干扰。
- **防猜测选项**：选择题可含「我不确定」类选项，学员选它按未答（Again）处理——防 25% 猜对虚增闸口正确率，给低信心一个诚实出口。
- **选项打乱与字母中立**：展示前打乱选项顺序；题干和解析都不引用「A/B/C/D」，按内容说答案；正确标签在批改前保持私有。
- **答案键与解析纪律**：正确答案/解析批改前不下发；每题都能在批改反馈或判分后的参考答案区找到解析（不要求在题面预写）；难度在题面或题组文件头注明「难度：易/中/难」，不写进调度档（调度档记录表现，不记录题目难度）；正确项不得更长、更完整或带「推荐」标记；选项不按正确性排序。
- **格式不泄题**：不在题干里暗示答案（如「以下**错误**的**是**」的加粗位置、选项排序规律）。
- **变式真变**：递进题（基础 → 应用 → 变式）须换情境或逆问题，而非只改数字；**变式一次只变一个维度（R43，结构判据见 `teaching/explain-quality.md`「智能变式一次一维」）**——数字/情境/条件/问向四选一，一次变两个维度学员无法归因；关键块变式前加预测轮。
- **条件化出题（判定题）**：每个题组至少 1 道考「**何时用**」的判定题——给出场景问该用哪个知识点 / 给出信号问该触发什么方法 / 追问权衡（「方法 A 什么时候反而不如 B」）。只考「是什么」的题组默认不合格：掌握 = 会内容 + 会判定适用条件，二者缺一不可。判定题的干扰项须是「邻近情境下才对」的方法，制造真实的判定张力，不用显然错的弱干扰；**干扰项与预判误区一一对应（R42）**——每个干扰项对应备课预判误区清单里的一条具名误区（本学员历史错因优先），写得出「选它的人错在哪」的干扰项才合法。
- **复习变式优先、原题按目标保留（T11）**：S3 热身、S4 复习、综合测验重试的题目**以变式为默认**（换措辞 / 换情境 / 反向问 / 迁移情境），与「变式真变」同一取向；但**不一律禁止原题**——按目标组合「**原题保持** / **近迁移** / **远迁移**」，需检验长期保持时可原样重问（同日两次正确 ≠ 长期保持）。
- **难度对齐**：题组难度对齐用户目标（考试对齐真题，兴趣对齐应用），不超纲、不降维羞辱；教学舒适区按**独立完成率 70–80%** 校准（伺服口径见 `assessment/scoring.md`「难度伺服」），连续全对加难、连错降难补铺垫。

## 出题范围与未讲授过滤（R35）

- **唯一允许的出题域 = 已讲授内容**：只对「已讲过，且学员已有至少一次作答记录（独立或经提示完成）」的知识点出题与变式；**从未讲授的知识点永不出题**——覆盖热身、练习、复习、综合测验与快捷指令出题的全部场景。
- **未讲授条目处理**：due-queue 输出中，所属知识点尚未讲授的薄弱点/错题条目**不入测验队列、不催答**；到期转为安排对应讲授（先教后练，六拍见 `teaching/lesson-flow.md`），讲授完成后再按新条目入调度。
- **摸底薄弱点 ≠ 已授内容**：S1 摸底产生的薄弱点，在其对应内容讲授完成前一律按未讲授处理。
- **「已讲授」判据**：清单状态 `已讲`、学习路线勾选、或该块有讲授/检验记录——三者取其一即可；复述与闸口是否通过是另一层的事，不影响「已讲过」的认定。
- **执行落点**：S3 热身（`workflow/s3-block.md`「每轮小步」②）、S4 抽取（`workflow/s4-review.md`「复习债治理」）、S5 综合测验（只测已勾选/已讲小节；覆盖率审计保证该讲的都讲了）。

## 出题前术语对账（R46）

R35 管「出题域」（只对已讲授知识点出题），本节管「题面词汇」——R35 的盲区是：题域对了，题面与被问项里却混入了**尚未引入的术语**（如讲词性判断却让学员「标出定语」），对零基础学员即卡死。对账是**动作**不是原则：每次生成判分题后、交付前执行。

- **已引入集合** = ①知识清单中状态「已讲」KP 的 `引入` 列术语（字段见 `data/lists.md`「知识清单文件」）；②已讲 KP 名称本身；③地基块/术语地图/S1 摸底证据中已给过定义的术语（用 `prereq_check.py --extra-terms` 追加）。
- **对账动作**：逐题扫题干、被问项与选项——每个 ≥2 字的术语必须 ∈ 已引入集合；不 ∈ → 二选一：**换问法**（改用已引入词汇重述）或**先补术语**（给一页术语地图/最小定义，把术语转入已引入集合，再出题）。禁止边出题边补定义、禁止用「语感」「读着顺」当替代判据。
- **术语族一次给地图**：族性术语（句子成分、时态语态、词性体系、记号体系等）首次触碰时，先给**一页地图**（族内全部名字 + 一句话功能），地图级不作判分项；此后该族术语进已引入集合——不按「被问到哪个补哪个」逐词打补丁。
- **机器护栏**：`python -B "<技能根>/scripts/prereq_check.py" --list <知识清单.md> --scan <题组文件>`（对账集合与扫描范围见脚本 docstring；违规输出 `W-TERM-UNTAUGHT`，exit 1）。模型自查不豁免跑脚本；旧任务清单无 `引入` 列时按「顺带补写」惯例补齐后再跑。
- **事故升级**：同类「未教术语进判分题」当轮撤题补救后一句简述（🟡 可安全恢复）；同课程第二次发生即教学事故，停轮按 `ops/failure.md` SR-10 处置并修订讲义。
