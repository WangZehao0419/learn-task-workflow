# 讲义与讲授规则（风格模板 · 讲授契约 · 密度 · 自检）

写讲义前先选风格：默认「标准讲义」；用户点名风格时优先用户指定；按适用时机匹配。同一份讲义只用一种风格。六套风格共用 SKILL.md 的教学四原则与学习科学取向；对话讲授轮与讲义交付的产物分工、文本密度与出厂质量由「对话讲授契约」「讲解文本密度原则」「讲解出厂自检」统一约束。

> 写/改讲义前先读 `handout-design.md` 的一页合同、§2 一致性裁决、§3 理解核心、§4–§9 类型/流水线/支持级/学习者/决策日志/来源与范围，以及 §10–§11 可选增强；本文件管产物格式、风格与答案框，不重复裁决。

**卡壳信号 → 换哪套**（只在「换角度重讲」或讲义改版时用，不用于首次选型）：

| 学员表现           | 换到    | 为什么                       |
| -------------- | ----- | ------------------------- |
| 概念抽象、复述总卡壳     | 费曼卡   | 白话 + 类比 + 反例，逼出定义         |
| 分不清 X 和 Y      | 对比辨析卡 | 对照表把适用条件摆出来               |
| 会做但慢、考场做不完     | 考试冲刺卡 | 步骤模板 + 时间预算               |
| 看得懂、动手就废       | 操作手册式 | 分步 + 成功标志                 |
| 论证文读不懂、抓不住作者主张 | 精读笔记式 | 块定位 + 结构骨架与证据强度 + 复述      |
| 标准讲义的信息量扛不住    | 压缩出口  | 结论 + 必要依据 + 边界（见「对话讲授契约」） |

## 类比纪律（所有风格共用）

- **类比优先取自学员的类比领域**：数据根存在学习者画像（见 `data-and-recovery.md`「学习者画像」小节）且记有类比领域时，类比例子优先从该领域选（学员熟悉做饭就先拿做饭打比方，其次才是本分册的默认素材）；无画像或未记录 → 用本分册默认类比。
- **确证已会才可当锚点**：类比与「跨界三猜想」（`teaching-loop.md` 第 3 节）共用的铁律——类比锚点必须是**确证的已会知识**（摸底判分 / 学员亲口确认 / 画像稳定模式），严禁把材料作者背景或「学员没否认」当成他会；拿不准先问一句。
- **类比不是定义**：讲清类比「哪里像、哪里不像」，边界处明说「类比到此为止」；不拿类比替代严格定义（理论概念类误区模式已列）。

## 对话讲授契约（所有风格共用）

约束「对话讲授轮」的产物形态，与讲义交付共同构成完整教学产出：

- **产物分工**：对话轮 = **引导过程**（学员可交互、可追问）；讲义 = **完整档案**（草稿即时落盘，定稿 = 学员自读版）。对话轮不是讲义整段投喂，也不是把讲义草稿照读一遍。
- **默认最小逻辑骨架（五段，命名标签）**：单个概念的主动讲授轮默认给出以下五段，**使用命名标签**（定位 / 核心 / 示例或正反例 / 小结 / 检验），不带 ①–⑤ 编号——编号只用于讲义侧（见「讲义概念单元 schema」）：
  - **定位**：接学员确证已会的旧知（跨界三猜想 / 为什么现在学），说明本轮目标；
  - **核心**：定义 / 规则 / 性质，按需配图；给一句**适用边界**（什么时候不适用或会失效）——边界不清的结论不可信；
  - **示例或正反例**：按内容需要给完整示例或正反例——此处「完整示例」指讲义五要素中的题目、解析、答案、易错；③ 答案框不强行塞入对话轮；
  - **小结**：最多三句、不引入新信息；一两句已完整回收则不凑数；
  - **检验**：0–1 道（计入本节题量预算），按诊断价值决定取舍；给出后**停轮等待作答**。
- **压缩出口**（任一命中即可压缩为「**结论 + 必要依据 + 边界**」）：学员已掌握的简单事实、纯记忆概念、局部纠错 / 批改、学员明确要求「直接讲 / 速答」、出现疲劳信号。**压缩不得删除必要条件、关键推导或纠错信息**；不强行生成完整示例、小结或检验题。**压缩只改本轮讲授形态，不免除小步④的练习义务与小节验收证据**：本节仍按 `phases-and-gates.md` 出题并取得判分；「直接讲」之后按 `teaching-loop.md` 第 4 节给独立练习验证机会。
- **风格槽位映射**：费曼卡、考试冲刺卡、对比辨析卡、操作手册式等把上述五段槽位映射到各自骨架，可重排、合并、压缩，但**不得另立与本契约冲突的规则**，不得删除必需信息；**讲义侧**的 ①–⑤ 与检验落点见各风格骨架里的〔〕标注（见「讲义概念单元 schema」）。
- **答案框默认不进主动讲授轮**（只落讲义）；仅当本题型首次讲授、学员明确索要完整解答、或批改需要给出完整解析时可附**一次**，并同轮提示「答案已落讲义」。
- **记账永不进正文**：判分记账、台账状态行、伺服档位记录永不混入讲授正文；学员明确查询进度 / 档位时另走**状态回复**（口径见 `data-and-recovery.md`「快捷指令明细·问进度」），不伪装成讲解内容。

## 讲解文本密度原则（无硬字数，所有风格共用）

总原则：**高效务实（最少文字、最大信息量），专业严谨（清晰、准确、值得信赖）**。质量取舍优先级：准确性、适用条件与必要推导 ＞ 清晰可复现 ＞ 信息密度与篇幅；为定义、边界、反例、单位或验根允许重复一次，**禁止为追求短而删掉会改变结论的内容**。

**信息量判据（四问，密度的下限）**：每个概念讲完，学员应能回答——**是什么、什么时候用、怎么用、什么时候会错**。四问由「核心」（是什么、什么时候用）、「示例」（怎么用）、「易错」（什么时候会错）承载，「定位」只接旧知与本轮目标；四问之外的内容（历史沿革、扩展证明、无关对比）属可选，后置并显式标注。四问是不可少的底线，不是篇幅上限。

密度由以下**可复核**子规则承载（逐条可人工判定，非机器校验；`scripts/verify_explanation.py` 不检查密度），既有硬字数上限及等价表述一律清退，风格目标为「短而完整」，**不以字数截断**：

- **易错点单一出处**：④ 一条写完（症状 + 原因），不另设「常见误区」节重复展开；
- **小结最多三句（或三条）**，不引入新信息；一两句已完整回收则不为凑数扩写。**记忆密集族**的「本节地图」变体可列到 7 条，但只列概念名与依赖关系、不写解释（见 `subject-playbooks.md`）；
- **无空转句**：每句承载新信息，衔接性废话删除；
- **按最小充分路径组织**：先给当前目标 / 结论，再给达成它必需的步骤；可选背景、延伸与证明后置并标注，不为「完整」堆砌；
- **答案框、判分记账、台账状态行、伺服档位记录不进主动讲授轮**（边界见「对话讲授契约」）；
- **② 与 ③ 不重复**：② 解析讲方法与关键判断（为什么这么做、哪一步最容易错；通常 2–6 步，简单题一步写清即可，不抄代数细节），并以结论收尾；③ 答案给可整体誊抄的规范卷面。**结论句允许两处各出现一次**（措辞可不同），但 ② 不得整段复述 ③ 的推导。
- **必要推导必须完整，不为任何字数考虑截断**。

**超长自查**（结构性判据，不设字数）：出现以下任一情形时自查一次「有无混入答案框 / 记账 / 重复内容、可选细节是否可后置」——① 同一概念连续三段以上没有新增信息（只是换说法）；② 存在整段删除后四问仍可完整回答的段落；③ 可选背景与当前目标混排、未后置标注。**字数本身不是触发条件，也不是上限或截断依据**；必要推导即使更长也完整保留。

**密度反例（不合格长什么样）**：

- 空转句：「接下来我们来看一下这个概念，相信大家一定不陌生」——删掉后信息量不变。
- 记账混入：「（本节已讲完，状态：已通过）」——导师记账归 progress.md，不进讲授正文。
- 重复展开：示例④已说「忘判开口方向」，易错点节又完整重述一遍——易错点只在一处展开。
- 无关前置：「这个定理 1820 年由某人首次证明……」与本轮目标无关，应后置并标注。

## 读者版可读性契约（所有风格共用）

本契约管「读者拿到讲义后怎么读」，不改变五要素、答案框与密度规则。质量取舍仍是准确性、适用条件与必要推导 ＞ 清晰可复现 ＞ 信息密度与篇幅；**不得为版面好看删掉会改变结论的内容**。

**默认不变量（所有新讲义，不因 P1 豁免）**：标题即导航、一段一义、列表/表格/正文分工、图解语法、颜色+形状/线型、黑白/去色可读、alt/图注、术语一致。**P1 可选增强（长节 ≥3 个概念或预计 ≥15 分钟）**：`## 本节速览`、`## 回看索引`、单元首行「一句话结论」、章级速览/回看。短节可省略 P1 导航块；**默认不变量不因短节或 P1 未启用而豁免**；旧讲义不回溯。

**支持级与类型变体**（本表只管可读性组件的取舍；完整讲解仍按 `handout-design.md` 第 4 节类型矩阵）：

| 场景 | 必做 | 可省略 |
|---|---|---|
| L1 长节（≥3 概念或 ≥15 分钟） | 三遍路径、完整示例、主图（按 10.4，可省）、一句话结论、本节速览 | 无 |
| L1 短节 | 默认不变量、完整示例、主图（按 10.4，可省） | 三遍路径、速览、回看索引、一句话结论 |
| L2 部分会 | 默认不变量、补全示例；长节加回看索引 | 本节速览；一句话结论可只放关键单元；短节连回看索引可省 |
| L3 已会/检索版 | ⑤/④、3–5 题（至少 1 道新情境） | 三遍路径、完整示例、主图、本节速览、一句话结论；回看索引可选 |
| 记忆型 | 线索卡/表、⑤/④ | 完整示例（纯记忆可标 ③ 不适用）、主图（除非时间线/地图） |
| 概念型 | 机制段、正反例、概念图/因果图（按 10.4，可省） | 无 |
| 程序型 | 流程图/决策树（按 10.4，可省）、决策点 | 概念图、完整叙述 |
| 设计型 | 权衡矩阵/架构图（按 10.4，可省）、案例 | 概念图、完整叙述 |
| 精读型 | 结构骨架表、原文定位 | 主图（除非论证结构图） |
| 参照级 | ①题目、定义/边界 | ②③④⑤、主图、速览、一句话结论 |

### 1. 三遍路径

- **30 秒扫读**：标题 + 节首导读三行 + `## 本节速览`（长节；放在节首导读之后、第一个 `## 概念` 之前；若同时有 `## 概念地图`，先速览、后地图）。读者只看这三处，应能说出「本节解决什么问题、一句话结论、什么时候用」。
- **10 分钟精读**：按默认顺序读概念单元；每个单元只承担一个主问题；每节最多 1 个完整深讲；图放在它解释的段落之后，不先甩图再解释。
- **2 分钟回看**：读 `## 回看索引`（长节；放在自测答案区之后、`## 待解决问题` 与 `## 扩展（选读）` 之前）：`核心一句话` / `最容易错` / `下一步` 三行；指向 ⑤、④ 或某道自测，不复制整段。

`## 本节速览` 用 3 列表：`要解决的问题 | 一句话结论 | 用在哪`，1–3 行，对应 1–3 项关键能力；只压缩，不引入新知识、不写题目答案。概念地图与速览可并存：速览给「读什么」，概念地图给「概念之间怎么连」。

### 2. 一段一义，先结论后展开

- **单元首行先给结论**：长节/读者版在每个概念单元标题后第一行写 `- 一句话结论：……`（P1；不替代定义、机制与边界，只做导航）。短节、纯概念、参照级、L3 检索卡可省略；省略时不要把 ⑤ 小结改写成第二份结论。
- **一段一义**：一段只说一个观点；第一句先给结论或判断，再给依据；超过约 5 行先检查是否混入第二个观点，混入就拆段。同一推导必须连续时保留，不为拆段切断必要推导。
- **一句一判断**：一句只下一个判断；长定语拆成短句；主语与谓语靠近；少用名词堆叠；不用双重否定。必要推导可长，但不要一句里塞三个转折。
- **实义动词**：少用“进行/对于/关于/通过……来”等空壳结构；能写“算出/比较/排除”就不写“进行……”。术语首现给白话；数字带单位与口径。
- **列表 / 表格 / 正文分工**：并列 ≥3 项用列表；≥3 个属性的对比用表；有先后顺序用编号列表；因果、机制、论证用正文，不硬拆成项目符号。只有一项不列表，只有两列不造表。
- **表格**：有表头；单位写在表头；不合并单元格；数字列尽量右对齐；表题/图注说结论，不写「如下表所示」。移动端列数上限见 `handout-design.md` 第 10.8 节。
- **代码**：代码块给可复制的最小片段；行宽尽量 ≤80 字符；紧接 `输出：` 或成功标志；长输出只留关键行。

### 3. 标题、强调与留白

- **标题即导航**：`## 概念 N · <一句话主张>`，主张写「解决什么/判别什么」，不写「概念 2」「其他」「补充」；三级标题只在单元内部确实超过一屏时使用；层级 H2→H3，不跳级。
- **强调配额**：加粗只给术语首现、关键判断、易错点；连续两段不要都用加粗制造重点膨胀，术语密集段可例外；不用全大写、斜体、下划线、彩色字来强调；不用装饰性 emoji、符号或分隔线堆气氛。
- **留白是结构信号**：标题、列表、表格、代码块、图片前后留空行；不写「文字墙」；同一屏只留一个视觉焦点（本节速览、一个主图或一个答案框，不并列争抢）。
- **术语一致**：同一概念全节同名；缩写首现给全称；中文标点用全角，英文/数字用半角；公式与符号按 `formula-typesetting.md`。

### 4. 图解语法

- **先写图 brief 再画**：`图型 | 回答什么问题 | 节点/关系 | 读图顺序 | 结论`。写不出结论就不画；文字更清楚就不配图。
- **一图一问**：一张图只回答一个问题；一次呈现的节点 ≤7±2，超过先分组或拆图；完整概念图可以更多，但必须分层/分组并给读图顺序。总览图用层级/流程布局，不用随机网络；概念图要有明显的主干与分组，低显著性的散点布局会增加迷失感。
- **边与标注**：箭头表示方向；实线 = 确定/主路径，虚线 = 可选/弱关系；每条关键边有文字标签；优先在图内直接标注，图例只用于 ≥3 类。
- **颜色与对比**：默认中性色 + 1 个强调色；领域语义色（化学/地图/电路）按领域惯例，但颜色必须同时配形状、线型或文字，**不得只靠颜色编码**；文字对比 ≥4.5:1，图形/线条 ≥3:1；深色字浅色底，SVG 自带浅色底（不依赖透明背景），不用深色背景。黑白打印或去色后仍能读懂。
- **SVG 技术要求**：`viewBox` 自适应；`role="img"`、`<title>`、`<desc>`；图内文字 100% 视图不小于 14px；线宽 ≥1.5；不引用外部脚本/字体/图片；窄屏不横向滚动，标签不旋转。
- **alt 与图注**：`![图型：一句话结论](assets/...)`，不写「示意图/图片/文件名」；图注写结论与「示意/按比例」；正文讲机制、图注给结论、alt 给图型+结论，**不把同一句复制三遍**；图与文字逐面板核对，图文不一致时以领域事实为准，先修图再继续。

### 5. 可读性自检（5 问，定稿前）

1. 30 秒内只看标题、导读（如有速览也看），能说出本节解决什么、结论是什么？
2. 段落是否一段一义、句子是否一句一判断？若启用 P1，概念单元第一行是否先给结论？
3. 列表/表格/正文是否选对？表格有表头、列数符合移动端上限吗？
4. 标题是否带信息、层级连续？连续两段是否都在用加粗抢重点？
5. 黑白打印、手机窄屏、去色后是否仍可读？

**读者验证四问（人工，定稿前）**：① 只看标题/导读（如有速览也看），30 秒内能否说出本节问题、结论、用途？② 隔天只看标题 + 回看索引，2 分钟内能否重建核心、易错、下一步？③ 手机 375px 宽是否无横向滚动、无过小图字？④ 黑白打印/去色后，主线、支线、重点是否仍可区分？四问失败时改结构/图/标题，不加题量。

### 6. 无障碍语义（默认不变量）

- **链接文字**：写清目的（如「二分法步骤表」），不写「点击这里/这里/链接/点我」；裸 URL 只放参考资料区。
- **公式**：关键公式/符号配一句文字解释；不能只给 LaTeX 让屏幕阅读器读；排版按 `formula-typesetting.md`。
- **代码**：围栏标语言；命令可复制；输出块写结果或成功标志。
- **表格**：速览表由 `## 本节速览` 承担表题；其他数据表加一句表题；有表头；单位写表头；不合并单元格；不用颜色单独表示状态。
- **标题与图**：标题层级连续；图片 alt 非空；颜色+形状/线型/文字三重编码；黑白/去色可读。

**渲染建议（非强制）**：正文字号 16–18px、行距 1.5–1.8、深色字浅色底、左对齐；宽屏连续正文控制在约 25–40 个汉字/行，最长不超过 48 个汉字/行。中文行长研究存在冲突（另有技术文本偏好 76 字/行的报告），本技能取保守区间，不把 76 当默认。

## 深度契约与深度审计（所有风格共用）

**深度不是篇幅，是解释层数。** 本节的“层”与「信息量四问」互补：四问是下限；深讲概念在四问之外补 **M（机制）** 与 **C（对比）** 两层。

### 深度分层（每节先定，最多 1 个完整深讲）

| 档位 | 每节数量   | 必须覆盖              | 说明                 |
| -- | ------ | ----------------- | ------------------ |
| 深讲 | 最多 1 个 | D/P/M/H/B/C（T 可选） | 选本节最关键、最易误解、最影响迁移者 |
| 工作 | 最多 2 个 | D/P/H/B           | M、C 可各一句带过         |
| 参照 | 其余     | D/B               | 知道是什么、何时不适用即可      |

- **机制段≠深讲**：每个【本节最小必需】概念至少一句机制/理由；只有 1 个概念做完整 D/P/M/H/B/C。**若 >1 项关键能力都需完整深讲，拆节，不压缩深度**（细则见 `handout-design.md` §2.7）。
- **D 定义** / **P 问题**（为什么需要）/ **M 机制**（为什么成立）/ **H 程序**（怎么用）/ **B 边界**（何时不适用）/ **C 对比**（为什么不是相邻方法）/ **T 迁移**（还能用在哪）。
- **机制豁免（M）只有三种**：公理/定义、纯约定、纯记忆清单；须显式写「本题材无机制，属约定/记忆」，不能默认省略。
- **M 段至少一句因果或推导**（因为……所以……），或一个外部来源；两者都无 → 标「课程约定/未核实」，禁止把推测写成因果。

### 三层追问（写后 30 秒）

1. 为什么需要它？→ P
2. 为什么这样能成立？→ M
3. 为什么不用另一种方法？→ C

第三问答「教材规定/记住就行」且不是公理 → M 或 C 缺失，**判 E**。

### 六问审计（讲义定稿前）

- **D1** 有没有回答“为什么需要它”，而不只是“它是什么”？
- **D2** 有没有至少一句机制解释，而不是“规定如此”？
- **D3** 有没有一个“不适用/会错”的边界，并配了反例？
- **D4** 有没有与一个相邻方法的对比，说明“为什么不是它”？
- **D5** 学员能否用这段去判断一个没见过的新案例？
- **D6** 删除测试：删掉哪一段会损失上述任一项？删掉不损失的是冗余；删掉就损失的是深度载体，保留。
- **判定**：D1–D5 任一不满足 → **E（深讲概念）**；D6 只用于删冗余，不单独判 E。

### 反浅薄清单（命中任一，重写该段）

- 定义 + 公式 + 一道例题，没有 P/M；
- 用类比代替机制，只说“像什么”，不说“为什么像、边界在哪”；
- 只讲标准情形，没有 B；
- 只讲一种方法，没有 C；
- 示例只演示步骤，不展示“为什么选这一步”；
- 用“显然/易得/众所周知”跳过关键推导；
- 小结重复定义，没有压缩出新结构。

### 学员侧深度验收（深讲概念节末）

- **为什么题**：为什么必须这样做？换一个条件还成立吗？
- **边界题**：什么情况下会失效？举一个反例。
- **对比题**：A 和 B 都能做，什么时候选 A？

答不出 → 判“讲浅了”，补对应层，不怪学员。

### 冲刺降级

冲刺姿态下 M/C 可压成“一句结论 + 选学指针”，标“考后补”；**B 不可省**。

### 现象→符号引入序（条件触发）

零基础 + 首次 + 非冲刺：真实现象/问题 → 直觉模型（白话/图）→ 术语与符号 → 代入演示 → 边界。符号一旦出现，仍按「新记号/新操作讲透」三件套执行。进阶/备考/纯记忆清单可直接从定义/符号开始。

## 事实、来源与不确定性（所有风格共用）

- **分层表述**：事实 / 推导 / 经验 / 类比 / 课程约定在讲授中可区分——**类比不得当定义、约定不得当事实**；经验与约定表述时标注其性质（如「工程经验法则」「本课程约定记为\__\_」）。
- **来源显式化**：涉及外部事实、版本、规范、统计数字或时效信息时，按风险给出可得来源（名称 / 年份 / 链接 / 核验日期），或明确标注「未核实 / 截至日期」；**不伪造链接、引文或权威背书**；无法访问来源时不得把推测写成定论，明示「先按已知讲、未核实」。
- **同轮 / 同节可见**：必要条件、假设、适用范围与反例与结论同轮或同节可见，不散落到后续轮次才补。

## 标准讲义（默认）

- 适用：绝大多数知识型小节。
- 骨架（〔〕= 槽位落点；六套风格都按此逐个指认，漏槽位即不算讲完）：概念〔定义/规则 + 一句机制/边界〕→ **类比（有合适类比时才用；无则改准确定义 / 实例 / 图示）〔按需表示，可省〕** → **教学例〔① 题目 ② 解析 ③ 答案〕（worked example；最小典型、透明）** → **配对练习〔配对自测：同构题，可回看教学例，答案放节末〕** → 易错点〔④：症状 + 原因 + 补救〕→ 三句话小结〔⑤ 小结：≤3 句、不引入新信息；优先写判别句〕→ **闭卷自检（阅读动作：3 句解释 → 信心 → 对照 ⑤）** → **评估例/迁移〔迁移自测：真实/新情境，答案放节末〕**。题区写 `## 本节自测`，题前固定一行「先独立做完，再看本节自测答案」——提示语里不写「③ 答案」字样，避免被当成③标记行；答案统一放 `## 本节自测答案` 区，短答案合法、可短但不得写「略／见教材／同上」，不属五要素之③。顺序与「讲义概念单元 schema · 默认顺序」一致；四段细节见 `handout-design.md` §3.3。配对题写在教学例后（配对自测）；`## 本节自测` 区放迁移题（迁移自测），也可两题都放；两题答案统一放 `## 本节自测答案`。**类型矩阵见 `handout-design.md` §4**：记忆/概念/设计按矩阵替换 ③/⑤/自测形态；**L2/L3 可不出完整教学例**（§6），不违反“教学例只用一个”。
- **教学例判据（完整示例；适用于含解题/操作/作答过程的概念；五要素缺一不算讲完）**：①题目（**要解决的问题或要完成的任务**：题目型写题干要点——要你做什么、产出什么、交付给谁看；纯概念 / 纯记忆 / 参照级没有题干，写「本节要弄清楚什么」即可，不编造题目。题目只在这里写一次，答案框内不再重复）；②解析（方法与关键判断：每步做什么、为什么这么做、哪一步最容易错，以结论收尾）；③答案（**参考解答**：可整体誊抄的规范卷面，完整可复现即可，不排斥等价解法）；④易错（本例最容易错的一步，症状 + 原因）；⑤小结（≤3 句，只压缩不新增）。**含解题/操作过程时③必选**；纯概念/纯记忆没有可复现产物时**③ 框可省，但标记行不可省**：须在概念单元内显式标注 `③ 不适用（纯概念）` 或 `③ 不适用（纯记忆）`（下称「③ 空位豁免」，与深度契约的「机制豁免」不是一回事），同时豁免②③，①题目、④易错、⑤小结仍须具备——④ 写进「易错点」槽位即可，不依赖完整示例；标记行放在③位置、正文叙述里不重复该字样，避免误判；单元须有正反例或等价表示；**参照级单元**标 `【参照】` + `③ 不适用（参照级）`，豁免 ②③④⑤、只需 ①题目，定义与边界写在正文。**③ 框的形态**：从交付起笔到结论/产物收笔的完整、可复现答案，**框内不写题面段**（题目已在①），按**最小单元**分段（一段一个可独立核对的最小单元，各族形状见下条「框内分段」）。交付起笔按学科族取形态——数学/理科 `解：`/`证明：`，文科 `答：`/`参考答案：`/`方案：`/`设计说明：`，语言 `参考答案：`/`参考译文：`/`范文：`/`Model answer:`/`Sample answer:`/`Translation:`，精读 `参考概括：`（收尾 `原文定位：`），编程/工具 `代码：`/`脚本：`/`输出：`/`Code:`/`Script:`/`Output:`（代码块本身即可交付，须给运行结果与成功标志），技能/实验 `步骤：`/`操作：`/`Steps:`（须给成功标志），记忆/客观 `答案：`/`Answer:`/`Key:`，英文材料 `Answer:`/`Solution:`/`Proof:`/`Model answer:`。**标识清单、分点与代码块规则见「讲义概念单元 schema · 答案框体例」与 `handout-design.md` §2.3**——不把某一学科的写法当通用标准。备考/阅卷型任务按已声明的给分点书写并可整体誊抄，非备考任务按可提交/可复现格式书写，不虚构评分细则——②讲「为什么这么做」，③示范「卷面长什么样」，在已声明评分口径下覆盖必要步骤（备考/阅卷型任务学员照抄③应能得分）。涉及新记号/新操作的示例另须满足「新记号/新操作讲透」三件套（见下）。
- **教学例 vs 评估例（四段支架）**：①–③ + 配对用**教学例**（最小典型、透明、可判别；可原创/简化并标「改编自 p.X」）；迁移自测用**评估例**（优先来源原题/真题/学员真实任务，换新情境；**不是第二个完整教学例**）。评估例的答案用答案三件套（答案 + 一句为什么 + 最常见错答），不写成第二个 ③ 示范盒；备考型至少每个高权重小节有 1 个来源/真题风格的评估例。
- 写作要点：**深讲概念先按「深度契约」定层（D/P/M/H/B/C）再动笔**；零基础首次按「现象→符号引入序」。类比**优先取自学习者画像的类比领域**（无画像则贴学员场景），且**仅在类比真能说清时才用**——新内容没有合适类比时改用准确定义 / 实例 / 图示，**不强凑生活故事**（衔接 `teaching-loop.md` 第 3 节「无同构可撬则跳过、不硬凑类比」）；**教学例只用一个、做完整**——宁可少讲半个概念，不可给半截教学例（L2 补全/L3 检索版按 `handout-design.md` §6，不受本句限制）；**评估例是迁移任务，不是第二个完整示范**（见 `handout-design.md` §3.3）；误区写「症状 + 原因」而不只写结论；**术语首次出现给一句白话或定义**，不假设学员已知、不依赖未提供的材料。
- 成品范例（供导师对照格式与密度，非讲义内容；本例为【本节最小必需】级；其余族的段结构见 schema「其余族的最小形态」）：
  > **概念：解一元二次不等式（图像法）【本节最小必需】**
  >
  > - 概念：解 ax^2+bx+c>0，本质是找「抛物线在 x 轴上方」的那段 x 范围。
  > - 类比：抛物线像一座拱桥，>0 就是桥面以上的部分。
  > - ① 题目：解不等式 x^2−x−6>0。
  > - ② 解析：先解 x^2−x−6=0，十字相乘 (x−3)(x+2)=0，得 x=3 或 x=−2；开口向上（a=1>0），两根之间 y<0、两根之外 y>0，故解集为 x<−2 或 x>3。
  > - ③ 答案（可整体誊抄）：
  >
  > > 解：由 x^2−x−6=0，十字相乘得 (x−3)(x+2)=0，解得 x_1=−2，x_2=3。
  > >
  > > ∵抛物线 y=x^2−x−6 开口向上，与 x 轴交于 x=−2、x=3，∴原不等式的解集为 x<−2 或 x>3。
  >
  > - ④ 易错：忘判开口方向；把 >0 的解集写成两根之间（那是 <0 的），开口向上时 >0 取两根之外；Δ<0 只说明无交点，开口向上时 >0 恒成立（解集为全体实数），不是「无解」。
  > - ⑤ 小结：①先解对应方程；②看开口定内外；③解集用区间写全。
  > - 自测：①解 x^2−4>0；②判断 x^2+2x+3>0 的解集。（答案见本节自测答案）

## 费曼卡

- 适用：抽象概念；用户复述总卡壳的小节；复习时重讲。
- 骨架：①题目〔要讲清什么问题，如「$\pm$ 到底怎么读」〕→ 一句话大白话定义〔定义/规则〕→ 为什么重要（1–2 句）〔按需表示·动机，可并入①〕→ 讲给 12 岁孩子听的版本〔② 解析：是什么 → 怎么用 → 哪里会错，可并成一段但三步不得缺〕→ 一个类比〔按需表示；说清哪里像、哪里不像〕→ 反例〔④ 易错：什么不是它 + 最容易错在哪〕→ ③ 答案〔「最容易怎么用错」的对照答案，可只给关键句；纯概念标「③ 不适用（纯概念）」〕→ 一句话回收〔⑤ 小结：≤2 句、不引入新信息；不复述开头定义，只做压缩〕→ 自测〔检验：请用户不看卡复述〕。
- 槽位下限：①③④⑤ 各一行即可（费曼卡靠短取胜，不为凑槽位扩写）；② 由 12 岁版内部的三步承担。**③ 与 ⑤ 分工**：③ 收住「怎么用才不错」的成品答案，⑤ 收住「怎么记、什么时候用」，两句不得同义重复。
- 写作要点：**短而完整**——句句白话、紧凑，但不以字数截断（密度口径见「讲解文本密度原则」）；禁用行话，术语首次出现随即给白话替换。自测若只做口头复述（无书面答案），且单独写成 `## 自测` 区，须在该区首行写 `- 检验说明：口头复述，无标准答案`，不要留空答案区。

## 考试冲刺卡

- 适用：备考型任务的考点小节；结课前总复习。
- 骨架：①题目〔本卡对应的题型与分值，一句〕→ 本节考点清单（按考频标注★）〔定义/规则 + ② 的取材面〕→ 高频题型与解题步骤模板〔② 解析：第一步 / 第二步，可照抄〕→ 易错点（含扣分点提示）〔④：写「症状 + 扣哪分」〕→ 秒杀技巧或口诀〔⑤ 小结：≤2 句、只压缩不新增〕→ 3 道真题风格题〔检验〕→ 详解〔③ 每题答案，按答案框格式写，备考型附给分点量表〕。
- 槽位下限：考点清单 + 步骤模板 + ④ + ⑤ + ③ 缺一不可；口诀不得引入清单外的新知识点（它只是压缩）。
- 写作要点：解题步骤写成「第一步/第二步」可照抄的形式；题目难度对齐用户的目标考试；不引入超纲内容。

## 对比辨析卡

- 适用：一对易混概念（触发信号：薄弱点出现「分不清 X 和 Y」）。
- 骨架：①题目〔要判定的问题：什么场景下该用 A、什么场景该用 B〕→ A/B 一句话定义并排〔定义/规则〕→ 对照表（适用条件 / 典型场景 / 关键差异，≥3 行）〔按需表示 + ② 的判定依据来源〕→ 易混陷阱〔④：最常把 A 的哪条特征错安到 B 上〕→ 判别口诀〔⑤ 小结：≤2 句、只压缩不新增〕→ 各一道辨析题〔检验；③ 答案 + 判定依据〕。
- 槽位下限：② 由对照表的「关键差异」逐行承担（能照着逐条比对即可，不另写流程段）；④ 必须是**一条具体误判**，不写「注意区分」这类空话。
- 写作要点：对照表先行；口诀 ≤2 句；两道题各埋一个「看起来像另一个」的陷阱。

## 操作手册式

- 适用：技能型任务（编程、工具、软件操作）。
- 骨架：①题目〔要完成的操作与预期成果〕→ 环境与前置〔按需表示〕→ 分步操作〔② 解析〕→ ③ 答案〔`步骤：`/`代码：` + `输出：` 成功标志，代码/命令可复制、逐行注释〕→ 常见报错与修复（≥2 条）〔④：报错原文特征 → 原因 → 修法〕→ 关键决策三句话〔⑤ 小结：先做什么 / 卡住看哪条报错 / 什么算做成，≤3 句〕→ 练手任务（改错 / 仿写 / 微项目三选二）〔检验〕→ 完成检查清单。
- 槽位下限：④ 的每条报错必须是**本操作真会遇到的**（能对上②里某一步），不写「权限不足」这类泛泛报错凑数。
- 写作要点：每步可独立验证并给出「成功标志」；报错条目写「报错原文特征 → 原因 → 修法」。练手任务以成功标志判定，若单独写成 `## 检验` 区，须在该区首行写 `- 检验说明：练手任务，按成功标志自评`。

## 精读笔记式（论证文材料默认）

- 适用：材料型任务中**有「主张—证据」结构**的论证文（论文 / 评论 / 著作章节；「带我读 X」「精读 X」「帮我啃 X」多属此类）——有原文、目标是读懂作者在说什么，而不是掌握一个可计算的概念。条文 / 手册 / 代码库 / 数据表不走本式，按 `phases-and-gates.md`「材料型按材料结构分流」改用标准讲义或操作手册式。
- **单元 = 一个论证块**（一章 / 一节 / 一组自然段）：标题写该块的主张一句话，编号沿用 `## 概念 N · …`（脚本与闸口按同一单元处理，不另设第二套 schema）。
- 骨架：**① 题目**（这块要回答的问题 / 读完能复述什么）→ **块定位**（原文位置 + 这块在整篇里干什么：提出 / 支撑 / 反驳 / 收束）→ **② 解析：读法**（先拆结构骨架与证据强度 → 再抠关键术语 → 最后合上原文复述）→ **结构骨架与证据强度**（3–6 条：主张 → 证据（数据 / 案例 / 引文 / 推理，标原文位置）→ 让步或反驳 → 结论；每条注明「已证」还是「只是断言」）→ **关键术语**（术语｜原文用法｜一句白话｜易混点）→ **④ 易错**（断章取义、把作者转述的观点当成作者主张、旧译名混淆）→ **③ 答案**（参考复述的可誊抄版：`参考概括：` 起笔 + 末段 `原文定位：`；学员先写自己的版本再对照）→ **⑤ 小结**（≤2 句：主张 + 最强证据的压缩，供隔周回看定位）→ **检验**（2 道：这块的主张是什么 / 作者用什么支撑、哪里可质疑）。
- **五要素映射**（仍按 schema 写，不得豁免）：①题目=这块要回答的问题（读完能复述什么）；②解析=读法步骤（先拆结构骨架与证据强度、再抠术语、后复述）；③答案=**参考概括 + 原文定位**——直接用 `参考概括：` 起笔，末段写 `原文定位：<章节·段句范围>`，不写题面段（原文出处放块定位）；④易错=断章取义、把作者转述的观点当成作者主张；⑤小结=主张 + 最强证据的压缩（≤2 句，不是第二份复述）。
- 写作要点：
  - **转述不抄写**：直接引用不超过本单元篇幅两成，其余用自己的话；引用加引号并标位置。
  - **区分三层**：作者的主张 / 作者的证据 / 我的判断——后两层不得写成第一层（衔接「事实、来源与不确定性」）。
  - **术语首现即解释**（同标准讲义）；原文用旧译名或异体字时并列，避免学员换本书就不认识。
  - **枝节不进正文**：与本节目标无关的背景、考据进「扩展（选读）」区，或只标位置不展开。
  - **争议与过时**：原文观点有争议或已被修正时，写一句「截至<日期>，另有……」并给出处；**不替作者补论证**，也不把作者的话升格成事实。
  - ③ 是**参考概括**不是唯一答案：学员用自己的话覆盖要点即通过（衔接 `teaching-loop.md` 第 8 节主观题批改纪律）。

## 讲义概念单元 schema（所有风格共用）

讲义每个概念单元具备**可定位的必需槽位**：定义/规则、按需表示（类比 / 配图 / 对照表等）、完整示例或正反例、易错点、小结、检验问题。其他风格可重排槽位，但**不得漏槽位、不得删除必需信息**（参照级单元按「分层标注」条豁免，只留 ① 题目与正文里的定义、边界）。

**单元≠KP**：`## 概念 N` 是**教学单元**（历史标题，保留给脚本），不是 KP；一个单元可映射多个 KP，一个 KP 可跨单元。类型以单元的主导类型为准；混合类型拆单元或加类型子块。类型/支持级写规划区，不塞进每个标题；tier 标签仍必须有（见 `handout-design.md` §2.5）。

**六个槽位的落点必须可指认**：每条风格骨架已用〔〕标出落点——五个编号槽位（① 题目 / ② 解析 / ③ 答案 / ④ 易错 / ⑤ 小结）外加 schema 的**检验**。写完按骨架逐项指认，指认不出的就是漏槽位；**④ 与 ⑤ 最容易被别的段落顺带承担**（反例、对照表、报错清单、检查清单、骨架末尾的收束句都不等于 ④ 或 ⑤），须能指到具体那一行，不认「隐含在……」。④ 与 ⑤ 都按「≤3 句、不引入新信息」写（⑤ 的记忆族「本节地图」变体上限见「讲解文本密度原则」），不因加了槽位就扩写。**修复表、决策日志、对照表算附件，不占 ④/⑤ 的三句额度；但单元仍要有一句 ≤3 句的摘要**（见 `handout-design.md` §2.9）。

- **节首导读（定稿必备，3 行）**：在第一个 `## 概念` 之前写 `- 本节目标：学完能独立……`｜`- 前置：需要……（无则写「无」）`｜`- 预计：约 N 分钟`。与对话轮「课首定位」（`teaching-loop.md` 第 1.1 节）同源，不复制理由；学员隔周回看先读这三行。脚本 `E-HEADER-BRIEF`：**定稿**缺任一行报 E，草稿不查（讲的过程中可后补）。**读者假设、已会/未会并入「前置」一行；用法放文末；类型/支持级放规划区——不新增第四行必填字段**（见 `handout-design.md` §2.6）。
- **默认顺序**（标准讲义）：定义/规则（含一句机制/边界）→ 配图（按需）→ 教学例（① 题目 → ② 解析 → ③ 答案框）→ 配对练习（配对自测）→ 易错点（④）→ 小结（⑤）→ 闭卷自检（阅读动作）→ 评估例/迁移（迁移自测）。类比不单设槽位，归入「按需表示」，有合适类比时才用（见「标准讲义」写作要点）。**读者版 P1 可选增量**：节首导读之后可加 `## 本节速览`，概念单元首行可加「一句话结论：」，自测答案区之后可加 `## 回看索引`；三者只做导航，不改变上述五要素顺序与答案框位置。
- **风格 × ③ ⑤ 落点（六套风格都必须写出 ③ 与 ⑤）**：下表只列最容易写错的 ③ 与 ⑤；① ② ④ 与检验的落点见各风格骨架里的〔〕标注，不在此重复。**③ 只允许纯概念/纯记忆/已会·检索版/参照级豁免；⑤ 除参照级外任何单元都不得省**（canonical 标签与各自豁免范围见 `handout-design.md` §2.2；下表逐行列出主要豁免，未列到的风格按同一规则处理）。
  | 风格       | ③ 答案（框）                        | ⑤ 小结                       | 允许的豁免                             |
  | -------- | ------------------------------ | -------------------------- | --------------------------------- |
  | 标准讲义（默认） | 可誊抄全文：从交付起笔到结论（不写题面段）        | 三句话小结（≤3 句）                | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」；参照级→「③ 不适用（参照级）」 |
  | 费曼卡      | 「最容易怎么用错」的对照答案，可只给关键句         | 一句话回收（≤2 句）                | 同上（纯概念/纯记忆/已会·检索版/参照级）          |
  | 考试冲刺卡    | 每题答案（选择题含逐项排除），详解附给分点量表       | 秒杀技巧或口诀（≤2 句）              | 无（备考型必有）                          |
  | 对比辨析卡    | 辨析题答案 + 判定依据                   | 判别口诀（≤2 句）                 | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」 |
  | 操作手册式    | `步骤：`/`代码：` + `输出：` 成功标志      | 关键决策三句话（≤3 句）              | 无                                 |
  | 精读笔记式    | `参考概括：` + 末段 `原文定位：`          | 主张 + 最强证据的压缩（≤2 句）         | 纯背景章→「③ 不适用（参照级）」                 |
- **分层标注（每概念单元出厂必须带）**：在概念单元起始处用方括号标签标注 **【本节最小必需】**、**【选学·后期必用（何时用/依赖哪节）】** 或 **【参照】**；也可写在规划区对应概念行（表格列或列表行，纯文本即可），二者其一。选学标注须写明何时用到、依赖哪节；学员据此自行判断是否当前深学，不必等导师逐个说明。**【参照】对应深度契约的参照级**：只需「知道它是什么、什么时候用不上」，可标 `③ 不适用（参照级）` 豁免 ②③④⑤（① 题目仍须，定义与边界写在正文）；**工作级/最小必需级不得用参照豁免**。正文里只是提到「选学 / 最小必需 / 参照」字样不算标注。**纯记忆用 `③ 不适用（纯记忆）`、已会·检索版用 `③ 不适用（已会·检索版）`；两者只用于对应情形，不得拿来给工作级/最小必需级省讲解**。
- **定稿边界**：定稿 = 判分记账零残留（**台账状态行**、伺服档位、检验作答记录、补讲台账留 progress.md 与题组文件，不进定稿；两态流转见 `phases-and-gates.md`「讲授机制」）。**`verify_explanation.py` 通过只表示「结构可定稿」，不等于状态转定稿**：**讲义状态行** `- 状态：` 仍保持「草稿」，待小节闸口通过后再改为「定稿」。台账状态行与讲义状态行不是一回事，见 `handout-design.md` §2.1。
- **讲义头部（讲义状态行 + 可选指针行，不复制规则正文）**：`- 状态：草稿（…）` 或 `- 状态：定稿（…）`；**台账状态行不进讲义**。需要记录体例约定时只写一行指针 `- 体例约定（LaTeX 排版/答案框）：统一见 progress.md「质量保障机制」`；**该区存在时才写指针，否则省略或先建区，不能留死指针**。规则正文归任务侧 progress.md；在头部复制规则块会触发 `W-STYLE-POINTER`。头部之后、第一个概念单元之前接「节首导读」三行；读者假设/用法/类型/支持级按 `handout-design.md` §2.6 合并，不新增必填行。
- **答案框体例（学科无关）**：框内只写**解题过程**，从**交付起笔**开始（以 `解：`/`答：`/`解答：`/`证明：`/`参考答案：`/`答案：`/`参考概括：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`代码：`/`脚本：`/`输出：`/`步骤：`/`操作：`/`方案：`/`设计说明：`/`Answer:`/`Solution:`/`Proof:`/`Model answer:`/`Sample answer:`/`Translation:`/`Output:`/`Code:`/`Script:`/`Steps:`/`Key:` 起笔），或框内直接给出代码块。**完整交付标识表与学科映射见 `handout-design.md` §2.3；本行与脚本 `LEAD_WORDS` 必须一致。****不写题面段**：题干归 ① 题目，框内不再抄一遍（`题目：`/`任务：`/`Prompt:`/`原文：` 这类题面起笔在框内不再使用）。精读式另在末段写 `原文定位：<章节·段句范围>`（收尾段，不算第二类必需标识）。**标记行留空**：只写 `③ 答案：`，答案写进框内；标记行带内容报 `W-MARKER-CONTENT`。**标记行须在行首**（列表项，可加粗），正文里提一句「见 ③ 答案」不会被当成标记。**多题单元**（如冲刺卡 3 道真题）：每题一个 `③ 答案（第 N 题）：` 框，或在一个框里按题号分段（`（1）解：…`，题号可写在框内段首，仍算交付起笔）。**交付段须有实质内容**：去掉标识与标点后为空、或只剩「略／从略／见教材／同上／自行体会」等占位词的，不算答案（`E-BOX-EMPTY`）。**分点编号**：段首 ①–⑩ 合法——按点给分的给分点就是「每点一段、段首起编号」；句中编号不合规（`答：①……②……` 挤在一行），须拆成每点一段。**代码块**：框内的代码围栏（三反引号起止）整块算一段，块内多行不拆行、不查箭头与验算标记（验算只认 ✓ ✔ ✅，`√` 视为根号不拦），紧接 `输出：` 段给运行结果与成功标志。**同一体例的五种形态**——数学 `解：…∴ …`；文科 `答：①资本：…`（每点一段）；语言 `Model answer: 他跑得很快。`；精读 `参考概括：…` / `原文定位：…`；编程 `代码：` + 围栏块 + `输出：无报错即成功`。**客观题**：选择题给「答案 + 逐项一句排除（错项错在哪）」，填空写清多空顺序与单位，不得只给字母——教辅答案册多把逐项分析并入答案，故留在 ③；② 只讲这类题的判定方法（何时用排除、何时直接算），不复述逐项内容。**带图答案**：作图 / 受力图 / 流程图 / 装置图 / 结构式在框内单独一行 `图：assets/NN-xx.svg（示意/按比例）`，图须先落盘后引用（同「图像可视化双轨」），并按「绘图后核对」检查图文一致；无图可画时写清作法与关键点。各族的默认形态见 `subject-playbooks.md`「③ 答案形态」。**不得默认 `解：`**——按当前内容所属学科族取形态；跨族内容（如物理借数学族）以内容所属族为准。
- **其余族的最小形态（只演示段结构、篇幅从简；完整范例见「标准讲义 · 成品范例」）**：以下只给框内内容，题面一律写在 ① 题目。
  - **语言**：`Model answer:` 起交付；翻译可用 `参考译文：`；改错类末段补一句「为什么这么改」。
    > Model answer: 他跑得很快。
  - **编程**：`代码：` 后接围栏块（整块算一段）；末段 `输出：` 给运行结果与成功标志。
    > 代码：
    >
    > ```python
    > import os
    > for name in os.listdir('.'):
    >     if not name.startswith('p_'):
    >         os.rename(name, 'p_' + name)
    > ```
    >
    > 输出：无报错，文件名已加前缀。
  - **理科计算 / 化学**：物理按「公式、代入（带单位）、结果（有效数字与单位）」各一段；化学把配平系数、条件与物态写在同一段，反应箭头用 `->`，不用 Unicode 箭头。
    > 解：由 $v^2=2gh$ 得 $v=\sqrt{2gh}$。
    >
    > 代入 $h=20$ m、$g=10$ m/s²，得 $v=20$ m/s，方向竖直向下（两位有效数字）。

    > 解：2 H2 + O2 -> 2 H2O (点燃)，两边 H 各 4、O 各 2。
  - **文科 / 记忆（按点给分）**：`答：` 后每点一段、段首 ①–⑩，段间空 `>` 行。
    > 答：①资本：殖民扩张与海外贸易积累了大量资本。
    >
    > ②劳动力：圈地运动为工厂提供自由劳动力。

- **给分点量表（框外，备考/阅卷型适用）**：紧跟 ③ 框之后**单独一行**，不进框内——格式 `- 给分点量表：①<要点>（2分）；②<要点>（3分）；合计 5 分（训练量表，非官方细则）`。各点分值之和须等于合计（`E-RUBRIC-SUM`）；无官方细则写「训练量表，非官方细则」，有官方来源写「官方细则」并附名称/年份（缺声明 `W-RUBRIC-SOURCE`）。非备考任务不写分值，改给关键步骤、验证方式或成功标志，不编造官方分值。
- **框内分段（通用判据）**：一段 = 一个**可独立核对的最小单元**——单独拿出来能判对错、能给分、能对照的最小块。段内不再塞第二个这样的单元，也不把一个单元拆到两段。**段间写一个只含 `>` 的空行**；**段数不设下限**（单步答案一段即可，`> 答：B。` 合法）；`解：`/`答：` 等交付起笔放在**首段起头**（不单独占一段），末段为结论；**公式 / 算式 / 引文不跨段**，长式转行只落在等号 / 关系符 / 运算符之后（细则见 `formula-typesetting.md` 第 3 节）。**每段以单行为准**：普通文字多行会被渲染器并成一行、内容不丢——脚本不再提示（`W-BOX-WRAP` 已取消，避免每个框都冒一条噪声），由「讲解出厂自检」第 2.1 项人工核对；若段内断行截断了 `$…$` 公式或行内代码，渲染直接损坏（`E-BOX-WRAP`）。**围栏代码块整块算一段**，块内多行照原样保留。分段前先把同一句被拆开的续行合并成一行。一句话：**看这一段能不能单独判对错**。
- **各族的「最小单元」（同一判据的不同形状）**：计算 / 证明 = 一个**语句**（对象 = 结果：一次变形、一次代入、一次判定各一单元，`∵…∴…` 依据与结论同段；同一表达式的连续变形可用连等式合并，解方程 / 不等式 / 证明逐步写）；按点给分（文科 / 记忆）= 一个**给分点**（段首 ①–⑩，每点一段）；论述 / 理论 = 一个**论证环节**（结论 / 依据 / 适用）；语言 = 一个**句子或意群**（译文按原句切）；编程 = 代码整块一段 + `输出：` 一段；精读 = 概括一段 + `原文定位：` 一段。
- **答案框紧邻**：③ 标记行之后只允许空行，紧邻的引用块即答案框；教材原题等其他引用内容放在 ③ 之前，不得插在标记与框之间。**卡片类的检验与详解都留在概念单元内**：冲刺卡 / 对比辨析卡的「检验：…」与 ③ 详解写成单元内的列表行与引用框，**不单独设 `## 检验` 标题**——任何 `## ` 标题都会终结单元，③ 落在单元外就会报「缺 ③」；若检验确需独立成区，③ 详解须写在区之前。
- **自测与题组的分工**：讲义自测 2 道 = **1 道配对执行 + 1 道迁移/判定**（低风险自检，不判分、不进闸门、不写 `exercises/`）；闭卷解释是阅读动作，不占题量。`exercises/` 题组 = **唯一判分证据**（2–3 道递进 + 1 道判定题，见 `phases-and-gates.md` 小步④）。二者**不得同题**（可同知识点换情境；L3 复习产物例外见下），自测答对也不作为掌握证据。答案三件套：答案 + 一句为什么 + 最常见错答；选择题逐项排除。**每节题量预算**：自测 2 + 题组 2–3（判定题计入题组）+ 单元检验 0–1（用剩余额度），单节新做题合计 ≤6；深度验收与 S4 复习复用题组题，不额外加题。超预算时先减单元检验，再并题组或移入 `exercises/` 次日再做，不靠加题补密度。**L3 复习产物例外**：检索版要点卡 3–5 题优先复用旧题/题组，不作新判分证据；「自测 2 + 题组 2–3 ≤6」与「自测≠题组同题」只约束 S3 新学，不约束 L3 复习产物；题区用 `## 本节自测`/`## 自测`，答案区同族（见 `handout-design.md` §2.4）。**类型化自测见 `handout-design.md` §4；L1/L2/L3 支持级见 §6。** **脚本检查（标题约定）**：题面区认 `## 本节自测`（推荐）/ `## 自测` / `## 自测题` / `## 检验` / `## 检验题` / `## 检验问题` / `## 本节检验`；答案区认同词干 + `答案`（`## 本节自测答案` 推荐）、`答案区`、`答案要点`、`答案与解析`，也认通用的 `## 答案` / `## 参考答案`。**标题统一用中文**——英文讲义也写中文标题（正文与答案内容可用英文），`## Self-test` 这类英文标题不识别。一个文件可有多个答案区（如自测、检验各一区），逐区检查。题面区之后没有同族答案区（自测 / 检验各自成族）、也没有通用答案区 → `W-SELFTEST-MISSING`（不阻断；文末一个 `## 参考答案` 可统管前面多个题面区，`## 检验问题答案` 不给 `## 自测` 兜底）；答案区只写「略／见教材／同上」或整区为空 → `W-SELFTEST-EMPTY`（不阻断；只有代码块的答案不算空）。**开放/动手检验豁免**：确无书面答案的（开放题、口头复述、动手练手、本节不设检验）须在该区首行显式写 `- 检验说明：开放题，无标准答案（说出/复述即算）`——含 开放/口头/无标准答案/不设/跳过/练手/动手/压缩 任一字样即认，不报 MISSING；没写说明又没答案区，一律按「学员做完无处对答案」处理。自造标题（如 `## 小测`）既不检查也不豁免。
- **闭卷自检（阅读动作，不计题量）**：在 ⑤ 之后、自测之前写一行「合上讲义，用 3 句话解释本节核心 → 自评 0–100% 把握 → 对照 ⑤ 补漏 → 做迁移题」。不新增答案区；模型答案用 ⑤，学员自评不写入 progress.md；≤3 个阅读动作/节（见 `handout-design.md` §3.5）。
- **概念地图（可选节首区块，5 个以上概念或 ≥3 条依赖关系的节建议写）**：`## 概念地图` 放在节首导读之后、第一个 `## 概念` 之前，用一张表列「概念 N｜一句话是什么｜依赖哪个概念｜分层」。脚本不把它当概念单元、不查五要素；它只用于隔周回看与复习定位，不替代各单元的完整讲解。长节可再加一张“空概念图”做闭卷检索（旧「8 个以上」阈值废止，见 `handout-design.md` §2.10）。
- **压缩已熟的落盘**：连续轻松答对后压缩为**要点卡**，写入 `materials/NN-<节名>-要点卡.md`（编号沿用节号），**不改写定稿正文**；要点卡只留结论、适用条件与一个易错点，不复制 ③ 全文。**L3 已会单元用「检索版要点卡」**（`materials/NN-<节名>-检索版要点卡.md`，3–5 题 + ⑤/④；至少 1 道换情境/新问法，避免只背答案），不再另造「检索单/复习卡」名称（见 `handout-design.md` §2.4/§2.9）。
- **扩展（选读）区**：讲义可在节末设 `## 扩展（选读）` 区，只放**不进闸口、不出题、不作定稿判定依据**的内容（背景沿革、更深的证明、工具技巧、跨领域补充）。准入三问——本节解题用得上吗？本节后必须会吗？删掉会不会漏考点？三条全为「否」才可进。区内**不挂**分层标注、**不强制**配 ③ 框，也不得写考点结论。位置排在「自测/检验答案区」之后，且必须是本文件最后一个区（范围到文末）。

## 交互式工作样例（所有风格共用）

复杂多步骤方法首次讲授时，先给**完整工作样例**（带完整解题过程与最终答案的示范，判据同「标准讲义 · 教学例判据」），再按需叠加三型互动形式（三型只作 S2 配对的可选变体，不替代四段/评估例；见 `handout-design.md` §3.3）：

- **自拟标签型**：工作样例按子目标分步呈现，**学员给每步自拟功能标签**（这一步在做什么，用学员自己的话命名）——不直接给标签，参考标签在样例末尾对照。
- **找错型**：样例中埋 1 处错误，请学员定位并修复。
- **重建型**：挖空样例的关键步，请学员补全重建。
- **强制触发（先示范后练习）**：学员起点 ∈ {零基础, 入门} 且本节含解题/操作型内容（计算、推导、代码、工具操作）→ 讲义骨架中的完整示例为**必选项**：先看完整示范再做练习，不得「讲完概念直接出题」。
- **选用规则**：首次接触的多步骤方法 → 先给**完整工作样例**（全部步骤 + 最终答案），互动三型只作其后的加固练习——①自拟标签型（学员给每步命名，参考标签在样例末尾对照）或③重建型**不得替代首次完整呈现**；该步骤属已预判易错点 → ②找错型（同样在完整样例之后）。
- **支架按「本项技能的表现证据」渐撤或恢复，不按出现次数硬撤**（T08）：同一方法第二次出现，若该学员**尚未表现出独立成功**，仍给所需范例；出现独立成功证据后再渐退到补全示例 / 独立题 / 迁移题。「第二次必撤样例」不成立——防样例依赖不能压倒新子技能的支架需求（决策规则见 `teaching-loop.md` 第 2 节）。
- **高起点跳样例（专长反转）**：仅当**本项技能**已有独立成功证据（该部分 S1 摸底全对或该技能伺服持续 >90%）→ 可跳过样例直接做题；**课程整体起点只作初始参考**（进阶者学全新子技能仍需示范）。样例支持随**本项技能**表现渐撤。**伺服「加难」只改出题难度，不减少讲义示范与细节密度。**
- 三型是通用教学结构，与学科无关；各学科族的具体素材差异见 `subject-playbooks.md`。样例本身落盘 `materials/`，沿用讲义两态（草稿/定稿）。

## 新记号/新操作讲透（所有风格共用，硬规则）

讲义或讲授中**每引入一个新记号、新公式、新操作**，当场给齐三件，少一件即不算讲完，不得等学员反馈再补讲：

1. **语义**：它是什么、怎么用（如「± 是一口气算两次：带 + 一次、带 − 一次，各得一个根」）——不把记号当自明；
2. **代入演示**：用一道学员已做对或最简单的例子完整代一遍，每个符号落到具体数值；
3. **易错点**：该记号/操作最常见的误用（如 −b 代入先翻符号）。

- **判据**：学员只看讲义、不听讲解，能复述该记号的用法并独立代入一次 = 讲透。
- **三件套独立成段**：首次引入的新记号/新操作段落，三件（语义＋代入演示＋易错点）**独立成段给出，不因篇幅压缩被合并或省略**（密度口径见「讲解文本密度原则」，必要内容不以字数截断）；伺服难度档位不改变本规则。

## 图像可视化双轨（所有风格共用）

讲义概念涉及**函数图像、几何图形、数轴/区间示意、流程图、架构图、时序图、装置图、受力图、结构式/反应式**时，默认双轨呈现，对话讲授场景下缺一不可：

**适用场景**：对话讲授轮与讲义定稿同时发生时执行双轨；纯文件交付（独立触发写讲义、批量生成）无对话轮可渲染，只执行落盘轨，并在交付说明标注「未做对话内渲染」；自检第 14 项按场景判定。

1. **对话内渲染**：讲解轮用前端 SVG 直接画出图形（学员当场可看、可追问；SVG 为纯静态图形——图形元素与文字标注，不含 script 与外部引用）；
2. **落盘存档**：SVG 源文件写入 `materials/assets/NN-<图名>.svg`（编号沿用材料契约），讲义 markdown 用图片语法引用该相对路径（相对 `materials/` 目录，如第 2 节第 1 图存为 `assets/02-01-抛物线三情形.svg`）——图进入复习链路，讲义复看、S4 复习、结课复盘均可再打开。**先落盘、后引用，同轮完成**，杜绝死链（脚本按讲义所在目录解析相对路径，缺失报 `E-IMG-DEADLINK`）。

- **绘图前约束**：先声明图形类型——**定性示意图**（示意趋势/位置，不承诺比例，须标注「示意」）或**按比例图**（须与数值/比例一致）；只标**当前任务真正需要的点**，不为「完整」机械塞入无关要素（如解不等式的图**不必机械加入顶点**）。
- **绘图后核对**：核对图与讲义文字**一致**——坐标图核关键坐标、走向与区间端点；流程图核步骤顺序与分支条件；装置图核部件、连接与方向；受力图核力的方向、作用点与个数；结构式核原子/基团与配平。**多面板图逐面板与讲义文字对应，禁止漏面板**（漏面板 = 内容缺失）；**图文不一致时以领域事实为准**（数学看计算与定义、物理看受力与量纲、化学看结构式与配平、流程看步骤依赖），先修图再继续（不转成辩护，并同步修正讲义与存档）。
- **图的可判读规范**：按图类给最小标注——坐标图有坐标轴、标度示意与关键点（顶点/交点/渐近线/截距，限于当前任务所需）；流程图有方向、分支条件与起止；装置图有部件名与连接顺序；受力图有箭头方向与作用点；结构式有键与条件。曲线与辅助线用不同样式区分；一张图只讲一件事，不堆叠。
- **兜底链**：对话内渲染失败 → 讲义内嵌可复制的 SVG 源码（学员侧可自行打开）→ 文字描述图（末位兜底，向学员标注「降级为文字图」）。
- SVG 为纯文本：零第三方运行时依赖、可复制可修改、跨平台；不引入 matplotlib 等绘图库依赖。
- **视觉任务与讲解图分开**：KP 的视觉任务证据必须来自原始材料图/表（页码/图号/数据位置），讲义 SVG/示意图只用于讲解，不能替代原始来源（见 `data-and-recovery.md`「视觉任务来源纪律」）。
- **图解语法与无障碍**：图 brief、节点预算、边/标注、颜色与对比、SVG 技术要求、alt/图注见「读者版可读性契约」第 4 条；跨节视觉一致性见 `handout-design.md` 第 10.11 节。

## 出题流水线（四步，v6.3）

出题（S3 练习、S4 复习、独立「考考我」/组卷）按四步执行；题量、题型与难度仍受 S3/S4 预算与目标约束。S5 综合测验不改变既有蓝图与目标线规则：先按「能力—任务—评分点蓝图」定覆盖、题量与分值，再用本流水线生成与自检。

1. **探索**：先读本次小节目标与讲义范围；有清单时读本次相关 KP（S5 按蓝图读全部纳入 KP）；S4/已有任务的独立出题先跑 `due-queue`（无任务时跳过；S3 沿用进入小节前的结果，跨日续学可重跑）；再读 `exercises/` 最近题组与判分记录，标出「要考的能力 / 主要错因 / 已出过的题」，避免重复旧题（T11 明确选择「原题保持」时除外）。
2. **规划**：按本次题量预算列题（默认 2–3 题；S5 综合测验按蓝图），逐题定 topic、题型（基础/应用/变式/判定）、难度、对应 KP 或能力；至少 1 道判定题；组内 topic 不重复（T11 明确选择「原题保持」时除外；同一薄弱点需多问、或 S5 蓝图要求同一 KP 多题时，用不同题型/情境/变式，不以换数字充数）；新学按基础→应用→变式递进，复习按 T11 选「原题保持 / 近迁移 / 远迁移」。
3. **生成**：逐题写题干、选项（选择题）、答案、解析、难度与 KP 映射；干扰项取本节常见误区；选项等长并打乱，题面与解析不引用字母；答案键批改前私有；用材料出题时记来源锚点（页码/图号/数据位置）。
4. **修复**：整套题一次性自检——答案键、选项字母中立、解析完整、难度标注、KP 映射、与旧题是否重复（T11 明确选择「原题保持」时除外）、是否与本节自测同题（仅 S3 新学题组适用，此项无例外）；发现问题修一次并重检，不无限重写；答案键不确定标 `未判`，不猜。

四步是同一轮的内部流程，不额外占用学员轮次；题组仍按既有「一组题一条消息交齐」交付。

## 出题零提示约束（所有风格共用）

出题时遵守「零提示」规则，防止题目本身泄漏答案或降低检索难度。以下规则在流水线第 3 步生成与第 4 步修复时逐条核对：

- **出题形态分界**：能从已有知识逻辑推导的内容，练成解题/应用题；无法推导、纯记忆的任意性内容（单词、常数、术语表）才做填空/背诵卡。判断标准一句话：**这条能否从别的东西推出来**——可推导内容做成死记卡是浪费检索练习，任意性内容硬出证明题是折磨学员。
- **不主动报答案**：题目与答案分离，先出题、等作答，批改阶段才给解析。
- **选项等长**：选择题选项在长度与结构上对称，避免最长的那个就是正确答案；干扰项 = 本节常见误区的具象化（与判定题「邻近情境干扰」同一取向），不用显然错的弱干扰。
- **防猜测选项**：选择题可含「我不确定」类选项，学员选它按未答（Again）处理——防 25% 猜对虚增闸口正确率，给低信心一个诚实出口。
- **选项打乱与字母中立（v6.2）**：展示前打乱选项顺序；题干和解析都不引用“A/B/C/D”，按内容说答案；正确标签在批改前保持私有。
- **答案键与解析纪律（v6.2）**：正确答案/解析批改前不下发；每题都能在批改反馈或判分后的参考答案区找到解析（不要求在题面预写）；难度在题面或题组文件头注明「难度：易/中/难」，不写进调度档（调度档记录表现，不记录题目难度）；正确项不得更长、更完整或带“推荐”标记；选项不按正确性排序。
- **格式不泄题**：不在题干里暗示答案（如「以下**错误**的**是**」的加粗位置、选项排序规律）。
- **变式真变**：递进题（基础 → 应用 → 变式）须换情境或逆问题，而非只改数字。
- **条件化出题（判定题）**：每个题组至少 1 道考「**何时用**」的判定题——给出场景问该用哪个知识点 / 给出信号问该触发什么方法 / 追问权衡（「方法 A 什么时候反而不如 B」）。只考「是什么」的题组默认不合格：掌握 = 会内容 + 会判定适用条件，二者缺一不可（条件化知识）。判定题的干扰项须是「邻近情境下才对」的方法，制造真实的判定张力，不用显然错的弱干扰项。
- **复习变式优先、原题按目标保留（T11）**：S3 热身、S4 复习、综合测验重试的题目**以变式为默认**（换措辞 / 换情境 / 反向问 / 迁移情境），与「变式真变」同一取向；但**不一律禁止原题**——按目标组合「**原题保持**（检验是否真记得这道）/ **近迁移** / **远迁移**」，需检验长期保持时可原样重问（同日两次正确 ≠ 长期保持）。
- **难度对齐**：题组难度对齐用户目标（考试对齐真题，兴趣对齐应用），不超纲、不降维羞辱。

## 应试技巧包（备考任务·冲刺期启用）

**启用时点**：备考型任务进入冲刺期（考点密集小节讲义改用「考试冲刺卡」起，至 S5 结课）开始执行本节；基础阶段与逐节学习前期不前置、不占轮次。五项均结合既有环节自然带出，不单独开课：

1. **时间预算**：按目标考试卷面结构给各题型定参考用时（有官方时长按官方，无则按题量估算并标注「估算」）；冲刺卡题组、S5 全真测验计时执行；单题超时先跳过标记、做完再回头。
2. **卡壳抢救**：教「解 → 设 → 列 → 能推几步推几步」的框架写法——把已知与目标摆上卷面就有关键步骤分，绝不空白；结合错题与模考复盘教，不空讲。
3. **检查策略**：交卷前预留固定检查时段（按时长定比例）；优先验算计算量大与踩过易错点的题——代回验算、符号与量纲快速核查。
4. **卷面管理**：草稿与解答分区，解答区只誊写 ③ 答案框的内容（判据五要素之③）；写错单横线划掉续写，不涂团。
5. **考前一页纸**（S5 结课产出）：公式卡 + 高频易错点 Top 5 + 各题型用时表 + 考场流程清单（含卡壳抢救与检查时点）。

## 讲解出厂自检（四维度，所有风格共用）

讲授正文（对话讲授轮与讲义正文）在发出/定稿前按以下四维度自检，逐项编号，每项标 **E（阻断）/ W（警告）**。**按执行时点分级，不全量平铺**：

| 时点      | 必查项                                                        | 可后置项                      |
| ------- | ---------------------------------------------------------- | ------------------------- |
| 发出讲授轮   | 1、2（仅含量词时）、3、4、5、6（仅高风险外部事实）、7（仅含计算/代码/可运行示例时）、11、14（仅含图时） | 8–10、12、13、15，以及 6 的完整四要素 |
| 讲义定稿    | 全部 15 项                                                    | 无                         |
| 相关内容修改后 | 受影响项 + 5（术语一致）、8（结构）、14（图）                                 | 其余                        |

**E 项命中 → 修复并重检该项，通过后才能发出/定稿**；**W 项命中 → 同轮修复或显式后置（注明原因），不阻断**。本自检是模型自检，不替代 `scripts/verify_explanation.py` 的静态校验（定稿前两者都跑）。**深讲概念另跑「深度契约」D1–D6**：D1–D5 任一不满足 = E；D6 只用于删冗余。该审计不替代本表，二者都跑；缺 M/C 的深讲概念不得定稿。

### 1. 准确性与可信度

1. （E）结论、条件/定义域、量词、单位、版本与边界逐条核对；**含量词的表述（所有/任意/存在/至少/当且仅当等）逐条标注量词归属**；
2. （E）含量词的定义或规则**出厂配齐正例 + 反例（或边界例）+ 代入/验证演示**；不适合举例时说明原因与替代核验方式；
3. （E）分类不完备时明示「只列代表类型、非完备分类 + 补全位置与时机」，本节检验题**不得考所列类外情形**；
4. （E）定义/定理/推导/经验/类比/课程约定可区分（类比不当定义、约定不当事实，见「事实、来源与不确定性」）；
5. （E）符号、术语与引用全节一致；术语首次出现已给白话或定义，未假设学员已知；
6. （E）外部来源学员侧可得并注明名称/年份/链接/核验日期；不可得则改为课程内约定并说明；无法核实的内容标出不确定性，**不编造来源**；
7. （E）计算、推导、代码或操作至少做一次独立核对（代回、量纲、边界样例、运行成功标志，按领域选用）。

### 2. 结构

1. （E）概念单元必需槽位齐全（见「讲义概念单元 schema」），节首导读三行齐，五要素、新记号三件套、分层标注按内容适用性齐全，答案框体例合规（`verify_explanation.py` 覆盖静态部分；**框内段内是否有多行、是否按最小单元分段，脚本不查，本项必查**）；**所用风格骨架里的 ④ 与 ⑤ 须指认到具体行**（反例/对照表/报错清单/检查清单不算 ④，骨架末尾的收束句不算 ⑤）；**纯概念豁免②③的单元，须有人工确认的正反例或等价表示（脚本不查，本项必查）**；**参照级豁免②③④⑤的单元，须人工确认定义与「何时用不上」的边界已写在正文（脚本只查①题目标记，不查内容）**；
2. （E）示例、讲义自测、题组三者不同题（可同知识点换情境），非只改数字的重复；
3. （E）所选风格可重排槽位，但未删除必需信息。

### 3. 密度

1. （W）易错点单一出处、小结不引入新信息、无空转句；②与③不原样重复（②给方法与判断、③给成品卷面；结论句允许各出现一次）；
2. （W）逐段做「删除测试」——删除后不损失目标、依据、边界或验证信息才删除；可选细节后置并显式标注。

### 4. 呈现

1. （W）公式符合 LaTeX 约定（见 `formula-typesetting.md`）；
2. （E）配图**逐面板与讲义文字对应，禁止漏面板**（漏面板 = 内容缺失）；按图类核对（坐标 / 流程 / 架构 / 时序 / 装置 / 受力 / 结构式，见「图像可视化双轨」可判读规范）；图文不一致时**以领域事实为准**先修图；
3. （W）代码/操作示例给出可复制的成功标志。
