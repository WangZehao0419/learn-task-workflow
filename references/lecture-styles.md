# 讲义与讲授规则（风格模板 · 讲授契约 · 密度 · 自检）

写讲义前先选风格：默认「标准讲义」；用户点名风格时优先用户指定；按适用时机匹配。同一份讲义只用一种风格。五套风格共用 SKILL.md 的教学四原则与学习科学取向；对话讲授轮与讲义交付的产物分工、文本密度与出厂质量由「对话讲授契约」「讲解文本密度原则」「讲解出厂自检」统一约束。

## 类比纪律（所有风格共用）

- **类比优先取自学员的类比领域**：数据根存在学习者画像（见 `data-and-recovery.md`「学习者画像」小节）且记有类比领域时，类比例子优先从该领域选（学员熟悉做饭就先拿做饭打比方，其次才是本分册的默认素材）；无画像或未记录 → 用本分册默认类比。
- **确证已会才可当锚点**：类比与「跨界三猜想」（`teaching-loop.md` 第 3 节）共用的铁律——类比锚点必须是**确证的已会知识**（摸底判分 / 学员亲口确认 / 画像稳定模式），严禁把材料作者背景或「学员没否认」当成他会；拿不准先问一句。
- **类比不是定义**：讲清类比「哪里像、哪里不像」，边界处明说「类比到此为止」；不拿类比替代严格定义（理论概念类误区模式已列）。

## 对话讲授契约（所有风格共用）

约束「对话讲授轮」的产物形态，与讲义交付共同构成完整教学产出：

- **产物分工**：对话轮 = **引导过程**（学员可交互、可追问）；讲义 = **完整档案**（草稿即时落盘，定稿 = 学生自读版）。对话轮不是讲义整段投喂，也不是把讲义草稿照读一遍。
- **默认最小逻辑骨架（五段，命名标签）**：单个概念的主动讲授轮默认给出以下五段，**使用命名标签**（定位 / 核心 / 示例或正反例 / 小结 / 检验），刻意与讲义五要素的 ①–⑤ 编号区分：
  - **定位**：接学员确证已会的旧知（跨界三猜想 / 为什么现在学），说明本轮目标；
  - **核心**：定义 / 规则 / 性质，按需配图；给一句**适用边界**（什么时候不适用或会失效）——边界不清的结论不可信；
  - **示例或正反例**：按内容需要给完整示例或正反例——此处「完整示例」指讲义五要素中的目标、分步、答案、易错点，标准答案框不强行塞入对话轮；
  - **小结**：最多三句、不引入新信息；一两句已完整回收则不凑数；
  - **检验**：0–2 道，按诊断价值决定取舍；给出后**停轮等待作答**。
- **压缩出口**（任一命中即可压缩为「**结论 + 必要依据 + 边界**」）：学员已掌握的简单事实、纯记忆概念、局部纠错 / 批改、学员明确要求「直接讲 / 速答」、出现疲劳信号。**压缩不得删除必要条件、关键推导或纠错信息**；不强行生成完整示例、小结或检验题。**压缩只改本轮讲授形态，不免除小步④的练习义务与小节验收证据**：本节仍按 `phases-and-gates.md` 出题并取得判分；「直接讲」之后按 `teaching-loop.md` 第 4 节给独立练习验证机会。
- **风格槽位映射**：费曼卡、考试冲刺卡、对比辨析卡、操作手册式等把上述五段槽位映射到各自骨架，可重排、合并、压缩，但**不得另立与本契约冲突的规则**，不得删除必需信息。
- **标准答案框默认不进主动讲授轮**（只落讲义）；仅当本题型首次讲授、学员明确索要完整解答、或批改需要给出完整解析时可附**一次**，并同轮提示「标准答案已落讲义」。
- **记账永不进正文**：判分记账、状态行、伺服档位记录永不混入讲授正文；学员明确查询进度 / 档位时另走**状态回复**（口径见 `data-and-recovery.md`「快捷指令明细·问进度」），不伪装成讲解内容。

## 讲解文本密度原则（无硬字数，所有风格共用）

总原则：**高效务实（最少文字、最大信息量），专业严谨（清晰、准确、值得信赖）**。质量取舍优先级：准确性、适用条件与必要推导 ＞ 清晰可复现 ＞ 信息密度与篇幅；为定义、边界、反例、单位或验根允许重复一次，**禁止为追求短而删掉会改变结论的内容**。

**信息量判据（四问，密度的下限）**：每个概念讲完，学员应能回答——**是什么、什么时候用、怎么用、什么时候会错**。四问由「核心」（是什么、什么时候用）、「示例」（怎么用）、「易错」（什么时候会错）承载，「定位」只接旧知与本轮目标；四问之外的内容（历史沿革、扩展证明、无关对比）属可选，后置并显式标注。四问是不可少的底线，不是篇幅上限。

密度由以下**可复核**子规则承载（逐条可人工判定，非机器校验；`scripts/verify_explanation.py` 不检查密度），既有硬字数上限及等价表述一律清退，风格目标为「短而完整」，**不以字数截断**：

- **易错点单一出处**：示例内（④）一句带过，展开归「易错点」槽位；
- **小结最多三句（或三条）**，不引入新信息；一两句已完整回收则不为凑数扩写；
- **无空转句**：每句承载新信息，衔接性废话删除；
- **按最小充分路径组织**：先给当前目标 / 结论，再给达成它必需的步骤；可选背景、延伸与证明后置并标注，不为「完整」堆砌；
- **标准答案框、判分记账、状态行、伺服档位记录不进主动讲授轮**（边界见「对话讲授契约」）；
- **必要推导必须完整，不为任何字数考虑截断**。

**超长自查**（结构性判据，不设字数）：出现以下任一情形时自查一次「有无混入标准答案框 / 记账 / 重复内容、可选细节是否可后置」——① 同一概念连续三段以上没有新增信息（只是换说法）；② 存在整段删除后四问仍可完整回答的段落；③ 可选背景与当前目标混排、未后置标注。**字数本身不是触发条件，也不是上限或截断依据**；必要推导即使更长也完整保留。

**密度反例（不合格长什么样）**：
- 空转句：「接下来我们来看一下这个概念，相信大家一定不陌生」——删掉后信息量不变。
- 记账混入：「（本节已讲完，状态：已通过）」——导师记账归 progress.md，不进讲授正文。
- 重复展开：示例④已说「忘判开口方向」，易错点节又完整重述一遍——易错点只在一处展开。
- 无关前置：「这个定理 1820 年由某人首次证明……」与本轮目标无关，应后置并标注。

## 事实、来源与不确定性（所有风格共用）

- **分层表述**：事实 / 推导 / 经验 / 类比 / 课程约定在讲授中可区分——**类比不得当定义、约定不得当事实**；经验与约定表述时标注其性质（如「工程经验法则」「本课程约定记为___」）。
- **来源显式化**：涉及外部事实、版本、规范、统计数字或时效信息时，按风险给出可得来源（名称 / 年份 / 链接 / 核验日期），或明确标注「未核实 / 截至日期」；**不伪造链接、引文或权威背书**；无法访问来源时不得把推测写成定论，明示「先按已知讲、未核实」。
- **同轮 / 同节可见**：必要条件、假设、适用范围与反例与结论同轮或同节可见，不散落到后续轮次才补。

## 标准讲义（默认）

- 适用：绝大多数知识型小节。
- 骨架：概念 → **类比（有合适类比时才用；无则改准确定义 / 实例 / 图示）** → **完整示例（worked example）** → 三句话小结 → 常见误区 → 2 道自测题（附答案）。
- **完整示例判据（适用于含解题/操作过程的概念；五要素缺一不算讲完）**：①题干与目标（求什么）；②分步过程（每步做了什么动作、为什么这么做）；③最终答案；④易错点提示（本例最容易错的一步）；⑤标准答案（**参考解答**：完整可复现即可，不排斥等价解法；完整示例含解题/操作过程时**必选**；纯概念/记忆类没有可复现产物时**⑤ 框可省，但标记行不可省**：须在概念单元内显式标注 `⑤ 不适用（纯概念）`，同时豁免②③⑤；①目标与④易错仍须具备——④ 写进「易错点」槽位即可，不依赖完整示例；标记行放在⑤位置、正文叙述里不重复该字样，避免误判；单元须有正反例或等价表示）：**题目/任务 + 从「解：」或等价交付起点到结论/产物收笔的完整、可复现解答**。数学可从「解：」起笔；代码须给出关键代码、输入输出与验证方式；操作须给出成功标志。备考/阅卷型任务按已声明的给分点书写并可整体誊抄，非备考任务按可提交/可复现格式书写，不虚构评分细则——②讲「为什么这么做」，⑤示范「完整答案长什么样」，在已声明评分口径下覆盖必要步骤（备考/阅卷型任务学员照抄⑤应能得分）。涉及新记号/新操作的示例另须满足「新记号/新操作讲透」三件套（见下）。
- 写作要点：类比**优先取自学习者画像的类比领域**（无画像则贴学员场景），且**仅在类比真能说清时才用**——新内容没有合适类比时改用准确定义 / 实例 / 图示，**不强凑生活故事**（衔接 `teaching-loop.md` 第 3 节「无同构可撬则跳过、不硬凑类比」）；示例只用一个、做完整——宁可少讲半个概念，不可给半截示例；误区写「症状 + 原因」而不只写结论。
- 成品范例（供导师对照格式与密度，非讲义内容）：

  > **概念：解一元二次不等式（图像法）**
  > - 概念：解 ax^2+bx+c>0，本质是找「抛物线在 x 轴上方」的那段 x 范围。
  > - 类比：抛物线像一座拱桥，>0 就是桥面以上的部分。
  > - 完整示例：解 x^2−x−6>0。①目标：找 y=x^2−x−6 在 x 轴上方的 x 段。②分步：先解 x^2−x−6=0，十字相乘 (x−3)(x+2)=0 → x=3 或 x=−2；开口向上（a=1>0），两根之间 y<0、两根之外 y>0。③答案：x<−2 或 x>3。④易错点：忘判开口方向；把 >0 的解集写成两根之间（那是 <0 的）。⑤标准答案：解：由 x^2−x−6=0，十字相乘得 (x−3)(x+2)=0，解得 x_1=−2，x_2=3。∵抛物线 y=x^2−x−6 开口向上，与 x 轴交于 x=−2、x=3，∴原不等式的解集为 x<−2 或 x>3。
  > - 三句话小结：①先解对应方程；②看开口定内外；③解集用区间写全。
  > - 常见误区：Δ<0 时误以为无解——Δ<0 只说明无交点，开口向上时 >0 恒成立（解集为全体实数）。
  > - 自测：①解 x^2−4>0；②判断 x^2+2x+3>0 的解集。（附答案）

## 费曼卡

- 适用：抽象概念；用户复述总卡壳的小节；复习时重讲。
- 骨架：一句话大白话定义 → 为什么重要（1–2 句）→ 讲给 12 岁孩子听的版本 → 一个类比 → 反例（什么不是它）→ 自测（请用户不看卡复述）。
- 写作要点：**短而完整**——句句白话、紧凑，但不以字数截断（密度口径见「讲解文本密度原则」）；禁用行话，术语首次出现随即给白话替换。

## 考试冲刺卡

- 适用：备考型任务的考点小节；结课前总复习。
- 骨架：本节考点清单（按考频标注★）→ 高频题型与解题步骤模板 → 易错点（含扣分点提示）→ 秒杀技巧或口诀 → 3 道真题风格题（附详解，详解按标准答案格式写）。
- 写作要点：解题步骤写成「第一步/第二步」可照抄的形式；题目难度对齐用户的目标考试；不引入超纲内容。

## 对比辨析卡

- 适用：一对易混概念（触发信号：薄弱点出现「分不清 X 和 Y」）。
- 骨架：A/B 一句话定义并排 → 对照表（适用条件 / 典型场景 / 关键差异，≥3 行）→ 判别口诀 → 各一道辨析题（附答案与判定依据）。
- 写作要点：对照表先行；口诀 ≤2 句；两道题各埋一个「看起来像另一个」的陷阱。

## 操作手册式

- 适用：技能型任务（编程、工具、软件操作）。
- 骨架：本节目标（做完能做出什么）→ 环境与前置 → 分步操作（代码/命令可复制，逐行注释）→ 常见报错与修复（≥2 条）→ 练手任务（改错 / 仿写 / 微项目三选二）→ 完成检查清单。
- 写作要点：每步可独立验证并给出「成功标志」；报错条目写「报错原文特征 → 原因 → 修法」。

## 讲义概念单元 schema（所有风格共用）

讲义每个概念单元具备**可定位的必需槽位**：定义/规则、按需表示（类比 / 配图 / 对照表等）、完整示例或正反例、易错点、小结、检验问题。其他风格可重排槽位，但**不得漏槽位、不得删除必需信息**。

- **默认顺序**（标准讲义）：定义/规则 → 配图（按需）→ 完整示例（五要素，④易错一句带过，展开归「易错点」槽位）→ 易错点 → 小结 → 检验问题。类比不单设槽位，归入「按需表示」，有合适类比时才用（见「标准讲义」写作要点）。
- **分层标注（每概念单元出厂必须带）**：在概念单元起始处用方括号标签标注 **【本节最小必需】** 或 **【选学·后期必用（何时用/依赖哪节）】**；也可写在规划区对应概念行（表格列或列表行，纯文本即可），二者其一。选学标注须写明何时用到、依赖哪节；学员据此自行判断是否当前深学，不必等导师逐个说明。正文里只是提到「选学 / 最小必需」字样不算标注。
- **定稿边界**：定稿 = 判分记账零残留（状态行、伺服档位、检验作答记录、补讲台账留 progress.md 与题组文件，不进定稿；两态流转见 `phases-and-gates.md`「讲授机制」）。**`verify_explanation.py` 通过只表示「结构可定稿」，不等于状态转定稿**：状态行仍保持「草稿」，待小节闸口通过后再改为「定稿」。
- **讲义头部（两行，不复制规则正文）**：`- 状态：草稿（…）` 或 `- 状态：定稿（…）`；需要记录体例约定时只写一行指针 `- 体例约定（LaTeX 排版/标准答案框）：统一见 progress.md「质量保障机制」`。规则正文归任务侧 progress.md；在头部复制规则块会触发 `W-STYLE-POINTER`。
- **答案框紧邻**：⑤ 标记行之后只允许空行，紧邻的引用块即答案框；教材原题等其他引用内容放在 ⑤ 之前，不得插在标记与框之间。

## 交互式工作样例（所有风格共用）

复杂多步骤方法首次讲授时，先给**完整工作样例**（带完整解题过程与最终答案的示范，判据同「标准讲义·完整示例」五要素），再按需叠加三型互动形式：

- **自拟标签型**：工作样例按子目标分步呈现，**学员给每步自拟功能标签**（这一步在做什么，用学员自己的话命名）——不直接给标签，参考标签在样例末尾对照。
- **找错型**：样例中埋 1 处错误，请学员定位并修复。
- **重建型**：挖空样例的关键步，请学员补全重建。

- **强制触发（先示范后练习）**：学员起点 ∈ {零基础, 入门} 且本节含解题/操作型内容（计算、推导、代码、工具操作）→ 讲义骨架中的完整示例为**必选项**：先看完整示范再做练习，不得「讲完概念直接出题」。
- **选用规则**：首次接触的多步骤方法 → 先给**完整工作样例**（全部步骤 + 最终答案），互动三型只作其后的加固练习——①自拟标签型（学员给每步命名，参考标签在样例末尾对照）或③重建型**不得替代首次完整呈现**；该步骤属已预判易错点 → ②找错型（同样在完整样例之后）。
- **支架按「本项技能的表现证据」渐撤或恢复，不按出现次数硬撤**（T08）：同一方法第二次出现，若该学员**尚未表现出独立成功**，仍给所需范例；出现独立成功证据后再渐退到补全示例 / 独立题 / 迁移题。「第二次必撤样例」不成立——防样例依赖不能压倒新子技能的支架需求（决策规则见 `teaching-loop.md` 第 2 节）。
- **高起点跳样例（专长反转）**：仅当**本项技能**已有独立成功证据（该部分 S1 摸底全对或该技能伺服持续 >90%）→ 可跳过样例直接做题；**课程整体起点只作初始参考**（进阶者学全新子技能仍需示范）。样例支持随**本项技能**表现渐撤。**伺服「加难」只改出题难度，不减少讲义示范与细节密度。**
- 三型是通用教学结构，与学科无关；各学科族的具体素材差异见 `subject-playbooks.md`。样例本身落盘 `materials/`，沿用讲义两态（草稿/定稿）。

## 新记号/新操作讲透（所有风格共用，硬规则）

讲义或讲授中**每引入一个新记号、新公式、新操作**，当场给齐三件，少一件即不算讲完，不得等学员反馈再补讲：

1. **语义**：它是什么、怎么用（如「± 是一口气算两次：带 + 一次、带 − 一次，各得一个根」）——不把记号当自明；
2. **代入演示**：用一道学员已做对或最简单的例子完整代一遍，每个符号落到具体数值；
3. **易错点**：该记号/操作最常见的误用（如 −b 代入先翻符号）。

- **判据**：学员只看讲义、不听讲解，能复述该记号的用法并独立代入一次 = 讲透。
- **三件套独立成段**：首次引入的新记号/新操作段落，三件（语义＋代入演示＋易错点）**独立成段给出，不因篇幅压缩被合并或省略**（密度口径见「讲解文本密度原则」，必要内容不以字数截断）；伺服难度档位不改变本规则。

## 图像可视化双轨（所有风格共用）

讲义概念涉及**函数图像、几何图形、数轴/区间示意**时，默认双轨呈现，对话讲授场景下缺一不可：

**适用场景**：对话讲授轮与讲义定稿同时发生时执行双轨；纯文件交付（独立触发写讲义、批量生成）无对话轮可渲染，只执行落盘轨，并在交付说明标注「未做对话内渲染」；自检第 14 项按场景判定。

1. **对话内渲染**：讲解轮用前端 SVG 直接画出图形（学员当场可看、可追问；SVG 为纯静态图形——坐标系、曲线、标注，不含 script 与外部引用）；
2. **落盘存档**：SVG 源文件写入 `materials/assets/NN-<图名>.svg`（编号沿用材料契约），讲义 markdown 用图片语法引用该相对路径（相对 `materials/` 目录，如第 2 节第 1 图存为 `assets/02-01-抛物线三情形.svg`）——图进入复习链路，讲义复看、S4 复习、结课复盘均可再打开。**先落盘、后引用，同轮完成**，杜绝死链。

- **绘图前约束**：先声明图形类型——**定性示意图**（示意趋势/位置，不承诺比例，须标注「示意」）或**按比例图**（须与数值/比例一致）；只标**当前任务真正需要的点**，不为「完整」机械塞入无关要素（如解不等式的图**不必机械加入顶点**）。
- **绘图后核对**：核对关键坐标、开口方向、区间端点与讲义文字**一致**；**多面板图逐面板与讲义文字对应，禁止漏面板**（漏面板 = 内容缺失）；**图文不一致时以数学事实为准，先修图再继续**（不转成辩护，并同步修正讲义与存档）。
- **图的可判读规范**：有坐标轴、有标度示意、关键点标注（顶点/交点/渐近线/截距，限于当前任务所需）、曲线与辅助线用不同样式区分；一张图只讲一件事，不堆叠。
- **兜底链**：对话内渲染失败 → 讲义内嵌可复制的 SVG 源码（学员侧可自行打开）→ 文字描述图（末位兜底，向学员标注「降级为文字图」）。
- SVG 为纯文本：零第三方运行时依赖、可复制可修改、跨平台；不引入 matplotlib 等绘图库依赖。

## 出题零提示约束（所有风格共用）

出题时遵守「零提示」规则，防止题目本身泄漏答案或降低检索难度：

- **出题形态分界**：能从已有知识逻辑推导的内容，练成解题/应用题；无法推导、纯记忆的任意性内容（单词、常数、术语表）才做填空/背诵卡。判断标准一句话：**这条能否从别的东西推出来**——可推导内容做成死记卡是浪费检索练习，任意性内容硬出证明题是折磨学员。
- **不主动报答案**：题目与答案分离，先出题、等作答，批改阶段才给解析。
- **选项等长**：选择题选项在长度与结构上对称，避免最长的那个就是正确答案；干扰项 = 本节常见误区的具象化（与判定题「邻近情境干扰」同一取向），不用显然错的弱干扰。
- **防猜测选项**：选择题可含「我不确定」类选项，学员选它按未答（Again）处理——防 25% 猜对虚增闸口正确率，给低信心一个诚实出口。
- **格式不泄题**：不在题干里暗示答案（如「以下**错误**的**是**」的加粗位置、选项排序规律）。
- **变式真变**：递进题（基础 → 应用 → 变式）须换情境或逆问题，而非只改数字。
- **条件化出题（判定题）**：每个题组至少 1 道考「**何时用**」的判定题——给出场景问该用哪个知识点 / 给出信号问该触发什么方法 / 追问权衡（「方法 A 什么时候反而不如 B」）。只考「是什么」的题组默认不合格：掌握 = 会内容 + 会判定适用条件，二者缺一不可（条件化知识）。判定题的干扰项须是「邻近情境下才对」的方法，制造真实的判定张力，不用显然错的弱干扰项。
- **复习变式优先、原题按目标保留（T11）**：S3 热身、S4 复习、综合测验重试的题目**以变式为默认**（换措辞 / 换情境 / 反向问 / 迁移情境），与「变式真变」同一取向；但**不一律禁止原题**——按目标组合「**原题保持**（检验是否真记得这道）/ **近迁移** / **远迁移**」，需检验长期保持时可原样重问（同日两次正确 ≠ 长期保持）。
- **难度对齐**：题组难度对齐用户目标（考试对齐真题，兴趣对齐应用），不超纲、不降维羞辱。

## 应试技巧包（备考任务·冲刺期启用）

**启用时点**：备考型任务进入冲刺期（考点密集小节讲义改用「考试冲刺卡」起，至 S5 结课）开始执行本节；基础阶段与逐节学习前期不前置、不占轮次。五项均结合既有环节自然带出，不单独开课：

1. **时间预算**：按目标考试卷面结构给各题型定参考用时（有官方时长按官方，无则按题量估算并标注「估算」）；冲刺卡题组、S5 全真测验计时执行；单题超时先跳过标记、做完再回头。
2. **卡壳抢救**：教「解 → 设 → 列 → 能推几步推几步」的框架写法——把已知与目标摆上卷面就有关键步骤分，绝不空白；结合错题与模考复盘教，不空讲。
3. **检查策略**：交卷前预留固定检查时段（按时长定比例）；优先验算计算量大与踩过易错点的题——代回验算、符号与量纲快速核查。
4. **卷面管理**：草稿与解答分区，解答区只誊写标准答案（判据五要素之⑤）；写错单横线划掉续写，不涂团。
5. **考前一页纸**（S5 结课产出）：公式卡 + 高频易错点 Top 5 + 各题型用时表 + 考场流程清单（含卡壳抢救与检查时点）。

## 讲解出厂自检（四维度，所有风格共用）

讲授正文（对话讲授轮与讲义正文）在发出/定稿前按以下四维度自检，逐项编号，每项标 **E（阻断）/ W（警告）**。**按执行时点分级，不全量平铺**：

| 时点 | 必查项 | 可后置项 |
|---|---|---|
| 发出讲授轮 | 1、2（仅含量词时）、3、4、5、6（仅高风险外部事实）、11 | 7、8–10、12–15，以及 6 的完整四要素 |
| 讲义定稿 | 全部 15 项 | 无 |
| 相关内容修改后 | 受影响项 + 5（术语一致）、8（结构）、14（图） | 其余 |

**E 项命中 → 修复并重检该项，通过后才能发出/定稿**；**W 项命中 → 同轮修复或显式后置（注明原因），不阻断**。本自检是模型自检，不替代 `scripts/verify_explanation.py` 的静态校验（定稿前两者都跑）。

### 1. 准确性与可信度

1. （E）结论、条件/定义域、量词、单位、版本与边界逐条核对；**含量词的表述（所有/任意/存在/至少/当且仅当等）逐条标注量词归属**；
2. （E）含量词的定义或规则**出厂配齐正例 + 反例（或边界例）+ 代入/验证演示**；不适合举例时说明原因与替代核验方式；
3. （E）分类不完备时明示「只列代表类型、非完备分类 + 补全位置与时机」，本节检验题**不得考所列类外情形**；
4. （E）定义/定理/推导/经验/类比/课程约定可区分（类比不当定义、约定不当事实，见「事实、来源与不确定性」）；
5. （E）符号、术语与引用全节一致；
6. （E）外部来源学员侧可得并注明名称/年份/链接/核验日期；不可得则改为课程内约定并说明；无法核实的内容标出不确定性，**不编造来源**；
7. （E）计算、推导、代码或操作至少做一次独立核对（代回、量纲、边界样例、运行成功标志，按领域选用）。

### 2. 结构

8. （E）概念单元必需槽位齐全（见「讲义概念单元 schema」），五要素、新记号三件套、分层标注按内容适用性齐全，标准答案框体例合规（`verify_explanation.py` 覆盖静态部分）；**纯概念豁免②③⑤的单元，须有人工确认的正反例或等价表示（脚本不查，本项必查）**；
9. （E）示例与检验题不同题、非只改数字的重复；
10. （E）所选风格可重排槽位，但未删除必需信息。

### 3. 密度

11. （W）易错点单一出处、小结不引入新信息、无空转句；
12. （W）逐段做「删除测试」——删除后不损失目标、依据、边界或验证信息才删除；可选细节后置并显式标注。

### 4. 呈现

13. （W）公式符合 LaTeX 约定（见 `formula-typesetting.md`）；
14. （E）配图**逐面板与讲义文字对应，禁止漏面板**（漏面板 = 内容缺失）；坐标轴、标度与关键点按「图像可视化双轨」可判读规范执行；图文不一致时以数学事实为准先修图；
15. （W）代码/操作示例给出可复制的成功标志。
