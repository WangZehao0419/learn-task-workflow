# language 学科群 正本册

> 本册是「language」学科族的四类切片（plan / teach / practice / review）合一。

## 语言群 · 规划切片

### 群边界与借用

本群：外语（英语、日语等）的语音、词汇、语法、听说读写；母语文（语文）同属本群但走独立学科包——母语文的读写教学与二语习得是两套完全不同的路径，不能共用一个细则。

默认内容类型分布：记忆型（词汇、搭配、句型）最多，程序型（语法判别、翻译操作）次之，概念型（时态语义、语篇结构）再次。S2 按实际目清单核正。

**发音在纯文字会话中不作判分依据**，只作提示；需要听辨的任务要么接入音频能力，要么不声明该目标。

### 内容结构与前置链

- **外语纵向链**：音形对应 → 基本句骨架 → 时态与体 → 从句与非谓语 → 语篇衔接 → 文体与语域。
- **前置断层高发点**：词性判断（不会判词性就没法谈成分）、句子骨架（主谓宾找不出，后面全是猜）、助动词体系。
- **词汇分层**：高频核心词 → 学术／考试词 → 低频认读词。词汇目标用覆盖率定，不用考试词表定（见学科包）。
- **母语文纵向链**：识字与写字 → 词句 → 段落与篇章 → 文体阅读 → 鉴赏与写作。文言文是独立支线，先实词与句式再文意。

### 目标深度锚点

- **定档用四维而不是一个总分**：听说读写各定一档，取最低那维作为教学起点——总分高但某一维塌陷，教学就得从塌陷那维起。
- **词汇目标用覆盖率**：以「读懂某类材料需要多少词族」定目标，不以「背完某本词书」定目标。
- **语法目与写作目的合格线**：见 `references/disciplines/english.md`「验收形态」；本群只定「入门不是终点」，语言升级是下一层目标。
- **母语文阅读**：能定位信息 → 能整合推理 → 能评估可信度与处理冲突信息，三层分开验收。

### 排期侧重

- **词汇靠高频短接触**：每天固定一小段，不攒成周末大块。间隔重复是词汇的主机制，排期要为它留每日入口。
- **语法与产出交替**：一节讲语法、下一节必须有一次产出（说或写），否则语法会停在能判别、不能使用。
- **阅读材料按覆盖率选**：生词率超过约 5% 的材料不适合独立阅读，适合精读；低于约 5% 才适合泛读。
- **母语文的整本书阅读单独占周期**：不给它排进常规节内，按「方法指导＋阅读任务」跨周推进。
- **考前**：词汇与语法错题优先，写作按结构模板收口，不新开语法专题。

## 语言群 · 出题切片

### 题型阶梯

三阶梯，逐级递进，每节至少覆盖前两阶：

1. **机械操练**：替换、变换、变形——只练形态（watch → watches）。目的是把形式练到不假思索。
2. **意义操练**：给情境选形式（信号词判时态、语境选近义词）。目的是把形式与意义接上。
3. **产出**：造句、改错、翻译、仿写。目的是把形式用到表达里。

在此之上再分题型：**改错题**（埋一处真实错误，不是伪错误）→ **翻译题**（句内翻译优先于整段）→ **仿写题**（给结构换内容）→ **写作题**（按要点组织）。词汇题按「认读 → 辨义 → 搭配 → 产出」四层出，不直接上拼写默写。

### 群级共享误区库

只放**跨语言通用**的条目；三单漏 -s、时态信号词、冠词系统、非谓语挂错主语等外语专属条目见 `references/disciplines/english.md`，文言实词与阅读层问题见 `references/disciplines/chinese.md`。

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 逐词对译 | 按母语语序拼出句子 | 把语言当编码表 | 把译文回译一遍，看意思是否走样 |
| 只背单词不背搭配 | 单个词认识，组成短语就不对 | 词表以词为单位 | 问「这个词常和什么一起用」 |
| 只认不用 | 认读全对、产出写不出 | 只走输入 | 当节小产出逼出缺口 |
| 求难词不求准确 | 用大词但搭配错、语域错 | 「难＝高级」的错觉 | 换一个简单但准确的词，看是否更好 |
| 忽视可数性／单复数 | 抽象名词加复数、可数名词裸用 | 母语无对应范畴 | 先判可数不可数，再决定冠词与复数 |
| 只记规则不看例外 | 规则背得溜，固定搭配全错 | 规则比例外好记 | 每讲一条规则配一个例外 |
| 读的时候查每个词 | 阅读速度极慢、抓不住主旨 | 把阅读当翻译 | 先通读抓结构，再回头查关键生词 |
| 写作只堆模板 | 结构完整但内容空、错误雷同 | 模板见效快 | 要求每段至少一处与题目具体信息绑定 |

### 判定题构造

问「何时用」而不是「叫什么」：给信号词问选哪个时态、给两个近义词问在这个语境选哪个、给一句话问换成另一种说法意思变了什么。干扰项取上表具名误区——尤其是「母语直觉」类干扰，它才是最真实的诱饵。

### 答案形态与最小单元

- 外语：`Answer:` / `Model answer:` 起笔；翻译给 `参考译文：`；写作给 `范文：` 并附一句升格点；改错给改后整句 + 一句「为什么这么改」。
- 母语文：现代文给 `参考答案：` 按「观点＋文本证据＋术语」组织；作文给范文 + 一段升格说明。
- 最小单元＝**一个句子或一个意群**；译文按原句切，不整段合并；填空写清多空顺序。
- 答案框体例见 `references/handout-layout.md`「答案框体例（学科无关）」；同一框内按题号分段时，题号写在段首仍算交付起笔。

### 视觉任务

本群视觉任务少。确需声明时用原始材料（图表、广告、海报、漫画）并记录来源；替代禁令与证据资格见 `references/assessment.md`「视觉任务证据」。语音与口型类任务在纯文字会话中不声明。

### 给分点结构

翻译按「要点覆盖 / 语法正确 / 表达通顺」三段给分；写作按「内容要点 / 结构衔接 / 语言准确 / 语言丰富」四段给分；语法题按题计。

## 语言群 · 复习切片

### 复习形态与间隔侧重

- **词汇只延长间隔，永不删除**：进入保持复习的词汇条目一直留在队列里，间隔可以拉长，但不移出。词汇的遗忘是渐进的，删掉就等于放弃。
- **词汇复习用双向检索**：中→外与外→中都要测，只测一个方向会出现「认得但写不出」。
- **句型用产出式复习**：隔天用已学句型造两句新句，不抄例句。抄写是识别，造句是提取。
- **易混对成对出现**：borrow/lend、hear/listen 这类必须同框对比，单侧复习防不住混淆。
- **精读产出的生词自动进队列**：读文章时标出的生词，当场入复习队列，不另建词表。
- **朗读与复述作流利度练习**：流利度靠重复使用维持，不靠再讲一遍规则。

### 错因分流与纠错脚本

| 错因 | 判别信号 | 纠错动作 |
|---|---|---|
| 形式未记住 | 知道该用什么，但写错形态 | 该条进机械操练，做替换练习到自动化 |
| 意义映射错 | 形式对但选错（时态选错、近义词选错） | 补「形式标记什么意义差」的对比栏，做意义操练 |
| 母语迁移 | 语序、搭配带母语痕迹 | 做母语与目标语的对照，标出「这里不能直译」 |
| 词汇缺口 | 想表达但词不够 | 补搭配与语块，不孤立补单词 |
| 输出组织弱 | 句子对但连不成篇 | 练语篇骨架（主张—支撑—转折—结论），不从语法重学 |
| 审题偏差 | 写偏要点、漏信息 | 审题圈要点，写完回查要点勾选 |

**纠错话术**：外语的错优先用提示式（「这里的主语是单数还是复数？」），让学员自己改；直接给正确答案会跳过检索过程。连续两次同类错误才改为直接讲解。

### 冲刺侧重（方法层）

- **词汇与语法错题优先**：冲刺期不再扩新词，只清错题清单与高频词。
- **写作按结构收口**：准备两到三套结构模板 + 每段的功能句，但每次批改都要指出模板之外的个性化错误；模板句不算「已掌握的语言能力」。
- **阅读限时**：精读转泛读节奏，练「先看题干定位再读」的考场读法。
- **翻译练句子切分**：先断句、再逐块译、最后按目标语重排，不要整段硬翻。
- **考前不背新词表**：最后一晚只看错题与模板，睡眠计入计划。

## 语言群 · 讲授切片

### 讲授侧重（六拍内的群差异）

- **规则先行**：每个语法点先给一句可判定的规则 + 一个完整示范句，再进练习。显式语法教学在实证上稳定优于纯隐式——零基础学员缺「自己发现规律」的原材料，硬走归纳等于猜谜。归纳式只在学员主动要求探索、或规则一句话能说完时使用。
- **每节一个小产出收口**：三句小对话、一句翻译、一段改写——学了不用等于没学。产出闸按课程计划执行。
- **输入输出成对**：每个输入样例（读或听）配一个输出动作（说或写）；当节学当节用。
- **词汇高频优先**：例句词汇不高于学员当前档位；超纲词首现即括注，不假设「应该认识」。
- **零基础全程中文释义**：例句、信号词、题干、选项、词表一律配中文释义（整句翻译或括注），不拿「语感」当理解。
- **纠错用提示式，不用重述式**：给出重述（recast）虽最省事，但引发的自我修正率最低。默认用「这个动词的时态再看看？」这类提示，让学员自己改；只有流利度练习或学员明显受挫时改为直接重述。

### 语言学习的思维实践

1. **形式—意义映射**：每个语法形式都要回答「它标记什么意义差」——不是「这个时态叫什么」，而是「换成另一个时态，意思变了什么」。
2. **语域意识**：同一意思在不同场景（口语／书面／正式）用不同表达，教任何表达都要带一句「什么时候不合适」。
3. **语块优先**：先说完整的可用块（「I'd rather…」），再拆解规则；反过来拆完规则常常组不出自然句子。
4. **输入的可理解性**：精读求「每个词都清楚」，泛读求「整体能跟上」——两种读法的目标不同，不能互相替代。

### 表征体系

- **句骨架标记法**：主语／谓语／宾语／补语用固定记号（S/V/O/C 或加粗），全课程同一套。
- **对比栏**：易混结构用两栏对照（形式／意义／信号词／典型错误），不做成两段描述。
- **时间轴**：时态用一条轴标事件点、参考点、说话点，比文字定义直观。
- **语篇骨架图**：篇章用「主张—支撑—转折—结论」的结构图，不做逐句翻译。

### 类比库

- 语法＝交通规则：保证交流不撞车；不像处——语言规则例外多、随场景变，交规不会。
- 词汇＝车辆、流利度＝对路况的熟悉度；不像处——车可以借，词必须自己装进去。
- 时态＝相机拍的时间点：一般过去＝拍过去瞬间，现在完成＝过去动作冲印到今天；不像处——相机不能同时拍两个时间，完成时恰恰把两个时间连起来。
- 学员画像有类比领域时优先取该领域；没有合适类比就用定义 + 例句，不硬凑。

### 记号与术语纪律

语法术语（时态名、成分名、词性名）首现必须「定义 + 例子 + 代入演示」三件齐。族性术语（句子成分、时态体系、词性体系）首次触碰先给一页地图，且必须齐三样：族内全部名字、各支彼此关系、每支的判别标志——缺一样即判未给地图；地图级不作判分项，「标成分」这类题在地图给过之前不得出现。判据只用本节已教工具，不提前调用后续章节的术语。

### 标准流程示范

**语法判定**：看信号词／看语境 → 定成分与词性 → 套规则 → 写出形式 → 回读检查一致。示范时把「先看什么、为什么先看它」说出来。
**翻译**：通读原句定主干 → 拆修饰关系 → 逐块转译 → 按目标语语序重排 → 回读查漏。
**写作**：审题定要点 → 列提纲（每段一个功能）→ 成文 → 自查（时态一致、主谓一致、连接词）→ 升格（换更准确的词与句式）。
