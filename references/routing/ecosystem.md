## 生态分工与触发优先级

| 技能 | 性质 | 与本技能的关系 | 判据 |
|------|------|---------------|------|
| **独立教学工作区能力** | 宿主提供的独立教学工作区或等价教学能力 | **互补，不替代** | 用户主动调用该能力 → 让位；本技能管中文应试/材料场景与 markdown 进度流。二者勿为同一主题同时建档 |
| **文档生产能力（若宿主提供）** | 本地 Office 文档创建/编辑（docx / xlsx / pptx 等） | **相邻需划界** | 用户要**正式文档产品**（Word / 可打印 / 排版交付）→ 归它；本技能的讲义/题组是**学习用 markdown 材料**（落数据根）。「学习过程中的讲义 / 出题 / 组卷」归本技能，不重复开文档管道 |
| **scaffold-exercises** | 代码课程仓库脚手架（目录规范 + lint） | 相邻不同职 | 「建课程仓库/章节脚手架」归它；「给学习主题出题/组卷」归本技能 |
| **summarize** | 总结 URL/视频/文章/PDF | 只读参考 | 「总结材料」→ summarize；「用材料学一个主题」→ 本技能 |
| **research** | 主题研究并落盘文档 | 只读参考 | 「调研并写文档」→ research；「学会并跟踪一个主题」→ 本技能 |

**学习简报的边界**：简报是学习用 markdown（落数据根 `materials/`），不是正式 Word 报告；只报有据可查的数，缺失标「未记录/未测」，不估算；用户要 Word/可打印排版时归文档生产能力，本技能只提供 markdown 底稿。

**优先级原则**：用户显式点名某技能或宿主能力时，尊重用户选择；未点名而意图落在本技能职责内时，本技能优先，并在必要时用一句话说明为何不是另一能力。
