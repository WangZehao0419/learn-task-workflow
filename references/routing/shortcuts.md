## 快捷指令明细

- **问进度**（「我的学习进度」「学到哪了」）：读 progress.md 与课程体系.md **只读**汇报——当前阶段、节完成度、薄弱点与错题数量、下次续学点。**不推进阶段、不改任务数据**（`index.json` 属派生缓存、由脚本重建，不受「不改文件」限制；**task_index 默认即只读、不写缓存**，需物化时才加 `--write-index`）。
  - **覆盖口径**：汇报**必须含未讲条数与暂缓条数**（**未讲节数 = 课程体系节路线未勾选数；暂缓条数 = hold_count − excluded_count**），**不得只以节路线为分母报完成度**——路线可能缺节，覆盖缺口须脱离路线分母独立可见。
  - **目清单口径**：progress.md 记有课程体系指针时，一并**只读**汇报课程体系头部「覆盖摘要」行的目口径（如「目 未讲 a/总 M」，带口径标签），不改任何文件。
  - **可选掌握徽章行**：薄弱点/错题条目中带调度元数据者，按稳定度 S 分档标注（🟥 S<3 天 ｜ 🟨 3–13 天 ｜ 🟩 14–89 天 ｜ 🟦 ≥90 天 ｜ ⬜ 未测）——纯呈现层，从已有元数据读值即可，不改任何文件、不新算数据；学员未要求明细时一句带过。
  - **可选连击行**：从记忆.md 学习日志的日期序列推导**连续学习天数**（连续自然日有学习日志记录即计），呈现为「已连续 N 天有学习记录」；**断档不评判、不追责**，一句「断过 X 天，今天接上」即可——与徽章行同为纯呈现层，从既有数据推导，不改任何文件。
- **学习简报**（「学习简报」「学习周报」）：只读 progress.md 与 exercises/，生成 `materials/简报-<YYYY-MM-DD>.md`，含六项（本周节数与时长、正确率与独立性、薄弱点 Top3、错题 Top3、下周安排、下周优先解决的一件事）；**时长/正确率无记录时写「未记录/未测」，不估算、不补造**；不引用聊天原文、不自动发送、不改阶段。
- **考考我**：有进行中任务 → 按 `assessment/generation.md`「出题流水线」执行，针对薄弱点/错题/已学小节出题（等价插入一轮 S4 或当前节练习；**按 S4 等价动作执行时须同 S4 规则记录「复习来源阶段」并临时切「复习巩固」**，仅当轮热身则不改阶段）；**已完成任务 → 视同可复习对象**，按归档错题、复习清单与已学小节出题；无任何任务 → 先澄清主题与意图，不静默建目录（红线 SR-1）；澄清后确需独立出题，才在用户指定主题下建目录并落盘 `exercises/`。
- **帮我复习 X**：有进行中任务 → 进入 S4；**已完成任务 → 视同可复习对象**，按归档错题与复习清单出题，并记录「复习来源阶段=已完成」——**复习结束返回「已完成」，不撤销课程结果、不丢返回点**；无任何任务 → 先澄清（见近邻陷阱），不凭空建档。
- **已完成→复习→已完成**：已完成任务被复习时，「当前阶段」临时切「复习巩固」、`复习来源阶段` 记「已完成」；复习结束后**返回「已完成」**（不是退回逐节学习），结课结论、徽章与复习清单均保留。
- **已完成后再触发**：读取复习清单提示复习日；汇报结课结论与 1/7/30 节奏；**与条目级调度并存时，以条目级 due 为主、课程级清单为复盘提示，不重复报两套日期**；用户要求再学 → 按错题状态自动选路（见 `workflow/gates.md` S5）。
- **调整学习计划**（任务进行中）：重排后续节并更新排期（课程体系.md），向用户复述新计划；阶段不变。
  - **当前节锚定按稳定 ID 优先（F09）**：课程体系节路线行带 `（lesson_id=…）` 时记下当前节的 `lesson_id`，重排后在新路线中**按 ID 定位**并同步「当前节」序号（重排/改名后仍正确，不靠序号猜）；无 ID 时回退**按节名内容锚定**（重排前记下当前节名，重排后定位同名节；原节被移除时向用户确认去向）。
  - **调整边界**：用户主动发起「调整」即视为授权——仅重排后续小节可即时复述执行；若涉及**更换对照源或删改已确认的节结构**（整体重排），按不可逆动作走停即报告确认。
  - **跳过处置**（用户说「跳过 X / 我已经会 Y」）：被跳过节二选一——①**快速判定**：出 2 道确认题，全对 → 正常勾选并留判分记录（文件名沿用 `exercises/NN-<节名>-<日期>.md` 契约，文件内标注「快速判定」）；未全对 → 回炉或走 ②；②**移入暂缓**：写入「暂缓与范围外」（来源：用户要求，触发条件：用户要求），节路线中保留编号不勾选。禁止无证据勾选（CR-4）与静默消失（SR-7）。
