# 触发边界与入口路由

## 适用对象与前提

**目标用户画像**：需要成体系学一个主题、且愿意多轮投入的学习者——在校学生、考证/考研/任职备考者、需要啃下一本书或一套文档的职场人与终身学习者。用户已知自己「要学什么」，缺的是结构、纪律与反馈。

**前提**：

- 工作区可写（能创建「数据根」`<工作区根>/.learning/` 下的目录与文件）。
- 用户愿意多轮会话往返（本技能不是一次问答能完成的）。
- 用户愿意作答与复述（否则无法产生判分证据，闸口会卡住）。
- 有明确或可澄清的学习主题；主题缺失时先澄清，不猜、不凭空建档。

**明确不适用**：一次性知识问答、单题解题、代写、纯材料摘要、纯主题调研、课程仓库脚手架（后四者分别归 summarize / research / scaffold-exercises 等技能）。

## 该不该触发

### 正向信号（应触发）

用户表达「要系统学一个主题」并具备至少一项持续投入特征：要求建立进度、要求多轮推进、要求练习与反馈、给出期限或节奏、附带学习材料。

典型表述：「我要学 X」「教我 X」「带我读 X」「精读 X」「帮我啃 X」「从零开始学 X」「零基础学 X」「备考 X」「我要考研/考证」「家教模式」「开始上课」「继续学习」「接着上次继续学」「调整学习计划」「我的学习进度」；独立触发「给 X 写讲义」「给 X 出题」「组一套卷」。

### 负向信号（不应触发）

- 单题解题求助：「这道题怎么做」「帮我看看这个报错」→ 正常作答/归调试流程。
- 代写类：「帮我写作业/文章/报告」→ 不进入本工作流。
- 普通知识问答：「Python 的列表推导式是什么」→ 正常回答，可轻量提示「说『教我 X』可系统学」。
- 单点操作求助：「教我怎么用 Excel 做数据透视表」→ 一次操作指导；仅当用户表达系统学意愿再转 S0。
- 只要建议 / 只要计划：走轻量出口 b / c，不建陪学流程。
- 材料摘要、主题调研、课程脚手架：归对应技能（见下文分工表）。

### 近邻陷阱（重点防过度触发）

高频词「复习」「考考我」「出题」「计划」在日常语境里并不指向学习任务。**触发前先做上下文校验**：该词是否指向一个学习主题，或是否已存在进行中的学习任务？二者皆否 → 不触发，先澄清。

| 用户输入 | 正确处理 | 为什么 |
|----------|---------|--------|
| 「帮我复习一下这份合同的要点」 | **不触发**（文档回顾语义） | 「复习」未指向学习任务，属文档要点回顾 |
| 「我快考试了，帮我复习一下」（无任务、无范围） | 先追问范围与是否已有任务，再决定独立出题 | 主题缺失，不得凭空建档 |
| 「帮我出几道题巩固下我刚学的」（无任务） | 澄清「独立出题」还是「开新任务」，不静默建目录 | 避免产生无主题孤立目录 |
| 「帮我看看我的学习计划合不合理」（无任务） | 给建议，不建档 | 只要建议 |
| 「帮我准备一下面试回答」 | 正常协助，不进陪学建档 | 超出陪学职责 |

## 入口路由判别决策树（a–f）

按序判定，命中即停。判定依据是**硬信号**，不是措辞感觉。

**硬信号清单**：① 是否指名一个可学的主题；② 是否表达多轮/持续意愿（「系统」「带我」「从零开始」「继续」）；③ 是否要求建立或更新进度；④ 是否要求练习/反馈/批改；⑤ 是否附带材料；⑥ 是否已有进行中的任务。

| 分支 | 判据（硬信号） | 动作 |
|------|---------------|------|
| **a 不进入** | 单题求助，或代写请求 | 正常作答/拒绝代写，不建档 |
| **b 轻量出口·建议** | 只问「怎么学」，无多轮意愿、不要求建进度、不要求练习 | 直接给建议，不建档；建议可含两层判断——**值不值得学**（要解决的具体问题是什么 / 现有知识能否搞定 / 只学最小够用的一节）与**怎么学**；末尾提示「说『教我 X』可开始系统学」 |
| **c 轻量出口·计划** | 明确只要一份计划/时间表，不要求陪学与练习 | **不建 progress.md、不进陪学流程**：建 `<slug>/materials/`（slug 按「主题-计划」生成，只放产物）并落盘 `计划-<主题>.md`（含排期、首节建议）；文档内注明「待开课」（**文档标记，不写入阶段字段**——阶段枚举无此值）；后续就该主题正式建档时沿用同 slug 目录写 progress.md，二者不冲突 |
| **d 独立触发** | 只要求写讲义/出题/组卷，不要求诊断与陪学 | 生成并落盘 `materials/` 或 `exercises/`，不进家教流程。讲义按 `handout/pipeline.md` 的生成流水线、类型、支持级与决策日志执行；无画像时写读者假设 + 前置自检，不打个性化标签；L3 可产出检索版要点卡；来源映射/覆盖行/深度分配按 `handout/pipeline.md`，无 progress.md 时覆盖行是唯一记录。教材/整章 → 章首路线图 + 章末混合检索；P1/P2 均为可选，不新增闸口。**无同主题任务时**：在数据根下建 `<slug>/materials/` 或 `<slug>/exercises/`，**不建 progress.md**——task_index 只认 progress.md，该目录不会被枚举为任务；后续正式建档时沿用同 slug 目录写 progress.md；落盘后向用户说明该目录是产物目录、尚未建档。**独立讲义仍须真人冷读四证后才能定稿；没有真人冷读时停在草稿并停止当前运行，不以「结构通过、未验证」作为最终交付。** |
| **e 快捷指令** | 命中问进度/考考我/帮我复习/已完成后再触发/调整计划 | 按对应快捷指令处理（含无任务分支），见「快捷指令明细」 |
| **f 系统学习** | 有可学主题 + 至少一项持续特征（②③④⑤之一）且非 a–e | 进入 S0 建档；**已有明确活动任务时**（如 e 类已定位到某任务、或上一轮刚在本任务内）**直接定位该任务继续**，不重复全量枚举、不新建目录 |

**数据访问条件（F05）**：**只有需恢复现场或做新建冲突检查时（f 类，或 e 类指向既有任务）才枚举学习数据**。a–d 与「技能审阅」等无陪学意图的请求**不建学习档、不枚举数据根**；任务进行中的单题求助（已有活动任务上下文）**直接用当前上下文作答**，不另建目录、不启动建档问卷。枚举与匹配规则见 `data/layout.md`「数据根」。

**关键裁决**：「X 怎么学」一律走 **b**（只要建议），**不进入建档**——它既不是列在触发词里的系统学习意图，也不满足任何持续特征。若该句后紧跟「带我学/从零开始」等持续信号，则升为 **f**。

**非 a–f 归入值说明**：语义桥中的「恢复（继续学习/接着上次继续学）」「收尾（下课/结束学习）」「调整（太慢了/跳过 X/调整计划）」**不属 a–f 分支**——「恢复」由 `workflow/gates.md` 的入场自检与 `data/layout.md` 的枚举/匹配处理，「收尾」由 `workflow/gates.md` 的节末/结课收尾与 `ops/failure.md` 的阻断规则处理；「调整」见`teaching/lesson-flow.md`「快捷指令明细」。a–f 只承载「是否进入最简陪学流程」的判定。

## 语义桥（短语 → 分支/动作 精确映射）

下表是执行阶段的强制对照表。**禁止绕过本表凭措辞硬编码判断**——不确定时查表，仍不确定就问用户。

| 用户短语（示例） | 归入 | 目标动作 | 备注 |
|------------------|------|----------|------|
| 我要学 X / 教我 X / 带我学 X / 从零开始学 X | f | 进入 S0 建档 | 主题明确 + 持续意愿 |
| 备考 X / 我要考研 / 我要考证 | f | 进入 S0，识别为**备考型** | S2 倒排排期 |
| 家教模式 / 开始上课 | f | 进入 S0 建档 | 与正向信号清单对齐（口语开课指令） |
| 带我读 X / 精读 X / 帮我啃 X | f | 进入 S0，识别为**材料型** | 沿用材料目录 |
| X 怎么学 | b | 只给建议，不建档 | 若后接持续信号 → f |
| 帮我排个学习计划就行 | c | 轻量建档，只问主题与期限 | 注明「待开课」 |
| 给我写一份《X》讲义 | d | 独立生成讲义 → `materials/` | 有同主题任务则并入 |
| 帮我出一套 X 的卷子 | d | 独立组卷 → `exercises/` | 同上 |
| 继续学习 / 接着上次继续学 | 恢复 | 先枚举数据根 → 命中则续学，未命中则 S0 | **不得覆盖** |
| 我的学习进度 / 学到哪了 | 快捷指令 | 只读汇报，不推进、不改文件 | 见「快捷指令明细」 |
| 学习简报 / 学习周报 | 快捷指令 | 只读 progress.md 与 exercises/，生成 `materials/简报-<日期>.md`；不推进阶段、不自动发送 | 同上 |
| 考考我 | 快捷指令 | 有任务→针对薄弱点/错题出题；无任务→先澄清 | 不得凭空建目录 |
| 帮我复习 X | 快捷指令 | 有任务→进入 S4；无任务→先澄清 | 见近邻陷阱 |
| 太慢了 / 跳过 X / 我已经会 Y / 改一下计划 | 调整 | 重排后续小节并复述，阶段不变；跳过/声称已会的小节按二选一处置（快速判定 / 移入暂缓） | 见「快捷指令明细」 |
| 下课 / 结束学习 / 退出家教模式 | 收尾 | 先落盘再退出 | 见 `workflow/gates.md` 交接与 `ops/failure.md` 阻断规则 |
