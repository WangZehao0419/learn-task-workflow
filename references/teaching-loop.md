# 教学决策环（teaching-loop）

本分册是「**每节怎么教**」的**决策唯一事实源**：备课定目标、选支架、提问与提示、反馈与纠错、按证据撤支架、复述与输出、判分口径、错因补救。

**边界**：阶段进入/退出、闸口与落盘证据、调度命令、覆盖率审计、结课与复习流程仍以 `phases-and-gates.md` 为唯一事实源；讲义与讲授产出纪律（对话讲授契约 / 文本密度 / 出厂自检）见 `lecture-styles.md`；学科素材见 `subject-playbooks.md`；公式、方程式和科学符号的呈现与降级见 `formula-typesetting.md`。本册只回答「教学决策怎么选」。

## 1. 备课短表：先定本次能力，再决定讲什么（T01）

备课前先读 `progress.md` 的 `本次交接` 与最近 `学习记录`（最多 7 条）：上一次留下什么、这次先做什么、哪些方法已被判低效；没有这二区就跳过，不强制。每节备课用一张短表表达，**不要求每个知识点都新增一套长字段**：

| 项目 | 要回答的问题 |
|---|---|
| 本次目标 | 学完能独立完成什么 |
| 必需先修 | 缺少它是否无法完成当前目标（**只用它约束排序**） |
| 核心方法 | 当前最小充分路径是什么 |
| 辅助表示/校验 | 哪些内容能帮助但不必逐题使用 |
| 后续或独立目标 | 哪些内容另有用途、何时学 |
| 本节深讲概念 | 哪一个概念做完整深讲（最多 1 个）；哪些是工作/参照；若 >1 项关键能力需完整深讲则拆节 |
| 关键能力质检 | 每项关键能力是否至少覆盖“判别 D + 边界 B” |

- 依赖边只用「必需先修」约束排序；「帮助理解」与「后续迁移」保留为**关联**，不把整个知识网络都变成前置闸口。课程地图保留整体范围，当前教学按本节任务展开。
- **讲义生成**：按 `handout-design.md` §3 的设计六问/四段支架/二次定稿，以及 §4–§8 的类型矩阵/四步流水线/支持级/学习者状态/决策日志；本短表只定教学决策，不替代讲义合同。
- **先回答「为什么现在学」**——不用远期价值或独立考点替代当前必要性；只有确实构成本节目标的前置才列为「必需先修」。

### 1.1 课首定位（每节第一次讲授前，2–3 句 + 块清单一行一块，计讲授不计新轮）

先说清**本次能力**——「本节学完你能独立完成什么」（本次目标）→ 达成它所需的**最小充分方法**与**必需先修** → 再点「本节在整条路线中的位置」（前面学过的哪块是地基、它给后面哪几节铺路）；**公示本节块清单与预计课时**（块名 + 顺序 + 总数 + 预计课时，一行一个最细知识点；只列名称、不展开讲解；不按场/段分组；块不设时间上限，不按块数拆节）；末尾半句回扣学习目标（「本节直接服务你的——」引 S0 记录的应试/求职/兴趣动机）。与节末对账（第 5 件）构成「前瞻—回看」闭环。

**与讲授契约「定位」的分工**：本节第一次讲授做本节的课首定位（一次，覆盖整节路线）；同一节内后续块只做一句**块级锚定**（接上一个概念或已确证旧知 + 本轮目标），不重复整节课首定位。

### 1.2 教学质疑与纠错分支（「为什么学这个」「这步能省吗」「你画错了」「这样讲太绕」都是**有效教学输入**，非跑题）

① 先核对用户指出的事实或必要性；② 对照本次目标与已有材料，区分「当前必需 / 独立目标 / 辅助作用」；③ 给出正确且足够的当前方法，**有错误时先纠正文字、图与存档**（不只加一段解释）；④ 说明具体安排变更（范围实质改变且用户未授权时才确认）；⑤ 恢复原待学位置或待答题，**不重开课程**。涉及用户已指出导师错误的：必要时重判受影响作答。

### 1.3 来源备课与讲授证据（v6.2）

- **先备来源包**：讲授前准备最小来源包——精确页码/章节/链接 + 原文/图，只取本次要讲的范围；不把整本书倒给学员，也不凭记忆补细节。**它不等于 `materials/00-备课来源.md` 的备料台账**：台账是“有哪些来源”的清单，来源包是“这次讲哪几段原文/哪张图”的最小证据。
- **讲义来源映射**：讲义单元/示例按 `handout-design.md` §9 记来源锚点、原创/改编与覆盖行；来源包是输入，不把整本书倒给学员，也不把来源原文当“已讲”。
- **只教覆盖范围**：来源包覆盖到哪讲到哪；来源缺失、矛盾或读不到时如实说明，必要时做一次定向补查；不编造、不把来源原文当“已讲”。
- **视觉任务取原始来源**：KP 声明视觉任务时，来源包必须包含原始图/表/截图/数据（页码/图号/数据位置）；讲义生成的 SVG/示意图只用于讲解，不能当作视觉任务的原始证据；原图不可用时，新任务不要声明该视觉任务；已声明的按 `未判` 处理或补齐来源，不删改字段绕闸。
- **讲完记证据（可选）**：向学员公开讲完后，可在 `## 讲授证据` 记一行：KP/概念、**已讲内容的逐字引用（≤80 字）**、来源锚点、日期。计划、内部思考、工具结果、来源原文都不算证据。
- **讲授 ≠ 掌握**：这条证据只证明“讲过”，不证明“学会”；掌握仍看判分、复述与关键能力闸口。

### 1.4 纠错闭环（学员指出或自查发现错误时）

当学员指出或模型自查发现讲解、图、公式、参考答案存在错误时，**在继续教学前**明确三件事：①错误是什么；②影响范围（哪些结论 / 配图 / 判分记录 / 存档内容受牵连）；③修正内容。随后**同步修改**讲义、图、存档及**受影响的判分证据**（错判的题按更正结论重判并留痕），重新运行适用的静态校验（如 `scripts/verify_explanation.py`）与 `lecture-styles.md`「讲解出厂自检」相关维度，并在学习日志**保留纠错留痕**（原结论 → 修正内容 → 日期）。**不得静默改写，不得继续引用旧结论**。定稿讲义的态流转按 `phases-and-gates.md`「讲授机制」执行：先改回草稿（修订中），修完重跑校验与自检再定稿。

## 2. 支架选择与渐撤（按证据，T08）

- 首次接触复杂方法 / 缺事实 → 给**完整、做透**的示范（worked example），不挖空。
- 已会一部分 → 问一个**有诊断价值**的问题，补实际缺口。
- 有**独立成功证据** → 从完整示例渐退到补全示例、独立题、迁移题。
- **同一子技能第二次仍不会 → 继续给需要的支架**，不按「出现次数」硬撤（撤的是「本项技能的表现证据」，不是课程整体起点）。
- 学员明确要求直接讲 → 直接讲清，再给独立练习验证机会。
- 新内容没有合适类比 → 用准确的定义、实例或图示，**不强凑**生活故事。
- **专长反转**：跳范例只看**本项技能**的独立成功证据（S1 对应部分全对或伺服持续 >90%）；课程整体起点只作初始参考；完整判据与例外见 `lecture-styles.md`「高起点跳样例」。

### 2.1 教学姿态三档（S2 选定，默认混合）

- **A 引导型**：多提问、少直给；适合兴趣/深度理解。学员说「直接讲」→ 当轮切 B，不追问理由。
- **B 直讲型**：先给完整示例/模板/参考答案 → 反推关键步 → 独立重做；适合赶考/时间紧/连续卡壳。**直讲不等于代做**：复述与判分证据不省。
- **C 混合（默认）**：关键处先示范，再提问与练习。
- **自动切 B**（满足任一）：距考试 ≤4 周；学员说「时间紧/只要过关/先应付考试」；同节连续 2 题 Again 或触发熔断。
- **不变量**：正确性 ≥2/3、关键能力独立通过、复述通过三条底线不变；姿态只改讲授顺序与提问密度，不改验收。
- **记录**：学习日志一句 `姿态：A/B/混合（依据：…）`；不新增字段。

### 2.2 教学策略（先测后教 / 先教后测，与姿态正交）

- **先测后教（默认）**：新 KP 先给 1 个诊断探针或前置检查，再决定讲多少；答对可压缩，答错定位缺口。已有 S1 摸底证据的，不重复摸底。**零基础/首次接触解题或操作型内容时，`lecture-styles.md` 的「示范先行」仍优先**——探针只用于定位起点，不替代完整 worked example，也不作为判分证据。
- **先教后测**：先完整示范/讲解，再给检查题；适合零基础、认知负荷高或学员明确要求。**不改变**小节闸口（正确性/关键能力/复述），也不取消检查。
- **策略以单个块为单位**：先测后教/先教后测都作用于当前块，不得扩成「整节先讲完再统一测」；策略只改「先探针还是先讲」，不改变逐块推进，也不把多个知识点合并进一块。
- 策略来自 `progress.md` 的 `教学策略` 字段；缺失按先测后教。策略只改“先探针还是先讲”，姿态 A/B/C 只改“引导/直讲/混合”，二者不互相替代。
- **目标程度决定停点**：读到 `目标程度` 时，按它判断本模块/本节教到哪里收束；达到学员说的“够了”即可，不把完整学科当成默认目标。未记录时按原目标线与课程计划执行。

### 2.3 节奏契约（默认）

- **节层**：开节前列块清单与预计课时；节内块数不设上限，块 = 最细知识点，教材节不按块数/时长拆。任何审计/追加知识点只加块，不静默重排节号。课首公示「本节 X 块 + 预计课时」。
- **块层**：1 块 = 1 个最细知识点（1 道题能独立检验；需 2 道题 → 拆块）；不设时间上限。**任何新记号/新定义块先做 30–60 秒前置探针**，工具/预备/衔接节 2–3 分钟，缺地基先补。每块讲完给 1 次可判定检验：关键块正式判分（不设每节道数上限），简单块用可判定的轻量问题（不得只问「懂了吗」）；**独立答对才进下一块**。
- **消息层**：无硬字数上限、必要推导完整；单块内容偏多时先查可选内容后置，不按阅读时间拆块（只有含两个独立知识点才拆）；简单事实/纯记忆可用 ~300 字作软提示。**300 字不是单轮预算或拆块依据**；不得据此截断推导或拆散完整示例。
- **确认 ≠ 掌握**：确认只控制推进，不写掌握、不翻转清单状态、不替代小节闸口。
- **姿态/策略不改变节奏**：A/B/C 与先测后教/先教后测都只改引导密度与顺序，不得把多个块合并成一整节输出；学员明确要求加速时只压缩单块讲法，不合并知识点。

## 3. 课首与旧知锚定

- **跨界三猜想前置**（讲授新概念的第一个动作）：讲新概念先**撬旧知**——①**换名字**：它是否就是学员已会的某概念**换了领域名称且语义确实等价**？命中可直接说「你已经会了，它只是改名叫 X」——**但仅在真等价时**：凡存在定义域/维度/适用条件差异的（如**导数→梯度**：一元导数与多元梯度不等价，梯度由偏导数组成的向量、含方向与维数语义），**禁止**按无条件同义词讲授，必须说明多元扩展与关键差异；不确定是否等价时走②或直接讲授。②**结构同构**：与学员已会的某知识做字段级对应（A↔a、B↔b），**明确标出哪里相同、哪里不同**；③**旧知解释**：用学员已掌握的知识把新概念讲通。开场或收尾给一句「你已经会了 ___ 部分，真正全新要学的只有 ___」。
  - **确证铁律**：判断「学员已会什么」只能用**确证证据**（S1 摸底判分记录 / 学员亲口确认 / 学习者画像第②层稳定模式），**严禁**把「材料作者的背景 / 对话里别人的知识 / 学员没否认」当成学员会的；拿不准 → 先问一句「你学过 ___ 吗」。无同构可撬（全新领域第一课）→ 跳过本步直接讲授，不硬凑类比。
- **备课查阅**：讲授与出题前按学科族查阅 `subject-playbooks.md`（本会话已读过则不重复读；该分册只补学科素材与侧重差异，教学流程以本册为准，示范规则以 `lecture-styles.md` 为准）。

## 4. 提问与提示起点（T06）

- **提示阶梯**：5 级 = ①再试一次 → ②指错位 → ③概念提示 → ④引导式问题 → 梯⑤答案+缘由（梯内 ②–④ 属非答案级提示）。每次只降一梯，禁止跳梯、禁止不经阶梯直接给答案。**按错误类型选起点（见下条）不算跳梯；跳梯仅指同一路径内越过中间梯级。**
- **提示起点按错误类型与先验选，不固定从①开始**：缺事实 → **直接补事实**（跳阶梯）；概念混淆 → 从**③概念提示**；计算/审题失误 → 从**②指错位**。**每次提示给可执行线索**（指到具体行/步/条件），不得只给「再想想」。
- **卡壳协议**：练习中求助且未附尝试 → 先问「你写到哪一步了？卡在哪？」；完全没动笔且非零基础首次 → 请先写 1 步（30–60 秒），再给提示。学员明确要求讲解/示范 → **不适用本协议，直接讲**；零基础 + 首次 → **豁免，按「示范先行」直接给完整示例**（不要求先写一步）。话术：「不是考你，是让我知道你卡在哪，好给准提示。」
- **不知道问什么时（ask hint，v6.2）**：学员说「不知道问什么 / 没思路 / 你问我吧」且确实卡住时，给 **1 个他此刻可以问的问题**，不是答案。**≤25 个汉字、第一人称、以问号结尾、不重复上一条已答内容**；优先区别、为什么、边界情况、「如果……会怎样」；避免是非题和对话里已经给过的定义。若这句话把答案讲出来了，就是错的，重写。例：「为什么这个式子不能直接开方？」；反例：「这里应该先配方，对吧？」（把答案说了）。它是脚手架，不是每轮必给；正常苏格拉底提问优先。
- **提示泄漏三判据**（引导/混合档）：提示不得含 ① 最终答案/最终数值/最终结论；② 可照抄的完整解答或可运行代码；③ 只剩代入的完整中间式。允许：指错位、条件提醒、概念提示、引导问题、反例、检查清单。
- **降梯触发**：同一题同一梯连续 2 次无效 → 降一梯；学员明确说「直接讲」→ 转 B 档，不算降梯。
- **发前自检**：「删掉这句，他还能不能自己走到答案？」不能 → 重写。
- **B 档例外**：直讲档可直接给完整答案/模板；泄漏三判据不适用于 B 档，但复述与判分不省。
- **新手加速豁免**：学员起点 ∈ {零基础, 入门} 且该知识点为**首次学习**（非复习、非错题重练）时，首次答错可 ②③ 同轮给出；连续第 2 次答错直接走梯⑤「答案+缘由」，**同轮补一道同型变式**请学员独立完成（梯⑤按 Again 记分不变；变式作为新的一条独立判分，做对计 Good）。
- **苏格拉底边界**（阶梯不适用的情形）：①**缺事实** → 直接给事实，再回到推导；②**明确要求讲解/示范**（「你直接讲 / 告诉我答案」用于把概念/方法讲清）→ **直接讲**（给完整 worked example 与完整解析），**不走「引导失败才给答案」那套**；只有用户要求**替其产出受评作业**时才先引导、坚持才给答案（见 SKILL.md「不代劳 vs 直接讲解」）；③**精力耗尽** → 接一把。判断标准一句话：**这个内容他自己能不能推出来**——能推则引导（走阶梯），不能推（缺事实）或**本人要求直讲**则直接给，能推但很慢则看精力。
- **同一卡两次走到第 5 梯 → 标「顽固」**，转入换角度重教而非重测。
- **熔断条（情绪/连错保险丝，优先级高于提示阶梯与闸口节奏）**：触发器任一即熔断——①学员明示负向语句（「不想学了 / 太难了 / 我是不是很笨」类）；②同节内**连续 2 题判 Again**（行为信号）。熔断后本轮不继续出题，从教学八动作中选一执行（换角度重讲 / 降档 / 简化表述），或直接收尾「今天到这，下次从这开始」；**归因重构话术原则**——把卡壳归因于策略与状态等可变因素，禁止空泛安慰（「你很聪明」）与能力评判。恢复信号：学员主动要求继续，或完成一次低难度成功作答，再回到阶梯。（课程级回退见 `data-and-recovery.md` 异常分支，本条只管节内即时修复。）

## 5. 反馈策略（T09）

- 作答后**先给清楚结论**（对/错 + 一句为什么），再按需要补关键依据。
- **按对错分流**：答错 → 作答轮内**即时**判分、指错位、析错因（答案级内容仍走提示阶梯，不直给——纠错趁热、给答案渐进）；答对 → 可延迟到节末批量一句确认；**答对但信心 ≤3（反馈前已提交）→ 即时确认并给解析**。
- **延迟反馈限明确场景**：批量练习 / 模考可统一延后到节末或交卷后；**单题、低信心、首次接触新方法 → 即时确认**。不得把「延迟确认」当绝对规则套用到所有作答。
- 反馈按三问组织——①我要去哪（对照本节目标）②我进行得如何（判分证据 + 伺服档位依据）③下一步去哪（从**教学八动作**选定）——只落**任务层 / 过程层 / 自我调节层**；**禁用自我层空泛表扬**（「你真聪明/真棒」），改**过程性表扬**（策略选择 / 努力投入 / 相对上次的进步归因）。

## 6. 判分口径与信心时序（T02/T03）

**判分三维 + 调度档位**（闸口正确性与调度 grade **分离**，避免「慢=半分」把独立性/流畅度混进正确性）：

- **正确性（四态）**：`对 / 部分 / 错 / 未判`。`对` 计入闸口分子与分母；`部分` 计入分母、不计入分子（未达完整正确，按缺失点归因并进薄弱点；如需保留原题再进错题本并标 `结果=部分`，调度档用 Again）；`错` 计入分母；`未判` 不计入分母、不写 S/D、不进错题本——它表示答案键/输入/来源不足以判，不是「错」。**作废**行只保留审计，不计入闸口/S/D，不删除原判分行。
- **独立性**：独立完成 / 经提示②–④（非答案级）后完成 / 经梯⑤获答案后才理解（**给答案不算答对**，计 0）；
- **流畅度**：快速（无停顿、无试错）/ 常规 / 明显卡顿·试错；**时间/过程不可观测时记「未测」**，不猜、不折半。
- **调度档位（仅用于 scheduler 算 S'/D'，不折算闸口正确性）**：Easy=独立且快速答对；Good=独立答对（常规节奏）；Hard=经提示②–④后答对 / 明显卡顿试错后答对；Again=未答对 / 梯⑤给答案后才理解。

| 参数 | 取值 |
|---|---|
| 滚动窗口 | 最近 **~7 题**正确率（按**正确性**计：独立正确与提示后正确均计 1，Again/给答案计 0） |
| 计分 | 正确性驱动：正确=1，未答对=0；**Hard 不再记半分** |
| \>90% | 加难（去提示 / 迁移题 / 双概念综合） |
| 70–90% | 保持 |
| <70% | 降难（缩 chunk / 给示例 / 降为选择题） |
| 落盘 | 伺服判定结论（档位 + 依据 + **样本数**）随判分记录落盘；报「正确 x/样本 n 题」，**n < 5 时标注「样本过小，档位仅供参考」** |

**统计口径**：正式推进确认题随 `## 作答与判分` 的 attempt 进入正确性分母；轻量确认不计入分母；难度伺服以题组 attempt 为主，正式确认只作即时教学信号，不单独改变档位（见 2.3）。

难度伺服 85% 目标为**启发式参数**（Wilson et al. 2019 仿真研究、Rosenshine 课堂 ~82% 呼应；边界见 `methodology.md`）。

**信心时序**：信心**可选**，学员可在**反馈前随作答一并提交**「当时几分把握（1–5）」——这是可用于 cw / 校准的**原信心**；若在批改反馈**之后**才补报，一律标注**回顾性**（postdiction），**不得据此推断其原先信心、不计入 cw、不计入信心校准**。（cw = 反馈前信心 ≥4 且判错；校准口径见 `data-and-recovery.md`「校准画像」）

## 7. 复述与输出证据（T07）

- **一份证据可复用**：teach-back 的复述已**覆盖 ≥2 个本节关键点且无事实性错误** → 即视为复述通过，**不再索要同义重复总结**。
- **深讲概念的深度验收**：节末除复述外，至少问一类「为什么/边界/对比」题（深讲概念建议三选二）；答不出 → 补对应层，不判学员。
- 节末输出**按本节目标选一种**（解释 / 独立操作 / 辨析 / 作品），**不强制逐节六选一轮换**；已产出充分证据者不必再产同一义证据。可选形态：①复述要点 ②类比解释 ③教给他人 ④动手练习 ⑤提问清单 ⑥场景迁移。
- **取消「装不懂」**：追问只在**真有疑点或需检验迁移**时进行，不为拖延而假追问；追问后仍以「覆盖 ≥2 关键点且无硬错」判定。

## 8. 批改机制

- **输入判读不预设预期**：判读学员输入（手写照片、OCR、复述转录）时**不按题干预期去读**；仅当指数、下标、正负号、分数线等关键字符**存在不确定性且可能影响判分**时，才将读到的题干与关键行向学员复述确认，确认无误再判分；已清晰且不影响结论的输入**不重复确认**（避免审问式负担）。学员更正输入时，**回滚**受影响的已写判分记录并留痕（记录更正日期与更正依据后按新判分重写）。
- **作废与申诉（v6.0）**：学员指出判分有误（答案键错、来源歧义、输入读错）时，先核对题目 ID、保存的作答、参考答案与来源；确认原判不成立 → 在原行标 `作废（原因，日期）`，**保留原行不删除**；需要改判时新增一行（可复用原 `attempt_id`，已作废行不参与冲突判定），并只按新行更新 S/D。若只是补判，原 `未判` 行改为新结果或另起一行，二者择一但不得同时作为有效证据。作废与未判都不算负面证据；申诉本身也不算掌握。全程在学习日志留一句纠错留痕。
- **归因定级**（判错收录错题时同轮完成）：见第 9 节错因分类；**定级**——A=反复出错 / 直接影响学习目标达成的核心条目，B=一般理解偏差，C=纯粗心；含凭猜测答对但不会解释的题照常收录并如实定级；**所有类型任务的错题均分级**，写入元数据段 `级=`。
- **教学八动作**（「下一步去哪」的完整选项集）：**推进**（达标，进下一概念/小节）｜**迁移验证**（答对但首次应用，换陌生情境再测一次）｜**压缩已熟**（连续轻松答对，讲义压缩为要点卡，提速）｜**换角度重讲**（理解性卡壳，换类比/换讲义风格重讲；风格映射见 `lecture-styles.md` 开头「卡壳信号 → 换哪套」）｜**降档**（过载，缩 chunk/给示例/降为选择题）｜**补练**（技巧性失误，同类变式专项）｜**回拉复习**（旧前置遗忘，插一轮热身/回退前置小节）｜**简化表述**（不是不会而是没听懂人话，用更朴素语言重说一遍）。组合规则见 `phases-and-gates.md`「机制关系表」。
- **主观题批改纪律**（问答/论述/作文类题面）：**接受语义等价表达**——学员用自己的话说对了意思即给分，不因措辞与参考答案不同重复扣分；**每个得分点关联学员作答中的对应证据**（引其原句或指出缺失位置）；无官方评分细则时**明示「本次按训练量表判分，非官方标准」**；未知官方扣分规则不得编造。批改对象是作答不是人——只判对错与差距，不作能力评价。
- **答案与解析格式**：批改中凡给出解析的时机，解题/计算/操作/论述/翻译类一律以**答案框格式**呈现（从交付起笔到结论/产物的完整可复现答案，不排斥等价解法；交付标识按学科族取 `解：`/`解答：`/`证明：`/`答：`/`参考答案：`/`答案：`/`参考概括：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`代码：`/`输出：`/`方案：`/`设计说明：`/`Answer:`/`Solution:`/`Proof:`/`Model answer:`/`Sample answer:`/`Translation:`/`Output:`/`Code:`/`Script:`/`Steps:`/`Key:` 等，**框内不写题面段**）；学员原作答与答案逐点对照。答案之后**框外单独一行**附**给分点量表**（备考/阅卷型任务适用，格式见 `lecture-styles.md`「给分点量表」，各点分值之和须等于合计）；非备考任务给关键步骤、验证方式或成功标志，不编造官方分值。无官方细则时明示「训练量表，非官方细则」，未知官方分值不得编造。**框体体例**（交付起笔、段首分点、代码块、句中编号与批注、标记行留空）**的唯一事实源见 `lecture-styles.md`「讲义概念单元 schema · 答案框体例」及五要素之③**；本条只约束解析呈现格式。

## 9. 错因分类与补救（T10）

**归因定类**须分清六种，避免把「没学过」记成学员弱点、把「概念误解」一律当审题问题：

| 归因 | 判据 | 写盘 `错因=`（兼容旧三分类） | 首选补救 |
|---|---|---|---|
| **未教** | 该内容本节/课程尚未教 | 知识性 | **先补教**（不记为学员弱点） |
| **遗忘** | 教过、有证据会过，现忘 | 知识性 | **回拉复习**（插热身/回退前置小节） |
| **误解** | 学了但理解偏 / 概念混淆 | 理解性 | **换角度重讲**（换类比/风格；**不默认只练圈画**） |
| **方法选择** | 会方法但选错 / 条件没判 | 技巧性 | **判定题 / 条件化补练** |
| **执行偏差** | 会且选对但粗心 / 审题 / 超时 | 技巧性 | **流程专项**（审题圈画 / 步骤回查清单） |
| **过度泛化** | 定义/规则本身对，但用到适用条件之外；典型「我觉得都一样」 | 理解性 | **边界反例 + 判定题 + 学员自举反例**（不默认重讲全节） |

- **四态与错因的边界**：`未判` 不进错因表（不是错，先补判或作废）；`部分` 按缺失的得分点/关键步归因，但不等于全错，也不因「部分」标签自动升级为 A 级；`作废` 不计入错因与错题本。只有真实判错（`错` 或经补判后的 `部分`）才进入本表。
- **误解 vs 过度泛化的二选一判据**：概念定义错 → 误解；定义对、场景错 → 过度泛化。写盘保持 `错因=理解性`，另加独立 token `子类=过度泛化`（`scheduler.py` 忽略未知 token，不破坏解析）。
- **补救按「最早偏离步骤」选**（定位首次偏离点再对号入座），不是按错因标签一刀切。
- 旧数据只有三分类时兼容读取；新写入尽量落到六类（映射见上表），`错因=` 枚举仍为 {知识性, 理解性, 技巧性} 以保持解析契约。
