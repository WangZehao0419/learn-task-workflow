# S0 建档与 S1 诊断

<!-- owns: S0 接料建档、S1 诊断摸底; must-not-define: S2 计划、教学动作、字段格式 -->

## S0 接料建档

- **目标**：学什么、为什么学、基础如何、时间多少，四项齐备；并定档**类型**与**学科族**。
- **输入**：用户学习需求 + 附带材料（文件/链接/大纲，可选）。
- **动作**：
  1. **材料读取**：附带材料时先读取抓取、提炼目录与核心脉络。**材料阈值**：材料达到阈值（正文 ≥ 40 页，或目录项 ≥ 60 条；页数按 PDF 页数或正文字符数 ÷ 约 500 字/页 估算）→ **先与用户确认本次范围**，只取一部分纳入路线，其余标注「后续节可续入」；低于阈值的材料直接全量纳入，无需确认。
  1b. **备料（仅无材料/材料不足）**：知识型/技能型且无材料或材料不足时，收集 3–5 个互不转载来源（官方教材/课程/标准文档优先），按「相关性/来源质量/时效/深度/阅读成本」五维筛，落 `materials/00-备课来源.md`（名称/链接/年份/一句话评价/可信度/分歧点）；无联网或查证失败 → 不建文件，S2 标「无外部基准」。材料型已有目录不触发。
  2. **三问（收集四项信息：学什么、为什么、基础、目标与时间）**：用交互式提问（宿主提供专用提问工具则优先，否则以文本提问逐项确认）问 ① 学什么 + 为什么（应试/求职/兴趣）；② 基础（零基础/入门/进阶）；③ 目标与时间（期限/每周时长/单次时长）。**可选补充（不阻塞 S0 闸口，S2 可再补）**：学到什么程度算完成（写入 `目标程度`）。
  3. **澄清纪律**：每一项缺失信息**最多追问 2 轮**；两轮仍缺 → 按现有信息出草案/假定缺省值并向用户**声明假设**（如「按每周 3 次、每次 30 分钟排，如不符告诉我」），不得无限问卷化。只追问**会改变答案的缺失信息**，已说明的不重复问。
  4. **定档**（必须显式生成并展示给用户）：
     - **类型** ∈ {知识型, 技能型, 备考型, 材料型}。判据：有考试日 → 备考型；以实操/动手为主 → 技能型；以现成材料为载体 → 材料型；其余以理解概念为主 → 知识型。生成后**向用户展示并请其确认/更正**。
     - **学科族** ∈ {数学与统计, 实验科学, 语言, 计算与技术, 人文社科, 医学与健康, 艺术与技能}。由主题推断后**向用户确认并落盘**；S1 摸底后若发现不符，**允许修正并记录修正理由**。
  5. **先读历史**：同数据根已有同主题或相关任务时，先读其记忆.md「学习记录」与学习者画像（`profile.md`：教学方法裁决、类比领域）——复用有效裁决与类比领域，不重蹈已判低效的教法。**按作用域复用（F13）**：跨主题沿用的只有「学员明说的通用偏好」与**学科族级**的有效裁决；**任务级 / 单次的教法裁决不跨主题预判**（不得因某任务一次低效就对同类主题一律换法，须在新任务重新评估）。
- **闸口**：四项信息齐备；类型与学科族均为合法枚举且已展示确认。`目标程度` 为可选补充，不阻塞本闸口。
- **产出**：在「数据根」下创建 `<slug>/progress.md`（元信息区，含类型、学科族、数据根、目标；如已获得则一并写 `目标程度`）。**「起点」由 S1 产出，S0 与 S1（诊断摸底进行中）均不要求**（`progress_check.py` 对「起点」的必填约束**自进入 S2 起生效**）。阶段 → 诊断摸底。
- **失败怎么办**：材料读取/解析失败 → 停止当前运行，请用户修复文件、重新提供，或粘贴目录/口述要点后重新解析；不得先用通用脉络开课。范围确认完成后从 S0 原步骤继续。

## S1 诊断摸底

- **目标**：判定起点，摸出薄弱点。
- **动作**：出 3–5 道由浅入深的摸底题（用户自报进阶且确认熟练时，可减为 2 道确认题——仍须判分证据支撑起点判定）；**技能型**任务改用一个小实操。无实跑环境时停止当前运行，恢复授权执行环境后补做实操；口述步骤不能冒充实操证据。只记录不批评。**摸底判分证据落盘 `exercises/00-摸底-<日期>.md`**（沿用 `NN-` 命名契约的 00 专号，含作答与判分结构）。**摸底同轮顺带问一句「类比领域」**：「你有没有特别熟悉的一个领域（做饭 / 游戏 / 音乐 / 某项运动 / 本职工作……）？之后讲新概念我优先拿它打比方。」答案写入学习者画像（见 `data/profile.md`「学习者画像」；无画像文件时本次顺带建立，用户不便回答则跳过，不阻塞闸口）。
- **闸口**：起点判定为三档之一（零基础/入门/进阶）；薄弱点清单**允许为空**——全对（=进阶）时记为「薄弱点：无」并正常推进。
- **产出**：起点字段、薄弱点清单（可记「无」）；阶段 → 计划确认中。
