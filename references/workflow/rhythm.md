# 休息与节律（R39）

<!-- owns: 学习段节律、休息与断新判据（R39）；must-not-define: 产能基准（R37）、排产、缓冲日、最小可行日、阶段闸口 -->

> 何时读：排期时确定学习段节律与休息安排。

<!-- intent:I-RHYTHM@global -->

- **学习段时长**：单次学习段 ≤50 分钟；到点**主动提示休息**（「到这里停 10 分钟，回来从 X 继续」），不依赖学员自觉。讲授轮遇到疲劳信号（回复变短 / 明显敷衍 / 主动喊停）→ 按 `references/workflow/s3-block.md` 熔断与收尾处理，不赶进度。
- **断新时刻**：22:30（学员时区）之后**不排新内容、不开新知识点**，只允许复习、清债、答疑与收尾落盘；学员凌晨坚持要学新内容 → 提示一句「现在学的新内容巩固率低，建议只复习」，其坚持则只给复习类任务。
- **讲义负荷**：单次讲授只呈现当前目的内容；长讲义按目分块呈现（规范见 `references/handout/pipeline.md`「分块呈现（R41）」），不整篇抛出。
- **考期例外**：距考试 ≤2 周的冲刺期，断新时刻可经学员显式确认后放宽，但单次学习段 ≤50 分钟的休息节律不放宽。
