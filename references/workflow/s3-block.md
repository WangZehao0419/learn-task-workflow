### 逐目推进（最细知识点）

<!-- intent:I-NO-CAP-PER-MU@global -->

- **开节核对**：开节前只核对三件事——① 本节教材目标与目清单（每目一个最细知识点，1 道题能独立检验）；② 本节预计课时（写入排期）；③ **本节的目已全部细化在课程体系.md 中**（每节开讲前必须细化至最细知识点级并登记「引入」列；未细化 → 回 S2 步骤 4 补细化，不得开讲；极简任务经用户确认的「无课程体系」形态除外）。**不设目数上限、不设新记号上限**，教材节不按目数拆，目不设时间上限（判据见下条）。预计讲义 ≤20k 字仍作质量提示（>20k 预警、>30k 提示拆分讲义文件，不拆节）。已开讲的节讲不完就停在目边界，下次从该目继续。
- **教材协作（备考型且学员持有对应教材时默认执行）**：开讲前先向学员报本节教材页码，等学员拍照后做三件核对——①细目有无遗漏；②书上表述/例句与我方讲义的冲突；③教材深度与我方讲义深度的差距——再按教材正文定目预算、出讲义与题组。**教材 = 底线**（考点覆盖、定理表述、例题难度以教材为准），**讲义 = 上限**（补前置、拆目、配图、易错、方法选择图）；学员未发照片时**不擅自开讲**，先提醒协议。无教材任务跳过本步；页码口径、拍多少、边界（不承诺逐字复刻）由课程体系.md「协作协议」记录细则。
- **课时口径与节律**：节级课时按实际讲授时间记录，不预设单目分钟数；**学习段节律（单次上限、休息、断新）按 `SKILL.md` 全局条与 `workflow/pacing.md`「休息与节律」R39**。学员说累或注意力下降 → 停在当前目边界，下次从该目继续，不赶进度。
- **节中进度重排**：每目/每次会话结束记录实际进度与剩余目；讲不完不拆节，停在目边界并写入 `## 下次续学`；只有教材结构本身允许时才新增节。
- **关键目**：只对含新记号/易错/薄弱点的目正式判分（题量口径见 `assessment/generation.md`「题量预算」）；不是每个目都必须正式判分，但每个目都必须有 1 次可判定检验。
- **拆节数据纪律**：拆节时保留既有 KP 编号、材料编号与判分记录；**优先拆目**（同节号下新增目行，不改路线/脚本）；确需拆节时用新的**整数**节号（插入并重排，或追加到路线末尾），**不用 3a/3b**——`ROUTE_RE` 只认 `\d+\.`，3a 会被当作未解析路线；不整体重编号既有编号；拆节结果写入学习路线与进度对账，按对象 ID 对账，不靠序号猜。
- **课首公示**：课首给一行「本节 N 个知识点 + 预计课时」，**目清单一行一个目名（知识点名），只列名称与顺序**，不提前展开讲解；不按场/段分组。**对学员只用目名指代**（口径见 `SKILL.md`「全场景必载硬规则」），不报内部编号。
- **目切分与最细判据**：**1 目 = 1 个最细知识点**（KP）。判据：① 能在当前节目标内独立讲清；② 能用 **1 道题**独立检验其核心判断；③ 若需要 2 道题分别检验两个判断，说明它含 ≥2 个知识点，必须拆目。**不设时间上限**（2 分钟或 20 分钟都可以，只要是一个知识点）。目内可以有定义、1–2 个例子、1 个易错点，但都必须服务同一个知识点；不得顺手带入相邻知识点。**组块审计**：一个目同时引入的新概念 + 新记号合计超过 4 个 → 拆目或分批呈现（工作记忆一次约持 4±1 个组块）。**最细是相对当前节目标**：下位细节属于后续节的，留给后续节，不提前塞进本节。**目名节内唯一**——同一节内两个目不得重名（重名先改名再入账）。**不可分割的单条推导/单个操作链**即使很长也保持完整，算一目一个知识点，不按时间拆。讲义单元可以对应多个目，不强制 1:1。
- **目-能力映射**：课首目清单每目标 `能力=C1/C2/C3` 或「支撑目」；每项关键能力至少映射 1 目；含新记号/易错/薄弱点的目为关键目。无能力映射的目不得占用正式确认题额度。
- **编号口径**：目行编号 = `KP-<两位节序>-<两位KP序>`（如 KP-03-08 = 第 3 节第 8 个目），判分行写 `KP=<id>`；无对应目行的极简任务写 `目=<目名>`，不编造编号。**目名必须与编号成对落盘**（如 `目 8「介词」`）；`目=` 是人读字段，不进闸口计算。
- **禁止多概念目**：不得用一个目承载两个及以上可独立检验的知识点。发现目内有两个判据 → 立即拆目；已讲部分标「草稿/未确认」，不把该目记为已讲（完整判定见 `ops/failure.md` SR-9）。
- **前置依赖检查**：读本节各目的 `前置` 列；前置未 `已讲`/`已会` → 视为缺地基。工具/预备节另列显式前置清单（如三角定义、单位圆、特殊角），不依赖目行。缺地基 → 加一个地基目或拆出地基目；不假设学员已会（确证铁律见 `teaching/lesson-prep.md`「课首与旧知锚定」）；不拆节，按目续学。新增地基目须向学员展示目清单变更；地基目仍按六拍先教后练，不新增闸口，补授情况记记忆.md 学习日志。**不做新内容前置探针**——前置是否已会看目行状态与确证证据，不看现场测验。
- **逐目循环**：每轮只讲 1 目 → 给 1 次确认 → 停轮等回应。关键目正式判分（1 道短题，写入 `## 作答与判分`；字段、计分与用途口径见 `data/layout.md`「正式/轻量确认」与「题组与判分文件（exercises/）」，道数口径见 `assessment/generation.md`「题量预算」）；简单目轻量确认（**必须是可判定的具体问题**：说出区别/给一个正例或反例/判断对错/复述关键判断；**禁止只问「懂了吗」「明白了吗」**；记账与留痕口径见 `data/layout.md`「正式/轻量确认」；答不出或答错 → 不得推进，按提示阶梯补讲，必要时升级为正式确认并补记判分行）。**每目都必须有 1 次检验，不得跳过或把两个知识点的检验合并成一次。** 正式确认**独立答对才进下一目**；经提示②–④后正确 → 同轮补 1 道同型变式，变式独立正确才推进；仍不能独立正确 → 本轮收尾、记薄弱点、不推进、不标已讲。
- **目关闭台账**：每目关闭（正式或轻量）在记忆.md `## 学习日志` 写一行：目名 + 正式/轻量 + 结果；正式判分另写 `## 作答与判分`。同节跨会话续学且间隔 ≥1 天 → 开讲下一目前做 30–60 秒上一目回忆题；答不出 → 3 分钟回顾再继续。
- **确认 ≠ 掌握**：确认只决定「能否讲下一目」，不写「已掌握」、不翻转 KP 状态、不替代节闸口（正确性达契约比例 + 关键能力独立通过 + 复述通过）。每项关键能力至少一条独立正确 evidence 不带 `用途=推进`（来自题组计划题）；确认题的分型证据资格与「不替代题组」口径见 `data/layout.md`「正式/轻量确认」。每节仍须有题组题与单元检验（数量按 `assessment/generation.md`「题量预算与自测≠题组」）；只有正式确认、没有题组判分 → 不得过闸。
- **闸口失败 → 目级回开**：节闸口未过时，按题组/关键能力/复述缺口映射到具体目；只重开对应目，不整节重讲；整节重讲仅作回炉重教手段。
- **轻量抽检**：每节至少抽 1 个轻量确认目，在节末题组中用 1 道题复核；若错，回开该目，不把整节判失败。抽检题按正式确认记录，不设道数上限。
- **跨目串联（多目节）**：含 ≥2 目的节，节末题组至少 **1 道跨目综合题**（或一张关系图/流程链），要求学员把本节两目以上的内容连起来用；该题计入核心题量，可复用本节综合练习或单元检验。只有单目的节可省略。**目内题只证明单点，跨目题才证明连接**；缺跨目证据时不得仅凭逐目确认判「本节已掌握」。
- **讲义边界**：讲义草稿按目增量追加到 `materials/`；**追加单元前先核对讲义版面契约（版面与槽位以讲义场景为准），同文件既有单元只作内容参照、不作体例范本**；节末整理定稿；对话轮不贴讲义全文，不因要生成整节讲义而把整节内容一次输出。
- **工具触发池**：标「选学·后期必用」的工具目，不排固定 due；在既有「保持抽样池」记一条「工具 → 首次触发节」，后续节首次用到时做 1–2 分钟回忆；答不出 → 回炉该目。不写入 `## 保持复习` 的机器调度区，避免 due-queue 误读。
- **疲劳与中断**：出现疲劳/熔断信号时收尾，不赶进度。本节未讲完就结束 → 在 `## 下次续学` 的「节」行写「第 N 节（已讲到第 k/N 目『目名』）」，并在 `## 本次交接` 的「下次先做」写「从第 k+1 目『目名』（KP）继续」；下次从该目起讲，不从头重灌。用户正常说下课按 SR-7 正常下课口径处理，不触发断章。
- **压缩与加速**：学员明确要求「一次讲完 / 别停 / 直接讲到底」→ 按 `teaching/presentation.md`「对话讲授契约」的压缩出口执行：可压缩每个目的讲法（结论 + 必要依据 + 边界）；**连发默认关闭**：学员明确说「连着发」才连续逐目输出（连发细则见 `teaching/presentation.md`「压缩出口」）；**每目仍 1 检、独立答对才下一目，不得把多个知识点合并成一组或整节灌入**。纯记忆/已会目可走压缩出口（结论 + 必要依据 + 边界 + 1 句可判定确认）。
- **深讲概念**：软默认每节选 1 个**完整深讲**，按 `teaching/explanation-depth.md`「深度契约」执行；每个被标为完整深讲的内容定稿前都跑 D1–D6，D1–D5 任一不满足 = E。**深度审计不替代节闸口**（正确性/关键能力/复述三条底线不变）。**深讲配额与 >1 关键能力的处理见 `teaching/explanation-depth.md`「深度分层」**；机制段≠深讲。
- **轮型版式**：讲授/反馈/提示/路线轮的首行、结构与结尾见 `teaching/presentation.md`「对话呈现系统」「讲授轮版式」「反馈轮、提示轮与路线轮版式」；本册只管目与闸口。

### S3 闸口（可检验）

<!-- intent:I-KP-TYPED-GATE@global -->

- **闸口（节验收）**：本节练习 **正确性达标**（独立正确 + 提示②–④后正确合计达到契约 `gates.min_ratio`）**且** **关键能力项独立通过** **且** **复述通过**。**关键能力不可被简单题抵消**：本节须先定「**关键能力清单**」（1–3 项，即本节核心方法 / 唯一核心应用题 / 主要易错点），**每项关键能力必须至少一次独立正确**（提示后正确不计入该项通过）；「两个简单题对、唯一核心应用题错」**不得**因总比例达标而判本节通过。正确性、独立性、流畅度**分别落盘、不折算合并**：慢但独立正确按**完整正确性**计；提示后正确另记**依赖程度**（独立 / 依赖提示），不外推为独立掌握。**四态语义与分母规则见 `assessment/scoring.md`「判分口径」**；若有效作答全为未判/作废 → `E-NO-GRADED-ATTEMPT`，不得标已掌握。**正式/轻量口径**：确认题的字段、计分、分型证据资格与「不替代题组」见 `data/layout.md`「正式/轻量确认」；每节仍须有题组题与单元检验（数量按 `assessment/generation.md`「题量预算与自测≠题组」）。**分型验收（仅声明了类型的目）**：记忆/程序须有 `KP=<id>` 的独立正确 attempt；概念/设计须有复述清单已勾选行含该 KP 编号；视觉任务须有 `KP=<id>｜视觉=<任务>` 的独立正确 attempt；缺失 → `E-KP-TYPED-GATE`。未声明类型 = 统一闸口。
- **复述通过标准**：见 `assessment/scoring.md`「复述证据」（覆盖关键点 ≥ 契约 `restatement.keypoints` 且无事实性错误）；本阶段只要求「复述通过」这一闸口项。
- **判分证据强制**：标记「已掌握」前，`exercises/` 必须有对应本节的判分记录（题号 / 正确性 / 独立性 / 流畅度 / 复述检查清单勾选）；无证据不得标「已掌握」。**信心与 cw 口径见 `assessment/scoring.md`**。
- **判分三维、调度档位与难度伺服**：见 `assessment/scoring.md`；**闸口两层**（比例线可按 `节目标线` 收紧/放宽，关键能力独立通过与复述通过是底线）与伺服落盘口径（含 n<5 样本过小标注）**唯一事实源见 `assessment/scoring.md`「闸口比例与节目标线」「难度伺服」**。过载靠降难，不靠同长度重讲。
- **产出**：节验收通过后的落盘清单按节末五件套执行（见 `workflow/s3-close.md`「节末收尾五件套」）。


## 分块呈现（R41）

<!-- intent:I-R41-BLOCK@handout -->

- **讲义按目组织**：一个目 = 一个最细知识点的完整呈现（一句定义 → 带注释示范例 → 补步练习 → 一句话小结），与 `teaching/lesson-flow.md`「单节课六拍」拍 3–5 同构；目内不得混入第二个知识点（目定义见本册「逐目推进（最细知识点）」）。
- **一次只呈现一个目**：对话轮与讲义投喂都按目推进；**禁止把整节讲义一次性全文抛出**——数万字符级长文远超工作记忆承载，必须拆为可暂停的分块序列，每目结尾停在该目的检验点，学员跟上再进下一目。
- **单目体量自查**：目以「四问可回答（是什么/何时用/怎么用/何时错）且不含第二个知识点」为界；**不设字数硬上限、必要推导不截断**（口径同 `teaching/explanation-density.md`「讲解文本密度原则」）。**weeding 是交付前常规动作，不待超长触发**：每段写完过一遍「这句服务本节目标吗」，背景漫谈、同义重复与未用术语当场删，可选内容后置；单目超过约 800 字再整体复查一次。
- **weeding（交付前）**：删与当前步骤无关的背景、重复表述与术语堆叠；**例题多于解释**——每个新概念至少 1 道带注释的完整示范例，解释文字围绕例题步骤展开，不写与步骤无关的综述；含两个独立知识点的目必须拆分（不按阅读时间拆）。
