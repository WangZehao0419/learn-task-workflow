## S3 逐节学习（循环体）

- **目标**：节节过关，逐节推进。
- **节级规则**：五个小步按序推进，每个小步跨一轮；凡需用户作答或复述处即停，等输入再走下一步。**节内按目推进，目 = 当前节目标内的最细知识点**；节内目数不设上限，教材节不按目数拆；**单轮只讲 1 个目**，见「逐目推进（最细知识点）」。**周对账**：本周**首次**开课时先跑 3 行对账——本周计划节（读课程体系.md「排期·周里程碑」区）/ 实际已完成节 / 偏差与原因；偏差 >3 天 → 给出排期微调建议（复用「调整学习计划」机制，向用户复述后执行）；无里程碑任务跳过本步。**进入新节讲授前先查 due-queue**：预算、优先清空与顺延口径**唯一事实源见 `assessment/scheduling.md`「due-queue 与复习预算」**；用户可随时改（衔接 🟡 SR-6）。**长队列不得吞掉整节课。**
- **轮次预算与合并弹性**：一节完整走完常需 10+ 轮对话，注意学员的节奏与疲劳——**可合并**：收作业与热身并为一轮、检验问题并入讲授尾轮、信心自评随作答一并请学员提交（不单独设轮）、学员出现疲劳信号（回复变短 / 明显敷衍 / 主动喊停）时提议五件套②跳过或降为口头一句；**不可合并**：讲授轮、练习作答轮、批改轮（节的核心，不省）。合并与否以学员状态为准，状态好时按完整节奏走；**紧凑节奏（S2 步骤 6 落盘）下无需等疲劳信号，直接适用上述可合并项**；合并不违反「单轮一小步」。**逐目节奏**：轮次随目数增加；每目的讲授轮与确认轮不可合并，判对后的批改可与下一目讲授同轮衔接（不额外等「继续」）；学员疲劳时按熔断条收尾并在交接记目位置，不得为省轮次把多目合进一轮。

### 每轮小步（五步）

| 步 | 动作 | 要点 |
|---|---|---|
| ① | **收作业** | 上次有作业先收先批：练习在题组文件内标记对/错，输出任务的漏洞记入薄弱点；错题入错题本 |
| ② | **热身** | 优先取 due-queue 的到期项，不足再从薄弱点/错题本补；题量、时长与打分口径按 `teaching/lesson-flow.md`「单节课六拍」；**只抽已讲授内容**，未讲授条目不入热身（见 `assessment/generation.md`「出题范围与未讲授过滤」） |
| ③ | **讲授** | 按 `teaching/lesson-flow.md`「单节课六拍」执行：**先教后练**（完整示范 → 补步 → 独立），单条讲解轮只含 1 个概念/1 个步骤；句数上限与版式按六拍与 `teaching/presentation.md`；讲义生成按 `handout/pipeline.md` |
| ④ | **练习** | 按 `assessment/generation.md` 的出题流水线与题量预算；自测≠题组；L3 例外见 `assessment/generation.md`「题量预算与自测≠题组」 |
| ⑤ | **批改** | 按 `assessment/scoring.md` 判分四态/反馈时序/信心与 cw；按 `teaching/interaction.md` 组织反馈三问与八动作；判错同轮归因定级 |
