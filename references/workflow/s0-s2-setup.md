## S0 接料建档

- **目标**：学什么、为什么学、基础如何、时间多少，四项齐备；并定档**类型**与**学科族**。
- **输入**：用户学习需求 + 附带材料（文件/链接/大纲，可选）。
- **动作**：
  1. **材料读取**：附带材料时先读取抓取、提炼目录与核心脉络。**材料阈值**：材料达到阈值（正文 ≥ 40 页，或目录项 ≥ 60 条；页数按 PDF 页数或正文字符数 ÷ 约 500 字/页 估算）→ **先与用户确认本次范围**，只取一部分纳入路线，其余标注「后续小节可续入」；低于阈值的材料直接全量纳入，无需确认。
  1b. **备料（仅无材料/材料不足）**：知识型/技能型且无材料或材料不足时，收集 3–5 个互不转载来源（官方教材/课程/标准文档优先），按「相关性/来源质量/时效/深度/阅读成本」五维筛，落 `materials/00-备课来源.md`（名称/链接/年份/一句话评价/可信度/分歧点）；无联网或查证失败 → 不建文件，S2 标「无外部基准」。材料型已有目录不触发。
  2. **三问（收集四项信息：学什么、为什么、基础、目标与时间）**：用交互式提问（宿主提供专用提问工具则优先，否则以文本提问逐项确认）问 ① 学什么 + 为什么（应试/求职/兴趣）；② 基础（零基础/入门/进阶）；③ 目标与时间（期限/每周时长/单次时长）。**可选补充（不阻塞 S0 闸口，S2 可再补）**：学到什么程度算完成（写入 `目标程度`）。
  3. **澄清纪律**：每一项缺失信息**最多追问 2 轮**；两轮仍缺 → 按现有信息出草案/假定缺省值并向用户**声明假设**（如「按每周 3 次、每次 30 分钟排，如不符告诉我」），不得无限问卷化。只追问**会改变答案的缺失信息**，已说明的不重复问。
  4. **定档**（必须显式生成并展示给用户）：
     - **类型** ∈ {知识型, 技能型, 备考型, 材料型}。判据：有考试日 → 备考型；以实操/动手为主 → 技能型；以现成材料为载体 → 材料型；其余以理解概念为主 → 知识型。生成后**向用户展示并请其确认/更正**。
     - **学科族** ∈ {数学类, 编程类, 语言类, 理论概念类, 记忆密集类}。由主题推断后**向用户确认并落盘**；S1 摸底后若发现不符，**允许修正并记录修正理由**。
  5. **先读历史**：同数据根已有同主题或相关任务时，先读其「错题归档」与学习者画像（`profile.md`：教学方法裁决、类比领域）——复用有效裁决与类比领域，不重蹈已判低效的教法。**按作用域复用（F13）**：跨主题沿用的只有「学员明说的通用偏好」与**学科族级**的有效裁决；**任务级 / 单次的教法裁决不跨主题预判**（不得因某任务一次低效就对同类主题一律换法，须在新任务重新评估）。
- **闸口**：四项信息齐备；类型与学科族均为合法枚举且已展示确认。`目标程度` 为可选补充，不阻塞本闸口。
- **产出**：在「数据根」下创建 `<slug>/progress.md`，写入元信息区（含类型、学科族、数据根、目标；如已获得则一并写 `目标程度`）。**「起点」由 S1 产出，S0 与 S1（诊断摸底进行中）均不要求**（`progress_check.py` 对「起点」的必填约束**自进入 S2 起生效**）。阶段 → 诊断摸底。
- **失败怎么办**：材料读取/解析失败 → 停止当前运行，请用户修复文件、重新提供，或粘贴目录/口述要点后重新解析；不得先用通用脉络开课。范围确认完成后从 S0 原步骤继续。

## S1 诊断摸底

- **目标**：判定起点，摸出薄弱点。
- **动作**：出 3–5 道由浅入深的摸底题（用户自报进阶且确认熟练时，可减为 2 道确认题——仍须判分证据支撑起点判定）；**技能型**任务改用一个小实操。无实跑环境时停止当前运行，恢复授权执行环境后补做实操；口述步骤不能冒充实操证据。只记录不批评。**摸底判分证据落盘 `exercises/00-摸底-<日期>.md`**（沿用 `NN-` 命名契约的 00 专号，含作答与判分结构）。**摸底同轮顺带问一句「类比领域」**：「你有没有特别熟悉的一个领域（做饭 / 游戏 / 音乐 / 某项运动 / 本职工作……）？之后讲新概念我优先拿它打比方。」答案写入学习者画像（见 `data/lists.md`「学习者画像」；无画像文件时本次顺带建立，用户不便回答则跳过，不阻塞闸口）。
- **闸口**：起点判定为三档之一（零基础/入门/进阶）；薄弱点清单**允许为空**——全对（=进阶）时记为「薄弱点：无」并正常推进。
- **产出**：起点字段、薄弱点清单（可记「无」）；阶段 → 计划确认中。

## S2 计划确认中

- **目标**：制定用户认可的小节计划与排期。
- **输入**：S0 定档结果、S1 起点与薄弱点、材料目录（材料型）、考试日（备考型）。

按以下六步顺序执行，不得跳步（六步为模型侧流程，用户仅在澄清问答与最终计划确认两处交互，其余步骤不占用用户轮次）：

**步骤 1：范围护栏**
先定课程规模：单课程初期小节数建议 ≤ 12，超出时先聚焦「最小可学骨架」再滚雪球，避免课程无限膨胀。材料型沿用材料目录；备考型从考试日倒排并留一周总复习；记忆密集类在排期里预留间隔重复节点。**排产产能**：排期任务量按 `workflow/pacing.md`「产能基准与排产」（R37：过去 14 天实测日均完成量 ×0.8，新任务按首节实测校准）折算，**不以学员自报的每日小时数直接折算任务量**；每周默认留 1 个缓冲日。

**步骤 2：模块全景先行，再拆节**
凡含「衔接 / 预备 / 工具 / 专题」类辅助模块，或任一模块含多个可独立命名的子块时，**先列全该模块子项清单，再切分为节**；其余课程直接拆节。**拆节按教材结构/模块子项，由浅入深**；节内块数不设上限，不按块数/时长拆节。只有教材结构本身没有可对应的节、或用户明确要求拆分时才新增节；审计/增补知识点只加块，不重排节号。清单对照权威结构构建——用户材料目录 / 权威教辅章节（可用联网查证能力核实，按来源分级标注；无材料任务优先引用 `materials/00-备课来源.md` 的来源台账，台账缺失按自拟总纲并标「无外部基准」）/ 用户口述期望；三者皆无时**显式标注「完备性自拟、无外部基准」**。对照源不含的辅助模块，其子项清单不受对照源约束、完备性以上述权威结构为准，并在对照结论三行式中**单列一行注明**。拆节结果按**「模块 → 节」映射**随计划展示，模块内被拆散或排在后面讲的子项逐条可见。**模块目标（能力句）**：每个模块写一句 `M<k> ｜ 模块名 ｜ 学完能独立……`，写能力不写话题清单；写入 progress.md `## 模块目标`。模块内容修改不得违背这句，超出就重新设计模块。**按目标程度定规模**：若 `progress.md` 记录了 `目标程度`，模块数量、深度与停点按它对齐；学员说「到这个程度就够了」就收束，不把整个学科教完。**材料全覆盖**：每份材料至少归入一个模块，写入 `## 材料覆盖`（`材料 → M1 / M2`）；不得因材料看起来次要就静默遗漏。

**步骤 3：覆盖对照（确定对照源并逐项核对，按类型分叉）**
- **材料型** = 材料目录（S0 已提炼）：目录每一项必须落到三态之一——映射到某小节 / 进暂缓清单 / 经用户确认排除；无目录时停止计划确认，请用户提供可读目录或明确改变任务范围，不得用通用脉络替代材料依据。
- **备考型** = 考纲/考点结构：有考纲材料用考纲；无则用联网查证能力核实官方考纲。**任务要求官方来源时**，指定官方来源不可得时停止当前运行（补齐官方材料或取得用户明确的新来源要求后继续），不用真题结构/通用骨架冒充官方考纲；**任务未要求官方来源时**，可使用已核实的稳定知识并标注来源等级，但不得声称按官方考纲核对。**来源分级与出处四要素见 `ops/evidence.md`**。**考纲权重分层（R38）**：备考型对照时把纳入项按考纲权重预分三档——**高频必做 / 中频选做 / 低频暂缓**（依据 = 真题分值/频次证据，口径与步骤 5 一致）；三档分布随对照结论展示，低频暂缓项进「暂缓与范围外」标「低频，考期前复盘」。**零裁剪路线（暂缓=0 且排除=0）必须附一句理由并走「停即报告」请用户确认**——默认不做零裁剪。
- **知识型 / 技能型** = 自拟体系总纲：可借联网查证能力核实主干，展示给用户后落盘作为对照基准。**对照源优先级（统一口径，防二义）**：有材料 → **材料目录为对照源**（自拟总纲仅作补充）；无材料 → 自拟总纲；材料型固定材料目录；备考型固定考纲/考点结构。对照源一经确定即落盘，审计分母随之定死。

对照结论按**三行式**（基础三行；辅助模块说明等补充信息可另起附加行）写入展示计划：第 1 行「对照源 X，共 N 项 → 纳入 M 项（=小节计划）」；第 2 行「暂缓 K 项：逐条列出」；第 3 行「排除 J 项：逐条给理由」。暂缓项全部写入 progress.md 区块「**暂缓与范围外**」，每条带触发条件（用户要求时 / 阶段末审计 / 考期前 / 无）。**滞后原因说明**：推迟到后续小节（下一节除外）才讲的子项，计划展示中标注一句推迟原因（如「二次方程与不等式 → 第 2 节：函数前段用不到，解定义域与不等式题时要用」），何时讲由「模块 → 节」映射天然可见；范围外内容仍走「暂缓与范围外」区块。有备料台账时，对照结论后追加一行 `备料来源 N 个（🟢x/🟡y/🟠z）`；无台账不写。**对照源本身落盘**（材料区记路径，或「自拟总纲」全文），供审计复核。**材料覆盖对账**：对照结论落盘后，检查 `## 材料` 的每份材料是否都在 `## 材料覆盖` 中出现并归入至少一个模块；缺失项补写或说明，不静默遗漏。

**步骤 4：KP 清单生成（三行式对照结论之后、展示计划之前；分级强制）**
机制下称 KP 清单，文件名固定为 知识清单.md，禁止 KP清单.md 等变体。
- **强制分级**：备考型/材料型**强制**生成（本子步是覆盖对照闸口的组成部分）；知识型/技能型**选做**——未做时在对照结论中显式声明「未建 KP 清单，分母为对照源条目级」。
- **落盘位置**：任务根层 `<数据根>/<slug>/知识清单.md`（不放 materials/）。
- **行式六字段**：`KP-<两位节序>-<两位KP序> ｜ 知识点 ｜ 所属小节 ｜ 前置（KP 编号或空） ｜ 来源（对照源条目） ｜ 状态（未讲/已讲/暂缓/排除）`（编号两位补零，脚本宽容匹配单位数）。**可选分型字段**：追加 `｜ 类型：记忆/概念/程序/设计` 与/或 `｜ 视觉任务：识别/关系/图表/比较`。新任务建议为每个 KP 标类型：记忆/程序走题目独立正确，概念/设计走定性复述；视觉任务另需独立正确 attempt，且只在确有原始图/表的 KP 上声明（来源纪律见 `assessment/scoring.md`）。旧任务缺字段 = 统一闸口，零迁移。
- **文件头**：版本号（KP 集合增/删/拆时 +1，状态翻转不改）、对照源指针、排序规则行、**覆盖范围行**（「全量」或「已细化至第 N 节，其余待细化」，缺省视同全量）、最近更新、覆盖摘要行（总/未讲/已讲/暂缓/排除计数）。格式模板见 `data/lists.md`「知识清单文件」。
- **原子判据**：每 KP = 当前节目标内的最细知识点，1 道题可独立检验；需 2 道题 → 拆 KP；不设时间上限。不达标条目拆分或合并后再入清单。
- **分批纪律**：未拆节的滚雪球候选拒绝入清单（仍留「暂缓与范围外」标「滚雪球候选」）；清单分批产出必须在「覆盖范围」行显式标注，未标注即 SR-7 命中。
- **摸底标注（保守口径）**：S1 摸底命中且有判分证据的 KP，状态列写 `未讲（已会：<摸底证据>，<日期>）`，随对照结论一并展示——信息性标注，**留在审计分母内**；任何把 KP 标「排除」出分母的动作必须经用户显式确认；不做运行时反向同步。
- **落盘时机与计划变更联动**：清单与排序结果随计划确认后同轮落盘；用户修改计划（增删节/改对照源）时按新对照源重建清单（版本 +1、重跑排序），不得静默沿用旧清单。
- **展示粒度**：清单全文落盘；随计划展示的为排序规则行、摸底标注与覆盖范围行摘要，不强制逐行展示全文（用户要求时给全文）。

**步骤 5：排序（清单生成后、写回清单行序；可解释是硬要求）**
无 KP 清单的任务（知识型/技能型选做未做）**本步显式跳过**，讲授序沿用拆节顺序——六步流水线的「不得跳步」不含此显式跳过。有清单时，排序规则按类型分叉，随计划展示、写入清单头「排序规则」行：
- **备考型** = 考纲板块 × 真题分值/频次的价值密度优先、被依赖度次之（「价值密度」「被依赖度」须绑定证据出处：真题分值/频次与依赖边计数，禁止凭语感编造分值）。**分值/频次允许粒度**：题型级 / 板块级 / 章节级皆可，按可得材料择最高粒度即可；**来源等级下限 🟡**（权威媒体或主流教辅转述，附年份），🟠 行业整理仅作参考并标「非官方口径」；**官方仅给题型级分值**（常见于统考）时，即以题型结构权重代替板块价值密度，并在对照结论中声明该口径。
- **材料型** = 目录序为主 + 显式依赖修正（修正须说明理由）；修正后**可选**跑 `kp_sort.py` **只检环**（读其 error/cycle 字段，不改行序），检出环即停止并报告。
- **知识型/技能型** = 依赖拓扑排序——模型声明依赖边 → 展示给用户 → `python "<技能根>/scripts/kp_sort.py" "<清单文件路径>"` 计算合法序 + 检环，检出环即停止并报告，不得静默假装排序。（补充：`kp_sort.py` 仅实现**拓扑序**——备考型的价值密度排序与材料型的目录序排序**无脚本支撑**，由模型按上述口径手工排，并在清单头「排序规则」行写明依据供复核）
- **查证失败判定**：无真题材料时，只有「已尝试查证并落盘尝试记录，且对照源内无真题分值材料」才判查证失败。此时停止计划确认并请用户补齐材料或明确取消分值排序要求；不得编造分值，也不以低等级来源替代。无边知识型按编号字典序稳定排序，不属于运行降级。
- 排序结果写回清单行序（清单头「排序规则」行与行序同轮更新）。示例仅为格式演示，KP 取舍与依赖声明规则领域无关。

**步骤 6：展示计划与确认**
展示计划（含对照结论）请用户确认。展示时一并问一句「你更希望我怎么教：A 多提问引导 / B 先讲后练 / C 混合（默认，可跳过）」；每节附「学完能：<一句话 ≤20 字>」与「本节 X 个知识点 + 预计课时」（知识点清单一行一个最细知识点；不按场/段列，不设时长阈值），每个模块附 `模块目标` 能力句。**教学姿态**：姿态 A/B/C 决定引导/直讲/混合，展示时一并问一句「你更希望我怎么教：A 多提问引导 / B 先讲后练 / C 混合（默认，可跳过）」，姿态写入学习日志，三档定义见 `teaching/lesson-flow.md`「教学姿态三档」。**教学策略字段（先测后教/先教后测）已废除、不再选路**——所有新内容一律先教后练（见 `teaching/lesson-flow.md`「核心教学序列」）。**节奏建议**：排期时建议**每周 ≥3 次、固定时段**；用户要求更低频时，**明示取舍**（「降频 → 两次间隔拉长 → 遗忘风险上升 → 达到同一目标总时长可能更长」），由用户显式确认后照办，不强推、不替用户决定。**节奏偏好**：**默认紧凑节奏**（默认启用 S3 可合并项，见「轮次预算与合并弹性」；用户要求完整节奏时改为完整五步走），展示计划时一并告知可切换；偏好随「节奏」字段落盘（如「每周 3 次；紧凑」，缺省即紧凑）。**周里程碑**：备考型/多节任务排期时按周给出「第 n 周（起止日期）：完成第 N–M 节」（复习/模考/强化周无新节时写「复习第 N–M 节」或「模考+强化」），写入 progress.md 可选「周里程碑」区（见 `data/layout.md`）；节级课时按首节实测校准（不预设单块分钟数；含块级检验，不含练习/复习/答疑），与每周可用时长显式核算。排期确认时向用户说明连续性承诺：全程同一技能人格、同一任务目录、同一节奏连续推进。节奏沿用既有「节奏」字段落盘，不新增字段。

- **闸口**：**用户明确认可计划 + 对照结论**（认可对象 = 排期路线与覆盖对照三行式）。**明确肯定**（「确认/可以/就这样/好的」）与**常规授权**均算认可——已展示完整常规计划后，用户说「随便，你来定」「都行」「你看着办」即**授权按默认方案执行、视为认可，不再追问**（F06）；**仅当**计划含**非默认取舍**（调整节奏 / 裁剪范围 / 改变目标线）或用户明确要求先看细节时才复述要点再确认。技能**必须停止并等待用户输入**；用户未回复不得推进。用户要改则改完再确认。
- **产出**：学习路线、排期、对照结论与对照源（含「暂缓与范围外」区块）写入 progress.md；**认可即同轮直接开讲第一节**（不再多问一轮「现在开始第一节，还是先到这里」；仅当用户明说「只要计划」时才本轮收尾，在「学习日志」写一句「待开课」，阶段保持「计划确认中」、**不写入阶段字段**）；阶段 → 逐节学习（当前小节 = 1）。
- **失败怎么办**：用户迟迟不回应 → 可用一句话复述计划要点并再次请其确认，不自行推进。
