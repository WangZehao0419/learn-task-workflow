## S2 计划确认中

- **目标**：制定用户认可的章/节/目课程体系与排期。
- **输入**：S0 定档结果、S1 起点与薄弱点、材料目录（材料型）、考试日（备考型）。

按以下六步顺序执行，不得跳步（六步为模型侧流程，用户仅在澄清问答与最终计划确认两处交互，其余步骤不占用用户轮次）：

**步骤 1：范围护栏**
先定课程规模：单课程初期节数建议 ≤ 12，超出时先聚焦「最小可学骨架」再滚雪球，避免课程无限膨胀。材料型沿用材料目录；备考型从考试日倒排并留一周总复习；记忆型内容占比高的科目在排期里预留间隔重复节点。**排产产能**：排期任务量按 `workflow/pacing.md`「产能基准与排产」（R37：过去 14 天实测日均完成量 ×0.8，新任务按首节实测校准）折算，**不以学员自报的每日小时数直接折算任务量**；每周默认留 1 个缓冲日。

**步骤 2：章全景先行，再拆节**
凡含「衔接 / 预备 / 工具 / 专题」类辅助模块，或任一章含多个可独立命名的子项时，**先列全该章子项清单，再切分为节**；其余课程直接拆节。**拆节按教材结构/章子项，由浅入深**；节内目数不设上限，不按目数/时长拆节。只有教材结构本身没有可对应的节、或用户明确要求拆分时才新增节；审计/增补知识点只加目，不重排节号。清单对照权威结构构建——用户材料目录 / 权威教辅章节（可用联网查证能力核实，按来源分级标注；无材料任务优先引用 `materials/00-备课来源.md` 的来源台账，台账缺失按自拟总纲并标「无外部基准」）/ 用户口述期望；三者皆无时**显式标注「完备性自拟、无外部基准」**。对照源不含的辅助模块，其子项清单不受对照源约束、完备性以上述权威结构为准，并在对照结论三行式中**单列一行注明**。拆节结果按**「章 → 节」映射**随计划展示，章内被拆散或排在后面讲的子项逐条可见。**章规划（能力句）**：每章写一句 `章<k> ｜ 章名 ｜ 学完能独立……`，写能力不写话题清单；写入课程体系.md `## 章规划`。章内容修改不得违背这句，超出就重新设计章。**按目标程度定规模**：若 progress.md 记录了 `目标程度`，章数量、深度与停点按它对齐；学员说「到这个程度就够了」就收束，不把整个学科教完。**材料全覆盖**：每份材料至少归入一个章，写入课程体系.md `## 材料覆盖`（`材料 → 章1 / 章2`）；不得因材料看起来次要就静默遗漏。

**步骤 3：覆盖对照（确定对照源并逐项核对，按类型分叉）**
- **材料型** = 材料目录（S0 已提炼）：目录每一项必须落到三态之一——映射到某节 / 进暂缓清单 / 经用户确认排除；无目录时停止计划确认，请用户提供可读目录或明确改变任务范围，不得用通用脉络替代材料依据。
- **备考型** = 考纲/考点结构：有考纲材料用考纲；无则用联网查证能力核实官方考纲。**任务要求官方来源时**，指定官方来源不可得时停止当前运行（补齐官方材料或取得用户明确的新来源要求后继续），不用真题结构/通用骨架冒充官方考纲；**任务未要求官方来源时**，可使用已核实的稳定知识并标注来源等级，但不得声称按官方考纲核对。**来源分级与出处四要素见 `ops/evidence.md`**。**考纲权重分层（R38）**：备考型对照时把纳入项按考纲权重预分三档——**高频必做 / 中频选做 / 低频暂缓**（依据 = 真题分值/频次证据，口径与步骤 5 一致）；三档分布随对照结论展示，低频暂缓项进「暂缓与范围外」标「低频，考期前复盘」。**零裁剪路线（暂缓=0 且排除=0）必须附一句理由并走「停即报告」请用户确认**——默认不做零裁剪。
- **知识型 / 技能型** = 自拟体系总纲：可借联网查证能力核实主干，展示给用户后落盘作为对照基准。**对照源优先级（统一口径，防二义）**：有材料 → **材料目录为对照源**（自拟总纲仅作补充）；无材料 → 自拟总纲；材料型固定材料目录；备考型固定考纲/考点结构。对照源一经确定即落盘，审计分母随之定死。

对照结论按**三行式**（基础三行；辅助模块说明等补充信息可另起附加行）写入课程体系.md `## 对照结论`：第 1 行「对照源 X，共 N 项 → 纳入 M 项（=节计划）」；第 2 行「暂缓 K 项：逐条列出」；第 3 行「排除 J 项：逐条给理由」。暂缓项全部写入 progress.md 区块「**暂缓与范围外**」，每条带触发条件（用户要求时 / 阶段末审计 / 考期前 / 无）。**滞后原因说明**：推迟到后续节（下一节除外）才讲的子项，计划展示中标注一句推迟原因（如「二次方程与不等式 → 第 2 节：函数前段用不到，解定义域与不等式题时要用」），何时讲由「章 → 节」映射天然可见；范围外内容仍走「暂缓与范围外」区块。有备料台账时，对照结论后追加一行 `备料来源 N 个（🟢x/🟡y/🟠z）`；无台账不写。**对照源本身落盘**（材料区记路径，或「自拟总纲」全文），供审计复核。**材料覆盖对账**：对照结论落盘后，检查课程体系.md `## 材料` 的每份材料是否都在 `## 材料覆盖` 中出现并归入至少一个章；缺失项补写或说明，不静默遗漏。**验证轴声明与计划冻结**：对照结论确认时同轮声明本次**已验证的轴**（如：考纲轴 / 教材目录轴 / 题型轴 / 词类轴——覆盖性声明必须标明已验证的轴，未验证的轴不得宣称「完整」）；用户认可计划后**计划冻结**——不得因「换一个轴还能查出缺口」而重开计划或连环重构排期，新轴级发现记入「暂缓与范围外」带触发条件，待触发或学员显式要求时再处置（真实漏讲仍由覆盖率审计与 SR-7 管，不受冻结豁免）。

**步骤 4：目清单细化（三行式对照结论之后、展示计划之前；全类型强制）**
机制载体 = 课程体系.md 的「学习路线」区：章标题下逐节列节行，节行下嵌目行；文件名固定为 课程体系.md，禁止变体。
- **全类型强制**：知识型/技能型与备考型/材料型一样，S2 **必须**建立章/节结构与目清单——它同时是**覆盖分母 + 前置依赖图 + 术语账本（`引入` 列，R46）+ 分型验收底座**，前置检查、出题对账、覆盖审计、排序全部以它为底座。唯一合法的新任务「无课程体系」形态：极简任务（单一操作演示、确无可拆知识点）**经用户确认后**按无课程体系处理并在对照结论声明理由。**分批下限**：允许分批细化（覆盖范围行显式标注），但**每节开讲前，本节的目必须已全部细化入课程体系并登记「引入」列**——未细化不得开讲，回本步补细化后再进 S3。
- **目行六字段**：`KP-<两位节序>-<两位KP序> ｜ 目名 ｜ 节 <N> ｜ 前置（KP 编号或空） ｜ 来源（对照源条目） ｜ 状态（未讲/已讲/暂缓/排除）`（编号两位补零，脚本宽容匹配单位数）。**可选分型字段**：追加 `｜ 类型：记忆/概念/程序/设计` 与/或 `｜ 视觉任务：识别/关系/图表/比较`。新任务建议为每个目标声明类型；分型验收口径见 `workflow/s3-block.md`「S3 闸口（可检验）」，视觉任务只在确有原始图/表的目上声明（来源纪律见 `assessment/scoring.md`）。格式与文件头字段见 `data/curriculum.md`「课程体系文件」。
- **原子判据**：每目 = 当前节目标内的最细知识点，1 道题可独立检验；需 2 道题 → 拆目；不设时间上限。不达标条目拆分或合并后再入账。
- **分批纪律**：未拆节的滚雪球候选拒绝入目行（仍留「暂缓与范围外」标「滚雪球候选」）；分批产出必须在「覆盖范围」行显式标注，未标注即 SR-7 命中。
- **摸底标注（保守口径）**：S1 摸底命中且有判分证据的目，状态列写 `未讲（已会：<摸底证据>，<日期>）`，随对照结论一并展示——信息性标注，**留在审计分母内**；任何把目标「排除」出分母的动作必须经用户显式确认。
- **落盘时机与计划变更联动**：课程体系与排序结果随计划确认后同轮落盘；用户修改计划（增删节/改对照源）时按新对照源重建（版本 +1、重跑排序），不得静默沿用。
- **展示粒度**：课程体系全文落盘；随计划展示的为排序规则行、摸底标注与覆盖范围行摘要，不强制逐行展示全文（用户要求时给全文）。

**步骤 5：排序（目清单细化后、写回目行序；可解释是硬要求）**
排序对全类型执行（课程体系为 S2 强制产物），排序规则按类型分叉，随计划展示、写入课程体系头部「排序规则」行：
- **备考型** = 考纲板块 × 真题分值/频次的价值密度优先、被依赖度次之（「价值密度」「被依赖度」须绑定证据出处：真题分值/频次与依赖边计数，禁止凭语感编造分值）。**分值/频次允许粒度**：题型级 / 板块级 / 章节级皆可，按可得材料择最高粒度即可；**来源等级下限 🟡**（权威媒体或主流教辅转述，附年份），🟠 行业整理仅作参考并标「非官方口径」；**官方仅给题型级分值**（常见于统考）时，即以题型结构权重代替板块价值密度，并在对照结论中声明该口径。
- **材料型** = 目录序为主 + 显式依赖修正（修正须说明理由）；修正后**可选**跑 `kp_sort.py` **只检环**（读其 error/cycle 字段，不改行序），检出环即停止并报告。
- **知识型/技能型** = 依赖拓扑排序（强制）——模型声明依赖边 → 展示给用户 → `python "<技能根>/scripts/kp_sort.py" "<课程体系.md 路径>"` 计算合法序 + 检环，检出环即停止并报告，不得静默假装排序。（补充：`kp_sort.py` 仅实现**拓扑序**——备考型的价值密度排序与材料型的目录序排序**无脚本支撑**，由模型按上述口径手工排，并在「排序规则」行写明依据供复核）
- **查证失败判定**：无真题材料时，只有「已尝试查证并落盘尝试记录，且对照源内无真题分值材料」才判查证失败。此时停止计划确认并请用户补齐材料或明确取消分值排序要求；不得编造分值，也不以低等级来源替代。无边知识型按编号字典序稳定排序，不属于运行降级。
- 排序结果写回课程体系目行序（「排序规则」行与行序同轮更新）。示例仅为格式演示，目取舍与依赖声明规则领域无关。

**步骤 6：展示计划与确认**
展示计划（含对照结论）请用户确认。展示时一并问一句「你更希望我怎么教：A 多提问引导 / B 先讲后练 / C 混合（默认，可跳过）」；每节附「学完能：<一句话 ≤20 字>」与「本节 N 个知识点 + 预计课时」（目清单一行一个目名；不按场/段列，不设时长阈值），每章附章规划能力句。

- **教学姿态**：A/B/C 决定引导/直讲/混合（问句见上），姿态写入记忆.md 学习日志；三档定义见 `teaching/lesson-prep.md`「教学姿态三档」。
- **先教后练**：所有新内容一律先教后练；具体教学序列在 S3 场景执行。
- **节奏建议**：排期建议每周 ≥3 次、固定时段；用户要求更低频时，明示取舍（降频 → 间隔拉长 → 遗忘风险上升 → 达成同一目标总时长可能更长），由用户显式确认后照办，不强推、不替用户决定。
- **节奏偏好**：默认紧凑节奏（进入 S3 后启用可合并项；用户要求完整节奏时改完整五步走），展示计划时一并告知可切换；偏好随「节奏」字段落盘（如「每周 3 次；紧凑」，缺省即紧凑）。
- **周里程碑与排期**：备考型/多节任务按周给出「第 n 周（起止日期）：完成第 N–M 节」（复习/模考/强化周无新节时写「复习第 N–M 节」或「模考+强化」），写入课程体系.md `## 排期`（见 `data/curriculum.md`）；节级课时按首节实测校准（不预设单目分钟数；含目级检验，不含练习/复习/答疑），与每周可用时长显式核算。
- **连续性承诺**：排期确认时向用户说明「全程同一技能人格、同一任务目录、同一节奏连续推进」；节奏沿用既有「节奏」字段，不新增字段。

- **闸口**：**用户明确认可计划 + 对照结论**（认可对象 = 排期路线与覆盖对照三行式）。**明确肯定**（「确认/可以/就这样/好的」）与**常规授权**均算认可——已展示完整常规计划后，用户说「随便，你来定」「都行」「你看着办」即**授权按默认方案执行、视为认可，不再追问**（F06）；**仅当**计划含**非默认取舍**（调整节奏 / 裁剪范围 / 改变目标线）或用户明确要求先看细节时才复述要点再确认。技能**必须停止并等待用户输入**；用户未回复不得推进。用户要改则改完再确认。
- **产出**：课程体系.md（对照结论、材料、章规划、材料覆盖、学习路线含节行与已细化目行、排期、质量保障机制）+ progress.md（元信息含当前节=1、暂缓与范围外、下次续学）；**认可即同轮直接开讲第一节**（不再多问一轮「现在开始第一节，还是先到这里」；仅当用户明说「只要计划」时才本轮收尾，在记忆.md 学习日志写一句「待开课」，阶段保持「计划确认中」、**不写入阶段字段**）；阶段 → 逐节学习。
- **失败怎么办**：用户迟迟不回应 → 可用一句话复述计划要点并再次请其确认，不自行推进。
