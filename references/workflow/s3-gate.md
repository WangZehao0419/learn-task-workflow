# S3 闸口（可检验）

<!-- owns: S3 闸口判据（可检验）、按 KP 类型分型验收；must-not-define: S3 循环五步（s3-cycle）、节末收尾（s3-close）、判分（scoring）、教学表达（teaching）、讲义分块（handout） -->

> 何时读：排计划时为目声明类型/验收口径。

<!-- intent:I-KP-TYPED-GATE@global -->

- **闸口（节验收）**：本节练习 **正确性达标**（独立正确 + 提示②–④后正确合计达到契约 `gates.min_ratio`）**且** **关键能力项独立通过** **且** **复述通过**。**关键能力不可被简单题抵消**：本节须先定「**关键能力清单**」（1–3 项，即本节核心方法 / 唯一核心应用题 / 主要易错点），**每项关键能力必须至少一次独立正确**（提示后正确不计入该项通过）；「两个简单题对、唯一核心应用题错」**不得**因总比例达标而判本节通过。**四态语义、分母规则与「有效作答全为未判/作废 → `E-NO-GRADED-ATTEMPT`」的判定见 `references/assessment/grading-states.md`「判分口径」**。**正式/轻量口径**：确认题的字段、用途与分型证据资格见 `references/assessment/exercise-files.md`「正式/轻量确认（推进确认）」；每节仍须有题组题与单元检验（数量按 `references/assessment/quiz-budget.md`「题量预算与自测≠题组」）。**分型验收（仅声明了类型的目）**：记忆/程序须有 `KP=<id>` 的独立正确 attempt；概念/设计须有复述清单已勾选行含该 KP 编号；视觉任务须有 `KP=<id>｜视觉=<任务>` 的独立正确 attempt；缺失 → `E-KP-TYPED-GATE`。未声明类型 = 统一闸口。
- **复述通过标准**：见 `references/assessment/restatement.md`「复述证据」（覆盖关键点 ≥ 契约 `restatement.keypoints` 且无事实性错误）；本阶段只要求「复述通过」这一闸口项。
- **判分证据强制**：标记「已掌握」前，`exercises/` 必须有对应本节的判分记录（题号 / 正确性 / 独立性 / 流畅度 / 复述检查清单勾选）；无证据不得标「已掌握」。**信心与 cw 口径见 `references/assessment/scoring.md`**。
- **判分三维、调度档位、难度伺服与闸口两层**：唯一事实源见 `references/assessment/grading-states.md`「判分口径」「难度伺服」「闸口比例与节目标线」。**过载靠降难，不靠同长度重讲。**
- **产出**：节验收通过后的落盘清单按节末五件套执行（见 `references/workflow/s3-close.md`「节末收尾五件套」）。
