## S4 复习巩固（可从逐节学习或结课随时插入）

- **目标**：清空薄弱点与错题，并维持已掌握内容的保持复习。
- **动作（抽取与出题）**：按 `assessment/generation.md`「出题流水线」执行。**错误修复**与**保持复习**分开——①**错误修复**：针对薄弱点与错题本出题；②**保持复习**：`## 保持复习` 区的已掌握条目按 due-queue 到期重测（未到期可每若干节 / 每周稀疏抽测 1–2 题，不只复习错题，防「只清错题却丢掉已会能力」）。**due-queue 同时读取「薄弱点」「错题本」「保持复习」三区**，输出 `kind` 与 `reason`；均不讲新内容。**抽取前先做未讲授过滤**（见本册「复习债治理（R36）」）。**抽取顺序 cw 优先**；`顽固` 条目不走重测，先重教（可换讲义风格），重教后重新计数。**检索变式口径**见 `ops/composition.md`。
- **动作（判分后调度落盘）**：**不心算**——按 `assessment/scheduling.md` 的调度命令取回 JSON 中的 S'（stability_new）、D'（difficulty_new）、due，用文件写入/编辑能力写回条目。
- **动作（收尾与返回）**：复习轮收尾同用「节末收尾五件套」（teach-back 可省略，其余四件保留；第 5 件进度对账照报——复习不掩盖未讲事实）。插入复习时记录**复习返回点**：progress.md 的「复习来源阶段」= 进入 S4 前的阶段（逐节学习 / 结课 / **已完成**），「当前阶段」临时切为「复习巩固」。
- **开场校准反馈（30 秒）**：进入 S4 时先跑 `scheduler.py calibration`，向学员读出其**当前问题记录中的高信心错误占比**（cw 占比）与信心分布（脚本 JSON，**禁止心算**）。**口径约束**：该占比只是「当前未清除问题记录」的投影统计，**不得用来评价学员整体人格或整体校准水平**。
- **元认知教学（四点，据读数展开）**：①用学员自己的 cw 条目举例说明「流利度 ≠ 存储强度」；②教**答题后延迟自评**（postdiction）——**明确这是「回顾性」估计，与原信心不是同一种测量**，只作元认知练习素材，不得当作原信心、不用于 cw、不用于校准；③**遗忘正常化**：复习中答错的条目按「忘了不是失败，是数据」的口径反馈，去羞耻化；④教学措辞用「当前快照」口径，不宣称全程累计。**样本数披露**：读出画像数字时同报分母条目数（如「12 条有信心记录的条目里 5 条 cw」），分母 < 5 时加「样本还小，这个比例先当参考」。
- **按错因分诊补救**：错因分类与补救动作见 `teaching/interaction.md`「错因分类与补救（T10）」；本阶段只决定抽题与返回阶段。
- **复盘火力分级**：A 级 → 详细整理 + 配同类变式（火力集中处）；B 级 → 记思路要点即可；C 级 → 仅标记知识点、不展开整理。**级不参与 due-queue 排序**，分级只影响整理深度与复盘优先注意力。S4 复习判分可**调整级别**（如 C 级反复错 → 升 B）。
- **缺省归因修正**：遇到错因为缺省推断（脚本输出标 `meta_default:true`）的旧条目，先按当下证据归因并写入真实值（这本身就是本轮动作，不得盲目补默认值）；可向学员说明「该条错因为缺省推断，如与实际不符请指正，可推翻重归因」。
- **闸口**：同一薄弱点连续 2 轮全部答对 → 从薄弱点清单移除，并**转入 `## 保持复习`**（初始值取契约并用 `scheduler.py next-interval` 算，不得直接消失）。**同日两次正确不等同长期保持**——转入保持复习后按 due-queue 到期重测，未到期可稀疏抽测；仍有残留 → 继续复习。**预算耗尽或用户示意结束时**：列出未清项与顺延日期（保留原到期日），按「复习来源阶段」返回或一句简短收尾——**不以「有残留」否决已约定预算**。**顽固条目不参与「连续 2 轮全对 → 移除」的普通清除路径**，走**四步清除链**：①**重教**（可换讲义风格）→ ②**重新计数 2 轮全对** → ③**变式自创关**（清零前最后一关，位置在计数通过之后、移除之前，每条只发生一次）：请学员把自己这条原错题**改造出一道新变式**（改条件 / 改问法 / 换情境任一）并自答自评；导师只核对变式是否真对准原错因——**变了题但考的仍是原错因才算过** → ④**通过后从薄弱点移除并转入保持复习**，不通过 → 回①再重教一轮。自创变式题落盘 `exercises/`（文件名前缀 `z-`，如 `z-变式-<日期>.md`），不计入节判分证据比对。
- **错题本清理/归档规则**：某错题对应的薄弱点被清除后，该错题**归档**（移入「错题归档」区，不再参与 S4 抽取）；连续答对 2 轮的错题同样归档；变式自创关通过后，原错题按既有归档规则移入「错题归档」。防止长任务下错题本无限增长。
- **产出**：薄弱点清除记录、错题归档记录、**保持复习条目更新**、本次交接 / 记忆.md 学习记录（可选）；复习结束后按「复习来源阶段」返回——从逐节学习插入则恢复当前节，从结课进入则回到结课重出综合测验，**从已完成进入则返回「已完成」（不撤销课程结果）**；**返回后把「复习来源阶段」清回「无」**（下次进入 S4 时重新记录，避免残留触发告警）。

## 复习债治理（R36）

- **未讲授过滤（抽取前置）**：薄弱点/错题条目所属知识点**尚未讲授**（课程体系目行状态未讲、或该内容从未进过任何讲授轮）时**不入队、不催答**——到期转为安排对应讲授（先教后测，六拍见 `teaching/lesson-flow.md`），不把「没学过的东西」当测验丢给学员；口径唯一事实源见 `assessment/generation.md`「出题范围与未讲授过滤」（R35）。
- **停新清债线**：任一复习条目**逾期 >2 天** → 当日**停止排新内容**，优先清债（插入一轮 S4）；清偿走每日配额，不要求一次清空。
- **每日配额与时间盒**：清债设**每日固定配额（≤5 条）与 45 分钟时间盒**；清不完的自动顺延（保留原到期日并在对账中可见），**禁止向学员展示「累计欠账 N 条」式清单施压**——对学员只说「今天清这 X 条就够」。
- **债不滚雪球**：连续 3 天触发停新清债线 → 说明产能基准失准，按 `workflow/pacing.md`「产能基准与排产」下调一档并重排后续节，而不是继续压清债配额。
