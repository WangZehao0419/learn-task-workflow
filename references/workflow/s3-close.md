# 节末收尾与未达标处理

### 节末收尾五件套（闸口达标后执行）

<!-- intent:I-CLOSE-FIVE@global -->

等待轮结构见 `ops/composition.md`。五件依次：

1. **teach-back**（已含在 S3 讲授，此处为汇总引用，见 `teaching/lesson-flow.md`）；
2. **学员输出任务（按目标选一种，不必逐节轮换）**——等用户写完，漏洞记入薄弱点。**已产出充分证据者（如 teach-back 复述已覆盖关键点且无硬错）不必再产同一义证据、不索要同义重复总结**。形态六选一、导师提议与学员自选替换的口径唯一事实源见 `teaching/interaction.md`「复述与输出证据」；
3. **落盘更新**（progress.md + materials 定稿 + exercises 判分；**同轮翻转本节各目行状态（未讲→已讲），在课程体系.md 学习路线勾选本节 `[x] N. 节名（已掌握 <日期>）`，并把 progress.md `当前节` 递增到 N+1（结课最后一节写末节序号）**，再更新课程体系.md 覆盖摘要行——见 `data/curriculum.md`「课程体系文件」；**节达标时同轮核对保持复习条目已齐**（目级保持条目在每目关闭时已写，R54；缺漏当场补齐，写入时机与初始值口径见 `data/progress-schema.md`「保持复习区」，不心算））；
4. **给出具体下次复习日期**——对本次新产生的薄弱点条目按 `assessment/scheduling.md` 的新条目命令取 due（不心算），用绝对日期（YYYY-MM-DD）告知，**禁止相对日期**；
5. **进度对账**（限 2–3 行）：本课程对照源共 N 项、已讲 M / 纳入 K 项、本节是第几节；剩余未讲逐条列；暂缓挂起 K 项及触发条件（一句话带过，详情指向 progress.md「暂缓与范围外」）。**学员不问也要报**——本件是覆盖透明度的主输出通道，落盘通道为 progress.md「下次续学」区块的「范围快照」行，二者同源同更。有目清单时，KP 口径数字**带口径标签**（如「目 未讲 a/M」，M = 目行总数）并入既有行、不新增行，2–3 行上限保留。

**节末交接（可选）**：五件套之后更新 progress.md `## 本次交接`（总结 / 下次先做 / 未解决）；如果出现了「这个学员在这个任务里为什么卡/为什么通了」的持久洞察，在记忆.md `## 学习记录` 写一条（≤120 字、带证据）；深讲概念公开讲完后可在记忆.md `## 讲授证据` 补一行（逐字引用 + 来源锚点）。三处都可选；没有新内容就不写，空更新合法。

**可选加练征询（R55，一句话，可选）**：五件套与交接之后导师提议一次：「今天的题都过了——要不要来一组举一反三 / 跨节挑战？拒绝不影响任何进度。」学员接受 → 按 `assessment/generation.md`「可选加练（巩固与举一反三，R55）」出题；拒绝 → 不追问、不展开、零评判；学员说「别再问」→ 写画像①层偏好（`data/profile.md`），此后只留快捷指令入口。征询整句 ≤1 句，学员疲劳时省略。

### 未达标处理

**错误处理第一动作永远是「定位误解点并针对性纠正」；整段重讲仅作重教后仍卡时的回炉手段**。记入薄弱点，下一轮插入巩固题或回退前置节；普通答错记薄弱点，**顽固**是更重一级（触发判据见 `teaching/interaction.md`「提问与提示起点（T06）」）——重教优先于重测，且回炉建议的判定把顽固计入；**回退有终止条件**——同一节连续 3 轮仍未过，改为「回炉建议」（拆更小步骤重讲或换讲义风格），不死循环。全部节「已掌握」→ 阶段 → 结课。
