讲授、出题、选讲义风格前，按学科族查阅对应分册；一门课跨族时，以当前节内容所属族为准，一节内显著跨族时按目取族（讲授前一句话声明「本目按 X 族细则处理」）。**本层只补学科素材与侧重差异（判档、类比素材、练习题型、误区模式、讲义风格建议），不改教学流程**——示范规则、阶段闸口、判分纪律等通用规则以 `teaching/lesson-flow.md`、`workflow/gates.md`、`assessment/scoring.md` 为唯一来源，冲突时以后者为准。

## 学科族判档表（S0 定档对照用）

| 族 | 核心动作判据（以学员大部分时间在做什么为准） | 典型主题 |
|---|---|---|
| 数学类 | 计算、推理、解题 | 高数/线代/概率统计/离散逻辑、K12 代数几何 |
| 编程类 | 写代码、读代码、调试、跑环境 | Python/SQL/算法/数据结构、脚本与工具 |
| 语言类 | 词汇句法积累、听说读写、产出文本 | 英语/日语等外语；语文（走「母语文」差异） |
| 理论概念类 | 概念理解、机制推导、边界判断、案例分析 | OS/网络原理/经济学/法学推理/教育学/心理学 |
| 记忆密集类 | 任意性配对事实的存储与提取 | 历史/生物事实/法规条文/医学名词/地理常识 |

**易误判裁决**：①语文归语言类（母语文差异见 `subjects/language.md`），默写与文学常识归记忆密集类调度；②物理/化学/生物：计算与解题目借数学类，概念解释与过程叙述归理论概念类，事实清单归记忆密集类——按目取族；③计算机理论（OS/网络/组成原理）归理论概念类，上机编程归编程类；④法规条文背诵归记忆密集类，案例推理归理论概念类；⑤医学：临床推理归理论概念类，药名剂量解剖名词归记忆密集类。判档冲突时以「学员时间主要花在哪个动作」裁决，并在 S0 确认时说明。

**类比素材的通用优先级（各族一致）**：学习者画像①层的「类比领域」＞ 本分册默认类比（学员无画像或未记录时）；锚点必须确证已会，铁律见 `teaching/presentation.md`「类比纪律」。

**误区库消费纪律**：各族分册的「误区库」是预判误区清单（R42）的**族级素材源**，不是题库——使用规则：备课短表取 2–3 条时，优先级 = 本学员历史错因 ＞ 族误区库 ＞ 通识；取条目必须结合本节内容具体化（换成当节的符号/场景），不整表照搬；干扰项绑定具名误区（`assessment/generation.md`「零提示与条件化判定题」消费）；讲授到误区高发步前主动点破（`teaching/explain-quality.md`「预判误区清单」）。

**视觉任务来源**：识别/关系/图表/比较类视觉任务只用原始材料图/表，不用生成图或讲义示意图替代；数学、物理、化学、生物等有原始图表的学科优先，其他学科有原始图/表时同样适用；细则见 `assessment/scoring.md`「视觉任务证据」。

**类型模板**：记忆/概念/程序/设计的内容形态（①–⑤、自测、误区、小结、答案）见 `handout/pipeline.md` §4；本层只补学科素材、误区与答案惯例，不另立类型规则。

**对照源与族联动（S2）**：K12 陪学以教材目录为主对照源、课标学业质量为深度标尺；中考备考「课标＋真题」双对照（中考已取消考纲）；专升本/考研/考证以官方考试大纲为对照源、近 3–5 年真题为权重源（R38 分层依据）——权重三层数据（大纲章节表/真题分值结构/真题频次统计）取最高可得粒度，**频次须实际统计真题得来，勿凭记忆写死**；成人兴趣学习自拟总纲并标「无外部基准」兜底（细则见 `workflow/s0-s2-setup.md`）。

## 应试技巧包（备考任务·冲刺期启用）

**启用时点**：备考型任务进入冲刺期（考点密集小节讲义改用「考试冲刺卡」起，至 S5 结课）开始执行本节；基础阶段与逐节学习前期不前置、不占轮次。五项均结合既有环节自然带出，不单独开课：

1. **时间预算**：按目标考试卷面结构给各题型定参考用时（有官方时长按官方，无则按题量估算并标注「估算」）；冲刺卡题组、S5 全真测验计时执行；单题超时先跳过标记、做完再回头。
2. **卡壳抢救**：教「解 → 设 → 列 → 能推几步推几步」的框架写法——把已知与目标摆上卷面就有关键步骤分，绝不空白；结合错题与模考复盘教，不空讲。
3. **检查策略**：交卷前预留固定检查时段（按时长定比例）；优先验算计算量大与踩过易错点的题——代回验算、符号与量纲快速核查。
4. **卷面管理**：草稿与解答分区，解答区只誊写 ③ 答案框的内容（判据五要素之③）；写错单横线划掉续写，不涂团。
5. **考前一页纸**（S5 结课产出）：公式卡 + 高频易错点 Top 5 + 各题型用时表 + 考场流程清单（含卡壳抢救与检查时点）。

**两条族通用提醒**：①多选/不定项题有「部分选对得部分分、选错得 0 分」计分时，训练「不确定项宁缺勿错」的取舍判断，练习时就按该规则计分；②考前一晚不排新内容，睡眠巩固计入计划（最小可行日见 `workflow/pacing.md`）。

> 技巧性错误的限时训练 / 同题限时重做按 `teaching/lesson-flow.md` T10「执行偏差」执行；本包只提供考试素材与用时口径。各族冲刺侧重见对应分册「备考侧重」节。
