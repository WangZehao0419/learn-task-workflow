# 学科族总则与应试技巧包

<!-- owns: 学科族查阅总则、类比素材优先级、视觉任务来源、类型模板指针、应试技巧包；must-not-define: 教学流程、判分、闸口、数据字段 -->

讲授、出题、选讲义风格前，按学科族查阅对应分册；一门课跨族时，以当前小节内容所属族为准。**本文件只补学科素材与侧重差异（类比素材、练习题型、误区模式、讲义风格建议），不改教学流程**——示范规则、阶段闸口、判分纪律等通用规则以 `teaching/lesson-flow.md`、`workflow/gates.md`、`assessment/scoring.md` 为唯一来源，冲突时以后者为准。

**类比素材的通用优先级（各族一致）**：学习者画像①层的「类比领域」＞ 本分册默认类比（学员无画像或未记录时）；`teaching/lesson-flow.md` 第 3 节）的锚点必须确证已会，铁律见 `teaching/presentation.md`「类比纪律」。

**视觉任务来源**：识别/关系/图表/比较类视觉任务只用原始材料图/表，不用生成图或讲义示意图替代；数学、物理、化学、生物等有原始图表的学科优先，其他学科有原始图/表时同样适用；细则见 `assessment/scoring.md`「视觉任务证据」与 `data/lists.md`「知识清单文件」「作答与判分」。

**类型模板**：记忆/概念/程序/设计的内容形态（①–⑤、自测、误区、小结、答案）见 `handout/pipeline.md` §4；本文件只补学科素材、误区与答案惯例，不另立类型规则。

## 应试技巧包（备考任务·冲刺期启用）

**启用时点**：备考型任务进入冲刺期（考点密集小节讲义改用「考试冲刺卡」起，至 S5 结课）开始执行本节；基础阶段与逐节学习前期不前置、不占轮次。五项均结合既有环节自然带出，不单独开课：

1. **时间预算**：按目标考试卷面结构给各题型定参考用时（有官方时长按官方，无则按题量估算并标注「估算」）；冲刺卡题组、S5 全真测验计时执行；单题超时先跳过标记、做完再回头。
2. **卡壳抢救**：教「解 → 设 → 列 → 能推几步推几步」的框架写法——把已知与目标摆上卷面就有关键步骤分，绝不空白；结合错题与模考复盘教，不空讲。
3. **检查策略**：交卷前预留固定检查时段（按时长定比例）；优先验算计算量大与踩过易错点的题——代回验算、符号与量纲快速核查。
4. **卷面管理**：草稿与解答分区，解答区只誊写 ③ 答案框的内容（判据五要素之③）；写错单横线划掉续写，不涂团。
5. **考前一页纸**（S5 结课产出）：公式卡 + 高频易错点 Top 5 + 各题型用时表 + 考场流程清单（含卡壳抢救与检查时点）。

> 技巧性错误的限时训练 / 同题限时重做按 `teaching/lesson-flow.md` T10「执行偏差」执行；本包只提供考试素材与用时口径。
