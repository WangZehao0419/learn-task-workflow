# 数学类（数学 / 统计 / 逻辑）

- 讲授侧重：先代具体数字算一遍，再上升到一般式；能画图必画图——函数图像/几何图形按 `handout/quality.md`「图像可视化双轨」执行（对话内 SVG 渲染＋落盘存档，缺一不可），文字描述图仅为兜底。零基础首目走 CRA 序（`teaching/lesson-flow.md`「现象→符号引入序」零基础默认强制版）；方法型目必配方法选择图与题型识别线索（`teaching/explain-quality.md`「元方法教学（T12）」）。
- 类比素材例：函数=饮料机（投原料出固定配方）；导数=车速表读数；概率=长期频率。
- 练习设计：**按任务细化**——计算类用同型三变式（改数字 → 改条件 → 逆向求解），并可加 1 道口算热身；**证明类**练「补全证明链 / 找证明漏洞」；**建模类**练「从情境列式 + 结果解释」。**不强制每节口算**。
- 常见误区模式：漏负号、适用条件未先判后用、单位与量纲出错。
- 讲义风格建议：默认标准讲义；考点密集期换考试冲刺卡。
- 工作样例差异：完整示范 = 「先代具体数字算一遍」的完整推导（逐步写到最终答案；完整示范末尾附 ③ 答案框，判据同 `handout/pipeline.md` 五要素之③）；完整样例之后的加固练习优先**重建型**（挖空关键推导步让学员补全），其次自拟标签型。
- ③ 答案形态：`解：`/`证明：` 起笔（题面写在 ① 题目），用 ∵/∴ 串联、每步一段；选择题给答案 + 逐项一句排除（错项写错在哪），填空写清多空顺序与单位，不写成纯答案清单；备考节在框后附给分点量表。
- 理科计算与化学（借用本族，不单设学科族）：物理按「公式 → 代入（带单位）→ 结果（有效数字与单位）→ 方向/符号」写，单位换算放在代入步；化学须给配平系数、反应条件（△/催化剂/点燃）与状态符号，计算题给物质的量关系与单位；生物、地理的计算类同此。
