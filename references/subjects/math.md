# 数学类（数学 / 统计 / 逻辑）

## 判档与借用

本族：高等数学/数学分析、线性代数、概率统计、离散数学、逻辑学、K12 代数与几何。物理/化学/生物/地理的**计算与解题目**借本族（概念解释目归理论概念类、事实清单目归记忆密集类，按目取族并在 S0 声明）。计算类讲授优先取教材例题与原始公式（来源锚点照记）。

## 讲授侧重（六拍内的族差异）

- **零基础首目强制 CRA 序**（具体情境 → 图形/表格表征 → 符号规则，`teaching/lesson-flow.md`「现象→符号引入序」；CRA 元分析大效应，Ebner 2025）。零基础跳过具体层直上符号 = 「讲了但没懂」第一诱因。
- **先代具体数字算一遍，再上升到一般式**；一般式与新记号出现即按「新记号讲透」三件套（语义/代入演示/易错点）。
- **能画图必画图**：函数图像、几何图、数轴、单位圆、概率树按 `handout/quality.md`「图像可视化双轨」（对话内 SVG＋落盘存档，缺一不可）；文字描述图仅兜底。
- **方法型目走元方法三件**（T12）：题型识别线索、方法选择图、示范带「我在想什么」；≥2 条方法时给「何时不用另一条」。
- **变式教学（顾泠沅）**：概念性变式（换非本质特征：方位、数字、字母）+ 过程性变式（铺垫递进：加一步/减一步）；对接 R43「一次一维」与预测轮。
- **解后必验算**：代回、量纲、特殊值三选一；验算作为示范收口步展示。

## 类比库（锚点须确证已会，明说「像/不像」）

- 函数=饮料机：同按键出同饮料；不像处：饮料机可能乱出，函数禁止一对多。
- 导数=车速表读数：瞬时变化率；不像处：车速表有延迟，导数是精确极限。
- 概率=长期频率：大量重复的稳定占比；不像处：不预言下一次，单次仍随机。
- 积分=无限个小矩形求面积；矩阵=按规则变形的表格（重点在变换规则，不在表格本身）。
- 学员画像有类比领域时优先取该领域。

## 练习与题型阶梯（按任务细化）

- **计算类**：口算热身 1 道（仅计算期）→ 同型三变式（改数字 → 改条件 → 逆向求解）。
- **概念/判定类**：判定题考「何时用」——给题面信号问走哪条方法（「看到联立求交点，先想哪条路？」）；干扰项取误区库具名条目（R42）。
- **证明类**：补全证明链（挖 1–2 步）→ 找证明漏洞（埋 1 处跳步或循环论证）。
- **建模类**：从情境列式 + 结果解释（算出来不合实际怎么判）。
- **交错排期**：独立解题成功率稳定后，题组混排 ≥2 类旧题型，迫使「先选方法再动手」（Rohrer 2020 课堂 RCT：交错 61% vs 分块 38%，d≈0.83）；切换判据见 `assessment/generation.md`「分块与交错切换」。
- **SSDD 同表面不同深层**（Barton）：题组可用同一题面/同一图形配 3–4 个不同深层的问法（同一等腰三角形分别考面积、角平分线、相似、三角函数），逼学员先判「这题到底在考什么」——顺带间隔复习旧知、防自动导航、逼出「什么变了→方法怎么变」的判别对比；判定题与跨目综合题的现成设计法（与 R43 一次一维互补：R43 管题与题之间变什么，SSDD 管同题面下问什么）。

## 误区库（喂 R42；症状/诱因/反证）

| 误区 | 症状（学员会怎么错） | 诱因 | 反证 |
|---|---|---|---|
| 等号当光标 | 3+4=7+2 连等到底 | 把等号读成「下一步是」 | 等号两边必须相等 |
| 分数分子分母各加 | 1/2+1/3=2/5 | 当两条独立数轴 | 同法算 1/2+1/2=2/4，等于没加 |
| 负数比大小看绝对值 | 认为 −7>−5 | 「7 比 5 大」迁移 | 欠 7 元比欠 5 元更穷 |
| 平方吞负号 | (−8)²=−64；−4² 与 (−4)² 不分 | 只记「负负得正」没接乘方 | (−4)²=16、−4²=−16，读法不同 |
| 系数指数混淆 | y·y·y 写成 3y | 乘法与加法记号互串 | 3y=y+y+y |
| 合并非同类项 | 9x+y−6x+y=5xy | 「有字母就能合」 | 苹果加香蕉合不成一个东西 |
| 去括号只乘第一项 | 5c(2d+1)=10cd | 分配律只看首项 | 5c·1 去哪了 |
| 解方程同侧重算 | c/4=8 → c=2 | 想「再除一次凑答案」 | 代回 2/4≠8 |
| 移项不变号 | x+3=7 → x=3+7 | 把移项当搬运 | 移项=两边同减 3 |
| 乘法使数变大 | 乘 1/2 或 0.3 也当变大 | 正整数经验泛化 | 半个西瓜比整个小 |
| 独立事件当有记忆 | 连开 3 次正面后押反面 | 赌徒谬误 | 硬币不记得上次 |
| 函数记号代入错位 | f(x+1) 算成 f(x)+1，或把 f(x) 读成「f 乘 x」 | 记号当缩写不当代入规则 | 代具体函数：f(x)=x² 时 f(x+1)=(x+1)²≠x²+1 |
| 导数只当切线斜率公式 | 会套公式求导，但说不出 f′(a) 是什么；求平均变化率反而错 | 求导可公式化，「斜率」只剩倾斜度直觉 | 同区间手算 (f(b)−f(a))/(b−a) 与 f′(a) 对比，一般不等（MAA 2018：学生几乎人人会算后者错前者） |

备课取 2–3 条；本学员历史错因优先占坑（消费纪律见 `subjects/common.md`「误区库消费纪律」）。

## 记号与术语纪律

族性记号地图首现给一页（集合、函数、逻辑、求导/求和记号各一句功能），地图级不作判分项；公式先给一句「怎么推来」再记忆，备考冲刺期公式卡除外。

## 复习与调度侧重（S4）

- 错题按错因分流：技巧性（漏负号/看错/超时）→ 限时重做同型题；理解性 → 回 CRA 具体层重建直觉，再回抽象层。
- 复习一律检索式：先做再对答案；重读笔记与抄公式不算复习（Dunlosky 2013 重读低效用）。
- 公式条目「会推导」可降频；纯记忆条目（三角特殊值、常数）保持间隔调度不删。

## 讲义与答案形态

- 默认标准讲义；考点密集期换考试冲刺卡。
- ③ 答案形态：`解：`/`证明：` 起笔（题面写在 ① 题目），用 ∵/∴ 串联、每步一段；选择题给答案 + 逐项一句排除（错项写错在哪）；填空写清多空顺序与单位；备考节在框后附给分点量表。
- **理科计算借用细则**：物理按「公式 → 代入（带单位）→ 结果（有效数字与单位）→ 方向/符号」写，单位换算放代入步；化学给配平系数、反应条件（△/催化剂/点燃）、状态符号与物质的量关系；生物、地理计算类同此。

## 备考侧重

- 压轴题按「能推几步推几步」（common 应试技巧包卡壳抢救的族内版）：把已知、设、列摆上卷面拿步骤分。
- 新高考数学 19 题制下多选「部分选对得部分分、选错得 0 分」——练习时就按该规则计分并训练取舍（`subjects/common.md`「应试技巧包」）；解答题按得分点写过程，规范过程本身值分。
- 真题分值统计定高频板块（R38），出题与复习优先高频。
