# 语言类（英语 / 日语等）

- 讲授侧重：场景优先于语法点；输入（听读）与输出（说写）成对出现；当节学当节用。
- **零基础语言协议（起点 ∈ {零基础, 入门} 时默认全程执行）**：
  1. **规则先行（演绎默认）**：每个语法点先给一句可判定的规则 + 1 个完整示范句，再进练习；归纳式（先给 3–5 例请学员发现规律）仅在学员主动要求探索或规则极简（≤1 句）时使用——零基础学员缺少「发现规律」所需的原材料，硬走归纳 = 猜谜。
  2. **三阶梯练习**：机械操练（替换/变换，只练形态，如 watch→watches）→ 意义操练（给情境选形式，信号词判时态）→ 产出（造句/改错/翻译）；每节练习至少覆盖前两阶，产出闸按课程计划执行。阶梯内的题按 `teaching/explain-quality.md`「智能变式一次一维」设计：一次只变一个维度。
  3. **全量中文释义**：所有英文内容——例句、信号词、题干、选项、词表、易错条目——一律配中文释义（整句翻译或词义括注「英文（中文）」）；学员词汇量以 S0/S1 记录为准，未记录时按 2000 处理；例句词汇不高于学员档位（超纲词首现即给括注，不假设「应该认识」）。
  4. **句型一致标记法**：主语/谓语/宾语/补语用固定记号（如 S/V/O/C 或加粗/下划线一种，全课程同一套）；成分术语族首次触碰先给一页成分地图（八个名字 + 一句话功能），地图级不作判分项——「标成分」类题在地图给过之前不得出现（与 `assessment/generation.md`「出题前术语对账（R46）」同源）。
- 术语纪律：语法术语（时态名、成分名、词性名）首现必须「定义 + 例子 + 代入演示」三件齐（同「新记号讲透」三件套）；判据只能用本节已教工具，不得提前调用后续章节的判据（如零基础阶段用「助动词/时态/缩合」检验谓语属跨节前置违规）。
- 类比素材例：语法=交通规则，词汇=车辆，流利度=对路况的熟悉度（学员画像禁类比时改准确定义 + 例句）。
- 练习设计：跟读 → 替换造句 → 情景对话；单选陷阱题干扰项 = 具名误区（R42，预判误区清单喂入：三单漏 -s、时态信号词误判、近义混填等）；拼写与搭配错误记入薄弱点（发音无法在文字会话判分，仅作提示、不作判分依据）。
- 常见误区模式：直译母语、只背不用、近义词混用、时态信号词误判、you 类主谓归类错。
- 讲义风格建议：标准讲义，自测题换成情景题；信号词表用「英文（中文）」双栏式。
- ③ 答案形态：`Answer:`/`Model answer:`/`参考答案：`（题干写在 ① 题目）；翻译给 `参考译文：`，写作给 `范文：`/`Sample answer:`，语法与改错给答案句 + 一句「为什么这么改」。
