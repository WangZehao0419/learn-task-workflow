# 记忆密集类（历史 / 生物事实 / 法规条文 / 医学名词 / 地理常识）

## 判档与借用

本族：以**任意性配对事实**为主的内容——名称↔属性、年份↔事件、条文↔要件、术语↔定义、地名↔特征；机制推导占比低的章节（凡能讲机制的部分应先讲机制再挂事实，机制部分借理论概念类处理）。历史因果分析、生物过程推理等理解型内容按目借理论概念类。

## 讲授侧重（六拍内的族差异）

- **框架先行**：先给地图（时间线分阶段、人体分系统、法典分编）再填细节；细节目开讲时先说「它挂在地图哪个格子」。
- **配对内容两种教法分界**：能推导 → 先讲机制再挂事实（如「为什么该地多雨」讲成因）；不能推导 → 直接给 + **当轮做 2 次检索**（学员看一眼遮住复述一次，稍后快问一次）——配对记忆吃检索，不吃理解。
- **双编码**：文字+图/时间线/流程图一起给（时间线、结构图、对比表是本族第一表征）；能画必画，按 `handout/quality.md`「图像可视化双轨」执行。
- **故事化串联**：有因果或时间顺序的条目串成因果链讲（事件不是孤点），防孤立背诵；无内在顺序的清单（解剖名词、法条编号）不硬编故事，改用结构框架。
- **口诀纪律**：只用学员自创或确证通用的口诀；不自造生硬口诀——口诀本身也是要记的负担。
- 词根词缀法（医学/生物/外语借用户）：把术语拆成已知部件再记整词，部件先教（词根清单归本族调度）。

## 类比库（锚点须确证已会，明说「像/不像」）

- 时间线=故事章节：有起承转合；不像处：真实历史多线并行，单线叙事会误导因果。
- 人体系统=城市管网：输水/供电/处理并行；不像处：系统间交互远比管网复杂。
- 法典结构=图书馆编目：先类后种；不像处：条文间有引用关系，编目没有。

## 练习与题型阶梯（按任务细化）

- **先填空回忆，后简答**：cloze 挖关键词起步（挖 1–2 处，不整句挖），稳了再上简答。
- **配对与排序题**：术语↔定义连线、事件排序、条文↔情形归类；判定题考「易混对辨析」——给一个情形问是 A 还是 B，干扰项=它的易混对（R42）。
- **对比表**：同类条目必做对比表（易混对并排呈现，差异行加粗）。
- 检索优先于重读：练习形式一律「先回忆再看答案」；**重读不算复习**（Dunlosky 2013：重读低效用；Karpicke & Blunt 2011：检索练习胜过精细加工）。

## 误区库（喂 R42；症状/诱因/反证）

| 误区 | 症状（学员会怎么错） | 诱因 | 反证 |
|---|---|---|---|
| 孤立背诵 | 单条会背、综合题不会用 | 没挂进框架 | 问「它和上一个知识点怎么连」 |
| 张冠李戴 | 年份/数值/人名错位（把 A 的内容安给 B） | 配对缺检索线索 | 对比表+首字钩（如「戊-1898-变」） |
| 流利度错觉 | 重读三遍觉得会了，一默写全忘 | 熟悉感≠可提取 | 当场遮住默写一次就知道 |
| 易混对混淆 | 动脉血/静脉血含氧量说反 | 相邻条目单独学 | 成对对比表差异行 |
| 关键词法滥用 | 抽象内容硬造联想，短期能背隔天忘 | 联想只搭了「音」没搭「义」 | 换机制挂钩：这个词从哪来的 |
| 只记答案不记问法 | 换个问法就答不出 | 配对单向学 | 反向再测一遍（A→B 会了测 B→A） |
| 默写整段混记 | 长答案背串行 | 无分点结构 | 每点一个钩子词，按点默写 |

备课取 2–3 条；本学员历史错因优先占坑。

## 复习与调度侧重（S4，本族主战场）

- 间隔重复是本族核心机制：S2 排期为记忆密集条目预留间隔重复节点；1/7/30 复习清单在 S5 结课执行（既有机制）。
- **cloze 卡原则：一张卡一个事实**（挖 1 个关键词），整段答案拆成多张卡；长答案另留一张「骨架卡」（只回忆分点框架）。
- 易混对在复习时**并排**出现（对比表行级复现），不分开各出各的。
- 反向检索：配对条目测完正向测反向；默写错字单独记薄弱点（不是整条重背）。

## 讲义与答案形态

- 标准讲义，⑤ 小结改为**「本节地图」**——地图只回收本节已有概念与依赖关系（≤7 条），不新增知识点，也不替代 ④ 易错。
- ③ 答案形态：`答：` 或 `答案：` 起笔（题目/材料/情境写在 ① 题目）；简答给要点句，按点给分时**每点一段、段首 ①–⑩**（历史「背景/内容/影响」、生物「结构/功能/过程」），不把要点挤成一段。纯记忆无可复现产物时按 `handout/pipeline.md` §2.2 用 `③ 不适用（纯记忆）`，不要写成「纯概念」。

## 备考侧重

- 主观题按点给分：答案句式「要点词 + 一句展开」，段首编号直接对齐阅卷给分点；背诵默写专项按薄弱点条目清单逐条清（每条一张 cloze 卡）。
- 考前一页纸 = 时间线 + 对比表 + 高频清单（common 应试技巧包的族内版）；选择题高频考点优先覆盖（R38 分层）。
