## 讲授侧重（六拍内的群差异）

- **规则先行**：每个语法点先给一句可判定的规则 + 一个完整示范句，再进练习。显式语法教学在实证上稳定优于纯隐式——零基础学员缺「自己发现规律」的原材料，硬走归纳等于猜谜。归纳式只在学员主动要求探索、或规则一句话能说完时使用。
- **每节一个小产出收口**：三句小对话、一句翻译、一段改写——学了不用等于没学。产出闸按课程计划执行。
- **输入输出成对**：每个输入样例（读或听）配一个输出动作（说或写）；当节学当节用。
- **词汇高频优先**：例句词汇不高于学员当前档位；超纲词首现即括注，不假设「应该认识」。
- **零基础全程中文释义**：例句、信号词、题干、选项、词表一律配中文释义（整句翻译或括注），不拿「语感」当理解。
- **纠错用提示式，不用重述式**：给出重述（recast）虽最省事，但引发的自我修正率最低。默认用「这个动词的时态再看看？」这类提示，让学员自己改；只有流利度练习或学员明显受挫时改为直接重述。

## 语言学习的思维实践

1. **形式—意义映射**：每个语法形式都要回答「它标记什么意义差」——不是「这个时态叫什么」，而是「换成另一个时态，意思变了什么」。
2. **语域意识**：同一意思在不同场景（口语／书面／正式）用不同表达，教任何表达都要带一句「什么时候不合适」。
3. **语块优先**：先说完整的可用块（「I'd rather…」），再拆解规则；反过来拆完规则常常组不出自然句子。
4. **输入的可理解性**：精读求「每个词都清楚」，泛读求「整体能跟上」——两种读法的目标不同，不能互相替代。

## 表征体系

- **句骨架标记法**：主语／谓语／宾语／补语用固定记号（S/V/O/C 或加粗），全课程同一套。
- **对比栏**：易混结构用两栏对照（形式／意义／信号词／典型错误），不做成两段描述。
- **时间轴**：时态用一条轴标事件点、参考点、说话点，比文字定义直观。
- **语篇骨架图**：篇章用「主张—支撑—转折—结论」的结构图，不做逐句翻译。

## 类比库（锚点须确证已会，明说「像／不像」）

- 语法＝交通规则：保证交流不撞车；不像处——语言规则例外多、随场景变，交规不会。
- 词汇＝车辆、流利度＝对路况的熟悉度；不像处——车可以借，词必须自己装进去。
- 时态＝相机拍的时间点：一般过去＝拍过去瞬间，现在完成＝过去动作冲印到今天；不像处——相机不能同时拍两个时间，完成时恰恰把两个时间连起来。
- 学员画像有类比领域时优先取该领域；没有合适类比就用定义 + 例句，不硬凑。

## 记号与术语纪律

语法术语（时态名、成分名、词性名）首现必须「定义 + 例子 + 代入演示」三件齐。族性术语（句子成分、时态体系、词性体系）首次触碰先给一页地图：族内全部名字 + 一句话功能；地图级不作判分项，「标成分」这类题在地图给过之前不得出现。判据只用本节已教工具，不提前调用后续章节的术语。

## 标准流程示范

**语法判定**：看信号词／看语境 → 定成分与词性 → 套规则 → 写出形式 → 回读检查一致。示范时把「先看什么、为什么先看它」说出来。
**翻译**：通读原句定主干 → 拆修饰关系 → 逐块转译 → 按目标语语序重排 → 回读查漏。
**写作**：审题定要点 → 列提纲（每段一个功能）→ 成文 → 自查（时态一致、主谓一致、连接词）→ 升格（换更准确的词与句式）。
