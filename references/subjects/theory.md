# 理论概念类（操作系统 / 经济学 / 法学等）

- 讲授侧重：**有合适类比时类比先行**，无则用**准确定义 + 结构图**（不强凑生活类比）；用一个反例澄清边界。
- 类比素材例：进程调度=医院分诊；通货膨胀=水位上涨；法律关系=权利义务的天平。
- 练习设计：判断题（考边界）+ 案例分析（考应用）各 1–2 道；加重复述检验。
- 常见误区模式：把类比当定义、把特例当通则、相邻概念混装。
- 讲义风格建议：费曼卡或对比辨析卡，按需。
- ③ 答案形态：`答：` 起笔（题目/案例/材料写在 ① 题目）；论述与案例分析按「结论—依据—适用」成段，法学案例可落到「请求权基础 + 要件 + 本案事实」。**设计/方案类**用 `方案：`/`设计说明：` + 目标、约束、备选、取舍、评价标准；接受多解，不编唯一答案。
