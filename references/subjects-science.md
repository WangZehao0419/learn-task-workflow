# science 学科群 正本册

> 本册是「science」学科族的四类切片（plan / teach / practice / review）合一。

## 实验科学群 · 规划切片

### 群边界与借用

本群：物理、化学、生物、地理与地球科学。四门共享三件事——**用模型解释现象、用实验验证模型、用多重表征描述模型**——所以合成一群；学科的专属误区与表征放在各自的学科包里。

默认内容类型分布：概念型与程序型并重（约各四成），记忆型（术语、常数、反应条件）约一成半，设计型（实验方案）少量。S2 按实际目清单核正。

借数学的地方：符号操作、方程求解、变式设计——由 `math-*.md` 提供；但**量纲、有效数字、图表判读、实验设计不借**，它们是本群的学科防线。

### 内容结构与前置链

- **四科主干链与前置断层**：物理 / 化学 / 生物 / 地理的逐科链与前置断层高发点见 `disciplines/` 对应学科包（physics / chemistry / biology / geography），本切片不重复维护——改链只改学科包一处。
- 跨学科共同前置：**能量与物质守恒**、**模型与现实的差别**、**因果与相关**。

### 目标深度锚点

- **概念型目**：能讲机制、能预测新现象、能说出模型的适用边界（SOLO 关联）。只会复述定义不算过。
- **程序型目**（计算、配平、实验操作）：能独立完成并说出每一步的物理／化学依据。
- **设计型目**（实验方案）：能定变量、设对照、说明如何排除干扰（SOLO 拓展抽象）。
- **记忆型目**：术语、常数、仪器名——到「能列举并区分易混」即可。
- 本群特别要防**「能算不能懂」**：算法题做对不代表概念成立。概念型目必须用概念题单独验收，不能用计算题替代。

### 排期侧重

- **实验与探究类目单独占课时**：实验设计、误差分析、图表处理不能挤在讲概念的同一轮里顺带说完。
- **一节一个模型**：本群一节课塞两个模型（例如同时讲动量守恒与能量守恒）几乎必然讲浅，宁可拆节。
- **真题/原始数据优先**：例题与练习优先取教材原始数据与真实图表，不用编造的整数化数据。
- **考前**：冲刺期转向概念题与实验题专项，计算题只做错题重做。

## 实验科学群 · 出题切片

### 题型阶梯

- **概念题**：先出「换情境仍能判断」的题（给新现象问用哪个原理），再出计算题。**概念题与计算题必须分开出**——能算对不代表懂，混在一起会把不懂掩盖成会。
- **预测题**：给条件改变，先问「结果会变大还是变小、为什么」，再算。预测轮本身就是检索练习。
- **图像题**：给 x-t／v-t 图、能量条图、浓度-时间曲线、等值线图，问斜率的物理意义、面积的物理意义、拐点代表什么。
- **实验设计题**：给目标，让学员写自变量／因变量／无关变量／对照设置／数据处理；再给一份有缺陷的方案让其找漏洞。
- **误差与排查题**：给一组偏低的实验数据，问可能原因并按影响方向排序。
- **交错**：概念、计算、图像三类混排，逼学员先判「这题在考什么」再动手。

### 群级共享误区库

只放**跨学科通用**的条目；冲力说、电流消耗模型、平衡即停止、光合呼吸互逆等学科专属误区见 `disciplines/` 下对应包。

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 公式当口诀 | 会套公式但说不出每个符号的物理意义，单位乱配 | 只背形式不建模型 | 把单位代进去看量纲是否成立 |
| 单位当装饰 | 计算中不写单位，结果没单位或单位错 | 只盯数字 | 量纲不对，结论必错 |
| 只看结果不看条件 | 把某条件下成立的结论套到全部情形 | 例题条件的代表性被夸大 | 换一个极限条件（趋零／极大）看结论是否仍成立 |
| 把现象当解释 | 「因为它是热的，所以温度高」式的循环解释 | 日常语言的因果倒置 | 追问「热是什么、温度是什么」，两者不可互证 |
| 只做一次实验就下结论 | 不提重复、不提误差 | 教材例题只给一组数据 | 问「再做一次结果会不会变」 |
| 忽略对照组 | 说「用了这个方法后变好了」却不设对照 | 叙事本能 | 问「不用这个方法会怎样」 |
| 混淆模型与实物 | 把粒子图当作真实照片、把光线图当作实景 | 示意图太逼真 | 问「这个模型哪里是简化」 |
| 只换数字不改结构就当作会了 | 同型题做对，换问法即卡 | 练习只有同型 | 换表征或逆问再测一次 |

### 判定题构造

问「用哪个模型」而不是「这个模型是什么」：给一个现象问该用哪条原理（且给一条「邻近情境下才对」的干扰原理）、给两组数据问哪组支持假设、给两种实验方案问哪个能排除干扰。干扰项要能写出「选它的人漏了哪个条件」。

### 答案形态与最小单元

- 计算题：`解：` 起笔，按「公式 → 代入（带单位）→ 结果（有效数字与单位）→ 方向或符号」分段；每段一个可独立核对的最小单元。跨学科一律用本条，不再分物理化学写法。
- 化学式与方程式：配平系数、条件、状态符号写在同一段，反应箭头用 `->` 不用 Unicode 箭头。
- 实验题：按「目的—变量—步骤—数据处理—误差分析」分段，每段一句可判结论。
- 概念题：`答：` 起笔，用「因为……所以……」写因果链，不写「就是这样」。

### 视觉任务

本群最常见的视觉任务：图像斜率与面积、装置图识别、显微结构识别、等值线判读、系谱图判读，一律取原始图、原始数据表与真实装置照并记录来源；替代禁令、证据资格与原图不可得处置见 `references/assessment.md`「视觉任务证据」。

### 给分点结构

计算题按「列式／代入／结果／单位与有效数字」四段给分；实验题按「变量／对照／步骤／数据处理／结论」五段给分；概念题按「主张／证据／推理」三段给分。

## 实验科学群 · 复习切片

### 复习形态与间隔侧重

- **概念靠迁移检验，不靠复述检验**：复习概念型目一律换情境——同一个原理换一个新现象来判。能复述定义、换情境就错，等于没掌握。
- **表征互译作热身**：给一张图让学生说过程，或给一段文字让学生画图，一分钟即可，比重新讲一遍有效。
- **公式与常数分层**：能推导的（由定义推出来的关系式）降到低频，只保留「会用」检验；推不出的（常数、特定条件下的经验关系）保持固定间隔。
- **实验类目用「方案复现」复习**：给目标让学生重写一份方案，与之前的对比差在哪。
- **图类知识用组块复现**：把同一类图像（v-t、浓度-时间、等值线）攒成一组对比着看，比单张反复看更能建立判别力。

### 错因分流与纠错脚本

| 错因 | 判别信号 | 纠错动作 |
|---|---|---|
| 模型缺失 | 能套公式但预测新现象就错 | 回到现象层重建模型，补「模型解释什么、预测什么、何时失效」 |
| 表征转换失败 | 会算但读不懂图，或画不出图 | 专项练互译：图→文、文→图、表→结论 |
| 条件遗漏 | 套用了不成立的前提 | 每题强制写「适用条件」一行，缺条件即扣 |
| 单位与量纲 | 结果数量级离谱 | 把单位追踪写进每一步，作为硬性格式 |
| 实验设计残缺 | 漏对照、漏无关变量 | 用三件套清单逐项自查，缺项不允许提交 |
| 审题偏差 | 答非所问、漏问 | 审题圈画：目标、条件、限制各圈一处 |

**纠错话术**：本群的错多来自「模型用错了」而非「算错了」，纠错要点明是哪一个假设／条件出了问题，不要笼统说「再想想」。

### 冲刺侧重（方法层）

- **概念题优先级高于计算题**：本群的失分大头在概念混淆，冲刺期把概念题与图像题排在计算题前面。
- **实验题模板化**：把「目的—变量—步骤—数据处理—误差」写成固定骨架，考试时按骨架填空，避免漏项。
- **单位与有效数字不丢分**：这是最容易拿也最容易丢的分，冲刺期把它写成检查清单。
- **计算题限时**：只用错题重做，不刷新题；单题超时先跳过。

## 实验科学群 · 讲授切片

### 讲授侧重（六拍内的群差异）

- **现象先于模型**：先给可观察的现象或数据，再问「什么模型能解释它」，最后才给公式。反过来讲（先公式后现象）会让学员把公式当口诀背。
- **一个模型三条腿**：讲任何模型都要说清它**解释了哪些现象**、**预测什么**、**在哪里失效**。缺第三条就是把它当真理教。
- **单位与量纲全程在场**：从第一道例题起，每个量带单位写；结果出来先查量纲，再查数量级。单位不是格式，是自检手段。
- **图先于式**：受力图、能量条图、粒子图、电路图、流程图先画，再列方程。图上标清楚系统边界与正方向。
- **实验设计三件套**：自变量、因变量、无关变量（须控制）——先能说清这三件，再谈具体步骤。
- **重复与对照**：讲到「这说明什么」之前，先问一句「还有别的解释吗」——把对照组与替代解释摆在台面上。
- **演示走预测—观察—解释**：先让学员写下预测与理由，再给真实结果；预测与结果冲突时才是解释的入口，预测不落字就等于没有预测。

### 学科思维实践

本群的核心不是知识点，是三类可迁移的思维动作：

1. **建模**：定系统与边界 → 选关键变量 → 作简化假设 → 写关系 → 用数据检验 → 说明适用条件。每一步都要学员说得出「假设了什么」。
2. **论证**：主张—证据—推理（CER）。任何「所以……」都要问「你的证据是什么」「为什么这条证据支持这个主张」。
3. **尺度与系统**：同一现象在分子层、个体层、系统层看到的机制不同（化学的微观／宏观／符号三重表征、生物的层级尺度、地理的多尺度区域）。换尺度重述同一件事，是本群最好的复述题。

### 表征体系

多重表征互译是本群最有效的教学杠杆：**文字描述 ↔ 图形／装置图 ↔ 数据表／图像 ↔ 方程／化学式**。同一对象至少给两种表征，并要求互译——「把这段过程画成图」「把这个图写成一句话」「根据这张表说出趋势并给解释」。三重表征在化学尤其刚性：宏观现象、粒子图景、符号方程至少两层联动才算讲清。

### 类比库

- 电路＝水路：电压像水位差、电流像流量；不像处——水会漏，电荷不会消失，且电流不是「被用掉」。
- 原子＝太阳系：核在中心、电子绕行；不像处——电子没有确定轨道，只是概率分布。
- 酶＝钥匙配锁：专一性；不像处——底物这把「钥匙」反应后被改写成产物，真钥匙开完锁原样拔出；像处——酶与锁都可反复使用。
- 自然选择＝筛子：环境筛掉不适应的变异；不像处——筛子是外力，选择没有目的，也不产生变异。
- 地球公转＝绕圈跑：轨道与倾角；**不要用「离太阳近所以热」的类比**，那是本群第一大误区（详见 `references/disciplines/geography.md`）。

### 记号与术语纪律

- 物理量符号与单位成对出现，同一课程内不换符号；矢量要标方向或用分量。
- 化学式、离子式、状态符号 (s)(l)(g)(aq)、反应条件（点燃／△／催化剂）为一等公民，缺项即算错。
- 生物与地理的术语首现给「白话 + 一句定义 + 一个例子」；同义异名（如「内环境」与「细胞外液」）统一到一个，另一个括注。

### 标准流程示范

**计算题**：画图并标已知 → 定系统与正方向 → 选原理（说为什么是这条）→ 列式并带单位代入 → 求值并定有效数字 → 量纲与数量级检验 → 说明结论的物理意义。
**实验题**：明确要测什么 → 定自变量与因变量 → 列无关变量及控制方法 → 写步骤（可复现）→ 说数据处理方式 → 说误差来源与影响方向。

### 撤架判据

概念型目以「能否预测新现象」为撤架信号，程序型目以「独立完成 + 说出每步依据」为信号；达到即撤完整样例，改换情境题。未达到时继续给样例，不按课时硬撤。
