**块游标**：`task_index.py` 从 `## 下次续学` 的「小节」行解析「已讲到第 k/总块」→ 输出 `current_block` / `block_total`（缺失为 null，零迁移）；`块=` 仍为人读字段，不进闸口。

**交接、学习记录与讲授证据**：四类文本各司其职——`学习日志` 是**事件时间线**（只追加）；`本次交接` 是**下一次开场的摘要**（每次收尾覆盖重写：总结 / 下次先做 / 未解决）；`下次续学` 是**任务状态与动作游标**（阶段、小节、待回应项）；`学习记录` 是**任务级持久洞察**（最多 5–7 条，回答“这个学员在这个任务里为什么卡/为什么通了”，不写流水账）。`学习记录` 不替代 `profile.md` ②：跨任务稳定模式进画像，任务内洞察留本区；**本区不直接写跨任务结论**，判断可跨任务时按 `profile.md` ② 的证据/确认流程另写。没有新洞察时不写，空更新合法。缺少 `本次交接` / `学习记录` 的旧任务，按学习日志最近一条 + `下次续学` 恢复，不补造。**若 `本次交接` 与 `下次续学` 冲突，以 `下次续学` 的阶段/小节/动作游标为准**，开场向学员说明差异，不按交接里的旧话硬推。**下次开场先处理 `未解决`**；同一未解决项跨多次仍未动，转入薄弱点 / 暂缓与范围外 / 学习记录，不无限滞留在交接里。`学习记录` 最多 5–7 条，超出时合并重复、删除低信号或已被推翻的；**讲授证据**只给深讲/关键概念记，同一概念保留最近一条，不逐题记。**讲授证据**只记“已经公开讲给学习者”的内容：逐字引用 + 来源页码/链接；计划、内部思考、工具结果、来源原文都不算；讲授证据只证明“讲过”，不证明“学会”，也不替代判分/复述闸口。来源不可用或不确定时如实说明，不编造。

**记忆写法纪律**：正文/洞察每条 ≤120 字（`profile.md` ② 的作用域、证据、日期、状态等元数据不计入）；用动词短语（“使用 X”“卡在 Y”“换 Z 后能独立完成”），不用形容词标签；每条带证据（日期 + 场景/原话）；推断标“暂定”，只有学员陈述或后续证据才升级；禁用绝对化词（深刻、彻底、完美掌握、专家、热爱、总是、从来不、完全理解）；无证据不写；空更新合法；当前证据与当前表态优先于旧记录；一次困难不得写成全局人格判断。

**动作游标（F08，可选、零迁移）**：恢复只到「阶段 + 小节」不足以区分「待出题 / 待作答 / 待批改 / 待落盘」——续学时先读本行定位**当前动作与待回应项**。出题后中断 → 据「待回应：题组文件 + 题号」继续原题，不重新出题；已答未批改 → 据「最后提交」指向的作答继续批改，不重复作答。无本行的旧任务 = 合法形态，退回「阶段 + 小节」恢复。

**保持复习区**：位置在「错题归档」之后、「暂缓与范围外」之前；`scheduler.py due-queue` 把它与「薄弱点」「错题本」一起读取，条目用 `kind=保持` 标识。**写入时机**：① S3 小节达标 → 新增该小节的保持条目；② S4 薄弱点连续 2 轮全对清除 → 转入本区（不得直接消失）；③ S5 结课后复习清单以本区为准。**初始值**：取契约 `scheduler` 块（default_s / default_d 与 due 偏移），last=掌握/清除日；用 `scheduler.py next-interval --new-card --grade good --last <日> --today <日>` 算，不心算。**日期前缀**：行首 `[YYYY-MM-DD]` 推荐；省略时以元数据 `last`/`due` 或「最近更新」兜底，全部缺失才报 `W-UNPARSED-ITEM` 不入队。**同一小节/知识点只保留一条**：复习时更新原行，不重复追加；对象身份优先用 `lesson_id` 或稳定的知识点名。**复习判分**：按既有条目命令更新 S/D/due；失败（Again）仍留本区，按短间隔重测；若需重讲，按条目对应小节回炉，**不要为同一知识点另建一套 S/D 调度条目**。**已完成任务的保持复习**：仍可由 due-queue 触发 S4，复习后按「复习来源阶段=已完成」返回。旧任务缺本区 = 合法形态，due-queue 零感知，不补建、不批量迁移。

**模块目标与材料覆盖**：`模块目标` 每行 `M1 ｜ 模块名 ｜ 学完能独立……`，一句能力句，不是话题清单；修改模块内容时不得违背该句，超出就重新设计。`材料覆盖` 每行 `材料 → M1 / M2`，每份材料至少归入一个模块，不允许静默遗漏。**有材料但缺 `材料覆盖`**，或**有 `材料覆盖` 但缺模块目标** → `W-MODULE-CONTRACT-INCOMPLETE`；无材料任务只写模块目标合法，不报缺覆盖。行畸形或仍是 `<…>`/待填占位 → `W-UNPARSED-MODULE` / `W-UNPARSED-MATERIAL`；`材料覆盖` 条目少于 `材料` 条目，或某份材料的字面名未在覆盖区出现 → `W-MATERIAL-COVERAGE-GAP`（简称/改名可人工确认）。旧任务两区都缺 = 合法形态，不补建、不报错。

**质量保障机制（可选区）**：记录本任务的体例约定（LaTeX 排版 / 答案框形态）与定稿校验结论；**讲义头部指针行指向本区**（头部只写指针，规则正文不进讲义，见 `handout/pipeline.md`「讲义头部（讲义状态行 + 可选指针行，不复制规则正文）」）。**自检 W 项的显式后置理由记在本区**（无后置写「无」）——这是 W 后置的唯一落盘位置。缺失 = 合法旧任务形态，零迁移。

**可选 token `子类=`**：错因第六类“过度泛化”写 `错因=理解性` + `子类=过度泛化`；`scheduler.py` 已识别该键（不参与调度计算、不输出到 due-queue），不会再报 `W-META-INVALID`。

**字段合法性**（由 `<技能根>/scripts/progress_check.py` 校验）：`当前阶段`、`类型`、`学科族` 必须为上述枚举值之一；`复习来源阶段` 在 S4 期间必须为合法返回枚举（**逐节学习 / 结课 / 已完成**，任意字符串被拒）。**必填项随阶段变化**：`当前阶段`、`类型`、`学科族`、`目标` 全程必填；**`起点` 在 S0（接料建档）与 S1（诊断摸底，进行中）不要求，自诊断结束进入 S2 起（计划确认中/逐节学习/复习巩固/结课/已完成）必填**——S1 尚未产出「起点」属正常，不得据此误判。**周里程碑（可选区）**：S2 排期产出、每周首次开课对账（见 `workflow/gates.md`「周对账」）；旧任务缺失 = 合法形态，不补建、不报错（零迁移）。

**勾选语法**：学习路线用 `- [x] N. <小节名>`（`x`/`X` 均可）标记已掌握、`- [ ] N. <小节名>` 标记未完成；N 为小节序号（阿拉伯数字）。若某行出现勾选语法却不匹配该格式，`<技能根>/scripts/progress_check.py` 将输出 `W-UNPARSED-ROUTE` 告警（不静默吞掉）。

**「暂缓与范围外」区块**：位置在「错题归档」之后、「学习日志」之前；条目为自由文本 + 竖线（`｜`）分段（来源 / 处置 / 触发条件 三段），**不做枚举硬校验**——有竖线分段但字段残缺的条目由 `<技能根>/scripts/progress_check.py` / `<技能根>/scripts/task_index.py` 输出 `W-UNPARSED-HOLD` 告警（不静默、不计入 hold_count）；**无竖线分段的纯自由文本行**不判畸形、仍计入 `hold_count`（解析器宽容口径；建议仍按三段式书写，以便 W-KP-HOLD-CROSS 交叉核对）；无暂缓项时本区写「无」。区块本身**可选**：旧任务缺失 = 合法「未审计」形态（见下方零迁移兼容）。

### 复习调度字段（薄弱点 / 错题本 / 保持复习条目元数据）

> 何时读：写薄弱点/错题/保持复习条目的元数据（挂载点、字段表、cw/顽固语义）时。

薄弱点条目的调度元数据放**行尾全角括号内**（半角括号 `()` 亦兼容，推荐全角）、逗号分隔的 `键=值`（`cw`/`顽固` 为无值标记）；错题本与保持复习条目在行尾追加「｜ 元数据：…」段（竖线分段与「元数据：」冒号均全角/半角双兼容）。保持复习行推荐以 `[YYYY-MM-DD]` 掌握日期开头；缺日期时用「最近更新」兜底并告警，仍缺 → `W-UNPARSED-ITEM` 不入队（不猜当日）。解析器只认这些挂载点，其余文本不动。`S'/D'/due` 的计算由 `<技能根>/scripts/scheduler.py next-interval` 负责（判分归模型、算数归脚本，调用细则见 `assessment/scheduling.md`「间隔调度」）。`due-queue` 输出新增 `reason` 字段（到期/逾期/优先级的人类可读说明），schema 为 `ltw-due-queue/3`。`错因`/`级`/`meta_default` 只对薄弱点/错题有意义；`kind=保持` 时前者为空、`meta_default=false`，不参与问题元数据。

| 字段 | 类型/取值 | 语义 | 默认值（缺省时） |
|------|-----------|------|------------------|
| S | 浮点（天） | 稳定天数，间隔重复核心参数 | 3.0 |
| D | 数值 0.5 粒度，[1,5] | 难度 | 3 |
| last | YYYY-MM-DD | 最近一次判分日期（绝对日期，禁相对日期） | 取 progress.md「最近更新」；仍缺 → 不入队，报 `W-UNPARSED-ITEM`（不猜当日） |
| due | YYYY-MM-DD | 下次复习日。**新写由 `scheduler.py` 以「本次复习日 + interval」计算**（见 `assessment/scheduling.md`「间隔调度」）；旧条目缺 due 时按 `last + round(S)` 兜底推算 | 由 last 推算 |
| 信心 | 1–5 | 作答信心自评（**反馈前**提交方可用于 cw/校准；反馈后补报标回顾性） | 未写 → 不计入校准分母（不补 3） |
| cw | 标记（无值） | 自信但错（**反馈前**信心 ≥4 且判错），due-queue 排序优先 | 无 |
| 顽固 | 标记（无值） | 提示阶梯两次到梯底，重教不重测（见 S3/S4） | 无 |
| evt | 可选 ID | **作答事件 ID（v2.3）**：同一次作答的投影（错题 / 薄弱点）共享同一 `evt`，供校准统计去重（T04）；旧条目缺 = 合法 | 无 |
| 错因 | 枚举：知识性 / 理解性 / 技巧性 | 归因分类，决定 S4 补救动作（重学 / 审题圈画 / 限时技巧）。**语义属性，归模型判断写入，禁止脚本代判** | 知识性 |
| 级 | 枚举：A / B / C | A=反复出错 / 直接影响学习目标达成的核心条目（详细整理+变式）；B=一般理解偏差（记思路）；C=纯粗心（仅标知识点）。与错因同轮由模型定级，S4 复习判分可调整级别 | B |

- `cw` 只由「信心 ≥4 且判错」产生；cw 条目修复后照常走清除/归档规则。
- due-queue 对 `顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- **`错因` 枚举放元数据段，与既有自由文本「错因：<具体描述>」并存不冲突**：自由文本答「错在哪」（行内 `错因：` 全角冒号写法），枚举答「属哪类、该用什么补救」（元数据段内 `错因=` 等号写法）。解析器只在元数据段内搜 `错因=`，正则锚定于元数据段，不会误吃行首自由文本。
- **`级` 与 `错因` 是内容属性（错什么），S/D 是调度属性（何时再练），互不替代；`级` 不参与 due-queue 排序**（排序契约 cw→最逾期→due 早→稳定序不变），分级只影响整理深度与复盘注意力，脚本仅在输出中回显 错因/级 供模型取用。
