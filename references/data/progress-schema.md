**目游标**：`task_index.py` 从 `## 下次续学` 的「节」行解析「已讲到第 k/N 目」→ 输出 `current_item` / `item_total`（缺失为 null）；目名随游标成对书写。**目编号是唯一游标口径**——按节连续（=KP 序），禁止按场分段重编号。

**三簿读写分工**：续学开场读 progress.md（本文件）恢复状态与游标；开节/规划读 `课程体系.md` 对应章/节；历史与洞察读 `记忆.md`。字段冲突时以本文件的状态字段为准。

**交接与记忆**：`本次交接` 是下一次开场的摘要（每次收尾覆盖重写）；事件时间线（学习日志）、持久洞察（学习记录）、讲授证据落 `记忆.md`（格式见 `data/memory.md`「记忆文件」）。**若 `本次交接` 与 `下次续学` 冲突，以 `下次续学` 的阶段/节/动作游标为准**，开场向学员说明差异，不按交接里的旧话硬推。**下次开场先处理 `未解决`**；同一未解决项跨多次仍未动，转入薄弱点 / 暂缓与范围外 / 记忆.md 学习记录，不无限滞留在交接里。

**记忆写法纪律**（适用于本次交接与记忆.md 各区）：正文/洞察每条 ≤120 字（`profile.md` ② 的作用域、证据、日期、状态等元数据不计入）；用动词短语（"使用 X""卡在 Y""换 Z 后能独立完成"），不用形容词标签；每条带证据（日期 + 场景/原话）；推断标"暂定"，只有学员陈述或后续证据才升级；禁用绝对化词（深刻、彻底、完美掌握、专家、热爱、总是、从来不、完全理解）；无证据不写；空更新合法；当前证据与当前表态优先于旧记录；一次困难不得写成全局人格判断。

**动作游标（F08，可选）**：恢复只到「阶段 + 节」不足以区分「待出题 / 待作答 / 待批改 / 待落盘」——续学时先读本行定位**当前动作与待回应项**。出题后中断 → 据「待回应：题组文件 + 题号」继续原题，不重新出题；已答未批改 → 据「最后提交」指向的作答继续批改，不重复作答。缺本行 = 合法形态，退回「阶段 + 节」恢复。

**保持复习区**：位置在「错题归档」之后、「暂缓与范围外」之前；`scheduler.py due-queue` 把它与「薄弱点」「错题本」一起读取，条目用 `kind=保持` 标识。**写入时机**：① S3 节达标 → 新增该节的保持条目；② S4 薄弱点连续 2 轮全对清除 → 转入本区（不得直接消失）；③ S5 结课后复习清单以本区为准。**初始值**：取契约 `scheduler` 块（default_s / default_d 与 due 偏移），last=掌握/清除日；用 `scheduler.py next-interval --new-card --grade good --last <日> --today <日>` 算，不心算。**日期前缀**：行首 `[YYYY-MM-DD]` 推荐；缺日期时用元数据 `last`/`due` 或「最近更新」兜底，全部缺失才报 `W-UNPARSED-ITEM` 不入队（不猜当日）。**同一节/目只保留一条**：复习时更新原行，不重复追加；对象身份优先用 `lesson_id` 或稳定的目名。**复习判分**：按既有条目命令更新 S/D/due；失败（Again）仍留本区，按短间隔重测；若需重讲，按条目对应节回炉，**不要为同一知识点另建一套 S/D 调度条目**。**已完成任务的保持复习**：仍可由 due-queue 触发 S4，复习后按「复习来源阶段=已完成」返回。

**暂缓与范围区块**：条目为自由文本 + 竖线（`｜`）分段（来源 / 处置 / 触发条件 三段），**不做枚举硬校验**——有竖线分段但字段残缺的条目由 `progress_check.py` / `task_index.py` 输出 `W-UNPARSED-HOLD` 告警（不静默、不计入 hold_count）；**无竖线分段的纯自由文本行**不判畸形、仍计入 `hold_count`（解析器宽容口径；建议仍按三段式书写，以便 W-KP-HOLD-CROSS 交叉核对）；无暂缓项时本区写「无」。

### 复习调度字段（薄弱点 / 错题本 / 保持复习条目元数据）

<!-- intent:I-KEEP-REVIEW-WRITE@global -->

> 何时读：写薄弱点/错题/保持复习条目的元数据（挂载点、字段表、cw/顽固语义）时。

薄弱点条目的调度元数据放**行尾全角括号内**（半角括号亦兼容，推荐全角）、逗号分隔的 `键=值`（`cw`/`顽固` 为无值标记）；错题本与保持复习条目在行尾追加「｜ 元数据：…」段（竖线分段与「元数据：」冒号均全角/半角双兼容）。保持复习行推荐以 `[YYYY-MM-DD]` 掌握日期开头；缺日期时用「最近更新」兜底并告警，仍缺 → `W-UNPARSED-ITEM` 不入队（不猜当日）。解析器只认这些挂载点，其余文本不动。`S'/D'/due` 的计算由 `scripts/scheduler.py next-interval` 负责（判分归模型、算数归脚本，调用细则见 `assessment/scheduling.md`「间隔调度」）。`due-queue` 输出 `reason` 字段（到期/逾期/优先级的人类可读说明），schema 为 `ltw-due-queue/3`。`错因`/`级`/`meta_default` 只对薄弱点/错题有意义；`kind=保持` 时前者为空、`meta_default=false`，不参与问题元数据。

| 字段 | 类型/取值 | 语义 | 默认值（缺省时） |
|------|-----------|------|------------------|
| S | 浮点（天） | 稳定天数，间隔重复核心参数 | 3.0 |
| D | 数值 0.5 粒度，[1,5] | 难度 | 3 |
| last | YYYY-MM-DD | 最近一次判分日期（绝对日期，禁相对日期） | 取 progress.md「最近更新」；仍缺 → 不入队，报 `W-UNPARSED-ITEM`（不猜当日） |
| due | YYYY-MM-DD | 下次复习日。**新写由 `scheduler.py` 以「本次复习日 + interval」计算**（见 `assessment/scheduling.md`「间隔调度」）；缺 due 时按 `last + round(S)` 兜底推算 | 由 last 推算 |
| 信心 | 1–5 | 作答信心自评（**反馈前**提交方可用于 cw/校准；反馈后补报标回顾性） | 未写 → 不计入校准分母（不补 3） |
| cw | 标记（无值） | 自信但错（**反馈前**信心 ≥4 且判错），due-queue 排序优先 | 无 |
| 顽固 | 标记（无值） | 提示阶梯两次到梯底，重教不重测（见 S3/S4） | 无 |
| evt | 可选 ID | **作答事件 ID**：同一次作答的投影（错题 / 薄弱点）共享同一 `evt`，供校准统计去重（T04） | 无 |
| 错因 | 枚举：知识性 / 理解性 / 技巧性 | 归因分类，决定 S4 补救动作（重学 / 审题圈画 / 限时技巧）。**语义属性，归模型判断写入，禁止脚本代判** | 知识性 |
| 级 | 枚举：A / B / C | A=反复出错 / 直接影响学习目标达成的核心条目（详细整理+变式）；B=一般理解偏差（记思路）；C=纯粗心（仅标知识点）。与错因同轮由模型定级，S4 复习判分可调整级别 | B |

- `cw` 只由「信心 ≥4 且判错」产生；cw 条目修复后照常走清除/归档规则。
- due-queue 对 `顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- **`错因` 枚举放元数据段，与既有自由文本「错因：<具体描述>」并存不冲突**：自由文本答「错在哪」（行内 `错因：` 全角冒号写法），枚举答「属哪类、该用什么补救」（元数据段内 `错因=` 等号写法）。解析器只在元数据段内搜 `错因=`，正则锚定于元数据段，不会误吃行首自由文本。
- **`级` 与 `错因` 是内容属性（错什么），S/D 是调度属性（何时再练），互不替代；`级` 不参与 due-queue 排序**（排序契约 cw→最逾期→due 早→稳定序不变），分级只影响整理深度与复盘注意力，脚本仅在输出中回显 错因/级 供模型取用。
- **可选 token `子类=`**：错因第六类"过度泛化"写 `错因=理解性` + `子类=过度泛化`；`scheduler.py` 已识别该键（不参与调度计算、不输出到 due-queue），不会再报 `W-META-INVALID`。

**字段合法性**（由 `scripts/progress_check.py` 校验）：`当前阶段`、`类型`、`学科族` 必须为上述枚举值之一；`复习来源阶段` 在 S4 期间必须为合法返回枚举（**逐节学习 / 结课 / 已完成**，任意字符串被拒）。**必填项随阶段变化**：`当前阶段`、`类型`、`学科族`、`目标` 全程必填；**`起点` 在 S0（接料建档）与 S1（诊断摸底，进行中）不要求，自诊断结束进入 S2 起（计划确认中/逐节学习/复习巩固/结课/已完成）必填**——S1 尚未产出「起点」属正常，不得据此误判。
