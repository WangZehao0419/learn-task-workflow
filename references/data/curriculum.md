## 课程体系文件

**文件**：`<数据根>/<slug>/课程体系.md`，任务目录第一层、与 progress.md 平级（不放 materials/）。它是**详细的课程规划**：章/节/目三级结构 + 每目的账本行，同时承担四职——覆盖分母、前置依赖图、术语账本（`引入` 列，R46 出题对账）、分型验收底座。**全类型强制**：四类任务 S2 一律生成；唯一例外 = 极简任务经用户确认的「无课程体系」形态（对照结论声明理由）。**详细度标准 = 原子判据**：细化到「1 道题能独立检验」的最细知识点（目）才算合格；允许分批细化（覆盖范围行显式标注），但**每节开讲前本节目的必须细化完毕并登记引入列**。

**格式模板**（逐行 + 全角 ｜ 分段；**示例仅为格式演示，目的取舍与依赖声明规则本身领域无关**）：

**层级口径（章/节/目）**：**章** = 课程顶层分组（教材的部/章、考纲板块或自拟分组；教材结构与课程章的对应经「章→节」归属与对照结论呈现，不要求一一对应）；**节** = 学习路线一行（`- [x] N. 节名`）；**目** = 节下最细知识点。**目行 = 原 KP 行**，编号 `KP-<两位节序>-<两位KP序>`（如 KP-03-08 = 第 3 节第 8 个目），两位补零沿用材料编号契约，脚本宽容匹配单位数；纯数字字典序 = 教学序，编号全文件唯一。**每个目必须有目名**（即知识点名），目名节内唯一；**目序按节连续，禁止按场/次分段重编号**。对学员指代一律用目名（说「知识点」），编号只落盘且与名称成对（`目=8「介词」`）。

**不属于已拆节的目**（暂缓 / 排除 / 计划外）用**伪节序专号段**（节序取 90 起，如 `KP-90-01`；保持两位数字以适配脚本正则），该段只按状态计数、不映射到任何节。

- **kp_sort 返回口径**：`<技能根>/scripts/kp_sort.py --list <课程体系.md>` 的 `order` 含**全部目行**（含暂缓/排除；输出另带 `excluded`/`held` 计数），讲授序与出题序仅取**纳入项**（状态 ∈ {未讲, 已讲}），暂缓/排除不入出题分母（见 `workflow/gates.md` S5）。
- **摸底标注（保守口径）**：S1 摸底命中且有判分证据的目，状态列写 `未讲（已会：<摸底证据>，<日期>）`——信息性标注，**留在审计分母内**（按「未讲」基值计数），任何把目标「排除」出分母的动作必须经用户显式确认；标注随 S2 对照结论一并展示。
- **字段合法性**：前置列只接受合法 KP 编号或空；`progress_check.py` 校验前置引用存在性（引用不存在的 KP → W-UNPARSED-KP）；行畸形（缺段/状态非法）→ W-UNPARSED-KP，**不计入摘要计数**（不静默）。
- **互为前置定向**：概念目与程序目互为前置会成环，`kp_sort.py` 报环即停；此时按「先教可独立检验的一侧」定向登记前置边，另一侧紧接着教（同节或相邻节，不悬空），复习把两侧串起来。
- **可选分型字段**：目行第 6 段后追加 `｜ 类型：记忆/概念/程序/设计`（精确枚举；全/半角冒号均可）与/或 `｜ 视觉任务：识别/关系/图表/比较`（多选用逗号/顿号分隔）。声明后启用分型验收；口径见 `workflow/s3-block.md`「S3 闸口（可检验）」。KP 标签支持单位数别名（`KP-1-1` ≡ `KP-01-01`）。分型门按 KP 编号的节序归组；重排节时保持编号稳定或同步更新 KP 编号/所属节，避免分型证据串节。`kp_sort.py` 只读前六段，忽略可选字段；可选字段畸形 → W-UNPARSED-KP，放行模式另报 E-KP-TYPED-GATE（不能靠写坏字段绕过分型门）。
- **引入字段**：追加 `｜ 引入：<术语1；术语2>…`，登记该目**首次引入**的术语/记号/族名（如「定语」「现在完成时」「±记号」；分号或顿号分隔）。这是出题前术语对账（R46，见 `assessment/generation.md`「出题前术语对账」）的账本：`scripts/prereq_check.py --list <课程体系.md>` 以已讲目的引入列 ∪ 目名 ∪ 追加项为「已引入集合」，扫描题面中的未引入术语。**新任务开节时逐目登记**；术语命名与讲授一致（同一概念全文件同名），畸形容忍：缺段不报错，只贡献空集。
- **覆盖范围行（分批显式标注）**：分批产出时必须写「已细化至第 N 节，其余待细化」；行缺失视同全量；分批未显式标注即 SR-7 命中。未拆节的滚雪球候选拒绝入目行（仍留 progress.md「暂缓与范围外」标「滚雪球候选」）。
- **progress.md 指针（元信息区可选字段）**：`- 课程体系：课程体系.md ｜ 版本 <N> ｜ 总 <M>`——指针存在但文件不存在 → W-KP-LIST-MISSING。
- **暂缓/排除双写与交叉核对**：课程体系目行记状态（分母账本），progress.md「暂缓与范围外」记处置明细（处置账本），职责不重叠。交叉核对**按对象 ID 集合对账**（**数量相同但对象不同也能检出**；warning 级，由 `progress_check.py` 只读输出）：目行暂缓集合 ≠ progress.md 暂缓区块可比条目的 KP 集合（剔除设计性范围外与排除条目）→ **W-KP-HOLD-CROSS**（暂缓侧，列出「仅清单 / 仅区块」差异）；目行排除集合 ≠ 处置为排除条目的 KP 集合 → **W-KP-HOLD-CROSS**（排除侧）；节勾选「已掌握」× 该节目行全「未讲」→ **W-KP-STATE-MISMATCH**（可能是账本滞后，处置归模型提醒补齐）。
