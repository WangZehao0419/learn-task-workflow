## 三簿分工（数据布局总纲）

每个任务的持久数据按「状态 / 规划 / 叙事」拆三簿，外加全局画像——**一类信息只进一本账**：

| 簿 | 文件 | 装什么 | 不装什么 |
|---|---|---|---|
| 状态簿 | `<slug>/progress.md` | 元信息、薄弱点/错题本/错题归档/保持复习（调度队列）、暂缓与范围外、本次交接、下次续学 | 任何规划与叙事 |
| 规划簿 | `<slug>/课程体系.md` | 章/节/目三级规划、目行账本（状态/前置/引入/类型）、对照结论、材料、材料覆盖、排期、质量保障机制、协作协议 | 判分记录、调度队列、对话叙事 |
| 叙事簿 | `<slug>/记忆.md` | 学习日志（事件时间线）、学习记录（任务级洞察）、讲授证据 | 状态字段、规划 |
| 画像 | `<数据根>/profile.md` | 跨任务学习者画像（见下「学习者画像」） | 任务内洞察（进记忆.md） |

**读写纪律**：续学开场读状态簿恢复游标；开节/重排读规划簿对应章/节；复盘与画像读取读叙事簿。同一信息出现两处 = 结构违规，以本册定义的簿为准并当场去重。判分记录仍在 `exercises/`（单一判分证据源，见 `data/layout.md`「题组与判分文件」）。

## 课程体系文件

**文件**：`<数据根>/<slug>/课程体系.md`，任务目录第一层、与 progress.md 平级（不放 materials/）。它是**详细的课程规划**：章/节/目三级结构 + 每目的账本行，同时承担四职——覆盖分母、前置依赖图、术语账本（`引入` 列，R46 出题对账）、分型验收底座。**全类型强制**：四类任务 S2 一律生成；唯一例外 = 极简任务经用户确认的「无课程体系」形态（对照结论声明理由）。**详细度标准 = 原子判据**：细化到「1 道题能独立检验」的最细知识点（目）才算合格；允许分批细化（覆盖范围行显式标注），但**每节开讲前本节目的必须细化完毕并登记引入列**。

**格式模板**（逐行 + 全角 ｜ 分段；**示例仅为格式演示，目的取舍与依赖声明规则本身领域无关**）：

## 学习者画像（可选全局文件）

**文件**：`<数据根>/profile.md`，**全局唯一**、跨任务共享（画像放数据根第一层、与任务目录平级）。**偏好按作用域生效（F13）**：①层 = 学员明说的**通用偏好**，跨主题适用；②层「稳定模式」**默认任务级作用域**（可标任务/学科族/全局），**带证据、可复评、可关闭**；**教法裁决与类比领域按任务/学科族作用域生效**，**不得当作跨主题的全局人格标签**，也不得据单任务低效就对同类主题预判。**可选**：无此文件 = 合法形态，不强制创建、不报错；首次触发建立时机 = S1 摸底顺带问「类比领域」时（见 `workflow/gates.md` S1），用户不便回答则跳过。**单一事实源声明**：画像内容的唯一事实源是本文件；讲授/类比时由模型现场读取。

**格式模板**（三层结构，逐层追加）：

```markdown
# 学习者画像
- 最近更新：<YYYY-MM-DD>

## ① 明说的偏好（只有学员亲口明确提过的才进这里；**明确通用偏好，跨主题适用**）
- 类比领域：做饭（S1 摸底时确认，2026-10-12）
- 沟通约定：<学员明确要求的沟通规则，如「不要堆术语」「重点加粗、结论先行」（无则写「无」）>

## ② 稳定模式（跨多次对话看清的，每条必须带证据；**带作用域：默认任务级，非全局人格标签**）
- <模式描述>（作用域：<任务/学科族/全局>；证据：<日期> <学员原话/具体场景>；至少 2 条独立证据）
- <教学方法裁决>：<有效 / 低效>（**作用域：<学科族 / 任务 / 目标>**；条件：<什么场景下>；证据：<日期> <场景与效果>；裁决日期：<YYYY-MM-DD>；状态：<生效 / 已复评 / 已关闭>）——同一条裁决**可复评、可关闭、可删除**；低效裁决在**其作用域内**不再推该方法，**不跨任务/学科族永久禁用**（数学类比无效 ≠ 编程类比无效），也不写成人格标签

## ③ 观察暂存（注意到了但没看清的，只记场景）
- <日期> 在 <什么场景> 做了 <什么>——<尚未归类，不起名字>
```

**三条铁律（画像纪律）**：

1. **①层只存学员明说的**，且只收**明确通用偏好**（跨主题适用）：模型观察到的偏好不算——学员明确说「讲慢点 / 别用类比讲代码」才进①层；擅自给学员贴偏好标签是越界。**任务级偏好不进①层全局段**——落到对应任务或②层作用域。
2. **②层必须有证据且带作用域**：每条稳定模式附 ≥2 条独立证据（日期 + 原话/场景）；**「永远不要从一次观察直接升级成画像」**——单次表现只进③层记场景，第三次以上同向证据才允许升②层。**教学方法裁决**带条件与作用域、证据与日期，**可复评/关闭/删除**——低效裁决只在作用域内生效，换学科族或换目标时**重新评估**，不做「连续 N 次低效即永久禁用」的绝对处置。
3. **写入前展示确认**：①层学员亲口说的事实**免确认**——学员刚说过的内容直接落盘，导师以自然话术带过（如「好，类比就用做饭」），不重复问「可以存吗」；新增②层条目时，把要写的内容读给学员、明确说「可以/对/保存」后才落盘；③层追加不需要逐条确认，但下次读到时学员可要求删除任何一条；**学员任何时候可要求删除/关闭②层任一条裁决**。

**写法纪律**：每条 ≤120 字；用**动词短语**（"用 X 能独立完成""卡在 Y""换 Z 后通过"），不用形容词标签；每条带**证据**（日期 + 场景/原话）；推断标"暂定"，只有学员陈述或后续证据才升级；禁用绝对化词（深刻、彻底、完美掌握、专家、热爱、总是、从来不、完全理解）；无证据不写；空更新合法；**当前证据与当前表态优先于旧记录**；一次困难不得写成全局人格判断。正例："遇到递归先画调用栈再写代码（2026-10-20 学员原话：画出来就不乱了）"；反例："学员递归很差 / 彻底掌握了递归"。

**消费方**：S3 讲授类比优先取①层「类比领域」（衔接 `teaching/presentation.md`「类比纪律」）；跨界三猜想的「确证已会」可用②层稳定模式作证据之一（仍以摸底判分/亲口确认为最强）；S3 讲授呈现与④批改的反馈措辞同取①层沟通约定；**任务级偏好按任务作用域读取**；「换角度重讲」/换讲义风格时**先查②层教学方法裁决**，**仅在其作用域内且状态为「生效」时**才不重复推该方法（裁决可复评/关闭/删除）。**画像不参与任何闸口判定、不进脚本**——它是教学个性化素材，不是调度数据。

**零感知**：脚本（task_index / progress_check / scheduler / kp_sort / prereq_check）对 `profile.md` 与 `记忆.md` **零感知**（不解析、不出告警；进度校验所需的审计记录改由 progress_check 从记忆.md 学习日志只读检索，缺文件 = 合法形态）。
