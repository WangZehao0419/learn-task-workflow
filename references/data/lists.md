## 知识清单文件

**文件**：`<数据根>/<slug>/知识清单.md`，任务目录第一层、与 progress.md 平级（不放 materials/）。**单一事实源声明**：KP 集合与 KP 状态的唯一事实源是本文件；progress.md 只存指针，不重复记账。**原子判据**：每个 KP = 当前节目标内的最细知识点，1 道题可独立检验；需 2 道题分别检验两个判断 → 拆 KP；不设时间上限。不达标条目拆分或合并后再入清单，归模型纪律。**状态枚举**：未讲 / 已讲 / 暂缓 / 排除（与审计四态同源）。

**格式模板**（逐行 + 全角 ｜ 分段；**示例仅为格式演示，KP 的取舍与依赖声明规则本身领域无关**）：

```markdown
# 知识清单：<主题>
- 版本：<N>              # KP 集合变化（增/删/拆）时 +1；状态翻转不改版本
- 对照源：<与 progress.md 对照结论一致的对照源指针>
- 排序规则：<备考型-价值密度（依据：真题分值/频次） / 材料型-目录序+依赖修正 / 拓扑序（依赖边见各行前置列）>
- 覆盖范围：<全量 / 已细化至第 N 节，其余待细化>     # 分批必须显式；行缺失视同全量；行存在但畸形 → W-UNPARSED-KP
- 最近更新：<YYYY-MM-DD>
- 覆盖摘要：总 <N> ｜ 未讲 <a> ｜ 已讲 <b> ｜ 暂缓 <c> ｜ 排除 <d>   # 人读快照，脚本核对权威（W-KP-SUMMARY-MISMATCH）

- KP-01-01 ｜ 变量命名 ｜ 小节 1 ｜ 前置：  ｜ 来源：目录 1.2 ｜ 状态：未讲 ｜ 类型：记忆
- KP-02-01 ｜ 循环与迭代 ｜ 小节 2 ｜ 前置：KP-01-01 ｜ 来源：目录 1.3 ｜ 状态：已讲 ｜ 类型：程序 ｜ 视觉任务：图表
- KP-02-02 ｜ 递归初步 ｜ 小节 2 ｜ 前置：KP-02-01 ｜ 来源：目录 1.3 ｜ 状态：未讲（已会：摸底题 2 全对，2026-10-11）｜ 类型：概念
- KP-02-03 ｜ 不等式应用 ｜ 小节 2 ｜ 前置：KP-02-01, KP-01-01 ｜ 来源：目录 1.4 ｜ 状态：未讲      # 多前置以逗号/顿号/空格分隔（与脚本解析一致）；类型/视觉任务可省略
- （无 KP 时写「无」——仅选做型任务可能出现）
```

- **编号规则**：`KP-<两位节序>-<两位KP序>`（如 KP-03-02 = 第 3 节第 2 个知识点），锚定小节推进粒度；两位补零沿用 materials/exercises「编号契约」先例，脚本宽容匹配单位数；纯数字字典序 = 教学序，编号全清单唯一。**不属于已拆小节的 KP**（暂缓 / 排除 / 计划外）用**伪节序专号段**（节序取 90 起，如 `KP-90-01`；保持两位数字以兼容脚本正则），该段只按状态计数、不映射到任何小节。
- **kp_sort 返回口径**：`<技能根>/scripts/kp_sort.py` 的 `order` 含清单**全部行**（含暂缓/排除；输出另带 `excluded`/`held` 计数），讲授序与出题序仅取**纳入项**（状态 ∈ {未讲, 已讲}），暂缓/排除不入出题分母（见 `workflow/gates.md` S5）。
- **摸底标注（保守口径）**：S1 摸底命中且有判分证据的 KP 状态列写 `未讲（已会：<摸底证据>，<日期>）`——信息性标注，**留在审计分母内**（按「未讲」基值计数），任何把 KP 标「排除」出分母的动作必须经用户显式确认；标注随 S2 对照结论一并展示，不做运行时反向同步。脚本解析状态取枚举基值（尾部 `（…）` 括注剥离不参与枚举校验）。
- **字段合法性**：前置列只接受合法 KP 编号或空；`<技能根>/scripts/progress_check.py` 校验前置引用存在性（引用不存在的 KP → W-UNPARSED-KP）；行畸形（缺段/状态非法）→ W-UNPARSED-KP，**不计入摘要计数**（与 W-UNPARSED-HOLD 同构，不静默）。
- **可选分型字段**：在第 6 段后追加 `｜ 类型：记忆/概念/程序/设计`（兼容 memory/concept/procedure/design、全/半角冒号）与/或 `｜ 视觉任务：识别/关系/图表/比较`（多选用逗号/顿号分隔，兼容英文别名、全/半角冒号）。**缺失 = 旧任务统一闸口**；声明后 `progress_check --release` 启用分型验收：记忆/程序要求至少一条 `KP=<id>` 的独立正确 attempt；概念/设计要求复述清单中已勾选行含该 KP 编号；视觉任务要求 `KP=<id>｜视觉=<任务>` 的独立正确 attempt。KP 标签支持单位数别名（`KP-1-1` ≡ `KP-01-01`）。分型门按 KP 编号的节序归组；重排小节时保持编号稳定或同步更新 KP 编号/所属节，避免分型证据串节。`kp_sort.py` 只读前六段，忽略可选字段；可选字段畸形 → W-UNPARSED-KP，放行模式另报 E-KP-TYPED-GATE（不能靠写坏字段绕过分型门）。
- **视觉任务来源纪律**：声明条件、原始来源要求、替代禁令、attempt 记录格式与旧任务兼容口径**唯一事实源见 `assessment/scoring.md`「视觉任务证据」**；本册只定字段格式（见上「可选分型字段」）。本纪律不新增字段、告警码或闸口。
- **覆盖范围行（分批显式标注）**：清单分批产出时必须写「已细化至第 N 节，其余待细化」；行缺失视同全量；分批未显式标注即 SR-7 命中。未拆节的滚雪球候选拒绝入清单（仍留「暂缓与范围外」标「滚雪球候选」）。
- **progress.md 指针（元信息区可选字段，append-only）**：`- 知识清单：知识清单.md ｜ 版本 <N> ｜ 总 <M>`——无清单任务缺省此行，合法；指针存在但文件不存在 → W-KP-LIST-MISSING。
- **暂缓/排除双写与交叉核对**：清单记状态（分母账本），progress.md「暂缓与范围外」记处置明细（处置账本），职责不重叠。交叉核对**按对象 ID 集合对账**（不再只比数量——**数量相同但对象不同也能检出**；warning 级、不阻断旧任务，由 `<技能根>/scripts/progress_check.py` 只读输出）：清单暂缓 KP 集合 ≠ progress.md 暂缓区块可比条目的 KP 集合（剔除设计性范围外与排除条目）→ **W-KP-HOLD-CROSS**（暂缓侧，列出「仅清单 / 仅区块」差异）；清单排除集合 ≠ 处置为排除条目的 KP 集合 → **W-KP-HOLD-CROSS**（排除侧）；小节勾选「已掌握」× 清单内该节 KP 全「未讲」→ **W-KP-STATE-MISMATCH**（可能是清单滞后，处置归模型提醒补齐，衔接「顺带补写」惯例）。

## 学习者画像（可选全局文件）

**文件**：`<数据根>/profile.md`，**全局唯一**、跨任务共享（画像放数据根第一层、与任务目录平级）。**偏好按作用域生效（F13）**：①层 = 学员明说的**通用偏好**，跨主题适用；②层「稳定模式」**默认任务级作用域**（可标任务/学科族/全局），**带证据、可复评、可关闭**；**教法裁决与类比领域按任务/学科族作用域生效**，**不得当作跨主题的全局人格标签**，也不得据单任务低效就对同类主题预判。**可选**：无此文件 = 合法形态，不强制创建、不报错；首次触发建立时机 = S1 摸底顺带问「类比领域」时（见 `workflow/gates.md` S1），用户不便回答则跳过。**单一事实源声明**：画像内容的唯一事实源是本文件；progress.md 不重复记账，讲授/类比时由模型现场读取。

**格式模板**（三层结构，逐层追加）：

```markdown
# 学习者画像
- 最近更新：<YYYY-MM-DD>

## ① 明说的偏好（只有学员亲口明确提过的才进这里；**明确通用偏好，跨主题适用**）
- 类比领域：做饭（S1 摸底时确认，2026-10-12）
- 沟通约定：<学员明确要求的沟通规则，如「不要堆术语」「重点加粗、结论先行」（无则写「无」）>

## ② 稳定模式（跨多次对话看清的，每条必须带证据；**带作用域：默认任务级，非全局人格标签**）
- <模式描述>（作用域：<任务/学科族/全局>；证据：<日期> <学员原话/具体场景>；至少 2 条独立证据）
- <教学方法裁决>：<有效 / 低效>（**作用域：<学科族 / 任务 / 目标>**；条件：<什么场景下>；证据：<日期> <场景与效果>；裁决日期：<YYYY-MM-DD>；状态：<生效 / 已复评 / 已关闭>）——同一条裁决**可复评、可关闭、可删除**；低效裁决在**其作用域内**不再推该方法，**不跨任务/学科族永久禁用**（数学类比无效 ≠ 编程类比无效），也不写成人格标签

## ③ 观察暂存（注意到了但没看清的，只记场景）
- <日期> 在 <什么场景> 做了 <什么>——<尚未归类，不起名字>
```

**三条铁律（画像纪律）**：

1. **①层只存学员明说的**，且只收**明确通用偏好**（跨主题适用）：模型观察到的偏好不算——学员明确说「讲慢点 / 别用类比讲代码」才进①层；擅自给学员贴偏好标签是越界。**任务级偏好不进①层全局段**——落到对应任务或②层作用域。
2. **②层必须有证据且带作用域**：每条稳定模式附 ≥2 条独立证据（日期 + 原话/场景）；**「永远不要从一次观察直接升级成画像」**——单次表现只进③层记场景，第三次以上同向证据才允许升②层。**教学方法裁决**带条件与作用域、证据与日期，**可复评/关闭/删除**——低效裁决只在作用域内生效，换学科族或换目标时**重新评估**，不做「连续 N 次低效即永久禁用」的绝对处置。
3. **写入前展示确认**：①层学员亲口说的事实**免确认**——学员刚说过的内容直接落盘，导师以自然话术带过（如「好，类比就用做饭」），不重复问「可以存吗」；新增②层条目时，把要写的内容读给学员、明确说「可以/对/保存」后才落盘；③层追加不需要逐条确认，但下次读到时学员可要求删除任何一条；**学员任何时候可要求删除/关闭②层任一条裁决**。

**写法纪律**：每条 ≤120 字；用**动词短语**（“用 X 能独立完成”“卡在 Y”“换 Z 后通过”），不用形容词标签；每条带**证据**（日期 + 场景/原话）；推断标“暂定”，只有学员陈述或后续证据才升级；禁用绝对化词（深刻、彻底、完美掌握、专家、热爱、总是、从来不、完全理解）；无证据不写；空更新合法；**当前证据与当前表态优先于旧记录**；一次困难不得写成全局人格判断。正例：“遇到递归先画调用栈再写代码（2026-10-20 学员原话：画出来就不乱了）”；反例：“学员递归很差 / 彻底掌握了递归”。

**消费方**：S3 讲授类比优先取①层「类比领域」（衔接 `teaching/presentation.md`「类比纪律」）；跨界三猜想的「确证已会」可用②层稳定模式作证据之一（仍以摸底判分/亲口确认为最强）；S3 讲授呈现与④批改的反馈措辞同取①层沟通约定；**任务级偏好按任务作用域读取**；「换角度重讲」/换讲义风格时**先查②层教学方法裁决**，**仅在其作用域内且状态为「生效」时**才不重复推该方法（裁决可复评/关闭/删除）。**画像不参与任何闸口判定、不进脚本**——它是教学个性化素材，不是调度数据。

**零迁移**：既有任务无 profile.md = 合法形态，不补建、不批量迁移、不报错；脚本（task_index / progress_check / scheduler / kp_sort）**零感知**此文件，不出任何告警。
