# 记忆簿格式

<!-- owns: 记忆簿：学习日志、学习记录、讲授证据; must-not-define: 课程体系、画像、状态簿 -->

## 记忆文件

**文件**：`<数据根>/<slug>/记忆.md`，任务目录第一层。任务级**叙事簿**：三个 append/覆盖区，全部是人读叙事，不进任何脚本解析、不参与闸口。

```markdown
# 记忆：<主题>
- 最近更新：<YYYY-MM-DD>

## 学习日志
- <日期>：<完成内容、练习结果、作业>；学员状态：<顺 / 挣扎（原因）/ 需换风格>；姿态：<A/B/混合>；深度：<M/C 未讲（S4 补）>   # 姿态与深度为可选追加
- （事件时间线，只追加不改写；审计记录（日期 + 对照源 + 差异数 + 处置）、纠错留痕、调度器读数等亦记于此）

## 学习记录
- R1 ｜ <一句话洞察> ｜ 证据：<日期 + 场景/原话>
- （无记录时写「无」；每条正文 ≤120 字；用动词短语；不写绝对化词；推断标「暂定」；最多 5–7 条，超出时合并重复、删除低信号或已被推翻的；跨任务稳定模式不写在这里，按 profile ② 的证据/确认流程另写）

## 讲授证据
- [<日期>] <KP/概念> ｜ 已讲：<逐字引用≤80字> ｜ 来源：<页码/链接；无外部来源写「自拟」>
- （只记已公开讲给学员的内容；计划、思考、工具结果、来源原文不算；讲授 ≠ 掌握；同一概念保留最近一条，不逐题记）
```

- **学习日志**是**事件时间线**（只追加）；**学习记录**是**任务级持久洞察**（回答「这个学员在这个任务里为什么卡/为什么通了」，不写流水账）；**讲授证据**只证明「讲过」，不证明「学会」，不替代判分/复述闸口。`学习记录` 不替代 `profile.md` ②：跨任务稳定模式进画像，任务内洞察留本区；**本区不直接写跨任务结论**。
- 来源不可用或不确定时如实说明，不编造。没有新内容就不写，空更新合法。
