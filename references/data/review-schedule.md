# 复习调度字段（T04）

> 何时读：写薄弱点/错题/保持复习条目的元数据（挂载点、字段表、cw/顽固语义）时。

薄弱点条目的调度元数据放**行尾全角括号内**（半角括号亦兼容，推荐全角）、逗号分隔的 `键=值`（`cw`/`顽固` 为无值标记）；错题本与保持复习条目在行尾追加「｜ 元数据：…」段（竖线分段与「元数据：」冒号均全角/半角双兼容）。保持复习行推荐以 `[YYYY-MM-DD]` 掌握日期开头；缺日期时用「最近更新」兜底并告警，仍缺 → `W-UNPARSED-ITEM` 不入队（不猜当日）。解析器只认这些挂载点，其余文本不动。`S'/D'/due` 的计算由 `scripts/scheduler.py next-interval` 负责（判分归模型、算数归脚本，调用细则见 `references/assessment/scheduling.md`「间隔调度」）。`due-queue` 输出 `reason` 字段（到期/逾期/优先级的人类可读说明），schema 为 `ltw-due-queue/3`。`错因`/`级`/`meta_default` 只对薄弱点/错题有意义；`kind=保持` 时前者为空、`meta_default=false`，不参与问题元数据。

| 字段 | 类型/取值 | 语义 | 默认值（缺省时） |
|------|-----------|------|------------------|
| S | 浮点（天） | 稳定天数，间隔重复核心参数 | 3.0 |
| D | 数值 0.5 粒度，[1,5] | 难度 | 3 |
| last | YYYY-MM-DD | 最近一次判分日期（绝对日期，禁相对日期） | 取 progress.md「最近更新」；仍缺 → 不入队，报 `W-UNPARSED-ITEM`（不猜当日） |
| due | YYYY-MM-DD | 下次复习日。**新写由 `scheduler.py` 以「本次复习日 + interval」计算**（见 `references/assessment/scheduling.md`「间隔调度」）；缺 due 时按 `last + round(S)` 兜底推算 | 由 last 推算 |
| 信心 | 1–5 | 作答信心自评（**反馈前**提交方可用于 cw/校准；反馈后补报标回顾性） | 未写 → 不计入校准分母（不补 3） |
| cw | 标记（无值） | 自信但错（**反馈前**信心 ≥4 且判错），due-queue 排序优先 | 无 |
| 顽固 | 标记（无值） | 提示阶梯两次到梯底，重教不重测（见 S3/S4） | 无 |
| evt | 可选 ID | **作答事件 ID**：同一次作答的投影（错题 / 薄弱点）共享同一 `evt`，供校准统计去重（T04） | 无 |
| 错因 | 枚举：知识性 / 理解性 / 技巧性 | 归因分类，决定 S4 补救动作（重学 / 审题圈画 / 限时技巧）。**语义属性，归模型判断写入，禁止脚本代判** | 知识性 |
| 级 | 枚举：A / B / C | A=反复出错 / 直接影响学习目标达成的核心条目（详细整理+变式）；B=一般理解偏差（记思路）；C=纯粗心（仅标知识点）。与错因同轮由模型定级，S4 复习判分可调整级别 | B |

- `cw` 只由「信心 ≥4 且判错」产生；cw 条目修复后照常走清除/归档规则。
- due-queue 对 `顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- **`错因` 枚举放元数据段，与既有自由文本「错因：<具体描述>」并存不冲突**：自由文本答「错在哪」（行内 `错因：` 全角冒号写法），枚举答「属哪类、该用什么补救」（元数据段内 `错因=` 等号写法）。解析器只在元数据段内搜 `错因=`，正则锚定于元数据段，不会误吃行首自由文本。
- **`级` 与 `错因` 是内容属性（错什么），S/D 是调度属性（何时再练），互不替代；`级` 不参与 due-queue 排序**（排序契约 cw→最逾期→due 早→稳定序不变），分级只影响整理深度与复盘注意力，脚本仅在输出中回显 错因/级 供模型取用。
- **可选 token `子类=`**：错因第六类"过度泛化"写 `错因=理解性` + `子类=过度泛化`；`scheduler.py` 已识别该键（不参与调度计算、不输出到 due-queue），不会再报 `W-META-INVALID`。

**字段合法性**（由 `scripts/progress_check.py` 校验）：`当前阶段`、`类型`、`学科族` 必须为上述枚举值之一；`复习来源阶段` 在 S4 期间必须为合法返回枚举（**逐节学习 / 结课 / 已完成**，任意字符串被拒）。**必填项随阶段变化**：`当前阶段`、`类型`、`学科族`、`目标` 全程必填；**`起点` 在 S0（接料建档）与 S1（诊断摸底，进行中）不要求，自诊断结束进入 S2 起（计划确认中/逐节学习/复习巩固/结课/已完成）必填**——S1 尚未产出「起点」属正常，不得据此误判。
