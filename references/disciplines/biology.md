## 学科身份

归 **实验科学群**。默认内容类型分布：概念型约五成、记忆型约三成半、程序型（遗传计算、实验设计）约一成半、设计型少量。

生物看起来像记忆学科，实际上最难的是**在多个尺度之间切换**：同一件事在分子、细胞、个体、种群四个层面看到的东西不一样。只在一个尺度上讲，学员就会把不同尺度的话混着说。

## 内容结构与前置链

**五条大概念骨架**（跨章节反复使用，章末必须回挂）：

1. **进化**：种群中可遗传变异频率的变化，是所有生物学的最上层解释框架。
2. **结构与功能**：结构决定功能，功能反过来约束结构。
3. **信息流**：遗传信息从 DNA 到 RNA 到蛋白质的传递与调控。
4. **能量与物质**：能量的单向流动与物质的循环，二者不是一回事。
5. **系统**：生命是有层次的系统，层次之间有涌现性质。

**主干**：分子与细胞 → 代谢（光合与呼吸）→ 遗传（孟德尔、分子遗传）→ 变异与进化 → 稳态与调节 → 生态。

**前置链最常断的三处**：能量的单向流动与物质循环区分、层级尺度（分子—细胞—个体—种群）、随机性（突变是随机的，选择才是有方向的）。

## 学科专属教学法

- **先给大概念地图，再填细节**：每个新目开讲先说「它挂在上面的哪条大概念上」。孤立地记细节，综合题必然不会。
- **结构与功能配对讲**：讲任何结构都必须配一句「这个形状能干什么」。反过来讲功能也必须指回结构。
- **尺度切换重述**：讲完一个过程，要求学员「用分子层的话再说一遍」「用个体层的话再说一遍」。这是本学科最好的复述题。
- **进化误区必须显式反驳**：有实证显示，即便经过一学年大学普通生物学，仍有七到九成学生在解释中至少使用一个进化误区；单靠主动学习不足以清除，必须点名误区并反驳。
- **概念图由学生自己画**：给一组概念，让学生自己连关系并标箭头含义。看现成图的效果远低于自己画。
- **实验设计三变量**：自变量、因变量、无关变量（须控制），加对照组。

## 实证误区库

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 个体主动进化 | 「长颈鹿为了吃到高处的叶子把脖子伸长了」 | 目的论直觉 | 变异先于选择；变化发生在种群，不在个体 |
| 目的论／拟人化 | 「细菌为了抵抗抗生素而变异」 | 把选择说成有意图 | 突变随机发生，抗生素只是筛选 |
| 进化＝进步 | 把演化树读成阶梯，「低等到高等」 | 线性进步叙事 | 分支无方向，现存物种都是同等「进化」的 |
| 适者生存循环论证 | 「活下来的就是适者，适者就是活下来的」 | 定义空转 | 要说清「适」相对于什么环境、哪个性状 |
| 植物「吃」土壤 | 「植物的食物来自土壤」 | 日常语言「喂养」 | 干重实验：植物质量主要来自 CO₂ 与水 |
| 光合与呼吸互逆且分时 | 「白天只光合、晚上只呼吸」 | 气体交换的表象 | 呼吸全天进行；两者并非简单互逆 |
| 能量在食物链中循环 | 「能量像物质一样被循环利用」 | 物质循环的类比越界 | 能量单向流动、逐级以热散失；循环的是物质 |
| 分解者不在生态系统内 | 画食物网时忽略分解者 | 教材图示省略 | 能量去向有四支：同化、呼吸、分解者、未利用 |
| 显性＝更多 | 「显性基因在种群中比例更高」 | 词义直觉 | 显隐性不等于频率，如多指症罕见但显性 |
| DNA／基因／染色体同级 | 三者当同义词或大小关系颠倒 | 教材图示比例失真 | 染色体包含 DNA，DNA 包含基因 |
| 减数分裂细节链错 | 「间期复制后 DNA 和染色体都加倍」「减半发生在第二次分裂」 | 有丝分裂负迁移 | 逐时期列 DNA 与染色体计数表 |
| 稳态＝恒定不变 | 「内环境稳态就是各成分保持不变」 | 「稳」的字面义 | 稳态是动态平衡，在波动范围内调节 |
| 酶被用完 | 「酶在反应中被消耗」 | 反应物类比 | 酶是催化剂，反应后不变 |

备课取 2–3 条，本学员历史错因优先占坑。

## 表征与标准流程

**标准表征**：概念图（学生自画）、层级图（分子—细胞—个体—种群）、流程图（代谢路径、信息流）、系谱图、能量金字塔、坐标曲线（酶活性、光合速率）。

**实验设计流程**：明确问题 → 提出假设 → 定自变量与因变量 → 列无关变量与控制方法 → 设对照组 → 写可复现步骤 → 预期结果与判据。

**遗传计算流程**：定基因型 → 画配子或棋盘 → 算子代比例 → 回代检查是否符合题意。

**过程题答案结构**：按「场所 → 条件 → 物质变化 → 能量变化」四要素组织。

## 验收形态

- **概念型目**：能跨尺度重述；能指出某个说法错在哪一层；能用大概念解释新现象。
- **记忆型目**：能列举并区分易混对（如动脉血与静脉血的含氧量）。
- **实验型目**：三变量与对照齐全，能指出给定方案的缺陷。
- **不接受**：只背结论不说机制；把光合与呼吸说成互逆；实验设计不设对照。
