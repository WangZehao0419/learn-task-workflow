## 学科身份

归 **实验科学群**。默认内容类型分布：概念型与程序型各约四成，记忆型（常数、单位、公式）约一成半，设计型（实验方案）少量。

物理的核心不是记住公式，而是**建立能预测的模型**。一个学员能把公式套对但预测不了新现象，本包一律按未掌握处理。

## 内容结构与前置链

**主干**：运动学 → 力与牛顿三定律 → 功与能 → 动量 → 圆周运动与万有引力 → 静电场 → 电路 → 磁场与电磁感应 → 振动与波 → 热学 → 光学。

**前置链最常断的三处**：矢量分解（不会拆力就做不了任何力学题）、图像判读（把 x-t 图当轨迹）、单位与量纲（不会换算就永远算错数量级）。

## 学科专属教学法

- **先图后式**：受力图、运动图、能量条图先画出来并标清系统与正方向，再列方程。跳过画图直接列式，是本学科最普遍的失分起点。
- **量纲先于数值**：结果出来先看量纲对不对，再看数量级合理不合理。量纲错说明公式选错了，不必再查算术。
- **多重表征互译**：同一过程至少给两种表征并要求互译——文字描述 ↔ 受力图 ↔ 能量图 ↔ 方程 ↔ 图像。互译本身就是最好的检索练习。
- **模型的适用边界必须给**：每个模型讲「解释什么、预测什么、什么时候失效」。例如匀变速只适用于加速度恒定；理想气体只在低压高温近似成立。
- **概念题与计算题分开**：概念上错了但算对了，是最危险的情形——它会让学员以为自己会了。用「换情境判断」的概念题单独验收。
- **实验用预测-观察-解释**：先让学员预测结果并写下理由，再给真实数据，冲突时进入解释。预测必须落字，不能口头「我也这么想」。

## 实证误区库

力学与电学的误区有成熟的概念清单（FCI 类工具）支撑，条目大多来自大样本前测的分布，属「高频误区」而非「已证明可完全纠正的误区」。

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 冲力说 | 「物体向前飞是因为还带着一个向前的力，力用完就掉下来」 | 生活经验（推才动） | 抛体在最高点只受重力，水平方向不需要受力维持 |
| 匀速需要恒力 | 「匀速直线运动一定受一个与速度同向的力」 | 推车经验 | 牛顿第一定律：合力为零即可 |
| 作用力反作用力不对称 | 「大车撞小车，大车施加的力更大」 | 看结果（毁坏程度） | 第三定律等值反向；差别在质量与加速度 |
| 速度为零即无力 | 「最高点速度为零，所以不受力」 | 把速度与力挂钩 | 抛体最高点加速度仍是 g |
| 摩擦力方向＝与运动方向相反 | 一律反向 | 只记结论不看相对运动 | 摩擦力与**相对运动或相对趋势**反向 |
| 图像当轨迹 | 把 x-t 图线当物体走过的路线 | 图形直觉 | 图线是坐标与时间的关系，不是空间路径 |
| 电流被消耗 | 「电流经过灯泡被用掉，后面的灯更暗」 | 「消耗」的日常语义 | 串联电流处处相等 |
| 单极模型 | 「电从正极出发到灯泡就用完了」 | 同上 | 电路必须闭合，电荷守恒 |
| 先到先亮 | 「电从正极先到哪个灯，哪个灯先亮」 | 时间顺序直觉 | 电路建立近乎瞬时；亮度由功率决定 |
| 电流节点处均分 | 不看电阻就认为电流平分 | 「公平」直觉 | 并联按电导分配 |
| 电势高就亮 | 只看一端电势 | 单端量代替差量 | 亮度由器件两端电压差决定 |
| 温度＝热量 | 「温度高的物体含的热量多」 | 热质说残留 | 热量是过程量，与质量、比热容有关 |
| 金属比木头冷 | 摸金属觉得更冷就说温度更低 | 混淆导热率与温度 | 室温下两者同温，差别在导热快慢 |
| 热从「热量多」流向「热量少」 | 按总热量判方向 | 热质守恒直觉 | 热流方向由温度差决定 |

备课取 2–3 条，本学员历史错因优先占坑。

## 表征与标准流程

**标准表征**：受力图（隔离体）、运动图（轨迹与速度箭头）、能量条图（初末能量分配）、x-t／v-t／a-t 图、电路图（含节点标号）、场线图。

**解题流程**：画图并标已知 → 定系统与正方向 → 选原理（牛顿、能量、动量，说清为什么是这条）→ 列式并带单位代入 → 求值并定有效数字 → 量纲与数量级检验 → 说明结论的方向与物理意义。

**实验流程**：明确测量目标 → 定自变量与因变量 → 列无关变量与控制方法 → 写可复现步骤 → 说数据处理（作图、斜率、截距的含义）→ 说误差来源与影响方向。

## 验收形态

- **概念型目**：能预测新情境的结果并说出依据；能指出某个模型在何种条件下失效。
- **程序型目**：能独立完成并说出每一步的物理依据；单位、方向、有效数字齐全。
- **实验型目**：能写出完整变量控制与数据处理方案；能找到给定方案的漏洞。
- **不接受的验收**：只报结果不写单位、只套公式不说依据、只算对但预测新现象就错。
