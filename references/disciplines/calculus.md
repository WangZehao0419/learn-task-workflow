## 学科身份

归 **数学与统计群**。默认内容类型分布：程序型（求导、积分、解方程）约六成，概念型（极限、连续、可导）约三成，记忆型（导数表、积分表、常见展开）与设计型（建模、应用题）各少量。

本包只承载**微积分特有**的内容与误区；符号操作、变式设计、答案形态等通用规则见 `math-practice.md` 与 `math-teach.md`。

## 内容结构与前置链

**主干**：函数与初等函数 → 极限与连续 → 导数与微分 → 中值定理与应用（单调、极值、凹凸、拐点）→ 不定积分 → 定积分与应用 → 微分方程 → 级数 → 多元微积分（偏导、全微分、重积分）。

**前置链最常断的三处**：

1. **初等函数与代数变形**——不是微积分问题，但几乎所有的「算不对」出在这里。分式化简、根式、绝对值、三角恒等式、因式分解，任一不稳都会在求导与积分里反复爆炸。
2. **不等式的解法与区间表示**——定义域、单调区间、收敛区间全靠它。
3. **函数图像与变换**——平移、伸缩、翻折。画不出草图，就判断不了连续性、极值与积分区域。

## 学科专属教学法

- **极限先行但不久留**：极限是概念地基，但不必一次讲透到 ε-δ。先建立「趋近」「左极限右极限」「无穷大与无定义」的直觉，能判分段函数与无穷小量级即可；ε-δ 只在需要严格证明的目单独立项。
- **导数的两条路必须先走「平均变化率」**：先算 Δy/Δx 的具体数值，再取极限。直接给求导公式会让学员把导数等同于「套公式得斜率」，丢掉「变化率」的含义——这是本学科第一大误区（详见误区库）。
- **积分反着来**：讲积分前先回看「导数做了什么」，把积分定位为「求原来那个函数」。定积分再引入「累积量」的含义（面积、路程、总量），两条线并行，不要只讲面积。
- **概念成熟度按 APOS 推进**：函数与极限先停在「逐点算」（Action），再让学生把求导当整体变换（Process），再把导数当可运算的对象（Object，如求二阶导、讨论导函数），最后纳入体系（Schema）。停在 Action 阶段就讲 Object 级的题（如「已知 f'(x) 的单调性推 f(x) 的凹凸」），必然听不懂。
- **方法选择图必给**：换元还是分部、比值还是根值、先换序还是先积分——每类题给出「看到什么信号走哪条路」的判据，并给「这个方法什么时候失效」。

## 实证误区库

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 导数＝切线斜率公式 | 会套公式求导，却说不出 f'(a) 是什么；算平均变化率反而错 | 求导可公式化，「斜率」只剩倾斜度直觉 | 同区间手算 (f(b)−f(a))/(b−a) 与 f'(a) 对比，一般不等 |
| 把导数当乘法 | f'(x) 读成「f 撇乘 x」 | 记号像上标 | f'(x) 是一个新函数，括号里是自变量 |
| 极限＝代入 | 一切极限都先代值，遇到 0/0 就卡住或直接说「不存在」 | 多项式经验泛化 | lim sin x/x 在 0 处无定义但极限存在 |
| 连续必可导 | 认为画得出来的曲线都可导 | 直观上「没有断点」 | |x| 在 0 处连续但不可导 |
| 可导必连续当双向 | 用「可导」推「连续」的反面 | 命题方向记混 | 连续不可导的例子只需一个 |
| 无穷大就是「很大的数」 | 把 ∞ 当具体数参与运算 | 符号像数字 | ∞−∞、∞/∞ 都不能直接算 |
| 微分与增量混淆 | 认为 Δy＝dy 恒成立 | 记 tick 不记条件 | Δy＝dy+o(Δx)，差一个高阶无穷小 |
| 积分常数可省 | 不定积分漏 +C | 求导是常数为零 | 两个原函数相差常数，漏了就错一族 |
| 换元不回代 | 换元后结果里留着 u | 忘记「换回去」这一步 | 检查最终表达式里是否还有中间变量 |
| 定积分面积当有向面积混用 | 求面积时漏绝对值，或求积分时误取绝对值 | 两条定义混在一起 | 求面积必须分段取绝对值；求积分保留符号 |
| 级数收敛当通项趋零 | 通项→0 就判收敛 | 必要条件当充分条件 | 调和级数通项趋零但发散 |
| 应用题不写定义域与单位 | 算完就交 | 只关注运算 | 结果超出实际范围即错 |


## 表征与标准流程

**标准表征**：函数草图（含渐近线、零点、单调）、数轴（定义域与区间）、单位圆与三角图像、面积分割图（定积分）、收敛区间数轴。

**求导流程**：判断函数结构（和差／积商／复合／隐式／参数）→ 选法则 → 写出中间变量 → 逐步求导 → 化简 → 检查定义域。

**积分流程**：看被积函数的结构特征 → 先试换元（有「内层导数在外」的迹象）→ 再试分部（有乘积且一类可积一类可导）→ 有理函数走部分分式 → 三角有理式走万能代换或恒等变形 → 检查是否可回代、是否需要 +C。

**应用题流程**：定变量与范围 → 列关系（几何、物理或经济）→ 求导找驻点 → 比较端点与驻点 → 回代解释并写单位。

## 验收形态

- **程序型目**：能独立完成并说出每一步用的是哪条法则；结果代回或求导验算通过。
- **概念型目**：能用具体数值演示「平均变化率 → 瞬时变化率」的过渡；能举出「连续不可导」的例子；能说出极限存在与函数值无关。
- **证明型目**：能写出关键引理与推理链，且不引用未证命题。
- **应用题**：必须写定义域、单位与结论的实际含义。
