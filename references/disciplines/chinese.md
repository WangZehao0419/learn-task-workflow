## 学科身份

归 **语言群**，但与外语走完全不同的路径：母语文的起点是**已经会说的语言**，要学的是书面语的解码、篇章的组织与鉴赏判断；外语的起点是零，要学的是形式系统本身。两者共用的只有「词汇要积累、输出要练」，方法几乎不重叠。

默认内容类型分布：概念型（篇章结构、鉴赏判断、文言虚实词规律）约四成，程序型（阅读作答、写作操作）约三成半，记忆型（默写、文学常识、文言实词）约两成半。S2 按实际目清单核正。

**默写与文学常识按记忆型处理**，走间隔重复；不要挤占阅读与写作的课时。

## 内容结构与前置链

**主干**：识字与写字 → 词句与语感 → 段落与篇章 → 记叙／说明／议论三类文体阅读 → 古诗文 → 整本书阅读 → 写作（记叙、议论、实用）。

**前置链最常断的三处**：**解码自动化不足**（字词识别还在耗力，读到后面忘了前面）、**背景知识缺口**（读不懂往往是不知道那件事，不是读不懂句子）、**篇章结构意识**（只会逐句读，不会看整体骨架）。

## 学科专属教学法

- **阅读能力＝解码 × 语言理解，先分流再干预**：读不懂有两种原因，干预完全不同——解码弱（认字慢、断句错）要练识字与朗读；语言理解弱（字都认识但不懂意思）要补词汇、背景知识与推理。用一篇材料先判是哪一种，不要一律「多读」。
- **解码优先于猜词**：以猜测（看上下文猜、看首字猜）作为主要解码策略是已被证伪的做法——它训练的恰好是弱读者的行为。遇到不认识的字词，先尝试按构字或拼音规则解码，猜只在解码尝试之后作为兜底。这条对低年级与基础薄弱者尤其重要。
- **阅读按三层认知过程设计**：定位信息（找到原文）→ 整合与推理（把多处信息连起来）→ 评估与反思（判断可信度、处理矛盾信息）。三层的题要分开出，只考定位会让人误以为读懂了。
- **写作走策略教学，不走「多写自然好」**：显式教体裁策略（这类文章该怎么组织）＋自我调节（写前定目标、写中自查、写后自评），效果远好于只给题目反复写。范文对照要指出「升格点」，不是笼统说「写得不错」。
- **文言文先实词与句式，再推文意**：不背实词就硬翻，等于猜。高频实词与常见句式（判断句、被动句、倒装、省略）先成清单，再进篇章。
- **整本书阅读走「方法指导＋阅读任务」**：不做情节摘要，做人物关系梳理、主题追踪、章节批注。
- **中文分级阅读没有国家标准**：市面上的分级体系是多轨并行的（学术标准、机构标准、商业产品），本课程若给「阅读档位」，必须写明这是**内部约定**，不得伪装成权威分级。

## 实证误区库

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 用猜词代替解码 | 遇到生字就跳过或看首字猜 | 曾被教「猜一猜」 | 猜对的场合有限；先尝试按构字规则读 |
| 读完就忘前面 | 读到段末已忘了段首 | 解码未自动化，占用工作记忆 | 朗读流畅度测试：读得磕绊就是解码层问题 |
| 只答定位不答推理 | 阅读题只抄原文句子 | 定位题练得多，推理题练得少 | 追问「这句话说明什么」「作者为什么写这句」 |
| 把修辞当主旨 | 找出一堆手法，说不出文章想干什么 | 术语先行 | 先问「作者想让读者相信什么」 |
| 作文套模板 | 结构完整但内容与题目无关 | 模板见效快 | 要求每段至少一处与题目具体信息绑定 |
| 议论只会举例 | 有例子没分析，例子与观点不咬合 | 例子好找、分析难写 | 每个例子后追问「这说明了什么」 |
| 文言以今义解古义 | 用现代词义硬套 | 同形字误导 | 建立古今异义对照表 |
| 文言只翻译不析句式 | 句子翻得通但说不出是什么句式 | 只求意思对 | 要求标出判断句／被动句／倒装 |
| 默写只背不写 | 背得出、写错字 | 只做口头记忆 | 默写必须动笔，错字单独记 |
| 文学常识当阅读能力 | 背了作者生平就以为会读作品 | 考试导向 | 常识与文本理解分开验收 |
| 阅读量＝阅读能力 | 读了很多但答题还差 | 只做泛读不做精读 | 精读一篇的结构梳理胜过泛读十篇 |
| 把「有文采」当唯一标准 | 追求辞藻，逻辑与要点缺失 | 评价标准单一 | 先判要点是否齐全，再谈语言 |


## 表征与标准流程

**标准表征**：文章结构图（主张—支撑—转折—结论）、人物关系图、时间线（叙事文与史传文）、文言句式标注、作文提纲表（段—功能—要点）。

**现代文阅读作答流程**：读题干定位题型 → 回原文找证据区间 → 提炼要点 → 按「观点＋文本证据＋术语」成句 → 检查要点是否齐全。

**文言翻译流程**：断句 → 逐词落实（实词、虚词、活用）→ 补省略成分 → 调语序 → 通读检查。

**写作流程**：审题（圈出限制与任务）→ 定立意与中心 → 列提纲（每段一个功能）→ 成文 → 自查（要点、结构、语句）→ 升格（换更准确的表达，不堆辞藻）。

## 验收形态

- **阅读目**：三层分开验收——能定位、能整合推理、能评估反思；只过定位不算掌握。
- **写作目**：要点齐全、结构清晰、语句通顺为合格；语言升格是下一步目标。
- **文言目**：能译且能标出句式；只译不标不算完整。
- **默写目**：动笔写，错字单独记，不以口头背诵代替。
- **不接受**：只答定位不答推理；作文套模板无具体内容；文言以今义解古义。
