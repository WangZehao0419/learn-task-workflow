## 学科身份

归 **人文社科群**。默认内容类型分布：概念型约六成、记忆型（术语、模型名称）约两成、设计型（政策与实验设计）约两成。

这两门合在一个包里的理由：它们的教学难点完全同构——**日常直觉有系统性偏差，而教科书概念正是用来纠正这些偏差的**。所以两门都适合用反驳式呈现：先摆直觉，再让它失灵，再给正解。

## 内容结构与前置链

**经济学主干**：稀缺与选择（机会成本）→ 供给与需求 → 弹性 → 消费者与生产者 → 市场结构 → 外部性与公共品 → 宏观经济指标 → 财政与货币政策 → 增长与开放。

**心理学主干**：感觉与知觉 → 学习与记忆 → 思维与决策 → 动机与情绪 → 人格 → 社会心理 → 发展与异常。

**前置链最常断的三处**：机会成本（只取次优这一点）、边际思维（看增量不看总量）、相关与因果的区分。

## 学科专属教学法

- **直觉陷阱先行**：每个核心概念开讲先摆一个日常直觉答案（多数是错的），让学员选，再翻正。经济的机会成本、沉没成本、比较优势，心理的幸存者偏差、基础率忽视、确认偏误，都是天然的靶子。
- **边际思维反复练**：「再多一个单位的收益与成本是多少」——所有「总量」类问题都要追问一次边际，否则会用平均数思考。
- **两门都要求「换成数字再说一遍」**：定性结论一律要求给一个具体的量级例子（「大概多少」），防止停在「相关」「影响很大」这类空话。
- **心理学用大众谬误做反驳素材**：学习风格、左右脑分工、宣泄能消气、莫扎特效应、只用了大脑百分之十——这些谬误是现成的靶子，而反驳式呈现本身有稳定的中等效应。讲谬误不是为了嘲讽，是为了建立「凭什么相信」的习惯。
- **经济学用「身边的事」做检索练习**：用刚学的一个原理去解释一件最近看到的事，比再做十道计算题有效。

## 实证误区库

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 机会成本＝所有没做的事 | 「上大学的机会成本是全部别的选择之和」 | 词义直译 | 只取**次优**选项的价值 |
| 沉没成本计入决策 | 「已经花了这么多，不能停」 | 损失厌恶 | 沉没成本不影响边际决策 |
| 混淆财政与货币政策 | 「调存款准备金率是财政政策」 | 主体不清 | 按决策主体归类：政府 vs 央行 |
| 通胀率下降＝物价下降 | 「通胀降了所以东西便宜了」 | 把变化率当水平 | 涨得慢仍在涨 |
| 相关当因果 | 见两变量同向变动即下因果结论 | 叙事本能 | 找共同原因或反向因果 |
| 用平均数代替边际 | 讨论「该不该再多做一单位」时算总量平均 | 只算总账 | 问「下一个单位呢」 |
| 自评素养＝实际素养 | 觉得自己懂金融就等于懂 | 过度自信 | 用实测题校准 |
| 学习风格匹配教学 | 「我是视觉型，所以要只看图」 | 直觉悦耳 + 广泛传播 | 无合格实验支持匹配效应；图文并用对所有人都有益 |
| 左右脑分工 | 「画画靠右脑、算数靠左脑」 | 伪科学包装 | 复杂任务都是两半球协同 |
| 宣泄能消气 | 「生气就去砸东西」 | 压力锅隐喻 | 提高唤醒的发泄无效甚至加重；降唤醒（呼吸、冥想）才有效 |
| 心理学结论当常识 | 「这个我早就知道」 | 事后聪明偏差 | 要求预测实验结果再对照 |
| 只记模型名不记假设 | 能说出模型，说不出它何时失效 | 名词化记忆 | 每个模型必须配一条失效条件 |


## 表征与标准流程

**标准表征**：供需曲线（含移动与沿曲线移动的区别）、成本收益表（含边际列）、博弈矩阵、因果链图（经济）、实验设计表（自变量／因变量／控制）、效应与置信区间示意（心理）。

**经济学分析流程**：定决策主体 → 定约束（预算、时间、制度）→ 看边际收益与边际成本 → 比较 → 给结论并说明假设。

**心理学分析流程**：定现象 → 给可检验的假设 → 想替代解释 → 说该用什么设计排除 → 给结论的限度。

**答题流程**：结论先行 → 机制（为什么）→ 条件（在什么假设下成立）→ 例子（一个具体场景）。

## 验收形态

- **概念型目**：能用新情境判断（给一个场景问该用哪个原理）；能说出该原理的失效条件。
- **计算型目**：机会成本与边际分析算对，且能解释每一步的经济含义。
- **设计型目**（政策、实验）：目标、约束、备选、取舍、评价标准齐全。
- **心理学目**：能说出「我原来以为是 X，实际是 Y，因为 Z」——只记结论不算掌握。
- **不接受**：只背定义不判新情境；用平均数代替边际；把相关说成因果。
