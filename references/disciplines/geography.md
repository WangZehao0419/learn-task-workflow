## 学科身份

归 **实验科学群**。默认内容类型分布：概念型约五成、记忆型（地名、物产、区域特征）约三成、程序型（等值线判读、区位分析）约一成半、设计型（区域规划）少量。

地理常被误当成背诵学科，实际主体是**系统因果推理加空间表征判读**——任意性配对事实只占少数（地名与物产）。把它归到记忆类，会丢掉综合思维与空间思维这两条主线。

## 内容结构与前置链

**主干**：地球运动（自转公转、昼夜与季节）→ 大气（受热、环流、天气系统、气候）→ 水（循环、洋流）→ 地貌（内力与外力）→ 人文地理（人口、城市、农业与工业区位）→ 区域与可持续发展。

**前置链最常断的三处**：地球运动的几何关系（倾角与直射点）、比例与尺度（地图与距离）、等值线的读法（等高线、等压线、等温线）。

## 学科专属教学法

- **季节与昼夜必须用几何讲，不能用距离讲**：「离太阳近所以热」是本学科最顽固的误区，且能穿透到高学历人群。正确路径是「地轴倾角 → 太阳直射点移动 → 单位面积接收辐射量变化 + 昼长变化」，必须让学员自己画出南北半球的季节相反来反驳距离说。
- **尺度先定再讲**：同一现象在不同尺度上结论不同（局地气候 vs 全球气候；单次天气 vs 长期气候）。每次开讲先说「我们现在在哪个尺度上」。
- **反馈环必须画环**：温室效应、水循环、城市热岛都涉及反馈。只画单向因果链会漏掉放大或抑制的机制。
- **等值线四步判读**：读数值范围 → 读疏密（变化快慢）→ 读弯曲（凸向高值还是低值）→ 结合地形或环流解释。
- **区域分析用要素链**：位置 → 地形 → 气候 → 水文 → 土壤植被 → 农业工业 → 人口城市，链条上有依赖，不是并列清单。
- **空间思维可训练但有边界**：地理信息系统类训练能提升空间定位与比较，对「空间综合分析」的提升证据不足——不要承诺「练了就会综合」。

## 实证误区库

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 季节成因＝日地距离 | 「夏天热因为地球离太阳近」 | 烤火直觉；课本轨道图夸张 | 南北半球季节相反，一票否决距离说；真因是倾角与直射角、昼长 |
| 深时压缩 | 把恐龙与人类放在同一时间线的两端，地球年龄估成几千年 | 大数直觉失灵 | 用卷纸或对数刻度做时间轴练习 |
| 天气＝气候 | 一次寒潮就否定气候变暖 | 尺度混淆 | 气候是三十年量级的统计 |
| 地壳静止 | 「山一直就是那样」 | 人类时间尺度错觉 | 板块速率约等于指甲生长，但累积巨大 |
| 火山＝地下在燃烧 | 「火山是地下的火」 | 词义误导 | 岩浆是熔融岩石，不是燃烧 |
| 单因素解释季风或洋流 | 只答海陆热力差异，漏行星风带季节移动 | 教材简化 | 双因叠加，缺一不可 |
| 等值线凸向读反 | 凸向高值区当成高值 | 只记结论不记判据 | 用「凸高为低、凸低为高」配合具体数值验证 |
| 上北下南套所有投影 | 极地投影图上仍套「上北下南」 | 平面地图习惯 | 先判投影类型再定方向 |
| 反馈环缺项 | 解释温室效应只写单向链，不写水汽正反馈 | 线性因果习惯 | 画环并标出放大或抑制 |
| 区域分析当清单背 | 把位置、地形、气候并列列一遍，不写依赖关系 | 答题模板化 | 要求写出「因为 A 所以 B」的链条 |
| 比例尺与距离混淆 | 图上距离直接当实际距离 | 单位意识弱 | 每次换算写单位 |


## 表征与标准流程

**标准表征**：地图（含三要素：比例尺、方向、图例）、等值线图、剖面图、统计图表、区域定位图、时间轴（地质年代）。

**等值线判读流程**：读数值与单位 → 读疏密 → 读弯曲方向 → 找闭合中心 → 结合地理要素解释。

**区域综合分析流程**：定位（经纬度与海陆位置）→ 自然要素链（地形→气候→水文→土壤植被）→ 人文要素（人口、城市、产业）→ 人地关系评价（优势、问题、对策）。

**地质过程题流程**：定时间尺度 → 定内力或外力 → 定作用方向 → 写结果地貌。

## 验收形态

- **概念型目**：能用几何关系解释季节与昼夜；能说出某个结论在哪个尺度上成立。
- **判读型目**：等值线四步齐全；能指出图上哪处变化最快。
- **综合分析目**：要素链有依赖关系，不是并列清单。
- **不接受**：用距离解释季节；只列要素不写因果；等值线只读数不读疏密与弯曲。
