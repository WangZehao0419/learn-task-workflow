# humanities 学科群 正本册

> 本册是「humanities」学科族的四类切片（plan / teach / practice / review）合一。

## 人文社科群 · 规划切片

### 群边界与借用

本群：历史、法学、经济、心理、教育、政治与社会学。共同点——知识以**概念＋机制＋论证**为骨架，事实是论据不是目的；考核大头是「能不能用概念解释一个具体情境」。

默认内容类型分布：概念型过半，记忆型约三成（年代、条文、术语），设计型（制度与方案）与程序型（论证写作）少量。S2 按实际目清单核正。

法学、经济的两块「程序」内容（请求权检索、分录与计算）由各自学科包给出操作序列，本群只供概念与论证的通用做法。

### 内容结构与前置链

- **概念三层**：定义 → 机制（为什么成立）→ 边界（何时失效）＋ 与相邻概念的对比。缺任何一层，学员都会停在「背定义」。
- **理论谱系**：同一现象常有多个竞争解释（心理学的流派、经济学的学派、历史学的解释框架）。学的不是「哪派对」，而是「各派在什么条件下更有解释力」。
- **前置断层高发点**：术语的日常语义与学术语义打架（「效率」「理性」「价值」）；混淆相关与因果；把个案当规律。
- **纵向链**：术语 → 概念 → 机制 → 适用条件 → 竞争解释 → 综合判断。

### 目标深度锚点

- **概念型目**：能用自己的话说机制、能给边界反例、能说「为什么不是相邻那个概念」（SOLO 关联）。
- **记忆型目**（年代、条文、人名）：能列举并区分易混对即可，不要求长篇复述。
- **论证型目**：主张明确、证据具体、推理链完整、能处理反方（对应论证结构四段）。
- **设计型目**（制度、方案、政策）：目标、约束、备选、取舍、评价标准齐全；接受多解。
- 本群最忌「结论对、前提错」：结论碰巧说对但机制说不清，按未掌握处理。

### 排期侧重

- **一节一个概念群**：把三个相邻概念塞进一节必然讲成名词解释。宁可一节只讲「进程与线程的区别」，也不要一节讲完整个操作系统。
- **案例紧随概念**：概念讲完当节必须配一个案例走通，隔节再补案例，概念已经凉了。
- **竞争解释成对出现**：有学派之争的主题，必须同一节把两派摆在一起，不要分两节讲。
- **写作类目单独占课时**：论述与案例分析的写作训练不能挤在讲概念的轮次里顺带完成。
- **考前**：主观题按得分点结构收口，事实类只清错题，不重背全书。

## 人文社科群 · 出题切片

### 题型阶梯

- **判断题（考边界）**：给「对一半」的表述，让学员判并说错在哪半。这比直接问定义有效得多。
- **概念对比题**：A 和 B 都能解释这个现象，什么时候选 A？考的是适用条件，不是「是什么」。
- **机制复述题**：用自己的话说「为什么成立」。说不出机制＝只背了定义。
- **案例分析题**：一个完整案例走到结论，历史落到史料互证，法学落到要件，经济心理落到替代解释。
- **论证写作题**：给主张与材料，要求写成完整论证（主张—依据—适用—反驳）。
- **设计/方案题**：给目标与约束，要求给方案并说明取舍；接受多解。
- **交错**：概念对比、案例、机制复述三类混排，逼学员先判「这题在考哪一层」。

### 群级共享误区库

只放**跨人文社科通用**的条目；史料即事实、请求权检索、经济直觉陷阱、心理学谬误等学科专属条目见 `disciplines/` 下对应包。

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 把类比当定义 | 用「像医院分诊」回答「什么是进程调度」 | 类比好记 | 类比在边界处必失真，答题要按定义 |
| 把特例当通则 | 用一个例子反推全部 | 首例印象深 | 问「所有情况下都成立吗」 |
| 相邻概念混装 | 名字相近的两个概念互换使用 | 教材分开讲 | 成对对比，把适用条件摆出来 |
| 结论对前提错 | 记得结论，说不清适用条件 | 背结论省力 | 换一个前提让它失效 |
| 日常语义读术语 | 把「效率」当「速度快」 | 母语直觉 | 术语首现给白话定义并与日常义区分 |
| 相关当因果 | 见相关即推因果 | 叙事本能 | 找共同原因或反向因果的反例 |
| 单因果叙事 | 一个事件只给一个原因 | 教材简化 | 分长期／中期／触发因素三层 |
| 用今天标准评过去 | 说「当时的人应该知道」 | 当下视角默认 | 先重建当时的条件与信息 |
| 只记结论不记推理 | 能说出「所以」说不出「因为」 | 结论可背、推理要跟 | 要求补出中间三步 |

### 判定题构造

问「边界」而不是「定义」：给一个「看起来适用、其实不适用」的情境问是否正确、给两条相邻规则问这条案子该用哪条、给一个结论问「它在什么条件下会反转」。干扰项要是「在相邻条件下才成立」的说法，让学员必须真判条件。

### 答案形态与最小单元

- 起笔用 `答：`；题面／案例／材料写在讲义 ① 题目；答案框体例见 `references/handout-layout.md`「答案框体例（学科无关）」。
- 最小单元＝一个**论证环节**：主张一段、依据一段、适用一段，各自可独立判对错。
- 论述按「结论—依据—适用」分段；案例落的学科另接「请求权基础 + 要件 + 本案事实」（法学）或「史料引用 + 互证」（历史）。
- 设计／方案类用 `方案：` 起笔，给目标、约束、备选、取舍、评价标准。
- 客观题给答案 + 逐项一句排除。

### 视觉任务

用原始史料图、地图、统计图表、制度架构图并记录来源与图号；替代禁令与证据资格（含讲义生成的概念图/对比表）见 `references/assessment.md`「视觉任务证据」。

### 给分点结构

论述按「定义／机制／条件／例子」四段给分；案例分析按「争点／依据／适用／结论」四段；设计题按「目标／约束／备选与取舍／评价标准」四段。主观题接受语义等价的表述，只要意思对、要点齐。

## 人文社科群 · 复习切片

### 复习形态与间隔侧重

- **相邻概念成对复习**：单侧复习防不住混装。复习时永远把易混对放在同一屏里，先让学员说出差异，再各自举例。
- **案例迁移复习**：换一个新案例判同一个概念——考边界而不考复述。同一个概念配三个不同情境，比背三遍定义有效。
- **机制问「为什么」**：说不出机制就回炉对应目，不死背。机制题可以口头回答，一句话因果即可。
- **事实类按易混对整理**：年代、条文、人名单独成对比表，用检索式复习（遮住一列回忆另一列），不做整段重读。
- **论证写作按段复练**：不重写整篇，只练最容易塌的那一段（多数人是「适用」段）。

### 错因分流与纠错脚本

| 错因 | 判别信号 | 纠错动作 |
|---|---|---|
| 概念混淆 | 相邻概念互换使用 | 成对对比表 + 各举一例；复习时强制同框 |
| 只背结论 | 能说结论、说不出条件 | 换前提让其失效；补机制与边界 |
| 论证跳步 | 结论对但中间推理缺失 | 用「主张—依据—适用」骨架补缺口，不整篇重写 |
| 证据弱 | 只有观点没有证据，或证据与主张不对应 | 练「这条证据支持哪一句」的配对 |
| 单因果 | 只给一个原因 | 补三层因果（长期／中期／触发），做多因排序 |
| 时代错置 | 用现代标准评判 | 先重建条件再评价；练 sourcing |

**纠错话术**：本群的错多在「前提与结论不匹配」，纠错要点名是哪一步的适用条件没对上，不要笼统说「理解不深」。

### 冲刺侧重（方法层）

- **主观题按四件套组答案**：定义 + 机制 + 条件 + 例子，写满得分点不灌水。
- **案例题限时**：冲刺期把案例题放进限时训练，练「先定争点再找依据」的答题节奏。
- **论述开头就给结论**：不留悬念，第一句亮明判断，后面再补依据。
- **事实类只清错题**：不重背全书，只过错题清单与易混对比表。
- **考前不排新内容**：最后一晚只看对比表与错题。

## 人文社科群 · 讲授切片

### 讲授侧重（六拍内的群差异）

- **反驳式呈现是默认讲法**：讲到高发误区时，先明说误解、再一句话戳破、然后给正确概念。机制上必须让学员先看见旧直觉失灵，新概念才挂得上去——直接给正解，旧直觉还在原位。
- **概念四件套**：定义 + 机制（为什么成立）+ 适用边界（什么时候不适用，配反例）+ 与相邻概念的对比（为什么不是它）。缺「对比」这一层，学员就分不清相邻概念。
- **案例先行或案例收口**：抽象概念配一个具体案例走全程。可以先用案例制造疑问再给概念，也可以讲完概念立刻用案例收束，但一案到底，不要每段换一个例子。
- **有合适类比时类比先行，没有就准确定义加结构图**，不强凑生活类比。用一个反例澄清边界。
- **社科概念配「直觉陷阱」**：经济与心理的日常直觉常指向错的方向。示范时先摆直觉答案，再翻正——这比直接给正解记得牢。

### 学科思维实践

1. **找主张**：这段材料／这个理论到底在说什么？用一句话写出来。
2. **找证据**：凭什么这么说？证据是一手还是转述？
3. **找替代解释**：还有没有别的解释？怎么排除？
4. **找边界**：这个结论在什么条件下会失效？

四问是复述题的骨架，也是论述题的骨架。历史偏 1–3（史料互证），法学偏 2–4（要件与例外），经济心理偏 3–4（替代解释与边界）。

### 表征体系

- **概念对比表**：相邻概念并排，行是「定义／机制／适用条件／典型误用」。
- **因果链图**：多因一果、一因多果都画出来，避免单因果叙事。
- **时间轴**：历史与制度演变用轴，标出同期事件，防止时间线压缩。
- **论证骨架图**：主张—证据—推理—反方，用于写作前搭架子。

概念图在章末由学员**自己画**，不用现成图代替——画的动作本身就是提取练习。

### 类比库

- 法律关系＝权利义务的天平；不像处——天平只显平衡，法律关系有主体、客体、内容三要素。
- 通货膨胀＝水位上涨：普涨但分布不均；不像处——水位没有「预期」，而通胀预期本身会改变行为。
- 自然选择＝筛子（见 `references/subjects-science.md`「类比库」）；社会领域的「筛选」常带制度设计，不能照搬。
- 类比不是定义——这是本群第一误区。讲完类比必须回严格定义。

### 术语纪律

概念族首次触碰给一页地图（同族概念各一句功能），地图级不作判分项。术语首现「定义 + 例子 + 代入演示」三件齐。本群术语常带译名分歧，全课程统一一个译名，其他译名括注一次。

### 论证写作的标准流程

**主张**：第一句就给结论，不铺垫。
**依据**：规则／理论／史料的原文或准确定位，说清出处与适用范围。
**适用**：把本案／本材料的事实逐条对上依据的要件，缺哪条说哪条。
**反驳**：主动处理最强反方（「有人会说……，但……」），不强求，但有能力就要写。
**收束**：回到主张，一句话给出判断与保留条件。
