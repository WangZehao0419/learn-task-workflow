# 分学科教学案例库

讲授、出题、选讲义风格前，按学科族查阅对应分册；一门课跨族时，以当前小节内容所属族为准。**本文件只补学科素材与侧重差异（类比素材、练习题型、误区模式、讲义风格建议），不改教学流程**——示范规则（完整示例、工作样例、新记号讲透）、阶段闸口、判分纪律等通用规则以 `lecture-styles.md` 与 SKILL.md 教学四原则为唯一来源，冲突时以后者为准。

**类比素材的通用优先级（各族一致）**：学习者画像①层的「类比领域」＞ 本分册默认类比（学员无画像或未记录时）；跨界三猜想（`teaching-loop.md` 第 3 节）的锚点必须确证已会，铁律见 `lecture-styles.md`「类比纪律」。

**视觉任务来源**：识别/关系/图表/比较类视觉任务只用原始材料图/表，不用生成图或讲义示意图替代；数学、物理、化学、生物等有原始图表的学科优先，其他学科有原始图/表时同样适用；细则见 `data-and-recovery.md`「视觉任务来源纪律」。

## 数学类（数学 / 统计 / 逻辑）

- 讲授侧重：先代具体数字算一遍，再上升到一般式；能画图必画图——函数图像/几何图形按 `lecture-styles.md`「图像可视化双轨」执行（对话内 SVG 渲染＋落盘存档，缺一不可），文字描述图仅为兜底。
- 类比素材例：函数=饮料机（投原料出固定配方）；导数=车速表读数；概率=长期频率。
- 练习设计：**按任务细化**——计算类用同型三变式（改数字 → 改条件 → 逆向求解），并可加 1 道口算热身；**证明类**练「补全证明链 / 找证明漏洞」；**建模类**练「从情境列式 + 结果解释」。**不强制每节口算**。
- 常见误区模式：漏负号、适用条件未先判后用、单位与量纲出错。
- 讲义风格建议：默认标准讲义；考点密集期换考试冲刺卡。
- 工作样例差异：完整示范 = 「先代具体数字算一遍」的完整推导（逐步写到最终答案；完整示范末尾附 ③ 答案框，判据同 `lecture-styles.md` 五要素之③）；完整样例之后的加固练习优先**重建型**（挖空关键推导步让学员补全），其次自拟标签型。
- ③ 答案形态：`解：`/`证明：` 起笔（题面写在 ① 题目），用 ∵/∴ 串联、每步一段；选择题给答案 + 逐项一句排除（错项写错在哪），填空写清多空顺序与单位，不写成纯答案清单；备考小节在框后附给分点量表。
- 理科计算与化学（借用本族，不单设学科族）：物理按「公式 → 代入（带单位）→ 结果（有效数字与单位）→ 方向/符号」写，单位换算放在代入步；化学须给配平系数、反应条件（△/催化剂/点燃）与状态符号，计算题给物质的量关系与单位；生物、地理的计算类同此。

## 编程类（Python / SQL / 算法等）

- 讲授侧重：先跑通最小例子再讲原理；先讲「它解决什么痛点」再讲语法。**按任务细化**——**阅读类**重点讲如何读（结构 / 意图 / 边界），**调试类**重点讲定位（假设 → 最小复现 → 二分），**实现类**重点讲设计与拆分。**逐行讲仅在必要处（新语法 / 易错点）使用，不一律逐行讲。**
- 类比素材例：变量=贴标签的盒子；循环=流水线；异常处理=安全气囊。
- 练习设计：改错（埋 1 个 bug）→ 仿写（换需求）→ 微项目；报错解读必练。学员有真实项目/工作场景时，变式与微项目**优先改造自学员的真实材料**（自己代码里的 bug、自己业务的需求），抽象素材退为兜底。
- 常见误区模式：环境与版本差异、缩进与边界（off-by-one）、只在理想输入下测过。
- 讲义风格建议：操作手册式。
- 工作样例差异：完整示范 = 先跑通的最小可运行例子（**首次示范可逐行讲透；学员已有基础后压缩为关键行，不一律逐行**）；**代码示例首次发出前必须实跑，不得只靠阅读或心算核对**；其后的加固练习用**找错型**时，报错代码须真实可运行，勿用伪代码。
- ③ 答案形态：`代码：` 围栏块（可复制运行；任务说明写在 ① 题目）+ `输出：` 运行结果与成功标志；**不以「解：」起笔**，不给虚构评分细则（非备考任务）。报错修复类附「报错原文特征 → 原因 → 修法」。

## 语言类（英语 / 日语等）

- 讲授侧重：场景优先于语法点；输入（听读）与输出（说写）成对出现；当节学当节用。
- 类比素材例：语法=交通规则，词汇=车辆，流利度=对路况的熟悉度。
- 练习设计：跟读 → 替换造句 → 情景对话；拼写与搭配错误记入薄弱点（发音无法在文字会话判分，仅作提示、不作判分依据）。
- 常见误区模式：直译母语、只背不用、近义词混用。
- 讲义风格建议：标准讲义，自测题换成情景题。
- ③ 答案形态：`Answer:`/`Model answer:`/`参考答案：`（题干写在 ① 题目）；翻译给 `参考译文：`，写作给 `范文：`/`Sample answer:`，语法与改错给答案句 + 一句「为什么这么改」。

## 理论概念类（操作系统 / 经济学 / 法学等）

- 讲授侧重：**有合适类比时类比先行**，无则用**准确定义 + 结构图**（不强凑生活类比）；用一个反例澄清边界。
- 类比素材例：进程调度=医院分诊；通货膨胀=水位上涨；法律关系=权利义务的天平。
- 练习设计：判断题（考边界）+ 案例分析（考应用）各 1–2 道；加重复述检验。
- 常见误区模式：把类比当定义、把特例当通则、相邻概念混装。
- 讲义风格建议：费曼卡或对比辨析卡，按需。
- ③ 答案形态：`答：` 起笔（题目/案例/材料写在 ① 题目）；论述与案例分析按「结论—依据—适用」成段，法学案例可落到「请求权基础 + 要件 + 本案事实」。

## 记忆密集类（历史 / 生物 / 法规条款）

- 讲授侧重：框架先行（先给地图后填细节）；故事化串联；间隔重复交给 S4 复习巩固。
- 类比素材例：时间线=故事章节；人体系统=城市管网。
- 练习设计：先填空回忆，后简答；同类条目做对比表。
- 常见误区模式：孤立背诵、年份数值张冠李戴。
- 讲义风格建议：标准讲义，⑤ 小结改为「本节地图」——地图只回收本节已有概念与依赖关系（≤7 条），不新增知识点，也不替代 ④ 易错。
- ③ 答案形态：`答：` 起笔（题目/材料/情境写在 ① 题目）；简答给要点句，按点给分时**每点一段、段首 ①–⑩**（如历史「背景/内容/影响」、生物「结构/功能/过程」），不把要点挤成一段。
- 排期提示：S2 排期时为记忆密集类预留间隔重复节点，配合结课的 1/7/30 复习清单。
