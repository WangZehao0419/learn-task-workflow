## 错因分类与补救（T10）

**归因定类**须分清六种，避免把「没学过」记成学员弱点、把「概念误解」一律当审题问题：

| 归因 | 判据 | 写盘 `错因=` | 首选补救 |
|---|---|---|---|
| **未教** | 该内容本节/课程尚未教 | 知识性 | **先补教**（不记为学员弱点） |
| **遗忘** | 教过、有证据会过，现忘 | 知识性 | **回拉复习**（插热身/回退前置小节） |
| **误解** | 学了但理解偏 / 概念混淆 | 理解性 | **换角度重讲**（换类比/风格；**不默认只练圈画**） |
| **方法选择** | 会方法但选错 / 条件没判 | 技巧性 | **判定题 / 条件化补练** |
| **执行偏差** | 会且选对但粗心 / 审题 / 超时 | 技巧性 | **流程专项**（审题圈画 / 步骤回查清单）；**备考型**可加限时技巧训练 / 同题限时重做（素材见 `subjects/common.md`「应试技巧包」） |
| **过度泛化** | 定义/规则本身对，但用到适用条件之外；典型「我觉得都一样」 | 理解性 | **边界反例 + 判定题 + 学员自举反例**（不默认重讲全节） |

- **四态与错因的边界**：`未判` 不进错因表（不是错，先补判或作废）；`部分` 按缺失的得分点/关键步归因，但不等于全错，也不因「部分」标签自动升级为 A 级；`作废` 不计入错因与错题本。只有真实判错（`错` 或经补判后的 `部分`）才进入本表。
- **误解 vs 过度泛化的二选一判据**：概念定义错 → 误解；定义对、场景错 → 过度泛化。写盘保持 `错因=理解性`，另加独立 token `子类=过度泛化`（`scheduler.py` 忽略未知 token，不破坏解析）。
- **补救按「最早偏离步骤」选**（定位首次偏离点再对号入座），不是按错因标签一刀切。写盘 `错因=` 枚举为 {知识性, 理解性, 技巧性}（解析契约），第六类「过度泛化」写 `错因=理解性` + 独立 token `子类=过度泛化`（映射见上表）。

### 定级与猜测答对

- **判错必须同轮定级**：错题入错题本时同轮完成 `级=` 定级（A=反复出错/直接影响目标达成；B=一般理解偏差；C=纯粗心），与 `错因=` 一起落盘；A/B/C 语义见 `data/progress-schema.md`「复习调度字段」。
- **所有任务类型均分级**：不因知识型/技能型/备考型/材料型而豁免。
- **猜测答对**：凭猜测答对但不会解释的题照常收录并如实定级，不因结果「对」而跳过。
- 只有真实判错（`错` 或经补判后的 `部分`）才进入本表；`未判`/`作废` 不进（见「四态与错因的边界」）。


## 修复动作（连错与负反馈，R40）

- **触发**：学员出现连错、负向语句或对讲解表达不满后，**下一轮先修复再继续**——修复不可拖延到节末（提问/答错后的即时情绪决定整场挫败感，拖延修复 = 放大挫败）。
- **第一句归因教法**：先归因于教学与材料（「是我没讲清 / 这块我讲快了 / 换个讲法」），**不归因于学员能力**，不连环追问「你哪里没懂」。
- **再降阶**：拆更小步骤重讲该步（回到 We do 补步，见 `teaching/lesson-flow.md`「单节课六拍」），或换讲义风格/类比（映射见 `handout/styles.md`「风格切换映射」）。
- **修复期间不新出题**：降阶讲解后给 **1 道低难度同型题**让学员做成、恢复胜任感，再回正常节拍；与「熔断条」连用时，熔断管停轮，本节管修复序列。


## 教学质疑与纠错分支（「为什么学这个」「这步能省吗」「你画错了」「这样讲太绕」都是**有效教学输入**，非跑题）

① 先核对用户指出的事实或必要性；② 对照本次目标与已有材料，区分「当前必需 / 独立目标 / 辅助作用」；③ 给出正确且足够的当前方法，**有错误时先纠正文字、图与存档**（不只加一段解释）；④ 说明具体安排变更（范围实质改变且用户未授权时才确认）；⑤ 恢复原待学位置或待答题，**不重开课程**。涉及用户已指出导师错误的：必要时重判受影响作答。

## 纠错闭环（学员指出或自查发现错误时）

当学员指出或模型自查发现讲解、图、公式、参考答案存在错误时，**在继续教学前**明确三件事：①错误是什么；②影响范围（哪些结论 / 配图 / 判分记录 / 存档内容受牵连）；③修正内容。随后**同步修改**讲义、图、存档及**受影响的判分证据**（错判的题按更正结论重判并留痕），重新运行适用的静态校验（如 `scripts/verify_explanation.py`）与 `handout/self-check.md`「讲解出厂自检」相关维度，并在学习日志**保留纠错留痕**（原结论 → 修正内容 → 日期）。**不得静默改写，不得继续引用旧结论**。定稿讲义的态流转按 `handout/pipeline.md` §2.1/§12 执行：先改回草稿（修订中），修完重跑校验与自检再定稿。
