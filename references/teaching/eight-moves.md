# 教学八动作（R23）

<!-- owns: 教学八动作（R23）；must-not-define: 反馈策略（T09）、教学质疑/纠错/错因、六拍、判分 -->

> 何时读：讲授中需要从教学八动作里选择具体动作时。

「下一步去哪」的完整选项集。每次判分后选定一个动作，随判分记录落盘（动作 + 一句依据）；组合规则见 `references/ops/composition.md`，错因补救见 `references/teaching/interaction-diagnosis.md`「错因分类与补救（T10）」。

| 动作 | 触发/目的 |
|---|---|
| 推进 | 达标，进下一概念/小节 |
| 迁移验证 | 答对但首次应用，换陌生情境再测一次 |
| 压缩已熟 | 连续轻松答对，讲义压缩为要点卡，提速 |
| 换角度重讲 | 理解性卡壳，换类比/换讲义风格重讲（风格见 `references/handout/styles.md`「风格切换映射」） |
| 降档 | 过载，缩 chunk/给示例/降为选择题 |
| 补练 | 技巧性失误，同类变式专项 |
| 回拉复习 | 旧前置遗忘，插一轮热身/回退前置小节 |
| 简化表述 | 不是不会而是没听懂人话，用更朴素语言重说一遍 |
