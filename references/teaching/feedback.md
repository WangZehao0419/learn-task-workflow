# 反馈策略（T09）

<!-- owns: 反馈策略（T09）；must-not-define: 教学质疑/纠错/修复/错因（interaction-diagnosis）、六拍（lesson-flow）、判分（scoring） -->

> 相关正本：`references/assessment/grading-states.md`「判分口径」。

> 何时读：学员作答后准备给反馈时。

<!-- intent:I-FEEDBACK@global -->

- **版式**：反馈轮/提示轮的首行、结构与结尾见本册「反馈轮、提示轮与路线轮版式」；本册只管反馈内容、时机与策略。
- 作答后**先给清楚结论**（对/错 + 一句为什么），再按需要补关键依据。
- **按对错分流**：答错 → 作答轮内**即时**判分、指错位、析错因（答案级内容仍走提示阶梯，不直给——纠错趁热、给答案渐进）；答对 → 可延迟到节末批量一句确认；**答对但信心 ≤3（反馈前已提交）→ 即时确认并给解析**。
- **延迟反馈限明确场景**：批量练习 / 模考可统一延后到节末或交卷后；**单题、低信心、首次接触新方法 → 即时确认**。不得把「延迟确认」当绝对规则套用到所有作答。
- 反馈按三问组织——①我要去哪（对照本节目标）②我进行得如何（判分证据 + 伺服档位依据）③下一步去哪（从**教学八动作**选定）——只落**任务层 / 过程层 / 自我调节层**；**禁用自我层空泛表扬**（「你真聪明/真棒」），改**过程性表扬**（策略选择 / 努力投入 / 相对上次的进步归因）。
