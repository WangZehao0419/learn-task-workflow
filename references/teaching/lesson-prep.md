## 备课短表：先定本次能力，再决定讲什么（T01）

备课前先读 `progress.md` 的 `本次交接` 与最近 `学习记录`（最多 7 条）：上一次留下什么、这次先做什么、哪些方法已被判低效；没有这二区就跳过，不强制。每节备课用一张短表表达，**不要求每个知识点都新增一套长字段**：

| 项目 | 要回答的问题 |
|---|---|
| 本次目标 | 学完能独立完成什么 |
| 必需先修 | 缺少它是否无法完成当前目标（**只用它约束排序**） |
| 核心方法 | 当前最小充分路径是什么 |
| 辅助表示/校验 | 哪些内容能帮助但不必逐题使用 |
| 后续或独立目标 | 哪些内容另有用途、何时学 |
| 本节深讲概念 | 完整深讲软默认 1 个；哪些是工作/参照；>1 关键能力的处理见 `teaching/explanation-depth.md`「深度分层」 |
| 预判误区 | **2–3 条（R42）**：每条 = 症状（学员会怎么错）+ 为什么诱人 + 反证；来源优先本学员历史错因，其次族误区模式；同一份清单喂讲义 ④易错、判定题干扰项与讲授时点点破（细则见 `teaching/explain-quality.md`「预判误区清单」） |
| 元方法 | **方法型目必填（T12）**：题型识别线索（这类题长什么样）+ 方法选择图（什么信号走哪条方法）+ 示范时「我在想什么」；「说明题依据」首次作答前按依据句模板带写一遍（细则见 `teaching/explain-quality.md`「元方法教学」） |
| 关键能力质检 | 每项关键能力是否至少覆盖“判别 D + 边界 B” |

- 依赖边只用「必需先修」约束排序；「帮助理解」与「后续迁移」保留为**关联**，不把整个知识网络都变成前置闸口。课程地图保留整体范围，当前教学按本节任务展开。
- **讲义生成**：按 `handout/pipeline.md` 的设计六问/四段支架/二次定稿与流水线，`handout/templates.md` 的类型矩阵/支持级/学习者状态；本短表只定教学决策，不替代讲义合同。
- **先回答「为什么现在学」**——不用远期价值或独立考点替代当前必要性；只有确实构成本节目标的前置才列为「必需先修」。

### 课首定位（拍 1，每节第一次讲授前，2–3 句 + 知识点清单一行一个，计讲授不计新轮）

先说清**本次能力**——「本节学完你能独立完成什么」（本次目标）→ 达成它所需的**最小充分方法**与**必需先修** → 再点「本节在整条路线中的位置」（前面学过的哪些目是地基、它给后面哪几节铺路）；**公示本节知识点清单与预计课时**（目名 + 顺序 + 总数 + 预计课时，一行一个目名；只列名称、不展开讲解；不按场/段分组；目不设时间上限，不按目数拆节）；**对学员只用目名指代，「块/目/节＋纯编号」不进学员可见文本**（编号仅用于落盘与游标，且与名称成对）；末尾半句回扣学习目标（「本节直接服务你的——」引 S0 记录的应试/求职/兴趣动机）。与节末对账（第 5 件）构成「前瞻—回看」闭环。

**与呈现契约「定位」的分工**：本节第一次讲授做本节的课首定位（一次，覆盖整节路线）；同一节内后续目只做一句**目级锚定**（接上一个概念或已确证旧知 + 本轮目标），不重复整节课首定位。

### 教学质疑与分支处理（「为什么学这个」「这步能省吗」类输入是有效教学输入，非跑题）

处置流程见 `teaching/interaction-diagnosis.md`「教学质疑与纠错分支」；本册只提示：质疑与纠错不重开课程，处理后恢复原待学位置。

### 来源备课与讲授证据

- **先备来源包**：讲授前准备最小来源包——精确页码/章节/链接 + 原文/图，只取本次要讲的范围；不把整本书倒给学员，也不凭记忆补细节。**它不等于 `materials/00-备课来源.md` 的备料台账**：台账是“有哪些来源”的清单，来源包是“这次讲哪几段原文/哪张图”的最小证据。
- **讲义来源映射**：讲义单元/示例按 `handout/quality.md` §9 记来源锚点、原创/改编与覆盖行；来源包是输入，不把整本书倒给学员，也不把来源原文当“已讲”。
- **只教覆盖范围**：来源包覆盖到哪讲到哪；来源缺失、矛盾或读不到时如实说明，必要时做一次定向补查；不编造、不把来源原文当“已讲”。
- **视觉任务取原始来源**：KP 声明视觉任务时，来源包必须包含原始图/表/截图/数据（页码/图号/数据位置）；讲义生成的 SVG/示意图只用于讲解，不能当作视觉任务的原始证据；原图不可用时，新任务不要声明该视觉任务；已声明的按 `未判` 处理或补齐来源，不删改字段绕闸。
- **讲完记证据（可选）**：向学员公开讲完后，可在 `## 讲授证据` 记一行：KP/概念、**已讲内容的逐字引用（≤80 字）**、来源锚点、日期。计划、内部思考、工具结果、来源原文都不算证据。
- **讲授 ≠ 掌握**：这条证据只证明“讲过”，不证明“学会”；掌握仍看判分、复述与关键能力闸口。

## 课首与旧知锚定（拍 3 定位）

<!-- intent:I-CONFIRMED-PRIOR@global -->

- **跨界三猜想前置**（讲授新概念的第一个动作）：讲新概念先**撬旧知**——①**换名字**：它是否就是学员已会的某概念**换了领域名称且语义确实等价**？命中可直接说「你已经会了，它只是改名叫 X」——**但仅在真等价时**：凡存在定义域/维度/适用条件差异的（如**导数→梯度**：一元导数与多元梯度不等价，梯度由偏导数组成的向量、含方向与维数语义），**禁止**按无条件同义词讲授，必须说明多元扩展与关键差异；不确定是否等价时走②或直接讲授。②**结构同构**：与学员已会的某知识做字段级对应（A↔a、B↔b），**明确标出哪里相同、哪里不同**；③**旧知解释**：用学员已掌握的知识把新概念讲通。开场或收尾给一句「你已经会了 ___ 部分，真正全新要学的只有 ___」。
  - **确证铁律**：判断「学员已会什么」只能用**确证证据**（S1 摸底判分记录 / 学员亲口确认 / 学习者画像第②层稳定模式），**严禁**把「材料作者的背景 / 对话里别人的知识 / 学员没否认」当成学员会的；拿不准 → 先问一句「你学过 ___ 吗」。无同构可撬（全新领域第一课）→ 跳过本步直接讲授，不硬凑类比。
- **前提审计**：讲授每一步前自问「学员此刻必须已会什么才能懂这一步」；向学员**明说**「这一步只用到 X、Y，你已经会了」；缺前提 → 先补一个地基目再讲，不假设学员已会。
- **备课查阅**：讲授与出题前按学科族查阅 `subjects/common.md` 与对应群切片；命中具体学科时再加 `disciplines/` 学科包（本会话已读过则不重复读；该层只补学科素材与侧重差异，教学流程以本册为准）。

## 教学姿态三档（S2 选定，默认混合）

<!-- intent:I-POSTURE@global -->

- **A 引导型**：多提问、少直给；适合兴趣/深度理解。学员说「直接讲」→ 当轮切 B，不追问理由。
- **B 直讲型**：先给完整示例/模板/参考答案 → 反推关键步 → 独立重做；适合赶考/时间紧/连续卡壳。**直讲不等于代做**：复述与判分证据不省。
- **C 混合（默认）**：关键处先示范，再提问与练习。
- **自动切 B**（满足任一）：距考试 ≤4 周；学员说「时间紧/只要过关/先应付考试」；同节连续 2 题 Again 或触发熔断。
- **不变量**：比例线取契约 `gates.min_ratio`，关键能力独立通过与复述通过是底线；姿态只改讲授顺序与提问密度，不改验收。
- **记录**：学习日志一句 `姿态：A/B/混合（依据：…）`；不新增字段，不写 `教学策略` 字段。
