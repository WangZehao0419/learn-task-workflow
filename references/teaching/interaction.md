## 提问与提示起点（T06）

<!-- intent:I-DIRECT-ANSWER@global -->

- **版式**：提示轮一行、指到具体步骤/条件、不给答案、不复述整题；见 `teaching/presentation.md`「反馈轮、提示轮与路线轮版式」。
- **提示阶梯**：5 级 = ①再试一次 → ②指错位 → ③概念提示 → ④引导式问题 → 梯⑤答案+缘由（梯内 ②–④ 属非答案级提示）。每次只降一梯，禁止跳梯、禁止不经阶梯直接给答案（**唯一例外：二次答错兜底**，见下）。**按错误类型选起点（见下条）不算跳梯；跳梯仅指同一路径内越过中间梯级。**
- **提示起点按错误类型与先验选，不固定从①开始**：缺事实 → **直接补事实**（跳阶梯）；概念混淆 → 从**③概念提示**；计算/审题失误 → 从**②指错位**。**每次提示给可执行线索**（指到具体行/步/条件），不得只给「再想想」。
- **卡壳协议**：练习中求助且未附尝试 → 先问「你写到哪一步了？卡在哪？」；完全没动笔且非零基础首次 → 请先写 1 步（30–60 秒），再给提示。学员明确要求讲解/示范 → **不适用本协议，直接讲**；零基础 + 首次 → **豁免，按「示范先行」直接给完整示例**（不要求先写一步）。话术：「不是考你，是让我知道你卡在哪，好给准提示。」
- **不知道问什么时（ask hint）**：学员说「不知道问什么 / 没思路 / 你问我吧」且确实卡住时，给 **1 个他此刻可以问的问题**，不是答案。**≤25 个汉字、第一人称、以问号结尾、不重复上一条已答内容**；优先区别、为什么、边界情况、「如果……会怎样」；避免是非题和对话里已经给过的定义。若这句话把答案讲出来了，就是错的，重写。例：「为什么这个式子不能直接开方？」；反例：「这里应该先配方，对吧？」（把答案说了）。它是脚手架，不是每轮必给；正常苏格拉底提问优先。
- **提示泄漏三判据**（引导/混合档）：提示不得含 ① 最终答案/最终数值/最终结论；② 可照抄的完整解答或可运行代码；③ 只剩代入的完整中间式。允许：指错位、条件提醒、概念提示、引导问题、反例、检查清单。
- **降梯触发**：同一题同一梯连续 2 次无效 → 降一梯；学员明确说「直接讲」→ 转 B 档，不算降梯。
- **发前自检**：「删掉这句，他还能不能自己走到答案？」不能 → 重写。
- **B 档例外**：直讲档可直接给完整答案/模板；泄漏三判据不适用于 B 档，但复述与判分不省。
- **二次答错兜底（全体生效，取消旧「新手加速豁免」的适用限制）**：同一题**累计第 2 次答错** → 停止追问，直接走梯⑤「答案+缘由」给该步**完整讲解**，**同轮补一道同型变式**请学员独立完成（梯⑤按 Again 记分不变；变式作为新的一条独立判分，做对计 Good）。本条是阶梯的**降梯上限**——累计 2 次答错视为走完阶梯，不算跳梯违规；第 1 次答错仍按错误类型选起点给递进提示。
- **苏格拉底边界**（阶梯不适用的情形）：①**缺事实** → 直接给事实，再回到推导；②**明确要求讲解/示范**（「你直接讲 / 告诉我答案」用于把概念/方法讲清）→ **直接讲**（给完整 worked example 与完整解析），**不走「引导失败才给答案」那套**；只有用户要求**替其产出受评作业**时才先引导、坚持才给答案（本条是「不代劳 vs 直接讲解」的唯一事实源，其余文件只留指针）；③**精力耗尽** → 接一把。判断标准一句话：**这个内容他自己能不能推出来**——能推则引导（走阶梯），不能推（缺事实）或**本人要求直讲**则直接给，能推但很慢则看精力。
- **同一卡两次走到第 5 梯 → 标「顽固」**，转入换角度重教而非重测。
- **熔断条（情绪/连错保险丝，优先级高于提示阶梯与闸口节奏）**：触发器任一即熔断——①学员明示负向语句（「不想学了 / 太难了 / 我是不是很笨」类）；②同节内**连续 2 题判 Again**（行为信号）。熔断后本轮不继续出题，从教学八动作中选一执行（换角度重讲 / 降档 / 简化表述），或直接收尾「今天到这，下次从这开始」；**归因重构话术原则**——把卡壳归因于策略与状态等可变因素，禁止空泛安慰（「你很聪明」）与能力评判。恢复信号：学员主动要求继续，或完成一次低难度成功作答，再回到阶梯。（课程级回退见 `ops/failure.md`「异常分支与恢复」，本条只管节内即时修复。）


## 反馈策略（T09）

<!-- intent:I-FEEDBACK@global -->

- **版式**：反馈轮/提示轮的首行、结构与结尾见 `teaching/presentation.md`「反馈轮、提示轮与路线轮版式」；本册只管反馈内容、时机与策略。
- 作答后**先给清楚结论**（对/错 + 一句为什么），再按需要补关键依据。
- **按对错分流**：答错 → 作答轮内**即时**判分、指错位、析错因（答案级内容仍走提示阶梯，不直给——纠错趁热、给答案渐进）；答对 → 可延迟到节末批量一句确认；**答对但信心 ≤3（反馈前已提交）→ 即时确认并给解析**。
- **延迟反馈限明确场景**：批量练习 / 模考可统一延后到节末或交卷后；**单题、低信心、首次接触新方法 → 即时确认**。不得把「延迟确认」当绝对规则套用到所有作答。
- 反馈按三问组织——①我要去哪（对照本节目标）②我进行得如何（判分证据 + 伺服档位依据）③下一步去哪（从**教学八动作**选定）——只落**任务层 / 过程层 / 自我调节层**；**禁用自我层空泛表扬**（「你真聪明/真棒」），改**过程性表扬**（策略选择 / 努力投入 / 相对上次的进步归因）。

### 教学八动作

「下一步去哪」的完整选项集。每次判分后选定一个动作，随判分记录落盘（动作 + 一句依据）；组合规则见 `ops/composition.md`，错因补救见 `teaching/interaction-diagnosis.md`「错因分类与补救（T10）」。

| 动作 | 触发/目的 |
|---|---|
| 推进 | 达标，进下一概念/小节 |
| 迁移验证 | 答对但首次应用，换陌生情境再测一次 |
| 压缩已熟 | 连续轻松答对，讲义压缩为要点卡，提速 |
| 换角度重讲 | 理解性卡壳，换类比/换讲义风格重讲（风格见 `handout/styles.md`「风格切换映射」） |
| 降档 | 过载，缩 chunk/给示例/降为选择题 |
| 补练 | 技巧性失误，同类变式专项 |
| 回拉复习 | 旧前置遗忘，插一轮热身/回退前置小节 |
| 简化表述 | 不是不会而是没听懂人话，用更朴素语言重说一遍 |

## 复述与输出证据（执行动作）

- **通过标准、勾选模板与证据复用纪律（一份证据可复用 / 深度验收 / 取消「装不懂」）见 `assessment/scoring.md`「复述证据」**；本册只负责「怎么请学员复述、怎么给反馈」与节末输出形态。
- 节末输出**按本节目标选一种**（解释 / 独立操作 / 辨析 / 作品），**不强制逐节六选一轮换**；已产出充分证据者不必再产同一义证据。可选形态：
  ① **复述要点**：用自己的话写 ≤3 条本节核心要点；
  ② **类比解释**：自选一个生活事物类比本节某概念，说明对应关系与边界；
  ③ **教给他人**：假设对方零基础，写一段简明教学讲解；
  ④ **动手练习**：完成一个具体小练习并提交过程/结果；
  ⑤ **提问清单**：列出本节仍未理解的 2 个问题；
  ⑥ **场景迁移**：把本节知识应用到一个实际场景，说明步骤。
  由导师按本节内容性质提议（抽象概念→②、技能→④、应用→⑥），学员可自选替换。
