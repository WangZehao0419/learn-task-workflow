# 内容类型教学处方

本册回答「这一目按它的类型该怎么教」。类型取 `课程体系.md` 目行的 `类型` 字段（记忆 / 概念 / 程序 / 设计）；未记录时由目名与内容判：能背下来的是记忆，能讲清机制的是概念，能做对一类题的是程序，能按约束给出方案的是设计。

**处方按内容类型开，不按学科开**（Gagné《学习的条件》：不同结果类型需要不同的教学条件；Merrill 成分显示理论的内容维＝事实/概念/程序/原理）。学科只决定**教什么**——例子、表征、误区与验收规范来自学科层，不改变本册的类型处方。

| | 记忆 | 概念 | 程序 | 设计 |
|---|---|---|---|---|
| **讲授序列** | 先给框架地图 → 挂事实 → 当场两轮检索 | 先激活旧直觉 → 看见它失灵 → 反驳式给正解 → 边界反例 | 完整样例（每步「做什么+为什么」）→ 补步 → 独立 | 目标与约束先行 → 给 1–2 个完整方案 → 比较取舍后自拟 |
| **表征默认** | 时间线 / 结构图 / 对比表；一图胜一段 | 机制图 + 一个反例；类比须标「在哪失效」 | 分步过程图 + 关键步标注 + 反例 | 约束清单 + 方案对照表 + 评价标准 |
| **练习阶梯** | 填空（挖 1 处，不整句挖）→ 简答 → 易混对辨析 | 判定「对一半」的表述 → 概念对比「何时选 A」→ 换情境迁移 | 样例复现 → 改错 → 补全 → 同型变式 → 逆向 → 微项目 | 给约束求方案 → 多方案比较 → 找出现有方案的失效条件 |
| **纠错风格** | 初学用 **errorless 渐退**（给答案 → 遮一半 → 全遮），不让学生先猜；猜错会固化错误痕迹；关键词编码只解决「怎么记」，必须叠加检索才算复习 | 先问「你原来怎么想的」，让旧模型先出场，再给反例戳破 | 错在哪一步就回哪一步，当场按脚本纠正后立即重做该步 | 不纠正「答案」，纠正「约束漏了哪条 / 评价标准错在哪」 |
| **复习侧重** | 检索优先于重读；一张卡一个事实；易混对并排出现；反向也测 | 机制复述（说不出「为什么成立」＝只背了定义）+ 边界题 | 读码式回忆：给题说第一步；交错混排逼先选方法 | 换约束重做；复盘取舍理由是否仍成立 |
| **验收天花板** | SOLO 多点结构即可毕业（能列举并能区分易混对），不要求拓展抽象 | SOLO 关联结构（机制 + 边界 + 与相邻概念对比） | SOLO 关联结构（能解释条件与纠错，不只结果对） | SOLO 拓展抽象（能在新约束下自拟方案并论证取舍） |

**跨类型的共同底线**

- **撤架判据**：独立正确率稳定 ≥70–80% 即停发完整样例，改补全题或纯问题；跨到新 KP 时判据重置（专长反转）。撤销的是支架，不是复述与判分证据。
- **分段自控**：一次只给一个步骤并等回应；由学员决定何时继续，系统不代替他分段。
- **反馈层级**：只落任务层/过程层/自我调节层、禁用自我层评价（三问组织与过程性表扬口径见 `teaching/interaction.md`「反馈策略（T09）」）——自我层几乎无效且在失败情境下有害。
- **受控失败**（仅概念型且学员已有前置）：允许先试错，但失败尝试**不计分**，且必须紧跟「你的解法 vs 规范解法」的对比讲解，否则净效应为负；记忆型与零基础学员禁用。
- **动作技能能力边界**：体育、演奏、书法、驾驶、手工等以身体协调为主的技能，对话式家教无法提供实时动作纠错、器材反馈与视奏听音即时反馈。可教的是练习设计、反馈解释、注意焦点改写与排程；不可教的部分必须在开课时明说，不假装能代练。
