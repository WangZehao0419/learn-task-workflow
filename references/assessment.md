# assessment 正本册

> 本册把 12 个分册合成一处：due-queue 与复习预算 / 题组与判分文件 / 出题与练习设计 / 判分口径 / 出题范围与未讲授过滤（R35） / 题量预算与自测≠题组 / 可选加练（巩固与举一反三，R55） / 复述证据 / 间隔调度与调度数据语义 / 闸口比例、批改与申诉 / 出题前术语对账（R46） / 智能变式一次一维（R43）。

## due-queue 与复习预算

- `due-queue` 同时读取「薄弱点」「错题本」「保持复习」三区，输出 `kind` 与 `reason`，schema 以契约为准；刚入库/当日的条目不重复入队。
- **未讲授过滤（R35 前置）**：未讲授条目不入队、转安排对应讲授（先教后练）；口径唯一事实源见「出题范围与未讲授过滤（R35）」。
- 进入新节前按本次可用时间设预算（复习不超过约 1/3 课时，其余留给新内容）；队列非空 → 优先清「关键先修 + 高影响错误（cw / 顽固）+ 到期的保持复习」，其余显式顺延（保留原到期日并在进度对账中可见）；队列长（>5 条）→ 明示队列长度与顺延方案，默认按预算顺延并继续新内容、不空等批准。
- 排序契约：cw → 最逾期 → due 早 → 稳定序；`顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- 缺日期/坏条目的口径见 `references/data.md`：缺日期不入队、`W-UNPARSED-ITEM`；不得以当日或猜值补造。

- **机器行与讲评行分离（v2 核心纪律）**：每题卡片 = `### 题 N · <考点>（能力）` 标题 + 一条**机器行**（`- 题 N：作答「…」｜字段…`，唯一携带 `正确性=`/`独立性=`/`调度档=`/`KP=`/attempt token 的行，≤120 字，括号注只缀在枚举值后）+ 按需的缩进 `- 讲评：` 行（放依据、错因、作答原文全文；**讲评行不得再写机器 token**，避免被解析成第二条作答）。判分解析按行配对三要素，机器行拆散到多行 = 判分丢失。

#### 正式/轻量确认（推进确认）

- **正式确认（可选）**：关键目正式确认写入 `## 作答与判分`（卡片体例见上方「推进确认」示例），标 `用途=推进`；有对应 KP 时写 `KP=<id>`（格式 `KP=KP-<节>-<KP序>`，如 `KP-03-08`；`KP-03-08a` 这类编号不合法，脚本不识别），无对应目行时写 `目=<目名>`——`目=` 是人读字段，不进闸口计算；计入正确性分母与本节新题总量（题量口径见「题量预算与自测≠题组」）；正式确认可作记忆/程序 KP 的分型证据（带 `KP=<id>` 独立正确），概念/设计仍需复述勾选行含该 KP 编号；早期错误与变式均保留，不删不改。简单目轻量确认不写 `正确性=` 判分行；需要留痕时在记忆.md 学习日志写一句「目名 + 确认方式 + 结果」。
- **分型字段**：若 `课程体系.md` 的目行声明了类型/视觉任务（可选分型字段见 `references/data.md`「课程体系文件」），attempt 行补 `KP=KP-<节>-<KP序>`；视觉任务再加 `｜视觉=<任务>`；概念/设计在复述勾选行写该 KP 编号。分型闸口见 `references/workflow.md`「S3 闸口（可检验）」。
- **反例（应避免的版面形态）**：`1.（节末第 1 题·词性判定）判定…` 无空格列表、单行 430 字「作答＋判分＋备注」流水账——按 Markdown 基本格式（列表空格、行内 `$` 成对、标题不跳级、表头齐全）自检改写，不设机器闸口。
- **向后兼容**：v1 单行台账格式仍可被脚本解析；新写与改写一律按 v2 卡片，不改判分语义（四态、调度档、attempt 语义 owner 仍在 本册）。
- **参考答案区块（可选，判分后回填）**：位置固定在文件**末尾**（「作答与判分」之后）——`progress_check.py` 的 `evidence_section` 截到下一个二级标题为止，区块放在判分段之前会把判分记录截断。**出题时不预写**（防泄题），判分完成后回填；客观题写「答案 + 一句依据」，主观/论述题写要点行或 `见 materials/NN-…md 概念 N 的 ③ 框`，不复制讲义全文。**正文唯一事实源仍是讲义 ③**：本区块只做复习索引，二者不一致时以 ③ 为准并同步更正。**不另建 `-答案.md` 分册**——`exercises/` 内文件按编号前缀被当作判分证据消费，同前缀的答案文件会被误当证据（`E-EMPTY-EVIDENCE` / 证据错配）。
- **组卷（独立触发「组一套卷」）**：卷末同设 `## 参考答案` 区块，题面区顶部写一行「作答后再看文末答案」；不拆答案册，命名与普通题组一致。
- **落盘自检**：写盘前按 Markdown 基本格式（列表空格、行内 `$` 成对、标题不跳级、表头齐全）核对即可，不设机器闸口。

#### 结课蓝图的机器可读形态（R5）

**为什么要有这一条**：S5 的「能力—任务—评分点蓝图」若只写在文档里，闸口就只能查「KP 编号有没有在卷子里出现过」——题面写一句「KP-03-08」即可过闸，而 R5 明写「仅题面提到该 KP 不算映射」。**编号出现 ≠ 有可判分的评分点**，所以映射必须落在机器行上。

- **形态**：`99-` 结课综合测验「作答与判分」段内，**同一条机器行**同时写 `KP=<id>` 与 `评分点=<该题可独立判 0/1 的步骤或断言>`，例：
  `- 题 2：作答「…」｜正确性=对｜独立性=独立｜调度档=Good｜KP=KP-03-08｜评分点=先判定适用条件再代入`
- **三条硬约束**：① `KP=` 与 `评分点=` **必须在同一行**——拆成两条行不算映射（解析按行配对，与三要素同口径）；② `评分点=` **空值不算映射**；③ 评分点写的是**步骤或断言**，不写「题 2 考 KP-03-08」这种同义反复（蓝图自检第 4 条，见 `references/workflow.md`「S5 结课」）。
- **闸口口径**：`E-FINAL-BLUEPRINT-GAP` 按**映射集合**判，不按文本子串判；缺口分两类报——「未出现」（卷子里根本没这个 KP）与「出现但未挂评分点」（编号出现在题面/讲评/复述，但没落到评分点）。KP 编号归一化后比较（`KP-1-1` ≡ `KP-01-01`）。
- **范围**：只对 `99-` 结课综合测验生效，且只对「纳入 KP」（目行状态 ∈ {未讲, 已讲}）生效；节题组、`z-` 变式、`j-` 加练不要求写评分点。

## 出题与练习设计

### 出题流水线（四步）

出题（S3 练习、S4 复习、独立「考考我」/组卷）按四步执行；题量、题型与难度仍受 S3/S4 预算与目标约束。S5 综合测验不改变既有蓝图与目标线规则：先按「能力—任务—评分点蓝图」定覆盖、题量与分值，再用本流水线生成与自检。

1. **探索**：先读本次节目标与讲义范围；读课程体系中本次相关 KP 目行（S5 按蓝图读全部纳入目行）；S4/已有任务的独立出题先跑 `due-queue`（无任务时跳过；S3 沿用进入节前的结果，跨日续学可重跑）；再读 `exercises/` 最近题组与判分记录，标出「要考的能力 / 主要错因 / 已出过的题」，避免重复旧题（T11 明确选择「原题保持」时除外）。
2. **规划**：按本次题量预算列题（默认取契约题组范围；S5 综合测验按蓝图），逐题定 topic、题型（基础/应用/变式/判定）、难度、对应 KP 或能力；题型含判定题（要求见「零提示与条件化判定题」）；组内 topic 不重复（T11 明确选择「原题保持」时除外；同一薄弱点需多问、或 S5 蓝图要求同一 KP 多题时，用不同题型/情境/变式，不以换数字充数）；新学按基础→应用→变式递进，复习按 T11 选「原题保持 / 近迁移 / 远迁移」。
3. **生成**：逐题写题干、选项（选择题）、答案、解析、难度与 KP 映射（选项与答案纪律见「零提示与条件化判定题」）；用材料出题时记来源锚点（页码/图号/数据位置）。主观题（计算、证明、解答、写作类）随题列**给分点清单**——按解题步骤逐点列，每点可独立判 0/1；判分按清单走「部分」，不整体印象分。
4. **修复**：整套题一次性复核**第 3 步各项**，另查四项——**难度自检两线**（题组预估难度至少跨两档；预期全对或全错的死题不入题组）、与旧题是否重复（T11 明确选择「原题保持」时除外）、是否与本节自测同题（仅 S3 新学题组适用，此项无例外）、**术语对账（R46，见「出题前术语对账」）**；发现问题修一次并重检，不无限重写；答案键不确定标 `未判`，不猜。

四步是同一轮的内部流程，不额外占用学员轮次；题组按「一组题一条消息交齐」交付。**未作答题组优先**：若 `exercises/` 已有本节未作答题组，直接取用并等用户作答，不重新出题；重发只复述题面与提交格式。

#### 短题与正式确认

- **短题豁免**：关键目正式推进确认题等短题不走四步流水线；但答案键须先核对、无提示泄漏。
- **答案键不确定**：标 `未判`，不得以未判推进；照片/手写输入按「批改与申诉」的输入判读规则处理。
- 正式确认仍按判分四态/独立性照记（分母口径见「统计口径」）；不替代题组的关键能力独立通过与节复述。

### 零提示与条件化判定题

出题时遵守「零提示」规则，防止题目本身泄漏答案或降低检索难度。以下规则在第 2 步规划与第 3 步生成时逐条核对：

- **出题形态分界**：能从已有知识逻辑推导的内容，练成解题/应用题；无法推导、纯记忆的任意性内容（单词、常数、术语表）才做填空/背诵卡。判断标准一句话：**这条能否从别的东西推出来**——可推导内容做成死记卡是浪费检索练习，任意性内容硬出证明题是折磨学员。
- **答案与选项纪律**：题目与答案分离，先出题、等作答，正确答案与解析批改前不下发。选择题选项在长度与结构上对称，正确项不得更长、更完整或带「推荐」标记；展示前打乱顺序；题干和解析都不引用「A/B/C/D」，按内容说答案。难度在题面或题组文件头注明「难度：易/中/难」，不写进调度档（调度档记录表现，不记录题目难度）；每题都能在批改反馈或判分后的参考答案区找到解析（不要求在题面预写）。
- **干扰项**：取本节常见误区的具象化，与预判误区清单一一对应（R42），不用显然错的弱干扰。
- **防猜测选项**：选择题可含「我不确定」类选项，学员选它按未答（Again）处理——防 25% 猜对虚增闸口正确率，给低信心一个诚实出口。
- **格式不泄题**：不在题干里暗示答案（如「以下**错误**的**是**」的加粗位置、选项排序规律）。
- **变式真变**：递进题（基础 → 应用 → 变式）须换情境或逆问题，而非只改数字；**一次只变一个维度（R43，结构判据与预测轮见「智能变式一次一维（R43）」）**——一次变两个维度学员无法归因；关键目变式前加预测轮。
- **条件化出题（判定题）**：每个题组至少 1 道考「**何时用**」的判定题——给出场景问该用哪个知识点 / 给出信号问该触发什么方法 / 追问权衡（「方法 A 什么时候反而不如 B」）。只考「是什么」的题组默认不合格：掌握 = 会内容 + 会判定适用条件，二者缺一不可。判定题的干扰项须是「邻近情境下才对」的方法，制造真实的判定张力（R42）。
- **复习变式优先、原题按目标保留（T11）**：S3 热身、S4 复习、综合测验重试的题目**以变式为默认**（换措辞 / 换情境 / 反向问 / 迁移情境），与「变式真变」同一取向；但**不一律禁止原题**——按目标组合「**原题保持** / **近迁移** / **远迁移**」，需检验长期保持时可原样重问（同日两次正确 ≠ 长期保持）。凡暴露过具名误区（概念探测或判错）的条目，重测设问优先对准该误区（迷思只被抑制、需反复压制）。
- **难度对齐**：题组难度对齐用户目标（考试对齐真题，兴趣对齐应用），不超纲、不降维羞辱；加难/降难按「难度伺服」执行，本册不另设目标区间。

## 判分口径

**判分三维 + 调度档位**（闸口正确性与调度 grade **分离**）：

- **正确性（四态）**：`对 / 部分 / 错 / 未判`（无别名，非法值放行模式报 `E-ENUM-GRADE`）。`对` 计入闸口分子与分母；`部分` 计入分母、不计入分子（未达完整正确，按缺失点归因并进薄弱点；如需保留原题再进错题本并标 `结果=部分`，调度档用 Again）；`错` 计入分母；`未判` 不计入分母、不写 S/D、不进错题本——它表示答案键/输入/来源不足以判，不是「错」。**作废**行只保留审计，不计入闸口/S/D，不删除原判分行。
- **独立性**：独立完成 / 经提示②–④（非答案级）后完成 / 经梯⑤获答案后才理解（**给答案不算答对**，计 0）。attempt 行 `独立性=` **缺失或 `未测` 一律不推为独立**（`E-NO-INDEPENDENCE`）。
- **流畅度**：快速（无停顿、无试错）/ 常规 / 明显卡顿·试错；**时间/过程不可观测时记「未测」**，不猜、不折半。
- **调度档位（仅用于 scheduler 算 S'/D'，不折算闸口正确性）**：Easy=独立且快速答对；Good=独立答对（常规节奏）；Hard=经提示②–④后答对 / 明显卡顿试错后答对；Again=未答对 / 梯⑤给答案后才理解。
- **有效作答全为未判/作废** → `E-NO-GRADED-ATTEMPT`，不得标已掌握。
- **attempt 幂等与冲突**：同一 `attempt_id` 幂等去重，结果/独立性/KP 冲突判定报 `E-ATTEMPT-CONFLICT`（脚本口径）。
- **证据内容抽查**：判分记录文件存在但**未提供可用证据**（空文件、或只含「作答/判分」标题模板而无真实结果行）→ `progress_check.py` 日常模式输出 `W-EMPTY-EVIDENCE`；**放行模式（`--release`）升级为 `E-EMPTY-EVIDENCE`**——空/模板证据不得支撑本次新增掌握或结课结论。文件缺失仍为 `E-NO-EVIDENCE`。闸口未过时**不删题组**，补齐判分后继续。

#### 难度伺服

| 参数 | 取值 |
|---|---|
| 滚动窗口 | 最近 **~7 题**正确率（按**正确性**计：独立正确与提示后正确均计 1，Again/给答案计 0） |
| 计分 | 正确性驱动：正确=1，未答对=0；**Hard 不记半分** |
| \>90% | 加难（去提示 / 迁移题 / 双概念综合） |
| 70–90% | 保持 |
| <70% | 降难（缩 chunk / 给示例 / 降为选择题） |
| 落盘 | 伺服判定结论（档位 + 依据 + **样本数**）随判分记录落盘；报"正确 x/样本 n 题"，**n < 5 时标注"样本过小，档位仅供参考"** |

难度伺服 85% 目标为**启发式参数**（Wilson et al. 2019 仿真研究、Rosenshine 课堂 ~82% 呼应；边界见 `references/ops.md`）。

**统计口径**：正式推进确认题进入正确性分母；难度伺服以题组 attempt 为主，正式确认只作即时教学信号，不单独改变档位（分母与字段见「正式/轻量确认（推进确认）」）。

#### 信心时序

信心**可选**，学员可在**反馈前随作答一并提交**「当时几分把握（1–5）」——这是可用于 cw / 校准的**原信心**；若在批改反馈**之后**才补报，一律标注**回顾性**（postdiction），**不得据此推断其原先信心、不计入 cw、不计入信心校准**。（cw 语义见 `references/data.md`「复习调度字段（T04）」。）

## 出题范围与未讲授过滤（R35）

- **唯一允许的出题域 = 已讲授内容**：**从未讲授的知识点永不出题**——覆盖热身、练习、复习、综合测验与快捷指令出题的全部场景。**分层准入门槛**：①**首练 / 讲义自测**：知识点已讲授即可出（首练是「先教后练」的补步/独立练习，不要求此前有作答）；②**变式 / 正式题组 / 迁移 / 复习抽题**：知识点已讲授，且学员已有至少一次**成功作答**（独立或经提示后正确，口径统一）；只有未判/作废作答不算成功记录。
- **未讲授条目处理**：due-queue 输出中，所属知识点尚未讲授的薄弱点/错题条目**不入测验队列、不催答**；到期转为安排对应讲授（先教后练，六拍见 `references/teaching.md`），讲授完成后再按新条目入调度。
- **摸底薄弱点 ≠ 已授内容**：S1 摸底产生的薄弱点，在其对应内容讲授完成前一律按未讲授处理。
- **「已讲授」判据**：课程体系目行状态 `已讲`、节路线勾选、或该目有讲授/检验记录——三者取其一即可；复述与闸口是否通过是另一层的事，不影响「已讲过」的认定。
- **执行落点**：S3 热身（`references/workflow.md`「每轮小步（五步）」②）、S4 抽取（`references/workflow.md`「复习债治理」）、S5 综合测验（覆盖约束的终极对照见 `references/workflow.md`「S5 结课」出题范围约束）。

## 题量预算与自测≠题组

- **每节核心新题合计 ≤ 契约 `budget.core_total_max`**：讲义自测取 `budget.self_test`；题组合计 `budget.exercise_group_min`–`budget.exercise_group_max`；单元检验 0–`budget.unit_check_max` 用剩余额度；深度验收与 S4 复习复用题组题，不额外加题。
- **关键目正式推进确认题另计**，不设每节道数上限；简单目轻量确认不计题量、不写判分行。
- **题组不与本节讲义自测同题**（L3 复习产物例外见下）；自测只作低风险自检，不作判分证据。**正式确认题必须使用未印答案的新题或变体**；已印答案的讲义自测不因复用而变成判分证据。
- **L3 复习产物例外**：检索版要点卡 3–5 题优先复用旧题/题组（至少 1 道换情境/新问法），不作新判分证据；`budget.l3_review_min/max` 以契约为准。产物形态（检索版要点卡、`③ 不适用（已会·检索版）` 标注）见 `references/handout-layout.md`「L1/L2/L3 支持级（阶段 2）」；本条只定义题量与同题例外。
- **超预算时**先减单元检验，再并题组或移入 `exercises/` 次日再做，不靠加题补密度。

#### 分块与交错切换

- **习得期**：新程序还在习得期（独立解题常失败）→ 同型分块练，先把单个程序练稳。
- **切换**：当独立解题开始成功 → 切为交错混练，混入已会程序/旧题型，迫使学员区分适用条件。
- 切换时序为推断级（证据见 `references/ops.md`）；不改变题量预算、判定题要求与 S3/S4 的其他规则。

## 可选加练（巩固与举一反三，R55）

- **定位**：节闸口达标后的**自愿**扩展练习——学生可选做，拒绝零评判（不追问、不记录负面、不施压）；不占节核心题量、不进节闸口分母、不计入伺服样本。两个入口：①**节末征询**（`references/workflow.md`「节末收尾五件套」后一句话提议）；②**快捷指令「来点挑战 / 加练」**（`references/routing.md`）。
- **两类题组（学员选其一或都做，合计 ≤ 契约 `budget.reinforce_max`）**：
  - **举一反三题组**：两道**表面不同、结构相同**的题并排（换情境 / 换问向；干扰项与预判误区同源）→ 学员各解 → 请学员**一句话总结两题共用的结构或方法**（说得出才算过——迁移的判据是结构可见，不是做对就算）→ 再给 1 道**远迁移题**（陌生情境或逆问题）。与 R43 的关系：并排对比是**并列对照**，不受「一次一维」约束（对比的目的就是让差异同时可见）；对比组内每道题的生成仍守 R43 与「变式真变」。与 R35 的关系：按**准入②**执行（已讲授 + 至少一次成功作答——节末达标后天然满足）；R46 术语对账照跑。
  - **跨节串联综合题**：把本节内容与 ≥1 个之前节的内容连起来用 1 道综合题（连接证据取向对齐 `references/workflow.md`「跨目串联（多目节）」）；选节按课程体系前置依赖图取与本节相邻或被依赖的已讲节；R35 / R46 照跑。
- **判分与落盘**：判分照四态与调度档，attempt 行写 KP 映射；落 `exercises/j-加练-<日期>.md`，文件头加一行「可选加练，不计闸口」（文件结构同 本册，`j-` 前缀见 `references/data.md`「目录布局」）。做对的内容条目按既有条目命令更新 S/D/due；**加练判错仍入薄弱点 / 错题本**（数据诚实；「判错↔入账」护栏对 `j-` 文件照常校验），反馈话术按「挑战题答错正常」零施压口径；熔断条照适用，熔断即止不转必修（见 `references/ops.md`）。
- **频控与关闭**：节末征询默认每节末一句话；学员说「别再问 / 不用来这套」→ 写 `references/data.md`「学习者画像」①层偏好（学员亲口说的，免确认落盘），此后只留快捷指令入口；快捷指令不受征询关闭影响。

## 复述证据

- **通过标准**：学员复述**覆盖 ≥ `restatement.keypoints` 个本节关键点**且**无事实性错误**。判分时逐项勾选检查清单（关键点 1 / 关键点 2 / 有无硬错），把勾选结果写进题组文件。
- **模板与字段**见「题组与判分文件（exercises/）」复述检查清单区块；勾选语法与解析规则以脚本为准。
- **一份证据可复用**：teach-back 的复述已覆盖关键点且无事实性错误 → 即视为复述通过，**不再索要同义重复总结**。
- **取消「装不懂」**：追问只在**真有疑点或需检验迁移**时进行，不为拖延而假追问；追问后仍以「覆盖关键点且无硬错」判定。
- 复述未通过时**逐项告知缺哪个关键点、错在哪**，再换角度重讲后请复述，不判通过、也不让学员猜。

## 间隔调度与调度数据语义

### 间隔调度

`scripts/scheduler.py` 采用 **FSRS-6 增长律 + 本仓记账法**：稳定度 S / 难度 D 双参数与六个公式（遗忘曲线、下次间隔、S0、D0、难度更新、成功/遗忘后 S）逐条照抄 FSRS-6 参考实现，21 个默认参数、边界取 fsrs-rs（Anki 实际在用的那套）；**记账法仍是本仓的**——四档判分、`elapsed=0` 同会话特判、纯文本 progress.md、零第三方依赖、不做 optimizer 参数拟合。公式结构见 `scheduler.py` docstring，常数唯一来源 = 契约 `scheduler` 块；本册只写策略与调用时机。**对学员不解释调度算法**（红线 6），这里只是维护侧口径。

两个旋钮决定全部间隔尺度：`desired_retention`（默认 0.9，即「承诺复习后仍记得的概率」）与 `maximum_interval`（默认 365 天，**产品护栏，偏离 FSRS 官方默认**——FSRS 的 S 上限是 36500 天）。改 `desired_retention` 会让所有既有条目**下一次**间隔跳变（r=0.85 时 S=100 → 约 130 天；r=0.95 → 约 74 天），改前须知会这件事。

#### 调用速查

> **有效域与边界（脚本强制、非有限数一律 exit 2 结构化拒绝）**：S ∈ [0.0001, 36500]、**D ∈ [1,10] 连续（无粒度要求）**、**elapsed 有限且 ≥0 且四档都必填**（失败档的遗忘后 S 也依赖 R(t,S)）；`interval_days` 恒 ≥ 1 且 ≤ `maximum_interval`（365）；日期加法越界同样拒绝，不裸崩、不输出非有限数。

- **新条目首次调度**（S3 新产生的薄弱点 / 错题 / 保持复习）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <判分档> --new-card --last <今天> --today <今天>`
  —— grade 取该条判分档（判错=again）；保持复习初始条目用 `--grade good`（例外：学员要求加速的同日清除按 `--grade hard` 档入保持，见 `references/workflow.md`「S4 复习巩固（可从逐节学习或结课随时插入）」闸口）；新卡 S0 / D0 **只由评分档决定**，**数值唯一来源 = 契约 `scheduler.w`**（本册不复制——要核对就跑脚本看 `stability_new` / `difficulty_new`）；首间隔四档为 1 / 1 / 2 / 8 天（again / hard / good / easy）。返回 stability_new / difficulty_new / due。**`--init-shift` 已失效**（形参暂留兼容旧调用，传了也不改变结果）。
- **既有条目复习判分**（S4）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <grade> --stability <S> --difficulty <D> --last <last> --today <今天> [--current-due <原due>]`。
  **同会话重复答对**（`--last` 与 `--today` 同日）：必须同时传 `--current-due <原due>`；脚本返回 `same_session=true` 并原样返回该 due，S/D 不变——只刷新召回，不把一天内反复刷题记成长期保持（FSRS-6 的同日复习公式 w17–w19 本仓不实现）。非同日复习不传 `--current-due`。保持复习按同一命令更新；`partial` 用 `again`，`未判/作废` 不写 S/D。前提：`due` 由脚本生成、不要手改；手改 due 的条目先按当前 S 与手工 due 对齐后再复习。

#### 校准画像

校准画像是脚本对既有「信心 / cw」元数据的**实时只读统计**：**不新增任何 progress.md 字段，不落任何新文件**。进入 S4 时由模型运行：

`python "<技能根>/scripts/scheduler.py" calibration --root "<数据根>" [--slug "<slug>"]`

- **指标名称**：**当前问题记录中的高信心错误占比**（cw 条目数 ÷ 分母；脚本键 `overconfidence_rate`）——它只描述「当前未清除问题记录」中高信心错误的投影比例，**不得用来评价学员整体人格或整体校准水平**（分母只含问题记录、不含正确作答，天然不代表整体校准）。若需整体校准判断，**必须另有**包含正确与错误作答、采样时机明确的有效窗口——当前快照口径不提供该窗口。
- **畸形数据判读**：脚本先按 `evt` 归组、合并互补字段，再形成「合法观察」（可推算日期 + 无冲突），最后才统计。**分子 `cw` 只数「反馈前信心 ≥4 且判错」的合法观察**——`cw` 必须是同口径高信心错误观察的**子集**；任何**孤立 cw**（有 cw 无显式信心）、**低信心 cw**（信心 <4）或**同 evt 投影冲突**都会单独告警并令脚本**输出 `overconfidence_rate: null` + `rate_valid:false` + `invalid_reason`**（不展示不可靠读数）；先核对补齐数据，不得采信该画像做元认知教学。
- **窗口口径：快照口径，不做时间窗**。统计对象是「当前未清除的条目」，教学呈现措辞必须用「当前快照」，禁称「全程累计」。
- **投影去重与口径披露**：条目**带 `evt=` 作答事件 ID** 时按事件归组，同一作答的投影（错题/薄弱点）**只计一次**，互补字段合并；**无 `evt=` 的条目各成单条观察**计入统计，脚本逐条报 `W-NO-EVT` 提示补标（补同一 `evt` 后同次作答的投影才会去重）。
- **两层语义（防模型混用）**：`cw` 是**逐条重测信号**——单条「自信但错」的调度标记，回答「这条该不该先练」（作用在 due-queue 排序优先）；校准画像是**聚合教学素材**——把当前问题记录里的信心标记汇总成**问题投影比例**，**只回答「当前错题快照里的高信心占比」**，**不得**回答「这位学员整体是否系统性高估自己」。一句话：**cw 是画像的输入行，画像是 cw 的列总和**。脚本只算不判；「本快照读数如何解读与呈现」归模型，但**不得越界作整体人格判断**。

### 调度数据语义

字段格式、默认值与解析器口径以 `references/data.md` 为准；本册只保留评估侧语义：

- **错因是语义属性**：缺省值只是脚本输出侧的占位回显（`meta_default:true`），模型侧必须按当下归因判断写入真实值；不得盲目补「知识性」把技巧性失误误导到重学。

## 闸口比例、批改与申诉

### 闸口比例与节目标线

- **默认比例**取契约 `gates.min_ratio`；**非默认值**写入 `progress.md` 元信息 `节目标线：a/b`（可选，缺省即契约默认）。非法值 → `E-GATE-RATIO-INVALID` 拦停，不得静默回退。
- **闸口两层**：比例线可按 `节目标线` 收紧/放宽；**关键能力独立通过与复述通过是底线**（缺独立通过 → `E-KEY-ABILITY-UNMET`），**不随量表放宽**、伺服不可替代。
- 独立正确 + 提示②–④后正确合计进入比例计算；提示后正确不计入「关键能力独立通过」。
- 所有阈值数字只在本册写契约键；不重复打印数值。

### 视觉任务证据

- 视觉任务（识别/关系/图表/比较）只在确有原始图/表/截图/数据的 KP 上声明；图类任务须基于原始图（原始像素或矢量图），表类任务须基于原始数据表；数学、物理、化学、生物等有原始图表的学科优先，其他学科有原始图/表时同样适用；纯文本概念不硬加。
- 证据必须基于原始来源：在题面或题组文件记录页码/图号/数据位置；**不得用生成图、重绘图或讲义示意图替代原图**；图中编号、关系与数据按原图，不重排、不补造；原图缺失、模糊或读不到时：新任务不要声明该视觉任务；已声明的不得删除或改写字段或证据标签来绕过闸口，按 `未判` 处理或补齐来源后再判，不凭记忆补。
- 分型闸口组合见 `references/workflow.md`「S3 闸口（可检验）」；本册只定视觉证据标准。attempt 仍按 `KP=<id>｜视觉=<任务>` 且 `独立性=独立` 记录；提示后作答不算独立。目行未声明视觉任务 = 合法；已声明但无来源锚点的证据不追溯作废（证据只增不改），下一次使用时补齐；无法补齐时按 `未判` 处理，不当作独立正确证据。
- 字段格式见 `references/data.md`「课程体系文件」（可选分型字段）与 「题组与判分文件（exercises/）」作答与判分区块。

### 批改与申诉

- **判分反馈最小框体**：判分反馈给答案框时只要求——框内不写题面段；标记行留空、紧邻引用块；框外单独一行给分点量表（备考型；各点分值之和须等于合计）。完整讲义体例见 `references/handout-layout.md`「答案框体例（学科无关）」。
- **输入判读（含手写照片）**：判读学员输入（手写照片、OCR、复述转录）时**不按题干预期去读**。**照片先预处理再判读**——转向正立、放大、按答题块分段裁剪后逐行识别；判读结果按「清楚/不确定」分级，仅对确实模糊且可能影响判分的关键字符（不等号方向、界值、指数、正负号、分数线）请学员确认，其余直接判分。已清晰且不影响结论的输入**不重复确认**（避免审问式负担）；**禁止以「不读照片」规避判读责任**，也禁止「先判分、后附注请更正」；预处理后仍无法确证的关键行，才索要文字版。学员更正输入时，**回滚**受影响的已写判分记录并留痕（记录更正日期与更正依据后按新判分重写）。

#### 作废与申诉

学员指出判分有误（答案键错、来源歧义、输入读错）时，先核对题目 ID、保存的作答、参考答案与来源；确认原判不成立 → 在原行标 `作废（原因，日期）`，**保留原行不删除**；需要改判时新增一行（可复用原 `attempt_id`，已作废行不参与冲突判定），并只按新行更新 S/D。若只是补判，原 `未判` 行改为新结果或另起一行，二者择一但不得同时作为有效证据。作废与未判都不算负面证据；申诉本身也不算掌握。全程在学习日志留一句纠错留痕。
#### 批改纪律与解析格式

批改主观题、以及任何题型给出解析时，统一按下面两条：纪律管「怎么判」，格式管「怎么呈现」。

- **主观题批改纪律**（问答/论述/作文类题面）：**接受语义等价表达**——学员用自己的话说对了意思即给分，不因措辞与参考答案不同重复扣分；**每个得分点关联学员作答中的对应证据**（引其原句或指出缺失位置）；批改对象是作答不是人——只判对错与差距，不作能力评价。
- **答案与解析格式**：批改中凡给出解析的时机，解题/计算/操作/论述/翻译类一律以**答案框格式**呈现（框体例见 `references/handout-layout.md`「答案框体例（学科无关）」，精确 canonical 集合见 `references/handout-layout.md`「交付起笔与答案标识」）；学员原作答与答案逐点对照。答案之后的给分点量表按上条「判分反馈最小框体」；非备考任务给关键步骤、验证方式或成功标志，不编造官方分值。本条只约束解析呈现格式。

## 出题前术语对账（R46）

R35 管「出题域」（只对已讲授知识点出题），本节管「题面词汇」——R35 的盲区是：题域对了，题面与被问项里却混入了**尚未引入的术语**（如讲词性判断却让学员「标出定语」），对零基础学员即卡死。对账是**动作**不是原则：每次生成判分题后、交付前执行。

- **已引入集合** = ①课程体系.md 中状态「已讲」目行的 `引入` 列术语（字段见 `references/data.md`「课程体系文件」）；②已讲目名本身；③地基目/术语地图/S1 摸底证据中已给过定义的术语（用 `prereq_check.py --extra-terms` 追加）。
- **对账动作**：逐题扫题干、被问项与选项——每个 ≥2 字的术语必须 ∈ 已引入集合；不 ∈ → 二选一：**换问法**（改用已引入词汇重述）或**先补术语**（给一页术语地图/最小定义，把术语转入已引入集合，再出题）。禁止边出题边补定义、禁止用「语感」「读着顺」当替代判据。
- **术语族一次给地图**：族性术语（句子成分、时态语态、词性体系、记号体系等）首次触碰时，先给**一页地图**。地图必须齐三样——**成员清单**（族内全部名字，一次列全）、**彼此关系**（各支靠什么区分、何时用哪支）、**每支的判别标志**（凭哪个特征认它属于这一支）；缺一样即判未给地图（判据原文见 `SKILL.md`「十一条教学红线」第 9 条 ③）。地图级不作判分项；此后该族术语进已引入集合——不按「被问到哪个补哪个」逐词打补丁。
- **机器护栏**：`python -B "<技能根>/scripts/prereq_check.py" --list <课程体系.md> --scan <题组文件>`（对账集合与扫描范围见脚本 docstring；违规输出 `W-TERM-UNTAUGHT`，exit 1）。模型自查不豁免跑脚本；目行缺 `引入` 列时先补齐后再跑。
- **事故升级**：同类「未教术语进判分题」当轮撤题补救后一句简述（🟡 可安全恢复）；同课程第二次发生即教学事故，停轮按 `references/ops.md` SR-10 处置并修订讲义。

## 智能变式一次一维（R43）

- **变式只变一个维度**：数字 / 情境 / 条件 / 问向，四选一；其余表面保持同构。一次变两个维度 = 学员无法归因「哪个变化导致了结果变化」，属违规（结构判据补强「变式真变」条）。
- **预测轮**：关键目的例题讲完、出变式前，先请学员预测"这题答案会怎么变、为什么"再动手——预测本身就是检索练习，预测错了印象更深；预测不落盘、不计分母。
- **变化链收口**：连续 2–3 题构成一条「一次一维」的变化链，链末请学员一句话总结"这组题里什么在变、结论跟着怎么变"；说得出的才关目。
- 与难度伺服的关系：伺服加难（「难度伺服」）改的是题的难度档位，本条改的是题与题之间的结构关系，两者叠加不互斥。
