## 判分口径

**判分三维 + 调度档位**（闸口正确性与调度 grade **分离**，避免「慢=半分」把独立性/流畅度混进正确性）：

- **正确性（四态）**：`对 / 部分 / 错 / 未判`。`对` 计入闸口分子与分母；`部分` 计入分母、不计入分子（未达完整正确，按缺失点归因并进薄弱点；如需保留原题再进错题本并标 `结果=部分`，调度档用 Again）；`错` 计入分母；`未判` 不计入分母、不写 S/D、不进错题本——它表示答案键/输入/来源不足以判，不是「错」。**作废**行只保留审计，不计入闸口/S/D，不删除原判分行。
- **独立性**：独立完成 / 经提示②–④（非答案级）后完成 / 经梯⑤获答案后才理解（**给答案不算答对**，计 0）。
- **流畅度**：快速（无停顿、无试错）/ 常规 / 明显卡顿·试错；**时间/过程不可观测时记「未测」**，不猜、不折半。
- **调度档位（仅用于 scheduler 算 S'/D'，不折算闸口正确性）**：Easy=独立且快速答对；Good=独立答对（常规节奏）；Hard=经提示②–④后答对 / 明显卡顿试错后答对；Again=未答对 / 梯⑤给答案后才理解。
- **有效作答全为未判/作废** → `E-NO-GRADED-ATTEMPT`，不得标已掌握。

### 难度伺服

| 参数 | 取值 |
|---|---|
| 滚动窗口 | 最近 **~7 题**正确率（按**正确性**计：独立正确与提示后正确均计 1，Again/给答案计 0） |
| 计分 | 正确性驱动：正确=1，未答对=0；**Hard 不记半分** |
| \>90% | 加难（去提示 / 迁移题 / 双概念综合） |
| 70–90% | 保持 |
| <70% | 降难（缩 chunk / 给示例 / 降为选择题） |
| 落盘 | 伺服判定结论（档位 + 依据 + **样本数**）随判分记录落盘；报「正确 x/样本 n 题」，**n < 5 时标注「样本过小，档位仅供参考」** |

难度伺服 85% 目标为**启发式参数**（Wilson et al. 2019 仿真研究、Rosenshine 课堂 ~82% 呼应；边界见 `evidence.md`）。

**统计口径**：正式推进确认题随 `## 作答与判分` 的 attempt 进入正确性分母；轻量确认不计入分母；难度伺服以题组 attempt 为主，正式确认只作即时教学信号，不单独改变档位。

### 信心时序

信心**可选**，学员可在**反馈前随作答一并提交**「当时几分把握（1–5）」——这是可用于 cw / 校准的**原信心**；若在批改反馈**之后**才补报，一律标注**回顾性**（postdiction），**不得据此推断其原先信心、不计入 cw、不计入信心校准**。（cw = 反馈前信心 ≥4 且判错。）

## 闸口比例与小节目标线

- **默认比例**取契约 `gates.min_ratio`；**非默认值**写入 `progress.md` 元信息 `小节目标线：a/b`（可选，缺省即契约默认）。非法值 → `E-GATE-RATIO-INVALID` 拦停，不得静默回退。
- **闸口两层**：比例线可按 `小节目标线` 收紧/放宽；**关键能力独立通过与复述通过是底线，不随量表放宽**、伺服不可替代。
- 独立正确 + 提示②–④后正确合计进入比例计算；提示后正确不计入「关键能力独立通过」。
- 所有阈值数字只在本册写契约键；不重复打印数值。

## 复述证据

- **通过标准**：学员复述**覆盖 ≥ `restatement.keypoints` 个本节关键点**且**无事实性错误**。判分时逐项勾选检查清单（关键点 1 / 关键点 2 / 有无硬错），把勾选结果写进题组文件。
- **模板与字段**见 `data.md`「复述检查清单」；勾选语法与解析规则以脚本为准。
- **一份证据可复用**：teach-back 的复述已覆盖关键点且无事实性错误 → 即视为复述通过，**不再索要同义重复总结**。
- **深讲概念的深度验收**：节末除复述外，至少问一类「为什么/边界/对比」题（深讲概念建议三选二）；答不出 → 补对应层，不判学员。
- **取消「装不懂」**：追问只在**真有疑点或需检验迁移**时进行，不为拖延而假追问；追问后仍以「覆盖关键点且无硬错」判定。
- 复述未通过时**逐项告知缺哪个关键点、错在哪**，再换角度重讲后请复述，不判通过、也不让学员猜。

## 题量预算与自测≠题组

- **每节核心新题合计 ≤ 契约 `budget.core_total_max`**：讲义自测取 `budget.self_test`；题组合计 `budget.exercise_group_min`–`budget.exercise_group_max`（其中至少 1 道判定题）；单元检验 0–`budget.unit_check_max` 用剩余额度；深度验收与 S4 复习复用题组题，不额外加题。
- **关键块正式推进确认题另计**，不设每节道数上限；简单块轻量确认不计题量、不写判分行。
- **题组不与本节讲义自测同题**（L3 复习产物例外见 `handout.md` §2.4）；自测只作低风险自检，不作判分证据。
- **L3 复习产物例外**：检索版要点卡 3–5 题优先复用旧题/题组（至少 1 道换情境/新问法），不作新判分证据；`budget.l3_review_min/max` 以契约为准。
- **超预算时**先减单元检验，再并题组或移入 `exercises/` 次日再做，不靠加题补密度。

### 分块与交错切换

- **习得期**：新程序还在习得期（独立解题常失败）→ 同型分块练，先把单个程序练稳。
- **切换**：当独立解题开始成功 → 切为交错混练，混入已会程序/旧题型，迫使学员区分适用条件。
- 切换时序为推断级（证据见 `evidence.md`）；不改变题量预算、判定题要求与 S3/S4 的其他规则。

## 出题流水线（四步）

出题（S3 练习、S4 复习、独立「考考我」/组卷）按四步执行；题量、题型与难度仍受 S3/S4 预算与目标约束。S5 综合测验不改变既有蓝图与目标线规则：先按「能力—任务—评分点蓝图」定覆盖、题量与分值，再用本流水线生成与自检。

1. **探索**：先读本次小节目标与讲义范围；有清单时读本次相关 KP（S5 按蓝图读全部纳入 KP）；S4/已有任务的独立出题先跑 `due-queue`（无任务时跳过；S3 沿用进入小节前的结果，跨日续学可重跑）；再读 `exercises/` 最近题组与判分记录，标出「要考的能力 / 主要错因 / 已出过的题」，避免重复旧题（T11 明确选择「原题保持」时除外）。
2. **规划**：按本次题量预算列题（默认取契约题组范围；S5 综合测验按蓝图），逐题定 topic、题型（基础/应用/变式/判定）、难度、对应 KP 或能力；至少 1 道判定题；组内 topic 不重复（T11 明确选择「原题保持」时除外；同一薄弱点需多问、或 S5 蓝图要求同一 KP 多题时，用不同题型/情境/变式，不以换数字充数）；新学按基础→应用→变式递进，复习按 T11 选「原题保持 / 近迁移 / 远迁移」。
3. **生成**：逐题写题干、选项（选择题）、答案、解析、难度与 KP 映射；干扰项取本节常见误区；选项等长并打乱，题面与解析不引用字母；答案键批改前私有；用材料出题时记来源锚点（页码/图号/数据位置）。
4. **修复**：整套题一次性自检——答案键、选项字母中立、解析完整、难度标注、KP 映射、与旧题是否重复（T11 明确选择「原题保持」时除外）、是否与本节自测同题（仅 S3 新学题组适用，此项无例外）；发现问题修一次并重检，不无限重写；答案键不确定标 `未判`，不猜。

四步是同一轮的内部流程，不额外占用学员轮次；题组仍按既有「一组题一条消息交齐」交付。**未作答题组优先**：若 `exercises/` 已有本节未作答题组，直接取用并等用户作答，不重新出题。

### 短题与正式确认

- **短题豁免**：关键块正式推进确认题等短题不走四步流水线；但答案键须先核对、无提示泄漏。
- **答案键不确定**：标 `未判`，不得以未判推进；照片/手写输入按「批改与申诉」的输入判读规则处理。
- 正式确认仍按判分四态/独立性照记，计入正确性分母；不替代题组的关键能力独立通过与小节复述。

## 零提示与条件化判定题

出题时遵守「零提示」规则，防止题目本身泄漏答案或降低检索难度。以下规则在流水线第 3 步生成与第 4 步修复时逐条核对：

- **出题形态分界**：能从已有知识逻辑推导的内容，练成解题/应用题；无法推导、纯记忆的任意性内容（单词、常数、术语表）才做填空/背诵卡。判断标准一句话：**这条能否从别的东西推出来**——可推导内容做成死记卡是浪费检索练习，任意性内容硬出证明题是折磨学员。
- **不主动报答案**：题目与答案分离，先出题、等作答，批改阶段才给解析。
- **选项等长**：选择题选项在长度与结构上对称，避免最长的那个就是正确答案；干扰项 = 本节常见误区的具象化（与判定题「邻近情境干扰」同一取向），不用显然错的弱干扰。
- **防猜测选项**：选择题可含「我不确定」类选项，学员选它按未答（Again）处理——防 25% 猜对虚增闸口正确率，给低信心一个诚实出口。
- **选项打乱与字母中立**：展示前打乱选项顺序；题干和解析都不引用「A/B/C/D」，按内容说答案；正确标签在批改前保持私有。
- **答案键与解析纪律**：正确答案/解析批改前不下发；每题都能在批改反馈或判分后的参考答案区找到解析（不要求在题面预写）；难度在题面或题组文件头注明「难度：易/中/难」，不写进调度档（调度档记录表现，不记录题目难度）；正确项不得更长、更完整或带「推荐」标记；选项不按正确性排序。
- **格式不泄题**：不在题干里暗示答案（如「以下**错误**的**是**」的加粗位置、选项排序规律）。
- **变式真变**：递进题（基础 → 应用 → 变式）须换情境或逆问题，而非只改数字。
- **条件化出题（判定题）**：每个题组至少 1 道考「**何时用**」的判定题——给出场景问该用哪个知识点 / 给出信号问该触发什么方法 / 追问权衡（「方法 A 什么时候反而不如 B」）。只考「是什么」的题组默认不合格：掌握 = 会内容 + 会判定适用条件，二者缺一不可。判定题的干扰项须是「邻近情境下才对」的方法，制造真实的判定张力，不用显然错的弱干扰项。
- **复习变式优先、原题按目标保留（T11）**：S3 热身、S4 复习、综合测验重试的题目**以变式为默认**（换措辞 / 换情境 / 反向问 / 迁移情境），与「变式真变」同一取向；但**不一律禁止原题**——按目标组合「**原题保持** / **近迁移** / **远迁移**」，需检验长期保持时可原样重问（同日两次正确 ≠ 长期保持）。
- **难度对齐**：题组难度对齐用户目标（考试对齐真题，兴趣对齐应用），不超纲、不降维羞辱。

## 视觉任务证据

- 视觉任务（识别/关系/图表/比较）只在确有原始图/表/截图/数据的 KP 上声明；图类任务须基于原始图（原始像素或矢量图），表类任务须基于原始数据表；数学、物理、化学、生物等有原始图表的学科优先，其他学科有原始图/表时同样适用；纯文本概念不硬加。
- 证据必须基于原始来源：在题面或题组文件记录页码/图号/数据位置；**不得用生成图、重绘图或讲义示意图替代原图**；图中编号、关系与数据按原图，不重排、不补造；原图缺失、模糊或读不到时：新任务不要声明该视觉任务；已声明的不得删除或改写字段或证据标签来绕过闸口，按 `未判` 处理或补齐来源后再判，不凭记忆补。
- 讲义 SVG 只用于讲解，不能充当视觉任务的原始来源。attempt 仍按 `KP=<id>｜视觉=<任务>` 且 `独立性=独立` 记录；提示后作答不算独立。旧任务未声明视觉任务 = 合法；已声明但无来源锚点的旧证据不追溯作废，下一次使用时补齐；无法补齐时按 `未判` 处理，不当作独立正确证据。
- 字段格式见 `data.md`「知识清单文件」「作答与判分」。

## 批改与申诉

- **输入判读不预设预期**：判读学员输入（手写照片、OCR、复述转录）时**不按题干预期去读**；仅当指数、下标、正负号、分数线等关键字符**存在不确定性且可能影响判分**时，才将读到的题干与关键行向学员复述确认，确认无误再判分；已清晰且不影响结论的输入**不重复确认**（避免审问式负担）。学员更正输入时，**回滚**受影响的已写判分记录并留痕（记录更正日期与更正依据后按新判分重写）。
- **作废与申诉**：学员指出判分有误（答案键错、来源歧义、输入读错）时，先核对题目 ID、保存的作答、参考答案与来源；确认原判不成立 → 在原行标 `作废（原因，日期）`，**保留原行不删除**；需要改判时新增一行（可复用原 `attempt_id`，已作废行不参与冲突判定），并只按新行更新 S/D。若只是补判，原 `未判` 行改为新结果或另起一行，二者择一但不得同时作为有效证据。作废与未判都不算负面证据；申诉本身也不算掌握。全程在学习日志留一句纠错留痕。
- **主观题批改纪律**（问答/论述/作文类题面）：**接受语义等价表达**——学员用自己的话说对了意思即给分，不因措辞与参考答案不同重复扣分；**每个得分点关联学员作答中的对应证据**（引其原句或指出缺失位置）；无官方评分细则时**明示「本次按训练量表判分，非官方标准」**；未知官方扣分规则不得编造。批改对象是作答不是人——只判对错与差距，不作能力评价。
- **答案与解析格式**：批改中凡给出解析的时机，解题/计算/操作/论述/翻译类一律以**答案框格式**呈现（从交付起笔到结论/产物的完整可复现答案，不排斥等价解法；交付标识按学科族取 `解：`/`解答：`/`证明：`/`答：`/`参考答案：`/`答案：`/`参考概括：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`代码：`/`输出：`/`方案：`/`设计说明：`/`Answer:`/`Solution:`/`Proof:`/`Model answer:`/`Sample answer:`/`Translation:`/`Output:`/`Code:`/`Script:`/`Steps:`/`Key:` 等，**框内不写题面段**）；学员原作答与答案逐点对照。答案之后**框外单独一行**附**给分点量表**（备考/阅卷型任务适用，格式见 `handout.md`「给分点量表」，各点分值之和须等于合计）；非备考任务给关键步骤、验证方式或成功标志，不编造官方分值。无官方细则时明示「训练量表，非官方细则」，未知官方分值不得编造。**框体体例**（交付起笔、段首分点、代码块、句中编号与批注、标记行留空）**的唯一事实源见 `handout.md`「讲义概念单元 schema · 答案框体例」及五要素之③**；本条只约束解析呈现格式。

## 间隔调度

`scripts/scheduler.py` 采用**自研简化双参数算法**（稳定度 / 难度双参数，按判分档位递增间隔），以零第三方依赖、简单稳健为先；**非 FSRS 算法，亦非 SM-2 标准实现**，不做参数个性化拟合。公式结构见 `scheduler.py` docstring，常数唯一来源 = 契约 `scheduler` 块；本册只写策略与调用时机。

### 调用速查

> **有效域与边界（脚本强制、非有限数一律 exit 2 结构化拒绝）**：S ∈ (0,365]、D ∈ [1,5] 且 0.5 粒度、**elapsed 有限且 ≥0**；日期加法越界同样拒绝，不裸崩、不输出非有限数。

- **新条目首次调度**（S3 新产生的薄弱点 / 错题 / 保持复习）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <判分档> --new-card --last <今天> --today <今天> [--init-shift {-1|0|1}]`
  —— grade 取该条判分档（判错=again）；保持复习初始条目固定用 `--grade good`；`--init-shift` 影响初始 D：顺向检索 -1（默认 0），反向问 / 迁移 +1；返回 stability_new / difficulty_new / due。
- **既有条目复习判分**（S4）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <grade> --stability <S> --difficulty <D> --last <last> --today <今天> [--current-due <原due>]`。
  **同会话重复答对**（`--last` 与 `--today` 同日）：必须同时传 `--current-due <原due>`；脚本返回 `same_session=true` 并原样返回该 due，S/D 不变——只刷新召回，不把一天内反复刷题记成长期保持。非同日复习不传 `--current-due`。保持复习按同一命令更新；`partial` 用 `again`，`未判/作废` 不写 S/D。前提：`due` 由脚本生成、不要手改；手改 due 的条目先按当前 S 与手工 due 对齐后再复习。

### due-queue 与复习预算

- `due-queue` 同时读取「薄弱点」「错题本」「保持复习」三区，输出 `kind` 与 `reason`，schema 以契约为准；刚入库/当日的条目不重复入队。
- 进入新小节前按本次可用时间设预算（复习不超过约 1/3 课时，其余留给新内容）；队列非空 → 优先清「关键先修 + 高影响错误（cw / 顽固）+ 到期的保持复习」，其余显式顺延（保留原到期日并在进度对账中可见）；队列长（>5 条）→ 明示队列长度与顺延方案，默认按预算顺延并继续新内容、不空等批准。
- 排序契约：cw → 最逾期 → due 早 → 稳定序；`顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- 缺日期/坏条目的口径见 `data.md`：缺日期不入队、`W-UNPARSED-ITEM`；不得以当日或猜值补造。

### 校准画像

校准画像是脚本对既有「信心 / cw」元数据的**实时只读统计**：**不新增任何 progress.md 字段，不落任何新文件**。进入 S4 时由模型运行：

`python "<技能根>/scripts/scheduler.py" calibration --root "<数据根>" [--slug "<slug>"]`

- **指标名称**：**当前问题记录中的高信心错误占比**（cw 条目数 ÷ 分母；脚本键 `overconfidence_rate`）——它只描述「当前未清除问题记录」中高信心错误的投影比例，**不得用来评价学员整体人格或整体校准水平**（分母只含问题记录、不含正确作答，天然不代表整体校准）。若需整体校准判断，**必须另有**包含正确与错误作答、采样时机明确的有效窗口——当前快照口径不提供该窗口。
- **畸形数据判读**：脚本先按 `evt` 归组、合并互补字段，再形成「合法观察」（可推算日期 + 无冲突），最后才统计。**分子 `cw` 只数「反馈前信心 ≥4 且判错」的合法观察**——`cw` 必须是同口径高信心错误观察的**子集**；任何**孤立 cw**（有 cw 无显式信心）、**低信心 cw**（信心 <4）或**同 evt 投影冲突**都会单独告警并令脚本**输出 `overconfidence_rate: null` + `rate_valid:false` + `invalid_reason`**（不展示不可靠读数）；先核对补齐数据，不得采信该画像做元认知教学。
- **窗口口径：快照口径，不做时间窗**。统计对象是「当前未清除的条目」，教学呈现措辞必须用「当前快照」，禁称「全程累计」。
- **投影去重与口径披露**：条目**带 `evt=` 作答事件 ID** 时按事件归组，同一作答的投影（错题/薄弱点）**只计一次**，互补字段合并；**无 ID 的旧条目**沿用「两条投影各计一次」的**声明式双计**。全部带 ID → `dedup_mode:"by_evt"`；全部无 ID → `"legacy_double_count"`；**新旧混排 → `"mixed"`**，并在呈现时显式披露 `evt_tagged_count` / `legacy_count`（不得统一标 `by_evt` 掩盖旧条目计数）。
- **兼容口径**：旧任务读数不静默变样，仅新写数据启用按事件去重；旧条目保持 `legacy_double_count` / `mixed` 披露，不统一改标 `by_evt`。
- **两层语义（防模型混用）**：`cw` 是**逐条重测信号**——单条「自信但错」的调度标记，回答「这条该不该先练」（作用在 due-queue 排序优先）；校准画像是**聚合教学素材**——把当前问题记录里的信心标记汇总成**问题投影比例**，**只回答「当前错题快照里的高信心占比」**，**不得**回答「这位学员整体是否系统性高估自己」。一句话：**cw 是画像的输入行，画像是 cw 的列总和**。脚本只算不判；「本快照读数如何解读与呈现」归模型，但**不得越界作整体人格判断**。

## 数据兼容语义

字段格式、默认值与解析器口径以 `data.md` 为准；本册只保留评估侧语义：

- **旧条目缺字段**：不做批量迁移、不新建文件；首次在 S4/S3 热身/due-queue 遇到时按默认值计算 due，并在下一次正常写入时顺带补写；缺日期不入队、输出 `W-UNPARSED-ITEM`，不得以当日或猜值补造。
- **错因是语义属性**：缺省值只是脚本输出侧的占位回显（`meta_default:true`），模型侧必须按当下归因判断写入真实值；不得盲目补「知识性」把技巧性失误误导到重学。
- **三种数据形态**：完整 / 缺错因级 / 旧格式的行为按 `data.md` 的表执行；旧格式不计入 calibration 分母，脚本标注 `migrated`/`meta_default`，不静默改样。
