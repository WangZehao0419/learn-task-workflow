# 阶段与闸口细则（S0–S5）

进入任一阶段时只加载对应小节；闸口条款是硬约束，未达标不得进入下一阶段。

## 机制关系表（跨机制组合规则速查）

正文中不再重复这些关系；执行中遇到组合场景先查本表。

| 机制 A | 机制 B | 关系与组合规则 |
|---|---|---|
| 教学八动作 | 难度伺服三档 | **正交**：八动作是教学动作维度，伺服三档是难度维度。可组合（如「降档 + 换角度重讲」），每次判分后选定动作并随判分记录落盘（动作 + 一句依据） |
| 单轮一小步 | 节末五件套 | **等待轮**：五件套②③各占一轮等待用户输入；第 5 件与第 3、4 件同轮输出、不新增等待轮（紧凑节奏下按 S3「轮次预算与合并弹性」合并，等待轮相应减少） |
| cw 条目 | 校准画像 | **两层语义**：cw 是逐条重测信号（该条先练，进 due-queue 排序优先）；校准画像 = **当前问题记录中的高信心错误占比**（聚合元认知素材）。cw 是画像的输入行，画像是 cw 的列总和；**画像只描述问题记录投影，不评价整体人格/整体校准水平** |
| KP 清单状态 | 「暂缓与范围外」 | **双写账本**：清单记状态（分母账本），progress.md 暂缓区块记处置明细（处置账本）；交叉核对走 W-KP-HOLD-CROSS |
| 错因 / 级 | S / D 调度字段 | **互不替代**：错因与级是内容属性（错什么，定补救动作与整理深度），S/D 是调度属性（何时再练）；级不参与 due-queue 排序 |
| 检索变式口径 | S3 热身 / S4 复习 / 测验重试 | **变式优先、原题按目标保留**：默认换措辞 / 换情境 / 反向问 / 迁移情境；需检验保持时可保留原题——按目标组合「原题保持 / 近迁移 / 远迁移」，**不一律禁原题**（T11） |
| 节末第 5 件对账 | 覆盖率审计 | **分工**：逐节对账走五件套第 5 件（限 2–3 行）；全量核对走覆盖率审计（不每节都做） |
| 提示阶梯第 5 梯 | 「不代劳」条款 | **不冲突**：梯底给「答案+缘由」是 4 次引导失败后的教学干预，不是响应用户代写请求 |
| 范围护栏（默认 ~12 节，可按目标调整） | 暂缓与范围外 | **裁剪留痕**：护栏触发时被推迟小节全部进暂缓清单并标「滚雪球候选」，裁剪必须留痕、可见、经用户过目 |
| 苏格拉底边界 | 提示阶梯 / 直接讲解 | **分工**：缺事实 → 直接给再回推导；**明确要求讲解/示范 → 直接讲**（完整 worked example + 完整解析）；只有要求替交受评作业才走「先引导、坚持才给答案」；精力耗尽 → 接一把。唯一事实源见 `teaching-loop.md` 第 4 节 |
| 反馈分流（按对错） | 提示阶梯 / 零提示 | **分工**：分流管「判分与错位反馈的时机」与「何时即时确认」（答错即时判分指错位；单题/低信心/首次新方法答对亦即时确认），阶梯管「答案级内容的释放节奏」（渐进 5 梯）；答错即时判分 ≠ 即时给答案。**唯一事实源见 `teaching-loop.md` 第 5 节**，本表与阶段表只引用不另立相反规则 |

## 通用闸口协议

每个阶段遵循同一节奏：1. **动作** → 2. **产出落盘**（写进 progress.md 与对应目录）→ 3. **闸口自检**（对照退出标准，逐条给证据）→ 4. **达标则推进、未达标则停留**。

- **证据先于结论**：任何「已掌握」「已认可」「通过」都必须伴随落盘证据（题号/对错/复述检查项/用户原话），禁止仅凭自述。
- **等待即停止**：凡需用户作答、复述或确认处，**必须停止本轮输出、等待用户输入**，不得代答或代判。
- **跨阶段前核查可见性**：推进前核查「未讲清单是否已向用户可见」（未讲小节逐条 + 暂缓项计数），不得以「转入下一阶段」静默掩盖未讲完的事实（衔接 🟡 SR-7）。
- **推进前跑校验**：跨阶段前运行 `python "<技能根>/scripts/progress_check.py" "<数据根>/<slug>"`，确认字段合法且证据齐全；**本次若涉及新增掌握 / 结课 / 跨阶段，须加 `--release`**（空/模板证据 `E-EMPTY-EVIDENCE`、未完成路线 `E-ROUTE-UNDONE` 会被拦停），再更新阶段。（`<技能根>` = 技能包目录，`<数据根>` = `<工作区根>/.learning/`；脚本路径以技能根为基准、任务目录显式传入，不依赖 cwd。）

## S0 接料建档

- **目标**：学什么、为什么学、基础如何、时间多少，四项齐备；并定档**类型**与**学科族**。
- **输入**：用户学习需求 + 附带材料（文件/链接/大纲，可选）。
- **动作**：
  1. **材料读取**：附带材料时先读取抓取、提炼目录与核心脉络。**材料阈值**：材料达到阈值（正文 ≥ 40 页，或目录项 ≥ 60 条；页数按 PDF 页数或正文字符数 ÷ 约 500 字/页 估算）→ **先与用户确认本次范围**，只取一部分纳入路线，其余标注「后续小节可续入」；低于阈值的材料直接全量纳入，无需确认。
  1b. **备料（仅无材料/材料不足）**：知识型/技能型且无材料或材料不足时，收集 3–5 个互不转载来源（官方教材/课程/标准文档优先），按「相关性/来源质量/时效/深度/阅读成本」五维筛，落 `materials/00-备课来源.md`（名称/链接/年份/一句话评价/可信度/分歧点）；无联网或查证失败 → 不建文件，S2 标「无外部基准」。材料型已有目录不触发。
  2. **三问（收集四项信息：学什么、为什么、基础、目标与时间）**：用交互式提问（宿主提供专用提问工具则优先，否则以文本提问逐项确认）问 ① 学什么 + 为什么（应试/求职/兴趣）；② 基础（零基础/入门/进阶）；③ 目标与时间（期限/每周时长/单次时长）。**可选补充（不阻塞 S0 闸口，S2 可再补）**：学到什么程度算完成（写入 `目标程度`）、希望先测后教还是先教后测（写入 `教学策略`，缺省先测后教）。
  3. **澄清纪律**：每一项缺失信息**最多追问 2 轮**；两轮仍缺 → 按现有信息出草案/假定缺省值并向用户**声明假设**（如「按每周 3 次、每次 30 分钟排，如不符告诉我」），不得无限问卷化。只追问**会改变答案的缺失信息**，已说明的不重复问。
  4. **定档**（必须显式生成并展示给用户）：
     - **类型** ∈ {知识型, 技能型, 备考型, 材料型}。判据：有考试日 → 备考型；以实操/动手为主 → 技能型；以现成材料为载体 → 材料型；其余以理解概念为主 → 知识型。生成后**向用户展示并请其确认/更正**。
     - **学科族** ∈ {数学类, 编程类, 语言类, 理论概念类, 记忆密集类}。由主题推断后**向用户确认并落盘**；S1 摸底后若发现不符，**允许修正并记录修正理由**。
  5. **先读历史**：同数据根已有同主题或相关任务时，先读其「错题归档」与学习者画像（`profile.md`：教学方法裁决、类比领域）——复用有效裁决与类比领域，不重蹈已判低效的教法。**按作用域复用（F13）**：跨主题沿用的只有「学员明说的通用偏好」与**学科族级**的有效裁决；**任务级 / 单次的教法裁决不跨主题预判**（不得因某任务一次低效就对同类主题一律换法，须在新任务重新评估）。
- **闸口**：四项信息齐备；类型与学科族均为合法枚举且已展示确认。`目标程度`/`教学策略` 为可选补充，不阻塞本闸口。
- **产出**：在「数据根」下创建 `<slug>/progress.md`，写入元信息区（含类型、学科族、数据根、目标；如已获得则一并写 `目标程度`/`教学策略`）。**「起点」由 S1 产出，S0 与 S1（诊断摸底进行中）均不要求**（`progress_check.py` 对「起点」的必填约束**自进入 S2 起生效**）。阶段 → 诊断摸底。
- **失败怎么办**：材料读取/解析失败 → 停止当前运行，请用户修复文件、重新提供，或粘贴目录/口述要点后重新解析；不得先用通用脉络开课。范围确认完成后从 S0 原步骤继续。

## S1 诊断摸底

- **目标**：判定起点，摸出薄弱点。
- **动作**：出 3–5 道由浅入深的摸底题（用户自报进阶且确认熟练时，可减为 2 道确认题——仍须判分证据支撑起点判定）；**技能型**任务改用一个小实操。无实跑环境时停止当前运行，恢复授权执行环境后补做实操；口述步骤不能冒充实操证据。只记录不批评。**摸底判分证据落盘 `exercises/00-摸底-<日期>.md`**（沿用 `NN-` 命名契约的 00 专号，含作答与判分结构）。**摸底同轮顺带问一句「类比领域」**：「你有没有特别熟悉的一个领域（做饭 / 游戏 / 音乐 / 某项运动 / 本职工作……）？之后讲新概念我优先拿它打比方。」答案写入学习者画像（见 `data-and-recovery.md`「学习者画像」小节；无画像文件时本次顺带建立，用户不便回答则跳过，不阻塞闸口）。
- **闸口**：起点判定为三档之一（零基础/入门/进阶）；薄弱点清单**允许为空**——全对（=进阶）时记为「薄弱点：无」并正常推进。
- **产出**：起点字段、薄弱点清单（可记「无」）；阶段 → 计划确认中。

## S2 计划确认中

- **目标**：制定用户认可的小节计划与排期。
- **输入**：S0 定档结果、S1 起点与薄弱点、材料目录（材料型）、考试日（备考型）。

按以下六步顺序执行，不得跳步（六步为模型侧流程，用户仅在澄清问答与最终计划确认两处交互，其余步骤不占用用户轮次）：

**步骤 1：范围护栏**
先定课程规模：单课程初期小节数建议 ≤ 12，超出时先聚焦「最小可学骨架」再滚雪球，避免课程无限膨胀。材料型沿用材料目录；备考型从考试日倒排并留一周总复习；记忆密集类在排期里预留间隔重复节点。

**步骤 2：模块全景先行，再拆节**
凡含「衔接 / 预备 / 工具 / 专题」类辅助模块，或任一模块含多个可独立命名的子块时，**先列全该模块子项清单，再切分为节**；其余课程直接拆节。**拆节按教材结构/模块子项，由浅入深**；节内块数不设上限，不按块数/时长拆节。只有教材结构本身没有可对应的节、或用户明确要求拆分时才新增节；审计/增补知识点只加块，不重排节号。清单对照权威结构构建——用户材料目录 / 权威教辅章节（可用联网查证能力核实，按来源分级标注；无材料任务优先引用 `materials/00-备课来源.md` 的来源台账，台账缺失按自拟总纲并标「无外部基准」）/ 用户口述期望；三者皆无时**显式标注「完备性自拟、无外部基准」**。对照源不含的辅助模块，其子项清单不受对照源约束、完备性以上述权威结构为准，并在对照结论三行式中**单列一行注明**。拆节结果按**「模块 → 节」映射**随计划展示，模块内被拆散或排在后面讲的子项逐条可见。**模块目标（能力句）**：每个模块写一句 `M<k> ｜ 模块名 ｜ 学完能独立……`，写能力不写话题清单；写入 progress.md `## 模块目标`。模块内容修改不得违背这句，超出就重新设计模块。**按目标程度定规模**：若 `progress.md` 记录了 `目标程度`，模块数量、深度与停点按它对齐；学员说“到这个程度就够了”就收束，不把整个学科教完。**材料全覆盖**：每份材料至少归入一个模块，写入 `## 材料覆盖`（`材料 → M1 / M2`）；不得因材料看起来次要就静默遗漏。

**步骤 3：覆盖对照（确定对照源并逐项核对，按类型分叉）**
- **材料型** = 材料目录（S0 已提炼）：目录每一项必须落到三态之一——映射到某小节 / 进暂缓清单 / 经用户确认排除；无目录时停止计划确认，请用户提供可读目录或明确改变任务范围，不得用通用脉络替代材料依据。
- **备考型** = 考纲/考点结构：有考纲材料用考纲；无则用联网查证能力核实官方考纲。指定官方来源不可得时停止当前运行（补齐官方材料或取得用户明确的新来源要求后继续），不用真题结构/通用骨架冒充官方考纲。**来源分级**：🟢 官方原文（附名称、年份、链接与核验日期四要素）＞ 🟡 权威媒体或主流教辅转述（附年份，能回溯原文时优先原文）＞ 🟠 行业整理/经验帖（标注「非官方口径」）；任务未要求官方来源时可使用已核实的稳定知识，但不得声称按官方考纲核对。
- **知识型 / 技能型** = 自拟体系总纲：可借联网查证能力核实主干，展示给用户后落盘作为对照基准。**对照源优先级（统一口径，防二义）**：有材料 → **材料目录为对照源**（自拟总纲仅作补充）；无材料 → 自拟总纲；材料型固定材料目录；备考型固定考纲/考点结构。对照源一经确定即落盘，审计分母随之定死。

对照结论按**三行式**（基础三行；辅助模块说明等补充信息可另起附加行）写入展示计划：第 1 行「对照源 X，共 N 项 → 纳入 M 项（=小节计划）」；第 2 行「暂缓 K 项：逐条列出」；第 3 行「排除 J 项：逐条给理由」。暂缓项全部写入 progress.md 区块「**暂缓与范围外**」，每条带触发条件（用户要求时 / 阶段末审计 / 考期前 / 无）。**滞后原因说明**：推迟到后续小节（下一节除外）才讲的子项，计划展示中标注一句推迟原因（如「二次方程与不等式 → 第 2 节：函数前段用不到，解定义域与不等式题时要用」），何时讲由「模块 → 节」映射天然可见；范围外内容仍走「暂缓与范围外」区块。有备料台账时，对照结论后追加一行 `备料来源 N 个（🟢x/🟡y/🟠z）`；无台账不写。**对照源本身落盘**（材料区记路径，或「自拟总纲」全文），供审计复核。**材料覆盖对账**：对照结论落盘后，检查 `## 材料` 的每份材料是否都在 `## 材料覆盖` 中出现并归入至少一个模块；缺失项补写或说明，不静默遗漏。

**步骤 4：KP 清单生成（三行式对照结论之后、展示计划之前；分级强制）**
机制下称 KP 清单，文件名固定为 知识清单.md，禁止 KP清单.md 等变体。
- **强制分级**：备考型/材料型**强制**生成（本子步是覆盖对照闸口的组成部分）；知识型/技能型**选做**——未做时在对照结论中显式声明「未建 KP 清单，分母为对照源条目级」。
- **落盘位置**：任务根层 `<数据根>/<slug>/知识清单.md`（不放 materials/）。
- **行式六字段**：`KP-<两位节序>-<两位KP序> ｜ 知识点 ｜ 所属小节 ｜ 前置（KP 编号或空） ｜ 来源（对照源条目） ｜ 状态（未讲/已讲/暂缓/排除）`（编号两位补零，脚本宽容匹配单位数）。**可选分型字段（v6.1）**：追加 `｜ 类型：记忆/概念/程序/设计` 与/或 `｜ 视觉任务：识别/关系/图表/比较`。新任务建议为每个 KP 标类型：记忆/程序走题目独立正确，概念/设计走定性复述；视觉任务另需独立正确 attempt，且只在确有原始图/表的 KP 上声明（来源纪律见 `data-and-recovery.md`「视觉任务来源纪律」）。旧任务缺字段 = 统一闸口，零迁移。
- **文件头**：版本号（KP 集合增/删/拆时 +1，状态翻转不改）、对照源指针、排序规则行、**覆盖范围行**（「全量」或「已细化至第 N 节，其余待细化」，缺省视同全量）、最近更新、覆盖摘要行（总/未讲/已讲/暂缓/排除计数）。格式模板见 `data-and-recovery.md`「知识清单文件」小节。
- **原子判据**：每 KP = 当前节目标内的最细知识点，1 道题可独立检验；需 2 道题 → 拆 KP；不设时间上限。不达标条目拆分或合并后再入清单。
- **分批纪律**：未拆节的滚雪球候选拒绝入清单（仍留「暂缓与范围外」标「滚雪球候选」）；清单分批产出必须在「覆盖范围」行显式标注，未标注即 SR-7 命中。
- **摸底标注（保守口径）**：S1 摸底命中且有判分证据的 KP，状态列写 `未讲（已会：<摸底证据>，<日期>）`，随对照结论一并展示——信息性标注，**留在审计分母内**；任何把 KP 标「排除」出分母的动作必须经用户显式确认；不做运行时反向同步。
- **落盘时机与计划变更联动**：清单与排序结果随计划确认后同轮落盘；用户修改计划（增删节/改对照源）时按新对照源重建清单（版本 +1、重跑排序），不得静默沿用旧清单。
- **展示粒度**：清单全文落盘；随计划展示的为排序规则行、摸底标注与覆盖范围行摘要，不强制逐行展示全文（用户要求时给全文）。

**步骤 5：排序（清单生成后、写回清单行序；可解释是硬要求）**
无 KP 清单的任务（知识型/技能型选做未做）**本步显式跳过**，讲授序沿用拆节顺序——六步流水线的「不得跳步」不含此显式跳过。有清单时，排序规则按类型分叉，随计划展示、写入清单头「排序规则」行：
- **备考型** = 考纲板块 × 真题分值/频次的价值密度优先、被依赖度次之（「价值密度」「被依赖度」须绑定证据出处：真题分值/频次与依赖边计数，禁止凭语感编造分值）。**分值/频次允许粒度**：题型级 / 板块级 / 章节级皆可，按可得材料择最高粒度即可；**来源等级下限 🟡**（权威媒体或主流教辅转述，附年份），🟠 行业整理仅作参考并标「非官方口径」；**官方仅给题型级分值**（常见于统考）时，即以题型结构权重代替板块价值密度，并在对照结论中声明该口径。
- **材料型** = 目录序为主 + 显式依赖修正（修正须说明理由）；修正后**可选**跑 `kp_sort.py` **只检环**（读其 error/cycle 字段，不改行序），检出环即停止并报告。
- **知识型/技能型** = 依赖拓扑排序——模型声明依赖边 → 展示给用户 → `python "<技能根>/scripts/kp_sort.py" "<清单文件路径>"` 计算合法序 + 检环，检出环即停止并报告，不得静默假装排序。（补充：`kp_sort.py` 仅实现**拓扑序**——备考型的价值密度排序与材料型的目录序排序**无脚本支撑**，由模型按上述口径手工排，并在清单头「排序规则」行写明依据供复核）
- **查证失败判定**：无真题材料时，只有「已尝试查证并落盘尝试记录，且对照源内无真题分值材料」才判查证失败。此时停止计划确认并请用户补齐材料或明确取消分值排序要求；不得编造分值，也不以低等级来源替代。无边知识型按编号字典序稳定排序，不属于运行降级。
- 排序结果写回清单行序（清单头「排序规则」行与行序同轮更新）。示例仅为格式演示，KP 取舍与依赖声明规则领域无关。

**步骤 6：展示计划与确认**
展示计划（含对照结论）请用户确认。展示时一并问一句「你更希望我怎么教：A 多提问引导 / B 先讲后练 / C 混合（默认，可跳过）」；每节附「学完能：<一句话 ≤20 字>」与「本节 X 个知识点 + 预计课时」（知识点清单一行一个最细知识点；不按场/段列，不设时长阈值），每个模块附 `模块目标` 能力句。**教学策略与姿态正交**：策略（先测后教 / 先教后测）决定新 KP 是先探针还是先讲，缺省先测后教；姿态 A/B/C 决定引导/直讲/混合；策略写入 `progress.md` 元信息区，姿态写入学习日志。若 S0 未记录策略，可在本轮一并问；不回答则按先测后教。**节奏建议**：排期时建议**每周 ≥3 次、固定时段**；用户要求更低频时，**明示取舍**（「降频 → 两次间隔拉长 → 遗忘风险上升 → 达到同一目标总时长可能更长」），由用户显式确认后照办，不强推、不替用户决定。**节奏偏好**：**默认紧凑节奏**（默认启用 S3 可合并项，见「轮次预算与合并弹性」；用户要求完整节奏时改为完整五步走），展示计划时一并告知可切换；偏好随「节奏」字段落盘（如「每周 3 次；紧凑」，缺省即紧凑）。**周里程碑**：备考型/多节任务排期时按周给出「第 n 周（起止日期）：完成第 N–M 节」（复习/模考/强化周无新节时写「复习第 N–M 节」或「模考+强化」），写入 progress.md 可选「周里程碑」区（见 `data-and-recovery.md`）；节级课时按首节实测校准（不预设单块分钟数；含块级检验，不含练习/复习/答疑），与每周可用时长显式核算。排期确认时向用户说明连续性承诺：全程同一技能人格、同一任务目录、同一节奏连续推进。节奏沿用既有「节奏」字段落盘，不新增字段。

- **闸口**：**用户明确认可计划 + 对照结论**（认可对象 = 排期路线与覆盖对照三行式）。**明确肯定**（「确认/可以/就这样/好的」）与**常规授权**均算认可——已展示完整常规计划后，用户说「随便，你来定」「都行」「你看着办」即**授权按默认方案执行、视为认可，不再追问**（F06：消除本欲消除的等待轮）；**仅当**计划含**非默认取舍**（调整节奏 / 裁剪范围 / 改变目标线）或用户明确要求先看细节时才复述要点再确认。技能**必须停止并等待用户输入**；用户未回复不得推进。用户要改则改完再确认。
- **产出**：学习路线、排期、对照结论与对照源（含「暂缓与范围外」区块）写入 progress.md；**认可即同轮直接开讲第一节**（不再多问一轮「现在开始第一节，还是先到这里」；仅当用户明说「只要计划」时才本轮收尾，在「学习日志」写一句「待开课」，阶段保持「计划确认中」、**不写入阶段字段**）；阶段 → 逐节学习（当前小节 = 1）。
- **失败怎么办**：用户迟迟不回应 → 可用一句话复述计划要点并再次请其确认，不自行推进。

## S3 逐节学习（循环体）

- **目标**：节节过关，逐节推进。
- **节级规则**：五个小步按序推进，每个小步跨一轮；凡需用户作答或复述处即停，等输入再走下一步。**节内按块推进，块 = 当前节目标内的最细知识点（1 道题能独立检验）**；节内块数不设上限，教材节不按块数拆；**单轮只讲 1 个块**，逐块检验后推进，见「逐块推进（最细知识点）」；单次讲授轮的骨架与文本密度见 `lecture-styles.md`「对话讲授契约」与「讲解文本密度原则」，**必要推导讲完整**、无硬字数上限）。**周对账**：本周**首次**开课时先跑 3 行对账——本周计划节（读「周里程碑」区）/ 实际已完成节 / 偏差与原因；偏差 >3 天 → 给出排期微调建议（复用「调整学习计划」机制，向用户复述后执行）；无里程碑任务跳过本步。**进入新小节讲授前先跑 due-queue**：`python "<技能根>/scripts/scheduler.py" due-queue --root "<数据根>" --slug "<slug>" --today <今天，YYYY-MM-DD>`——**按本次可用时间为复习设预算**（复习不超过约 1/3 课时，其余留给新内容）；队列非空 → **优先清「关键先修 + 高影响错误（cw / 顽固）+ 到期的保持复习」**，其余**显式顺延**（顺延项保留原到期日并在进度对账中可见）；队列长（>5 条）→ **明示队列长度与顺延方案**（含默认顺延项与原到期日），**默认按预算顺延并继续新内容、不空等批准**；用户可随时改（衔接 🟡 SR-6）。**长队列不得吞掉整节课。**
- **轮次预算与合并弹性**：一节完整走完常需 10+ 轮对话，注意学员的节奏与疲劳——**可合并**：收作业与热身并为一轮、检验问题并入讲授尾轮、信心自评随作答一并请学员提交（不单独设轮）、学员出现疲劳信号（回复变短 / 明显敷衍 / 主动喊停）时提议五件套②跳过或降为口头一句；**不可合并**：讲授轮、练习作答轮、批改轮（节的核心，不省）。合并与否以学员状态为准，状态好时按完整节奏走；**紧凑节奏（S2 步骤 6 落盘）下无需等疲劳信号，直接适用上述可合并项**；合并不违反「单轮一小步」——单轮仍只推进一个教学动作组。**逐块节奏**：轮次随块数增加；每块的讲授轮与确认轮不可合并，判对后的批改可与下一块讲授同轮衔接（不额外等「继续」）；学员疲劳时按熔断条收尾并在交接记块位置，不得为省轮次把多块合进一轮。

### 每轮小步（五步）

| 步 | 动作 | 要点 |
|---|---|---|
| ① | **收作业** | 上次有作业（= 上轮未完成的练习作答与输出任务）先收先批：练习在题组文件内标记对/错，输出任务的漏洞记入薄弱点；错题入错题本 |
| ② | **热身** | **优先取 `due-queue` 输出的到期项**，不足再从薄弱点/错题本补，合计抽 2–3 个旧问题做 5 分钟热身 |
| ③ | **讲授** | 讲授前先按 `teaching-loop.md` 1.3 准备最小来源包（页码/原文/图），只教覆盖范围；来源不完整如实说明。当前小节一次只讲一个块 = 当前节目标内的最细知识点（多块小节先公示知识点清单、逐块检验后推进，见「逐块推进（最细知识点）」；讲授轮骨架与文本密度按 `lecture-styles.md`「对话讲授契约」五段内容契约与「讲解文本密度原则」执行，**呈现按「对话轮呈现标记」执行**，**必要推导讲完整**、无硬字数上限；首次引入的新记号/新操作段落须给齐「语义＋代入演示＋易错点」三件套，见 `lecture-styles.md`「新记号/新操作讲透」），讲完给 1 次确认：关键块出 1 道正式推进确认题（写入 `## 作答与判分`，标 `用途=推进`；有对应 KP 时写 `KP=<id>`，无则只写 `块=<块名>`；计入本节题量与闸口分母；优先复用讲义配对练习，复用只计一次；关键块正式判分、简单块轻量确认，不设每节道数上限），简单块用一句复述/口头确认（不写判分行、不计闸口）；讲义迁移题留到节末迁移自测，不得用作逐块确认。重要概念仍请用户复述——复述即 **teach-back**：复述**覆盖 ≥2 关键点且无硬错**即通过；**不再「装不懂」**，追问只在真有疑点或需检验迁移时进行（T07）。**先示范后练习**（强制条件、例外与支架渐撤见 `lecture-styles.md`「交互式工作样例」，此处不重复）。配套规则见 `teaching-loop.md` 与 `lecture-styles.md`；讲义生成按 `handout-design.md` §4–§6。 |
| ④ | **练习** | 出题按 `lecture-styles.md`「出题流水线（四步，v6.3）」执行（探索→规划→生成→修复）。出 2–3 道递进题（基础 → 应用 → 变式），**每个题组至少含 1 道判定题**（考「何时用」而非「是什么」，衔接 `lecture-styles.md`「条件化出题」）。**核心题量预算**：每节核心新题合计 ≤6（含讲义自测 2 道；题组 2–3 道，判定题计入题组；单元检验 0–1 道用剩余额度；深度验收与 S4 复习复用题组题，不额外加题）；**关键块正式推进确认题另计，不设每节道数上限**（写入 `## 作答与判分`，标 `用途=推进`；优先复用讲义配对练习/单元检验，复用时只计一次；复用后按正式确认判分，讲义侧仍标自测；迁移自测留到节末；短题不走题组四步流水线，但答案键须正确、无提示泄漏）；**简单块轻量确认不计题量、不写判分行**。**L3 复习产物例外**：检索版要点卡 3–5 题优先复用旧题/题组（至少 1 道换情境/新问法），不作新判分证据；「自测 2 + 题组 2–3 ≤6」与「自测≠题组同题」只约束 S3 新学（见 `handout-design.md` §2.4）。**讲义四段（④/⑤ 为槽位，不计段）**：教学例→配对→④/⑤ 易错与小结→闭卷解释→评估例/迁移；配对可作对话检验，迁移是迁移自测，题组仍独立（见 `handout-design.md` §3.3–3.4）。**取材优先级**：技能型任务且学员有真实项目/工作场景时，变式优先改造自学员真实材料，无则用抽象素材。**分块与交错的切换**：新程序还在习得期（独立解题常失败）时同型分块练；当独立解题开始成功，切为交错混练以区分已会的程序。`exercises/` 有未作答题组时直接取用，等用户作答；**题组不与本节讲义自测同题**（L3 复习产物例外见前；自测只作低风险自检，不作判分证据）。出题时注明**作答格式**：一组题可同一条消息一并交齐；**信心可选**——学员可随答案一并提交「当时几分把握（1–5）」（**反馈前**提交），也可略过（时序规则见小步⑤） |
| ⑤ | **批改** | **反馈时序与信心（唯一事实源 `teaching-loop.md` 第 5 节，此处只留执行要点）**：答错 → 作答轮内立即判分、指错位；答对 → 单题 / 反馈前信心 ≤3 / 首次接触新方法即时确认，仅批量练习与模考延后到节末或交卷后。信心可选、只在**反馈前**提交才有效；反馈后补报标「回顾性」，不计入 cw 与校准。判分后反馈按三问组织——①我要去哪（对照本节目标）②我进行得如何（判分证据 + 伺服档位依据）③下一步去哪（从**教学八动作**清单选定）——反馈只落**任务层 / 过程层 / 自我调节层**三层；**禁用自我层空泛表扬**（「你真聪明/真棒」），改**过程性表扬**（策略选择 / 努力投入 / 相对上次的进步归因）。判错收录错题时**同轮完成归因定级**（见 `teaching-loop.md` 第 8、9 节）。**判分四态**：`对/部分/错/未判`；部分按缺失点归因、调度档 Again，未判不计闸口、不写 S/D、不进错题本；作废行保留审计、不删原行。**分型标签**：清单 KP 声明类型/视觉任务时，attempt 行补 `KP=KP-xx-xx`（视觉任务再加 `视觉=<任务>`），概念/设计在复述勾选行写该 KP 编号；未声明类型的旧任务不需要补标签 |

### 逐块推进（最细知识点）

- **开节核对**：开节前只核对两件事——① 本节教材目标与知识点清单（每块一个最细知识点，1 道题能独立检验）；② 本节预计课时（写入排期）。**不设** 15–30 分钟、≤5–7 块、≤2 套新记号、30/45 分钟休息阈值；节内块数不设上限，教材节不按块数拆。预计讲义 ≤20k 字仍作质量提示（>20k 预警、>30k 提示拆分讲义文件，不拆节）。已开讲的小节讲不完就停在块边界，下次从该块继续。
- **课时口径**：节级课时按实际讲授时间记录，不预设单块分钟数；不设强制休息阈值。学员说累或注意力下降 → 停在当前块边界，下次从该块继续，不赶进度。
- **节中进度重排**：每块/每次会话结束记录实际进度与剩余块；讲不完不拆节，停在块边界并写入 `## 下次续学`；只有教材结构本身允许时才新增节。
- **关键块**：只对含新记号/易错/薄弱点的块正式判分；不设每节道数上限；不是每个块都必须正式判分，但每个块都必须有 1 次可判定检验。
- **拆节数据纪律**：拆节时保留既有 KP ID、材料编号与判分记录；**优先拆块**（同节号，块名 8a–8e，不改路线/脚本）；确需拆节时用新的**整数**节号（插入并重排，或追加到路线末尾），**不用 3a/3b**——`ROUTE_RE` 只认 `\d+\.`，3a 会被当作未解析路线；不整体重编号旧数据；拆节结果写入学习路线与进度对账，按对象 ID 对账，不靠序号猜。
- **课首公示**：课首给一行「本节 X 个知识点 + 预计课时」，清单一行一个最细知识点，只列名称与顺序，不提前展开讲解；不按场/段分组。**对学员一律用知识点名称指代**，不报「块 0／第 N 块」等内部编号（块编号只出现在落盘字段与进度游标）。
- **块切分与最细判据**：**1 块 = 1 个最细知识点**（KP）。判据：① 能在当前节目标内独立讲清；② 能用 **1 道题**独立检验其核心判断；③ 若需要 2 道题分别检验两个判断，说明它含 ≥2 个知识点，必须拆块。**不设时间上限**（2 分钟或 20 分钟都可以，只要是一个知识点）。块内可以有定义、1–2 个例子、1 个易错点，但都必须服务同一个知识点；不得顺手带入相邻知识点。**最细是相对当前节目标**：下位细节属于后续节的，留给后续节，不提前塞进本节。**无 `知识清单.md` 时**按教材自然知识点切块，不把相邻知识点并块。**不可分割的单条推导/单个操作链**即使很长也保持完整，算一块一个知识点，不按时间拆。讲义单元可以对应多个块，不强制 1:1。
- **块-能力映射**：课首知识点清单每块标 `能力=C1/C2/C3` 或「支撑块」；每项关键能力至少映射 1 块；含新记号/易错/薄弱点的块为关键块。无能力映射的块不得占用正式确认题额度。
- **编号口径**：块名可写 `块=8a`（**仅落盘/内部引用**；对学员说知识点名称）；`KP=` 只接受 `KP-<节>-<KP序>`（如 `KP-03-08`），不得写 `KP-03-08a`；无对应 KP 时只写 `块=8a`，不编造编号。`块=` 是人读字段，不进闸口计算。
- **禁止多概念块**：不得用一个块承载两个及以上可独立检验的知识点。发现块内有两个判据 → 立即拆块；已讲部分标「草稿/未确认」，不把该块记为已讲（完整判定见 `redlines.md` SR-9）。
- **前置探针（通用）**：**任何块**首次引入新记号/新定义，或块目标依赖**未确证**的旧知时，开讲前做 **30–60 秒**探针（1 题）；工具/预备/衔接节做 2–3 分钟探针（1–2 题）。缺地基先补地基块或拆出「地基块」，不假设「高中已会」；新增地基块须向学员展示知识点清单变更。探针结果记学习日志，不新增闸口。
- **前置依赖检查**：有 `知识清单.md` 时，读本节各 KP 的 `前置` 列；前置未 `已讲`/`已会` → 视为缺地基。工具/预备节另列显式前置清单（如三角定义、单位圆、特殊角），不依赖 KP 清单。缺地基 → 加一个地基块；不拆节，按块续学。
- **逐块循环**：每轮只讲 1 块 → 给 1 次确认 → 停轮等回应。关键块正式判分（1 道短题，写入 `## 作答与判分`，标 `用途=推进`；有对应 KP 时写 `KP=<id>`，无则只写 `块=<块名>`；计入正确性分母；不设每节道数上限）；简单块轻量确认（**必须是可判定的具体问题**：说出区别/给一个正例或反例/判断对错/复述关键判断；**禁止只问「懂了吗」「明白了吗」**；不写判分行、不计分母，需要留痕时写学习日志；答不出或答错 → 不得推进，按提示阶梯补讲，必要时升级为正式确认并补记判分行）。**每块都必须有 1 次检验，不得跳过或把两个知识点的检验合并成一次。** 正式确认**独立答对才进下一块**；经提示②–④后正确 → 同轮补 1 道同型变式，变式独立正确才推进；仍不能独立正确 → 本轮收尾、记薄弱点、不推进、不标已讲。
- **块关闭台账**：每块关闭（正式或轻量）写一行 `## 学习日志`：块名 + 正式/轻量 + 结果；正式判分另写 `## 作答与判分`。同节跨会话续学且间隔 ≥1 天 → 开讲下一块前做 30–60 秒上一块回忆题；答不出 → 3 分钟回顾再继续。
- **答案键与照片**：正式确认题沿用题组答案键纪律（先核答案键、无提示泄漏）；照片/手写输入按既有「输入判读不预设预期」硬步骤；答案键不确定标 `未判`，不得以未判推进；作废保留原行。
- **确认 ≠ 掌握**：确认只决定「能否讲下一块」，不写「已掌握」、不翻转 KP 状态、不替代小节闸口（正确性 ≥2/3 + 关键能力独立通过 + 复述通过）。每项关键能力至少一条独立正确 evidence 不带 `用途=推进`（来自题组计划题）；正式推进确认题可作记忆/程序 KP 的分型证据（带 `KP=<id>` 独立正确），概念/设计仍需复述勾选行含该 KP 编号；正式题不得替代题组的关键能力独立通过与小节复述。每节仍须有 2–3 道题组题与 0–1 道单元检验；只有正式确认、没有题组判分 → 不得过闸。
- **闸口失败 → 块级回开**：小节闸口未过时，按题组/关键能力/复述缺口映射到具体块；只重开对应块，不整节重讲；整节重讲仅作回炉重教手段。
- **轻量抽检**：每节至少抽 1 个轻量确认块，在节末题组中用 1 道题复核；若错，回开该块，不把整节判失败。抽检题按正式确认记录，不设道数上限。
- **跨块串联（多块小节）**：含 ≥2 块的小节，节末题组至少 **1 道跨块综合题**（或一张关系图/流程链），要求学员把本节两块以上的内容连起来用；该题计入核心题量 ≤6，可复用 `8e` 综合练习或单元检验。只有单块的小节可省略。**块内题只证明单点，跨块题才证明连接**；缺跨块证据时不得仅凭逐块确认判「本节已掌握」。
- **消息长度**：保留「无硬字数上限、必要推导完整」；单块内容偏多时先查可选内容后置，不按阅读时间拆块（只有含两个独立知识点才拆）。简单事实/纯记忆可用 ~300 字作软提示；数学推导、完整示例、公式证明不受 300 字约束。**超长自查仍按结构判据，不设字数上限；300 字软提示只用于简单内容，不触发截断，也不改变超长自查口径。300 字不是单轮讲解预算，也不是拆块依据；不得为凑 300 字把一条完整推导或一个完整示例拆成多条消息。** 对话轮呈现与标记按 `lecture-styles.md`「对话轮呈现标记」执行。
- **讲义边界**：讲义草稿按块增量追加到 `materials/`，节末整理定稿；对话轮不贴讲义全文，不因要生成整节讲义而把整节内容一次输出。
- **工具触发池**：标「选学·后期必用」的工具块，不排固定 due；在既有「保持抽样池」记一条「工具 → 首次触发节」，后续节首次用到时做 1–2 分钟回忆；答不出 → 回炉该块。不写入 `## 保持复习` 的机器调度区，避免 due-queue 误读。
- **疲劳与中断**：出现疲劳/熔断信号时收尾，不赶进度。本节未讲完就结束 → 在 `## 下次续学` 的「小节」行写「第 N 节（已讲到第 k/总块）」，并在 `## 本次交接` 的「下次先做」写「从第 k+1 块（块名/KP）继续」；下次从该块起讲，不从头重灌。用户正常说下课按 SR-7 正常下课口径处理，不触发断章。
- **压缩与加速**：学员明确要求「一次讲完 / 别停 / 直接讲到底」→ 可压缩每个块的讲法（结论 + 必要依据 + 边界），连续快速逐块输出，但**每块仍 1 检、独立答对才下一块；不得把多个知识点合并成一组或整节灌入**。纯记忆/已会块可走压缩出口（结论 + 必要依据 + 边界 + 1 句可判定确认）。

- **深讲概念**：软默认每节选 1 个**完整深讲**，按 `lecture-styles.md`「深度契约」执行；每个被标为完整深讲的内容定稿前都跑 D1–D6，D1–D5 任一不满足 = E。**若 >1 项关键能力都需完整深讲，逐块深讲并增加课时，不拆节、不压缩深度**；机制段≠深讲（见 `handout-design.md` §2.7）。**姿态**：按 `teaching-loop.md` 第 2.1 节三档执行。

### 讲授机制（小步③内执行）

- **讲义两态**：讲授一开始先把本节草稿增量写入 `materials/`（标记「草稿」），闸口通过后再改写为「定稿」——**草稿即时落盘**，会话中断也能恢复；闸口未过时保留草稿，不删。**定稿 = 学员自读版**：只保留教学正文（概念单元必需槽位与默认顺序见 `lecture-styles.md`「讲义概念单元 schema」），并含节首导读三行（本节目标 / 前置 / 预计时长，见同一 schema），按讲义骨架组织而非时间线；**长节/教材级按 `lecture-styles.md`「读者版可读性契约」执行 P1 读者路径（`## 本节速览` / 单元首行「一句话结论：」/ `## 回看索引`，可选，不替代五要素）**；**台账状态行**、伺服档位、检验作答记录、补讲台账等导师记账一律留在 progress.md 与题组文件，不进定稿；**讲义状态行 `- 状态：` 保留在讲义头**；补讲中有的教学价值并入正文对应位置，不得随清理丢失。**L3 检索版要点卡不生成完整讲义**，按 `handout-design.md` §2.4 走复习产物；头部指针只在 progress.md 质量保障机制区存在时写（§2.6）。**正文学习路径按 `handout-design.md` §3.3–3.6（④/⑤ 为槽位，不计段）：教学例→配对→④/⑤ 易错与小结→闭卷解释→评估例/迁移；本节判分与复述完成后、状态转定稿前按 `handout-design.md` §3.6 做二次定稿，只回填概念/方法/讲义缺口，不写分数。** **类型/支持级/学习者状态/决策日志按 `handout-design.md` §4–§8：类型矩阵、四步流水线、L1/L2/L3、读者状态、复杂程序/设计的决策日志与修复表；L2 可补全、L3 用检索版；不新增闸口。** **来源/覆盖/深度按 `handout-design.md` §9：来源→KP→讲义→题组四向对齐；覆盖行写暂缓/范围外；深度分配按证据；覆盖行派生自 progress.md，不改数据。** **P1/P2 可选增强见 `handout-design.md` §10–§11；不新增闸口。** **定稿前跑 `scripts/verify_explanation.py` 静态校验并完成 `lecture-styles.md`「讲解出厂自检」，E 项与 `W-UNICODE-CHAR` 均清零才定稿；读者版加 `--reader` 跑 W 级可读性检查（不阻断，失败按四问改结构/图/标题）**（其余 W 可显式后置）；**深讲概念另跑「深度契约」D1–D6，D1–D5 任一不满足 = E，不得定稿**。**脚本通过只表示「结构可定稿」，讲义状态行仍保持「草稿」，待小节闸口通过后才改为「定稿」。** **`## 扩展（选读）` 区不参与闸口判定**——区内内容不出题、不进测验、不作掌握证据，其结构要求（不挂分层、不强制配 ③ 框）见 `lecture-styles.md`「讲义概念单元 schema」。**定稿后纠错**：问题出在已定稿讲义时，先把**讲义状态行**改回 `草稿（修订中）`，按 `teaching-loop.md` 第 1.3 节同步修正讲义/图/存档与受影响的判分证据，重跑 `verify_explanation.py` 与出厂自检、E 项清零后再改回定稿——不得边定稿边改，也不得只改对话不改存档。
- **备课查阅 / 课首定位 / 备课短表 / 教学质疑与纠错分支**：见 `teaching-loop.md` 第 1、3 节。示范规则（完整示例、工作样例三型、新记号讲透、强制触发条件）见 `lecture-styles.md`，此处不重复。
- **材料型按材料结构分流（不一律精读）**：**判据 = 材料有没有「主张—证据」结构**。论证文（论文 / 评论 / 著作章节）→「精读笔记式」，单元 = 一个论证块，③ 为「参考概括 + 原文定位」（见 `lecture-styles.md`「精读笔记式」）；条文 / 手册 / 规范 / 教材条目（无论证结构）→「标准讲义」，单元 = 一条款，③ 为「条款引用 + 适用条件与例外」；代码库 / 配置文件 →「操作手册式」，单元 = 一个可跑通的改动，③ 为 `代码：` + `输出：`；数据表 / 图表 →「标准讲义」，单元 = 一个读图结论，③ 为结论 + 数据位置。知识型/技能型/备考型按学科族选标准讲义或对应卡片。
- **跨界三猜想前置（含确证铁律）**：见 `teaching-loop.md` 第 3 节（讲授新概念第一个动作；无同构可撬则跳过，不硬凑类比）。

### 批改机制 / 引导机制（小步③ 讲授、小步⑤ 批改内执行）

教学决策细则——归因定级与**六类错因**、教学八动作、主观题批改纪律、答案与解析格式、提示阶梯与**提示起点选择**、苏格拉底边界、熔断条——见 `teaching-loop.md` 第 4、6、8、9 节。此处只保留与闸口/落盘直接相关的约束：

- **判错必须同轮完成归因定级**（`错因=` ∈ {知识性, 理解性, 技巧性}，`级=` ∈ {A, B, C}），随错题本收录同轮落盘。
- **同一卡两次走到第 5 梯 → 标「顽固」**，转入换角度重教而非重测。
- **熔断条优先于提示阶梯与闸口节奏**（节内即时修复；课程级回退见 `data-and-recovery.md` 异常分支）。

### S3 闸口（可检验）

- **闸口（小节验收）**：本节练习 **正确性达标**（独立正确 + 提示②–④后正确合计 **≥2/3**，2/3 为默认线、可按目标量表收紧/放宽）**且** **关键能力项独立通过** **且** **复述通过**。**关键能力不可被简单题抵消（R05）**：本节须先定「**关键能力清单**」（1–3 项，即本节核心方法 / 唯一核心应用题 / 主要易错点），**每项关键能力必须至少一次独立正确**（提示后正确不计入该项通过）；「两个简单题对、唯一核心应用题错」**不得**因总比例达标而判本节通过。正确性、独立性、流畅度**分别落盘、不折算合并**：慢但独立正确按**完整正确性**计，不因慢折算；提示后正确另记**依赖程度**（独立 / 依赖提示），不外推为独立掌握。**正确性四态**（v6.0）：`对` 计入分子与分母；`部分` 只计入分母（未达完整正确）；`未判` 与 `作废` 不计入分母（未判应补判或作废，脚本给 W 提示）；若有效作答全为未判/作废 → `E-NO-GRADED-ATTEMPT`，不得标已掌握。**正式/轻量口径**：正式推进确认题按判分四态/独立性照记，计入正确性分母；轻量确认不写判分行、不计入分母、不作分型验收证据；早期错误与变式均保留为独立 attempt，不删不改；正式推进确认可作记忆/程序 KP 的分型证据（带 `KP=<id>` 独立正确），概念/设计仍需复述勾选行含该 KP 编号；正式题不得替代题组的关键能力独立通过与小节复述；每节仍须有 2–3 道题组题与 0–1 道单元检验。**分型验收（v6.1，仅声明了类型的 KP）**：记忆/程序须有 `KP=<id>` 的独立正确 attempt；概念/设计须有复述清单已勾选行含该 KP 编号；视觉任务须有 `KP=<id>｜视觉=<任务>` 的独立正确 attempt；缺失 → `E-KP-TYPED-GATE`。Unlabeled/旧清单不触发。
- **复述通过标准**：用户复述**覆盖 ≥2 个本节关键点**且**无事实性错误**。判分时逐项勾选检查清单（关键点 1 / 关键点 2 / 有无硬错），把勾选结果写进题组文件。复述未通过时**逐项告知缺哪个关键点、错在哪**，再换角度重讲后请复述，不判通过、也不让学员猜。
- **判分证据强制**：标记「已掌握」前，`exercises/` 必须有对应本节的判分记录（题号 / 正确性 / 独立性 / 流畅度 / 复述检查清单勾选）；无证据不得标「已掌握」。**信心与 cw 口径见 `teaching-loop.md` 第 6 节**：只有反馈前提交的信心有效，反馈后补报标「回顾性」；反馈前信心 ≥4 且判错标 `cw`，due-queue 优先修复，修复后照常走清除规则。
- **判分三维（正确性/独立性/流畅度）、调度档位与难度伺服参数表（85% 目标）**：见 `teaching-loop.md` 第 6 节（85% 为启发式参数，边界见 `references/methodology.md`）。**闸口两层**：比例线（≥2/3）可按目标量表收紧/放宽，伺服只在其上调节难度；关键能力独立通过与复述通过是底线，不随量表放宽、伺服不可替代。过载靠降难，不靠同长度重讲。**落盘**：伺服判定结论（档位 + 依据 + **样本数**）随判分记录落盘，报「正确 x/样本 n 题」，n < 5 时标注「样本过小，档位仅供参考」。

- **产出**：小节勾选、讲义从草稿转定稿落盘 `materials/`、题组与判分落盘 `exercises/`、错题本、学习日志、下次续学点。

### 节末收尾五件套（闸口达标后执行）

等待轮结构见「机制关系表」。五件依次：

1. **teach-back**（已含在小步③讲授，此处为汇总引用）；
2. **学员输出任务（按目标选一种，不必逐节轮换）**——等用户写完，漏洞记入薄弱点（即下场复习队列）。**已产出充分证据者（如 teach-back 复述已覆盖关键点且无硬错）不必再产同一义证据、不索要同义重复总结**。按本节目标选一种：①**复述要点**（用自己的话写 ≤3 条本节核心要点）②**类比解释**（自选一个生活事物类比本节某概念，说明对应关系与边界）③**教给他人**（假设对方零基础写一段简明教学讲解）④**动手练习**（完成一个具体小练习并提交过程/结果）⑤**提问清单**（列出本节仍未理解的 2 个问题）⑥**场景迁移**（把本节知识应用到一个实际场景，说明步骤）。由导师按本节内容性质提议（抽象概念节→②、技能节→④、应用型→⑥），学员可自选替换（细则见 `teaching-loop.md` 第 7 节）；
3. **落盘更新**（progress.md + materials 定稿 + exercises 判分；**有清单时同轮翻转本节 KP 状态（未讲→已讲）并更新覆盖摘要行**——见 `data-and-recovery.md`「知识清单文件」小节；**小节达标时同轮在 `## 保持复习` 写初始条目**（S=3.0、D=3、last=掌握日、due=+3；用 `scheduler.py next-interval --new-card --grade good --last <日> --today <日>` 算，不心算））；
4. **给出具体下次复习日期**——对本次新产生的薄弱点条目按 S4「调度调用速查」的新条目命令取 due（不心算），用绝对日期（YYYY-MM-DD）告知（如「2026-10-15 回来，3 条到期，含你自信答错那条」），**禁止相对日期**。
5. **进度对账**（限 2–3 行）：本课程对照源共 N 项、已讲 M / 纳入 K 项、本节是第几节；剩余未讲逐条列；暂缓挂起 K 项及触发条件（一句话带过，详情指向 progress.md「暂缓与范围外」）。**学员不问也要报**——本件是覆盖透明度的主输出通道，落盘通道为「下次续学」区块的「范围快照」行，二者同源同更。有清单时，KP 口径数字**带口径标签**（如「KP 未讲 a/M」，M = 清单总行数）并入既有行、不新增行，2–3 行上限保留。

**节末交接（v6.2，可选）**：五件套之后更新 `## 本次交接`（总结 / 下次先做 / 未解决）；如果出现了“这个学员在这个任务里为什么卡/为什么通了”的持久洞察，写一条 `## 学习记录`（≤120 字、带证据）；深讲概念公开讲完后可写 `## 讲授证据`（逐字引用 + 来源锚点）。三区都可选，旧任务缺省合法；没有新内容就不写，空更新合法。

### 未达标处理

**错误处理第一动作永远是『定位误解点并针对性纠正』；整段重讲仅作重教后仍卡时的回炉手段**（与「过载靠降难不靠重讲」及 S4 重教路径互为印证）。记入薄弱点，下一轮插入巩固题或回退前置小节；普通答错记薄弱点，**顽固**是更重一级——重教优先于重测，且回炉建议的判定把「两次到梯底」计入；**回退有终止条件**——同一小节连续 3 轮仍未过，改为「回炉建议」（拆更小步骤重讲或换讲义风格），不死循环。

全部小节「已掌握」→ 阶段 → 结课。

## 覆盖率审计（S3 与 S5 之间的强制关卡）

- **定位**：对照落盘的对照源做全量核对，防「学员不问不补」的静默断章（衔接 🟡 SR-7）。审计是发现机制，处置权在用户；不每节都做（节末第 5 件已承担逐节对账）。
- **触发（四路，任一命中即审）**：

| 路径 | 触发条件 |
|---|---|
| 主 | S3 最后一个小节「已掌握」→ 转 S5 前**强制一次**（转阶段前置义务，先于 S5 任何动作） |
| 章末辅助 | 多模块/多章课程每完成一章（模块），追加一次章末覆盖审计 |
| 辅 A | 备考型距考试日 ≤ 2 周（**可调参数**：默认 2 周，模型可按任务节奏在 7–21 天区间调整并声明依据）时，无论当前阶段，主动跑一次对照源核对 |
| 辅 B | 用户随时要求（「讲完了吗」「还有哪些没讲」）→ 即时审计并出差异清单 |

- **动作**：重读落盘的对照源 → 逐项核对四态（纳入-已讲 / 纳入-未讲 / 暂缓 / 排除）→ 产出差异清单。
- **分母细化（两档合法）**：有清单 → 逐 KP 四态核对，分母 = 清单纳入项，已讲判定 = 对应小节勾选 × KP 状态「已讲」，差异清单细化到 KP 行；无清单 → 维持对照源条目级。漏讲项落到 KP 行时处置仍走处置三态，不得静默。
- **KP 审计计数落盘格式**（有清单时）：审计四态计数并入学习日志审计记录行，格式（键序与清单覆盖摘要行一致）：「KP 审计：总 N ｜ 未讲 a ｜ 已讲 b ｜ 暂缓 c ｜ 排除 d ｜ 差异 X 项：<清单>」。
- **先分类再处置**：「计划内未到」（尚未到达的后续小节，属正常状态，处置为「按计划继续」，**不计漏讲、不触发 SR-7**）与「漏讲」（越过计划顺序却缺失）分开处理，只有后者进入下列处置：
  1. **漏讲项**：当场列给用户，二选一——「**现在补节**」（走 S3 新小节完整流程：due-queue 前置 → 讲授 → 练习 → 闸口，一节不省）或「**挂入暂缓清单**」（记触发条件）；不得静默补、不得静默弃；
  2. **深度存疑**：只在差异清单标注「深度存疑」交用户决定，不自动重讲、不阻塞（覆盖完整性与讲解深度两层勿混）；
  3. **对照源被推翻**（如考纲更新）：更新对照结论与暂缓清单，差异项走处置 1。
- **结论落盘**：学习日志记审计记录（日期 + 对照源 + 差异数 + 处置），「暂缓与范围外」区块同步更新。
- **零迁移**：旧任务无对照源/暂缓区块 = 合法「未审计」形态，本次审计即为首次审计（见 `data-and-recovery.md` 兼容规则）；缺区块不报错，模型在下一次正常文件写入/编辑时顺带补区块。

## S4 复习巩固（可从逐节学习或结课随时插入）

- **目标**：清空薄弱点与错题，并维持已掌握内容的保持复习。
- **动作（抽取与出题）**：抽题后按 `lecture-styles.md`「出题流水线（四步，v6.3）」执行（探索→规划→生成→修复）。**错误修复**与**保持复习**分开——①**错误修复**：针对薄弱点与错题本出题；②**保持复习**：`## 保持复习` 区的已掌握条目按 due-queue 到期重测（未到期可每若干节 / 每周稀疏抽测 1–2 题，不只复习错题，防「只清错题却丢掉已会能力」）。**due-queue 同时读取「薄弱点」「错题本」「保持复习」三区**，输出 `kind` 与 `reason`；均不讲新内容。**抽取顺序 cw 优先**（自信但错者先复习）；`顽固` 条目不走重测，先重教（可换讲义风格，衔接 `lecture-styles.md` 的费曼卡 / 对比辨析卡），重教后重新计数。**检索变式口径**见「机制关系表」。
- **动作（判分后调度落盘）**：**不心算**——按下方「调度调用速查」选命令执行，取回 JSON 中的 S'（stability_new）、D'（difficulty_new）、due，用文件写入/编辑能力写回条目（`--confidence` 仅回显供落盘记录，不进公式）。

**调度调用速查**（S3 节末第 4 件与 S4 共用；脚本只读计算，落盘由文件写入/编辑能力负责）：
> **有效域与边界（脚本强制、非有限数一律 exit 2 结构化拒绝）**：S ∈ (0,365]、D ∈ [1,5] 且 0.5 粒度、**elapsed 有限且 ≥0**（R=elapsed/S 已夹在 [0.25,2.0]，长中断不放大间隔，故不再设 3650 天上界）；日期加法越界（如 `9999-12-31` + 间隔）同样拒绝，不裸崩、不输出非有限数。
- **新条目首次调度**（S3 新产生的薄弱点 / 错题 / 保持复习）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <判分档> --new-card --last <今天> --today <今天> [--init-shift {-1|0|1}]`
  —— grade 取该条判分档（判错=again）；保持复习初始条目固定用 `--grade good`（S=3、D=3、due=+3）；`--init-shift` 影响初始 D：顺向检索 -1（默认 0），反向问 / 迁移 +1；返回 stability_new / difficulty_new / due。
- **既有条目复习判分**（S4）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <grade> --stability <S> --difficulty <D> --last <last> --today <今天> [--current-due <原due>]`。
  **同会话重复答对**（`--last` 与 `--today` 同日）：必须同时传 `--current-due <原due>`；脚本返回 `same_session=true` 并原样返回该 due，S/D 不变——只刷新召回，不把一天内反复刷题记成长期保持。非同日复习不传 `--current-due`。保持复习按同一命令更新；`partial` 用 `again`，`未判/作废` 不写 S/D。前提：`due` 由脚本生成、不要手改；手改 due 的条目先按当前 S 与手工 due 对齐后再复习。
- **动作（收尾与返回）**：复习轮收尾同用「节末收尾五件套」（teach-back 可省略，其余四件保留；第 5 件进度对账照报——复习不掩盖未讲事实）。插入复习时记录**复习返回点**：progress.md 的「复习来源阶段」= 进入 S4 前的阶段（逐节学习 / 结课 / **已完成**，见 `data-and-recovery.md` 返回枚举），「当前阶段」临时切为「复习巩固」。
- **开场校准反馈（30 秒）**：进入 S4 时先跑 `python "<技能根>/scripts/scheduler.py" calibration --root "<数据根>" --slug "<slug>"`，向学员读出其**当前问题记录中的高信心错误占比**（cw 占比）与信心分布（脚本 JSON，**禁止心算**）。**口径约束**：该占比只是「当前未清除问题记录」的投影统计，**不得用来评价学员整体人格或整体校准水平**（见 `data-and-recovery.md`「校准画像」）。
- **元认知教学（四点，据读数展开）**：①用学员自己的 cw 条目举例说明『流利度 ≠ 存储强度』；②教**答题后延迟自评**（做完一组题后隔一刻钟再估对错，比交卷即估更准——postdiction）——**明确这是「回顾性」估计，与原信心不是同一种测量**：回顾性自评只作元认知练习素材，**不得当作原信心、不用于 cw、不用于校准**；③**遗忘正常化**：复习中答错的条目按「忘了不是失败，是数据——它只是告诉我们这条该今天再练」的口径反馈，去羞耻化；④教学措辞用『当前快照』口径，不宣称全程累计。**样本数披露**：读出画像数字时同报分母条目数（如「12 条有信心记录的条目里 5 条 cw」），分母 < 5 时加「样本还小，这个比例先当参考」。cw 与校准画像的两层语义见「机制关系表」，统计口径见 `data-and-recovery.md`「校准画像」小节。
- **按错因分诊补救（六类错因的唯一事实源见 `teaching-loop.md` 第 9 节；本表只给与阶段/落盘相关的侧重，不另立相反规则）**：

| 错因 | 补救侧重（教学动作以 `teaching-loop.md` 第 9 节为准） |
|---|---|
| 知识性（未教 / 遗忘） | 回归材料重学或**先教未教内容**（衔接重教路径） |
| 理解性（概念误解） | **换角度重讲 + 换证据**（换类比 / 换讲义风格），**不默认只练圈画**；概念缺口按实际误点重教 |
| 理解性（过度泛化） | **边界反例 + 判定题 + 学员自举反例**；不默认重讲全节 |
| 技巧性（执行偏差 / 流程习惯） | **流程专项**：审题圈画、步骤回查清单；**备考型**可加限时技巧训练 / 同题限时重做（衔接考试冲刺卡） |

> 说明：旧表曾把「理解性」一律导向「审题关键词圈画」——这是把概念误解当成执行偏差，属相反规则，已按 `teaching-loop.md` 六类错因分诊修正（R06）。

- **复盘火力分级**：A 级 → 详细整理 + 配同类变式（火力集中处）；B 级 → 记思路要点即可；C 级 → 仅标记知识点、不展开整理。**级不参与 due-queue 排序**（排序契约 cw→最逾期→due 早→稳定序不变），分级只影响整理深度与复盘优先注意力。S4 复习判分可**调整级别**（如 C 级反复错 → 升 B）。
- **缺省归因修正**：遇到错因为缺省推断（脚本输出标 `meta_default:true`）的旧条目，先按当下证据归因并写入真实值（这本身就是本轮动作，不得盲目补默认值，见 `data-and-recovery.md` 兼容规则第 5 条）；可向学员说明「该条错因为缺省推断，如与实际不符请指正，可推翻重归因」。
- **闸口**：同一薄弱点连续 2 轮全部答对 → 从薄弱点清单移除，并**转入 `## 保持复习`**（初始 S=3/D=3/last=清除日/due=+3；不得直接消失）。**同日两次正确不等同长期保持**——转入保持复习后按 due-queue 到期重测，未到期可稀疏抽测；仍有残留 → 继续复习。**预算耗尽或用户示意结束时**：列出未清项与顺延日期（保留原到期日），按「复习来源阶段」返回或一句简短收尾——**不以「有残留」否决已约定预算**（S3「复习预算」同源）。**顽固条目不参与「连续 2 轮全对 → 移除」的普通清除路径**，走**四步清除链**：①**重教**（可换讲义风格）→ ②**重新计数 2 轮全对** → ③**变式自创关**（清零前最后一关，位置在计数通过之后、移除之前，每条只发生一次）：请学员把自己这条原错题**改造出一道新变式**（改条件 / 改问法 / 换情境任一）并自答自评；导师只核对变式是否真对准原错因——**变了题但考的仍是原错因才算过** → ④**通过后从薄弱点移除并转入保持复习**，不通过 → 回①再重教一轮。自创变式题落盘 `exercises/`（文件名前缀 `z-`，如 `z-变式-<日期>.md`），不计入小节判分证据比对。
- **错题本清理/归档规则**：某错题对应的薄弱点被清除后，该错题**归档**（移入「错题归档」区，不再参与 S4 抽取）；连续答对 2 轮的错题同样归档；变式自创关通过后，原错题按既有归档规则移入「错题归档」。防止长任务下错题本无限增长。
- **产出**：薄弱点清除记录、错题归档记录、**保持复习条目更新**、本次交接/学习记录（可选）；复习结束后按「复习来源阶段」返回——从逐节学习插入则恢复当前小节，从结课进入则回到结课重出综合测验，**从已完成进入则返回「已完成」（不撤销课程结果）**；**返回后把「复习来源阶段」清回「无」**（下次进入 S4 时重新记录，避免残留触发 W-STALE-REVIEW-ORIGIN 告警）。

## S5 结课

- **目标**：验收并沉淀。
- **按目标程度收束**：结项前对照 `progress.md` 的 `目标程度`；达到学员说的程度即可结课，不要求覆盖完整学科。未记录时不额外加码，仍按原计划与目标线判定。
- **动作**：
  1. **一页纸总结**：核心概念、易混点、错题 Top 5，落盘 `materials/结课-一页纸总结.md`（讲义区，不进 `exercises/`）；**可选掌握徽章行**：对薄弱点/错题条目中带调度元数据者按稳定度 S 分档可视化（分档阈值与呈现口径的唯一事实源见 `data-and-recovery.md`「快捷指令明细·问进度」）；纯呈现层，不改任何数据，**分档阈值为经验值、不参与任何闸口判定**，无元数据条目不显示徽章，学员要求简洁时可整行省略。
  2. **综合测验按类型分叉**：
     - **类型=备考型且目标考试明确 → 全真模式**：①时长 = 目标考试真实时长（用户未告知则以交互式提问确认一次，同 S0 口径）；②时段尽量对齐真实考试日程（如上午 9:00–11:00）；③题型分布参照真题结构（题型 × 题量 × 分值）；④中途做**时间分配检查点**——每过约 1/3 时长向学员报一次应到进度（如「此时应完成选择+前两道大题」），请其自查。
     - **考前睡眠优先**：进入考期前 2 周内的复习轮与考前提示中，向学员说明「通宵突击是用长期巩固换几小时未巩固记忆，睡眠优先于加练；与成绩相关的是**学习期间的规律睡眠**，而非考前一晚（MIT 2019）」；不强推、不制造焦虑，备考审计触发点可顺带一提。
     - **类型非备考型 → 迁移综合测验**：题量与覆盖**由「能力—任务—评分点蓝图」决定**（先按对照源纳入项列出关键能力与对应评分点，再定题量、每题分值与此卷达标线，**不再一律固定 5 题**）；题量默认取下限，长课程多 KP 时按蓝图扩展。
     - **全真模式只改测验的组织方式（时长/时段/题型）**；验收**按真实分值与目标线**判定（见下闸口），错题仍回 S4；重试上限见下。
     - **诚实约束**：会话无法强制锁时——向学员说明以自觉计时模拟，导师按报时给检查点提示；**不得谎称系统能强制限时**。
- **闸口（分型通过线；练习反馈 / 小节验收 / 考试模拟三档分明）**：
  - **练习反馈**（S3 日常）与**小节验收**（S3 闸口）已按「判分三维」分开，**考试模拟**（S5 综合测验）另按**真实分值与目标线**评价，三者不混用同一套通过线。
  - **类型非备考型 → 迁移综合测验**：按**目标量表**判定（默认**蓝图合计分值的 4/5 达标线**，可按目标收紧/放宽）——答错题回 S4 清零后**仅重测错题对应 KP**（不整卷重考），重测通过即视为通过该题。**达标线须机器可读**：在 `exercises/99-结课综合测验-<日期>.md` 头部写 `目标线：a/b`（如 `目标线：4/5`）；未写则 `progress_check.py` 按默认 4/5 判，写了则按该值判（`a ≤ b`，非法值忽略回落默认）——收紧/放宽而不写这一行，脚本仍按 4/5 拦停，等于没改。
  - **类型=备考型全真模式 → 按目标考试的真实分值与目标线判定**：以真题分值结构计分（题型 × 分值），达标线取用户的目标分数（未告知则以交互式提问确认一次）；**不再一律要求 5/5 满分**——高分非满分不自动陷入无限重学，保留薄弱点继续攻克。任一达标 → 任务置「已完成」；未达标 → 回 S4 清完再来。（4/5 依据掌握学习 80–90% 通过线惯例，见 `references/methodology.md`；分型语义运行时生效，零数据迁移，已完成任务不受影响）
- **重试上限**：同一综合测验**连续 3 次未达目标线（分型口径）** → 触发「回炉建议」分支：列出反复出错的考点，建议回 S3 重学对应小节或调整讲义风格，不死循环、不无限挫败用户。
- **出题范围约束（终极对照）**：综合测验出题范围**必须覆盖对照源全部纳入项**（含审计后补讲的节），不得只测已勾选小节（衔接「覆盖率审计」小节）。有清单时细化：**纳入 = 状态 ∈ {未讲, 已讲}**（暂缓/排除不入出题分母），综合测验须覆盖全部纳入 KP，题组文件固定命名 `exercises/99-结课综合测验-<日期>.md`（99 专号），KP↔题面映射在该文件内留痕供抽查（可一题多 KP），且**每个纳入 KP 必须对应至少一个可判分评分点**（仅题面提到该 KP 不算映射，R05）；无清单维持原口径。
- **复习节奏落地**：结课必须产出一个**可执行的复习清单文件** `materials/复习清单-<课程名>.md`，含具体日期：第 1 / 7 / 30 天各一条，**以结课日为第 1 天**（即结课日、结课日 + 6 天、结课日 + 29 天；逐条写出绝对日期），每条列出当日要复习的小节/薄弱点/错题/保持复习条目。后续「已完成后再触发」时读取该清单，并先用 `scheduler.py due-queue` 核对 `## 保持复习` 的到期项；保持复习到期可随时插入 S4，复习后返回「已完成」。
- **结课交接（v6.2，可选）**：S5 收尾更新 `## 本次交接`（本课程总结 / 下次先做 / 未解决）；把本课程真正有效的任务级洞察沉淀为 `## 学习记录`（≤120 字、带证据），跨任务稳定模式仍进 `profile.md` ②，不重复。深讲概念公开讲完后可补 `## 讲授证据`。
- **再学选路**：用户要求再学 → 技能**按错题状态自动选路**并说明理由：错题未清零 → 进 S4 先清错题；错题已清零 → 从 S1 重新诊断（可能已进阶，路线需重排）。
