## 0. 当前执行边界

§2 执行阶段 0 一致性裁决；§3 执行理解核心；§4–§8 执行阶段 2；§9 执行阶段 3（来源四向对齐、覆盖行、深度分配、教学例/评估例真实性、来源保真）。§10–§11 是 P1/P2 可选增强，按需启用，不改变 11 条硬合同；不启用时按现有分册执行，不得以「合同要求」为由跳过闸口或改写旧讲义。

### 0.1 风格选择

写/改讲义前先选一种风格：默认「标准讲义」；用户点名风格时优先用户指定；按适用时机匹配；**同一份讲义只用一种风格**。六套风格的骨架与适用条件见本册附录；卡壳后换风格的映射见 `teaching.md`「风格切换映射」。

## 1. 一页合同（目标态，11 条）

1. **类型 + 支持级 + 证据**：先定记忆/概念/程序/设计，再定 L1/L2/L3；证据来自 KP 状态、判分/错题、交接/画像，不凭空假设。
2. **目标与拆解**：1–3 项关键能力；每项拆 3–7 个子技能/决策点；新手最可能卡的那一步单独解释。
3. **一条主线**：机制链 + 适用边界 + 关键对比 + 高信心误解；每个最小必需概念至少一句机制；完整深讲软默认 1 个，多项关键能力确有必要时可逐块深讲并增加课时。
4. **四段支架（④/⑤ 为槽位，不计段）**：完整示范（或补全）→ 配对练习（可回看）→ ④/⑤ 易错与小结 → 闭卷解释（不占题量）→ 评估例/迁移（新情境）。两道自测 = 配对 + 迁移（L1/L2；L3 见 §2.4/§6）。
5. **生成动作**：先猜（有相关经验时）、关键步自解释、闭卷自检（3 句 → 信心 → 对照 ⑤ → 迁移）；≤3 个/节，不判分。
6. **类型化落点**：①–⑤ 与自测按类型填；记忆用线索/辨别，概念用机制/正反例，程序用决策点，设计用案例/权衡/评价标准。
7. **答案与反馈**：答案三件套（答案 + 为什么 + 常见错答）；选择题逐项排除；不泄题；设计类用 `方案：`/`设计说明：`，记忆/客观用 `答案：`。
8. **文本与图示**：机制用因果段；连接词不算空转句；跨段重复名词；强调标记按「连续两段不都用加粗抢重点」控制（术语密集段可例外；结构信号词不计）；图注说结论、标注内嵌、alt 非空；去装饰图/趣闻；引用原文 ≤20%。
9. **冷读与回填**：合上讲义答四证（解释/判别/执行/纠错）至少 3/4；判分后按真实错因回填 ④/对比/误解框，只补 1–2 处，不写分数。
10. **脚本与零迁移**：定稿前跑 `verify_explanation.py` 与出厂自检；旧讲义不回溯；不新增字段/闸口。
11. **范围与来源**：来源→KP→讲义→题组四向对齐；覆盖行写清暂缓/范围外；来源锚点、原创/改编、引用 ≤20%。

## 2. 一致性裁决（阶段 0 立即执行）

### 2.1 状态行：两个词

- **讲义状态行**：`- 状态：草稿（…）` / `- 状态：定稿（…）`，留在讲义头部；脚本靠它判两态，不是判分记账。
- **台账状态行**：`状态(日期): 通过/已讲/…`，只留 `progress.md` 与题组文件，不进讲义。
- 文档里不再用无修饰的「状态行」指代两者；两者不是一回事。`handout.md`「定稿边界」与 §2.1 的讲义两态统一用上述两个词。
- **草稿留存**：讲义草稿即时落盘；小节闸口未过时保留草稿、不删，补齐后继续；仅闸口通过后改为定稿。

### 2.2 ③ 豁免 canonical 标签

允许且只允许：

- `③ 不适用（纯概念）`：豁免 ②③，①④⑤仍须；
- `③ 不适用（纯记忆）`：豁免 ②③，①④⑤仍须；记忆有可复现答案时仍可给 ③，但给了 ③ 就要按完整示例补 ②；不补 ② 就用本条豁免，不要只给 ③；
- `③ 不适用（已会·检索版）`：豁免 ②③，①④⑤仍须；用于 L3/已会单元的检索版；若给 ③，同样按完整示例补 ②，不补 ② 就用本条豁免；
- `③ 不适用（参照级）`：豁免 ②③④⑤，①仍须。

禁止把纯记忆写成「纯概念」；脚本 `THIRD_EXEMPT_RE` 接受任意 `③ 不适用`，文档与 `E-REQ-MISSING` 提示必须列全上述四类。

### 2.3 交付标识 canonical 表

| 类别 | 交付标识 |
|---|---|
| 数学/理科 | `解：`/`解答：`/`证明：`/`Solution:`/`Proof:` |
| 文科/理论 | `答：`/`解答：`/`参考答案：`/`方案：`/`设计说明：` |
| 语言 | `参考答案：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`Model answer:`/`Sample answer:`/`Translation:` |
| 精读 | `参考概括：`（收尾 `原文定位：`） |
| 编程 | `代码：`/`脚本：`/`输出：`/`Code:`/`Script:`/`Output:` |
| 技能/实验 | `步骤：`/`操作：`/`Steps:` |
| 记忆/客观 | `答案：`/`Answer:`/`Key:` |

**canonical 集合**（脚本必须全部接受，本表必须全部列出）：`解`、`答`、`解答`、`证明`、`参考答案`、`答案`、`参考概括`、`参考译文`、`译文`、`范文`、`例文`、`代码`、`脚本`、`输出`、`步骤`、`操作`、`方案`、`设计说明`、`Model answer`、`Sample answer`、`Answer`、`Solution`、`Proof`、`Translation`、`Output`、`Code`、`Script`、`Steps`、`Key`。

- `方案：`/`设计说明：` 用于设计类，接受多解 + 评价标准；`答案：` 用于记忆/客观；**不得默认 `解：`**。
- 本表是文档与脚本的单一来源；`scripts/verify_explanation.py` 的 `LEAD_WORDS` 必须覆盖本表（由 `rule_contract.py --topology` 与 `verify_explanation.py --selftest` 守护）。

### 2.4 L3 复习产物例外

- L3 用**检索版要点卡**，不生成完整讲义；3–5 题优先复用旧题/题组，但**至少 1 道换情境/新问法**，避免只背答案；不再作为新判分证据。
- 题区用 `## 本节自测`/`## 自测`，答案区用同族答案区；不新造 `## 检索` 等脚本不认识的标题。
- 「自测≠题组同题」只约束 **S3 新学**；题量预算见 `assessment.md`「题量预算与自测≠题组」。**关键块正式推进确认题另计，不设每节道数上限**（简单块轻量确认不计题量，见 `workflow.md` S3「逐块推进（最细知识点）」）；L3 复习产物不受「不得同题」限制，但不得把复用题当新判分。
- L3 单元若嵌在完整讲义里，标 `③ 不适用（已会·检索版）`；独立检索卡没有 `## 概念` 单元时不需要 ③。
- 本条只定义 L3 产物的合法出口；完整的 L1/L2/L3 判定与支持级调整见 §6。

### 2.5 单元 ≠ KP

- `## 概念 N` 是**教学单元**（历史标题，保留给脚本），不是 KP；一个单元可映射多个 KP，一个 KP 可跨单元。**但对话讲授仍按 `workflow.md` 的块单位推进**；不得用「单元可多 KP」反推讲授块可多知识点。
- 类型以单元的主导类型为准；混合类型拆单元或加类型子块。类型/支持级写规划区，不塞进每个标题；tier 标签仍必须有。
- 来源→KP→讲义→题组四向矩阵允许「一单元→多 KP」，不强制 1:1。
- 讲授块也 ≠ 讲义单元：一个块可对应多个讲义单元（如 8a 含定义 + 特殊角表），一个单元也可承载多个块；逐块推进不要求讲义按块一一拆单元，但每个块仍只讲一个最细知识点。

### 2.6 头部合并与指针

- 必填节首导读仍 3 行：本节目标 / 前置 / 预计；**读者假设、已会/未会并入「前置」**；用法放文末一行；类型/支持级放规划区，不新增必填行。
- `- 体例约定…见 progress.md「质量保障机制」` **只在目标区存在时写**；否则省略或先建区，不能留死指针。

### 2.7 深讲与关键能力

- 软默认每节选 1 个**完整深讲**（D/P/M/H/B/C）；其余关键能力用工作级「机制一句 + 对比一句」。
- 若 >1 项关键能力都需完整深讲，**逐块深讲并增加课时，不拆节、不压缩深度**；机制段 ≠ 深讲。

### 2.8 类型单元数

- 记忆 5–7 chunk；概念 5–7；程序 3–5 个决策点；设计 1–3 个案例。这是讲义组织提示，不是学习路线闸口。
- `workflow.md` 的「~7 个概念」只适用于概念型；其他类型按本表。
- 单元数明显超出时，优先重组单元或拆讲义文件，不自动改变教材节、不按时间拆节；不得用增加题量或压缩必要讲解来硬塞。

### 2.9 命名、标题与附件

- 复习产物统一叫 `要点卡` 或 `检索版要点卡`；不再另造 `检索单`/`复习卡` 名称。
- `概念地图` 在混合类型下称「结构图」；`## 概念 N` 保留给脚本，正文可称「学习单元」。
- ④/⑤ 摘要仍 ≤3 句（记忆族 ⑤ 线索卡可到 7 条，见 §4.2 与 `handout.md` 密度例外）；修复表/决策日志/对照表算附件，不占三句，但单元仍要有一句摘要。

### 2.10 概念地图阈值

- ≥5 个概念或 ≥3 条依赖关系建议写；长节可加空概念图做闭卷检索。
- 旧「8 个以上」阈值废止。

### 2.11 定稿硬项

- 定稿前 `verify_explanation.py` 的 **E 项**与 **`W-UNICODE-CHAR`** 必须清零；其余 W 可显式后置并记入 progress.md「质量保障机制」。
- **补讲价值不得丢失**：补讲台账留在 progress.md/题组文件，不进定稿；补讲中产生的教学价值必须并入正文对应位置，不得随清理丢失。
- 定稿态流转与二次定稿见 §2.1、§3.6、§5.4。

## 3. 理解核心（阶段 1 立即执行）

本节用于**新生成/新定稿**讲义；旧讲义不回溯。与 `handout.md` 冲突时，本节决定“学习路径”，产物格式/风格仍按 `handout.md`。

### 3.1 理解四证

- **解释**：合上讲义用 3 句话说出核心机制/规则/线索/权衡（按类型），不是背定义。
- **判别**：给新情境，判断用不用、何时不用。
- **执行**：合上讲义独立完成迁移/评估任务；配对练习是支架，不算独立执行证据。
- **纠错**：指出一个典型误解并改正。
- 按类型调动词：记忆=提取/辨别/应用/纠错；概念=解释/判别/举例/纠错；程序=解释决策/执行/条件/纠错；设计=分析/权衡/产出/批判。
- 四证是读者侧验收，不新增自动闸口；S3 闸口仍由判分+关键能力+复述把关。

### 3.2 设计六问

1. **读者**：已会/未会什么？关键能力 1–3 项？前置是什么？
2. **目标**：本节要回答的 1 个核心问题；学完能迁移到什么？
3. **机制**：3–5 步因果/逻辑/证据链（记忆/约定可标机制豁免；设计用目标—约束—取舍链）；适用条件与边界反例。
4. **对比**：与哪个相邻方法易混？判别线索是什么？
5. **误解**：这个学员最可能信什么？为什么诱人？反证是什么？
6. **卡点**：最可能卡在哪一步？回看哪段/做哪题？

关键能力、边界、卡点并入六问答案，不新增第七问。

### 3.3 四段支架

| 段 | 学员做什么 | 支持 | 题量 |
|---|---|---|---|
| S1 教学例 | 读完整示例/示范（①–③；记忆用线索-目标例，概念用正/反例，设计用案例） | 全支持 | 0 |
| S2 配对 | 同构题，可回看教学例，不可看答案 | 可回看 | 1（配对自测） |
| S3 闭卷解释（在 ④/⑤ 之后） | 合上讲义 3 句解释 → 信心 → 对照 ⑤ | 无支持 | 0 |
| S4 评估例/迁移 | 换一个情境/条件，判断/执行 | 无支持 | 1（迁移自测） |

- **S1–S4 是学习段，不占用五要素编号 ①–⑤**；④ 始终是「易错」，⑤ 始终是「小结」。
- **④/⑤ 的位置**：易错（④）与小结（⑤）在配对之后、闭卷之前；闭卷解释用 ⑤ 作对照，再进评估例。四段指学习动作，不改变五要素槽位。

- 配对只换表面（数字/情境/措辞）；迁移只换一个维度（条件/问法/表征）；远迁移放章末/S5。
- 对话轮的逐块确认可复用配对题；复用时只计一次确认题量，不再重复计核心题量。
- 三型互动是②的可选变体：默认同构题；程序性可补全；找错只在已知误解后。

### 3.4 两道自测 = 配对 + 迁移

- 1 道配对执行 + 1 道迁移/判定；闭卷解释不占题量。
- 配对可回看教学例；迁移必须合上讲义；答案都在节末同族答案区。
- 自测 ≠ 题组；迁移题不与题组同题；答案三件套：答案 + 一句为什么 + 最常见错答；选择题逐项排除。
- 配对题可作某个关键块的正式确认题；迁移题留到节末，不作逐块确认。
- L3 复习产物例外见 §2.4。

### 3.5 闭卷自检

- 在 ⑤ 之后、自测之前写一行：**合上讲义，用 3 句话解释本节核心 → 自评 0–100% 把握 → 对照 ⑤ 补漏 → 做迁移题**。
- 这是阅读动作，不判分、不进闸口、不计题量；≤3 个/节（先猜/自解释/闭卷）。
- **先猜**：只在学员有相关经验/直觉时用；写一句猜测，读完回来对照；零基础改为“先看现象，读完回来解释”，不硬猜。**自解释**：在 1–2 个关键步写“遮住 ③、保留 ②，解释为什么这一步”，模型答案用 ②。
- 模型答案用 ⑤，不新增答案区；学员自评不写入 progress.md。

### 3.6 二次定稿

- **本节判分与复述完成后、状态转定稿前**执行；只回填**概念误解/过度泛化/方法选择/讲义缺口**，不因粗心回填。
- 回填位置：④真实症状+原因、反误解框、对比表一行、边界例、配对变体；每节 1–2 处。
- 不写学员答案/分数；用“换一个读者会不会也犯”判断是否讲义问题；不过度拟合单个学员。
- 留一句学习记录（≤120 字）说明补什么/依据；无错误则不改，草稿直接转定稿。定稿后在反馈里告诉学员补了什么（一句），不写分数。
- 定稿后纠错仍走“改回草稿（修订中）→ 修 → 重跑 → 定稿”。

### 3.7 关键能力对齐

- S3 的关键能力清单（或备课短表的 1–3 项）已定；每项至少有一次解释/示范、一次配对或自测、一次迁移/判定。
- 讲义 + 题组合起来覆盖即可；不要求讲义单独出很多题；**核心题量按 `assessment.md` 的题量预算**（关键块正式确认题另计，不设每节道数上限）。
- 若某项关键能力没有对应练习，先补练习；无法覆盖时停止当前运行并请用户明确修改目标/范围、重新确认计划，不得静默删除关键能力。

### 3.8 冷读四证

- 合上讲义、无导师提示，答四证至少 3/4；失败点要能映射到设计层（缺机制/缺对比/缺边界/缺练习），不归因学员。
- 模型自检只做结构；四证必须由真人读者完成。没有真人冷读时讲义停在草稿并停止当前运行，不定稿；不得用模拟冷读替代。补做后再复核失败点，通过才继续。该要求不新增脚本闸口。

### 3.9 条件触发

- 深讲/易混概念：加“同/异/判别线索”对比表 + 1 道“这题像哪例”；只对已知高信心误解加四行反误解框。
- 每个关键概念在定义槽位写一行“何时不适用 + 反例”（记忆可写易混项/适用范围；纯约定写适用课程/版本）；不要塞进 ④。
- 文本/图示按 §1 第 8 条；不新增每节必填项。

## 4. 类型模板（阶段 2）

### 4.1 类型判定

- **记忆**：要背、要列、要认；没有可推导的机制（术语表、年份、常数、清单）。
- **概念**：要解释“为什么/是什么/何时用”；有正例、非例与边界。
- **程序**：要按步骤执行；有条件分支、决策点与完成标志。
- **设计**：要在约束下选择、创造或评价；有多解、备选与权衡。
- S0 任务类型只作先验：知识型→记忆/概念；技能型→程序/设计；备考型→记忆/概念/程序；材料型→概念/设计（论证）。
- 混合类型：定**主导类型**；两种都需要独立证据时拆单元或加类型子块。类型标签写规划区，不塞进每个标题；`## 概念 N` 继续保留给脚本，正文可称“学习单元”。
- 判不清时直接问学员：“你要**记住、解释、执行，还是在约束下设计方案**？”不静默混用。

### 4.2 四类矩阵

| 类型 | ① 题目/任务 | ② 解析/过程 | ③ 答案 | ④ 易错 | ⑤ 小结 | 配对 / 迁移 |
|---|---|---|---|---|---|---|
| 记忆 | 记住什么、与什么区分 | 编码线索/记忆策略 | `答案：`/`答：`，或 `③ 不适用（纯记忆）` | 混淆/干扰 | 线索卡（≤7 条） | 回忆+辨别 / 新语境使用 |
| 概念 | 回答/判断什么 | 机制、正例、非例 | `答：`/`参考答案：`+模型解释+例/非例 | 过度泛化/假类比 | 判别句（是什么/何时用/何时错） | 解释+分类 / 新例或非例 |
| 程序 | 完成什么任务 | 决策点、为什么这一步 | `解：`/`步骤：`/`代码：`+输出（决策点/验证写 ②/④，不写框内批注） | 步骤/顺序/条件/单位 | 决策流程（先…再…；卡住看…） | 同构/补全 / 新条件执行 |
| 设计 | 设计/评估什么，约束是什么 | 权衡、备选、评价标准 | `方案：`/`设计说明：`+权衡+标准 | 忽略约束/单一指标/过早定案 | 权衡句（目标/约束/取舍） | 案例分析（改一个约束）/ 新约束或替代方案 |

- **类型决定证据形态，风格决定呈现，学科提供素材**。六套风格不扩；类型模板不是第七套风格。
- 类型化自测：配对 = 同构；迁移 = 只换一个维度；四证动词按 §3.1 调整。
- 类型化误区（预判）：记忆=线索混淆/干扰；概念=过度泛化/假类比/相邻概念混装；程序=步骤遗漏/顺序/条件/单位；设计=忽略约束/单一指标/过早定案。
- 类型化误区是**预判清单**；实际错因仍按 `teaching.md` 六类（未教/遗忘/误解/方法选择/执行偏差/过度泛化）诊断，不替代错因分类。
- 单元数按 §2.8：记忆 5–7 chunk、概念 5–7、程序 3–5 决策点、设计 1–3 案例。
- ③ 形态与标识按 §2.3/§2.2：设计用 `方案：`/`设计说明：`，接受多解+标准；概念用 `答：`/`参考答案：`+例/非例；程序用 `解：`/`步骤：`/`代码：`；记忆用 `答案：`/`答：` 或纯记忆豁免。
- 类型标签可选；tier 标签仍必须有；两者不要混成同一个标签。

## 5. 讲义生成四步流水线（阶段 2）

| 步 | 动作 | 产出/检查 |
|---|---|---|
| 分析 | 定类型 + 1–3 项关键能力 + 3–7 个子技能/决策点 + 专家盲点 + 前置 + 学习者状态 + 支持级 | 每个子技能有解释/示范/练习；新手最可能卡的那一步已单独解释 |
| 设计 | 定读者/目标/前置；答设计六问；选风格/学科素材；定教学例/评估例；定支持级 | 六问有答案；误解/边界/迁移明确；支持级与产物形态一致 |
| 生成 | 写四段支架；按类型填 ①–⑤；出配对/迁移；写答案三件套 | 配对同构、迁移只换一个维度；类型标记；不泄题 |
| 修复 | 真人冷读四证；跑脚本；二次定稿；质量回路 | 真人四证至少 3/4；0 E；只回填概念/方法/讲义缺口；无真人冷读则停止，不定稿 |

它与 `teaching.md` 备课短表**同源不同物**：短表定教学决策，本流水线定讲义产物；复用短表结果，不重复问学员。

### 5.1 分析：任务拆解与专家盲点

- 把目标能力拆成 **3–7 个子技能/决策点**；每个子技能逐条问：“新手在这里会不知道什么？我假设了什么？”
- 把**最大的假设缺口**补成解释或示例；每个子技能至少有一次解释/示范、一次练习或自测。
- 专家盲点优先于篇幅：专家自动完成的那一步，常是新手最需要的解释。
- 前置只列“缺了就无法完成当前目标”的；其他关联不当前置闸口。
- 学习者状态与支持级在此步定（§6/§7），不要等写完再补。

### 5.2 设计：六问、例子与支持级

- 设计六问见 §3.2；答案写进规划区或草稿，不要求成为学员可见字段。
- 先定**教学例**（最小典型、透明、可判别），再定**评估例**（真实/真题/学员场景，新情境）；评估例不是第二个完整教学例。
- 例子选择五判据：最小典型（不引入本节不需要的新符号/规则/背景）、可判别（含区分相邻方法的关键特征）、透明（例子与规则的对应关系清楚）、可变（配对换表面、迁移换一个结构维度）、有边界（一个看似适用但不适用的反例）。
- 学员有真实材料/项目时，评估例优先改造真实材料；没有则用最小典型例，不用复杂故事凑趣。
- 支持级按 §6 定；L2/L3 不必生成完整教学例。

### 5.3 生成：四段与类型化落点

- 四段：S1 教学例 → S2 配对 → ④/⑤ → S3 闭卷解释 → S4 评估例/迁移；详见 §3.3。
- 类型化 ①–⑤ 按 §4.2；两道自测 = 配对 + 迁移；闭卷解释不占题量。
- 答案三件套：答案 + 一句为什么 + 最常见错答；选择题逐项排除。
- 复杂程序/设计另加决策日志/修复表（§8）；简单记忆/事实不加。

### 5.4 修复：冷读、脚本、二次定稿

- 真人冷读四证（§3.8）至少 3/4；失败点映射到设计层，不归因学员；没有真人冷读就停止，不得定稿。
- 跑 `verify_explanation.py` 与出厂自检；E 项与 `W-UNICODE-CHAR` 清零（定稿硬项见 §2.11）。
- 本节判分与复述完成后、状态转定稿前做二次定稿（§3.6）。
- 质量回路（P1）：记录实际用时/心理努力/停在哪/哪个段落被错题击中/是否需要重教，供下一次调整支持级或拆段；升 L3 仍按 §6.1；独立讲义无 progress.md 时按 §10.6 省略、不新建。
- 流水线是同一轮内部流程，不额外占用学员轮次；不新增脚本闸口。与“出题四步流水线”分开：本流水线生成讲义，出题流水线生成题组。

## 6. L1/L2/L3 支持级（阶段 2）

| 支持级 | 判定证据 | 讲义形态 | 产物 |
|---|---|---|---|
| L1 新手/新技能 | 无独立成功证据；首次；高元素交互；零基础/入门 | 完整教学例 → 配对 → 闭卷 → 评估例 | 完整讲义 |
| L2 部分会 | 有部分独立成功（S1 部分对、伺服 70–90%、旧题对但慢） | 补全式教学例 → 独立 → 闭卷 → 迁移 | 补全式讲义（完整五要素） |
| L3 已会 | 独立成功稳定（S1 全对、伺服 >90%、跨会话持续正确） | 无完整教学例；3–5 题检索（至少 1 道新情境） | 检索版要点卡 |

- **按技能判，不按课程判**：课程整体进阶不等于本子技能已会；进阶者学全新子技能仍走 L1。
- 证据缺失：新/复杂内容默认 L1；复习/熟悉内容默认 L2；在讲义前置行写明假设，不假装知道。
- L2 用**补全式教学例**，不是“半截教学例”；③ 仍须；不追求多级渐撤。
- L3 用**检索版要点卡**：3–5 题优先复用旧题/题组，至少 1 道换情境/新问法；不作新判分证据；题区用 `## 本节自测`，答案区同族；L3 单元嵌在完整讲义里时标 `③ 不适用（已会·检索版）`。
- 题量与同题例外见 §2.4；支持级不是闸口，S3 仍由判分+关键能力+复述把关。
- 记录：学习日志/质量保障机制一句 `支持级：L2→L3（依据：…）`；不新增字段。

### 6.1 动态升降

| 当前 | 证据 | 下次 |
|---|---|---|
| L1 | 关键能力独立通过 + 连续 2 次独立成功（可同会话） | L2 |
| L2 | 关键能力独立通过 + 伺服 >90% + 至少一次跨会话独立成功 | L3 |
| L2 | 关键能力失败 / 提示后才过 | L1 |
| L3 | 检索或迁移失败 | L2 |
| L3 | 连续 2 次跨会话独立成功 | L3 保持 |

- L1→L2 是**支架渐退**，同会话独立成功可用；L2→L3、L3 保持要求跨会话独立成功（存储强度），同会话重复答对不单独升级。
- 冲刺模式不因时间压力跳级；新题型/新技能仍按证据定级。
- 同一会话重复答对不单独作为升级到 L3 的证据；S/D 也不因同会话重复增长（同会话抑制）。
- 同一子技能第二次仍不会 → 继续给支架，不按“出现次数”硬撤。

## 7. 学习者状态层（阶段 2）

| 来源 | 怎么用 | 禁止 |
|---|---|---|
| KP 状态（未讲/已讲/暂缓/排除） | 未讲→L1；暂缓→不写或标选学；排除→不写；已讲按已会证据决定 | 把“未讲”当“不会”或“已会” |
| 已会证据（S1 全对/伺服>90%/跨会话连续正确） | 已会→L3/压缩 | 把“没否认”当已会 |
| 薄弱点/错题本/保持复习 | 选误解、对比、配对；优先真实错因 | 把一次粗心写成概念误解 |
| 本次交接/学习记录/画像 | 类比领域、沟通偏好、稳定模式 | 把“没否认”当已会 |
| 本次 S1/S3 证据 | 支持级、起点、伺服 | 用课程整体起点替代本技能证据 |

**已会不是 KP 状态**：KP 状态只有未讲/已讲/暂缓/排除；已会证据来自 S1/伺服/连续正确/学员确认，不写进状态列。

- **确证铁律延伸到讲义**：`【已会·可跳过】` 必须带证据/日期；`【薄弱·重点】` 必须来自判分/错题；没有证据就不打标签。
- 标签可选：写规划区或单元旁，不铺满正文；与内容分层（最小必需/选学/参照）正交。
- **先预判真实错误**：六问里的“高信心误解”优先用这个学员的错因，其次才是通用误区；能在草稿里加反误解/辨析，不等二次定稿。
- 独立写讲义无画像：写明读者假设 + 前置自检，不打个性化标签，不假装知道学员已会什么。
- 一个单元映射多个 KP 时，按 KP 分别取状态；不要把“一个 KP 已会”当成整单元已会。

## 8. 决策日志与修复表（阶段 2）

适用于复杂程序与设计类；简单记忆/事实不加。

- **② 决策日志**：在关键决策点写 2–4 行“看到什么 → 先想到什么 → 为什么放弃另一个 → 怎么检查”。不是完整内心独白，只展示选择、放弃和验证。
- **④ 修复表**：每行 `症状 → 最可能原因 → 现在做什么 → 怎么验证修好了`；2–4 行，至少一行能对上 ② 的某个决策点。
- **设计类**：决策日志展示目标/约束/备选/取舍/评价标准；修复表展示“忽略约束/只优化一个指标/过早定案”的失败模式与修法。
- 表和日志是**附件**，不占 ④/⑤ 的 ≤3 句摘要；单元仍要有一句摘要（§2.9）。
- **③ 框只放成品答案**：决策点/修复/验证说明放 ②/④；程序类成功标志用 `输出：` 作为交付段，不写 `验证：` 这类框内批注。
- 示例（备份方案设计）：
  - 决策：先满足恢复时间 → 比较成本 A/B → 选择增量备份；放弃全量备份。
  - 修复：若恢复时间超标 → 检查是否漏了增量链 → 重算恢复步骤 → 用演练验证。

## 9. 来源、范围与评估真实性（阶段 3）

### 9.1 四向对齐

- **内部矩阵**（家教/规划侧）：来源小节 | KP | 讲义单元 | 深度 | 自测/题组 | 状态。
- 每个讲义单元至少有一个来源锚点（页码/章节/图号/表号/数据位置），或标“原创/改编自 p.X”。
- 每个自测/题组映射到 KP/关键能力；允许一单元→多 KP、一 KP→多单元（§2.5）。
- 四向对齐要能回答：来源哪段 → 对应哪个 KP → 写在哪个讲义单元 → 哪个自测/题组考它。
- 题组考了但讲义没讲 → 补讲义或移出题组；来源漏了但没写暂缓 → 补覆盖行（§9.2）。
- 矩阵是内部/家教侧；学员讲义只留一行覆盖声明 + 必要锚点，不塞整张表。
- 不新增 progress.md 字段：复用对照源、材料覆盖、KP 清单、题组。

### 9.2 覆盖行与暂缓/范围外

- 讲义头部或末尾（有 `## 扩展（选读）` 时放在其前）写一行：
  `- 覆盖：来源 3.1–3.2（KP-01/02）；暂缓：3.3（原因）；补充：原创例 1 个；范围外：3.4（原因）`
- 这行是 SR-7“静默断章/静默裁剪范围”的合规出口：不写暂缓/范围外，就等于暗示“已经讲全”。
- 暂缓与范围外的唯一事实源仍是 progress.md；讲义行是派生显示，不改数据。独立写讲义无 progress.md 时，这行就是唯一记录。
- 来源缺失、读不到、与目标无关：写“未覆盖/暂缓/范围外 + 原因”，不静默跳过。
- 覆盖行不写分数、判分记录或内部调度信息。

### 9.3 深度分配

| 任务类型 | 深度依据 | 分配 |
|---|---|---|
| 备考 | 真题分值/频次/考纲 | 高频高分→深讲/工作；低频→参照；范围外→扩展/暂缓 |
| 知识型 | 依赖度/下游节数/迁移价值 | 高依赖/多下游→深讲；孤立→参照 |
| 技能型 | 真实任务频率/失败代价 | 高频/高代价→深讲；低频→参照 |
| 材料型 | 材料结构/作者权重 | 核心论证→深讲；枝节→参照 |

- 深度用现有分层标注：深讲/工作/参照；不平均用力。
- 若所有概念都标“最小必需”，先重查证据；不要把“全讲”当负责。
- 深度分配与题量预算一致：深讲多练、参照少练，不靠加题补密度；**核心新题按 `assessment.md` 的题量预算**（关键块正式确认题另计，不设每节道数上限）。
- 用户 `目标程度` 与证据冲突时，用户目标优先，并写明取舍。
- 深度分配是内部决策，不新增字段；可在规划区/覆盖行标注。

### 9.4 教学例 vs 评估例：来源真实性

- 教学例：最小典型、透明、可判别；可原创/简化，标“改编自 p.X”。
- 评估例：优先来源原题/真题/学员真实任务；换新情境；不是第二个完整教学例；答案三件套。
- 备考型：每个高权重小节至少 1 个来源原题/真题风格的评估例；用考试题型/分值/格式，不用通用例子替代。
- 非备考：用学员真实场景或现实情境；没有真实材料时用最小典型迁移。
- 来源例子太密：教学例可简化，评估例保留来源真实性；不要把来源例子同时当教学例和评估例。
- 来源例子有误/过时：写明并修正，不静默沿用。

### 9.5 来源保真

- 每个单元/示例记来源锚点：页码/章节/图号/表号/数据位置；原创/改编明确标注。
- 简化可以改语法/数字/背景，不得删适用条件、单位、例外；写明简化了什么。
- 引用原文不超过本单元两成；其余转述并标锚点；不伪造引文/链接/权威背书。
- 来源冲突：并列两说，写选择理由与日期；不静默取一个。
- 来源过时：标版本/年份；考试/考纲变化时说明；无法核实标“未核实”。
- 来源不可得：不得把推测写成事实；先按已知讲并标不确定性。

### 9.6 模块目标与考试对齐

- 每个讲义小节映射到 S2 的一个模块目标与 1–3 项关键能力；映射写规划区/覆盖行，不新增必填头部字段。独立写讲义无 S2/progress.md 时，用讲义目标 + 覆盖行作模块目标记录，写读者假设，不伪造 progress.md。
- 备考型：在覆盖行或评估例旁标考频/题型/分值；答案格式/单位/有效数字按考试口径；不编造官方分值。
- 非备考：迁移目标对齐学员目标/真实场景；不把“覆盖教材”当目标。
- 模块目标/材料覆盖的唯一事实源仍是 progress.md；讲义只引用，不复制记账。

## 10. P1 质量与运营（可选增强）

P1/P2 是可选增强；按需启用，不改变 11 条硬合同。

### 10.1 文本结构

- 按内容选一种：序列（程序/时间线）、比较（易混概念）、因果（机制）、问题—解决（设计/排错）、主张—证据（论证文）。
- 长节（按 §2.10 阈值）在节首导读之后、第一个概念单元之前给 3–5 节点结构图/路线（可写成正文段落，不另起 `##`）；用标题/信号词标结构（先…再…；因为…所以…；不同于…；如果…就…）。
- 不把所有讲义写成“定义→例子→易错”；结构要和类型 §4 一致。
- 只改组织，不新增风格。

### 10.2 主张—证据表

- 理论/人文/经验主张可用小表：`主张 | 证据/来源 | 强度/边界`。
- 强度标：已验证/方向支持/争议/未核实；来源锚点按 §9.5。
- 区分作者主张、作者证据、我的判断；不把断言写成事实。
- 只用于有外部证据的主张，不用于程序步骤；学员版放正文，需要补充时放 `## 扩展（选读）` 区，不另起附录。

### 10.3 设计类评价量表

- 设计/开放任务用“标准 + 水平”，不用单一答案。
- 标准：问题界定、约束覆盖、备选、权衡、可行性、表达。
- 水平：未达/部分/达标（或 0–2）；合计可选（有分值+合计时须相加一致）；非官方细则标“训练量表”。
- 参考方案 + 标准；接受多解；不编造官方分值；与设计 ③ `方案/设计说明` 配套。

### 10.4 按类型选主图

- 记忆：时间线/地图/表；概念：概念图/对比表/因果图；程序：流程图/决策树；设计：权衡矩阵/架构图。
- 每单元最多 1 张主图；图注说结论、标注内嵌、alt 非空、颜色+线型；不用装饰图。
- 文字更清楚就不配图；不强行每节画图。仍按图像双轨落盘/引用。
- 单图语法（图 brief、节点预算、边/标注、颜色对比、SVG 技术要求）见 `handout.md`「读者版可读性契约」第 4 条；跨单元/跨节一致性见第 10.11 节。

### 10.5 效用价值提示

- 一句“学完这个，你能解决…/避免…”，绑学员目标/画像；不写“很重要”。
- 不是趣闻、不占大段；没有具体用途就省略。
- 可放节首导读之后或节末，作为独立一行，不并入 ⑤ 三句；不新增必填行。

### 10.6 质量回路

- 每节后可选记：实际用时、心理努力 1–5、停在哪、哪个讲义段落被错题击中、是否需要重教。
- **读者验证四问结果**（30 秒扫读 / 2 分钟回看 / 375px 窄屏 / 黑白打印）随质量回路记：通过项、失败点、对应设计层（结构/图/标题）；失败先改设计，不归因学员、不加题量。
- 用现有质量保障机制/学习记录，不新增字段；不写分数；记在 progress.md 记录侧，不写进定稿讲义；独立讲义无 progress.md 时省略，不新建。
- 努力高+错题集中→下次加支架/拆段；努力低+掌握高→下次可压缩/加迁移题，升 L3 仍按 §6.1 的跨会话证据，不凭一次低努力跳级。

### 10.7 要点卡与间隔复习

- 普通要点卡：⑤ 小结（按类型：概念判别句/记忆线索卡/程序决策流程/设计权衡句）+ ④ 易错；只留结论/适用条件/一个易错点（记忆线索卡按 §2.9 可到 7 条），不塞自测题。L3 检索版按 §6 的 3–5 题（至少 1 道新情境），不压成 1 题。
- 独立讲义/结课清单按 1/7/30 写绝对日期；陪学任务内按现有 `## 保持复习` 条目交给 scheduler/due-queue，以条目级 due 为主，不另造 1/7/30 双轨。
- 不新增 schema；要点卡不改写定稿正文。

### 10.8 移动端与 MVP

- 移动端：表格 ≤4 列、必须有表头、单位写表头；宽表拆列表；代码块可滚动；SVG 用 viewBox/自适应、图内文字不小于 14px；短图注；不用深色底；黑白打印/去色后仍可读。
- MVP：时间紧时保“核心解释段（按类型：概念机制/记忆线索/程序决策/设计权衡）+ 教学例 + 一个易错 + 小结 + 2 道自测”；其余标“本次略”；不省答案/核心推导。
- 可选；不因 MVP 跳过 S3 闸口。

### 10.9 问题停车位/贯穿案例/难度预算

- 问题停车位：讲义末尾 `## 待解决问题`（有 `## 扩展（选读）` 时放在其前，扩展区仍是最后区；若写 `## 回看索引`，放在 `## 待解决问题` 之前），学员写 1–2 个没弄懂的问题；下次课首接进热身/交接；不判分。
- 贯穿案例：多概念小节可用一个案例逐步演化；只用于教学例，评估例换情境。
- 难度预算：每节 1 道“够一够”的迁移题，其余建立成功体验；不整套都难。

### 10.10 读者路径与三层速览

P1 可选；不新增必填字段/闸口，旧讲义不回溯；短节可省略速览与回看索引。**默认不变量（标题导航/段落/图解语法）按 `handout.md`「读者版可读性契约」执行，不因本节 P1 未启用而豁免**；支持级与类型变体见同节表格。详细版式规则见同节。

- **三遍路径**：30 秒扫读（标题/导读/`## 本节速览`）→ 10 分钟精读（概念单元默认顺序）→ 2 分钟回看（`## 回看索引`）。
- **`## 本节速览`**：节首导读之后、`## 概念地图` 与第一个 `## 概念` 之前；同时有地图时**先速览、后地图**；3 列表 `要解决的问题 | 一句话结论 | 用在哪`，1–3 行，对应 1–3 项关键能力；只压缩，不引入新知识、不写答案。短节可省略。
- **`## 回看索引`**：自测答案区之后、`## 待解决问题` 与 `## 扩展（选读）` 之前；3 行 `核心一句话` / `最容易错` / `下一步`；指向 ⑤、④ 或某道自测，不复制整段。短节可省略。
- **标题即导航**：`## 概念 N · <一句话主张>`；三级标题只在单元内部超过一屏时用；层级 H2→H3，不跳级。
- **章级**：教材级章首在节首导读之后加大问题 + 3–5 节点路线图 + `## 本章速览`（可选，同本节速览格式）；章末用 `## 本章回看` 汇总核心、易错、术语表与混合检索入口（对应 11.1）。
- **不替代**：速览/回看索引不替代 ①–⑤、概念地图、自测与 ⑤ 小结；与 ⑤ 冲突时以 ⑤ 为准，速览只做索引。

### 10.11 图表系统与视觉一致性

P1 可选；单图语法见 `handout.md`「读者版可读性契约」第 4 条，本节管跨单元/跨节一致性。

- **一章一套视觉语法**：节点形状、箭头、线型、颜色含义全章一致；默认中性色 + 1 个强调色，领域语义色按领域惯例；换含义换形状/标签，不只换颜色。
- **图目预算**：每单元最多 1 张主图；一章主图数不超过概念单元数；同一图不重复贴，改用「回看第 N 节图」指针。
- **图表清单**：章首规划区或章末可附 `图号 | 回答什么问题 | 类型 | 用在哪节`；无图不建表。
- **一致布局**：总览图统一方向（自上而下或从左到右）；细节图沿用总览的节点命名与颜色语义；跨节术语/符号一致。
- **黑白/窄屏**：去色后仍可读；手机宽度不横向滚动；宽图拆两张或改表；图内字号取 `max(14px, 0.8×正文主题字号)`。
- **图注/alt**：图注说结论；alt 写「图型 + 结论」；同一图多处引用时图注按上下文重写结论。
- **不装饰**：不加图标、阴影、3D、背景纹理；装饰性元素按 coherence 原则删除。

### 材料型按材料结构分流

### 1. 三遍路径

- **30 秒扫读**：标题 + 节首导读三行 + `## 本节速览`（长节；放在节首导读之后、第一个 `## 概念` 之前；若同时有 `## 概念地图`，先速览、后地图）。读者只看这三处，应能说出「本节解决什么问题、一句话结论、什么时候用」。
- **10 分钟精读**：按默认顺序读概念单元；每个单元只承担一个主问题；完整深讲软默认 1 个，可按关键能力需要增加；图放在它解释的段落之后，不先甩图再解释。
- **2 分钟回看**：读 `## 回看索引`（长节；放在自测答案区之后、`## 待解决问题` 与 `## 扩展（选读）` 之前）：`核心一句话` / `最容易错` / `下一步` 三行；指向 ⑤、④ 或某道自测，不复制整段。

`## 本节速览` 用 3 列表：`要解决的问题 | 一句话结论 | 用在哪`，1–3 行，对应 1–3 项关键能力；只压缩，不引入新知识、不写题目答案。概念地图与速览可并存：速览给「读什么」，概念地图给「概念之间怎么连」。

### 2. 一段一义，先结论后展开

- **单元首行先给结论**：长节/读者版在每个概念单元标题后第一行写 `- 一句话结论：……`（P1；不替代定义、机制与边界，只做导航）。短节、纯概念、参照级、L3 检索卡可省略；省略时不要把 ⑤ 小结改写成第二份结论。
- **一段一义**：一段只说一个观点；第一句先给结论或判断，再给依据；超过约 5 行先检查是否混入第二个观点，混入就拆段。同一推导必须连续时保留，不为拆段切断必要推导。
- **一句一判断**：一句只下一个判断；长定语拆成短句；主语与谓语靠近；少用名词堆叠；不用双重否定。必要推导可长，但不要一句里塞三个转折。
- **实义动词**：少用“进行/对于/关于/通过……来”等空壳结构；能写“算出/比较/排除”就不写“进行……”。术语首现给白话；数字带单位与口径。
- **列表 / 表格 / 正文分工**：并列 ≥3 项用列表；≥3 个属性的对比用表；有先后顺序用编号列表；因果、机制、论证用正文，不硬拆成项目符号。只有一项不列表，只有两列不造表。
- **表格**：有表头；单位写在表头；不合并单元格；数字列尽量右对齐；表题/图注说结论，不写「如下表所示」。移动端列数上限见 `handout.md` 第 10.8 节。
- **代码**：代码块给可复制的最小片段；行宽尽量 ≤80 字符；紧接 `输出：` 或成功标志；长输出只留关键行。

### 3. 标题、强调与留白

- **标题即导航**：`## 概念 N · <一句话主张>`，主张写「解决什么/判别什么」，不写「概念 2」「其他」「补充」；三级标题只在单元内部确实超过一屏时使用；层级 H2→H3，不跳级。
- **强调配额**：加粗只给术语首现、关键判断、易错点；连续两段不要都用加粗制造重点膨胀，术语密集段可例外；不用全大写、斜体、下划线、彩色字来强调；不用装饰性 emoji、符号或分隔线堆气氛。
- **留白是结构信号**：标题、列表、表格、代码块、图片前后留空行；不写「文字墙」；同一屏只留一个视觉焦点（本节速览、一个主图或一个答案框，不并列争抢）。
- **术语一致**：同一概念全节同名；缩写首现给全称；中文标点用全角，英文/数字用半角；公式与符号按 `formulas.md`。

### 4. 图解语法

- **先写图 brief 再画**：`图型 | 回答什么问题 | 节点/关系 | 读图顺序 | 结论`。写不出结论就不画；文字更清楚就不配图。
- **一图一问**：一张图只回答一个问题；一次呈现的节点 ≤7±2，超过先分组或拆图；完整概念图可以更多，但必须分层/分组并给读图顺序。总览图用层级/流程布局，不用随机网络；概念图要有明显的主干与分组，低显著性的散点布局会增加迷失感。
- **边与标注**：箭头表示方向；实线 = 确定/主路径，虚线 = 可选/弱关系；每条关键边有文字标签；优先在图内直接标注，图例只用于 ≥3 类。
- **颜色与对比**：默认中性色 + 1 个强调色；领域语义色（化学/地图/电路）按领域惯例，但颜色必须同时配形状、线型或文字，**不得只靠颜色编码**；文字对比 ≥4.5:1，图形/线条 ≥3:1；深色字浅色底，SVG 自带浅色底（不依赖透明背景），不用深色背景。黑白打印或去色后仍能读懂。
- **SVG 技术要求**：`viewBox` 自适应；`role="img"`、`<title>`、`<desc>`；图内文字 100% 视图不小于 14px；线宽 ≥1.5；不引用外部脚本/字体/图片；窄屏不横向滚动，标签不旋转。
- **alt 与图注**：alt 示例——方括号内写「图型：一句话结论」，圆括号内写图片文件名；不写「示意图/图片/文件名」；图注写结论与「示意/按比例」；正文讲机制、图注给结论、alt 给图型+结论，**不把同一句复制三遍**；图与文字逐面板核对，图文不一致时以领域事实为准，先修图再继续。

### 5. 可读性自检（5 问，定稿前）

1. 30 秒内只看标题、导读（如有速览也看），能说出本节解决什么、结论是什么？
2. 段落是否一段一义、句子是否一句一判断？若启用 P1，概念单元第一行是否先给结论？
3. 列表/表格/正文是否选对？表格有表头、列数符合移动端上限吗？
4. 标题是否带信息、层级连续？连续两段是否都在用加粗抢重点？
5. 黑白打印、手机窄屏、去色后是否仍可读？

**读者验证四问（人工，定稿前）**：① 只看标题/导读（如有速览也看），30 秒内能否说出本节问题、结论、用途？② 隔天只看标题 + 回看索引，2 分钟内能否重建核心、易错、下一步？③ 手机 375px 宽是否无横向滚动、无过小图字？④ 黑白打印/去色后，主线、支线、重点是否仍可区分？四问失败时改结构/图/标题，不加题量。

### 6. 无障碍语义（默认不变量）

- **链接文字**：写清目的（如「二分法步骤表」），不写「点击这里/这里/链接/点我」；裸 URL 只放参考资料区。
- **公式**：关键公式/符号配一句文字解释；不能只给 LaTeX 让屏幕阅读器读；排版按 `formulas.md`。
- **代码**：围栏标语言；命令可复制；输出块写结果或成功标志。
- **表格**：速览表由 `## 本节速览` 承担表题；其他数据表加一句表题；有表头；单位写表头；不合并单元格；不用颜色单独表示状态。
- **标题与图**：标题层级连续；图片 alt 非空；颜色+形状/线型/文字三重编码；黑白/去色可读。

**渲染建议（非强制）**：正文字号 16–18px、行距 1.5–1.8、深色字浅色底、左对齐；宽屏连续正文控制在约 25–40 个汉字/行，最长不超过 48 个汉字/行。中文行长研究存在冲突（另有技术文本偏好 76 字/行的报告），本技能取保守区间，不把 76 当默认。

## 标准讲义（默认）

- 适用：绝大多数知识型小节。
- 骨架（〔〕= 槽位落点；六套风格都按此逐个指认，漏槽位即不算讲完）：概念〔定义/规则 + 一句机制/边界〕→ **类比（有合适类比时才用；无则改准确定义 / 实例 / 图示）〔按需表示，可省〕** → **教学例〔① 题目 ② 解析 ③ 答案〕（worked example；最小典型、透明）** → **配对练习〔配对自测：同构题，可回看教学例，答案放节末〕** → 易错点〔④：症状 + 原因 + 补救〕→ 三句话小结〔⑤ 小结：≤3 句、不引入新信息；优先写判别句〕→ **闭卷自检（阅读动作：3 句解释 → 信心 → 对照 ⑤）** → **评估例/迁移〔迁移自测：真实/新情境，答案放节末〕**。题区写 `## 本节自测`，题前固定一行「先独立做完，再看本节自测答案」——提示语里不写「③ 答案」字样，避免被当成③标记行；答案统一放 `## 本节自测答案` 区，短答案合法、可短但不得写「略／见教材／同上」，不属五要素之③。顺序与「讲义概念单元 schema · 默认顺序」一致；四段细节见 `handout.md` §3.3。配对题写在教学例后（配对自测）；`## 本节自测` 区放迁移题（迁移自测），也可两题都放；两题答案统一放 `## 本节自测答案`。**类型矩阵见 `handout.md` §4**：记忆/概念/设计按矩阵替换 ③/⑤/自测形态；**L2/L3 可不出完整教学例**（§6），不违反“教学例只用一个”。
- **教学例判据（完整示例；适用于含解题/操作/作答过程的概念；五要素缺一不算讲完）**：①题目（**要解决的问题或要完成的任务**：题目型写题干要点——要你做什么、产出什么、交付给谁看；纯概念 / 纯记忆 / 参照级没有题干，写「本节要弄清楚什么」即可，不编造题目。题目只在这里写一次，答案框内不再重复）；②解析（方法与关键判断：每步做什么、为什么这么做、哪一步最容易错，以结论收尾）；③答案（**参考解答**：可整体誊抄的规范卷面，完整可复现即可，不排斥等价解法）；④易错（本例最容易错的一步，症状 + 原因）；⑤小结（≤3 句，只压缩不新增）。**含解题/操作过程时③必选**；纯概念/纯记忆没有可复现产物时**③ 框可省，但标记行不可省**：须在概念单元内显式标注 `③ 不适用（纯概念）` 或 `③ 不适用（纯记忆）`（下称「③ 空位豁免」，与深度契约的「机制豁免」不是一回事），同时豁免②③，①题目、④易错、⑤小结仍须具备——④ 写进「易错点」槽位即可，不依赖完整示例；标记行放在③位置、正文叙述里不重复该字样，避免误判；单元须有正反例或等价表示；**参照级单元**标 `【参照】` + `③ 不适用（参照级）`，豁免 ②③④⑤、只需 ①题目，定义与边界写在正文。**③ 框的形态**：从交付起笔到结论/产物收笔的完整、可复现答案，**框内不写题面段**（题目已在①），按**最小单元**分段（一段一个可独立核对的最小单元，各族形状见下条「框内分段」）。交付起笔按学科族取形态——数学/理科 `解：`/`证明：`，文科 `答：`/`参考答案：`/`方案：`/`设计说明：`，语言 `参考答案：`/`参考译文：`/`范文：`/`Model answer:`/`Sample answer:`/`Translation:`，精读 `参考概括：`（收尾 `原文定位：`），编程/工具 `代码：`/`脚本：`/`输出：`/`Code:`/`Script:`/`Output:`（代码块本身即可交付，须给运行结果与成功标志），技能/实验 `步骤：`/`操作：`/`Steps:`（须给成功标志），记忆/客观 `答案：`/`Answer:`/`Key:`，英文材料 `Answer:`/`Solution:`/`Proof:`/`Model answer:`。**标识清单、分点与代码块规则见「讲义概念单元 schema · 答案框体例」与 `handout.md` §2.3**——不把某一学科的写法当通用标准。备考/阅卷型任务按已声明的给分点书写并可整体誊抄，非备考任务按可提交/可复现格式书写，不虚构评分细则——②讲「为什么这么做」，③示范「卷面长什么样」，在已声明评分口径下覆盖必要步骤（备考/阅卷型任务学员照抄③应能得分）。涉及新记号/新操作的示例另须满足「新记号/新操作讲透」三件套（见下）。
- **教学例 vs 评估例（四段支架）**：①–③ + 配对用**教学例**（最小典型、透明、可判别；可原创/简化并标「改编自 p.X」）；迁移自测用**评估例**（优先来源原题/真题/学员真实任务，换新情境；**不是第二个完整教学例**）。评估例的答案用答案三件套（答案 + 一句为什么 + 最常见错答），不写成第二个 ③ 示范盒；备考型至少每个高权重小节有 1 个来源/真题风格的评估例。
- 写作要点：**深讲概念先按「深度契约」定层（D/P/M/H/B/C）再动笔**；零基础首次按「现象→符号引入序」。类比**优先取自学习者画像的类比领域**（无画像则贴学员场景），且**仅在类比真能说清时才用**——新内容没有合适类比时改用准确定义 / 实例 / 图示，**不强凑生活故事**（衔接 `teaching.md` 第 3 节「无同构可撬则跳过、不硬凑类比」）；**教学例只用一个、做完整**——宁可少讲半个概念，不可给半截教学例（L2 补全/L3 检索版按 `handout.md` §6，不受本句限制）；**评估例是迁移任务，不是第二个完整示范**（见 `handout.md` §3.3）；误区写「症状 + 原因」而不只写结论；**术语首次出现给一句白话或定义**，不假设学员已知、不依赖未提供的材料。
- 成品范例（供导师对照格式与密度，非讲义内容；本例为【本节最小必需】级；其余族的段结构见 schema「其余族的最小形态」）：
  > **概念：解一元二次不等式（图像法）【本节最小必需】**
  >
  > - 概念：解 ax^2+bx+c>0，本质是找「抛物线在 x 轴上方」的那段 x 范围。
  > - 类比：抛物线像一座拱桥，>0 就是桥面以上的部分。
  > - ① 题目：解不等式 x^2−x−6>0。
  > - ② 解析：先解 x^2−x−6=0，十字相乘 (x−3)(x+2)=0，得 x=3 或 x=−2；开口向上（a=1>0），两根之间 y<0、两根之外 y>0，故解集为 x<−2 或 x>3。
  > - ③ 答案（可整体誊抄）：
  >
  > > 解：由 x^2−x−6=0，十字相乘得 (x−3)(x+2)=0，解得 x_1=−2，x_2=3。
  > >
  > > ∵抛物线 y=x^2−x−6 开口向上，与 x 轴交于 x=−2、x=3，∴原不等式的解集为 x<−2 或 x>3。
  >
  > - ④ 易错：忘判开口方向；把 >0 的解集写成两根之间（那是 <0 的），开口向上时 >0 取两根之外；Δ<0 只说明无交点，开口向上时 >0 恒成立（解集为全体实数），不是「无解」。
  > - ⑤ 小结：①先解对应方程；②看开口定内外；③解集用区间写全。
  > - 自测：①解 x^2−4>0；②判断 x^2+2x+3>0 的解集。（答案见本节自测答案）

## 费曼卡

- 适用：抽象概念；用户复述总卡壳的小节；复习时重讲。
- 骨架：①题目〔要讲清什么问题，如「$\pm$ 到底怎么读」〕→ 一句话大白话定义〔定义/规则〕→ 为什么重要（1–2 句）〔按需表示·动机，可并入①〕→ 讲给 12 岁孩子听的版本〔② 解析：是什么 → 怎么用 → 哪里会错，可并成一段但三步不得缺〕→ 一个类比〔按需表示；说清哪里像、哪里不像〕→ 反例〔④ 易错：什么不是它 + 最容易错在哪〕→ ③ 答案〔「最容易怎么用错」的对照答案，可只给关键句；纯概念标「③ 不适用（纯概念）」〕→ 一句话回收〔⑤ 小结：≤2 句、不引入新信息；不复述开头定义，只做压缩〕→ 自测〔检验：请用户不看卡复述〕。
- 槽位下限：①③④⑤ 各一行即可（费曼卡靠短取胜，不为凑槽位扩写）；② 由 12 岁版内部的三步承担。**③ 与 ⑤ 分工**：③ 收住「怎么用才不错」的成品答案，⑤ 收住「怎么记、什么时候用」，两句不得同义重复。
- 写作要点：**短而完整**——句句白话、紧凑，但不以字数截断（密度口径见「讲解文本密度原则」）；禁用行话，术语首次出现随即给白话替换。自测若只做口头复述（无书面答案），且单独写成 `## 自测` 区，须在该区首行写 `- 检验说明：口头复述，无标准答案`，不要留空答案区。

## 考试冲刺卡

- 适用：备考型任务的考点小节；结课前总复习。
- 骨架：①题目〔本卡对应的题型与分值，一句〕→ 本节考点清单（按考频标注★）〔定义/规则 + ② 的取材面〕→ 高频题型与解题步骤模板〔② 解析：第一步 / 第二步，可照抄〕→ 易错点（含扣分点提示）〔④：写「症状 + 扣哪分」〕→ 秒杀技巧或口诀〔⑤ 小结：≤2 句、只压缩不新增〕→ 3 道真题风格题〔检验〕→ 详解〔③ 每题答案，按答案框格式写，备考型附给分点量表〕。
- 槽位下限：考点清单 + 步骤模板 + ④ + ⑤ + ③ 缺一不可；口诀不得引入清单外的新知识点（它只是压缩）。
- 写作要点：解题步骤写成「第一步/第二步」可照抄的形式；题目难度对齐用户的目标考试；不引入超纲内容。

## 对比辨析卡

- 适用：一对易混概念（触发信号：薄弱点出现「分不清 X 和 Y」）。
- 骨架：①题目〔要判定的问题：什么场景下该用 A、什么场景该用 B〕→ A/B 一句话定义并排〔定义/规则〕→ 对照表（适用条件 / 典型场景 / 关键差异，≥3 行）〔按需表示 + ② 的判定依据来源〕→ 易混陷阱〔④：最常把 A 的哪条特征错安到 B 上〕→ 判别口诀〔⑤ 小结：≤2 句、只压缩不新增〕→ 各一道辨析题〔检验；③ 答案 + 判定依据〕。
- 槽位下限：② 由对照表的「关键差异」逐行承担（能照着逐条比对即可，不另写流程段）；④ 必须是**一条具体误判**，不写「注意区分」这类空话。
- 写作要点：对照表先行；口诀 ≤2 句；两道题各埋一个「看起来像另一个」的陷阱。

## 操作手册式

- 适用：技能型任务（编程、工具、软件操作）。
- 骨架：①题目〔要完成的操作与预期成果〕→ 环境与前置〔按需表示〕→ 分步操作〔② 解析〕→ ③ 答案〔`步骤：`/`代码：` + `输出：` 成功标志，代码/命令可复制、逐行注释〕→ 常见报错与修复（≥2 条）〔④：报错原文特征 → 原因 → 修法〕→ 关键决策三句话〔⑤ 小结：先做什么 / 卡住看哪条报错 / 什么算做成，≤3 句〕→ 练手任务（改错 / 仿写 / 微项目三选二）〔检验〕→ 完成检查清单。
- 槽位下限：④ 的每条报错必须是**本操作真会遇到的**（能对上②里某一步），不写「权限不足」这类泛泛报错凑数。
- 写作要点：每步可独立验证并给出「成功标志」；报错条目写「报错原文特征 → 原因 → 修法」。练手任务以成功标志判定，若单独写成 `## 检验` 区，须在该区首行写 `- 检验说明：练手任务，按成功标志自评`。

## 精读笔记式（论证文材料默认）

- 适用：材料型任务中**有「主张—证据」结构**的论证文（论文 / 评论 / 著作章节；「带我读 X」「精读 X」「帮我啃 X」多属此类）——有原文、目标是读懂作者在说什么，而不是掌握一个可计算的概念。条文 / 手册 / 代码库 / 数据表不走本式，按本册「材料型按材料结构分流」改用标准讲义或操作手册式。
- **单元 = 一个论证块**（一章 / 一节 / 一组自然段）：标题写该块的主张一句话，编号沿用 `## 概念 N · …`（脚本与闸口按同一单元处理，不另设第二套 schema）。
- 骨架：**① 题目**（这块要回答的问题 / 读完能复述什么）→ **块定位**（原文位置 + 这块在整篇里干什么：提出 / 支撑 / 反驳 / 收束）→ **② 解析：读法**（先拆结构骨架与证据强度 → 再抠关键术语 → 最后合上原文复述）→ **结构骨架与证据强度**（3–6 条：主张 → 证据（数据 / 案例 / 引文 / 推理，标原文位置）→ 让步或反驳 → 结论；每条注明「已证」还是「只是断言」）→ **关键术语**（术语｜原文用法｜一句白话｜易混点）→ **④ 易错**（断章取义、把作者转述的观点当成作者主张、旧译名混淆）→ **③ 答案**（参考复述的可誊抄版：`参考概括：` 起笔 + 末段 `原文定位：`；学员先写自己的版本再对照）→ **⑤ 小结**（≤2 句：主张 + 最强证据的压缩，供隔周回看定位）→ **检验**（2 道：这块的主张是什么 / 作者用什么支撑、哪里可质疑）。
- **五要素映射**（仍按 schema 写，不得豁免）：①题目=这块要回答的问题（读完能复述什么）；②解析=读法步骤（先拆结构骨架与证据强度、再抠术语、后复述）；③答案=**参考概括 + 原文定位**——直接用 `参考概括：` 起笔，末段写 `原文定位：<章节·段句范围>`，不写题面段（原文出处放块定位）；④易错=断章取义、把作者转述的观点当成作者主张；⑤小结=主张 + 最强证据的压缩（≤2 句，不是第二份复述）。
- 写作要点：
  - **转述不抄写**：直接引用不超过本单元篇幅两成，其余用自己的话；引用加引号并标位置。
  - **区分三层**：作者的主张 / 作者的证据 / 我的判断——后两层不得写成第一层（衔接「事实、来源与不确定性」）。
  - **术语首现即解释**（同标准讲义）；原文用旧译名或异体字时并列，避免学员换本书就不认识。
  - **枝节不进正文**：与本节目标无关的背景、考据进「扩展（选读）」区，或只标位置不展开。
  - **争议与过时**：原文观点有争议或已被修正时，写一句「截至<日期>，另有……」并给出处；**不替作者补论证**，也不把作者的话升格成事实。
  - ③ 是**参考概括**不是唯一答案：学员用自己的话覆盖要点即通过（衔接 `teaching.md` 第 8 节主观题批改纪律）。

## 讲义概念单元 schema（所有风格共用）

讲义每个概念单元具备**可定位的必需槽位**：定义/规则、按需表示（类比 / 配图 / 对照表等）、完整示例或正反例、易错点、小结、检验问题。其他风格可重排槽位，但**不得漏槽位、不得删除必需信息**（参照级单元按「分层标注」条豁免，只留 ① 题目与正文里的定义、边界）。

**单元≠KP**：`## 概念 N` 是**教学单元**（历史标题，保留给脚本），不是 KP；一个单元可映射多个 KP，一个 KP 可跨单元。类型以单元的主导类型为准；混合类型拆单元或加类型子块。类型/支持级写规划区，不塞进每个标题；tier 标签仍必须有（见 `handout.md` §2.5）。

**六个槽位的落点必须可指认**：每条风格骨架已用〔〕标出落点——五个编号槽位（① 题目 / ② 解析 / ③ 答案 / ④ 易错 / ⑤ 小结）外加 schema 的**检验**。写完按骨架逐项指认，指认不出的就是漏槽位；**④ 与 ⑤ 最容易被别的段落顺带承担**（反例、对照表、报错清单、检查清单、骨架末尾的收束句都不等于 ④ 或 ⑤），须能指到具体那一行，不认「隐含在……」。④ 与 ⑤ 都按「≤3 句、不引入新信息」写（⑤ 的记忆族「本节地图」变体上限见「讲解文本密度原则」），不因加了槽位就扩写。**修复表、决策日志、对照表算附件，不占 ④/⑤ 的三句额度；但单元仍要有一句 ≤3 句的摘要**（见 `handout.md` §2.9）。

- **节首导读（定稿必备，3 行）**：在第一个 `## 概念` 之前写 `- 本节目标：学完能独立……`｜`- 前置：需要……（无则写「无」）`｜`- 预计：约 N 分钟`。与对话轮「课首定位」（`teaching.md` 第 1.1 节）同源，不复制理由；学员隔周回看先读这三行。脚本 `E-HEADER-BRIEF`：**定稿**缺任一行报 E，草稿不查（讲的过程中可后补）。**读者假设、已会/未会并入「前置」一行；用法放文末；类型/支持级放规划区——不新增第四行必填字段**（见 `handout.md` §2.6）。
- **默认顺序**（标准讲义）：定义/规则（含一句机制/边界）→ 配图（按需）→ 教学例（① 题目 → ② 解析 → ③ 答案框）→ 配对练习（配对自测）→ 易错点（④）→ 小结（⑤）→ 闭卷自检（阅读动作）→ 评估例/迁移（迁移自测）。类比不单设槽位，归入「按需表示」，有合适类比时才用（见「标准讲义」写作要点）。**读者版 P1 可选增量**：节首导读之后可加 `## 本节速览`，概念单元首行可加「一句话结论：」，自测答案区之后可加 `## 回看索引`；三者只做导航，不改变上述五要素顺序与答案框位置。
- **风格 × ③ ⑤ 落点（六套风格都必须写出 ③ 与 ⑤）**：下表只列最容易写错的 ③ 与 ⑤；① ② ④ 与检验的落点见各风格骨架里的〔〕标注，不在此重复。**③ 只允许纯概念/纯记忆/已会·检索版/参照级豁免；⑤ 除参照级外任何单元都不得省**（canonical 标签与各自豁免范围见 `handout.md` §2.2；下表逐行列出主要豁免，未列到的风格按同一规则处理）。
  | 风格       | ③ 答案（框）                        | ⑤ 小结                       | 允许的豁免                             |
  | -------- | ------------------------------ | -------------------------- | --------------------------------- |
  | 标准讲义（默认） | 可誊抄全文：从交付起笔到结论（不写题面段）        | 三句话小结（≤3 句）                | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」；参照级→「③ 不适用（参照级）」 |
  | 费曼卡      | 「最容易怎么用错」的对照答案，可只给关键句         | 一句话回收（≤2 句）                | 同上（纯概念/纯记忆/已会·检索版/参照级）          |
  | 考试冲刺卡    | 每题答案（选择题含逐项排除），详解附给分点量表       | 秒杀技巧或口诀（≤2 句）              | 无（备考型必有）                          |
  | 对比辨析卡    | 辨析题答案 + 判定依据                   | 判别口诀（≤2 句）                 | 纯概念/纯记忆→「③ 不适用（…）」；已会·检索版→「③ 不适用（已会·检索版）」 |
  | 操作手册式    | `步骤：`/`代码：` + `输出：` 成功标志      | 关键决策三句话（≤3 句）              | 无                                 |
  | 精读笔记式    | `参考概括：` + 末段 `原文定位：`          | 主张 + 最强证据的压缩（≤2 句）         | 纯背景章→「③ 不适用（参照级）」                 |
- **分层标注（每概念单元出厂必须带）**：在概念单元起始处用方括号标签标注 **【本节最小必需】**、**【选学·后期必用（何时用/依赖哪节）】** 或 **【参照】**；也可写在规划区对应概念行（表格列或列表行，纯文本即可），二者其一。选学标注须写明何时用到、依赖哪节；学员据此自行判断是否当前深学，不必等导师逐个说明。**【参照】对应深度契约的参照级**：只需「知道它是什么、什么时候用不上」，可标 `③ 不适用（参照级）` 豁免 ②③④⑤（① 题目仍须，定义与边界写在正文）；**工作级/最小必需级不得用参照豁免**。正文里只是提到「选学 / 最小必需 / 参照」字样不算标注。**纯记忆用 `③ 不适用（纯记忆）`、已会·检索版用 `③ 不适用（已会·检索版）`；两者只用于对应情形，不得拿来给工作级/最小必需级省讲解**。
- **定稿边界**：定稿 = 判分记账零残留（**台账状态行**、伺服档位、检验作答记录、补讲台账留 progress.md 与题组文件，不进定稿；两态流转见本册 §2.1/§12）。**`verify_explanation.py` 通过只表示「结构可定稿」，不等于状态转定稿**：**讲义状态行** `- 状态：` 仍保持「草稿」，待小节闸口通过后再改为「定稿」。台账状态行与讲义状态行不是一回事，见 `handout.md` §2.1。
- **讲义头部（讲义状态行 + 可选指针行，不复制规则正文）**：`- 状态：草稿（…）` 或 `- 状态：定稿（…）`；**台账状态行不进讲义**。需要记录体例约定时只写一行指针 `- 体例约定（LaTeX 排版/答案框）：统一见 progress.md「质量保障机制」`；**该区存在时才写指针，否则省略或先建区，不能留死指针**。规则正文归任务侧 progress.md；在头部复制规则块会触发 `W-STYLE-POINTER`。头部之后、第一个概念单元之前接「节首导读」三行；读者假设/用法/类型/支持级按 `handout.md` §2.6 合并，不新增必填行。
- **答案框体例（学科无关）**：框内只写**解题过程**，从**交付起笔**开始（以 `解：`/`答：`/`解答：`/`证明：`/`参考答案：`/`答案：`/`参考概括：`/`参考译文：`/`译文：`/`范文：`/`例文：`/`代码：`/`脚本：`/`输出：`/`步骤：`/`操作：`/`方案：`/`设计说明：`/`Answer:`/`Solution:`/`Proof:`/`Model answer:`/`Sample answer:`/`Translation:`/`Output:`/`Code:`/`Script:`/`Steps:`/`Key:` 起笔），或框内直接给出代码块。**完整交付标识表与学科映射见 `handout.md` §2.3；本行与脚本 `LEAD_WORDS` 必须一致。****不写题面段**：题干归 ① 题目，框内不再抄一遍（`题目：`/`任务：`/`Prompt:`/`原文：` 这类题面起笔在框内不再使用）。精读式另在末段写 `原文定位：<章节·段句范围>`（收尾段，不算第二类必需标识）。**标记行留空**：只写 `③ 答案：`，答案写进框内；标记行带内容报 `W-MARKER-CONTENT`。**标记行须在行首**（列表项，可加粗），正文里提一句「见 ③ 答案」不会被当成标记。**多题单元**（如冲刺卡 3 道真题）：每题一个 `③ 答案（第 N 题）：` 框，或在一个框里按题号分段（`（1）解：…`，题号可写在框内段首，仍算交付起笔）。**交付段须有实质内容**：去掉标识与标点后为空、或只剩「略／从略／见教材／同上／自行体会」等占位词的，不算答案（`E-BOX-EMPTY`）。**分点编号**：段首 ①–⑩ 合法——按点给分的给分点就是「每点一段、段首起编号」；句中编号不合规（`答：①……②……` 挤在一行），须拆成每点一段。**代码块**：框内的代码围栏（三反引号起止）整块算一段，块内多行不拆行、不查箭头与验算标记（验算只认 ✓ ✔ ✅，`√` 视为根号不拦），紧接 `输出：` 段给运行结果与成功标志。**同一体例的五种形态**——数学 `解：…∴ …`；文科 `答：①资本：…`（每点一段）；语言 `Model answer: 他跑得很快。`；精读 `参考概括：…` / `原文定位：…`；编程 `代码：` + 围栏块 + `输出：无报错即成功`。**客观题**：选择题给「答案 + 逐项一句排除（错项错在哪）」，填空写清多空顺序与单位，不得只给字母——教辅答案册多把逐项分析并入答案，故留在 ③；② 只讲这类题的判定方法（何时用排除、何时直接算），不复述逐项内容。**带图答案**：作图 / 受力图 / 流程图 / 装置图 / 结构式在框内单独一行 `图：assets/NN-xx.svg（示意/按比例）`，图须先落盘后引用（同「图像可视化双轨」），并按「绘图后核对」检查图文一致；无图可画时写清作法与关键点。各族的默认形态见 `subjects.md`「③ 答案形态」。**不得默认 `解：`**——按当前内容所属学科族取形态；跨族内容（如物理借数学族）以内容所属族为准。
- **其余族的最小形态（只演示段结构、篇幅从简；完整范例见「标准讲义 · 成品范例」）**：以下只给框内内容，题面一律写在 ① 题目。
  - **语言**：`Model answer:` 起交付；翻译可用 `参考译文：`；改错类末段补一句「为什么这么改」。
    > Model answer: 他跑得很快。
  - **编程**：`代码：` 后接围栏块（整块算一段）；末段 `输出：` 给运行结果与成功标志。
    > 代码：
    >
    > ```python
    > import os
    > for name in os.listdir('.'):
    >     if not name.startswith('p_'):
    >         os.rename(name, 'p_' + name)
    > ```

- **框内分段（通用判据）**：一段 = 一个**可独立核对的最小单元**——单独拿出来能判对错、能给分、能对照的最小块。段内不再塞第二个这样的单元，也不把一个单元拆到两段。**段间写一个只含 `>` 的空行**；**段数不设下限**（单步答案一段即可，`> 答：B。` 合法）；`解：`/`答：` 等交付起笔放在**首段起头**（不单独占一段），末段为结论；**公式 / 算式 / 引文不跨段**，长式转行只落在等号 / 关系符 / 运算符之后（细则见 `formulas.md` 第 3 节）。**每段以单行为准**：普通文字多行会被渲染器并成一行、内容不丢——脚本不再提示（避免每个框都冒一条噪声），由「讲解出厂自检」第 2.1 项人工核对；若段内断行截断了 `$…$` 公式或行内代码，渲染直接损坏（`E-BOX-WRAP`）。**围栏代码块整块算一段**，块内多行照原样保留。分段前先把同一句被拆开的续行合并成一行。一句话：**看这一段能不能单独判对错**。

- **闭卷自检（阅读动作，不计题量）**：在 ⑤ 之后、自测之前写一行「合上讲义，用 3 句话解释本节核心 → 自评 0–100% 把握 → 对照 ⑤ 补漏 → 做迁移题」。不新增答案区；模型答案用 ⑤，学员自评不写入 progress.md；≤3 个阅读动作/节（见 `handout.md` §3.5）。

## 图像可视化双轨（所有风格共用）

讲义概念涉及**函数图像、几何图形、数轴/区间示意、流程图、架构图、时序图、装置图、受力图、结构式/反应式**时，默认双轨呈现，对话讲授场景下缺一不可：

**适用场景**：对话讲授轮与讲义定稿同时发生时执行双轨；纯文件交付（独立触发写讲义、批量生成）无对话轮可渲染，只执行落盘轨，并在交付说明标注「未做对话内渲染」；自检第 14 项按场景判定。

1. **对话内渲染**：讲解轮用前端 SVG 直接画出图形（学员当场可看、可追问；SVG 为纯静态图形——图形元素与文字标注，不含 script 与外部引用）；
2. **落盘存档**：SVG 源文件写入 `materials/assets/NN-<图名>.svg`（编号沿用材料契约），讲义 markdown 用图片语法引用该相对路径（相对 `materials/` 目录，如第 2 节第 1 图存为 `assets/02-01-抛物线三情形.svg`）——图进入复习链路，讲义复看、S4 复习、结课复盘均可再打开。**先落盘、后引用，同轮完成**，杜绝死链（脚本按讲义所在目录解析相对路径，缺失报 `E-IMG-DEADLINK`）。

- **绘图前约束**：先声明图形类型——**定性示意图**（示意趋势/位置，不承诺比例，须标注「示意」）或**按比例图**（须与数值/比例一致）；只标**当前任务真正需要的点**，不为「完整」机械塞入无关要素（如解不等式的图**不必机械加入顶点**）。
- **绘图后核对**：核对图与讲义文字**一致**——坐标图核关键坐标、走向与区间端点；流程图核步骤顺序与分支条件；装置图核部件、连接与方向；受力图核力的方向、作用点与个数；结构式核原子/基团与配平。**多面板图逐面板与讲义文字对应，禁止漏面板**（漏面板 = 内容缺失）；**图文不一致时以领域事实为准**（数学看计算与定义、物理看受力与量纲、化学看结构式与配平、流程看步骤依赖），先修图再继续（不转成辩护，并同步修正讲义与存档）。
- **图的可判读规范**：按图类给最小标注——坐标图有坐标轴、标度示意与关键点（顶点/交点/渐近线/截距，限于当前任务所需）；流程图有方向、分支条件与起止；装置图有部件名与连接顺序；受力图有箭头方向与作用点；结构式有键与条件。曲线与辅助线用不同样式区分；一张图只讲一件事，不堆叠。
- **渲染阻断**：对话内或落盘图形无法生成、渲染或核对时停止当前运行，说明失败图与恢复条件；不用 SVG 源码或文字描述替代已承诺的图。若任务一开始只要求文字说明，则按文字目标生成，不属于替代。
- SVG 为纯文本：零第三方运行时依赖、可复制可修改、跨平台；不引入 matplotlib 等绘图库依赖。
- **视觉任务与讲解图分开**：KP 的视觉任务证据必须来自原始材料图/表（页码/图号/数据位置），讲义 SVG/示意图只用于讲解，不能替代原始来源（见 `data.md`「视觉任务来源纪律」）。
- **图解语法与无障碍**：图 brief、节点预算、边/标注、颜色与对比、SVG 技术要求、alt/图注见「读者版可读性契约」第 4 条；跨节视觉一致性见 `handout.md` 第 10.11 节。

## 讲解出厂自检（四维度，所有风格共用）

讲授正文（对话讲授轮与讲义正文）在发出/定稿前按以下四维度自检，逐项编号，每项标 **E（阻断）/ W（警告）**。**按执行时点分级，不全量平铺**：

| 时点      | 必查项                                                        | 可后置项                      |
| ------- | ---------------------------------------------------------- | ------------------------- |
| 发出讲授轮   | 1、2（仅含量词时）、3、4、5、6（仅高风险外部事实）、7（仅含计算/代码/可运行示例时）、11、14（仅含图时） | 8–10、12、13、15，以及 6 的完整四要素 |
| 讲义定稿    | 全部 15 项                                                    | 无                         |
| 相关内容修改后 | 受影响项 + 5（术语一致）、8（结构）、14（图）                                 | 其余                        |

**E 项命中 → 修复并重检该项，通过后才能发出/定稿**；**W 项命中 → 同轮修复或显式后置（注明原因），不阻断——但 `W-UNICODE-CHAR` 是定稿例外，必须清零（见 §2.11）**。本自检是模型自检，不替代 `scripts/verify_explanation.py` 的静态校验（定稿前两者都跑）。**深讲概念另跑「深度契约」D1–D6**：D1–D5 任一不满足 = E；D6 只用于删冗余。该审计不替代本表，二者都跑；缺 M/C 的深讲概念不得定稿。

### 1. 准确性与可信度

1. （E）结论、条件/定义域、量词、单位、版本与边界逐条核对；**含量词的表述（所有/任意/存在/至少/当且仅当等）逐条标注量词归属**；
2. （E）含量词的定义或规则**出厂配齐正例 + 反例（或边界例）+ 代入/验证演示**；不适合举例时说明原因与替代核验方式；
3. （E）分类不完备时明示「只列代表类型、非完备分类 + 补全位置与时机」，本节检验题**不得考所列类外情形**；
4. （E）定义/定理/推导/经验/类比/课程约定可区分（类比不当定义、约定不当事实，见「事实、来源与不确定性」）；
5. （E）符号、术语与引用全节一致；术语首次出现已给白话或定义，未假设学员已知；
6. （E）外部来源学员侧可得并注明名称/年份/链接/核验日期；不可得则改为课程内约定并说明；无法核实的内容标出不确定性，**不编造来源**；
7. （E）计算、推导、代码或操作至少做一次独立核对（代回、量纲、边界样例、运行成功标志，按领域选用）。

### 2. 结构

1. （E）概念单元必需槽位齐全（见「讲义概念单元 schema」），节首导读三行齐，五要素、新记号三件套、分层标注按内容适用性齐全，答案框体例合规（`verify_explanation.py` 覆盖静态部分；**框内段内是否有多行、是否按最小单元分段，脚本不查，本项必查**）；**所用风格骨架里的 ④ 与 ⑤ 须指认到具体行**（反例/对照表/报错清单/检查清单不算 ④，骨架末尾的收束句不算 ⑤）；**纯概念豁免②③的单元，须有人工确认的正反例或等价表示（脚本不查，本项必查）**；**参照级豁免②③④⑤的单元，须人工确认定义与「何时用不上」的边界已写在正文（脚本只查①题目标记，不查内容）**；
2. （E）示例、讲义自测、题组三者不同题（可同知识点换情境），非只改数字的重复；
3. （E）所选风格可重排槽位，但未删除必需信息。

### 3. 密度

1. （W）易错点单一出处、小结不引入新信息、无空转句；②与③不原样重复（②给方法与判断、③给成品卷面；结论句允许各出现一次）；
2. （W）逐段做「删除测试」——删除后不损失目标、依据、边界或验证信息才删除；可选细节后置并显式标注。

### 4. 呈现

1. （W）公式符合 LaTeX 约定（见 `formulas.md`）；
2. （E）配图**逐面板与讲义文字对应，禁止漏面板**（漏面板 = 内容缺失）；按图类核对（坐标 / 流程 / 架构 / 时序 / 装置 / 受力 / 结构式，见「图像可视化双轨」可判读规范）；图文不一致时**以领域事实为准**先修图；
3. （W）代码/操作示例给出可复制的成功标志。
