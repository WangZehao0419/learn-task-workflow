# 画像与叙事簿 正本册

> 要写学习者画像（可选全局文件）、记忆簿（学习日志 / 学习记录 / 讲授证据），或要定课程体系的「质量保障机制」「协作协议」两个可选区的体例时读本册。

## 本册目录

1. 记忆簿格式
2. 学习者画像
3. 续学匹配（多任务与科目别名）
4. 质量保障机制（可选；体例约定与定稿校验）
5. 协作协议（可选；任务级操作约定，如教材拍照协议）

## 记忆簿格式
### 记忆文件

**文件**：`<数据根>/<slug>/记忆.md`，任务目录第一层。任务级**叙事簿**：三个 append/覆盖区，全部是人读叙事，不进任何脚本解析、不参与闸口。

```markdown
# 记忆：<主题>
- 最近更新：<YYYY-MM-DD>

## 学习日志
- <日期>：<完成内容、练习结果、作业>；学员状态：<顺 / 挣扎（原因）/ 需换风格>；姿态：<A/B/混合>；深度：<M/C 未讲（S4 补）>   # 姿态与深度为可选追加
- （事件时间线，只追加不改写；审计记录（日期 + 对照源 + 差异数 + 处置）、纠错留痕、调度器读数等亦记于此）

## 学习记录
- <一句话洞察> ｜ 证据：<日期 + 场景/原话>
- （无记录时写「无」；写法纪律唯一事实源见 data.md「记忆写法纪律」；最多 5–7 条，超出时合并重复、删除低信号或已被推翻的；跨任务稳定模式不写在这里，按 profile ② 的证据/确认流程另写）

## 讲授证据
- [<日期>] <KP/概念> ｜ 已讲：<逐字引用≤80字> ｜ 来源：<页码/链接；无外部来源写「自拟」>
- （只记已公开讲给学员的内容；计划、思考、工具结果、来源原文不算；讲授 ≠ 掌握；同一概念保留最近一条，不逐题记）
```

- **学习日志**是**事件时间线**（只追加）；**学习记录**是**任务级持久洞察**（回答「这个学员在这个任务里为什么卡/为什么通了」，不写流水账）；**讲授证据**只证明「讲过」，不证明「学会」，不替代判分/复述闸口。`学习记录` 不替代 `profile.md` ②：跨任务稳定模式进画像，任务内洞察留本区；**本区不直接写跨任务结论**。
- 来源不可用或不确定时如实说明，不编造。没有新内容就不写，空更新合法。

## 学习者画像
### 学习者画像（可选全局文件）

**文件**：`<数据根>/profile.md`，**全局唯一**、跨任务共享（画像放数据根第一层、与任务目录平级）。**偏好按作用域生效（F13）**：①层 = 学员明说的**通用偏好**，跨主题适用；②层「稳定模式」**默认任务级作用域**（可标任务/学科族/全局），**带证据、可复评、可关闭**；**教法裁决与类比领域按任务/学科族作用域生效**，**不得当作跨主题的全局人格标签**，也不得据单任务低效就对同类主题预判。**可选**：无此文件 = 合法形态，不强制创建、不报错；首次触发建立时机 = S1 摸底顺带问「类比领域」时（见 `references/intake.md` S1），用户不便回答则跳过。**单一事实源声明**：画像内容的唯一事实源是本文件；讲授/类比时由模型现场读取。

**格式模板**（三层结构，逐层追加）：

```markdown
## 学习者画像
- 最近更新：<YYYY-MM-DD>

### ① 明说的偏好（只有学员亲口明确提过的才进这里；**明确通用偏好，跨主题适用**）
- 类比领域：做饭（S1 摸底时确认，2026-10-12）
- 沟通约定：<学员明确要求的沟通规则，如"不要堆术语""重点加粗、结论先行"（无则写「无」）>

### ② 稳定模式（跨多次对话看清的，每条必须带证据；**带作用域：默认任务级，非全局人格标签**）
- <模式描述>（作用域：<任务/学科族/全局>；证据：<日期> <学员原话/具体场景>；至少 2 条独立证据）
- <教学方法裁决>：<有效 / 低效>（**作用域：<学科族 / 任务 / 目标>**；条件：<什么场景下>；证据：<日期> <场景与效果>；裁决日期：<YYYY-MM-DD>；状态：<生效 / 已复评 / 已关闭>）——同一条裁决**可复评、可关闭、可删除**；低效裁决在**其作用域内**不再推该方法，**不跨任务/学科族永久禁用**（数学类比无效 ≠ 编程类比无效），也不写成人格标签

### ③ 观察暂存（注意到了但没看清的，只记场景）
- <日期> 在 <什么场景> 做了 <什么>——<尚未归类，不起名字>
```

**三条铁律（画像纪律）**：

1. **①层只存学员明说的**，且只收**明确通用偏好**（跨主题适用）：模型观察到的偏好不算——学员明确说「讲慢点 / 别用类比讲代码」才进①层；擅自给学员贴偏好标签是越界。**任务级偏好不进①层全局段**——落到对应任务或②层作用域。
2. **②层必须有证据且带作用域**：每条稳定模式附 ≥2 条独立证据（日期 + 原话/场景）；**「永远不要从一次观察直接升级成画像」**——单次表现只进③层记场景，第三次以上同向证据才允许升②层。**教学方法裁决**带条件与作用域、证据与日期，**可复评/关闭/删除**——低效裁决只在作用域内生效，换学科族或换目标时**重新评估**，不做「连续 N 次低效即永久禁用」的绝对处置。
3. **写入前展示确认**：①层学员亲口说的事实**免确认**——学员刚说过的内容直接落盘，导师以自然话术带过（如"好，类比就用做饭"），不重复问"可以存吗"；新增②层条目时，把要写的内容读给学员、明确说"可以/对/保存"后才落盘；③层追加不需要逐条确认，但下次读到时学员可要求删除任何一条；**学员任何时候可要求删除/关闭②层任一条裁决**。

**写法纪律**：每条 ≤120 字（作用域、证据、日期、状态等元数据不计入）；用**动词短语**，不用形容词标签；每条带**证据**（日期 + 场景/原话）；推断标"暂定"，只有学员陈述或后续证据才升级；无证据不写，空更新合法，当前证据与当前表态优先；禁用绝对化词，一次困难不得写成全局人格判断。正例："遇到递归先画调用栈再写代码（2026-10-20 学员原话：画出来就不乱了）"；反例："学员递归很差 / 彻底掌握了递归"。

**消费方**：S3 讲授类比优先取①层「类比领域」（衔接 `references/teaching-method.md`「类比纪律」）；跨界三猜想的「确证已会」可用②层稳定模式作证据之一（仍以摸底判分/亲口确认为最强）；S3 讲授呈现与④批改的反馈措辞同取①层沟通约定；**任务级偏好按任务作用域读取**；「换角度重讲」/换讲义风格时**先查②层教学方法裁决**，**仅在其作用域内且状态为「生效」时**才不重复推该方法（裁决可复评/关闭/删除）。**画像不参与任何闸口判定、不进脚本**——它是教学个性化素材，不是调度数据。

**零感知**：脚本（task_index / progress_check / scheduler / kp_sort / prereq_check）对 `profile.md` 与 `记忆.md` **零感知**（不解析、不出告警；进度校验所需的审计记录改由 progress_check 从记忆.md 学习日志只读检索，缺文件 = 合法形态）。

## 续学匹配（多任务与科目别名）
- 命中同名任务 → 续学：只读其 progress.md「当前阶段」，不得覆盖既有文件。
- 命中多个任务且用户未指名科目 → **列出候选**（科目名 + 当前阶段 + 最近学习日期），请用户选择；不猜、不默认最近一个。
- 用户指名科目 → 按科目与任务 slug/主题模糊匹配（含别名，如「高数」↔ shaanxi-gaoshu），命中单个即续学。
- 未命中 → 新任务，从 S0 开始。
- 枚举异常或为空但怀疑有数据 → 先用 `task_index.py --root` 兜底；`scan_status=partial/failed` 时任务集合不完整，不得当「无任务」处理，停止枚举/续学并修复后重跑。

## 协作协议（可选；任务级操作约定，如教材拍照协议）
- <协议条目>
```

**层级口径（章/节/目）**：**章** = 课程顶层分组（教材的部/章、考纲板块或自拟分组；教材结构与课程章的对应经「章→节」归属与对照结论呈现，不要求一一对应）；**节** = 学习路线一行（`- [x] N. 节名`）；**目** = 节下最细知识点。**目行 = 原 KP 行**，编号 `KP-<两位节序>-<两位KP序>`（如 KP-03-08 = 第 3 节第 8 个目），两位补零沿用材料编号契约，脚本宽容匹配单位数；纯数字字典序 = 教学序，编号全文件唯一。**每个目必须有目名**（即知识点名），目名节内唯一；**目序按节连续，禁止按场/次分段重编号**。**1 个讲授目 = 1 个 KP**：禁止一个目挂多个 KP；一个知识点若需要多个目，先拆 KP 再讲（目定义见 `references/lessons.md`「S3 逐目推进」）。对学员指代一律用目名、编号只落盘（口径见 `SKILL.md`「十一条教学红线（判据自足，任何场景都生效）」）。

**不属于已拆节的目**（暂缓 / 排除 / 计划外）用**伪节序专号段**（节序取 90 起，如 `KP-90-01`；保持两位数字以适配脚本正则），该段只按状态计数、不映射到任何节。

#### 摸底标注（保守口径）

S1 摸底命中且有判分证据的目，状态列写 `未讲（已会：<摸底证据>，<日期>）`——信息性标注，**留在审计分母内**（按「未讲」基值计数），任何把目标「排除」出分母的动作必须经用户显式确认；标注随 S2 对照结论一并展示。
#### 目行字段与标注规则

目行除基本六段外，还有解析口径、标注、可选字段与合法性约束，按下述口径登记：

- **kp_sort 返回口径**：`<技能根>/scripts/kp_sort.py --list <课程体系.md>` 的 `order` 含**全部目行**（含暂缓/排除；输出另带 `excluded`/`held` 计数），讲授序与出题序仅取**纳入项**（状态 ∈ {未讲, 已讲}），暂缓/排除不入出题分母（见 `references/closeout.md` S5）。
- **fringe 返回口径（票 37 Q3 / 票 83）**：`<技能根>/scripts/kp_sort.py fringe <课程体系.md>` 输出 `schema=ltw-fringe/1` 的两张清单——**已会**（讲授域内 `判定=已判`）与**现在能学**（讲授域内自身未判、且硬前置全部 `判定=已判` 或带摸底「已会」括注）。摸底括注按 `kp_status_base` 归「未讲」基值，它只让该目**作为前置放行**，不等于该目已判（不进已会）。暂缓/排除的行两张清单都不收；硬前置被暂缓/排除时该目既不进能学也不进 pending，而是进 `blockers`（复用拓扑序的同一形状）。输出另带 `pending`（自身未判但还有前置未满足，附 `waiting_for`）——没有它，「能学清单为空」就分不出「全学完了」与「全被前置挡住」。**输出按原文行序**：票 37 未定「现在能学」的排序口径，脚本不发明排序，要排序另起决策票。`--list` 是默认拓扑序的显式别名，输出与裸路径逐字节相同。
- **需巩固标注（R54）**：目行状态可写 `已讲（需巩固：<依据>，<日期>）`——信息性标注，随「已讲」基值计数、不进覆盖摘要新键；触发与翻回口径见「保持复习区」。纳入/出题域判定不受影响（按已讲基值，`kp_sort.py` 仍计入讲授序与出题序）。
- **字段合法性**：前置列只接受合法 KP 编号或空；`progress_check.py` 校验前置引用存在性（引用不存在的 KP → W-UNPARSED-KP）；行畸形（缺段/状态非法）→ W-UNPARSED-KP，**不计入摘要计数**（不静默）。
- **未知段兜底（票 92 / 批① 前向兼容）**：第 6 段之后**段名不在白名单**的段（白名单只有 `引入 / 类型 / 视觉任务 / 判定 / 独立正确 / 判定依据`）不再判整行畸形——忽略该段、其余照常解析、排序可用，由 `progress_check.py` 出 **W-KP-ROW-UNKNOWN-SEG**（每个段名一条，同一段名跨行合并，原文逐段留在 `coverage.unknown_segs`）；`kp_sort.py` 的拓扑序与 `fringe` 输出另带 `unknown_segs`（去重 + 稳定排序，便于消费端先动手）。**兜底只放宽这一个分支**：状态非法、前置引用不存在、缺段、重复编号四条维持严格硬失败；无冒号的残段（如 `节 2`）与必需段（`前置/来源/状态`）被错位写进可选区，同样判畸形——「不认识的新字段」才兜底，「写坏的行」不兜底。
- **互为前置定向**：概念目与程序目互为前置会成环，`kp_sort.py` 报环即停；此时按「先教可独立检验的一侧」定向登记前置边，另一侧紧接着教（同节或相邻节，不悬空），复习把两侧串起来。
- **可选分型字段**：目行第 6 段后追加 `｜ 类型：记忆/概念/程序/设计`（精确枚举；全/半角冒号均可）与/或 `｜ 视觉任务：识别/关系/图表/比较`（多选用逗号/顿号分隔）。声明后启用分型验收；口径见 `references/lessons.md`「S3 闸口（可检验）」。KP 标签支持单位数别名（`KP-1-1` ≡ `KP-01-01`）。分型门按 KP 编号的节序归组；重排节时保持编号稳定或同步更新 KP 编号/所属节，避免分型证据串节。`kp_sort.py` 只读前六段，忽略可选字段；可选字段畸形 → W-UNPARSED-KP，放行模式另报 E-KP-TYPED-GATE（不能靠写坏字段绕过分型门）。
- **引入字段**：追加 `｜ 引入：<术语1；术语2>…`，登记该目**首次引入**的术语/记号/族名（如「定语」「现在完成时」「±记号」；分号或顿号分隔）。这是出题前术语对账（R46，见 `references/assessment.md`「出题前术语对账（R46）」）的账本：`scripts/prereq_check.py --list <课程体系.md>` 以已讲目的引入列 ∪ 目名 ∪ 追加项为「已引入集合」，扫描题面中的未引入术语。**新任务开节时逐目登记**；术语命名与讲授一致（同一概念全文件同名），畸形容忍：缺段不报错，只贡献空集。
- **判定字段（目行判定三字段，票 81 决议 / 票 82 落地）**：目行第 6 段后可追加三个可选段，承载「这一目判没判、凭什么判」：
  - `判定：已判` / `判定：未判`——精确枚举（全/半角冒号均可）；其他值 → 行畸形（`W-UNPARSED-KP`）。**不要**写进 `状态：` 括注（与 `已讲（需巩固：…）` 抢位会让 `prereq_check` 的术语对账静默失效）。
  - `独立正确：YYYY-MM-DD[,YYYY-MM-DD]`——存**日期集合**不存计数（存计数则同日两次与跨日两次都写 2，「跨日」不可机检）；ISO 升序、**最多 2 个不同日期**，满 2 后不再追加；非真实日历日（如 `2026-02-30`）→ 行畸形。**可空**：摸底「已会」是一次性证据，为空表示「本次判定的证据不是跨日两次」，不是「没证据」——证据在 `判定依据`。
  - `判定依据：exercises/<文件名>.md#题<N>`——多个用**全角分号** `；` 分隔。**个数对齐规则按 `独立正确` 是否为空分两支**：日期非空 → 指针个数**必须等于**日期个数；日期为空（摸底「已会」的单次证据路径）→ **只允许 1 个指针**。少了这个例外，「独立正确可空」那条规则就会被自己的对齐要求判成违规。
  - **推荐书写顺序（不作判据，按前缀识别）**：`类型` → `视觉任务` → `引入` → `判定` → `独立正确` → `判定依据`。
  - **缺省语义 = 未判**，且缺字段**零告警**（与显式写 `判定：未判` 下游行为完全一致；旧六段行零迁移继续合法）。
  - **形态 vs 语义分家**：非法枚举 / 重复键 / 日期格式坏或超上限 / 指针格式坏 → 行畸形 `W-UNPARSED-KP`；格式合法但语义不闭合（已判却缺依据 / 依据指向的文件或题号不存在 / 指针个数 ≠ 日期个数 / 同日重复不足「不同日数」/ 未判却写了另两字段）→ `W-KP-JUDGE`，**只告警不拦停**。该码只验指针闭合，**验不了「这个题号是不是真的判对了」**。
