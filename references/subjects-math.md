# math 学科群 正本册

> 本册是「math」学科族的四类切片（plan / teach / practice / review）合一。

## 数学与统计群 · 规划切片

### 群边界与借用

本群：高等数学与数学分析、线性代数、概率论与数理统计、离散数学、逻辑学、K12 代数与几何。物理与化学的**计算目**由学科包提供学科表征（受力图、量纲、配平），本群只供数学侧的符号操作、验算与变式——不再出现「借数学族」这种把学科防线丢掉的路由。

默认内容类型分布：程序型最多，概念型次之，记忆型（特殊值、公式）少量，设计型（建模）少量。S2 按实际目清单核正后写入课程体系。

### 内容结构与前置链

- **纵向链**：算术与式 → 函数 → 极限 → 导数 → 积分 → 级数／多元；代数侧为 式 → 方程与不等式 → 线性方程组 → 向量空间。
- **横向依赖**：三角与单位圆是后续一切周期与旋转的地基；不等式与绝对值是定义域、极限、判号的地基。
- **前置断层高发点**：分式运算、因式分解、根式与指数、三角恒等式、绝对值的分段处理。这五处是本群最常见的「假高数问题」。

### 目标深度锚点

- **程序型目**：能独立做对同型题并说出关键步的理由（SOLO 关联），不只结果对。
- **概念型目**：能讲机制、给边界、指出与相邻概念的区别（定义—机制—边界—对比四件）。
- **记忆型目**：特殊值、常见极限、导数与积分表——到「能列举并能区分易混」即可，不要求推导。
- **几何目**：先判几何思维水平再定教法——只会按图形外观判断（视觉水平）时禁止直接上形式化证明，先用具体图形与剪切拼补过渡（van Hiele 五水平）。
- **概念成熟度**：极限、导数、积分这类概念按 APOS 四阶段推进（Action 逐点算 → Process 整体变换 → Object 可当作对象运算 → Schema 纳入体系）；学员停在 Action 时，讲「对象级」操作会听不懂。

### 排期侧重

- **前置探针先于开课**：成人重学数学卡在初等代数而非高数，是社区压倒性共识。S1 摸底先跑五处前置断层的探针；任一失败即在本节前插一节预修，并向学员说明「降一级起步零成本，几天就能确认并跳过」。
- **每日微量维护**：数学的程序性靠高频短练维持，断更两三天手感明显下滑。排期宁可短而密，不要一周一次长课。
- **课时倾斜**：证明类目默认按「结论＋适用条件＋反例」教，学员明确要求时才展开完整证明——把课时省给程序型与概念型目。这一条在看懂结论不影响做题的目上尤其成立。
- **考前**：冲刺期把课时从新目转向错题重做与整套限时，不再开新概念（与 `references/subjects-common.md` 应试技巧包一致）。

## 数学与统计群 · 出题切片

### 题型阶梯

- **计算类**：口算热身 1 道 → 同型三变式（改数字 → 改条件 → 逆向求解）。
- **判定类**：构造与干扰项纪律见下「判定题构造」节。
- **证明类**：补全证明链（挖一到两步）→ 找漏洞（埋一处跳步或循环论证）。
- **建模类**：从情境列式 + 结果解释（算出来不合实际怎么判）。
- **交错排期**：独立解题成功率稳定后，题组混排两类以上旧题型，逼「先选方法再动手」；切换判据见 `references/assessment.md`「分块与交错切换」。
- **同题面不同深层**：同一图形或同一题面配三四个不同问法（同一等腰三角形分别考面积、角平分线、相似、三角函数），逼学员先判「这题到底在考什么」。与一次一维互补：一次一维管题与题之间变什么，同题面管同一情境下问什么。

### 群级共享误区库

只放**跨数学学科通用**的条目；导数、极限、积分等学科专属误区见 `references/disciplines/calculus.md`。

| 误区 | 症状 | 诱因 | 反证 |
|---|---|---|---|
| 等号当光标 | 3+4=7+2 一路连等 | 把等号读成「下一步是」 | 等号两边必须相等 |
| 分数分子分母各加 | 1/2+1/3=2/5 | 当两条独立数轴 | 用 1/2+1/2 试，得 2/4 等于没加 |
| 负数比大小看绝对值 | 认为 −7>−5 | 「7 比 5 大」迁移 | 欠 7 元比欠 5 元更穷 |
| 平方吞负号 | (−8)²=−64；−4² 与 (−4)² 不分 | 只记「负负得正」没接乘方 | (−4)²=16、−4²=−16，读法不同 |
| 系数指数混淆 | y·y·y 写成 3y | 乘法与加法记号互串 | 3y=y+y+y |
| 合并非同类项 | 9x+y−6x+y=5xy | 「有字母就能合」 | 苹果加香蕉合不成一个东西 |
| 去括号只乘首项 | 5c(2d+1)=10cd | 分配律只看首项 | 5c·1 去哪了 |
| 移项不变号 | x+3=7 → x=3+7 | 把移项当搬运 | 移项＝两边同减 3 |
| 解方程同侧重算 | c/4=8 → c=2 | 想「再除一次凑答案」 | 代回 2/4≠8 |
| 乘法使数变大 | 乘 1/2 或 0.3 也当变大 | 正整数经验泛化 | 半个西瓜比整个小 |
| 独立事件当有记忆 | 连开三次正面后押反面 | 赌徒谬误 | 硬币不记得上次 |
| 函数记号代入错位 | f(x+1) 算成 f(x)+1，或把 f(x) 读成「f 乘 x」 | 记号当缩写不当代入规则 | 取 f(x)=x²，f(x+1)=(x+1)²≠x²+1 |

### 判定题构造

问「何时用」而不是「是什么」：给信号问方法（「看到定积分区间对称，先想哪条性质」）、给两法问取舍（「这题用换元还是分部，凭什么」）、给反例问失效（「这个方法什么时候反而不如另一条」）。**干扰项必须是「邻近情境下才对」的方法**，能被一句「选它的人错在哪」解释；不用显然错的弱干扰。

### 答案形态与最小单元

- 起笔用 `解：` / `证明：`；题面写在讲义 ① 题目，答案框体例见 `references/handout-layout.md`「答案框体例（学科无关）」。
- 最小单元＝一个**语句**：一次变形、一次代入、一次判定各算一单元；`∵…∴…` 的依据与结论同段；同一表达式的连续变形可合为连等式。段间空一行。
- 选择题给答案 + 逐项一句排除（错项写错在哪）；填空写清多空顺序与单位。
- 作图在框内单独一行 `图：assets/NN-xx.svg（示意／按比例）`，图须先落盘。
- 跨学科计算（物理、化学）起笔与分段**一律按 `references/subjects-science.md`「答案形态与最小单元」执行**（不再分物理化学写法），不套本群的 `解：` 默认。

### 视觉任务

函数图像判读、几何图形识别、概率树读图是本群最常见的三类视觉任务，一律用原始图与数据表并记录页码/图号；替代禁令、证据资格与原图缺失处置见 `references/assessment.md`「视觉任务证据」。

### 给分点结构

解答题按得分点拆「建模／列式」「关键变形」「结论与范围」「验算说明」四段；每段独立可判。客观题不拆给分点。

## 数学与统计群 · 复习切片

### 复习形态与间隔侧重

- **一律检索式**：先做再对答案。重读笔记、抄公式、看视频都不算复习——熟悉感不等于能提取。
- **题型轮换**：计算 → 判定 → 改错 → 补全，隔次换型，避免同一动作重复到机械化。
- **公式条目按可推导性分频**：能自己推出的（导数表、积分基本公式）降频，只保留「会推」的检验；推不出来的纯记忆条目（三角特殊值、常用常数）保持固定间隔，不删。
- **错题按错因分流再复习**：先判是技巧性还是理解性，再选复习形态——不要把所有错题都塞进同一套重做流程。
- **跨目串联**：每隔几次复习插一道跨知识点题（例如求完导数顺手问单调区间），用旧目带新目。

### 错因分流与纠错脚本

| 错因 | 判别信号 | 纠错动作 |
|---|---|---|
| 概念缺失 | 说不出为什么这么做，换个问法就错 | 回到该目的具体层重建直觉，再回抽象层；不进题海 |
| 方法选错 | 会算但选错路，或两条路都试 | 补方法选择图，重做「识别线索 → 选法」这一步，不从计算开始 |
| 计算失误 | 思路对、结果错，重算能对 | 限时重做同型题；把易错步写成检查项（如「先定符号」） |
| 审题偏差 | 漏条件、看错问法 | 审题圈画专项：三步圈出已知、所求、限制 |
| 时间不够 | 会做但做不完 | 单题限时重做 + 跳过标记训练，不补知识 |

**纠错话术**：指出错在哪一步、下一步改做什么；不评价人。数学的「粗心」几乎都有具体机制（符号、分配律、移项），要落到机制上，不落到「再仔细点」。

### 冲刺侧重（方法层）

- **错题优先于新题**：冲刺期把主要课时给错题重做与整套限时，不开新概念。
- **压轴按「能推几步推几步」**：把已知、设、列摆上卷面拿步骤分；空白是零分，半成品常有分。
- **过程即得分**：解答题的可判步骤要写全，跳步在阅卷里就是丢分点；平时练习就按得分点写。
- **多选取舍**：按「部分选对得部分分、选错得 0 分」计分时，不确定项宁缺勿错——平时练习就按这个规则计分。
- **考前不排新内容**：最后一晚只看一页纸与错题清单，睡眠计入计划。

## 数学与统计群 · 讲授切片

### 讲授侧重（六拍内的群差异）

- **零基础首目先具体再符号**：先给真实现象或学员做过的题，再上图形／表格，最后才给符号规则。跳过具体层直上符号，是「讲了但没懂」的第一诱因。具体层优先取学员自己做过的题，不取编造故事。
- **先代具体数字，再上一般式**：一般式与新记号出现时，当场给语义、代入演示、易错点三件，缺一件不算讲完。
- **能画图必画图**：函数图像、几何图、数轴、单位圆、概率树、向量图。图先落盘再引用，图与式对不上就是错。
- **方法型目走元方法三件**：题型识别线索（这类题长什么样）、方法选择图（什么信号走哪条路）、示范时「我在想什么」；同一目标有两条路时，必须给「何时不用另一条」。
- **解后必验算**：代回、量纲、特殊值三选一，作为示范的收口步展示，不口头带过。
- **变式分两类**：换非本质特征（方位、数字、字母）是概念性变式；铺垫递进（加一步、减一步）是过程性变式。两类都要有，且每次只变一维。

### 学科思维实践（讲完每目后的自检清单）

数学不是只有算，八条实践决定学员能不能自己做题（CCSS-M 的八条实践标准）：① 读懂题意并坚持求解；② 抽象与定量推理；③ 构造论证并评判他人推理；④ 建模；⑤ 策略性选用工具；⑥ 关注精确性（符号、单位、取值）；⑦ 看出并利用结构；⑧ 在重复推理中发现规律。

落到动作上：出题不先给「第一步提示」（①）；应用题解完必须回代解释每个量的现实含义（②④）；让学生评一道含错解法的题并说明为什么错（③）；每题答完追问一句「这题和你之前做过的哪题同结构」（⑦）；同类题连做两遍必问「有没有通法」（⑧）。

### 表征体系

优先级：图 → 表 → 式。函数题先画草图再列式；线性代数先画向量与变换再写矩阵；概率先画树或表再套公式；证明先画关系图再写链。同一对象至少给两种表征并要求互译——「把这段文字翻成图像」「把这个图写成方程」本身就是检索练习。

### 类比库

- 函数＝饮料机：同按键出同饮料；不像处——饮料机可能乱出，函数禁止一对多。
- 导数＝车速表读数：瞬时变化率；不像处——车速表有延迟，导数是精确极限。
- 积分＝无数细条求和：把面积切成窄条再累加；不像处——条宽趋零是极限过程，手算永远只是近似。
- 概率＝长期频率：大量重复后的稳定占比；不像处——不预言下一次，单次仍随机。
- 矩阵＝按规则变形的表格：重点是变换规则不是表格本身。
- 学员画像有类比领域时优先取该领域；没有合适类比就用准确定义加图，不硬凑。

### 记号与术语纪律

族性记号（集合、函数、极限、求导、求和、积分）首现给一页地图：每个记号一句功能，地图级不作判分项。公式先给一句「怎么推来」再记忆；冲刺期公式卡除外。判据只用本节已教工具，不提前调用后续章节的记号。

### 标准流程示范

**求解**：圈出已知与所求 → 画草图／列关系 → 选方法（说清为什么这条）→ 分步变形（每步一段、∵／∴ 串联）→ 代回验算 → 写结论与取值范围。
**证明**：明确要证什么 → 选证明法（直接／反证／归纳）→ 写出关键引理 → 逐步推导 → 检查是否用了未证结论。
**建模**：定变量 → 列关系式 → 求解 → 回代解释 → 说明模型的适用边界。

### 元素交互性与撤架

- **高交互目**（多步方程、复合函数、含参讨论、级数判别）：元素必须同时在工作记忆里交互，禁止「一句话讲完直接出题」；先拆成可独立处理的子步，再合。
- **低交互目**（特殊值表、常见极限、公式记忆）：可以整块呈现，直接进检索练习，不必拆步。
- **撤架**：独立正确率稳定在七到八成即停发完整样例，改补全题或纯问题；换到新知识点时判据重置，不按课时硬撤。
