## S4 复习巩固与复习债治理
### S4 复习巩固（可从逐节学习或结课随时插入）

- **目标**：清空薄弱点与错题，并维持已掌握内容的保持复习。
- **动作（抽取与出题）**：按 `references/assessment.md`「出题流水线」执行。**错误修复**与**保持复习**分开——①**错误修复**：针对薄弱点与错题本出题；②**保持复习**：`## 保持复习` 区的已掌握条目按 due-queue 到期重测（未到期可每若干节 / 每周稀疏抽测 1–2 题，不只复习错题，防「只清错题却丢掉已会能力」）。**due-queue 三区读取（薄弱点/错题本/保持复习）与 `kind`/`reason` 输出口径见本节「due-queue 与复习预算」**；均不讲新内容。**抽取前先做未讲授过滤**（见「复习债治理（R36）」）。**抽取顺序 cw 优先**；`顽固` 条目不走重测，走四步清除链（见下方「闸口」条）。**检索变式口径**见 `references/ops.md`。
- **动作（判分后调度落盘）**：**不心算**——按 `references/assessment.md` 的调度命令取回 JSON 中的 S'（stability_new）、D'（difficulty_new）、due，用文件写入/编辑能力写回条目。
- **动作（收尾与返回）**：复习轮收尾同用「节末收尾五件套」（**teach-back 不省**——可用轻量形态：请学员一句话总结本轮清掉的错因或这条现在怎么想；其余四件保留；第 5 件进度对账照报——复习不掩盖未讲事实）。插入复习时记录**复习返回点**：progress.md 的「复习来源阶段」= 进入 S4 前的阶段（逐节学习 / 结课 / **已完成**），「当前阶段」临时切为「复习巩固」。
- **开场校准（30 秒）**：进入 S4 先跑 `scheduler.py calibration`（**禁止心算**），按 `references/interaction.md`「输出边界与交付形态」呈现开场；不得评价人格，其余边界见本节「校准画像」。
- **元认知教学（四点，据开场报的条数展开）**：①用学员自己的 cw 条目举例说明「流利度 ≠ 存储强度」；②教**答题后延迟自评**（postdiction）——「回顾性」估计，与原信心不是同一种测量（口径见 `references/assessment.md`「判分口径」），只作素材；③**遗忘正常化**：答错按「忘了不是失败，是数据」反馈，去羞耻化；④措辞守当前快照口径（见上条）。**样本分母随「几条」给，不足 5 条加注**；开场报「其中没有」时不展开本节，学员问走 `references/routing.md` 状态轮。
- **按错因分诊补救**：错因分类与补救动作见 `references/interaction.md`「错因分类与补救（T10）」；本阶段只决定抽题与返回阶段。
- **复盘火力分级**：A 级 → 详细整理 + 配同类变式（火力集中处）；B 级 → 记思路要点即可；C 级 → 仅标记知识点、不展开整理。**级不参与 due-queue 排序**，分级只影响整理深度与复盘优先注意力。S4 复习判分可**调整级别**（如 C 级反复错 → 升 B）。
- **考期冲刺（距考试 ≤2 周）**：复习轮与考前提示中说明"通宵突击是用长期巩固换几小时未巩固记忆，睡眠优先于加练；与成绩相关的是**学习期间的规律睡眠**，而非考前一晚"；不强推、不制造焦虑（「熬夜有害」为强证据、「考前一晚补觉有效」无证据——边界标注归维护侧档案 CREDITS.md，不进闸口）。
- **缺省归因修正**：遇到错因为缺省推断（脚本输出标 `meta_default:true`）的条目，先按当下证据归因并写入真实值（这本身就是本轮动作，不得盲目补默认值）；可向学员说明「该条错因为缺省推断，如与实际不符请指正，可推翻重归因」。
- **闸口**：同一薄弱点 **2 轮全部答对且两轮跨日**（R52）→ 从薄弱点清单移除，并**转入 `## 保持复习`**（写入时机与初始值口径见 `本册`「复习调度字段（T04）」，不得直接消失）。**同日多轮全对只计 1 轮**（对齐调度 `same_session` 口径——同日重复答对不记长期保持）；**学员明确要求加速**可同日清除，但转入保持复习的初始条目按 `--grade hard` 档计算（更快到期回访兜底）。清除的同时撤去该目「需巩固」标注（若有，见 `本册`「保持复习区」）。转入保持复习后按 due-queue 到期重测，未到期可稀疏抽测；仍有残留 → 继续复习。**预算耗尽或用户示意结束时**：列出未清项与顺延日期（保留原到期日），按「复习来源阶段」返回或一句简短收尾——**不以「有残留」否决已约定预算**。**顽固条目不参与「连续 2 轮全对 → 移除」的普通清除路径**，走**四步清除链**：①**重教**（可换讲义风格）→ ②**重新计数 2 轮全对** → ③**变式自创关**（清零前最后一关，位置在计数通过之后、移除之前，每条只发生一次）：请学员把自己这条原错题**改造出一道新变式**（改条件 / 改问法 / 换情境任一）并自答自评；导师只核对变式是否真对准原错因——**变了题但考的仍是原错因才算过** → ④**通过后从薄弱点移除并转入保持复习**，不通过 → 回①再重教一轮。②的「2 轮全对」同样按 R52 跨日口径计（同日多轮只计 1 轮）。自创变式题落盘 `exercises/`（文件名前缀 `z-`，如 `z-变式-<日期>.md`），不计入节判分证据比对。
- **错题本清理/归档规则**：某错题对应的薄弱点被清除后，该错题**归档**（移入「错题归档」区，不再参与 S4 抽取与 due-queue）；连续答对 2 轮的错题同样归档；变式自创关通过后，原错题按既有归档规则移入「错题归档」。防止长任务下错题本无限增长。**归档不是遗忘（R53）**：进行中任务每完成 2–3 节（节末落盘时核对计数），从「错题归档」抽 1 条出**变式回访题**（变式优先，原题按 T11 目标保留；不占节核心题量、不计闸口）：答对 → 刷新该条 last、留归档；答错 → 移回「错题本」重新调度，按普通错题流程处理。已完成任务的归档回访由快捷指令「考考我 / 帮我复习」覆盖（`references/routing.md`）。
- **产出**：薄弱点清除记录、错题归档记录、**保持复习条目更新**、本次交接 / 记忆.md 学习记录（可选）；复习结束后按「复习来源阶段」返回——从逐节学习插入则恢复当前节，从结课进入则回到结课重出综合测验，**从已完成进入则返回「已完成」（不撤销课程结果）**；**返回后把「复习来源阶段」清回「无」**（下次进入 S4 时重新记录，避免残留触发告警）。

### 复习债治理（R36）

- **未讲授过滤（抽取前置）**：薄弱点/错题条目所属知识点**尚未讲授**时**不入队**，到期转为安排对应讲授（先教后练，六拍见 `references/interaction.md`）；「已讲授」判据与口径唯一事实源见 `references/assessment.md`「出题范围与未讲授过滤（R35）」（R35）。
- **停新清债线**：任一复习条目**逾期 >2 天** → 当日**停止排新内容**，优先清债（插入一轮 S4）；清偿走每日配额，不要求一次清空。
- **每日配额与时间盒**：清债设**每日固定配额（≤5 条）与 45 分钟时间盒**；清不完的自动顺延（保留原到期日并在对账中可见），**禁止向学员展示「累计欠账 N 条」式清单施压**——对学员只说「今天清这 X 条就够」。
- **顺延形态判据（标 E5，工程约定不是证据）**：条目元数据里 `顺延>0` → **下一轮开场必须明示队列长度与顺延方案**。判据是**形态不是阈值**——不引入任何新数字（三个撤架阈值的前车之鉴见 `docs/research/threshold-provenance-audit.md`）；写入 `顺延` 本身就是「这次没清」的证据，不再另判「且未清完」。判分落盘时**同轮清零**（否则已复习条目永久带 `顺延>0`，债永远清不掉）。
- **披露面（学员可见，只说今天做多少）**：对学员只报「**今天清这 X 条就够**」。三条禁止项写死：① 禁「累计欠账 N 条」式清单；② 禁把 `顺延` 数当进度指标展示；③ 禁把停新原因归到学员身上（对齐「不归因到人」）。
- **与停新清债线的关系**：`W-REVIEW-DEBT`（`progress_check` 告警）**只验数据形态**，**验不了「模型有没有明示」**——闸口看不到对话，不得把「数据对了」当成「行为做了」。该告警**不参与**「连续 3 天触发停新」计数：`progress.md` 没有承载「连续 N 天」的字段，缺口见 [票 75](https://github.com/WangZehao0419/learn-task-workflow/issues/75)，本条不新造字段。
- **债不滚雪球**：连续 3 天触发停新清债线 → 说明产能基准失准，按「产能基准与排产」下调一档并重排后续节，而不是继续压清债配额。

## due-queue 与复习预算
- `due-queue` 同时读取「薄弱点」「错题本」「保持复习」三区，输出 `kind` 与 `reason`，schema 以契约为准；刚入库/当日的条目不重复入队。
- **未讲授过滤（R35 前置）**：未讲授条目不入队、转安排对应讲授（先教后练）；口径唯一事实源见「出题范围与未讲授过滤（R35）」。
- 进入新节前按本次可用时间设预算（复习不超过约 1/3 课时，其余留给新内容）；队列非空 → 优先清「关键先修 + 高影响错误（cw / 顽固）+ 到期的保持复习」，其余显式顺延（保留原到期日并在进度对账中可见）；队列长（>5 条）→ 明示队列长度与顺延方案，默认按预算顺延并继续新内容、不空等批准。
- 排序契约：cw → 最逾期 → due 早 → 稳定序；`顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- **两种「顺延」不是一件事**：① **`reschedule` 式改期**（若将来引入）会**改写 `due`**，把逾期推后，等于抹掉「这次没清」的证据；② 本仓现用的是**保留原到期日**的顺延——`due` 一字不动，只在条目元数据写 `顺延=n` 留痕。判据只认第②种：`due` 被改过就看不出债了。`顺延` **不进排序**（不抬优先级、不降优先级），只作披露。
- 缺日期/坏条目的口径见本节「复习调度字段（T04）」：缺日期不入队、`W-UNPARSED-ITEM`；不得以当日或猜值补造。

## 间隔调度与调度数据语义
### 间隔调度

`scripts/scheduler.py` 采用 **FSRS-6 增长律 + 本仓记账法**：稳定度 S / 难度 D 双参数与六个公式（遗忘曲线、下次间隔、S0、D0、难度更新、成功/遗忘后 S）逐条照抄 FSRS-6 参考实现，21 个默认参数、边界取 fsrs-rs（Anki 实际在用的那套）；**记账法仍是本仓的**——四档判分、`elapsed=0` 同会话特判、纯文本 progress.md、零第三方依赖、不做 optimizer 参数拟合。公式结构见 `scheduler.py` docstring，常数唯一来源 = 契约 `scheduler` 块；本册只写策略与调用时机。**对学员不解释调度算法**（红线 6），这里只是维护侧口径。

两个旋钮决定全部间隔尺度：`desired_retention`（默认 0.9，即「承诺复习后仍记得的概率」）与 `maximum_interval`（默认 365 天，**产品护栏，偏离 FSRS 官方默认**——FSRS 的 S 上限是 36500 天）。改 `desired_retention` 会让所有既有条目**下一次**间隔跳变（r=0.85 时 S=100 → 约 130 天；r=0.95 → 约 74 天），改前须知会这件事。

#### 调用速查

> **有效域与边界（脚本强制、非有限数一律 exit 2 结构化拒绝）**：S ∈ [0.0001, 36500]、**D ∈ [1,10] 连续（无粒度要求）**、**elapsed 有限且 ≥0 且四档都必填**（失败档的遗忘后 S 也依赖 R(t,S)）；`interval_days` 恒 ≥ 1 且 ≤ `maximum_interval`（365）；日期加法越界同样拒绝，不裸崩、不输出非有限数。

- **新条目首次调度**（S3 新产生的薄弱点 / 错题 / 保持复习）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <判分档> --new-card --last <今天> --today <今天>`
  —— grade 取该条判分档（判错=again）；保持复习初始条目用 `--grade good`（例外：学员要求加速的同日清除按 `--grade hard` 档入保持，见本节「复习债治理」闸口）；新卡 S0 / D0 **只由评分档决定**，**数值唯一来源 = 契约 `scheduler.w`**（本册不复制——要核对就跑脚本看 `stability_new` / `difficulty_new`）；首间隔四档为 1 / 1 / 2 / 8 天（again / hard / good / easy）。返回 stability_new / difficulty_new / due。**`--init-shift` 已删除**——旧调用侧传它一律 exit 2（argparse 未知参数），不再静默接受。
- **既有条目复习判分**（S4）：
  `python "<技能根>/scripts/scheduler.py" next-interval --grade <grade> --stability <S> --difficulty <D> --last <last> --today <今天> [--current-due <原due>]`。
  **同会话重复答对**（`--last` 与 `--today` 同日）：必须同时传 `--current-due <原due>`；脚本返回 `same_session=true` 并原样返回该 due，S/D 不变——只刷新召回，不把一天内反复刷题记成长期保持（FSRS-6 的同日复习公式 w17–w19 本仓不实现）。非同日复习不传 `--current-due`。保持复习按同一命令更新；`partial` 用 `again`，`未判/作废` 不写 S/D。前提：`due` 由脚本生成、不要手改；手改 due 的条目先按当前 S 与手工 due 对齐后再复习。

#### 校准画像

校准画像是脚本对既有「信心 / cw」元数据的**实时只读统计**：**不新增任何 progress.md 字段，不落任何新文件**。进入 S4 时由模型运行：

`python "<技能根>/scripts/scheduler.py" calibration --root "<数据根>" [--slug "<slug>"]`

- **指标名称**：**当前问题记录中的高信心错误占比**（cw 条目数 ÷ 分母；脚本键 `overconfidence_rate`）——它只描述「当前未清除问题记录」中高信心错误的投影比例，**不得用来评价学员整体人格或整体校准水平**（分母只含问题记录、不含正确作答，天然不代表整体校准）。若需整体校准判断，**必须另有**包含正确与错误作答、采样时机明确的有效窗口——当前快照口径不提供该窗口。
- **畸形数据判读**：脚本先按 `evt` 归组、合并互补字段，再形成「合法观察」（可推算日期 + 无冲突），最后才统计。**分子 `cw` 只数「反馈前信心 ≥4 且判错」的合法观察**——`cw` 必须是同口径高信心错误观察的**子集**；任何**孤立 cw**（有 cw 无显式信心）、**低信心 cw**（信心 <4）或**同 evt 投影冲突**都会单独告警并令脚本**输出 `overconfidence_rate: null` + `rate_valid:false` + `invalid_reason`**（不展示不可靠读数）；先核对补齐数据，不得采信该画像做元认知教学。
- **窗口口径：快照口径，不做时间窗**。统计对象是「当前未清除的条目」，教学呈现措辞必须用「当前快照」，禁称「全程累计」。
- **投影去重与口径披露**：条目**带 `evt=` 作答事件 ID** 时按事件归组，同一作答的投影（错题/薄弱点）**只计一次**，互补字段合并；**无 `evt=` 的条目各成单条观察**计入统计，脚本逐条报 `W-NO-EVT` 提示补标（补同一 `evt` 后同次作答的投影才会去重）。
- **两层语义（防模型混用）**：`cw` 是**逐条重测信号**——单条「自信但错」的调度标记，回答「这条该不该先练」（作用在 due-queue 排序优先）；校准画像是**聚合教学素材**——把当前问题记录里的信心标记汇总成**问题投影比例**，**只回答「当前错题快照里的高信心占比」**，**不得**回答「这位学员整体是否系统性高估自己」。一句话：**cw 是画像的输入行，画像是 cw 的列总和**。脚本只算不判；「本快照读数如何解读与呈现」归模型，但**不得越界作整体人格判断**。

### 调度数据语义

字段格式、默认值与解析器口径以 `references/intake.md` 为准；本册只保留评估侧语义：

- **错因是语义属性**：缺省值只是脚本输出侧的占位回显（`meta_default:true`），模型侧必须按当下归因判断写入真实值；不得盲目补「知识性」把技巧性失误误导到重学。

## 复习调度字段（T04）
薄弱点条目的调度元数据放**行尾全角括号内**（半角括号亦兼容，推荐全角）、逗号分隔的 `键=值`（`cw`/`顽固` 为无值标记）；错题本与保持复习条目在行尾追加「｜ 元数据：…」段（竖线分段与「元数据：」冒号均全角/半角双兼容）。保持复习行推荐以 `[YYYY-MM-DD]` 掌握日期开头；缺日期时用「最近更新」兜底并告警，仍缺 → `W-UNPARSED-ITEM` 不入队（不猜当日）。解析器只认这些挂载点，其余文本不动。`S'/D'/due` 的计算由 `scripts/scheduler.py next-interval` 负责（判分归模型、算数归脚本，调用细则见本节「间隔调度」）。`due-queue` 输出 `reason` 字段（到期/逾期/优先级的人类可读说明）与 `顺延` 计数，schema 为 `ltw-due-queue/5`（v2.7 因 D 回显形态随 FSRS-6 换律而变升 /4；v2.8 加 `顺延` 回显键升 /5；排序契约始终不动）。`错因`/`级`/`meta_default` 只对薄弱点/错题有意义；`kind=保持` 时前者为空、`meta_default=false`，不参与问题元数据。

| 字段 | 类型/取值 | 语义 | 默认值（缺省时） |
|------|-----------|------|------------------|
| S | 浮点（天），[0.0001, 36500] | 稳定天数（FSRS-6 的 stability），间隔重复核心参数 | 2.3065（= S0(good)） |
| D | 浮点连续值，[1,10] | 难度（FSRS-6 的 difficulty），**无粒度要求**，落盘保留 4 位小数 | 2.1181（= D0(good)） |
| last | YYYY-MM-DD | 最近一次判分日期（绝对日期，禁相对日期） | 取 progress.md「最近更新」；仍缺 → 不入队，报 `W-UNPARSED-ITEM`（不猜当日） |
| due | YYYY-MM-DD | 下次复习日。**新写由 `scheduler.py` 以「本次复习日 + interval」计算**（见本节「间隔调度」）；缺 due 时按 `last + I(desired_retention, S)` 兜底推算（与正式路径同一个 `interval_for`，不另算一套） | 由 last 推算 |
| 信心 | 1–5 | 作答信心自评（**反馈前**提交方可用于 cw/校准；反馈后补报标回顾性） | 未写 → 不计入校准分母（不补 3） |
| cw | 标记（无值） | 自信但错（**反馈前**信心 ≥4 且判错），due-queue 排序优先 | 无 |
| 顽固 | 标记（无值） | 提示阶梯两次到梯底，重教不重测（见 S3/S4） | 无 |
| evt | 可选 ID | **作答事件 ID**：同一次作答的投影（错题 / 薄弱点）共享同一 `evt`，供校准统计去重（T04） | 无 |
| 错因 | 枚举：知识性 / 理解性 / 技巧性 | 归因分类，决定 S4 补救动作（重学 / 审题圈画 / 限时技巧）。**语义属性，归模型判断写入，禁止脚本代判** | 知识性 |
| 顺延 | 非负整数 | **干预留痕计数**：该条目被「显式顺延」的次数（保留原到期日、不判分）。**不改 S/D、不写 `last`、不产生 `evt`**；`顺延>0` 是「这段等待期没清完」的形态证据，判分落盘同轮清零（删键或写 0）。坏值（`顺延=abc`/`顺延=-1`）走 `invalid_tokens` → 按缺省链继续、不硬拒 | 缺省视为 0（无顺延） |
| 级 | 枚举：A / B / C | A=反复出错 / 直接影响学习目标达成的核心条目（详细整理+变式）；B=一般理解偏差（记思路）；C=纯粗心（仅标知识点）。与错因同轮由模型定级，S4 复习判分可调整级别 | B |

- `cw` 只由「信心 ≥4 且判错」产生；cw 条目修复后照常走清除/归档规则。
- due-queue 对 `顽固` 条目标 `teach:true`（排序不豁免），由模型据文本规则改走重教。
- **`错因` 枚举放元数据段，与既有自由文本「错因：<具体描述>」并存不冲突**：自由文本答「错在哪」（行内 `错因：` 全角冒号写法），枚举答「属哪类、该用什么补救」（元数据段内 `错因=` 等号写法）。解析器只在元数据段内搜 `错因=`，正则锚定于元数据段，不会误吃行首自由文本。
- **`级` 与 `错因` 是内容属性（错什么），S/D 是调度属性（何时再练），互不替代；`级` 不参与 due-queue 排序**（排序契约 cw→最逾期→due 早→稳定序不变），分级只影响整理深度与复盘注意力，脚本仅在输出中回显 错因/级 供模型取用。
- **可选 token `子类=`**：错因第六类"过度泛化"写 `错因=理解性` + `子类=过度泛化`；`scheduler.py` 已识别该键（不参与调度计算、不输出到 due-queue），不会再报 `W-META-INVALID`。

**字段合法性**（由 `scripts/progress_check.py` 校验）：`当前阶段`、`类型`、`学科族` 必须为上述枚举值之一；`复习来源阶段` 在 S4 期间必须为合法返回枚举（**逐节学习 / 结课 / 已完成**，任意字符串被拒）。**必填项随阶段变化**：`当前阶段`、`类型`、`学科族`、`目标` 全程必填；**`起点` 在 S0（接料建档）与 S1（诊断摸底，进行中）不要求，自诊断结束进入 S2 起（计划确认中/逐节学习/复习巩固/结课/已完成）必填**——S1 尚未产出「起点」属正常，不得据此误判。
