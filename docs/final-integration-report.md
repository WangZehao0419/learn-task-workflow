- 教学规则语料零丢失，硬约束（判分四态/调度/三簿/版本）全部保持

**必须随发布声明的限制（不可省略）**：
1. **红线盲回放 11/11 与真人冷读尚未执行**。资产已就绪（`evals/evals.json` 的
   `redline_regression` / `human_cold_read`），但 `verdict` 全部是 `未验证`。
   按 `evidence_policy`：**未跑条目不得标「通过」**。所以「红线零违规」目前**未被证明**，
   只是判据已自足可判。
2. **触发率 eval 与 baseline 对照尚未执行**。用例（20 条）与汇总工具已就绪，
   但没有任何实测数字；`compare-baseline.py` 在无数据时明确输出 `no-data`。
3. **官方 Agent Skills 规范符合度未出具报告**（按规格它只作报告项，不设闸）。

### 因此，发布口径是：
