# v9.7.0 排版证据档案（维护者侧，不进安装包）

> 目的：为 v9.7.0「呈现与排版系统重构」逐条登记来源、结论、落地位置与边界。本文是研究档案，不是运行时规则；运行时唯一事实源仍是 `references/` 各 owner。

## 1. 范围与方法

- **范围**：聊天讲授轮（`teaching/presentation.md`）、讲义版式（`handout/typography.md`）、共享文字排印（`ops/typography.md`）、读者版校验（`scripts/ltw_typography.py`）。
- **来源家族**：教材体系、AI 家教产品、文档可读性指南、图像可视化、教学设计、教学论文、社区讨论、Agent Skill/GitHub/ClawHub、中文出版规范、Markdown 渲染器。
- **检索方式**：官方文档/标准/论文优先；产品与社区来源只作设计参考；不能核到原文的条目标「方向支持」或「未核实」，不写成「研究证明」。
- **证据分级**：
  - **A**：实验/元分析/标准原文可直接支持（如 Mayer/Noetel、Sweller & Cooper、Kestin 2025、Delgado 2018、WCAG 1.4.8、W3C clreq、GB/T 15834/15835）。
  - **B**：方向支持/复制研究/排版惯例（如 Hartley & Trueman 1983、Waller 1982、Butterick、NN/g、Bjork & Bjork 2011、Meyer et al. 2015）。
  - **C**：产品/社区/设计决策（如 OpenStax、Khanmigo、Math Academy、OpenAI Study Mode、Wikipedia AISIGNS、ClawHub）。
- **边界**：排版可读性研究不等于学习成绩；单篇效应量不是固定承诺；产品与社区来源不作实验证据。

## 2. 逐领域发现

### 2.1 教材体系（C → A 的结构参考）

- **OpenStax College Algebra 2e**：章首列出章节大纲与学习目标；节内有 **Be Prepared**（前置检查）、**worked example** 与紧跟的 **Try It**（配对练习）、**Everyday Connection**、**Key Terms / Key Equations**、**Section Summary**、**Review Exercises**、**Answer Key**。
- **可吸收**：章首目标/前置、例后即练、节末小结、答案分区、图表/例题编号、术语/公式索引。
- **不吸收**：多栏正文、彩色框堆叠、图标/装饰、把教材做成平台。现有 ①–⑤ schema 已覆盖约 80%，本批只补「编号/图注/教学例版面/章级导航」，不新增第七套风格。
- **落地**：`handout/typography.md` §4（编号/图注）、§8（章节层）、§9（教学例版面）；`handout/templates.md` 保留内容槽位。

### 2.2 AI 家教产品（C，设计参考）

- **Khanmigo**：不直接给答案；以「你认为下一步是什么」逐步引导；识别错误类型后给提示；复杂计算调用工具而非纯文本猜测。
- **Math Academy**：知识图谱 + 精熟学习 + 间隔复习；每主题小步任务，首次学习约 10 题、复习 3–5 题；默认「先示范/讲解，再做」。
- **OpenAI Study Mode**：把信息组织成易跟随的小节，小节间 quick check；不直接给答案；支持「换个讲法/考考我」。
- **Duolingo**：bite-size 回合、即时反馈、连续成功体验。
- **可吸收**：一次一步、提示阶梯、每步检查、反馈后给具体下一步、路线先行。
- **不吸收**：学习风格适配、游戏化装饰、无限对话、emoji 开关；这些是产品增长手段，不是教学证据。
- **落地**：`presentation.md`「对话呈现系统」「反馈轮/提示轮/路线轮版式」。

### 2.3 文档可读性指南（A/B）

- **Butterick《Practical Typography》key rules**：行宽 45–90 字符；印刷 10–12pt、网页 15–25px；行距 120–145%；少用加粗/斜体，不并用；除链接外不用下划线；慎用居中；段距 4–10pt 或首行缩进二选一。
- **WCAG 2.2 1.4.8（AAA）**：行宽 ≤80 字符（CJK 40）；文本不两端对齐；行距 ≥1.5；段距 ≥1.5×行距；200% 缩放无横向滚动；用户可自选前景/背景色。
- **W3C clreq**：中文正文行长 17–40 字、横排最长 48 字；行首行尾禁则、标点挤压/悬挂、中英文混排间距、数字与单位、着重号等。
- **ISO 24495-1:2023**：简明语言四原则——相关、可找、可理解、可用。
- **NN/g**：79% 用户扫描、16% 逐字读；F 型/层饼型扫描；TLDR 先行。
- **冲突**：中文行长研究存在 17–48 字/行与 76 字/行两组结果；本技能取保守区间 25–40 字、上限 48，不把 76 当默认。
- **落地**：`handout/typography.md` §2 版式基线、§3 字体系统；`ops/typography.md` 标点/空格/数字/单位。

### 2.4 图像可视化（A/B）

- **Mayer CTML**：coherence（删无关材料）、signaling（突出关键）、spatial contiguity（图与解释邻近）、segmenting（分段）、pre-training（先备概念）、redundancy（不重复同一信息）；效应量受先验知识、材料复杂度、媒介与时长调节。
- **Tufte**：data-ink ratio、small multiples、去装饰；图内直接标注优于图例。
- **WCAG**：颜色不是唯一编码；文字对比 ≥4.5:1，图形/线条 ≥3:1；黑白/去色可读。
- **可吸收**：图随文、图注说结论、alt、颜色+形状/线型、去色可读、一图一问、节点 ≤7±2。
- **不吸收**：装饰图/3D/阴影/背景纹理；不为每节强行配图。
- **落地**：`handout/typography.md` §4 元素系统、§7 无障碍、§10 元素预算；`quality.md`「图像可视化双轨」保留工作流。

### 2.5 教学设计（A/B）

- **Rosenshine 2012 十条**：小步呈现、一次一点；提问与检查理解；提供模型/示范；引导练习；独立练习；周/月复习。
- **Sweller & Cooper 1985**：新手先学完整工作样例，优于直接解题。
- **Merrill / 4C/ID / CLT**：成分显示、整体任务、认知负荷——本仓六拍与 ①–⑤ 已吸收。
- **可吸收**：小步、示范、检查、独立练习；聊天「步骤行」一行一步，不把多步塞进一段。
- **不吸收**：新增教学阶段/闸口；六拍与判分口径不动。
- **落地**：`presentation.md` 结构预算；`lesson-flow.md` 六拍不变。

### 2.6 教学论文（A/B）

- **Kestin et al. 2025（Scientific Reports）**：AI 家教 RCT，系统提示约束「简短、一次只给一步」；学习增益 0.73–1.3 SD，用时更短。
- **Delgado et al. 2018**：54 研究、约 17 万参与者；纸面理解优于屏幕，说明文/限时/长文更明显；效应不大且非所有阅读。
- **Bjork & Bjork 2011**：流利度（当下顺手）≠ 存储强度（隔天还记得）；排版让内容「看起来简单」不等于学会。
- **Meyer et al. 2015 / Rummer et al. 2016 / Xie et al. 2018 / Kühl 2020**：难读字体（disfluency）效果不稳定，复制失败与元分析编码争议并存；**不采用**。
- **落地**：`handout/typography.md` §5 打印契约、§11 证据边界；`presentation.md` 语气契约。

### 2.7 社区讨论（C）

- **Wikipedia《Signs of AI writing》**：过度加粗、列表化标题、层级错误、emoji 滥用、破折号泛滥、模板化过渡语。
- **HN/Reddit 对 AI 输出的批评**：观点之间本有逻辑关联却硬拆成项目符号；嵌套列表；空洞总结；三段式排比；「不是……而是……」对偶句堆叠。
- **可吸收**：列 6 条可判定模式，挂在「语气契约」；不做「检测 AI」的伪科学。
- **不吸收**：为了「像人」而故意写长/写散；不牺牲必要推导与完整示例。
- **落地**：`presentation.md`「反 AI 腔 6 条」。

### 2.8 Agent Skill / GitHub / ClawHub（C）

- **ClawHub/OpenClaw**：Skill = Markdown + YAML frontmatter；显式触发、渐进披露、失败即停；社区技能多为工作流封装，不提供排版规则。
- **Mr. Ranedeer AI Tutor**：可配置 Depth / Learning-Style / Communication-Style / Tone / Reasoning-Framework / Emojis；其中「学习风格」是神经迷思，不采纳；可借鉴「显式输出契约 + 可配置深度」。
- **Anthropic Skills**：SKILL.md 短、references 按需加载、示例优先；本仓已有。
- **GitHub/Markdown**：CommonMark 可移植性优先；不用 `> [!NOTE]`、复杂 HTML、脚注依赖；嵌套列表在部分宿主渲染不稳。
- **落地**：按场景加载的 owner + 模块化校验；聊天禁嵌套列表/HTML/标题。

### 2.9 中文出版规范（A）

- **GB/T 15834-2011《标点符号用法》**：17 类标点；引号、书名号、破折号、省略号、范围号等。
- **GB/T 15835-2011《出版物上数字用法》**：阿拉伯数字 vs 汉字数字；得体原则、局部体例一致；日期、概数、计量。
- **GB 3100-3102《量和单位》**：数值与单位之间空格；单位符号正体；量纲与单位制。
- **可吸收**：全角标点、中英文空格、数字/单位、范围号、引号/书名号、破折号/省略号；不把出版级规范变成 E 级闸口。
- **落地**：`ops/typography.md` 全文；`handout/typography.md` §6 印刷侧。

### 2.10 Markdown 渲染器（C）

- 渲染器差异：行长/字号/行距不可控；表格列宽、代码换行、引用块样式、`<details>` 支持不一；`<br>`/双空格换行在部分宿主被吞。
- **可吸收**：规则写成「内容级、渲染器无关」；不承诺具体主题；打印契约作为导出指导，不写成 CSS 承诺。
- **落地**：`handout/typography.md` §2/§5；`ops/typography.md` §7 不手写断行。

## 4. 不采纳清单

| 项 | 原因 |
|---|---|
| 学习风格（视觉/听觉/动觉）适配 | 神经迷思；无稳定证据；Mr. Ranedeer 的配置不作教学依据 |
| bionic reading（首字母加粗） | 无收益；Zhao et al. 2025 RCT 不优于原文（本仓 v9.x 已排除） |
| 「注意力只有 8 秒」 | 营销数字，学界不认可 |
| 难读字体 / Sans Forgetica / 低对比制造「努力感」 | 效果不稳定、复制失败；排版应降低无关负荷 |
| 两端对齐 | WCAG 1.4.8 不允许；中文易出现字距裂口 |
| 全大写/下划线/彩色字强调 | Butterick/WCAG；跨渲染器不稳 |
| 装饰 emoji/图标/3D/阴影/背景纹理 | coherence 原则；增加无关负荷 |
| 双栏中文正文 | 行长过短、断行频繁；不利于长时阅读 |
| `> [!NOTE]` 等宿主专属 callout | 可移植性差；只用引用块 + 加粗标签 |
| 嵌套列表（聊天） | 渲染不稳、扫读差；用步骤行/拆段替代 |
| 「留白越多越好」 | 留白是结构信号，不是装饰；过度留白降低密度 |
| 「一行一个观点」拆碎推导 | 必要推导必须连续；拆段以「一个判断」为界 |
| 「所有内容都用表格」 | 表格只用于并列属性对比；因果/论证用正文 |
| Forte 渐进式总结分层加粗 | 个人知识管理经验，无教学实验；与信号稀缺冲突 |
| 学习金字塔/左右脑/一万小时 | 已在本仓 v9.5 蓝军清单排除 |

## 5. 未核实 / 未执行

- 未逐篇核对全部论文的精确效应量与页码；引用时按 `ops/evidence.md` 的分级标注。
- 中文行长证据冲突未解决；本批取 25–40 字、上限 48，属保守取舍。
- 打印/PDF 未在具体引擎（pandoc/xelatex、浏览器打印、Prince）上逐项实测；打印契约是导出指导，不声称已打印验证。
- 未跑真人冷读与延迟迁移；`--reader` 只证明结构项，不证明教学效果。
- 反 AI 腔、产品轮型、教材结构属社区/产品/设计参考，不是实验证据。
- 未验证所有 Markdown 渲染器对 `<details>`、表格对齐、引用块的实际支持。

## 6. 设计决策与边界

- **版式基线是参考值，不是闸口**：不因 px/pt 不达标阻断；只把「行长、左对齐、单栏、黑白可读、图注/alt」作为默认不变量。
- **4 个新 W 检查不阻断**：标题后正文、图注、链接文字、数值列右对齐；命中后同轮修复或显式后置。
- **加载预算上升是自觉取舍**：单一 owner + 无重复的代价；s3-teach 48k、s3-handout 74k、s3-deep 42.5k。
- **不引入 CSS/JS/渲染脚本**：规则按渲染器无关写；未来若加样式文件，不改规则。
- **不新增教学阶段/闸口/学习者字段**：本批只改呈现层。

## 7. 结论

v9.7.0 的排版规则可分为三类：**标准依据**（中文标点/数字/单位、WCAG/clreq 行长与对比度）、**方向支持**（标题 access structure、小步/示范/检查、纸面优势）、**设计决策/产品参考**（轮型、结构预算、反 AI 腔、元素预算）。三类都在 `ops/evidence.md` 与各 owner 中标明边界；不把「排版好看」写成「学习更好」，也不把单篇效应量当固定收益。
