## 2. 外部调研（联网，来源按可信度分层）

### 官方规范
- CommonMark Spec §6.3（0.31.2）：列表标记后必须跟空格/制表符——`1.（题）`不构成列表。https://spec.commonmark.org/0.31.2/
- W3C《中文排版需求》clreq：全角标点、中西文混排间距、避头尾。https://w3c.github.io/clreq/zh/
- GitHub 数学表达式文档：行内公式定界符兼容性分歧（`$...$`/`` $`...`$ ``/```math```）。https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions
- Google 开发者文档风格指南（表格）：≥3 个相关信息才用表，保持窄而简单。https://developers.google.com/style/tables
- W3C WAI 标题教程：层级连续（不跳级）为最佳实践。https://www.w3.org/WAI/tutorials/page-structure/headings/
- Anthropic prompt engineering 文档：范例（multishot）比描述更能锁定模型的格式/语气/结构。https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview

### 学术
- Miller 1956 / Cowan 2001：工作记忆 7±2 / 4±1 chunks——列表 ≤7 项、图元素 ≤7±2 的阈值根源。
- Mayer《Multimedia Learning》及 2014 证据综述：multimedia/coherence/signaling/spatial-contiguity/segmenting 原则——配图触发条件、「查值用表、装饰图删除」的依据。
- IFEval（arXiv:2311.07911）/ AutoIF（arXiv:2406.13542）/ FollowBench：LLM 对**可验证约束**（数字阈值、格式标记）遵守率高且可自动回归；模糊原则（「简洁、美观」）遵守不稳定；约束叠加时遵守率显著下降——「激活硬规则 ≤15 条、其余外置 lint 后置检查」的依据。

### 行业指南
- NN/g：How Users Read on the Web（扫读 20%–28%）、Concise/Scannable/Objective（简洁文案可用性 +58%）、F 型模式、bulleted lists 规范。https://www.nngroup.com/articles/how-users-read-on-the-web/
- Abela 图表选择器 / FT Visual Vocabulary：比较→柱状、趋势→折线、构成→饼、关系→散点。https://ft-interactive.github.io/visual-vocabulary/
- Stephen Few：查值用表、看模式用图；Baymard 行长 50–75 CPL（中文折算 25–45 字/行）。

### 社区
- 中文文案排版指北（盘古之白等）。https://github.com/sparanoid/chinese-copywriting-guidelines
- Anti-Slop / Field Guide to AI Slop：AI 排版反模式（过度加粗、滥用分隔线、八股结构）——问题在「过度且均匀使用」，不在元素本身。

## 3. 落地转化（本版采用的规范写法）

- **数字阈值 + 正反例**优于原则式表述（IFEval 证据）；
