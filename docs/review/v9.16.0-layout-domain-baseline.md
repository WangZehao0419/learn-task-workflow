## 1. 目标结构与分类学

分类学 = 「层级×载体」二维（与 subjects 的「学科群×场景」同构，文件名编码二维）；与设计系统文档惯例（字级 foundations / 结构 structural / 载体版面 components 分离）对齐。

| 新路径 | 来源 | 分类（层级×载体） |
|---|---|---|
| references/layout/doc-structure.md | ← references/ops/layout.md | 结构层·落盘文件（文档结构性，E/W 硬禁令） |
| references/layout/char-typography.md | ← references/ops/typography.md | 字级层·跨载体（标点/空格/数字/单位/字体语义） |
| references/layout/chat-round.md | ← references/teaching/round-layout.md | 轮版式·交付轮 |
| references/layout/chat-presentation.md | ← references/teaching/presentation.md | 轮版式·讲授轮（混合正本：含内容契约+语气） |
| references/layout/handout-page.md | ← references/handout/typography.md | 版面层·讲义（元素系统含表格/信息卡=信息可视化落点） |
| references/layout/handout-figures.md | ← references/handout/figures.md | 视觉层·讲义（图像可视化双轨+图表选型） |

| references/layout/formula-subjects.md | ← references/ops/formula-subjects.md | 特化·公式×学科（物化统记号） |

设计裁决：

1. **正本边界零重排**：11 册正文与 owns/must-not-define 边界是 v9.13.x 三轮去重收敛的资产；本批推倒重设的合理边界是目录与命名，不是拆散正本。
2. **不新建 layout/common.md**：subjects/common.md 的独有职能（学科族未定时的兜底加载）版式域不存在——场景表总是知道加载哪册；跨册裁决已由各册互指 must-not-define 网络承担（v9.13.2 正本归一成果）；新建会撞「文件必属某场景」契约约束且吃预算。域地图由 SKILL.md 目录导航行+各册 owns 头承担。
3. **同名消除红利**：ops/typography.md 与 handout/typography.md 撞 basename（_normalize_target 兜底解析脆弱点）随改名消除；layout/doc-structure.md 与 data/layout.md（数据根目录布局，同名不同物，不迁）从此无混淆。
4. **files[].id 对齐**：id 改为 `layout-` 前缀，同步 rules.json 内 id 引用。
5. **「信息可视化」不单独设册**：已由 handout-page 元素系统（表格/答案框/details）+ handout-figures 图表选型覆盖，拆散元素系统违反内聚并断 I-ANSWER-BOX-VISUAL owner 锚。
