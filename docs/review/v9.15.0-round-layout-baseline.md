## 4. 引号口径依据变化（标准依据 → 设计决策）

- 旧口径：中文引号用 ""（对齐 GB/T 15834-2011 横排主形态，直角引号定位竖排）。
- 新口径：**功能分工**——「」＝标示（把文字当名字/称呼用：术语、目名、题号、条目名、指令词；文件与小节锚点引用一律「」）；""＝引述（把文字当话引用：学员原话、题面原文、材料成句）。辅助判据：引文含句读（、，。；：？！）必 ""，无句读默认「」，拿不准且无句读用「」；引中引按形态对换（""↔''、「」↔『』）；引用原文保持原样。**聊天轮与落盘文件同一规则。**
- 依据性质：GB/T 15834 未禁「」横排，本条为自主体例（设计决策），不再是标准依据；理由＝①98 册文档行文全用「」，规则与示例一致后「示例说 B」失效模式消除；②「」全角方正、与逗号/撇号/英文直引号不混淆，聊天扫读定位强；③句读辅助判据使分工可判定。
- 机检现状：无引号形态检查；候选后续＝ltw_typography 增「句读入「」」W 级检查（只管落盘），未列入本批。
