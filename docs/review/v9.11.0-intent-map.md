## 3. 口径

- `local` = 该规则没有跨文件 consumer；仍在原 owner 生效，不进入 intent 指针闭合检查。
- 同一 intent 多个 rule ID 时，编号全部保留；正文合并到 owner 小节，其他位置只留指针。
- 多 scope（定义/应用/视觉/标准等）用 `cluster` + consumer `role` 表达；同一 owner 小节不得被两个 intent 无声明共用。
- `scenes` 只列 owner 可加载且至少有一个 consumer 为核心/叠加文件的场景；跨场景规则走补读或场景切换。
