## 4. 计划外（2 项，均为补偿性改动，已核验）

| 改动 | 原因 | 核验 |
|---|---|---|
| `ops/formulas.md` 恢复 6 条边界规则 bullet（触发/不触发/混合任务/跨学科适用/不设默认定界符/边界分工）+ blockquote 与职责段间空行 | 6 条规则为 `- ` 行格式，统一变换按「块内 bullet=导航」误删；与回滚锚 `pre-v9.13.4-toc-slim` 逐字比对后恢复 | 恢复后该文件 diff 仅剩 `## 目录` 行 + 5 条导航 bullet + 2 空行删除；`--topology`/`--coverage` 0 issues |
| `handout/typography.md` 补回「相关正本」blockquote 与职责段间空行 | 同款空行吞没问题；空行缺失会使段落被 markdown 吸进引用块、改变渲染语义 | 该文件 diff 收敛为纯 bullet 删除 |

**方法论沉淀**：批量删行变换的「格式相同 ≠ 语义相同」——`- ` bullet 行在目录块里可能是导航、也可能是实质规则；凡按行前缀分类的批量变换，必须先对每文件的保留类行做语义核对，或把断言从「行数一致」升级为「保留行逐字比对」。
